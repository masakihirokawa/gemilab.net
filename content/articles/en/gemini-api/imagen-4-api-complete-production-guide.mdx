## What Changed from Imagen 3 to Imagen 4

The Imagen 4 family is now generally available through the Gemini API, and it represents a significant leap forward from Imagen 3. Three improvements stand out in practice.

First, text rendering accuracy. Imagen 3 would often garble longer text strings, especially at smaller font sizes. Imagen 4 maintains correct spelling even with small fonts, which makes it genuinely useful for posters, comics, slides, and marketing materials where text accuracy is non-negotiable.

Second, resolution. Both Standard and Ultra now support up to 2048×2048 pixel (2K) output, covering print-quality and digital signage use cases that previously required post-processing upscaling.

Third, tiered models. With Fast, Standard, and Ultra available, you can match speed, quality, and cost to each use case instead of using a single model for everything. This flexibility is what makes Imagen 4 practical for production workloads.

If you need a refresher on the previous generation, see our [Imagen 3 API Complete Guide](/en/articles/gemini-advanced/gemini-imagen-3-image-generation-api-guide).

## Understanding the Three Model Tiers

Each Imagen 4 model targets a distinct production scenario.

**Imagen 4 Fast** (`imagen-4.0-fast-generate-001`) generates images in roughly 2.7 seconds at $0.02 per image. Maximum resolution is 1408×768 pixels. Rate limit: 150 requests per minute. This is your workhorse for thumbnails, social media posts, content previews, and any scenario where throughput matters more than pixel-perfect quality.

**Imagen 4 Standard** (`imagen-4.0-generate-001`) costs $0.04 per image and supports 2K output up to 2048×2048. It delivers noticeably better detail coherence and prompt adherence than Fast. Use it for blog hero images, e-commerce product shots, and presentation assets where quality and cost need to balance. Rate limit: 75 requests per minute.

**Imagen 4 Ultra** (`imagen-4.0-ultra-generate-001`) is $0.06 per image with the highest quality in the family. Texture fidelity, complex scene composition, and text rendering precision all exceed the other two tiers. Use it for brand assets, print materials, and advertising creatives where every detail matters. Rate limit: 30 requests per minute.

The key insight: "always use Ultra" is almost never the right strategy. The 3× price difference between Fast and Ultra adds up quickly at scale. The right approach is building a routing layer that selects the model based on purpose — which we'll implement later in this guide.

## Basic Implementation with the Python SDK

Imagen 4 is accessed through the Google Gen AI SDK (`google-genai`). Here's a foundation that wraps all three models.

```python
import os
from google import genai
from google.genai import types

client = genai.Client(api_key=os.environ.get("GEMINI_API_KEY"))

def generate_image(
    prompt: str,
    model: str = "imagen-4.0-generate-001",
    aspect_ratio: str = "1:1",
    number_of_images: int = 1,
    person_generation: str = "allow_adult",
) -> list[bytes]:
    """Generate images with Imagen 4, returning raw bytes."""
    try:
        response = client.models.generate_images(
            model=model,
            prompt=prompt,
            config=types.GenerateImagesConfig(
                number_of_images=number_of_images,
                aspect_ratio=aspect_ratio,
                person_generation=person_generation,
            ),
        )
        return [img.image.image_bytes for img in response.generated_images]
    except genai.errors.ClientError as e:
        print(f"ClientError: {e}")
        raise
    except genai.errors.ServerError as e:
        print(f"ServerError: {e}")
        raise

# Fast: social media thumbnails (speed + low cost)
thumbnails = generate_image(
    prompt="Minimalist flat design icon of a robot reading a book, "
           "vibrant blue gradient background, no text",
    model="imagen-4.0-fast-generate-001",
    aspect_ratio="1:1",
    number_of_images=4,
)

# Standard: blog hero image (quality + cost balance)
hero = generate_image(
    prompt="Professional photograph of a developer workspace with "
           "multiple monitors showing code, warm ambient lighting, "
           "shallow depth of field",
    model="imagen-4.0-generate-001",
    aspect_ratio="16:9",
)

# Ultra: brand advertising asset (maximum quality)
brand = generate_image(
    prompt='Photorealistic product shot of a sleek white wireless '
           'earbud case on marble, studio lighting, '
           'text overlay reading "SoundPure Pro" in elegant sans-serif',
    model="imagen-4.0-ultra-generate-001",
    aspect_ratio="4:3",
)

for i, img_bytes in enumerate(thumbnails):
    with open(f"thumbnail_{i}.png", "wb") as f:
        f.write(img_bytes)
```

Supported `aspect_ratio` values: `"1:1"`, `"3:4"`, `"4:3"`, `"9:16"`, `"16:9"`. The `person_generation` parameter accepts `"dont_allow"`, `"allow_adult"` (default), or `"allow_all"`.

Why wrap the API in a function? Because this is where you'll later add model routing, retry logic, and cost tracking. Scattering raw API calls across your codebase makes these cross-cutting concerns painful to maintain.

## Maximizing Text Rendering Accuracy

Text rendering is Imagen 4's headline feature, but getting consistent results requires deliberate prompt design.

**Principle 1: Quote literal text and specify font style**

```python
# Prone to garbled text
bad = "A poster with the words Welcome to Tokyo"

# Stable text rendering
good = (
    'A modern travel poster featuring the text "Welcome to Tokyo" '
    "in bold sans-serif white font, centered at the top. "
    "Background: Tokyo skyline at sunset with Tokyo Tower silhouette."
)
```

Wrapping the desired text in double quotes signals to the model that these characters should be rendered literally. Adding font family (serif/sans-serif), weight (bold/light), color, and position further stabilizes output.

**Principle 2: Keep text short, structure multi-line text explicitly**

Spelling error risk increases with text length. For images with more than 12 words, separate main and sub-text in your prompt.

```python
structured = (
    'Event poster design. '
    'Main headline: "AI Developer Summit 2026" in large bold white text. '
    'Subheadline: "June 15-17 | San Francisco" in smaller gray text below. '
    'Background: abstract geometric pattern in dark blue and purple.'
)
result = generate_image(prompt=structured, model="imagen-4.0-ultra-generate-001", aspect_ratio="9:16")
```

**Principle 3: Use Ultra for text-heavy images**

While Fast and Standard can render text, Ultra's accuracy with longer strings and smaller fonts is clearly superior. At $0.06 per image, Ultra is often more cost-effective for text-focused use cases than retrying with Fast multiple times after garbled output.

## Building a Batch Processing Pipeline

Production services rarely generate images one at a time. E-commerce catalogs, blog platforms, and multi-language marketing campaigns all need batch capability with proper error handling.

```python
import asyncio
import random
from dataclasses import dataclass

@dataclass
class ImageJob:
    job_id: str
    prompt: str
    model: str = "imagen-4.0-generate-001"
    aspect_ratio: str = "1:1"
    max_retries: int = 3
    status: str = "pending"
    result: bytes | None = None
    error: str | None = None

async def process_job(job: ImageJob) -> ImageJob:
    """Process a single image job with exponential backoff retry."""
    for attempt in range(job.max_retries):
        try:
            loop = asyncio.get_event_loop()
            response = await loop.run_in_executor(
                None,
                lambda: client.models.generate_images(
                    model=job.model,
                    prompt=job.prompt,
                    config=types.GenerateImagesConfig(
                        number_of_images=1,
                        aspect_ratio=job.aspect_ratio,
                    ),
                ),
            )
            job.result = response.generated_images[0].image.image_bytes
            job.status = "completed"
            return job
        except genai.errors.ClientError as e:
            if "SAFETY" in str(e) or "BLOCKED" in str(e):
                job.status = "blocked"
                job.error = f"Safety filter: {e}"
                return job
            job.error = str(e)
        except Exception as e:
            job.error = str(e)
        if attempt < job.max_retries - 1:
            await asyncio.sleep((2 ** attempt) + random.uniform(0, 1))
    job.status = "failed"
    return job

async def run_batch(jobs: list[ImageJob], concurrency: int = 5) -> list[ImageJob]:
    """Run batch with controlled concurrency.
    
    Tune concurrency to model rate limits:
    Fast: 150 RPM -> concurrency 10-15
    Standard: 75 RPM -> concurrency 5-8
    Ultra: 30 RPM -> concurrency 2-3
    """
    sem = asyncio.Semaphore(concurrency)
    async def bounded(job):
        async with sem:
            return await process_job(job)
    results = await asyncio.gather(*[bounded(j) for j in jobs])
    completed = sum(1 for j in results if j.status == "completed")
    failed = sum(1 for j in results if j.status == "failed")
    blocked = sum(1 for j in results if j.status == "blocked")
    print(f"Batch: {completed} ok, {failed} failed, {blocked} blocked")
    return results
```

The `concurrency` parameter is critical. Exceeding the model's rate limit triggers 429 errors. The exponential backoff handles occasional spikes, but the semaphore is your primary throttle.

## Purpose-Based Model Routing

Instead of hardcoding a model, build a routing layer that maps image purpose to the optimal model.

```python
from enum import Enum

class ImagePurpose(Enum):
    THUMBNAIL = "thumbnail"
    HERO_IMAGE = "hero_image"
    PRODUCT_PHOTO = "product_photo"
    BRAND_ASSET = "brand_asset"
    TEXT_OVERLAY = "text_overlay"
    SOCIAL_MEDIA = "social_media"

MODEL_ROUTING = {
    ImagePurpose.THUMBNAIL: {"model": "imagen-4.0-fast-generate-001", "cost": 0.02, "concurrency": 12},
    ImagePurpose.HERO_IMAGE: {"model": "imagen-4.0-generate-001", "cost": 0.04, "concurrency": 6},
    ImagePurpose.PRODUCT_PHOTO: {"model": "imagen-4.0-generate-001", "cost": 0.04, "concurrency": 6},
    ImagePurpose.BRAND_ASSET: {"model": "imagen-4.0-ultra-generate-001", "cost": 0.06, "concurrency": 2},
    ImagePurpose.TEXT_OVERLAY: {"model": "imagen-4.0-ultra-generate-001", "cost": 0.06, "concurrency": 2},
    ImagePurpose.SOCIAL_MEDIA: {"model": "imagen-4.0-fast-generate-001", "cost": 0.02, "concurrency": 12},
}

def get_model(purpose: ImagePurpose) -> str:
    return MODEL_ROUTING[purpose]["model"]

def estimate_cost(purpose: ImagePurpose, count: int) -> float:
    return round(MODEL_ROUTING[purpose]["cost"] * count, 2)
```

Externalizing this routing table makes it trivial to A/B test models or adjust routing rules for cost optimization. For broader API cost strategies, see our [Gemini API Cost Optimization Complete Guide](/en/articles/gemini-api/gemini-api-cost-optimization-complete-guide).

## SynthID Watermarks: What You Need to Know

Every image generated by Imagen 4 is automatically watermarked with SynthID, Google's imperceptible digital watermark. This cannot be disabled.

SynthID survives resizing, cropping, and moderate compression. Two production considerations matter. First, intentional removal degrades image quality significantly since the watermark is embedded at the pixel level. Second, AI-generated content disclosure regulations (such as the EU AI Act) are evolving globally. SynthID helps with compliance but may not satisfy all legal requirements on its own. Review applicable regulations for your target markets.

## Production Error Handling Patterns

Three error patterns dominate production Imagen 4 deployments.

**Safety filter blocks** are the most common. The filter sometimes blocks prompts that aren't obviously problematic. Build a fallback chain: simplify the prompt, then try removing person references, then fall back to a default image.

```python
def handle_safety_block(prompt: str, purpose: ImagePurpose) -> list[bytes] | None:
    simplified = prompt.replace("weapon", "tool").replace("blood", "red liquid")
    try:
        return generate_image(prompt=simplified, model=get_model(purpose))
    except genai.errors.ClientError:
        pass
    try:
        return generate_image(prompt=prompt, model=get_model(purpose), person_generation="dont_allow")
    except genai.errors.ClientError:
        pass
    return None
```

For comprehensive error troubleshooting, see [Gemini Image Generation Error Resolution Guide](/en/articles/gemini-api/gemini-image-generation-errors-fix-guide).

**Timeouts** are common with Ultra. Set your HTTP client timeout to at least 60 seconds.

```python
client = genai.Client(
    api_key=os.environ.get("GEMINI_API_KEY"),
    http_options=types.HttpOptions(timeout=60_000),
)
```

**Rate limiting (429)** is handled by the exponential backoff in the batch pipeline, but persistent 429s indicate your concurrency setting is too aggressive for the model's RPM limit.

## Cost Optimization Techniques

At scale, smart generation strategies matter as much as model selection.

**Two-stage generation**: Show previews with Fast, finalize the selected image with Ultra.

```python
def two_stage(prompt: str, num_previews: int = 4) -> dict:
    previews = generate_image(
        prompt=prompt,
        model="imagen-4.0-fast-generate-001",
        number_of_images=num_previews,
    )
    return {
        "previews": previews,
        "finalize": lambda: generate_image(
            prompt=prompt, model="imagen-4.0-ultra-generate-001", number_of_images=1,
        ),
    }
# All Ultra: $0.06 × 4 = $0.24
# Fast preview + Ultra final: $0.02 × 4 + $0.06 = $0.14 (42% savings)
```

**Prompt-based caching**: Hash the prompt + parameters and cache the result. Skip the API call entirely for repeated requests.

```python
import hashlib, json
from pathlib import Path

CACHE = Path("./image_cache")
CACHE.mkdir(exist_ok=True)

def cached_generate(prompt: str, model: str = "imagen-4.0-generate-001", ar: str = "1:1") -> bytes:
    key = hashlib.sha256(json.dumps({"p": prompt.strip().lower(), "m": model, "a": ar}, sort_keys=True).encode()).hexdigest()[:16]
    path = CACHE / f"{key}.png"
    if path.exists():
        return path.read_bytes()
    imgs = generate_image(prompt=prompt, model=model, aspect_ratio=ar)
    path.write_bytes(imgs[0])
    return imgs[0]
```

**Daily budget enforcement**: Track spend per model and block generation when the budget is exhausted.

```python
import threading

class CostTracker:
    COSTS = {"imagen-4.0-fast-generate-001": 0.02, "imagen-4.0-generate-001": 0.04, "imagen-4.0-ultra-generate-001": 0.06}
    def __init__(self, daily_budget: float = 10.0):
        self.budget = daily_budget
        self.spend = 0.0
        self._lock = threading.Lock()
    def can_generate(self, model: str, n: int = 1) -> bool:
        with self._lock:
            return self.spend + self.COSTS.get(model, 0.06) * n <= self.budget
    def record(self, model: str, n: int = 1):
        with self._lock:
            self.spend += self.COSTS.get(model, 0.06) * n
```

## Five Common Pitfalls and How to Avoid Them

**1. Long prompts accidentally rendered as image text.** When your prompt includes detailed context alongside quoted text, the model sometimes renders the context as visible text. Keep rendering instructions separate from literal text, and always quote the text you want displayed.

**2. Exceeding Fast's resolution limits.** Fast maxes out at 1408×768. Requesting higher resolution throws an error. Validate resolution against model constraints before calling the API.

**3. Blowing through rate limits with async.** Unbounded `asyncio.gather()` hits rate limits instantly. Always use a semaphore matching the model's RPM.

**4. Image post-processing that damages SynthID.** Light resizing and cropping are fine. Heavy pixel manipulation may destroy the watermark, which could create compliance issues.

**5. Forgetting person_generation defaults.** The default `"allow_adult"` blocks images of children. If you need images without people entirely, set `"dont_allow"`. If you're confused about why people aren't appearing, check this parameter first.

## Combining with Gemini Text Generation

Imagen 4 is most powerful when paired with Gemini's text models. A common workflow: feed article text into Gemini 2.5 Pro to generate an optimal image prompt, then pass that prompt to Imagen 4.

```python
def generate_article_image(article_text: str) -> bytes:
    """Auto-generate a hero image from article content."""
    prompt_resp = client.models.generate_content(
        model="gemini-2.5-pro",
        contents=f"""Generate one English image prompt for this blog article's hero image.
Requirements: no text in image, visually represent the article's core topic, commercial-use safe.
Article: {article_text[:3000]}
Output only the prompt.""",
        config=types.GenerateContentConfig(temperature=0.7, max_output_tokens=200),
    )
    return generate_image(
        prompt=prompt_resp.text.strip(),
        model="imagen-4.0-generate-001",
        aspect_ratio="16:9",
    )[0]
```

This pipeline eliminates manual image creation for content teams publishing multiple articles daily.
