## Introduction: How Gemini API + Pandas Transforms Data Analysis

Working with CSV and Excel files is a constant in data analysis. But deciding how to handle missing values, spotting outliers, or choosing the right chart for a dataset often requires time-consuming manual work.

Combining Gemini API with Python's Pandas library lets you automate much of this effort. In this guide, you'll learn how to:

- Query a DataFrame in natural language using Gemini
- Automatically detect and get cleaning suggestions for data quality issues
- Generate comprehensive analysis reports with a single function call
- Let Gemini decide the best visualization approach for your data

This tutorial is aimed at engineers and data analysts who are familiar with Python and Pandas basics, and want to bring AI into their day-to-day workflows.

## Querying Your DataFrame in Natural Language

### The Core Pattern

The simplest way to pass a DataFrame to Gemini is to convert it to a string and embed it in your prompt. Here's a reusable helper function:

```python
import pandas as pd
import google.generativeai as genai
import os

genai.configure(api_key=os.environ["GEMINI_API_KEY"])
model = genai.GenerativeModel("gemini-2.5-flash")

# Load your CSV (we'll use hypothetical sales data here)
df = pd.read_csv("sales_data.csv")

def ask_gemini_about_dataframe(df: pd.DataFrame, question: str) -> str:
    """
    Ask Gemini a natural language question about a DataFrame.

    Args:
        df: The DataFrame to analyze
        question: Your question in plain language

    Returns:
        Gemini's analysis as a string
    """
    df_info = f"""
Dataset overview:
- Rows: {len(df)}, Columns: {len(df.columns)}
- Column names: {', '.join(df.columns.tolist())}
- Data types:
{df.dtypes.to_string()}

First 5 rows:
{df.head().to_string()}

Summary statistics:
{df.describe().to_string()}
"""

    prompt = f"""
Please answer the following question about this dataset.

{df_info}

Question: {question}

Provide a concrete, data-driven analysis with specific insights.
"""

    response = model.generate_content(prompt)
    return response.text

# Example usage
question = "Which product category has the highest sales? Are there any seasonal trends?"
answer = ask_gemini_about_dataframe(df, question)
print(answer)
# Example output: "The top-performing category is 'Electronics' at 35% of total sales.
#  December shows a clear spike, suggesting strong seasonal demand..."
```

### Handling Large Datasets Efficiently

For large DataFrames, passing all rows would consume too many tokens. Use sampling and aggregation instead:

```python
def prepare_df_summary(df: pd.DataFrame, sample_size: int = 20) -> str:
    """
    Generate a compact summary of a large DataFrame for use in prompts.
    Preserves statistical characteristics while minimizing token usage.

    Args:
        df: Target DataFrame
        sample_size: Number of sample rows to include (default: 20)

    Returns:
        A formatted summary string
    """
    parts = []

    # Basic info
    parts.append(f"Dataset size: {len(df)} rows × {len(df.columns)} columns")

    # Numeric column statistics
    numeric_cols = df.select_dtypes(include='number').columns.tolist()
    if numeric_cols:
        parts.append(f"\nNumeric statistics:\n{df[numeric_cols].describe().to_string()}")

    # Categorical column value counts
    cat_cols = df.select_dtypes(include='object').columns.tolist()
    for col in cat_cols[:5]:
        top_vals = df[col].value_counts().head(5)
        parts.append(f"\nTop 5 values for '{col}':\n{top_vals.to_string()}")

    # Missing values
    missing = df.isnull().sum()
    if missing.any():
        parts.append(f"\nMissing values:\n{missing[missing > 0].to_string()}")

    # Random sample
    sample = df.sample(min(sample_size, len(df)), random_state=42)
    parts.append(f"\nRandom sample ({sample_size} rows):\n{sample.to_string()}")

    return "\n".join(parts)

# Works efficiently even for million-row datasets
large_df = pd.read_csv("large_sales_data.csv")
summary = prepare_df_summary(large_df, sample_size=30)
response = model.generate_content(f"Analyze this dataset and describe the main trends:\n{summary}")
print(response.text)
```

## Automating Data Cleaning

Use Gemini to detect quality issues and propose targeted cleaning strategies with code.

```python
def auto_clean_suggestions(df: pd.DataFrame) -> dict:
    """
    Detect data quality problems and get AI-generated cleaning recommendations.

    Returns:
        dict with 'issues' list and 'suggestions' string
    """
    issues = []

    # Missing values
    missing = df.isnull().sum()
    if missing.any():
        issues.append(f"Missing values: {missing[missing > 0].to_dict()}")

    # Duplicate rows
    duplicates = df.duplicated().sum()
    if duplicates > 0:
        issues.append(f"Duplicate rows: {duplicates}")

    # Outlier detection via IQR method
    for col in df.select_dtypes(include='number').columns:
        Q1 = df[col].quantile(0.25)
        Q3 = df[col].quantile(0.75)
        IQR = Q3 - Q1
        outliers = ((df[col] < Q1 - 1.5 * IQR) | (df[col] > Q3 + 1.5 * IQR)).sum()
        if outliers > 0:
            issues.append(f"Outliers in '{col}': {outliers} (IQR method)")

    issues_text = "\n".join(issues) if issues else "No major quality issues detected."

    prompt = f"""
The following data quality issues were detected:
{issues_text}

Dataset overview:
- Shape: {len(df)} rows × {len(df.columns)} columns
- Columns: {', '.join(df.columns.tolist())}
- Data types: {df.dtypes.to_dict()}

As a data scientist, propose the best cleaning strategy for each issue.
Include Pandas code examples for each fix.
"""

    response = model.generate_content(prompt)

    return {
        "issues": issues,
        "suggestions": response.text
    }

# Example usage
df = pd.read_csv("messy_data.csv")
result = auto_clean_suggestions(df)
print("Detected issues:")
for issue in result["issues"]:
    print(f"  - {issue}")
print("\nGemini's recommendations:")
print(result["suggestions"])
```

## Automated Report Generation

Generate a full Markdown analysis report from any DataFrame with a single function call.

```python
def generate_analysis_report(df: pd.DataFrame, report_title: str = "Data Analysis Report") -> str:
    """
    Use Gemini to generate a comprehensive analysis report for a DataFrame.

    Args:
        df: DataFrame to analyze
        report_title: Title for the report

    Returns:
        Markdown-formatted analysis report
    """
    numeric_stats = df.describe().to_string() if not df.select_dtypes(include='number').empty else "No numeric columns"

    prompt = f"""
You are a professional data analyst. Create a detailed analysis report in Markdown for the dataset below.

## Dataset Overview
- Rows: {len(df)}
- Columns: {len(df.columns)}
- Column names and types: {df.dtypes.to_dict()}
- Missing values: {df.isnull().sum().to_dict()}

## Numeric Statistics
{numeric_stats}

## Sample Data (first 5 rows)
{df.head().to_string()}

## Report Requirements
1. Executive Summary (3–5 sentences)
2. Data characteristics and quality assessment
3. Key statistical findings
4. Business implications (informed inference is fine)
5. Recommended next steps

Report title: {report_title}

Write a professional report in clear, concise English.
"""

    response = model.generate_content(prompt)
    return response.text

# Example usage
df = pd.read_csv("quarterly_sales.csv")
report = generate_analysis_report(df, "Q1 2026 Sales Analysis Report")

# Save the report
with open("analysis_report.md", "w", encoding="utf-8") as f:
    f.write(report)

print("✅ Report generated: analysis_report.md")
print(report[:500] + "...")
```

## AI-Driven Visualization Selection

Let Gemini decide which chart type best fits your data.

```python
import matplotlib.pyplot as plt
import matplotlib
matplotlib.use('Agg')

def decide_visualization(df: pd.DataFrame, target_column: str) -> dict:
    """
    Ask Gemini to recommend the best visualization approach for a column.

    Returns:
        dict with chart_type, x_col, y_col, and reason
    """
    col_info = {
        col: {
            "dtype": str(df[col].dtype),
            "nunique": df[col].nunique(),
            "sample": df[col].dropna().head(3).tolist()
        }
        for col in df.columns
    }

    prompt = f"""
I want to visualize the column "{target_column}" in the following dataset.

Column info:
{col_info}

Choose the best chart type (bar/line/scatter/histogram/box) and the appropriate x/y axes.
Reply in this exact JSON format:
{{
  "chart_type": "chart type",
  "x_col": "x-axis column name or null",
  "y_col": "y-axis column name",
  "reason": "one-sentence justification"
}}
"""

    response = model.generate_content(prompt)

    import json, re
    json_match = re.search(r'\{[^}]+\}', response.text, re.DOTALL)
    if json_match:
        return json.loads(json_match.group())
    return {"chart_type": "histogram", "x_col": None, "y_col": target_column, "reason": "default fallback"}

def create_chart(df: pd.DataFrame, viz_config: dict, save_path: str = "chart.png"):
    """
    Generate a chart based on Gemini's visualization recommendation.
    """
    fig, ax = plt.subplots(figsize=(10, 6))
    chart_type = viz_config.get("chart_type", "histogram")
    x_col = viz_config.get("x_col")
    y_col = viz_config.get("y_col")

    if chart_type == "bar" and x_col:
        df.groupby(x_col)[y_col].mean().plot(kind="bar", ax=ax)
        ax.set_xlabel(x_col)
        ax.set_ylabel(f"Average {y_col}")
    elif chart_type == "line" and x_col:
        df.plot(x=x_col, y=y_col, kind="line", ax=ax)
    elif chart_type == "scatter" and x_col:
        df.plot(x=x_col, y=y_col, kind="scatter", ax=ax, alpha=0.5)
    elif chart_type == "box":
        df[y_col].plot(kind="box", ax=ax)
    else:
        df[y_col].plot(kind="hist", ax=ax, bins=20)
        ax.set_xlabel(y_col)

    ax.set_title(f"{y_col} Analysis ({chart_type} chart)")
    plt.tight_layout()
    plt.savefig(save_path, dpi=150)
    print(f"✅ Chart saved: {save_path}")
    return fig

# Example usage
df = pd.read_csv("sales_data.csv")
viz = decide_visualization(df, "monthly_sales")
print(f"Recommended chart: {viz['chart_type']} — Reason: {viz['reason']}")
create_chart(df, viz, "sales_chart.png")
```

## Common Errors and Fixes

### Error 1: `ResourceExhausted` (Rate Limit Hit)

When processing large DataFrames, prompts can become long enough to trigger rate limits. Use exponential backoff to handle this gracefully:

```python
import time
from google.api_core.exceptions import ResourceExhausted

def safe_generate(model, prompt: str, max_retries: int = 3) -> str:
    """
    Retry-aware generation with exponential backoff for rate limit handling.
    """
    for attempt in range(max_retries):
        try:
            response = model.generate_content(prompt)
            return response.text
        except ResourceExhausted:
            wait_time = 2 ** attempt  # 1s, 2s, 4s
            print(f"Rate limit hit. Retrying in {wait_time}s... ({attempt + 1}/{max_retries})")
            time.sleep(wait_time)
    raise Exception("Max retries exceeded")
```

### Error 2: Token Limit Exceeded

Even with Gemini 2.5 Flash's ~1M token context window, sending an entire large DataFrame is impractical. Use stratified sampling:

```python
def truncate_df_for_prompt(df: pd.DataFrame, max_rows: int = 50) -> pd.DataFrame:
    """
    Reduce a DataFrame to a representative sample for prompt inclusion.
    Uses stratified sampling to preserve the distribution of numeric columns.
    """
    if len(df) <= max_rows:
        return df

    numeric_cols = df.select_dtypes(include='number').columns
    if len(numeric_cols) > 0:
        primary_col = numeric_cols[0]
        df['_quantile'] = pd.qcut(df[primary_col], q=min(10, max_rows), labels=False, duplicates='drop')
        sampled = df.groupby('_quantile', group_keys=False).apply(
            lambda x: x.sample(min(len(x), max(1, max_rows // 10)), random_state=42)
        )
        return sampled.drop('_quantile', axis=1).head(max_rows)

    return df.sample(max_rows, random_state=42)
```

### Error 3: Gemini Returns Malformed JSON

```python
import json, re

def extract_json_from_response(text: str) -> dict:
    """
    Extract JSON from Gemini's response, handling Markdown code blocks.
    """
    # Prefer JSON inside a code block
    code_block = re.search(r'```(?:json)?\s*(\{.*?\})\s*```', text, re.DOTALL)
    if code_block:
        return json.loads(code_block.group(1))

    # Fall back to bare JSON
    json_match = re.search(r'\{[^{}]*\}', text, re.DOTALL)
    if json_match:
        return json.loads(json_match.group())

    raise ValueError(f"No JSON found in response: {text[:200]}")
```

## FAQ

**Q. How much does it cost to use Gemini API for data analysis?**

As of April 2026, Gemini 2.5 Flash is priced at approximately $0.15 per million input tokens and $0.60 per million output tokens. For typical data analysis tasks, each analysis call usually costs a fraction of a cent. For a comprehensive cost control strategy, check out the [Gemini API Cost Optimization Complete Guide](/articles/gemini-api/gemini-api-cost-optimization-complete-guide).

**Q. Can I use this in Google Colab?**

Absolutely. Google Colab supports both Pandas and Gemini API natively. Install with `pip install google-generativeai` and use Colab's Secrets panel (the 🔑 icon in the left sidebar) to securely manage your API key. See the [Google Colab × Gemini API Guide](/articles/gemini-dev/google-colab-gemini-guide) for a full walkthrough.

**Q. Is it safe to send sensitive data to the Gemini API?**

According to Google's API data usage policy, data sent via the API is not used to train models by default. That said, for production environments with sensitive data — such as PII or financial records — we strongly recommend masking or anonymizing the data before including it in prompts.

**Q. Does this work with Polars instead of Pandas?**

Yes. You can convert a Polars DataFrame with `.to_pandas()`, or serialize it directly to a string with `.write_csv()` or a custom formatter. For performance-sensitive pipelines, do your data processing in Polars and only convert to string when building the Gemini prompt.

**Q. How accurate is Gemini with Japanese-language datasets?**

Gemini 2.5 series models have excellent multilingual support. If your column names, categories, and values are in Japanese, simply write your prompts in Japanese and Gemini will understand and respond accurately.
