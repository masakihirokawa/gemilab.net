## Setup and context: Why LangChain.js with Gemini API?

Building AI applications that go beyond a single API call requires substantial infrastructure: retrieval-augmented generation (RAG) systems that reference large document collections, agents that autonomously orchestrate multiple tools, and stateful conversations with long-term memory. Implementing all of this from scratch means hundreds of lines of boilerplate and complex state management.

LangChain.js solves these problems elegantly. With first-class integration for Google Gemini now stable, it's one of the best choices for building production AI systems in TypeScript/Node.js. This guide goes beyond the basics — we'll focus on what it takes to actually ship these systems to production, including the error handling, caching, and deployment patterns that tutorials typically skip.

**What you'll learn:**
- Production-ready setup for LangChain.js with Gemini API
- Custom RAG pipelines with vector store integration
- Multi-tool agent design and implementation
- Conversation memory with persistence
- Error handling, rate limiting, and deployment best practices

**Prerequisites:** Comfortable with TypeScript and Node.js, looking to deploy AI systems to production.

## 1. Environment Setup and Configuration

### Installing Dependencies

```bash
npm install @langchain/google-genai @langchain/core @langchain/community langchain
npm install @langchain/textsplitters
# Vector store (using Chroma)
npm install chromadb
# Type definitions
npm install --save-dev typescript @types/node
```

Set `"type": "module"` in `package.json` and use `"moduleResolution": "bundler"` in `tsconfig.json` for the best compatibility with modern ESM packages.

### Configuring the Gemini LLM

```typescript
// src/config/llm.ts
import { ChatGoogleGenerativeAI } from "@langchain/google-genai";
import { GoogleGenerativeAIEmbeddings } from "@langchain/google-genai";

// Production-ready LLM initialization
export function createLLM(options?: {
  temperature?: number;
  maxOutputTokens?: number;
  streaming?: boolean;
}) {
  return new ChatGoogleGenerativeAI({
    model: "gemini-2.0-flash",
    apiKey: process.env.GEMINI_API_KEY,
    temperature: options?.temperature ?? 0.1,
    maxOutputTokens: options?.maxOutputTokens ?? 8192,
    streaming: options?.streaming ?? false,
    // Production safety settings
    safetySettings: [
      {
        category: "HARM_CATEGORY_DANGEROUS_CONTENT",
        threshold: "BLOCK_MEDIUM_AND_ABOVE",
      },
    ],
  });
}

// Embedding model initialization
export function createEmbeddings() {
  return new GoogleGenerativeAIEmbeddings({
    model: "text-embedding-004",
    apiKey: process.env.GEMINI_API_KEY,
  });
}
```

## 2. Building a Production RAG Pipeline

RAG augments the LLM's knowledge by retrieving relevant documents at query time, dramatically improving accuracy on domain-specific questions.

### Document Ingestion and Vectorization

```typescript
// src/rag/ingestion.ts
import { RecursiveCharacterTextSplitter } from "@langchain/textsplitters";
import { Chroma } from "@langchain/community/vectorstores/chroma";
import { PDFLoader } from "@langchain/community/document_loaders/fs/pdf";
import { TextLoader } from "langchain/document_loaders/fs/text";
import { Document } from "@langchain/core/documents";
import { createEmbeddings } from "../config/llm.js";

// Text splitter with production-tuned settings
const splitter = new RecursiveCharacterTextSplitter({
  chunkSize: 1000,       // Characters per chunk
  chunkOverlap: 200,     // Overlap for context continuity
  separators: ["\n\n", "\n", ".", " ", ""],
});

export async function ingestDocuments(
  filePaths: string[],
  collectionName: string
): Promise<void> {
  const allDocuments: Document[] = [];

  for (const filePath of filePaths) {
    let loader;
    if (filePath.endsWith(".pdf")) {
      loader = new PDFLoader(filePath);
    } else {
      loader = new TextLoader(filePath);
    }

    const rawDocs = await loader.load();
    const splitDocs = await splitter.splitDocuments(rawDocs);

    // Enrich metadata for filtering at query time
    const enrichedDocs = splitDocs.map((doc) => ({
      ...doc,
      metadata: {
        ...doc.metadata,
        source: filePath,
        ingestedAt: new Date().toISOString(),
        collectionName,
      },
    }));

    allDocuments.push(...enrichedDocs);
  }

  // Persist to vector store
  await Chroma.fromDocuments(allDocuments, createEmbeddings(), {
    collectionName,
    url: process.env.CHROMA_URL ?? "http://localhost:8000",
  });

  console.log(
    `✅ Ingested ${allDocuments.length} chunks into "${collectionName}"`
  );
}
```

### Building the RAG Chain

```typescript
// src/rag/chain.ts
import { Chroma } from "@langchain/community/vectorstores/chroma";
import { createRetrievalChain } from "langchain/chains/retrieval";
import { createStuffDocumentsChain } from "langchain/chains/combine_documents";
import { ChatPromptTemplate } from "@langchain/core/prompts";
import { createLLM, createEmbeddings } from "../config/llm.js";

const SYSTEM_TEMPLATE = `You are a helpful and accurate AI assistant.
Use the following context to answer the user's question.
If the context doesn't contain the answer, say so clearly and offer
what general knowledge you can.

Context:
{context}`;

export async function createRAGChain(collectionName: string) {
  const vectorStore = await Chroma.fromExistingCollection(
    createEmbeddings(),
    {
      collectionName,
      url: process.env.CHROMA_URL ?? "http://localhost:8000",
    }
  );

  // Retriever: top 5 results by similarity
  const retriever = vectorStore.asRetriever({
    k: 5,
    searchType: "similarity",
  });

  const prompt = ChatPromptTemplate.fromMessages([
    ["system", SYSTEM_TEMPLATE],
    ["human", "{input}"],
  ]);

  const documentChain = await createStuffDocumentsChain({
    llm: createLLM({ temperature: 0.1 }),
    prompt,
  });

  return await createRetrievalChain({
    retriever,
    combineDocsChain: documentChain,
  });
}

export async function queryRAG(
  question: string,
  collectionName: string
): Promise<{ answer: string; sources: string[] }> {
  const chain = await createRAGChain(collectionName);
  const result = await chain.invoke({ input: question });

  const sources = result.context
    .map((doc: any) => doc.metadata.source as string)
    .filter((v: string, i: number, a: string[]) => a.indexOf(v) === i);

  return { answer: result.answer, sources };
}
```

### Hybrid Search for Better Recall

Combining vector search (semantic similarity) with keyword search (BM25) significantly improves retrieval quality across different query patterns:

```typescript
// src/rag/hybrid-retriever.ts
import { EnsembleRetriever } from "langchain/retrievers/ensemble";
import { BM25Retriever } from "@langchain/community/retrievers/bm25";

export async function createHybridRetriever(
  documents: Document[],
  vectorStore: Chroma
) {
  const bm25Retriever = BM25Retriever.fromDocuments(documents, { k: 4 });
  const vectorRetriever = vectorStore.asRetriever({ k: 4 });

  // Weight vector search more heavily for semantic queries
  return new EnsembleRetriever({
    retrievers: [bm25Retriever, vectorRetriever],
    weights: [0.4, 0.6],
  });
}
```

## 3. Custom Tools and Agent Implementation

Agents are where LangChain.js really shines. With Gemini API as the reasoning backbone, you can build agents that autonomously decide which tools to call, interpret results, and compose multi-step solutions.

### Defining Custom Tools

```typescript
import { DynamicStructuredTool } from "@langchain/core/tools";
import { z } from "zod";

// Weather tool example
export const weatherTool = new DynamicStructuredTool({

    unit: z

      .default("celsius")
      .describe("Temperature unit"),
  }),
  func: async ({ city, unit }) => {
    // In production, call a real weather API here

      city,
      temperature: unit === "celsius" ? "22°C" : "71.6°F",
      condition: "Clear",
      humidity: "45%",
      windSpeed: "12km/h",
    };
    return JSON.stringify(mockData);
  },

// Database search tool
export const databaseSearchTool = new DynamicStructuredTool({
  name: "search_database",
  description:
    "Search internal databases for product, customer, or inventory information.",
  schema: z.object({
    query: z.string().describe("The search query"),
    table: z
      .enum(["products", "customers", "inventory"])
      .describe("Which table to search"),
    limit: z.number().default(10).describe("Maximum results to return"),

// Safe calculator tool
export const calculatorTool = new DynamicStructuredTool({
  name: "calculator",
  description:
    "Evaluates mathematical expressions. Supports arithmetic, percentages, and formulas.",
  schema: z.object({
    expression: z
      .string()
      .describe('A math expression (e.g., "1234 * 0.08", "(100 + 50) / 3")'),
  }),
  func: async ({ expression }) => {

      const result = Function(`"use strict"; return (${expression})`)();

      return "Error: Invalid expression";
    }
```

### Building a React Agent

```typescript
// src/agents/react-agent.ts
import { createReactAgent } from "langchain/agents";
import { AgentExecutor } from "langchain/agents";
import { ChatPromptTemplate, MessagesPlaceholder } from "@langchain/core/prompts";
import { HumanMessage, AIMessage } from "@langchain/core/messages";
import { createLLM } from "../config/llm.js";
import { weatherTool, databaseSearchTool, calculatorTool } from "./tools.js";

const AGENT_SYSTEM_PROMPT = `You are a capable AI assistant with access to several tools.
Use them efficiently to solve the user's requests.

Guidelines:
1. Only use tools when necessary — avoid unnecessary API calls
2. Combine tool results logically to form your final answer
3. Ask the user for clarification when you're uncertain
4. If one approach fails, try an alternative`;

export async function createProductionAgent() {
  const llm = createLLM({ temperature: 0 });
  const tools = [weatherTool, databaseSearchTool, calculatorTool];

  const agent = await createReactAgent({
    llm,
    tools,
    prompt: ChatPromptTemplate.fromMessages([
      ["system", AGENT_SYSTEM_PROMPT],
      new MessagesPlaceholder("chat_history"),
      ["human", "{input}"],
      new MessagesPlaceholder("agent_scratchpad"),
    ]),
  });

  return new AgentExecutor({
    agent,
    tools,
    verbose: process.env.NODE_ENV === "development",
    maxIterations: 10,
    returnIntermediateSteps: true,
    handleParsingErrors: (error: Error) => {
      console.error("Agent parsing error:", error.message);
      return "I encountered an error processing your request. Please try again.";
    },
  });
}

export async function runAgentWithHistory(
  input: string,
  chatHistory: Array<HumanMessage | AIMessage> = []
): Promise<{ output: string; steps: any[] }> {
  const executor = await createProductionAgent();
  const result = await executor.invoke({
    input,
    chat_history: chatHistory,
  });

  return {
    output: result.output,
    steps: result.intermediateSteps ?? [],
  };
}
```

## 4. Memory Management and Session Persistence

Production AI systems need robust memory management. LangChain.js supports multiple backends — here's how to implement them properly.

### Redis-Backed Persistent Memory

```typescript
// src/memory/redis-memory.ts
import { BufferMemory } from "langchain/memory";
import { RedisChatMessageHistory } from "@langchain/community/stores/message/ioredis";
import { ConversationChain } from "langchain/chains";
import { createLLM } from "../config/llm.js";

export function createRedisMemory(sessionId: string) {
  return new BufferMemory({
    chatHistory: new RedisChatMessageHistory({
      sessionId,
      sessionTTL: 300, // 5-minute TTL
      url: process.env.REDIS_URL ?? "redis://localhost:6379",
    }),
    returnMessages: true,
    memoryKey: "chat_history",
    inputKey: "input",
    outputKey: "output",
  });
}

export async function createConversationChainWithMemory(sessionId: string) {
  const memory = createRedisMemory(sessionId);
  return new ConversationChain({
    llm: createLLM({ temperature: 0.7 }),
    memory,
    verbose: false,
  });
}
```

### Token-Aware Memory for Long Conversations

As conversations grow, token management becomes critical. Use `ConversationTokenBufferMemory` to automatically trim older messages:

```typescript
// src/memory/token-aware-memory.ts
import { ConversationTokenBufferMemory } from "langchain/memory";
```

## 5. Streaming Responses

Users expect real-time feedback. Here's how to wire up Gemini's streaming API through LangChain.js into a Next.js API route:

```typescript
// src/streaming/stream-handler.ts
import { ChatGoogleGenerativeAI } from "@langchain/google-genai";
import { ChatPromptTemplate } from "@langchain/core/prompts";
import { StringOutputParser } from "@langchain/core/output_parsers";
import { RunnableSequence } from "@langchain/core/runnables";

export async function streamingConversation(
  userMessage: string,
  onChunk: (chunk: string) => void,
  onComplete: () => void
): Promise<void> {
  const streamingLLM = new ChatGoogleGenerativeAI({
    model: "gemini-2.0-flash",
    apiKey: process.env.GEMINI_API_KEY,
    streaming: true,
    temperature: 0.7,
  });

  const chain = RunnableSequence.from([
    ChatPromptTemplate.fromMessages([
      ["system", "You are a helpful AI assistant."],
      ["human", "{input}"],
    ]),
    streamingLLM,
    new StringOutputParser(),
  ]);

  const stream = await chain.stream({ input: userMessage });

  for await (const chunk of stream) {
    onChunk(chunk);
  }

  onComplete();
}

// Example: Next.js API Route
export async function POST(req: Request) {
  const { message } = await req.json();
  const encoder = new TextEncoder();

  const stream = new ReadableStream({
    async start(controller) {
      await streamingConversation(
        message,
        (chunk) => controller.enqueue(encoder.encode(chunk)),
        () => controller.close()
      );
    },
  });

  return new Response(stream, {
    headers: {
      "Content-Type": "text/plain; charset=utf-8",
      "Transfer-Encoding": "chunked",
    },
  });
}
```

## 6. Error Handling and Rate Limiting

Rate limits and transient network failures are facts of life in production. Build resilience into every call.

### Exponential Backoff with Retry

```typescript
// src/utils/retry.ts
export async function withRetry<T>(
  fn: () => Promise<T>,
  options: {
    maxRetries?: number;
    initialDelayMs?: number;
    maxDelayMs?: number;
    onRetry?: (attempt: number, error: Error) => void;
  } = {}
): Promise<T> {
  const {
    maxRetries = 3,
    initialDelayMs = 1000,
    maxDelayMs = 30000,
    onRetry,
  } = options;

  let lastError: Error;

  for (let attempt = 0; attempt <= maxRetries; attempt++) {
    try {
      return await fn();
    } catch (error) {
      lastError = error as Error;
      if (attempt === maxRetries) break;

      // Rate limit errors (429) warrant a longer wait
      const isRateLimit =
        lastError.message.includes("429") ||
        lastError.message.includes("RATE_LIMIT");
      const delay = isRateLimit
        ? maxDelayMs
        : Math.min(initialDelayMs * Math.pow(2, attempt), maxDelayMs);

      onRetry?.(attempt + 1, lastError);
      await new Promise((resolve) => setTimeout(resolve, delay));
    }
  }

  throw lastError!;
}

// Usage
const result = await withRetry(
  () => chain.invoke({ input: userMessage }),
  {
    maxRetries: 3,
    onRetry: (attempt, error) =>
      console.warn(`Retry ${attempt}: ${error.message}`),
  }
);
```

## 7. Production Deployment and Performance

### Singleton Vector Store Connections

Avoid re-initializing vector store connections on every request:

```typescript
// src/lib/vectorstore-singleton.ts
import { Chroma } from "@langchain/community/vectorstores/chroma";
import { createEmbeddings } from "../config/llm.js";

let stores: Map<string, Chroma> | null = null;

export async function getVectorStore(collectionName: string): Promise<Chroma> {
  if (!stores) stores = new Map();

  if (!stores.has(collectionName)) {
    const store = await Chroma.fromExistingCollection(createEmbeddings(), {
      collectionName,
      url: process.env.CHROMA_URL ?? "http://localhost:8000",
    });
    stores.set(collectionName, store);
  }

  return stores.get(collectionName)!;
}
```

### Response Caching

Cache identical queries to cut API costs and improve latency:

```typescript
// src/cache/response-cache.ts
```
