## What Is Function Calling? Connecting AI to the Real World

Gemini API's **Function Calling** (also referred to as tool use) is the feature that allows AI models to interact with external functions and APIs. While a standard LLM only generates text, Function Calling lets your application trigger real actions — checking the weather, querying a database, scheduling a calendar event, and much more.

As of 2026, Function Calling is supported across all major Gemini models, including Gemini 2.5 Pro, Gemini 2.5 Flash, and the Gemini 3 series. It's widely used by individual developers and enterprise teams alike.

Here's how the flow works at a high level:

1. You define "available functions" and pass them to the API alongside the user's message
2. The user asks something like "What's the weather in Tokyo?"
3. Gemini decides that `get_weather(city="Tokyo")` is the right call and returns that function invocation
4. Your application actually runs the function and sends the result back to the model
5. Gemini generates a natural-language response based on the result

This division of labor — AI decides, app executes — is the essence of Function Calling.

## Your First Function Calling Implementation

Let's walk through a weather-retrieval example using dummy data — no real weather API needed to understand the mechanics.

### Step 1: Define the Function (Tool Declaration)

```python
import json
from google import genai
from google.genai import types

# The actual Python function your app will call (dummy implementation)
def get_weather(city: str) -> dict:
    """Returns weather info for a given city (dummy data)."""
    weather_data = {
        "Tokyo": {"condition": "Sunny", "temperature": 22, "humidity": 55},
        "Osaka": {"condition": "Cloudy", "temperature": 19, "humidity": 68},
        "Sapporo": {"condition": "Snowy", "temperature": -3, "humidity": 85},
    }
    return weather_data.get(city, {"condition": "Unknown", "temperature": 0, "humidity": 0})

# The tool definition passed to Gemini
weather_tool = types.Tool(
    function_declarations=[
        types.FunctionDeclaration(
            name="get_weather",
            description="Retrieves current weather info (condition, temperature, humidity) for a given city",
            parameters=types.Schema(
                type=types.Type.OBJECT,
                properties={
                    "city": types.Schema(
                        type=types.Type.STRING,
                        description="The city name to check weather for (e.g., Tokyo, Osaka)"
                    )
                },
                required=["city"]
            )
        )
    ]
)
```

### Step 2: Send the Request and Receive the Function Call

```python
client = genai.Client(api_key=os.environ["YOUR_GEMINI_API_KEY"])

# Send the user's message along with the tool definition
response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="What's the weather like in Tokyo today?",
    config=types.GenerateContentConfig(
        tools=[weather_tool]
    )
)

# Check if Gemini responded with a function call
for part in response.candidates[0].content.parts:
    if part.function_call:
        func_call = part.function_call
        print(f"Function: {func_call.name}")
        print(f"Args: {dict(func_call.args)}")
        # Expected output:
        # Function: get_weather
        # Args: {'city': 'Tokyo'}
```

### Step 3: Execute the Function and Return the Result

```python
# Retrieve the function call from the response
func_call = response.candidates[0].content.parts[0].function_call

# Execute the actual function
if func_call.name == "get_weather":
    result = get_weather(**dict(func_call.args))
    print(f"Function result: {result}")
    # Expected: {'condition': 'Sunny', 'temperature': 22, 'humidity': 55}

# Send the result back to Gemini to generate the final answer
final_response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents=[
        types.Content(role="user", parts=[
            types.Part(text="What's the weather like in Tokyo today?")
        ]),
        response.candidates[0].content,  # The model's function call
        types.Content(role="tool", parts=[
            types.Part(
                function_response=types.FunctionResponse(
                    name="get_weather",
                    response=result
                )
            )
        ])
    ],
    config=types.GenerateContentConfig(tools=[weather_tool])
)

print(final_response.text)
# Expected: "It's sunny in Tokyo today with a temperature of 22°C and humidity at 55%. A pleasant day!"
```

Once you understand this three-step loop, the rest of Function Calling is just variations on this theme.

## Defining Multiple Functions

Real-world applications typically need several tools. You can define them all at once, and Gemini will pick the right one based on context.

```python
# Multi-function tool definition
tools = types.Tool(
    function_declarations=[
        types.FunctionDeclaration(
            name="get_weather",
            description="Get weather information for a city",
            parameters=types.Schema(
                type=types.Type.OBJECT,
                properties={
                    "city": types.Schema(type=types.Type.STRING, description="City name")
                },
                required=["city"]
            )
        ),
        types.FunctionDeclaration(
            name="search_restaurants",
            description="Search for restaurants by city and cuisine type",
            parameters=types.Schema(
                type=types.Type.OBJECT,
                properties={
                    "city": types.Schema(type=types.Type.STRING, description="City name"),
                    "cuisine": types.Schema(type=types.Type.STRING, description="Cuisine type (e.g., sushi, Italian)"),
                    "max_results": types.Schema(type=types.Type.INTEGER, description="Maximum results to return (default 5)")
                },
                required=["city", "cuisine"]
            )
        )
    ]
)

# Gemini selects the right function based on the question
response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="Can you recommend 3 sushi restaurants in Tokyo?",
    config=types.GenerateContentConfig(tools=[tools])
)
# → Gemini calls: search_restaurants(city="Tokyo", cuisine="sushi", max_results=3)
```

## Parallel Function Calls

Gemini 2.5 models support calling multiple functions **simultaneously**. This is useful when you need data from several sources at once.

```python
response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="What's the weather in Tokyo, Osaka, and Sapporo right now?",
    config=types.GenerateContentConfig(
        tools=[weather_tool]
    )
)

# Multiple function calls may be returned in parallel
for part in response.candidates[0].content.parts:
    if part.function_call:
        print(f"{part.function_call.name}({dict(part.function_call.args)})")
# Expected output:
# get_weather({'city': 'Tokyo'})
# get_weather({'city': 'Osaka'})
# get_weather({'city': 'Sapporo'})
```

Parallel calls dramatically reduce response time when working with multiple external APIs.

## Automatic Function Calling

The Google AI Python SDK supports an automatic mode where function execution and result handling are done for you automatically.

```python
# Just pass Python function objects directly — no manual loop needed
def get_stock_price(ticker: str) -> float:
    """Returns the current stock price for a given ticker (dummy data)."""
    prices = {"GOOGL": 175.30, "MSFT": 420.50, "AAPL": 195.80}
    return prices.get(ticker, 0.0)

def get_company_info(ticker: str) -> dict:
    """Returns basic company information for a ticker (dummy data)."""
    companies = {
        "GOOGL": {"name": "Alphabet Inc.", "sector": "Technology"},
        "MSFT": {"name": "Microsoft Corp.", "sector": "Technology"},
    }
    return companies.get(ticker, {})

# Pass function objects directly — SDK handles the rest
response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="What's Google's (GOOGL) stock price and what sector is it in?",
    config=types.GenerateContentConfig(
        tools=[get_stock_price, get_company_info],
    )
)

print(response.text)
# → Automatically calls get_stock_price("GOOGL") and get_company_info("GOOGL"),
#    then returns a unified natural-language answer
```

Automatic Function Calling is ideal for rapid prototyping. For production, manual handling gives you more control over error management and retry logic.

## Common Errors and How to Fix Them

### Error 1: Function Return Value Is Not JSON-Serializable

```python
# ❌ Problem: datetime objects can't be JSON-serialized
def get_schedule(date: str) -> dict:
    from datetime import datetime
    return {"event": "Meeting", "time": datetime.now()}  # datetime → fails

# ✅ Fix: Convert to a string
def get_schedule(date: str) -> dict:
    from datetime import datetime
    return {"event": "Meeting", "time": datetime.now().isoformat()}  # ISO string → works
```

### Error 2: Model Returns Plain Text Instead of a Function Call

```python
# ❌ Vague description — Gemini can't decide when to use this
types.FunctionDeclaration(
    name="get_data",
    description="Gets data",  # Too ambiguous
    ...
)

# ✅ Specific description — clear trigger conditions
types.FunctionDeclaration(
    name="get_weather",
    description="Retrieves real-time weather data (condition, temperature, humidity, wind speed) for a specified city",
    ...
)
```

### Error 3: `finish_reason` Is `MAX_TOKENS` Instead of `STOP`

Long Function Calling conversations can exceed the context window. In this case, switch to `gemini-2.5-pro` (2M token context) or implement conversation history pruning.

## A Practical Example: FAQ Chatbot with Database Search

Here's a more realistic example — a company FAQ chatbot that queries a knowledge base.

```python
def search_faq(keyword: str, max_results: int = 3) -> list:
    """Search the FAQ database for entries matching the keyword."""
    # In production, this would query a real database
    faq_data = [
        {"question": "How do I request paid leave?", "answer": "Submit a request via the HR portal."},
        {"question": "When is the expense report deadline?", "answer": "The last day of each month."},
        {"question": "How do I apply for remote work?", "answer": "Send an email to your manager in advance."},
    ]
    results = [faq for faq in faq_data if keyword.lower() in faq["question"].lower() or keyword.lower() in faq["answer"].lower()]
    return results[:max_results]

def get_contact(department: str) -> dict:
    """Returns contact information for a department."""
    contacts = {
        "HR": {"email": "hr@example.com", "tel": "03-xxxx-0001"},
        "Finance": {"email": "accounting@example.com", "tel": "03-xxxx-0002"},
    }
    return contacts.get(department, {"message": f"No info found for {department}"})

def company_chatbot(user_input: str) -> str:
    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=f"Answer the following using the company FAQ: {user_input}",
        config=types.GenerateContentConfig(
            tools=[search_faq, get_contact],
            system_instruction="You are a helpful internal support chatbot. Always search the FAQ before answering."
        )
    )
    return response.text

print(company_chatbot("How do I request time off?"))
# → "To request time off, submit your request through the HR portal. For more details, contact HR at hr@example.com."
```

## FAQ

**Q: Can I use Function Calling on the free tier?**

A: Yes — Function Calling is available within Google AI Studio's free quota. However, free-tier usage is subject to rate limits (RPM). For production workloads, a paid API plan is recommended.

**Q: How many functions can I define in a single request?**

A: Gemini 2.5 models support up to 128 function declarations per request. In practice, however, keeping it to 10–20 well-defined functions gives better results, as too many options can reduce the model's selection accuracy.

**Q: Does the same code work with Vertex AI?**

A: Mostly yes, but you'll need to initialize the client differently: `client = genai.Client(vertexai=True, project="YOUR_PROJECT_ID", location="us-central1")`. Authentication also uses Google Cloud IAM rather than an API key.

**Q: What if Gemini calls the wrong function?**

A: This typically happens when function descriptions are too vague. Make your `description` fields as specific as possible, and always define `required` parameters explicitly. Providing clear naming conventions also helps.
