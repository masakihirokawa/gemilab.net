## Step 1: Download Audio from a YouTube Video

We use yt-dlp to download the audio track of a YouTube video as an MP3 file.

```python
import yt_dlp
import os

def download_youtube_audio(url: str, output_dir: str = "./audio") -> str:
    """
    Downloads the audio track from a YouTube video as MP3.

    Args:
        url: The YouTube video URL
        output_dir: Directory to save the audio file

    Returns:
        Path to the downloaded audio file
    """
    os.makedirs(output_dir, exist_ok=True)

    ydl_opts = {
        "format": "bestaudio/best",
        "outtmpl": f"{output_dir}/%(id)s.%(ext)s",
        "postprocessors": [
            {
                "key": "FFmpegExtractAudio",
                "preferredcodec": "mp3",
                "preferredquality": "128",
            }
        ],
        "quiet": True,
    }

    with yt_dlp.YoutubeDL(ydl_opts) as ydl:
        info = ydl.extract_info(url, download=True)
        video_id = info["id"]
        audio_path = f"{output_dir}/{video_id}.mp3"

    print(f"✅ Audio downloaded: {audio_path}")
    return audio_path


# Usage example:
# audio_file = download_youtube_audio("https://www.youtube.com/watch?v=EXAMPLE_VIDEO_ID")
```

Adjust `preferredquality` to `"64"` for very long videos to keep file sizes manageable.

## Step 2: Upload Audio to Gemini Files API

Once downloaded, upload the audio file to the Gemini Files API. Uploaded files are retained for up to 48 hours, so you can analyze the same file multiple times without re-uploading.

```python
import google.genai as genai
import google.genai.types as types
import os
import time

# Initialize the API client
client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

def upload_audio_to_gemini(audio_path: str) -> genai.types.File:
    """
    Uploads an audio file to the Gemini Files API.

    Args:
        audio_path: Path to the local audio file

    Returns:
        The uploaded file object
    """
    print(f"📤 Uploading to Files API: {audio_path}")

    with open(audio_path, "rb") as f:
        uploaded_file = client.files.upload(
            file=f,
            config=types.UploadFileConfig(
                mime_type="audio/mpeg",
                display_name=os.path.basename(audio_path),
            ),
        )

    # Wait for processing to complete
    while uploaded_file.state.name == "PROCESSING":
        time.sleep(3)
        uploaded_file = client.files.get(name=uploaded_file.name)

    if uploaded_file.state.name == "FAILED":
        raise RuntimeError(f"File upload failed: {uploaded_file.state}")

    print(f"✅ Upload complete: {uploaded_file.uri}")
    return uploaded_file
```

## Step 3: Generate a Video Summary with Gemini API

Using the uploaded file, prompt Gemini to produce a structured summary. System Instructions help you control the output format — bullet points, chapter breakdown, key takeaways, and more.

```python
def summarize_video(uploaded_file: genai.types.File, language: str = "en") -> str:
    """
    Generates a structured summary of the uploaded audio using Gemini.

    Args:
        uploaded_file: The uploaded file object from the Files API
        language: Output language ("en" for English, "ja" for Japanese)

    Returns:
        The generated summary text
    """
    lang_instruction = "in English" if language == "en" else "in Japanese"

    system_prompt = f"""You are an expert video content summarizer.
Analyze the provided audio {lang_instruction} and produce output in the following format:

1. **Title**: A concise title capturing the video's main subject
2. **Overview**: A 2–3 sentence summary of the key message
3. **Key Points**: 5–8 bullet points covering the main ideas
4. **Conclusion**: The primary takeaway for the viewer (2–3 sentences)
"""

    response = client.models.generate_content(
        model="gemini-2.5-pro",
        contents=[
            types.Part.from_uri(
                file_uri=uploaded_file.uri,
                mime_type="audio/mpeg",
            ),
            types.Part.from_text(
                "Please summarize this audio content using the specified format."
            ),
        ],
        config=types.GenerateContentConfig(
            system_instruction=system_prompt,
            temperature=0.3,  # Lower temperature for consistent output
        ),
    )

    return response.text


# Expected output example:
# **Title**: Getting Started with Gemini API: Multimodal Fundamentals
# **Overview**: This video introduces the core concepts of the Gemini API...
# **Key Points**:
# - How to upload files using the Files API
# - Combining text, images, and audio in a single request
# ...
```

## Step 4: Auto-Generate SRT Subtitles

Gemini can produce timestamped transcriptions that we can convert directly into SRT (SubRip Text) format — the standard subtitle format supported by virtually every video player.

```python
def generate_subtitles(uploaded_file: genai.types.File, output_path: str = "output.srt") -> str:
    """
    Generates SRT-format subtitles from the uploaded audio.

    Args:
        uploaded_file: The uploaded file object from the Files API
        output_path: Path where the .srt file will be saved

    Returns:
        The generated SRT content as a string
    """
    subtitle_prompt = """Transcribe this audio and output ONLY valid SRT subtitle content.
Do not include any other text. Use this exact format:

1
00:00:00,000 --> 00:00:05,000
First subtitle text here

2
00:00:05,000 --> 00:00:10,000
Second subtitle text here

Keep each block 1–5 seconds long and limit lines to 42 characters."""

    response = client.models.generate_content(
        model="gemini-2.5-pro",
        contents=[
            types.Part.from_uri(
                file_uri=uploaded_file.uri,
                mime_type="audio/mpeg",
            ),
            types.Part.from_text(subtitle_prompt),
        ],
        config=types.GenerateContentConfig(
            temperature=0.1,  # Prioritize accuracy for subtitles
        ),
    )

    srt_content = response.text

    with open(output_path, "w", encoding="utf-8") as f:
        f.write(srt_content)

    print(f"✅ Subtitles saved: {output_path}")
    return srt_content


# Expected output (output.srt contents):
# 1
# 00:00:00,000 --> 00:00:04,500
# Welcome. Today we're covering the Gemini API.
#
# 2
# 00:00:04,500 --> 00:00:09,200
# Let's start with how to obtain your API key.
```

## Complete Integration Script

Here's the full, production-ready script combining all four steps.

```python
"""
YouTube Video Auto-Summarizer and Subtitle Generator
Usage: python youtube_summarizer.py <YOUTUBE_URL>
"""

import sys
import os
import time
import yt_dlp
import google.genai as genai
import google.genai.types as types

client = genai.Client(api_key=os.environ.get("GEMINI_API_KEY"))


def main(youtube_url: str):
    print(f"🎬 Processing: {youtube_url}\n")

    # Step 1: Download audio
    print("📥 Step 1: Downloading audio...")
    os.makedirs("./audio", exist_ok=True)
    ydl_opts = {
        "format": "bestaudio/best",
        "outtmpl": "./audio/%(id)s.%(ext)s",
        "postprocessors": [{"key": "FFmpegExtractAudio", "preferredcodec": "mp3", "preferredquality": "128"}],
        "quiet": True,
    }
    with yt_dlp.YoutubeDL(ydl_opts) as ydl:
        info = ydl.extract_info(youtube_url, download=True)
        video_id = info["id"]
        audio_path = f"./audio/{video_id}.mp3"
    print(f"  ✅ Saved to: {audio_path}")

    # Step 2: Upload to Files API
    print("\n📤 Step 2: Uploading to Gemini Files API...")
    with open(audio_path, "rb") as f:
        uploaded = client.files.upload(
            file=f,
            config=types.UploadFileConfig(mime_type="audio/mpeg"),
        )
    while uploaded.state.name == "PROCESSING":
        time.sleep(3)
        uploaded = client.files.get(name=uploaded.name)
    print("  ✅ Upload complete")

    # Step 3: Generate summary
    print("\n🤖 Step 3: Generating summary...")
    summary_response = client.models.generate_content(
        model="gemini-2.5-pro",
        contents=[
            types.Part.from_uri(file_uri=uploaded.uri, mime_type="audio/mpeg"),
            types.Part.from_text(
                "Summarize this audio in English. List 5–8 key points as bullet points."
            ),
        ],
        config=types.GenerateContentConfig(temperature=0.3),
    )
    with open(f"./summary_{video_id}.txt", "w", encoding="utf-8") as f:
        f.write(summary_response.text)
    print(f"  ✅ Summary saved: ./summary_{video_id}.txt")

    # Step 4: Generate subtitles
    print("\n📝 Step 4: Generating subtitles (SRT)...")
    subtitle_response = client.models.generate_content(
        model="gemini-2.5-pro",
        contents=[
            types.Part.from_uri(file_uri=uploaded.uri, mime_type="audio/mpeg"),
            types.Part.from_text(
                "Transcribe this audio as SRT subtitles. Output ONLY valid SRT format, no other text."
            ),
        ],
        config=types.GenerateContentConfig(temperature=0.1),
    )
    with open(f"./subtitle_{video_id}.srt", "w", encoding="utf-8") as f:
        f.write(subtitle_response.text)
    print(f"  ✅ Subtitles saved: ./subtitle_{video_id}.srt")

    # Step 5: Clean up uploaded file
    client.files.delete(name=uploaded.name)
    print("\n🗑️ Deleted uploaded file from Files API")
    print("\n✨ Done!")
    print(f"  Summary: ./summary_{video_id}.txt")
    print(f"  Subtitles: ./subtitle_{video_id}.srt")


if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("Usage: python youtube_summarizer.py <YOUTUBE_URL>")
        sys.exit(1)
    main(sys.argv[1])
```

A typical 30-minute tutorial video processes in 1–2 minutes, producing both a summary and a ready-to-use subtitle file.

## Common Errors and Fixes

### Error 1: `yt_dlp.utils.DownloadError`

YouTube periodically changes its internal URL formats. Run `pip install -U yt-dlp` to update to the latest version — this resolves most download errors.

### Error 2: `google.genai.errors.ResourceExhausted` (HTTP 429)

You've hit the API rate limit. The free tier allows 15 requests per minute. Add `time.sleep(10)` between requests, or upgrade to a paid plan if you're processing many videos.

### Error 3: Subtitle Timestamps Are Inaccurate

This typically happens with low-quality audio containing background music or noise. Try raising `preferredquality` to `"192"` in yt-dlp, and add "Please maintain accurate timestamps" to your Gemini prompt. Choosing source videos with clear speech also helps significantly.

## FAQ

**Q1. Does this work with private or premium YouTube videos?**

Downloading private, premium, or members-only content is restricted by YouTube's Terms of Service. Only use this tool on content you have explicit rights to access. Always review the terms before use.

**Q2. Can it handle videos longer than one hour?**

The Files API accepts files up to 2 GB, but Gemini's context window has limits. For videos over 60 minutes, split the audio into 10–15 minute chunks, process each chunk separately, and merge the summaries afterward.

**Q3. Does it support languages other than English?**

Yes — Gemini handles many languages natively. Simply change the prompt language or add an explicit instruction like "Summarize in French." For subtitle generation, you can request translated subtitles in a single pass by including "Translate to Spanish and output as SRT" in your prompt.

**Q4. How much does it cost to run?**

With Gemini 2.5 Pro, expect roughly $0.10–$0.30 per hour of audio (as of April 2026, depending on token count). The free tier is sufficient for personal use. For batch processing large volumes, consider the Batch API for a significant cost reduction.
