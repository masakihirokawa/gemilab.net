## Setup and context: Why Go Developers Should Learn the Gemini API

Go (Golang) has earned its reputation as one of the most productive languages for building backend services, microservices, CLI tools, and cloud-native applications. With Kubernetes, Docker, and countless other cloud infrastructure projects written in Go, it's a natural home for production-grade AI integrations.

Google's **official Go SDK for Gemini** makes it straightforward to add AI capabilities to your existing Go services without stepping outside the language you already know. Whether you're building a backend API, a CLI tool, or a data processing pipeline, Gemini's Go SDK integrates naturally with Go's concurrency model and type system.

In this guide, you'll learn everything you need to get started:

- Installing the Google AI Go SDK and configuring your API key
- Generating text and building multi-turn conversations
- Working with streaming responses
- Processing images and other media with multimodal inputs
- Implementing Function Calling to connect Gemini to real-world data

**Who this is for**: Go developers with basic language familiarity who want to integrate AI features into their applications. No prior Gemini or AI experience required.

## Setting Up Your Environment

### Prerequisites

- Go 1.21 or later (verify with `go version`)
- A Gemini API key (free to obtain from [Google AI Studio](https://aistudio.google.com/))

### Getting Your API Key

1. Visit [Google AI Studio](https://aistudio.google.com/) and sign in with your Google account
2. Click **"Get API key"** in the left sidebar
3. Select **"Create API key"** and copy the generated key

Keep your API key secure. The examples in this guide read it from the `GEMINI_API_KEY` environment variable — never hardcode secrets in your source code.

```bash
# Add this to your .bashrc or .zshrc for persistence
export GEMINI_API_KEY="YOUR_API_KEY"
```

### Project Setup

Create a new Go module and install the necessary packages:

```bash
# Create and enter your project directory
mkdir gemini-go-example
cd gemini-go-example

# Initialize a Go module
go mod init gemini-go-example

# Install the Google AI Go SDK
go get github.com/google/generative-ai-go/genai
go get google.golang.org/api/option
```

After running these commands, verify that both packages appear in your `go.mod` file.

## Step 1: Basic Text Generation

Let's start with the simplest possible example — sending a prompt and printing the response. Create `main.go` in your project root:

```go
package main

import (
	"context"
	"fmt"
	"log"
	"os"

	"github.com/google/generative-ai-go/genai"
	"google.golang.org/api/option"
)

func main() {
	ctx := context.Background()

	// Read the API key from the environment
	apiKey := os.Getenv("GEMINI_API_KEY")
	if apiKey == "" {
		log.Fatal("GEMINI_API_KEY environment variable is not set")
	}

	// Initialize the Gemini client
	client, err := genai.NewClient(ctx, option.WithAPIKey(apiKey))
	if err != nil {
		log.Fatalf("Failed to create client: %v", err)
	}
	defer client.Close()

	// Select the model — Gemini 2.5 Flash is fast and cost-effective
	model := client.GenerativeModel("gemini-2.5-flash")

	// Send a prompt
	resp, err := model.GenerateContent(ctx, genai.Text("What makes Go a good language for backend services? Answer in 3 sentences."))
	if err != nil {
		log.Fatalf("Failed to generate content: %v", err)
	}

	// Print the response
	for _, cand := range resp.Candidates {
		if cand.Content != nil {
			for _, part := range cand.Content.Parts {
				fmt.Println(part)
			}
		}
	}
}
```

Run it:

```bash
go run main.go
# Expected output:
# Go excels at backend services due to its fast compilation, low memory footprint,
# and built-in concurrency primitives like goroutines and channels.
# Its static typing catches errors at compile time, and the standard library
# provides robust HTTP and networking support out of the box.
# The language's simplicity also makes codebases easy to maintain as teams scale.
```

Notice the `defer client.Close()` call — this is idiomatic Go, ensuring resources are always released when the function exits.

## Step 2: Multi-Turn Chat with Conversation History

Most real applications need to maintain context across multiple exchanges. The SDK's `ChatSession` handles this automatically:

```go
package main

import (
	"bufio"
	"context"
	"fmt"
	"log"
	"os"
	"strings"

	"github.com/google/generative-ai-go/genai"
	"google.golang.org/api/option"
)

func main() {
	ctx := context.Background()

	client, err := genai.NewClient(ctx, option.WithAPIKey(os.Getenv("GEMINI_API_KEY")))
	if err != nil {
		log.Fatal(err)
	}
	defer client.Close()

	model := client.GenerativeModel("gemini-2.5-flash")

	// Set a system instruction to define the assistant's persona
	model.SystemInstruction = &genai.Content{
		Parts: []genai.Part{
			genai.Text("You are a Go programming expert. Give concise, practical answers and include code snippets when helpful."),
		},
	}

	// Start a chat session — the SDK manages conversation history automatically
	cs := model.StartChat()

	scanner := bufio.NewScanner(os.Stdin)
	fmt.Println("Go Assistant is ready (type 'quit' to exit)")
	fmt.Println("---")

	for {
		fmt.Print("You: ")
		if !scanner.Scan() {
			break
		}

		input := strings.TrimSpace(scanner.Text())
		if input == "quit" || input == "" {
			break
		}

		// The ChatSession keeps track of all previous messages
		resp, err := cs.SendMessage(ctx, genai.Text(input))
		if err != nil {
			log.Printf("Error: %v", err)
			continue
		}

		fmt.Print("Gemini: ")
		for _, cand := range resp.Candidates {
			if cand.Content != nil {
				for _, part := range cand.Content.Parts {
					fmt.Println(part)
				}
			}
		}
		fmt.Println()
	}
}
```

The `ChatSession` returned by `StartChat()` accumulates the full conversation history. On each subsequent call to `SendMessage`, the model receives the entire prior context automatically — there's nothing extra you need to manage.

## Step 3: Streaming Responses

For long responses or real-time UX, streaming lets you display output as it's generated rather than waiting for the entire response:

```go
package main

import (
	"context"
	"fmt"
	"log"
	"os"

	"github.com/google/generative-ai-go/genai"
	"google.golang.org/api/iterator"
	"google.golang.org/api/option"
)

func main() {
	ctx := context.Background()

	client, err := genai.NewClient(ctx, option.WithAPIKey(os.Getenv("GEMINI_API_KEY")))
	if err != nil {
		log.Fatal(err)
	}
	defer client.Close()

	model := client.GenerativeModel("gemini-2.5-flash")

	// GenerateContentStream returns an iterator over response chunks
	iter := model.GenerateContentStream(ctx,
		genai.Text("Explain Go's concurrency model — goroutines, channels, and select — with practical examples."),
	)

	fmt.Print("Gemini: ")
	for {
		resp, err := iter.Next()
		if err == iterator.Done {
			// Stream finished normally
			break
		}
		if err != nil {
			log.Fatalf("Stream error: %v", err)
		}

		// Print each chunk immediately without a newline
		for _, cand := range resp.Candidates {
			if cand.Content != nil {
				for _, part := range cand.Content.Parts {
					fmt.Print(part)
				}
			}
		}
	}
	fmt.Println() // Final newline after streaming completes
}
```

The `iterator.Done` sentinel error signals a clean end to the stream — a pattern you'll recognize from other Go iterator APIs. Streaming is especially valuable in chat interfaces and CLI tools where users expect immediate feedback.

## Step 4: Multimodal Processing (Image Analysis)

One of Gemini's most powerful features is its ability to process images alongside text. Here's how to analyze a local image file:

```go
package main

import (
	"context"
	"fmt"
	"log"
	"os"

	"github.com/google/generative-ai-go/genai"
	"google.golang.org/api/option"
)

func main() {
	ctx := context.Background()

	client, err := genai.NewClient(ctx, option.WithAPIKey(os.Getenv("GEMINI_API_KEY")))
	if err != nil {
		log.Fatal(err)
	}
	defer client.Close()

	model := client.GenerativeModel("gemini-2.5-flash")

	// Read the image from disk
	imageData, err := os.ReadFile("sample.jpg")
	if err != nil {
		log.Fatalf("Failed to read image: %v", err)
	}

	// Combine text and image in the same request
	resp, err := model.GenerateContent(ctx,
		genai.Text("Describe what you see in this image in detail."),
		genai.ImageData("image/jpeg", imageData),
	)
	if err != nil {
		log.Fatalf("Failed to generate content: %v", err)
	}

	for _, cand := range resp.Candidates {
		if cand.Content != nil {
			for _, part := range cand.Content.Parts {
				fmt.Println(part)
			}
		}
	}
}
```

`genai.ImageData(mimeType, data)` accepts raw bytes with a MIME type. Supported formats include JPEG, PNG, WebP, and GIF. You can pass multiple images in a single request or mix images with text for complex vision tasks.

## Step 5: Function Calling

Function Calling enables Gemini to invoke your Go functions to retrieve real-world information or trigger actions. This is the foundation for building AI agents that interact with databases, APIs, and services:

```go
package main

import (
	"context"
	"fmt"
	"log"
	"os"

	"github.com/google/generative-ai-go/genai"
	"google.golang.org/api/option"
)

// A placeholder function — in production, this would call a weather API
func getWeather(city string) string {
	data := map[string]string{
		"Tokyo":    "Sunny, 22°C, humidity 45%",
		"New York": "Partly cloudy, 18°C, humidity 60%",
		"London":   "Overcast, 12°C, humidity 75%",
	}
	if weather, ok := data[city]; ok {
		return weather
	}
	return "Weather data not available"
}

func main() {
	ctx := context.Background()

	client, err := genai.NewClient(ctx, option.WithAPIKey(os.Getenv("GEMINI_API_KEY")))
	if err != nil {
		log.Fatal(err)
	}
	defer client.Close()

	model := client.GenerativeModel("gemini-2.5-flash")

	// Declare the tool Gemini can call
	weatherTool := &genai.Tool{
		FunctionDeclarations: []*genai.FunctionDeclaration{
			{
				Name:        "get_weather",
				Description: "Returns the current weather for a given city",
				Parameters: &genai.Schema{
					Type: genai.TypeObject,
					Properties: map[string]*genai.Schema{
						"city": {
							Type:        genai.TypeString,
							Description: "The city name, e.g. Tokyo, London",
						},
					},
					Required: []string{"city"},
				},
			},
		},
	}

	model.Tools = []*genai.Tool{weatherTool}

	resp, err := model.GenerateContent(ctx, genai.Text("What's the weather like in Tokyo right now?"))
	if err != nil {
		log.Fatal(err)
	}

	for _, cand := range resp.Candidates {
		if cand.Content != nil {
			for _, part := range cand.Content.Parts {
				if fc, ok := part.(genai.FunctionCall); ok {
					fmt.Printf("Function called: %s\n", fc.Name)
					fmt.Printf("Arguments: %v\n", fc.Args)

					city := fmt.Sprintf("%v", fc.Args["city"])
					result := getWeather(city)
					fmt.Printf("Result: %s\n", result)
					// Expected output:
					// Function called: get_weather
					// Arguments: map[city:Tokyo]
					// Result: Sunny, 22°C, humidity 45%
				} else {
					fmt.Println(part)
				}
			}
		}
	}
}
```

## Common Errors and How to Fix Them

### Error 1: Invalid API Key

```
PERMISSION_DENIED: API key not valid. Please pass a valid API key.
```

**Fix**: Verify that your `GEMINI_API_KEY` environment variable is set correctly and contains no extra whitespace.

```bash
echo $GEMINI_API_KEY  # Should print your API key
```

### Error 2: Rate Limit Exceeded

```
RESOURCE_EXHAUSTED: Quota exceeded for quota metric...
```

**Fix**: The free tier has request-per-minute limits. Implement exponential backoff for retries:

```go
import "time"

func generateWithRetry(ctx context.Context, model *genai.GenerativeModel, prompt string) (*genai.GenerateContentResponse, error) {
	for attempt := 0; attempt < 3; attempt++ {
		resp, err := model.GenerateContent(ctx, genai.Text(prompt))
		if err == nil {
			return resp, nil
		}
		// Exponential backoff: 1s, 2s, 4s
		time.Sleep(time.Duration(1<<uint(attempt)) * time.Second)
	}
	return nil, fmt.Errorf("all 3 retry attempts failed")
}
```

### Error 3: Context Timeout

Long-running requests may time out. Set an explicit deadline:

```go
ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
defer cancel()
```

## Advanced Pattern: Parallel Batch Processing with Goroutines

Go's goroutines make concurrent API calls trivially easy — just be mindful of rate limits:

```go
package main

import (
	"context"
	"fmt"
	"log"
	"os"
	"sync"

	"github.com/google/generative-ai-go/genai"
	"google.golang.org/api/option"
)

func main() {
	ctx := context.Background()

	client, err := genai.NewClient(ctx, option.WithAPIKey(os.Getenv("GEMINI_API_KEY")))
	if err != nil {
		log.Fatal(err)
	}
	defer client.Close()

	model := client.GenerativeModel("gemini-2.5-flash")

	prompts := []string{
		"What is a goroutine? One sentence only.",
		"What is a channel in Go? One sentence only.",
		"What is an interface in Go? One sentence only.",
	}

	results := make([]string, len(prompts))
	var wg sync.WaitGroup

	for i, prompt := range prompts {
		wg.Add(1)
		go func(idx int, p string) {
			defer wg.Done()

			resp, err := model.GenerateContent(ctx, genai.Text(p))
			if err != nil {
				results[idx] = fmt.Sprintf("error: %v", err)
				return
			}

			for _, cand := range resp.Candidates {
				if cand.Content != nil {
					for _, part := range cand.Content.Parts {
						results[idx] = fmt.Sprintf("%v", part)
					}
				}
			}
		}(i, prompt)
	}

	wg.Wait() // Block until all goroutines complete

	for i, result := range results {
		fmt.Printf("Q%d: %s\n", i+1, result)
	}
	// Expected output:
	// Q1: A goroutine is a lightweight, concurrently executing function managed by the Go runtime.
	// Q2: A channel is a typed conduit for safely passing data between goroutines.
	// Q3: An interface is a type that defines a set of method signatures that other types can satisfy.
}
```

`sync.WaitGroup` coordinates all goroutines cleanly, and writing to separate slice indices avoids any data races. For production batch processing at scale, consider rate-limiting middleware to stay within API quotas.

- **Text generation**: `GenerateContent` for single-shot prompts
- **Multi-turn chat**: `StartChat()` + `SendMessage` with automatic history management

- **Multimodal**: `genai.ImageData` for image analysis alongside text
- **Function Calling**: Connecting Gemini to real-world Go functions
- **Concurrency**: Using goroutines for efficient parallel API calls
