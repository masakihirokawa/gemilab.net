The Gemini Text-to-Speech (TTS) API converts text into natural-sounding audio, but you might encounter various errors and unexpected behaviors. This guide covers the most common issues and their solutions.

## Gemini TTS API Basics Review

Before troubleshooting, let's review the basic TTS API usage:

```python
import google.generativeai as genai

# Configure your API key
genai.configure(api_key='YOUR_GEMINI_API_KEY')

# Make a basic TTS API call
response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=['Hello, this is a test message']
)

# Retrieve the audio data
audio_data = response.audio
```

Understanding the basic structure helps you troubleshoot errors more effectively.

## Audio Generation Fails (Empty Response)

### Incorrect Model Name

TTS functionality isn't available on all models. You must use the correct model names.

**Available models:**
- `gemini-2.5-flash-tts` (recommended, latest)
- `gemini-2.5-pro-tts`
- `gemini-1.5-pro-tts` (legacy)

```python
# Wrong: Using a non-TTS model
response = genai.models.generate_content(
    model='gemini-2.5-pro',  # TTS not available
    contents=['Test']
)

# Correct: Using a TTS-enabled model
response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=['Test']
)
```

If you're unsure about available models, retrieve them programmatically:

```python
# List available TTS models
for model in genai.list_models():
    if 'tts' in model.name.lower():
        print(f"Available: {model.name}")
```

### Incorrect speech_config Format

Invalid `speech_config` parameters prevent audio generation.

```python
# Wrong: Incorrect dictionary format
response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=['Test'],
    speech_config={
        'voice_config': {'preset_voice': 'Aoife'}  # Invalid structure
    }
)

# Correct: Using proper SpeechConfig object
from google.generativeai.types import speech_config as speech_types

response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=['Test'],
    speech_config=speech_types.SpeechConfig(
        voice_config=speech_types.VoiceConfig(preset_voice='Aoife')
    )
)
```

### Text Exceeds Token Limit

The TTS API has limits on text length. Exceeding this limit causes errors or truncated audio.

```python
# Check text length (estimate: 1 word ≈ 1.3 tokens)
text = "Long text here..."
estimated_tokens = len(text.split()) * 1.3

if estimated_tokens > 3000:  # TTS API limit
    print(f"Warning: Text too long ({estimated_tokens} tokens estimated)")
    # Split text into chunks
    texts = [text[i:i+1000] for i in range(0, len(text), 1000)]
    for chunk in texts:
        response = genai.models.generate_content(
            model='gemini-2.5-flash-tts',
            contents=[chunk]
        )
```

Use the tokenizer for precise token counting:

```python
# Count tokens accurately
model = genai.GenerativeModel('gemini-2.5-flash')
token_data = model.count_tokens(text)
print(f"Total tokens: {token_data.total_tokens}")

if token_data.total_tokens > 3000:
    # Split the text
    pass
```

## Poor Audio Quality

### Proper voice_config Settings

Improve audio quality by configuring voice parameters correctly.

```python
from google.generativeai.types import speech_config as speech_types

# High-quality voice configuration
response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=['This is a high-quality voice test.'],
    speech_config=speech_types.SpeechConfig(
        voice_config=speech_types.VoiceConfig(
            preset_voice='Aoife'  # Available: Aoife, Breeze, Cora, Ember, etc.
        ),
        speaking_rate=1.0  # 1.0 = normal speed (range: 0.25 - 4.0)
    )
)
```

**Available voice options:**
- Aoife (female, clear)
- Breeze (female, natural)
- Cora (female, friendly)
- Ember (female, dynamic)
- Juniper (female, professional)
- Kore (male, clear)
- Orion (male, deep)
- Sage (male, natural)

Experiment with different voices to find what works best for your use case.

### Using Style Instructions

Use `style_instructions` to fine-tune voice expression and tone.

```python
from google.generativeai.types import speech_config as speech_types

response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=['Welcome to our service!'],
    speech_config=speech_types.SpeechConfig(
        voice_config=speech_types.VoiceConfig(preset_voice='Cora'),
        style_instructions='Speak in a warm, enthusiastic tone. Add slight emphasis on key words.'
    )
)
```

Style instructions let you control:
- Tone (casual, formal, humorous)
- Pace (slow, normal, fast)
- Emotion (joyful, neutral, sincere)

## Multilingual Support Issues

### Text Encoding Problems

Processing non-ASCII characters (like Japanese) can cause encoding errors.

```python
# Wrong: No explicit encoding
text = "こんにちは、テスト中です。"
response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=[text]
)

# Correct: Explicitly encode as UTF-8
text = "こんにちは、テスト中です。"
response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=[text.encode('utf-8').decode('utf-8')]
)
```

Specify the language explicitly for better results:

```python
response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=['こんにちは、テスト中です。'],
    speech_config=speech_types.SpeechConfig(
        voice_config=speech_types.VoiceConfig(preset_voice='Aoife'),
        language_code='ja-JP'  # Explicitly set Japanese
    )
)
```

## Streaming Output Cuts Off

### Network Connection Stability

Interrupted streaming often indicates network issues. Set timeouts and implement retries:

```python
# Set timeout for stability
import time

def generate_tts_with_retry(text, max_retries=3):
    for attempt in range(max_retries):
        try:
            response = genai.models.generate_content(
                model='gemini-2.5-flash-tts',
                contents=[text],
                generation_config={
                    'timeout': 30.0  # 30-second timeout
                }
            )
            return response
        except Exception as e:
            if attempt < max_retries - 1:
                wait_time = 2 ** attempt  # Exponential backoff
                print(f"Retrying after {wait_time} seconds...")
                time.sleep(wait_time)
            else:
                raise

# Usage
audio_response = generate_tts_with_retry("Test text for audio generation.")
```

### Proper Streaming Response Handling

When using streaming mode, buffer the response correctly:

```python
# Process audio in streaming mode
response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=['This is a streaming test.'],
    stream=True
)

audio_buffer = b''

for chunk in response:
    if hasattr(chunk, 'audio'):
        audio_buffer += chunk.audio
        print(f"Received {len(chunk.audio)} bytes")

# Save complete audio data
if audio_buffer:
    with open('output.wav', 'wb') as f:
        f.write(audio_buffer)
```

## Rate Limits and Quota Management

The TTS API has these limits:
- **Free plan**: 1,000 characters per day (non-ASCII languages count higher)
- **Pro plan**: Limits based on subscription tier

```python
# Handle rate limit errors
try:
    response = genai.models.generate_content(
        model='gemini-2.5-flash-tts',
        contents=['Test']

    if '429' in str(e) or 'quota' in str(e).lower():
```

## Complete Error Handling Implementation

Here's a robust implementation handling common TTS errors:

```python
import google.generativeai as genai
import time
from typing import Optional

class TTSError(Exception):
    pass

def generate_speech(
    text: str,
    voice: str = 'Aoife',
    max_retries: int = 3
) -> Optional[bytes]:
    """
    Generate speech from text.

    Args:
        text: Text to synthesize
        voice: Voice preset (Aoife, Breeze, Cora, etc.)
        max_retries: Number of retry attempts

    Returns:
        Audio data (bytes) or None on error
    """

    if not text:
        raise TTSError("Text cannot be empty")

    if len(text) > 5000:
        raise TTSError(f"Text too long ({len(text)} characters)")

    for attempt in range(max_retries):
        try:
            response = genai.models.generate_content(
                model='gemini-2.5-flash-tts',
                contents=[text],
                speech_config={
                    'voice_config': {'preset_voice': voice}
                }
            )

            if hasattr(response, 'audio') and response.audio:
                return response.audio
            else:
                raise TTSError("No audio data returned")

        except Exception as e:
            error_msg = str(e)

            # Handle 429 rate limit error
            if '429' in error_msg:
                if attempt < max_retries - 1:
                    wait_time = 60 * (2 ** attempt)
                    print(f"Rate limited. Waiting {wait_time}s...")
                    time.sleep(wait_time)
                    continue
                else:
                    raise TTSError("Rate limit exceeded. Retry later.")

            # Handle 401 authentication error
            elif '401' in error_msg:
                raise TTSError("Invalid API key")

            # Handle 400 bad request error
            elif '400' in error_msg:
                raise TTSError(f"Bad request: {error_msg}")

            # Handle other errors
            else:
                if attempt < max_retries - 1:
                    wait_time = 2 ** attempt
                    print(f"Error occurred. Retrying in {wait_time}s...")
                    time.sleep(wait_time)
                    continue
                else:
                    raise TTSError(f"Unexpected error: {error_msg}")

    return None

# Usage example
try:
    audio_data = generate_speech("This is a test message.", voice='Cora')
    if audio_data:
        with open('output.wav', 'wb') as f:
            f.write(audio_data)
        print("Audio file saved successfully")
except TTSError as e:
    print(f"TTS Error: {e}")
```

## Frequently Asked Questions (FAQ)

**Q1: I'm using `model='gemini-2.5-flash-tts'` but getting a "Model not found" error.**

A: Check several things: (1) Ensure your API key is configured correctly. (2) Verify your API key has TTS API permissions enabled (check in Google AI Studio settings). (3) Double-check the model name for typos (`gemini-2.5-flash-tts` is correct). (4) List available models using `genai.list_models()` to confirm TTS models are accessible.

**Q2: Japanese text generates unnatural-sounding audio.**

A: Try these fixes: (1) Explicitly set `language_code='ja-JP'`. (2) Experiment with different voices (Aoife, Breeze, Cora). (3) Use `style_instructions` to adjust pacing (e.g., "Speak slowly and clearly"). (4) Add appropriate punctuation to help the API understand sentence structure and intonation.

**Q3: The same text generates different audio each time it's synthesized.**

A: This is normal behavior. The TTS API generates new audio each time, creating slight variations. To get consistent audio, cache and reuse previously generated files. Use text hashing as a cache key, storing generated audio in memory or a database for retrieval.
