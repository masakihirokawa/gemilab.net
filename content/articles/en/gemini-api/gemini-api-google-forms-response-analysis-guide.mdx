Google Forms is a go-to tool for surveys and sign-ups, but reading through dozens or hundreds of responses manually takes a lot of time. With the Gemini API, you can load all your form responses at once and let AI handle sentiment analysis, theme clustering, and actionable improvement suggestions — automatically.

In this guide, you'll learn how to build a Python script that fetches Google Forms responses via Google Sheets, sends them to Gemini API for analysis, and saves a structured report. The code includes comments throughout so it's accessible even if you're just getting started with Python.

## What You Can Do with Google Forms + Gemini API

Once your form responses are flowing into the Gemini API, here's what you can automate:

- **Sentiment analysis of free-text responses**: Automatically gauge whether feedback is positive, negative, or neutral
- **Topic clustering**: Group similar comments and feature requests together
- **Improvement suggestions**: Extract specific action items from critical feedback
- **Auto-generated summary report**: Get a narrative overview of what respondents are really saying

Whether you have 10 responses or 1,000, the Gemini API delivers results in seconds.

## Step 1: Fetch Form Responses from Google Sheets

Start by writing a function that reads response data from the linked spreadsheet.

```python
import gspread
from google.oauth2.service_account import Credentials

def get_form_responses(spreadsheet_url: str, sheet_name: str = "Form Responses 1") -> list[dict]:
    """
    Fetch responses from a Google Form-linked spreadsheet.

    Args:
        spreadsheet_url: The URL of the linked spreadsheet
        sheet_name: The worksheet name (default matches Google's auto-generated name)

    Returns:
        A list of dicts, one per response row
    """
    # Define the required OAuth scopes
    scopes = [
        "https://www.googleapis.com/auth/spreadsheets.readonly",
        "https://www.googleapis.com/auth/drive.readonly",
    ]
    creds = Credentials.from_service_account_file(
        "service_account.json",  # Path to your downloaded JSON key
        scopes=scopes,
    )

    # Open the spreadsheet and grab all records
    client = gspread.authorize(creds)
    spreadsheet = client.open_by_url(spreadsheet_url)
    worksheet = spreadsheet.worksheet(sheet_name)

    # Returns a list of dicts (row 1 = headers, rows 2+ = responses)
    records = worksheet.get_all_records()
    print(f"✅ Fetched {len(records)} responses")
    return records
```

## Step 2: Analyze Responses with Gemini API

With the response data in hand, send it to Gemini API for analysis. One of Gemini's strengths is its large context window — you can pass hundreds of responses in a single prompt.

```python
from google import genai

def analyze_form_responses(responses: list[dict], gemini_api_key: str) -> str:
    """
    Use Gemini API to analyze a batch of form responses.

    Args:
        responses: Response data from get_form_responses()
        gemini_api_key: Your Gemini API key

    Returns:
        A formatted analysis report as a string
    """
    # Initialize the Gemini client
    client = genai.Client(api_key=gemini_api_key)

    # Format each response as readable text (skip the Timestamp column)
    response_texts = []
    for i, row in enumerate(responses, start=1):
        items = {k: v for k, v in row.items() if k.lower() != "timestamp"}
        text = f"[Response {i}]\n" + "\n".join(f"{k}: {v}" for k, v in items.items())
        response_texts.append(text)

    all_responses_text = "\n\n".join(response_texts)

    # Prompt that instructs Gemini to produce a structured analysis
    prompt = f"""
You are an expert data analyst. Analyze the following survey responses and produce a report covering these five sections:

1. **Executive Summary**: A 3–5 sentence overview of the key findings.
2. **Sentiment Breakdown**: Estimate the percentage of positive, negative, and neutral responses.
3. **Top Themes**: List the 5 most frequently mentioned topics or themes.
4. **Action Items**: Identify 3 concrete improvements based on critical feedback.
5. **Notable Quotes**: Share one standout positive response and one that highlights an improvement area.

---
{all_responses_text}
---
"""

    # Use gemini-2.5-flash for fast, cost-effective analysis
    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=prompt,
    )

    return response.text
```

## Step 3: Save the Report to a File

Persist the generated report as a Markdown file so you can reference it later or share it with your team.

```python
from datetime import datetime

def save_report(report: str, form_name: str = "Survey") -> str:
    """
    Save the analysis report as a Markdown file with a timestamp.
    """
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    filename = f"report_{form_name.replace(' ', '_')}_{timestamp}.md"

    with open(filename, "w", encoding="utf-8") as f:
        f.write(f"# {form_name} — Analysis Report\n")
        f.write(f"**Generated**: {datetime.now().strftime('%B %d, %Y at %H:%M')}\n\n")
        f.write(report)

    print(f"✅ Report saved: {filename}")
    return filename
```

## Full Script: Putting It All Together

Here's the complete end-to-end script — fetch, analyze, and save in one run.

```python
import os
import gspread
from google import genai
from google.oauth2.service_account import Credentials
from datetime import datetime

# ─── Configuration (update these values) ────────────────
SPREADSHEET_URL = "https://docs.google.com/spreadsheets/d/YOUR_SPREADSHEET_ID/edit"
SHEET_NAME = "Form Responses 1"
FORM_NAME = "Customer Satisfaction Survey"
# ────────────────────────────────────────────────────────

def main():
    # Load the API key from environment
    api_key = os.environ.get("GEMINI_API_KEY")
    if not api_key:
        raise ValueError("Environment variable GEMINI_API_KEY is not set")

    # 1. Fetch form responses
    print("📋 Fetching Google Forms responses...")
    scopes = [
        "https://www.googleapis.com/auth/spreadsheets.readonly",
        "https://www.googleapis.com/auth/drive.readonly",
    ]
    creds = Credentials.from_service_account_file("service_account.json", scopes=scopes)
    gc = gspread.authorize(creds)
    ws = gc.open_by_url(SPREADSHEET_URL).worksheet(SHEET_NAME)
    responses = ws.get_all_records()
    print(f"  → {len(responses)} responses fetched")

    if not responses:
        print("⚠️ No responses found. Check your spreadsheet URL and sharing settings.")
        return

    # 2. Analyze with Gemini API
    print("🤖 Analyzing with Gemini API...")
    client = genai.Client(api_key=api_key)

    response_texts = "\n\n".join(
        f"[Response {i+1}]\n" + "\n".join(
            f"{k}: {v}" for k, v in row.items() if k.lower() != "timestamp"
        )
        for i, row in enumerate(responses)
    )

    prompt = f"""
Analyze the following survey responses and write a professional report with these sections:

1. **Executive Summary** (3–5 sentences)
2. **Sentiment Breakdown** (positive / negative / neutral percentages)
3. **Top Themes** (up to 5)
4. **Action Items** (3 specific improvements)
5. **Notable Quotes** (one positive, one critical)

---
{response_texts}
"""

    result = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=prompt,
    )

    # 3. Save the report
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    filename = f"report_{timestamp}.md"
    with open(filename, "w", encoding="utf-8") as f:
        f.write(f"# {FORM_NAME} — Analysis Report\n")
        f.write(f"**Generated**: {datetime.now().strftime('%B %d, %Y at %H:%M')}\n\n")
        f.write(result.text)

    print(f"✅ Report saved: {filename}")

if __name__ == "__main__":
    main()
```

## Bonus: Email the Report Automatically

You can extend this script to email the report automatically using Python's built-in `smtplib`. Pair it with a cron job and you'll get a weekly analysis in your inbox every Monday morning.

```python
import smtplib
from email.mime.text import MIMEText

def send_report_email(report: str, to_email: str, smtp_password: str):
    """Send the analysis report via Gmail."""
    msg = MIMEText(report, "plain", "utf-8")
    msg["Subject"] = f"📊 Survey Analysis — {datetime.now().strftime('%b %d, %Y')}"
    msg["From"] = "YOUR_GMAIL@gmail.com"
    msg["To"] = to_email

    with smtplib.SMTP_SSL("smtp.gmail.com", 465) as server:
        server.login("YOUR_GMAIL@gmail.com", smtp_password)
        server.send_message(msg)

    print(f"✅ Report emailed to {to_email}")
```

## Common Errors and How to Fix Them

### `gspread.exceptions.SpreadsheetNotFound`

**Cause**: The spreadsheet URL is incorrect, or the service account hasn't been granted access.

**Fix**: Open the spreadsheet, click **Share**, and add the service account email address (e.g., `name@project.iam.gserviceaccount.com`) as a Viewer or Editor.

### `google.auth.exceptions.DefaultCredentialsError`

**Cause**: Python can't find `service_account.json`, or the path is wrong.

**Fix**: Place `service_account.json` in the same directory as your script, or pass an absolute path to `Credentials.from_service_account_file()`.

### Gemini API Timeout with Large Datasets

**Cause**: Too many responses in a single prompt can exceed context limits or time out.

**Fix**: Split responses into batches of 100 and process them in a loop.

```python
BATCH_SIZE = 100
partial_reports = []

for i in range(0, len(responses), BATCH_SIZE):
    batch = responses[i:i + BATCH_SIZE]
    partial = analyze_form_responses(batch, api_key)
    partial_reports.append(partial)

# Merge partial reports
final_report = "\n\n---\n\n".join(partial_reports)
```
