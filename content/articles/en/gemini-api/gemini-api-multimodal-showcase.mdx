What makes the Gemini API truly exciting is its **multimodal capability** — the ability to process text, images, video, audio, and code through a single model. This goes far beyond simple text generation, enabling applications that can handle the complex, layered information of the real world.


## Getting Started with the Gemini API

Let's begin with the development environment. The Gemini API supports Python, JavaScript/TypeScript, Go, Java, and REST — we'll focus on Python here.

### Obtain an API Key

Visit [Google AI Studio](https://aistudio.google.com), sign in with your Google account, and generate an API key.

### Install the Python Library

```bash
pip install google-generativeai
```

### Basic Initialization

```python
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")

model = genai.GenerativeModel('gemini-2.0-flash')
```

In production code, always load your API key from environment variables:

```python
import os
import google.generativeai as genai

genai.configure(api_key=os.environ.get("GEMINI_API_KEY"))
```

## Text Generation Basics

Let's start with the simplest use case: text generation.

```python
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel('gemini-2.0-flash')

response = model.generate_content("Explain asynchronous programming in Python for beginners.")
print(response.text)
```

### Multi-turn Conversations

The Gemini API includes built-in conversation history management for chat applications:

```python
chat = model.start_chat(history=[])

response1 = chat.send_message("Introduce me to machine learning.")
print(response1.text)

response2 = chat.send_message("Tell me more about supervised learning.")
print(response2.text)
# The response incorporates the context from the previous exchange
```

### System Instructions

You can shape the model's behavior with a system instruction:

```python
model = genai.GenerativeModel(
    model_name='gemini-2.0-flash',
    system_instruction="You are a technical writer specializing in clear, beginner-friendly explanations. Always include practical code examples in your answers."
)
```

## Image Understanding: Analyzing Visual Content

One of Gemini's standout capabilities is image comprehension. You can combine images with text as inputs.

### Analyzing a Local Image

```python
import PIL.Image
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel('gemini-2.0-flash')

image = PIL.Image.open("screenshot.png")

response = model.generate_content([
    "Please identify three areas for improvement in this UI.",
    image
])
print(response.text)
```

### Analyzing an Image from a URL

```python
import httpx
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel('gemini-2.0-flash')

image_url = "https://example.com/product-photo.jpg"
image_data = httpx.get(image_url).content

response = model.generate_content([
    {
        "mime_type": "image/jpeg",
        "data": image_data
    },
    "List the key features of this product based on the image."
])
print(response.text)
```

### Comparing Multiple Images

```python
image1 = PIL.Image.open("version_1.png")
image2 = PIL.Image.open("version_2.png")

response = model.generate_content([
    "Compare these two designs and analyze the pros and cons of each.",
    "Version 1:",
    image1,
    "Version 2:",
    image2
])

```

## Video Understanding: Analyzing Video Content

Gemini 1.5/2.0 models can process videos up to approximately one hour long.

### Uploading a Video via the File API

Large files are uploaded via the File API:

```python
import time
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")

# Upload the video file
video_file = genai.upload_file("demo_video.mp4")

# Wait for processing to complete
while video_file.state.name == "PROCESSING":
    time.sleep(2)
    video_file = genai.get_file(video_file.name)

if video_file.state.name == "FAILED":
    raise ValueError("Video processing failed.")

# Query the video
model = genai.GenerativeModel('gemini-2.0-flash')
response = model.generate_content([
    video_file,
    "Provide a chronological summary of this video and highlight the three most important points."
])
print(response.text)

# Clean up to save storage
genai.delete_file(video_file.name)
```

## Structured Output: Getting JSON Responses

In application development, you often need the LLM's output in a structured, parseable format:

```python
import json
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel('gemini-2.0-flash')

response = model.generate_content(
    """Extract product information from the following description as JSON.

    Description: "Premium stainless steel water bottle. 500ml capacity, 8-hour insulation. Available in red, blue, and black. Price: ¥2,980."

    Output in this exact JSON format:
    {
        "name": "product name",
        "material": "material",
        "capacity_ml": capacity (number),
        "insulation_hours": insulation hours (number),
        "colors": ["color1", "color2"],
        "price_jpy": price (number)
    }

    Output JSON only, no explanation.""",
    generation_config=genai.types.GenerationConfig(
        response_mime_type="application/json"
    )
)

product_data = json.loads(response.text)
print(product_data)
```

## Function Calling: Connecting to External Tools

Function Calling enables agent-like behavior where Gemini decides when to call external functions based on the conversation:

```python
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")

def get_current_weather(city: str) -> dict:
    """Returns current weather for a city (connect to a real weather API in production)"""
    return {"city": city, "temperature": 22, "condition": "sunny"}

tools = [
    genai.protos.Tool(
        function_declarations=[
            genai.protos.FunctionDeclaration(
                name="get_current_weather",
                description="Get the current weather for a specified city",
                parameters=genai.protos.Schema(
                    type=genai.protos.Type.OBJECT,
                    properties={
                        "city": genai.protos.Schema(type=genai.protos.Type.STRING)
                    },
                    required=["city"]
                )
            )
        ]
    )
]

model = genai.GenerativeModel('gemini-2.0-flash', tools=tools)
response = model.generate_content("What's the weather like in Tokyo right now?")

if response.candidates[0].content.parts[0].function_call:
    fc = response.candidates[0].content.parts[0].function_call
    result = get_current_weather(**dict(fc.args))
    print(f"Weather data: {result}")
```

## Streaming Responses

For long responses, streaming lets you display output to the user in real time:

```python
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel('gemini-2.0-flash')

response = model.generate_content(
    "Explain the principles of quantum computing in detail.",
    stream=True
)

for chunk in response:
    print(chunk.text, end="", flush=True)
print()
```

## Error Handling and Retry Logic

Production applications need robust error handling:

```python
import time
import google.generativeai as genai
from google.api_core import exceptions

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel('gemini-2.0-flash')

def generate_with_retry(prompt: str, max_retries: int = 3) -> str:
    """Content generation with automatic retry on transient errors."""
    for attempt in range(max_retries):
        try:
            response = model.generate_content(prompt)
            return response.text
        except exceptions.ResourceExhausted:
            if attempt < max_retries - 1:
                wait_time = 2 ** attempt  # Exponential backoff
                print(f"Rate limit hit. Retrying in {wait_time}s...")
                time.sleep(wait_time)
            else:
                raise
        except exceptions.GoogleAPIError as e:
            print(f"API error: {e}")
            raise
    return ""
```
