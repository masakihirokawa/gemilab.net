## Setup and context: Automate Receipt Management with AI

If you're a freelancer or small business owner, keeping track of receipts and expenses is one of those tedious tasks that eats into your time every month. Manually transcribing data from receipt photos into a spreadsheet is slow and error-prone.

In this tutorial, we'll build a Python system that combines **Gemini API's multimodal (vision) capabilities** with the **Google Sheets API** to automatically extract expense data from receipt images and log everything into a spreadsheet — no manual entry required.

What you'll learn:

- How to use Gemini API to extract date, store name, amount, and tax info from receipt images
- How to write expense data to Google Sheets automatically using the Sheets API
- How to build a batch processor that handles multiple receipts at once

This guide targets Python developers who are already familiar with the basics of the Gemini API. We'll cover everything from setup to a fully working script.

## How the System Works

The workflow consists of three straightforward steps:

**Step 1 — Send the receipt image to Gemini API**

We use Gemini's multimodal capabilities to send both the receipt image and a structured prompt to the API, asking it to extract specific fields: date, store name, total amount, tax amount, tax type, and payment method.

**Step 2 — Gemini returns structured JSON**

By carefully crafting our prompt, we instruct Gemini to respond with clean JSON output that's easy to parse programmatically.

**Step 3 — Write to Google Sheets via the Sheets API**

The extracted data is appended to a designated sheet in a Google Spreadsheet, building up a running expense log.

## Step-by-Step Implementation

### 1. Analyze a Receipt with Gemini API

```python
import google.generativeai as genai
import base64
import json
import os
from pathlib import Path

# Initialize the Gemini API client
genai.configure(api_key=os.environ["GEMINI_API_KEY"])
model = genai.GenerativeModel("gemini-2.5-flash")

def analyze_receipt(image_path: str) -> dict:
    """
    Analyze a receipt image with Gemini API and return structured expense data.

    Args:
        image_path: Path to the receipt image file (JPEG or PNG)

    Returns:
        dict with keys: date, store_name, total_amount, tax_amount,
                        tax_rate, tax_type, payment_method, notes
    """
    with open(image_path, "rb") as f:
        image_data = base64.b64encode(f.read()).decode("utf-8")

    suffix = Path(image_path).suffix.lower()
    mime_type = "image/jpeg" if suffix in [".jpg", ".jpeg"] else "image/png"

    prompt = """
Analyze this receipt or invoice image and return the following information as JSON.
If a field cannot be read, set it to null.
Return ONLY the JSON object — no explanations, no markdown formatting.

{
  "date": "Date in YYYY-MM-DD format",
  "store_name": "Name of the store or issuer",
  "total_amount": Total amount including tax (number only, in local currency),
  "tax_amount": Tax amount (number only, null if unknown),
  "tax_rate": Tax rate percentage (e.g., 10 or 8, null if unknown),
  "tax_type": "taxable" or "tax-exempt" or "reduced-rate",
  "payment_method": "cash" or "credit card" or "e-money" or "other",
  "notes": "Brief summary of items purchased (empty string if not applicable)"
}
"""

    response = model.generate_content([
        {"mime_type": mime_type, "data": image_data},
        prompt,
    ])

    # Strip any markdown code fences if present
    raw = response.text.strip()
    if raw.startswith("```"):
        raw = raw.split("```")[1]
        if raw.startswith("json"):
            raw = raw[4:]

    return json.loads(raw.strip())
```

### 2. Append Expense Data to Google Sheets

```python
from googleapiclient.discovery import build
from google.oauth2 import service_account

SCOPES = ["https://www.googleapis.com/auth/spreadsheets"]
SPREADSHEET_ID = "YOUR_SPREADSHEET_ID"  # Found in the spreadsheet URL
SHEET_NAME = "Expenses"

def get_sheets_service():
    """Build and return a Google Sheets API service object."""
    creds = service_account.Credentials.from_service_account_file(
        os.environ["GOOGLE_APPLICATION_CREDENTIALS"], scopes=SCOPES
    )
    return build("sheets", "v4", credentials=creds)

def append_expense_to_sheet(expense: dict, filename: str) -> None:
    """
    Append a single expense record to the Google Sheet.

    Args:
        expense: Dict returned by analyze_receipt()
        filename: Original receipt filename (for audit trail)
    """
    service = get_sheets_service()

    row = [
        expense.get("date", ""),
        expense.get("store_name", ""),
        expense.get("total_amount", ""),
        expense.get("tax_amount", ""),
        expense.get("tax_rate", ""),
        expense.get("tax_type", ""),
        expense.get("payment_method", ""),
        expense.get("notes", ""),
        filename,
    ]

    result = service.spreadsheets().values().append(
        spreadsheetId=SPREADSHEET_ID,
        range=f"{SHEET_NAME}!A:I",
        valueInputOption="USER_ENTERED",
        body={"values": [row]},
    ).execute()

    updated = result.get("updates", {}).get("updatedCells", 0)
    print(f"  ✅ {updated} cells updated")
```

### 3. Batch Process an Entire Folder of Receipts

```python
import time

def process_receipts(image_dir: str) -> None:
    """
    Process all receipt images in a directory and log them to Google Sheets.

    Args:
        image_dir: Path to the folder containing receipt images
    """
    image_dir = Path(image_dir)
    images = (
        list(image_dir.glob("*.jpg"))
        + list(image_dir.glob("*.jpeg"))
        + list(image_dir.glob("*.png"))
    )

    if not images:
        print("No image files found.")
        return

    print(f"Processing {len(images)} receipts...\n")
    success, errors = 0, 0

    for image_path in sorted(images):
        print(f"Analyzing: {image_path.name}")
        try:
            expense = analyze_receipt(str(image_path))
            store = expense.get("store_name", "Unknown")
            amount = expense.get("total_amount", "-")
            print(f"  Store: {store} | Amount: {amount}")

            append_expense_to_sheet(expense, image_path.name)
            success += 1
            time.sleep(1)  # Stay within rate limits

        except json.JSONDecodeError as e:
            print(f"  JSON parse error: {e}")
            errors += 1
        except Exception as e:
            print(f"  Error: {e}")
            errors += 1

    print(f"\nDone: {success} succeeded, {errors} failed")

if __name__ == "__main__":
    process_receipts("./receipts")
```

## Troubleshooting Common Errors

### Error 1: `json.JSONDecodeError`

Gemini occasionally wraps its JSON response in markdown code fences or adds extra explanation text. Our cleanup logic handles this in most cases, but if it persists, add this line to your prompt: "Do not use markdown formatting or code fences. Return raw JSON only."

### Error 2: `403 Forbidden` from the Sheets API

Your service account doesn't have edit access to the spreadsheet. Open the spreadsheet, click "Share," and add the service account's email address (e.g., `name@project.iam.gserviceaccount.com`) as an Editor.

### Error 3: Incorrect Amount Extraction

Handwritten receipts and faded print reduce accuracy. Try these fixes:
- Increase image resolution (at least 1,200px on the long edge)
- Photograph in bright, shadow-free lighting
- Switch to `gemini-2.5-pro` for higher OCR accuracy when it matters

### Error 4: `ResourceExhausted` (429)

You've hit the API rate limit. Increase the sleep interval: change `time.sleep(1)` to `time.sleep(3)`. The free tier on Google AI Studio allows 15 requests per minute for `gemini-2.5-flash`.
