Managing social media across multiple platforms is time-consuming. Crafting unique posts for X (formerly Twitter), Instagram, and LinkedIn—each with its own character limits, tone, and formatting conventions—can eat up hours every week.

In this guide, you'll learn how to use Gemini API and Python to **automatically generate social media content** that fits each platform. We'll start with a simple single-post generator and work up to a full content calendar that produces a week's worth of posts in a single run.

## Why Gemini API Works Well for Social Media Automation

Gemini API has several features that make it especially well-suited for content generation tasks:

**Structured output (JSON mode)** lets you receive posts for multiple platforms in one organized API call, eliminating messy string parsing. **A large context window (up to 1 million tokens)** allows you to feed in brand guidelines, past post samples, and reference URLs to maintain a consistent voice. And **multimodal support** means you can pass in product images and generate captions based on their visual content.

For pricing details, check out our [Gemini API Pricing Complete Guide](/en/articles/gemini-api/gemini-api-pricing-billing-complete-guide-2026). The `gemini-2.5-flash` model in particular lets you generate large volumes of content at a very low cost.

## Generating a Single Post

Let's start simple: generating one X (Twitter) post from a given topic.

```python
import os
from google import genai

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

def generate_tweet(topic: str, tone: str = "informative") -> str:
    """
    Generate an X (Twitter) post for a given topic and tone.

    Args:
        topic: The subject of the post (e.g., "Python async programming")
        tone: Writing style — "informative", "casual", or "inspiring"

    Returns:
        A generated post (under 280 characters)
    """
    prompt = f"""
You are a professional social media content creator.
Write one X (Twitter) post based on the following inputs.

Topic: {topic}
Tone: {tone}

Requirements:
- Under 280 characters
- Include 2–3 relevant hashtags
- Add 1–2 emojis for visual appeal
- Return only the post text (no explanations)
"""

    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=prompt
    )
    return response.text.strip()

# Example usage
topic = "Automating business workflows with Gemini API"
tweet = generate_tweet(topic, tone="informative")
print(tweet)
# Example output:
# 🤖 Automate your entire workflow with Gemini API!
# From email classification to report generation — all with a few lines of Python.
# Start free and scale as you grow.
# #GeminiAPI #Automation #Python
```

## Multi-Platform Output: Using Structured JSON

In practice, you'll want to generate posts for X, Instagram, and LinkedIn from a single topic at once. Gemini's **structured output mode** makes this clean and reliable.

```python
import os
from google import genai
from pydantic import BaseModel

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

class SocialMediaPost(BaseModel):
    platform: str       # "twitter" | "instagram" | "linkedin"
    content: str        # Post body text
    hashtags: list[str] # List of hashtags (without #)
    char_count: int     # Approximate character count

class SocialMediaBundle(BaseModel):
    topic: str
    posts: list[SocialMediaPost]

def generate_multi_platform_posts(
    topic: str,
    brand_voice: str = "professional yet approachable"
) -> SocialMediaBundle:
    """
    Generate posts for X, Instagram, and LinkedIn from a single topic.

    Args:
        topic: The content theme
        brand_voice: Description of your brand's tone and style

    Returns:
        A SocialMediaBundle containing posts for all three platforms
    """
    prompt = f"""
You are a social media marketing expert.
Create posts for three platforms based on the topic and brand voice below.

Topic: {topic}
Brand Voice: {brand_voice}

Platform requirements:
- X (Twitter): Under 280 characters, 2–3 hashtags, emojis welcome
- Instagram: Caption format (under 500 characters), 5–10 hashtags, use line breaks effectively
- LinkedIn: Professional tone (under 300 characters), 3–5 hashtags, include an insight or takeaway

Write naturally for each platform's audience.
"""

    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=prompt,
        config=genai.types.GenerateContentConfig(
            response_mime_type="application/json",
            response_schema=SocialMediaBundle,
        )
    )

    return SocialMediaBundle.model_validate_json(response.text)

# Example usage
topic = "How Python automation cut our team's workload by 50%"
bundle = generate_multi_platform_posts(topic)

for post in bundle.posts:
    print(f"\n=== {post.platform.upper()} ===")
    print(post.content)
    print(f"Hashtags: {', '.join(['#' + h for h in post.hashtags])}")
    print(f"Character count: {post.char_count}")
```

## Batch Processing: Generate a Full Week's Content Calendar

Rather than generating posts one at a time, it's far more efficient to produce an entire week's content in a single run.

```python
import os
import json
from datetime import date, timedelta
from google import genai

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

def generate_content_calendar(
    topics: list[str],
    start_date: date,
    platform: str = "twitter"
) -> list[dict]:
    """
    Generate a content calendar from a list of topics.

    Args:
        topics: List of themes (7 recommended for a weekly calendar)
        start_date: The first date of the calendar period
        platform: Target platform for post formatting

    Returns:
        List of dicts with date, day-of-week, topic, post content, and hashtags
    """
    topics_text = "\n".join([f"{i+1}. {t}" for i, t in enumerate(topics)])

    prompt = f"""
Write one {platform} post for each of the 7 topics below.
Adapt the tone to match the day of the week (e.g., motivational on Monday, reflective on Friday).

{topics_text}

Return JSON in this format:
[
  {{"day": 1, "topic": "...", "post": "...", "hashtags": ["tag1", "tag2"]}},
  ...
]
"""

    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=prompt,
        config=genai.types.GenerateContentConfig(
            response_mime_type="application/json",
        )
    )

    posts_data = json.loads(response.text)
    calendar = []
    days = ["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]

    for i, post in enumerate(posts_data):
        post_date = start_date + timedelta(days=i)
        calendar.append({
            "date": post_date.strftime("%Y-%m-%d"),
            "day": days[post_date.weekday()],
            "topic": post["topic"],
            "post": post["post"],
            "hashtags": post.get("hashtags", [])
        })

    return calendar

# Example usage
topics = [
    "Getting started with Gemini API",
    "Python automation basics",
    "Prompt engineering fundamentals",
    "Function Calling in practice",
    "Weekly AI news roundup",
    "Weekend learning resources",
    "Automation results and lessons learned"
]

today = date.today()
calendar = generate_content_calendar(topics, start_date=today)

for entry in calendar:
    print(f"\n[{entry['date']} ({entry['day']})]")
    print(entry["post"])
    print(f"Tags: {', '.join(['#' + h for h in entry['hashtags']])}")
```

## Generating Captions from Images (Multimodal)

Gemini's multimodal capabilities let you generate captions directly from product photos or design assets — no need to manually describe what's in the image.

```python
import os
import base64
from pathlib import Path
from google import genai

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

def generate_caption_from_image(
    image_path: str,
    platform: str = "instagram",
    brand_keywords: list[str] = None
) -> str:
    """
    Analyze an image and generate a platform-specific caption.

    Args:
        image_path: Path to the image file
        platform: Target social media platform
        brand_keywords: Optional list of brand-related keywords to weave in

    Returns:
        A generated caption string
    """
    image_data = Path(image_path).read_bytes()
    image_base64 = base64.b64encode(image_data).decode("utf-8")

    keywords_text = ""
    if brand_keywords:
        keywords_text = f"\nBrand keywords to incorporate: {', '.join(brand_keywords)}"

    prompt = f"""
Analyze this image and write a compelling {platform} caption.

Requirements:
- Accurately reflect what's in the image
- Use emotionally engaging language
- Include 5–8 relevant hashtags
- Use line breaks to improve readability{keywords_text}
"""

    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=[
            prompt,
            {
                "inline_data": {
                    "mime_type": "image/jpeg",
                    "data": image_base64
                }
            }
        ]
    )
    return response.text.strip()
```

## Common Errors and How to Fix Them

### `ResourceExhausted: 429 RESOURCE_EXHAUSTED`

This happens when you hit the rate limit on the free tier (15 RPM for `gemini-2.5-flash`). Add a short delay between requests in batch processing:

```python
import time

for topic in topics:
    post = generate_tweet(topic)
    print(post)
    time.sleep(2)  # Wait 2 seconds between requests
```

### Posts Feel Generic or Repetitive

Add a System Instruction to give the model a specific persona and context. This consistently improves output quality:

```python
response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents=prompt,
    config=genai.types.GenerateContentConfig(
        system_instruction=(
            "You are the social media manager for a developer tools startup. "
            "Your audience is engineers and indie hackers. "
            "Be concise, practical, and avoid hype. Use concrete numbers when possible."
        )
    )
)
```

### JSON Parse Errors

Even with `response_mime_type="application/json"`, the model may occasionally return malformed JSON. Wrap parsing in a try/except and retry:

```python
import json

try:
    data = json.loads(response.text)
except json.JSONDecodeError:
    print("JSON parse error — retrying...")
    response = client.models.generate_content(model="gemini-2.5-flash", contents=prompt)
    data = json.loads(response.text)
```

## FAQ

**Q: How many posts can I generate on the free tier?**

A: The `gemini-2.5-flash` free tier allows 500 requests per day (RPD) and 15 requests per minute (RPM). If each request generates posts for 3 platforms at once, you can produce content for 500+ topic–platform combinations daily — more than enough for individual creators or small teams.

**Q: My generated posts all sound the same. How do I add more variety?**

A: Set the `temperature` parameter higher (0.9–1.0) to increase output diversity. You can also instruct the model to vary its structure: "Each post should use a different opening style — question, statistic, anecdote, or bold statement." In your prompt, explicitly say: "Avoid repeating patterns from previous posts."

**Q: Can I schedule posts to publish automatically after generating them?**

A: Gemini API doesn't handle scheduling, but you can pair it with n8n for a fully automated pipeline. Our [Gemini API × n8n Workflow Automation Guide](/en/articles/gemini-api/gemini-api-n8n-workflow-automation-guide) covers exactly this — including integrations with the X API and other social platforms.

**Q: How do I handle multiple brands or accounts with different voices?**

A: Create a configuration dictionary for each brand that stores the System Instruction and any brand keywords. Pass the right config at runtime based on which brand you're generating content for. This keeps your code clean and makes adding new brands straightforward.
