Keeping a blog updated with fresh, high-quality content is one of the hardest parts of content marketing. Between coming up with ideas, researching topics, and actually writing — it's easy for posting frequency to fall behind. Combining the Gemini API with the WordPress REST API solves this by automating the entire pipeline: from topic selection to draft creation, all from a single Python script.

In this guide, you'll learn how to build a **Gemini-powered WordPress auto-posting system** that generates SEO-optimized articles and saves them as drafts for human review before publishing. We'll cover everything from API authentication to scheduling with GitHub Actions.

## What You Can Automate with Gemini API and WordPress

When Gemini API and the WordPress REST API work together, you get a flexible content pipeline:

- **Article generation on demand**: Provide a topic and target keywords, and get a full post back — intro, body sections, FAQ, and summary
- **SEO-ready structure**: Automatically include title tags, meta descriptions, and properly formatted H2/H3 headings
- **Draft publishing**: Posts are saved as `draft` status so a human can review and refine before going live
- **Tag and category assignment**: Let Gemini analyze the content and suggest appropriate categories and tags
- **Scheduled runs**: Combine with cron jobs or GitHub Actions to generate new drafts every morning automatically

The key principle here is **keeping humans in the loop**. AI-generated content works best as a starting point, not a finished product. Saving everything as drafts and having someone review before publishing keeps quality high while dramatically cutting writing time.

## Prerequisites

Before building, make sure you have the following ready:

- **Gemini API key**: Get yours for free at [Google AI Studio](https://aistudio.google.com/)

## Getting a WordPress Application Password

WordPress Application Passwords let external tools authenticate with the REST API without using your main login credentials. They're available by default in WordPress 5.6 and later.

Here's how to create one:

1. Log into your WordPress admin dashboard
2. Navigate to **Users → Profile**
3. Scroll down to the **Application Passwords** section
4. Enter a name for the application (e.g., `Gemini Auto Post`) and click **Add New Application Password**
5. Copy the generated password immediately — it's only shown once
6. Paste it into your `.env` file as `WP_APP_PASSWORD`

## Step 1: Generate Article Content with Gemini API

Start by building the content generation module. The key is crafting a prompt that consistently produces well-structured, SEO-friendly articles.

```python
# article_generator.py
import os
import json
from google import genai
from google.genai import types
from dotenv import load_dotenv

load_dotenv()

# Initialize the Gemini client
client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

def generate_article(topic: str, target_keywords: list[str]) -> dict:
    """
    Generate an SEO-optimized blog article for the given topic and keywords.

    Args:
        topic: The article topic (e.g., "Getting Started with Machine Learning in Python")
        target_keywords: List of SEO target keywords

    Returns:
        Dictionary with title, meta_description, content, and tags
    """
    keywords_str = ", ".join(target_keywords)

    prompt = f"""You are an experienced SEO content writer. Create a high-quality blog post
targeting the following topic and keywords.

Topic: {topic}
Target keywords: {keywords_str}

Return your response as JSON in this exact format:
{{
  "title": "Article title (include primary keyword, under 60 characters)",
  "meta_description": "Meta description (include keyword, under 120 characters)",
  "content": "Full article body in Markdown (at least 1500 words)",
  "tags": ["tag1", "tag2", "tag3"]
}}

Structure the content with:
- Engaging introduction that addresses the reader's pain point
- 4–5 H2 sections covering the topic thoroughly
- At least one practical code example
- A FAQ section with 3 questions and answers
- A concise summary with next steps
"""

    response = client.models.generate_content(
        model="gemini-2.5-pro",
        contents=prompt,
        config=types.GenerateContentConfig(
            response_mime_type="application/json",
            temperature=0.7,
        )
    )

    article_data = json.loads(response.text)
    return article_data

# Quick test
if __name__ == "__main__":
    result = generate_article(
        topic="Getting Started with Machine Learning in Python",
        target_keywords=["machine learning Python", "scikit-learn tutorial", "ML for beginners"]
    )
    print(f"Title: {result['title']}")
    print(f"Word count: {len(result['content'].split())} words")
    # Expected output:
    # Title: Getting Started with Machine Learning in Python — A Beginner's Guide
    # Word count: 1800 words
```

Setting `response_mime_type="application/json"` tells Gemini to return structured JSON every time, which prevents parse errors in the next step. This is one of the most reliable ways to get consistent output from the API.

## Step 2: Publish Drafts via WordPress REST API

Now build the module that handles posting to WordPress. Using `status: "draft"` ensures nothing goes live without human approval.

```python
# wp_poster.py
import os
import base64
import requests
from dotenv import load_dotenv

load_dotenv()

WP_URL = os.environ["WP_URL"]
WP_USERNAME = os.environ["WP_USERNAME"]
WP_APP_PASSWORD = os.environ["WP_APP_PASSWORD"]

def get_auth_header() -> dict:
    """Build the Basic Auth header for WordPress REST API."""
    credentials = f"{WP_USERNAME}:{WP_APP_PASSWORD}"
    token = base64.b64encode(credentials.encode()).decode()
    return {"Authorization": f"Basic {token}"}

def get_or_create_tags(tag_names: list[str]) -> list[int]:
    """
    Resolve tag names to WordPress tag IDs.
    Creates new tags if they don't exist yet.
    """
    tag_ids = []
    headers = get_auth_header()

    for tag_name in tag_names:
        # Search for existing tag
        response = requests.get(
            f"{WP_URL}/wp-json/wp/v2/tags",
            params={"search": tag_name},
            headers=headers,
            timeout=10
        )
        existing = response.json()

        if existing:
            tag_ids.append(existing[0]["id"])
        else:
            # Create new tag
            create_resp = requests.post(
                f"{WP_URL}/wp-json/wp/v2/tags",
                json={"name": tag_name},
                headers={**headers, "Content-Type": "application/json"},
                timeout=10
            )
            if create_resp.status_code == 201:
                tag_ids.append(create_resp.json()["id"])

    return tag_ids

def post_draft(title: str, content: str, meta_description: str, tags: list[str]) -> dict:
    """
    Save an article as a draft post in WordPress.

    Returns:
        The created post data (includes id and link)
    """
    tag_ids = get_or_create_tags(tags)
    headers = get_auth_header()

    post_data = {
        "title": title,
        "content": content,
        "status": "draft",      # Save as draft — not published immediately
        "tags": tag_ids,
        "meta": {
            "_yoast_wpseo_metadesc": meta_description   # Yoast SEO compatible
        }
    }

    response = requests.post(
        f"{WP_URL}/wp-json/wp/v2/posts",
        json=post_data,
        headers={**headers, "Content-Type": "application/json"},
        timeout=30
    )

    if response.status_code == 201:
        result = response.json()
        print(f"✅ Draft saved: {result['link']}")
        return result
    else:
        print(f"❌ Failed to post: {response.status_code} {response.text}")
        response.raise_for_status()
```

## Step 3: Wire Everything Together

Combine both modules into a main script that processes a list of topics in sequence.

```python
# main.py
import time
from article_generator import generate_article
from wp_poster import post_draft

# Topics to generate articles for
TOPICS = [
    {
        "topic": "Getting Started with Machine Learning in Python",
        "keywords": ["machine learning Python", "scikit-learn tutorial", "ML for beginners"]
    },
    {
        "topic": "Next.js 15 App Router Complete Guide",
        "keywords": ["Next.js App Router", "React Server Components", "Next.js tutorial"]
    },
    {
        "topic": "Docker for Beginners — From Setup to Production Deployment",
        "keywords": ["Docker tutorial", "Docker Compose guide", "containerization basics"]
    }
]

def main():
    for item in TOPICS:
        print(f"\n📝 Generating article: {item['topic']}")

        try:
            # Generate article content with Gemini
            article = generate_article(
                topic=item["topic"],
                target_keywords=item["keywords"]
            )

            # Post to WordPress as a draft
            result = post_draft(
                title=article["title"],
                content=article["content"],
                meta_description=article["meta_description"],
                tags=article["tags"]
            )

            print(f"  Title: {article['title']}")
            print(f"  Post ID: {result['id']}")
            print(f"  URL: {result['link']}")

            # Respect API rate limits
            time.sleep(3)

        except Exception as e:
            print(f"  ❌ Error: {e}")
            continue

    print("\n✅ All articles generated and saved as drafts.")

if __name__ == "__main__":
    main()
```

## Automate with GitHub Actions

To run this daily without any manual effort, set up a GitHub Actions workflow:

```yaml
# .github/workflows/auto-blog.yml
name: Auto Blog Generation

on:
  schedule:
    - cron: "0 22 * * *"    # Runs daily at 07:00 JST (22:00 UTC)
  workflow_dispatch:          # Also allows manual runs

jobs:
  generate-posts:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Install dependencies
        run: pip install google-genai requests python-dotenv

      - name: Run article generator
        env:
          GEMINI_API_KEY: ${{ secrets.GEMINI_API_KEY }}
          WP_URL: ${{ secrets.WP_URL }}
          WP_USERNAME: ${{ secrets.WP_USERNAME }}
          WP_APP_PASSWORD: ${{ secrets.WP_APP_PASSWORD }}
        run: python main.py
```

Store your credentials as repository secrets under **Settings → Secrets and variables → Actions**. The workflow will run automatically every morning, and you'll wake up to fresh draft articles waiting for your review.

## Prompt Design Tips for Better SEO Output

The quality of your generated articles depends heavily on how you craft the prompt. Here are a few strategies that consistently produce better results.

**Be specific about search intent.** Rather than "write about topic X," tell Gemini exactly who the reader is and what they're trying to accomplish: "Write for a developer who just heard about Docker and wants to run their first container today." This keeps the content focused and practical.

**Specify the structure in detail.** Tell Gemini exactly how many H2 sections you want, minimum word count, and what elements to include (code examples, FAQ, summary). Vague prompts produce inconsistent results; detailed prompts produce predictable ones.

**Encourage differentiation from generic content.** Add a line like: "This article should be more practical and specific than typical tutorials on this topic. Include a real code example that readers can run immediately." This pushes Gemini away from surface-level summaries.

**Define the tone clearly.** Something like "Write in a friendly, approachable tone — like an experienced developer explaining to a curious colleague" keeps the voice consistent across multiple generated articles.
