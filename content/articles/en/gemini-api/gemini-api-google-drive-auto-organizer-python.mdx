If your Google Drive has turned into a digital junk drawer — hundreds of files with no clear structure — you're not alone. Meeting notes, project proposals, status reports… they pile up fast without a consistent system.

This guide shows you how to combine the **Gemini API and Google Drive API** in Python to build a tool that automatically reads your documents, summarizes their content, classifies them into categories, and moves them into the right folders. You'll get working code you can run today.

## Prerequisites and Setup

You'll need three things to follow along:

- **Python 3.9 or later** (3.11+ recommended)
- **A Gemini API key** (available at Google AI Studio or via Vertex AI)
- **A Google Cloud project** with the Google Drive API enabled

Install the required libraries first:

```bash
pip install google-generativeai google-api-python-client google-auth-httplib2 google-auth-oauthlib
```

### Getting Your Gemini API Key

Visit [Google AI Studio](https://aistudio.google.com/), click "Get API key," and create one. Store it as an environment variable — never hardcode keys in source files.

```bash
export GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
```

### Enabling the Google Drive API

In the Google Cloud Console, create a project, enable the **Google Drive API**, then go to **Credentials → Create OAuth Client ID**. Download the resulting `credentials.json` file and place it in your project folder.

## Connecting to Google Drive: Fetching Your Files

The first step is authenticating with Google and pulling a list of documents from Drive.

```python
import os
import io
from google.oauth2.credentials import Credentials
from google_auth_oauthlib.flow import InstalledAppFlow
from google.auth.transport.requests import Request
from googleapiclient.discovery import build
from googleapiclient.http import MediaIoBaseDownload

# OAuth scopes: read files and manage folder structure
SCOPES = [
    'https://www.googleapis.com/auth/drive.readonly',
    'https://www.googleapis.com/auth/drive.file'
]

def get_drive_service():
    """Authenticate and return a Google Drive API service object."""
    creds = None
    # Reuse cached credentials if available
    if os.path.exists('token.json'):
        creds = Credentials.from_authorized_user_file('token.json', SCOPES)
    if not creds or not creds.valid:
        if creds and creds.expired and creds.refresh_token:
            creds.refresh(Request())
        else:
            flow = InstalledAppFlow.from_client_secrets_file('credentials.json', SCOPES)
            creds = flow.run_local_server(port=0)
        with open('token.json', 'w') as token:
            token.write(creds.to_json())
    return build('drive', 'v3', credentials=creds)

def list_documents(service, folder_id=None, max_files=20):
    """Return a list of Google Docs from Drive (or a specific folder)."""
    query = "mimeType='application/vnd.google-apps.document' and trashed=false"
    if folder_id:
        query += f" and '{folder_id}' in parents"
    results = service.files().list(
        q=query,
        pageSize=max_files,
        fields="files(id, name, mimeType, createdTime)"
    ).execute()
    return results.get('files', [])

def export_document_as_text(service, file_id):
    """Export a Google Doc as plain text."""
    request = service.files().export_media(
        fileId=file_id,
        mimeType='text/plain'
    )
    buffer = io.BytesIO()
    downloader = MediaIoBaseDownload(buffer, request)
    done = False
    while not done:
        _, done = downloader.next_chunk()
    return buffer.getvalue().decode('utf-8', errors='replace')
```

## Analyzing Documents with the Gemini API

Now for the core logic: sending document text to Gemini and getting back a structured summary and category.

```python
import google.generativeai as genai

def analyze_document(text: str, filename: str) -> dict:
    """
    Use Gemini to summarize and categorize a document.
    Returns: {"summary": str, "category": str, "keywords": list}
    """
    genai.configure(api_key=os.environ["GEMINI_API_KEY"])
    model = genai.GenerativeModel("gemini-2.0-flash")

    # Trim to first 2,000 characters to stay within rate limits for batch jobs
    truncated = text[:2000]

    prompt = f"""Analyze the following business document and respond with JSON only.

Filename: {filename}
Content (excerpt):
{truncated}

Return this exact JSON structure:
{{
  "summary": "2-3 sentence summary of the document",
  "category": "One of: Meeting Notes / Proposal / Report / Manual / Memo / Other",
  "keywords": ["keyword1", "keyword2", "keyword3"]
}}
Return only the JSON. No explanation."""

    response = model.generate_content(prompt)
    import json, re
    json_match = re.search(r'\{.*\}', response.text, re.DOTALL)
    if json_match:
        return json.loads(json_match.group())
    return {"summary": "Unable to parse", "category": "Other", "keywords": []}
```

We're using `gemini-2.0-flash` here because it's fast and cost-effective for batch processing. Gemini supports up to 1 million tokens of context per request, so you can increase `truncated` beyond 2,000 characters if you need more accuracy.

For more reliable JSON extraction, consider using Gemini's built-in Structured Output feature, which returns strongly-typed responses without regex parsing. This technique is covered in depth in the [Gemini API × E-commerce Product Content Automation Guide](/articles/gemini-api/gemini-api-ecommerce-product-content-automation).

## Building the Workflow: Classify → Move to Folder

With summaries and categories in hand, we can move files into the appropriate folders automatically.

```python
def get_or_create_folder(service, folder_name: str, parent_id: str = None) -> str:
    """Return the ID of a folder by name, creating it if it doesn't exist."""
    query = f"name='{folder_name}' and mimeType='application/vnd.google-apps.folder' and trashed=false"
    if parent_id:
        query += f" and '{parent_id}' in parents"
    results = service.files().list(q=query, fields="files(id)").execute()
    folders = results.get('files', [])
    if folders:
        return folders[0]['id']
    # Create the folder
    metadata = {'name': folder_name, 'mimeType': 'application/vnd.google-apps.folder'}
    if parent_id:
        metadata['parents'] = [parent_id]
    folder = service.files().create(body=metadata, fields='id').execute()
    return folder['id']

def move_file_to_folder(service, file_id: str, new_folder_id: str):
    """Move a file to a new parent folder."""
    file = service.files().get(fileId=file_id, fields='parents').execute()
    previous_parents = ','.join(file.get('parents', []))
    service.files().update(
        fileId=file_id,
        addParents=new_folder_id,
        removeParents=previous_parents,
        fields='id, parents'
    ).execute()

def organize_drive(root_folder_id: str = None, dry_run: bool = True):
    """
    Main function: analyze Drive docs and sort them into category folders.
    Set dry_run=False to actually move files.
    """
    service = get_drive_service()
    files = list_documents(service, folder_id=root_folder_id, max_files=10)

    print(f"Files to process: {len(files)}\n")

    for file in files:
        print(f"Processing: {file['name']}")
        try:
            text = export_document_as_text(service, file['id'])
        except Exception as e:
            print(f"  ⚠️  Could not read file: {e}")
            continue

        result = analyze_document(text, file['name'])
        category = result.get('category', 'Other')
        summary = result.get('summary', '')

        print(f"  Category: {category}")
        print(f"  Summary: {summary}")

        if not dry_run:
            folder_id = get_or_create_folder(service, category, parent_id=root_folder_id)
            move_file_to_folder(service, file['id'], folder_id)
            print(f"  ✅ Moved to '{category}' folder")
        else:
            print(f"  [DRY RUN] Would move to '{category}' folder")
        print()

if __name__ == "__main__":
    # Always test with dry_run=True before enabling actual moves
    organize_drive(dry_run=True)
```

The `dry_run=True` default is an important safety net. Run in dry-run mode first to verify categories look correct before committing any moves.

## Common Errors and How to Fix Them

**`HttpError 403: The caller does not have permission`**
Your OAuth scopes are too restrictive. Make sure `SCOPES` includes `drive.file` (to move files) alongside `drive.readonly`. Delete `token.json` and re-authenticate.

**`google.auth.exceptions.RefreshError`**
Your cached OAuth token has expired. Delete `token.json` and run `organize_drive()` again to trigger a fresh browser login.

**Gemini response isn't valid JSON**
Even with explicit JSON instructions, the model occasionally wraps responses in markdown code blocks. The `re.search(r'\{.*\}', ..., re.DOTALL)` pattern handles this. For production use, set `response_mime_type="application/json"` in the generation config for guaranteed JSON output.

**Slow processing speed**
On the free tier, Gemini API enforces requests-per-minute (RPM) limits. If you're processing many files, add `import time; time.sleep(1)` between API calls to stay within limits.
