There's a persistent gap between people who can work with AI APIs and businesses that need what those APIs can do.

Most small and mid-sized companies are interested in AI but can't hire a machine learning engineer. They don't know how to interact with APIs, evaluate vendors, or implement anything themselves. If you can do what they can't, that's a service business waiting to happen.

This article covers the practical path from "I know how to use Gemini API" to a running B2B consulting service — with service design, demo implementation code, monthly reporting automation, and pricing logic.

## Three Service Patterns That Actually Sell

Based on what tends to find clients and hold them, three patterns stand out.

**Pattern 1 — Workflow Automation Agent ($300–$1,500/month)**

Examples: auto-classifying incoming support emails and routing them to the right person; extracting amounts and vendors from invoice PDFs and logging them to a spreadsheet; generating first-draft responses to common inquiries.

These are recurring, repetitive tasks that cost companies real labor hours every month. You automate them once, charge a monthly retainer, and the value is immediately measurable.

**Pattern 2 — AI Report Generation Service ($200–$800/month)**

Examples: weekly competitive intelligence report summarizing relevant news; monthly e-commerce sales analysis with AI-generated insights; automated quarterly market briefings for sales teams.

You define the report spec once. Gemini does the data gathering and synthesis. The client receives a polished document without anyone having spent hours researching.

**Pattern 3 — Custom Chatbot Build ($1,500–$5,000 one-time + monthly maintenance)**

FAQ chatbots, internal knowledge search, sales enablement bots. Pair Gemini with RAG (Retrieval-Augmented Generation) to ground responses in company-specific documents. One-time build fee, optional monthly maintenance retainer.

## Discovery Interview Framework

Five questions to ask before any proposal. If you know these answers, you can design a service that actually delivers value.

**① What's the specific bottleneck?** (e.g., "handling support requests takes our team 2 hours a day")

**② What's the volume and frequency?** (e.g., "500 inquiries per month, 3 people handling them")

**③ What's the current process?** (e.g., "manually sorting emails in Gmail, copy-pasting answers")

**④ What does success look like?** (e.g., "reduce time spent by half" vs. "eliminate errors" vs. "handle volume without adding headcount")

**⑤ What's the budget range?** (Not always answerable upfront, but worth asking early)

The answers tell you which pattern fits and what to scope.

## Implementation: Inquiry Classification Agent (Demo Quality)

Showing a working demo converts significantly better than describing what you'd build. Here's an inquiry classification agent you can demo immediately.

```python
import google.generativeai as genai
import json
from enum import Enum
from dataclasses import dataclass

genai.configure(api_key="YOUR_GEMINI_API_KEY")

class InquiryCategory(str, Enum):
    SUPPORT = "Technical Support"
    BILLING = "Billing & Payment"
    SALES = "Sales & Pricing"
    GENERAL = "General Inquiry"
    URGENT = "Urgent - Escalate Immediately"

@dataclass
class ClassificationResult:
    category: InquiryCategory
    priority: str           # high / medium / low
    suggested_assignee: str
    summary: str
    estimated_response_time: str

def classify_inquiry(email_body: str, team_context: str = "") -> ClassificationResult:
    """
    Classifies an incoming inquiry and returns routing recommendations.
    
    team_context: Pass company-specific info (team members, specialties, policies)
                  to customize routing logic per client.
    """
    model = genai.GenerativeModel(
        "gemini-2.5-pro",
        generation_config=genai.GenerationConfig(
            response_mime_type="application/json",
            response_schema={
                "type": "object",
                "properties": {
                    "category": {"type": "string", "enum": [e.value for e in InquiryCategory]},
                    "priority": {"type": "string", "enum": ["high", "medium", "low"]},
                    "suggested_assignee": {"type": "string"},
                    "summary": {"type": "string"},
                    "estimated_response_time": {"type": "string"},
                },
                "required": ["category", "priority", "suggested_assignee", "summary", "estimated_response_time"]
            }
        )
    )
    
    context = f"\n\nTeam context:\n{team_context}" if team_context else ""
    
    prompt = f"""Analyze this incoming inquiry and determine classification, priority, and routing.{context}

Inquiry:
{email_body}

Priority guidelines:
- high: System outages, refund demands, legal threats, SLA breaches
- medium: Standard support, general questions, feature requests
- low: Sales inquiries, documentation requests, feedback

Estimate response time as one of: "Immediate", "Within 2 hours", "Within 24 hours", "Within 2 business days"
"""
    
    response = model.generate_content(prompt)
    data = json.loads(response.text)
    
    return ClassificationResult(
        category=InquiryCategory(data["category"]),
        priority=data["priority"],
        suggested_assignee=data["suggested_assignee"],
        summary=data["summary"],
        estimated_response_time=data["estimated_response_time"]
    )


# Demo with a sample inquiry
sample = """
Hi, I've been trying to access my account for the past 3 hours and keep getting 
an authentication error. I have a client presentation in 2 hours and I need access 
to pull my reports. If this isn't resolved soon I may need to request a refund 
for this month's subscription.
"""

team_context = """
- Agent Sarah: Technical issues and outages specialist
- Agent Marcus: Billing, refunds, subscription changes  
- Agent Lisa: Sales, onboarding, feature questions
"""

result = classify_inquiry(sample, team_context)
print(f"Category: {result.category.value}")
print(f"Priority: {result.priority}")
print(f"Route to: {result.suggested_assignee}")
print(f"Respond by: {result.estimated_response_time}")
print(f"Summary: {result.summary}")
```

The demo's value is in the `team_context` parameter — you can customize it for each prospect in 5 minutes, making it feel purpose-built for their organization.

## Implementation: Automated Monthly Report Generator

Monthly reports justify ongoing retainers. Without them, clients start wondering if you're actually doing anything.

```python
import google.generativeai as genai

def generate_monthly_report(
    client_name: str,
    service_description: str,
    usage_data: dict,
    billing_period: str,
) -> str:
    """
    Generates a client-facing monthly service report.
    
    usage_data expects:
        total_processed: int (total inquiries/items handled)
        auto_resolved: int (handled without human intervention)
        escalated: int (required human review)
        avg_response_time_minutes: float
        labor_hours_saved: float
    """
    model = genai.GenerativeModel("gemini-2.5-pro")
    
    total = usage_data["total_processed"]
    auto = usage_data["auto_resolved"]
    resolution_rate = (auto / total * 100) if total > 0 else 0
    
    prompt = f"""Generate a professional monthly service report for a client.

Client: {client_name}
Period: {billing_period}
Service: {service_description}

Performance metrics:
- Total items processed: {total:,}
- Automatically resolved: {auto:,} ({resolution_rate:.1f}% auto-resolution rate)
- Escalated to human: {usage_data['escalated']:,}
- Average response time: {usage_data['avg_response_time_minutes']:.1f} minutes
- Estimated labor hours saved: {usage_data['labor_hours_saved']:.1f} hours

Structure the report as:
1. Executive Summary (3 bullet points)
2. Key Achievements This Month
3. Performance Highlights (use a list, not tables)
4. Recommendations for Next Month (1-2 items)

Tone: Professional, concise, positive. Lead with outcomes, not process."""
    
    response = model.generate_content(prompt)
    return response.text


# Generate example report
report = generate_monthly_report(
    client_name="Acme Corp",
    service_description="Customer inquiry auto-classification and routing",
    usage_data={
        "total_processed": 847,
        "auto_resolved": 721,
        "escalated": 126,
        "avg_response_time_minutes": 2.3,
        "labor_hours_saved": 42.5,
    },
    billing_period="April 2026",
)
print(report)
```

Automate the PDF conversion and email delivery of this report, and the entire "end-of-month client update" task runs itself.

## Pricing Logic

Start from what you're actually spending — time and API costs — then work outward.

API cost for 10,000 Gemini calls/month using gemini-2.5-pro: roughly $50–100. Your time (initial build, maintenance, monthly report review): at $80/hour, 10 hours/month = $800. Add margin.

At $500/month, you're covering costs with modest margin. At $1,000/month, the math works well with a small client base. At $1,500+/month, you can take 5–8 clients and build a real practice.

**When clients ask to lower the price**: Respond by adjusting scope, not rate. "We could remove the monthly reporting feature and drop the price to $X." This protects your hourly value while giving the client a choice.

## Three Failure Modes to Avoid

**Scope creep without billing**: "Can you just add one more thing?" happens every engagement. Define deliverables in writing. New features are new line items.

**No error handling in production**: Gemini API will occasionally fail. Without retry logic and fallback behavior, your client sees errors and questions reliability. Add exponential backoff retries and log every failure. Know about outages before your clients do.

**Invisible value**: If clients don't see what's happening, they wonder if they're getting value. Monthly reports aren't optional — they're how you prove ongoing worth.

## Getting the First Client

The fastest path to a first paying client is warm outreach: former colleagues, local business contacts, owners of businesses you already use.

Offer to run the first pilot for free or at a steep discount in exchange for usage data and a testimonial. Real numbers — "we processed 847 items last month and saved 42 hours of manual work" — are your primary sales asset going forward. Once you have one client's data to show, conversations with the second and third become much easier.
