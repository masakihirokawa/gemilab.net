## Setup and context — Why Production Live API Is Harder Than It Looks

The Gemini Live API is a powerful tool for building low-latency, bidirectional real-time AI experiences. Many developers get it running in a demo or proof-of-concept without trouble — then hit a wall when moving to production.

The core challenge is **security architecture**.

Live API uses WebSocket (WSS) connections. A naïve implementation has the client browser connect directly to `wss://generativelanguage.googleapis.com/ws/...?key=YOUR_API_KEY`. This leaves your API key visible in browser DevTools and network logs — completely unacceptable in production.

Google's recommended approach is the **Ephemeral Token** architecture. Your backend generates a short-lived, single-use token and hands it to the frontend. The frontend then connects directly to the Live API using that token. This gives you the performance benefit of a direct client-to-server WebSocket while keeping the API key completely server-side.

This article covers everything you need for production: ephemeral token implementation, WebSocket design patterns, audio PCM streaming, Function Calling integration, reconnection logic, and a complete Next.js App Router integration.

If you're new to the Live API, start with the [Gemini Live API Complete Guide](/en/articles/gemini-api/gemini-live-api-guide) first. This article picks up where that leaves off.

## Live API Architecture Overview

Understanding the difference between the standard REST API and the Live API is essential before writing a line of code.

**Standard REST API (generateContent)** is stateless: one request, one response. The client sends an HTTP POST, the server returns JSON. Simple, familiar, and cacheable.

**Live API (BidiGenerateContent)** is a persistent, stateful WebSocket connection. Once established, client and server exchange messages asynchronously — audio frames, text turns, tool calls, and tool responses all flow over the same connection.

The connection lifecycle follows four steps.

**Step 1: Send a setup message.** Immediately after the WebSocket opens, the client sends a `setup` message containing the model name, generation config, response modalities, system instructions, and any tool definitions.

**Step 2: Receive `setupComplete`.** The server acknowledges the session is ready.

**Step 3: Bidirectional streaming.** The client sends `realtimeInput` (high-frequency audio/video/text chunks) or `clientContent` (structured turn-based messages). The server sends back `serverContent` (model responses) or `toolCall` messages.

**Step 4: Disconnection.** Either side closes the connection. If the server is initiating, it sends a `goAway` message first.

## Basic Implementation: Establishing a WebSocket Session

Before adding ephemeral tokens, here is a server-side-only baseline implementation. This is appropriate for backend scripts and server-to-server proxy architectures.

```python
# backend/live_api_basic.py
import asyncio
import json
import websockets
import os

GEMINI_API_KEY = os.environ["GEMINI_API_KEY"]
LIVE_API_URL = (
    f"wss://generativelanguage.googleapis.com/ws/"
    f"google.ai.generativelanguage.v1beta."
    f"GenerativeService.BidiGenerateContent?key={GEMINI_API_KEY}"
)

SETUP_MESSAGE = {
    "setup": {
        "model": "models/gemini-2.0-flash",
        "generationConfig": {
            "temperature": 0.7,
            "maxOutputTokens": 1024,
            "responseModalities": ["TEXT"]
        },
        "systemInstruction": {
            "parts": [{"text": "You are a helpful assistant. Respond concisely."}]
        }
    }
}

async def run_live_session():
    async with websockets.connect(LIVE_API_URL) as ws:
        # 1. Send setup
        await ws.send(json.dumps(SETUP_MESSAGE))
        print("Setup sent")

        # 2. Wait for setupComplete
        while True:
            msg = json.loads(await ws.recv())
            if "setupComplete" in msg:
                print("Session ready!")
                break

        # 3. Send a text message
        client_content = {
            "clientContent": {
                "turns": [
                    {"role": "user", "parts": [{"text": "Hello! What can you do?"}]}
                ],
                "turnComplete": True
            }
        }
        await ws.send(json.dumps(client_content))

        # 4. Receive and print the response
        async for raw_msg in ws:
            msg = json.loads(raw_msg)
            if "serverContent" in msg:
                content = msg["serverContent"]
                if "modelTurn" in content:
                    for part in content["modelTurn"].get("parts", []):
                        if "text" in part:
                            print(part["text"], end="", flush=True)
                if content.get("turnComplete"):
                    print("\n--- Turn complete ---")
                    break

asyncio.run(run_live_session())
```

Expected output:

```
Setup sent
Session ready!
I can help you with a wide range of tasks...
--- Turn complete ---
```

## Ephemeral Token Implementation (The Security Core)

In production, the frontend should never hold your API key. The ephemeral token flow works as follows:

```
[Client] → auth request → [Your Backend]
                          ↓
              [Backend calls Gemini ephemeral token API]
                          ↓
[Client] ← short-lived token (30 min) ← [Your Backend]
    ↓
[Client] → WebSocket with token → [Gemini Live API]
```

### Backend: Token Issuance API Route (Next.js)

```typescript
// app/api/live/token/route.ts
import { NextRequest, NextResponse } from "next/server";

const TOKEN_ENDPOINT =
  "https://generativelanguage.googleapis.com/v1alpha/ephemeralTokens:create";

export async function POST(req: NextRequest) {
  // 1. Verify the user is authenticated (your own auth logic)
  const session = await getServerSession(req); // e.g., next-auth
  if (!session?.user) {
    return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
  }

  const apiKey = process.env.GEMINI_API_KEY;
  if (!apiKey) {
    return NextResponse.json({ error: "Server config error" }, { status: 500 });
  }

  try {
    const response = await fetch(`${TOKEN_ENDPOINT}?key=${apiKey}`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        ttl: "1800s",                         // 30-minute expiry
        model: "models/gemini-2.0-flash",
        systemInstruction: {
          parts: [{ text: "You are a helpful assistant for our application." }]
        },
        responseModalities: ["TEXT", "AUDIO"] // restrict what the token can do
      })
    });

    if (!response.ok) {
      const errorBody = await response.text();
      console.error("Token generation failed:", errorBody);
      return NextResponse.json({ error: "Failed to generate token" }, { status: 500 });
    }

    const data = await response.json();
    return NextResponse.json({
      token: data.token,
      expiresAt: data.expireTime
    });
  } catch (err) {
    console.error("Token API error:", err);
    return NextResponse.json({ error: "Internal error" }, { status: 500 });
  }
}
```

### Frontend: Connecting with an Ephemeral Token

```typescript
// hooks/useLiveApi.ts
import { useCallback, useRef, useState } from "react";

const LIVE_WS_BASE =
  "wss://generativelanguage.googleapis.com/ws/" +
  "google.ai.generativelanguage.v1alpha." +
  "GenerativeService.BidiGenerateContentConstrained";

export function useLiveApi() {
  const wsRef = useRef<WebSocket | null>(null);
  const [isConnected, setIsConnected] = useState(false);
  const [isReady, setIsReady] = useState(false);
  const [messages, setMessages] = useState<string[]>([]);

  const connect = useCallback(async () => {
    // 1. Fetch ephemeral token from your backend
    const res = await fetch("/api/live/token", { method: "POST" });
    if (!res.ok) throw new Error("Failed to get token");
    const { token } = await res.json();

    // 2. Connect directly to Live API using the token (no API key exposed)
    const ws = new WebSocket(`${LIVE_WS_BASE}?access_token=${token}`);
    wsRef.current = ws;

    ws.onopen = () => {
      setIsConnected(true);
      ws.send(JSON.stringify({
        setup: {
          model: "models/gemini-2.0-flash",
          generationConfig: {
            temperature: 0.7,
            maxOutputTokens: 1024,
            responseModalities: ["TEXT"]
          }
        }
      }));
    };

    ws.onmessage = (event) => {
      const msg = JSON.parse(event.data);

      if ("setupComplete" in msg) {
        setIsReady(true);
        return;
      }

      if ("serverContent" in msg) {
        const parts = msg.serverContent?.modelTurn?.parts ?? [];
        for (const part of parts) {
          if (part.text) {
            setMessages((prev) => [...prev, part.text]);
          }
        }
      }
    };

    ws.onerror = (err) => console.error("WebSocket error:", err);
    ws.onclose = () => {
      setIsConnected(false);
      setIsReady(false);
    };
  }, []);

  const sendText = useCallback((text: string) => {
    if (!wsRef.current || wsRef.current.readyState !== WebSocket.OPEN) return;
    wsRef.current.send(JSON.stringify({
      clientContent: {
        turns: [{ role: "user", parts: [{ text }] }],
        turnComplete: true
      }
    }));
  }, []);

  const disconnect = useCallback(() => {
    wsRef.current?.close();
    wsRef.current = null;
  }, []);

  return { connect, sendText, disconnect, isConnected, isReady, messages };
}
```

## Real-Time Audio Streaming

Audio streaming is the Live API's killer feature. Microphone input needs to be captured as 16kHz, 16-bit PCM and Base64-encoded before sending.

```typescript
// hooks/useLiveAudio.ts
import { useCallback, useRef } from "react";

const SAMPLE_RATE = 16000; // Input: 16 kHz
// Output from server: 24 kHz PCM

export function useLiveAudio(ws: WebSocket | null) {
  const audioContextRef = useRef<AudioContext | null>(null);
  const processorRef = useRef<ScriptProcessorNode | null>(null);
  const streamRef = useRef<MediaStream | null>(null);

  const startRecording = useCallback(async () => {
    if (!ws || ws.readyState !== WebSocket.OPEN) return;

    const stream = await navigator.mediaDevices.getUserMedia({
      audio: {
        sampleRate: SAMPLE_RATE,
        channelCount: 1,
        echoCancellation: true,
        noiseSuppression: true
      }
    });
    streamRef.current = stream;

    const audioCtx = new AudioContext({ sampleRate: SAMPLE_RATE });
    audioContextRef.current = audioCtx;

    const source = audioCtx.createMediaStreamSource(stream);
    // Note: For production, prefer AudioWorkletNode over ScriptProcessorNode
    const processor = audioCtx.createScriptProcessor(4096, 1, 1);
    processorRef.current = processor;

    processor.onaudioprocess = (event) => {
      const inputData = event.inputBuffer.getChannelData(0);
      const pcm16 = float32ToPcm16(inputData);
      const base64Audio = arrayBufferToBase64(pcm16.buffer);

      ws.send(JSON.stringify({
        realtimeInput: {
          mediaChunks: [{
            mimeType: "audio/pcm;rate=16000",
            data: base64Audio
          }]
        }
      }));
    };

    source.connect(processor);
    processor.connect(audioCtx.destination);
  }, [ws]);

  const stopRecording = useCallback(() => {
    processorRef.current?.disconnect();
    audioContextRef.current?.close();
    streamRef.current?.getTracks().forEach((t) => t.stop());
  }, []);

  return { startRecording, stopRecording };
}

function float32ToPcm16(float32Array: Float32Array): Int16Array {
  const pcm16 = new Int16Array(float32Array.length);
  for (let i = 0; i < float32Array.length; i++) {
    const clamp = Math.max(-1, Math.min(1, float32Array[i]));
    pcm16[i] = clamp < 0 ? clamp * 32768 : clamp * 32767;
  }
  return pcm16;
}

function arrayBufferToBase64(buffer: ArrayBuffer): string {
  const bytes = new Uint8Array(buffer);
  let binary = "";
  for (let i = 0; i < bytes.byteLength; i++) {
    binary += String.fromCharCode(bytes[i]);
  }
  return btoa(binary);
}
```

Audio responses from the server arrive as Base64-encoded 24kHz PCM in `serverContent.modelTurn.parts[].inlineData.data`. Decode and play them using the Web Audio API's `AudioContext.decodeAudioData()`.

## Function Calling Integration

Function Calling works in Live API sessions. Define your tools in the setup message and respond to `toolCall` messages.

```typescript
// Setup with tools defined
const SETUP_WITH_TOOLS = {
  setup: {
    model: "models/gemini-2.0-flash",
    generationConfig: { responseModalities: ["TEXT"] },
    tools: [
      {
        functionDeclarations: [
          {
            name: "get_weather",
            description: "Get current weather for a location",
            parameters: {
              type: "OBJECT",
              properties: {
                location: {
                  type: "STRING",
                  description: "City and country, e.g. Tokyo, Japan"
                }
              },
              required: ["location"]
            }
          }
        ]
      }
    ]
  }
};

// Handle incoming toolCall messages
async function handleToolCall(
  ws: WebSocket,
  msg: Record<string, unknown>
) {
  const toolCall = msg.toolCall as {
    functionCalls: Array<{ id: string; name: string; args: Record<string, unknown> }>;
  };

  const functionResponses = await Promise.all(
    toolCall.functionCalls.map(async (call) => {
      let result: unknown = { error: "Unknown function" };

      if (call.name === "get_weather") {
        result = await fetchWeatherFromApi(call.args.location as string);
      }

      return { id: call.id, name: call.name, response: { result } };
    })
  );

  ws.send(JSON.stringify({ toolResponse: { functionResponses } }));
}
```

## Production Hardening: Reconnection and Error Handling

WebSocket connections drop. Network hiccups, server restarts, and token expiry all cause disconnections. A production implementation needs automatic reconnection with exponential backoff.

```typescript
// lib/LiveApiManager.ts
export class LiveApiManager {
  private ws: WebSocket | null = null;
  private reconnectAttempts = 0;
  private readonly maxReconnectAttempts = 5;
  private readonly baseDelay = 1000;
  private onMessageHandler: ((msg: Record<string, unknown>) => void) | null = null;
  private isIntentionallyClosed = false;

  constructor(
    private readonly getToken: () => Promise<string>,
    private readonly wsBase: string
  ) {}

  setMessageHandler(handler: (msg: Record<string, unknown>) => void) {
    this.onMessageHandler = handler;
  }

  async connect(): Promise<void> {
    this.isIntentionallyClosed = false;
    await this.createConnection();
  }

  private async createConnection(): Promise<void> {
    const token = await this.getToken();
    const ws = new WebSocket(`${this.wsBase}?access_token=${token}`);

    ws.onopen = () => {
      console.log("Connected to Gemini Live API");
      this.reconnectAttempts = 0;
      ws.send(JSON.stringify({
        setup: {
          model: "models/gemini-2.0-flash",
          generationConfig: { temperature: 0.7, responseModalities: ["TEXT"] }
        }
      }));
    };

    ws.onmessage = (event) => {
      this.onMessageHandler?.(JSON.parse(event.data));
    };

    ws.onclose = (event) => {
      this.ws = null;
      if (this.isIntentionallyClosed) return;
      console.warn(`WebSocket closed (code: ${event.code}). Reconnecting...`);
      this.scheduleReconnect();
    };

    this.ws = ws;
  }

  private scheduleReconnect() {
    if (this.reconnectAttempts >= this.maxReconnectAttempts) {
      console.error("Max reconnect attempts reached.");
      return;
    }
    // Exponential backoff with jitter: 1s, 2s, 4s, 8s, 16s
    const delay =
      this.baseDelay * Math.pow(2, this.reconnectAttempts) +
      Math.random() * 500;
    this.reconnectAttempts++;
    setTimeout(() => this.createConnection(), delay);
  }

  send(data: Record<string, unknown>): boolean {
    if (!this.ws || this.ws.readyState !== WebSocket.OPEN) return false;
    this.ws.send(JSON.stringify(data));
    return true;
  }

  disconnect() {
    this.isIntentionallyClosed = true;
    this.ws?.close();
    this.ws = null;
  }

  get isConnected(): boolean {
    return this.ws?.readyState === WebSocket.OPEN;
  }
}
```

## Full Next.js Integration Example

Here is how everything comes together in a Next.js App Router component.

```tsx
// components/LiveApiChat.tsx
"use client";

import { useEffect, useRef, useState } from "react";
import { LiveApiManager } from "@/lib/LiveApiManager";

const WS_BASE =
  "wss://generativelanguage.googleapis.com/ws/" +
  "google.ai.generativelanguage.v1alpha." +
  "GenerativeService.BidiGenerateContentConstrained";

export function LiveApiChat() {
  const managerRef = useRef<LiveApiManager | null>(null);
  const [isReady, setIsReady] = useState(false);
  const [messages, setMessages] = useState<Array<{ role: string; text: string }>>([]);
  const [input, setInput] = useState("");

  useEffect(() => {
    const manager = new LiveApiManager(
      async () => {
        const res = await fetch("/api/live/token", { method: "POST" });
        if (!res.ok) throw new Error("Token fetch failed");
        return (await res.json()).token;
      },
      WS_BASE
    );

    manager.setMessageHandler((msg) => {
      if ("setupComplete" in msg) {
        setIsReady(true);
        return;
      }
      if ("serverContent" in msg) {
        const parts =
          (msg.serverContent as Record<string, unknown>)?.modelTurn as
          { parts?: Array<{ text?: string }> } | undefined;
        const text = (parts?.parts ?? [])
          .filter((p) => p.text)
          .map((p) => p.text as string)
          .join("");
        if (text) setMessages((prev) => [...prev, { role: "model", text }]);
      }
    });

    managerRef.current = manager;
    manager.connect();
    return () => manager.disconnect();
  }, []);

  const handleSend = () => {
    const text = input.trim();
    if (!text || !isReady || !managerRef.current) return;
    setMessages((prev) => [...prev, { role: "user", text }]);
    managerRef.current.send({
      clientContent: {
        turns: [{ role: "user", parts: [{ text }] }],
        turnComplete: true
      }
    });
    setInput("");
  };

  return (
    <div className="flex flex-col h-screen max-w-2xl mx-auto p-4">
      <div className="mb-2 text-sm text-gray-500">
        Status: {isReady ? "🟢 Ready" : "🟡 Connecting..."}
      </div>
      <div className="flex-1 overflow-y-auto space-y-2 mb-4">
        {messages.map((m, i) => (
          <div
            key={i}
            className={`p-3 rounded-lg max-w-xs ${
              m.role === "user"
                ? "bg-blue-100 ml-auto"
                : "bg-gray-100 mr-auto"
            }`}
          >
            {m.text}
          </div>
        ))}
      </div>
      <div className="flex gap-2">
        <input
          className="flex-1 border rounded-lg px-4 py-2"
          value={input}
          onChange={(e) => setInput(e.target.value)}
          onKeyDown={(e) => e.key === "Enter" && handleSend()}
          placeholder="Type a message..."
          disabled={!isReady}
        />
        <button
          className="px-6 py-2 bg-blue-600 text-white rounded-lg disabled:opacity-50"
          onClick={handleSend}
          disabled={!isReady || !input.trim()}
        >
          Send
        </button>
      </div>
    </div>
  );
}
```

## Cost Management and Token Optimization

Live API charges accumulate quickly if left unchecked. Keep these points in mind.

**Audio data volume**: 16kHz mono PCM generates roughly 960 KB per minute. Long idle sessions with an open connection can still consume tokens.

**Idle disconnect pattern**: Implement a timer that closes the WebSocket after 30 seconds of user inactivity. Re-establish the connection (and fetch a new ephemeral token) when the user resumes typing or speaking.

**Voice Activity Detection (VAD)**: Monitor microphone volume in the browser using the Web Audio API. Filter out frames below a dB threshold before sending to the API to avoid transmitting silence.
