## What Is Grounding with Google Search?

**Grounding with Google Search** is a powerful Gemini API feature that connects your AI's responses to real-time web search results. While standard LLM responses are limited by their training data cutoff, enabling Grounding allows Gemini to automatically perform Google searches and generate answers backed by current, up-to-date web content.

Consider questions like "What's today's stock price?" or "What are the latest Gemini model releases?" With Grounding enabled, Gemini automatically runs relevant web searches and synthesizes accurate answers from trustworthy sources. The API also returns `grounding_metadata` containing the URLs of referenced pages — enabling you to build **transparent, citation-backed AI applications**.


---

## When to Use Grounding

Grounding with Google Search is especially valuable for:

- **News and current events**: Answering questions about recent developments with accurate, current information
- **Real-time data**: Prices, availability, weather, and other information that changes frequently
- **Fact-checking**: Reducing hallucinations by grounding responses in verifiable web sources
- **Competitive research and market analysis**: Gathering the latest information about companies and products
- **Customer support bots**: Pulling current service information, documentation, and FAQs from the web

When handling questions about current events or rapidly evolving topics, Grounding dramatically improves response quality compared to ungrounded generation.

For closed-domain use cases — such as answering questions from your own internal documentation — combining Grounding with a [RAG pipeline](/articles/gemini-api/gemini-flash-rag-pipeline) is often the better approach. Choose the right tool for your specific needs.

## Python Implementation

### Basic Grounding Example

```python
import os
from google import genai
from google.genai import types

# Initialize the client
client = genai.Client(api_key=os.environ["YOUR_GEMINI_API_KEY"])

# Generate a response with Grounding enabled
response = client.models.generate_content(
    model="gemini-2.0-flash",
    contents="What are the latest developments in Gemini AI as of April 2026?",
    config=types.GenerateContentConfig(
        tools=[types.Tool(google_search=types.GoogleSearch())]
    ),
)

# Display the answer
print("=== Answer ===")
print(response.text)

# Display the grounding sources
if response.candidates[0].grounding_metadata:
    metadata = response.candidates[0].grounding_metadata
    print("\n=== Sources ===")
    for chunk in metadata.grounding_chunks:
        if chunk.web:
            print(f"- {chunk.web.title}: {chunk.web.uri}")
```

When you run this code, Gemini automatically executes Google searches and incorporates real-time web data into its response. The `grounding_metadata` provides the titles and URLs of referenced pages, so you can surface source information alongside the answer.

### Inspecting Search Queries

Grounding also lets you inspect the search queries the model generated automatically:

```python
response = client.models.generate_content(
```

## JavaScript/Node.js Implementation

```javascript
import { GoogleGenAI } from "@google/generative-ai";

const genai = new GoogleGenAI({ apiKey: process.env.YOUR_GEMINI_API_KEY });

async function searchWithGrounding(question) {
  const response = await genai.models.generateContent({
    model: "gemini-2.0-flash",
    contents: question,
    config: {
      tools: [{ googleSearch: {} }],
    },
  });

  const candidate = response.candidates[0];
  const answer = candidate.content.parts[0].text;

  // Extract grounding sources
  const sources = [];
  if (candidate.groundingMetadata?.groundingChunks) {
    for (const chunk of candidate.groundingMetadata.groundingChunks) {
      if (chunk.web) {
        sources.push({
          title: chunk.web.title,
          url: chunk.web.uri,
        });
      }
    }
  }

  return { answer, sources };
}

// Usage
const result = await searchWithGrounding(
  "What AI trends should developers focus on in 2026?"
);
console.log("Answer:", result.answer);
console.log("Sources:", result.sources);
```

## Production Integration — FastAPI Example

Here's how to integrate Grounding into a production FastAPI backend:

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from google import genai
from google.genai import types
import os

app = FastAPI()
client = genai.Client(api_key=os.environ["YOUR_GEMINI_API_KEY"])

class SearchRequest(BaseModel):
    question: str
    use_grounding: bool = True

class SearchResponse(BaseModel):
    answer: str
    sources: list[dict]
    search_queries: list[str]

@app.post("/search", response_model=SearchResponse)
async def search_with_ai(request: SearchRequest):
    try:
        config = types.GenerateContentConfig()
        if request.use_grounding:
            config = types.GenerateContentConfig(
                tools=[types.Tool(google_search=types.GoogleSearch())]
            )

        response = client.models.generate_content(
            model="gemini-2.0-flash",
            contents=request.question,
            config=config,
        )

        candidate = response.candidates[0]
        metadata = candidate.grounding_metadata

        sources = []
        search_queries = []

        if metadata:
            if metadata.grounding_chunks:
                for chunk in metadata.grounding_chunks:
                    if chunk.web:
                        sources.append({
                            "title": chunk.web.title,
                            "url": chunk.web.uri,
                        })
            if metadata.web_search_queries:
                search_queries = list(metadata.web_search_queries)

        return SearchResponse(
            answer=response.text,
            sources=sources,
            search_queries=search_queries,
        )

    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))
```

## Production Best Practices

### Cost Management

Grounding with Google Search incurs additional costs beyond standard text generation because each request may trigger multiple search queries. Monitor your usage closely and consider applying Grounding selectively — only for queries that genuinely require real-time information.

### Error Handling with Retry Logic

Build resilience into your implementation with exponential backoff and graceful fallbacks:

```python
import time

def search_with_retry(client, question: str, max_retries: int = 3) -> dict:
    """Grounding search with automatic retry and fallback."""
    for attempt in range(max_retries):
        try:
            response = client.models.generate_content(
                model="gemini-2.0-flash",
                contents=question,
                config=types.GenerateContentConfig(
                    tools=[types.Tool(google_search=types.GoogleSearch())]
                ),
            )
            return {
                "success": True,
                "answer": response.text,
                "metadata": response.candidates[0].grounding_metadata,
            }
        except Exception as e:
            if attempt < max_retries - 1:
                wait_time = 2 ** attempt  # Exponential backoff
                print(f"Retry {attempt + 1}/{max_retries} — retrying in {wait_time}s")
                time.sleep(wait_time)
            else:
                # Fallback: respond without Grounding
                print("Grounding failed. Falling back to standard generation.")
                response = client.models.generate_content(
                    model="gemini-2.0-flash",
                    contents=question,
                )
                return {
                    "success": False,
                    "answer": response.text,
                    "metadata": None,
                }
```

## Building Citation-Aware UI with Grounding Metadata

The `grounding_supports` field in the Grounding response maps specific passages in the generated text to their source documents. You can use this to display inline citations — similar to how Wikipedia or research papers present references:

```python
def format_answer_with_citations(response) -> str:
    """Generate a response text with inline source references."""
    candidate = response.candidates[0]
    metadata = candidate.grounding_metadata

    if not metadata or not metadata.grounding_chunks:
        return response.text

    # Build a source index
    sources = {}
    for i, chunk in enumerate(metadata.grounding_chunks, 1):
        if chunk.web:
            sources[i] = {"title": chunk.web.title, "url": chunk.web.uri}

    answer = response.text

    # Append a references section
    if sources:
        answer += "\n\n**References**\n"
        for idx, source in sources.items():
            answer += f"[{idx}] [{source['title']}]({source['url']})\n"

    return answer
```

This pattern is especially effective in research tools, news summarizers, and any application where user trust depends on verifiable sourcing.

## Frequently Asked Questions

**Q1. Which Gemini models support Grounding with Google Search?**

Grounding is available on Gemini 2.0 Flash and newer, including `gemini-2.0-flash`, `gemini-2.5-pro`, and `gemini-2.5-flash`. It is not supported on older models like `gemini-1.0-pro`.

**Q2. How reliable are the search results?**

Grounding uses Google's search infrastructure, which generally surfaces high-quality, authoritative pages. That said, no automated search is 100% accurate. Always display source URLs to your users so they can verify critical information themselves.

**Q3. Does Grounding increase API costs?**

Yes — enabling Grounding adds search execution costs on top of standard token-based pricing. Check the [Gemini API pricing page](https://ai.google.dev/pricing) for current rates. To control costs, apply Grounding selectively rather than enabling it for every request.

**Q4. Can I combine Grounding with System Instructions?**

Absolutely. Grounding and System Instructions work well together. For example, you can use System Instructions to specify a particular response format or tone, while Grounding supplies the up-to-date factual content.

**Q5. Can I restrict search results to specific domains?**

Domain-level filtering is not currently supported in Grounding. If you need to restrict answers to a specific knowledge base (such as your company's documentation), a vector database RAG approach is the better fit.
