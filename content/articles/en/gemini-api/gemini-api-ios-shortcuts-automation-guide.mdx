## Introduction — Turning Your iPhone into an AI Gateway

What if every time you wanted to summarize an article, translate a sentence, or brainstorm ideas, all it took was a tap or a Siri command on your iPhone? By connecting **iOS Shortcuts** with the **Gemini API**, that's exactly what you can do — no third-party apps required, just your existing iPhone and a free Google API key.

This guide walks you through everything you need to know: from getting your API key to building practical Shortcuts that leverage Gemini's powerful language models for everyday tasks.

## What You Need

Getting started requires only three things:

- **iPhone (or iPad) running iOS 16 or later** — the Shortcuts app comes pre-installed
- **A Google Account** — a free account works perfectly fine
- **A Gemini API key** — issued for free at [Google AI Studio](https://aistudio.google.com/)

### How to Get Your API Key

1. Go to [Google AI Studio](https://aistudio.google.com/) and sign in with your Google account
2. Click **"Get API key"** in the left sidebar
3. Select **"Create API key"**, then choose or create a project
4. Copy the generated key and store it somewhere safe (a password manager works well)

The whole process takes about two minutes. The free tier gives you 15 requests per minute and 1,500 requests per day — more than enough for personal use.

> **Important**: Never share your API key. If you use it inside a Shortcut, make sure you don't share that Shortcut with others.

For a more detailed walkthrough of getting set up with the Gemini API, see our [Gemini API Quickstart Guide](/en/articles/gemini-api/gemini-api-quickstart).

## How It Works: iOS Shortcuts Meets REST API

The Gemini API is a standard REST API, which means iOS Shortcuts can call it directly using the built-in **"Get Contents of URL"** action. No special plugins or workarounds needed.

The endpoint you'll use:

```
https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent?key=YOUR_API_KEY
```

The request body is a JSON object:

```json
{
  "contents": [
    {
      "parts": [
        {
          "text": "Your prompt goes here"
        }
      ]
    }
  ]
}
```

To extract the response text from the JSON returned by the API, you'll navigate this path:

```
candidates[0].content.parts[0].text
```

The Shortcuts "Get Dictionary Value" action makes this straightforward, as you'll see below.

## Building Your First Shortcut — Text Summarizer

Let's build a Shortcut that **summarizes any selected text using Gemini**. You'll be able to trigger it from the share sheet in Safari, Notes, or any other app.

### The Overall Flow

```
① Receive text from the share sheet
② Embed the text into a prompt
③ Send a POST request to the Gemini API
④ Extract the answer text from the JSON response
⑤ Display the result as a notification or copy to clipboard
```

### Step-by-Step Instructions

**Step 1: Create a new Shortcut**

Open the Shortcuts app, tap **"+"** in the top right, and name the Shortcut "Gemini Summarize."

**Step 2: Accept input from the share sheet**

Add the **"Receive"** action and set it to accept **Text** from share sheet apps. This lets you trigger the Shortcut by selecting text in any app and tapping the share button.

**Step 3: Build the prompt**

Add a **"Text"** action and type:

```
Please summarize the following text in 3 sentences or fewer. Be concise and clear.

[Shortcut Input variable]
```

(Tap the variable token area and insert the input from Step 2.)

**Step 4: Call the Gemini API**

Add a **"Get Contents of URL"** action with these settings:

- **URL**: `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent?key=YOUR_API_KEY`
- **Method**: POST
- **Request Body**: JSON
- **Body fields** (as a dictionary):

```json
{
  "contents": [
    {
      "parts": [
        {
          "text": "[Text variable from Step 3]"
        }
      ]
    }
  ]
}
```

**Step 5: Extract the response**

Add three **"Get Dictionary Value"** actions in sequence:

1. Get value for key `candidates` from the API response → grab the first item
2. Get value for key `content` → then `parts` → first item
3. Get value for key `text`

**Step 6: Show the result**

Add a **"Quick Look"** action (or "Show Notification") and pass in the extracted text from Step 5.

### Testing It Out

Open Safari, highlight any paragraph of text, tap the share icon, scroll down to find "Gemini Summarize," and tap it. Within a few seconds, a concise summary should appear. If it does — you've successfully connected iOS Shortcuts to the Gemini API!

## Practical Shortcut Recipes

Once you understand the basic pattern, you can create powerful AI shortcuts just by changing the prompt.

### Recipe 1: English ↔ Japanese Translation Shortcut

Replace the prompt text with this to get instant translation:

```
Translate the following text into natural English. Preserve the tone and meaning of the original.

[Input text]
```

For the reverse direction (English to Japanese):

```
Translate the following English text into natural, fluent Japanese.

[Input text]
```

### Recipe 2: Idea Generator from the Home Screen

Add this Shortcut to your Home Screen for on-demand brainstorming. Start with a **"Ask for Input"** action (so you can type a topic), then pass it to this prompt:

```
Give me 5 unique and creative ideas related to the following topic. Keep each idea to 1–2 sentences.

Topic: [Input text]
```

### Recipe 3: Ask Questions About Your Notes

Combine **"Find Notes"** (or a "Choose from List" with your Apple Notes) with a **"Ask for Input"** action for a question. Pass both to Gemini and you have a personal Q&A assistant over your own notes.

## Advanced Tips — Choosing Models and Tuning Parameters

Swapping out the model in the URL is all it takes to use a more powerful model:

```
# Gemini 2.5 Pro (best reasoning, most capable)
https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-pro:generateContent?key=YOUR_API_KEY

# Gemini 2.5 Flash (fast and generous free tier)
https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=YOUR_API_KEY
```

You can also add a `generationConfig` object to the request body to fine-tune responses:

```json
{
  "contents": [
    {
      "parts": [{ "text": "Your prompt" }]
    }
  ],
  "generationConfig": {
    "temperature": 0.7,
    "maxOutputTokens": 512
  }
}
```

- **temperature**: Lower values (closer to 0) give more predictable, focused answers; higher values (closer to 1) give more creative, varied ones
- **maxOutputTokens**: Caps the length of the response (roughly 1–2 characters per token)

## Frequently Asked Questions

**Q: I accidentally shared my API key. What should I do?**

Go to [Google AI Studio](https://aistudio.google.com/) immediately, delete the compromised key, and generate a new one. API keys can be misused if they fall into the wrong hands, so don't hesitate — replace it right away.

**Q: The "Get Contents of URL" action returns an error. How do I fix it?**

The three most common causes are:

- **Wrong API key** — double-check for copy-paste errors, especially at the beginning or end of the key
- **Malformed JSON** — review the dictionary structure in your "Get Contents of URL" action; every key must be correctly spelled
- **No internet connection** — make sure Wi-Fi or cellular data is active

**Q: Should I use Gemini 2.0 Flash or 2.5 Pro?**

For everyday tasks like summarization, translation, and quick Q&A, **Gemini 2.0 Flash** is fast, accurate, and has a generous free tier. Use **Gemini 2.5 Pro** when you need deeper reasoning, longer documents, or more nuanced analysis. Note that Pro consumes your free quota faster.

**Q: Can I trigger this Shortcut with Siri?**

Absolutely. Give your Shortcut a memorable name like "Ask Gemini," then add it to Siri via Settings. Say "Hey Siri, ask Gemini" to launch it hands-free. This works especially well combined with a "Speak Text" action at the end for a fully voice-driven experience.
