Manually pulling spec information from 30 product demo videos is the kind of work that disappears the moment you hand it off to Gemini 2.5 Pro. Pass a URL, get back a structured JSON. For a five-minute video, the whole thing runs in under two minutes.

Gemini 2.5 Pro can process up to one hour of video in a single API call. Its multimodal design means it processes text on screen, the speaker's audio, and visual actions simultaneously — which is what makes it useful for anything beyond just transcription.

## Analyzing YouTube Videos Directly

The simplest approach: pass a YouTube URL directly.

```python
import google.generativeai as genai
import json

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel("gemini-2.5-pro-latest")

response = model.generate_content([
    {
        "file_data": {
            "mime_type": "video/mp4",
            "file_uri": "https://www.youtube.com/watch?v=VIDEO_ID"
        }
    },
    "Output a JSON object with these fields:\n"
    "- title: video title\n"
    "- summary: summary in under 200 words\n"
    "- key_points: list of main takeaways (max 5)\n"
    "- mentioned_tools: list of tools or technologies referenced\n"
    "Output JSON only, no markdown code blocks."
])

try:
    result = json.loads(response.text.strip())
    print(json.dumps(result, indent=2))
except json.JSONDecodeError:
    print(response.text)
```

Gemini fetches the video from YouTube directly — no downloading required. This doesn't work for private or age-restricted videos.

## Processing Local Video Files

For files on disk, use the File API:

```python
import google.generativeai as genai
import time

genai.configure(api_key="YOUR_GEMINI_API_KEY")

def analyze_local_video(file_path: str, prompt: str) -> str:
    """Upload a local video file and analyze it."""
    
    print(f"Uploading: {file_path}")
    video_file = genai.upload_file(
        path=file_path,
        mime_type="video/mp4"
    )
    
    # Must wait for processing to complete before generating
    max_wait = 120
    elapsed = 0
    while video_file.state.name == "PROCESSING":
        if elapsed >= max_wait:
            raise TimeoutError("Video processing timed out")
        print(f"  Processing... ({elapsed}s)")
        time.sleep(10)
        elapsed += 10
        video_file = genai.get_file(video_file.name)
    
    if video_file.state.name == "FAILED":
        raise RuntimeError(f"Video processing failed: {video_file.state}")
    
    model = genai.GenerativeModel("gemini-2.5-pro-latest")
    response = model.generate_content([video_file, prompt])
    
    # Clean up to avoid storage accumulation
    genai.delete_file(video_file.name)
    
    return response.text

result = analyze_local_video(
    "product_demo.mp4",
    "List every feature demonstrated in this product demo video, "
    "in the order they appear. For each feature, include: "
    "how it works, who it's designed for, and what was emphasized."
)
print(result)
```

After upload, the file goes into a `PROCESSING` state. You can't generate content until it transitions to `ACTIVE`. For short videos this takes 10–30 seconds; for longer ones, a few minutes.

## Batch Processing Multiple Videos

When you need to process a directory of videos with the same analysis, separating upload and analysis makes retries easier:

```python
import google.generativeai as genai
import time, json
from pathlib import Path
from typing import Optional

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel("gemini-2.5-pro-latest")

ANALYSIS_PROMPT = """
Analyze this video and return a JSON object with these fields.
Output JSON only — no markdown, no explanation.

{
  "duration_estimated": "estimated length (e.g., about 5 minutes)",
  "content_type": "one of: tutorial / presentation / demo / interview",
  "main_topic": "main topic in under 50 words",
  "key_insights": ["insight 1", "insight 2", "insight 3"],
  "action_items": ["what someone could do next based on this video"],
  "quality_rating": number from 1 to 5
}
"""

def upload_video(file_path: str) -> Optional[genai.types.File]:
    """Upload and wait for processing. Returns None on failure."""
    try:
        video_file = genai.upload_file(path=file_path, mime_type="video/mp4")
        for _ in range(24):  # up to 4 minutes
            if video_file.state.name \!= "PROCESSING":
                break
            time.sleep(10)
            video_file = genai.get_file(video_file.name)
        return video_file if video_file.state.name == "ACTIVE" else None
    except Exception as e:
        print(f"Upload error ({file_path}): {e}")
        return None

def batch_analyze(video_dir: str) -> list[dict]:
    results = []
    video_files = list(Path(video_dir).glob("*.mp4"))
    
    for i, path in enumerate(video_files, 1):
        print(f"[{i}/{len(video_files)}] {path.name}")
        
        video_file = upload_video(str(path))
        if not video_file:
            results.append({"file": path.name, "error": "upload_failed"})
            continue
        
        try:
            response = model.generate_content([video_file, ANALYSIS_PROMPT])
            result = json.loads(response.text.strip())
            result["file"] = path.name
            results.append(result)
        except Exception as e:
            results.append({"file": path.name, "error": str(e)})
        finally:
            try:
                genai.delete_file(video_file.name)
            except Exception:
                pass
        
        time.sleep(2)  # Rate limit buffer between videos
    
    return results

results = batch_analyze("./videos")
with open("analysis_results.json", "w") as f:
    json.dump(results, f, indent=2)
print(f"Done: processed {len(results)} videos")
```

## Finding When a Topic Appears

For "where in this video is X explained," timestamp extraction works well:

```python
def find_topic_timestamps(video_file, topic: str) -> str:
    """Find where a specific topic appears in the video."""
    
    prompt = f"""
    Find every part of this video where "{topic}" is discussed or demonstrated.
    For each occurrence, output:
    
    [START MM:SS] [END MM:SS] [One-sentence description of what's covered]
    
    List all occurrences. If the topic doesn't appear, output "Not found."
    """
    
    response = model.generate_content([video_file, prompt])
    return response.text

# Example usage
timestamps = find_topic_timestamps(video_file, "error handling")
print(timestamps)
# Example output:
# [12:30] [14:45] Demonstrates try/except patterns for API error handling
# [28:10] [29:20] Covers retry logic for rate limit errors
```

## Cost and Performance Estimates

Video processing is token-intensive. Gemini 2.5 Pro charges approximately 263 tokens per second of video.

- 5-minute video (300s): ~78,900 tokens ≈ $0.60 input cost
- 30-minute video (1,800s): ~473,400 tokens ≈ $3.60 input cost

Processing time runs at roughly 20–50% of video duration (a 5-minute video takes 1–2.5 minutes), varying with API load.

To cut costs on large batches: run a first pass with Gemini 2.5 Flash to get summaries and identify the most important videos, then use Pro only for those. Flash costs significantly less per token and often produces adequate results for initial filtering.

The range of applications here is wider than it first appears: turning tutorial libraries into searchable documentation, extracting action items from recorded meetings, analyzing competitor product demos, auditing onboarding videos for accuracy. If you have video content sitting around that's too slow to review manually, this API is the right tool for it.
