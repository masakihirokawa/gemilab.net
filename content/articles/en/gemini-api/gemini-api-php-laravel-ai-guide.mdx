PHP powers a significant portion of the web, from WordPress sites to enterprise systems built on Laravel and Symfony. By integrating the Gemini API into your PHP applications, you can add AI-powered chat, content summarization, and text generation without switching stacks or rewriting your entire backend.

In this guide, you'll build a working AI chat feature inside a Laravel application step by step — complete with multi-turn conversation support, error handling, and rate limiting ready for production.

## Prerequisites

Before diving in, make sure you have:

- PHP 8.2 or higher
- Composer (PHP package manager)
- Laravel 11.x
- A Gemini API key (available for free at [Google AI Studio](https://aistudio.google.com/))

## Creating the GeminiService Class

In Laravel, encapsulating external API logic inside a service class keeps your controllers clean and your code testable. Create `app/Services/GeminiService.php`:

```php
<?php
// app/Services/GeminiService.php

namespace App\Services;

use Illuminate\Support\Facades\Http;
use Illuminate\Support\Facades\Log;

class GeminiService
{
    private string $apiKey;
    private string $model;
    private string $baseUrl = 'https://generativelanguage.googleapis.com/v1beta';

    public function __construct()
    {
        $this->apiKey = config('services.gemini.api_key');
        $this->model  = config('services.gemini.model', 'gemini-2.5-flash');
    }

    /**
     * Generate text from a single prompt (non-streaming)
     */
    public function generateText(string $prompt, array $options = []): string
    {
        $url = "{$this->baseUrl}/models/{$this->model}:generateContent?key={$this->apiKey}";

        $body = [
            'contents' => [
                ['parts' => [['text' => $prompt]]],
            ],
        ];

        // Optional system instruction
        if (!empty($options['system_instruction'])) {
            $body['systemInstruction'] = [
                'parts' => [['text' => $options['system_instruction']]],
            ];
        }

        // Optional generation config
        if (!empty($options['temperature']) || !empty($options['max_tokens'])) {
            $body['generationConfig'] = [
                'temperature'     => $options['temperature'] ?? 0.7,
                'maxOutputTokens' => $options['max_tokens'] ?? 2048,
            ];
        }

        try {
            $response = Http::timeout(30)->post($url, $body);

            if ($response->failed()) {
                Log::error('Gemini API error', [
                    'status' => $response->status(),
                    'body'   => $response->body(),
                ]);
                throw new \RuntimeException('Gemini API request failed: ' . $response->status());
            }

            $data = $response->json();
            return $data['candidates'][0]['content']['parts'][0]['text'] ?? '';

        } catch (\Exception $e) {
            Log::error('GeminiService error', ['message' => $e->getMessage()]);
            throw $e;
        }
    }

    /**
     * Multi-turn chat with conversation history
     */
    public function chat(array $history, string $userMessage, string $systemInstruction = ''): string
    {
        $url = "{$this->baseUrl}/models/{$this->model}:generateContent?key={$this->apiKey}";

        // Build the conversation history
        $contents = [];
        foreach ($history as $turn) {
            $contents[] = [
                'role'  => $turn['role'], // 'user' or 'model'
                'parts' => [['text' => $turn['content']]],
            ];
        }

        // Append the new user message
        $contents[] = [
            'role'  => 'user',
            'parts' => [['text' => $userMessage]],
        ];

        $body = ['contents' => $contents];

        if ($systemInstruction) {
            $body['systemInstruction'] = [
                'parts' => [['text' => $systemInstruction]],
            ];
        }

        $response = Http::timeout(30)->post($url, $body);

        if ($response->failed()) {
            throw new \RuntimeException('Chat API error: ' . $response->status());
        }

        $data = $response->json();
        return $data['candidates'][0]['content']['parts'][0]['text'] ?? '';
    }
}
```

Then register Gemini config in `config/services.php`:

```php

    'api_key' => env('GEMINI_API_KEY'),
    'model'   => env('GEMINI_MODEL', 'gemini-2.5-flash'),
],
```

## Registering in the Service Container

Bind `GeminiService` as a singleton in `app/Providers/AppServiceProvider.php` so the same instance is reused per request:

```php
<?php
// app/Providers/AppServiceProvider.php

namespace App\Providers;

use App\Services\GeminiService;
use Illuminate\Support\ServiceProvider;

class AppServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        $this->app->singleton(GeminiService::class, function ($app) {
            return new GeminiService();
        });
    }

    public function boot(): void {}
}
```

## Building the Chat Controller

Create the controller that handles requests:

```bash
php artisan make:controller ChatController
```

```php
<?php
// app/Http/Controllers/ChatController.php

namespace App\Http\Controllers;

use App\Services\GeminiService;
use Illuminate\Http\Request;
use Illuminate\Http\JsonResponse;

class ChatController extends Controller
{
    public function __construct(private readonly GeminiService $geminiService) {}

    /**
     * Show the chat UI
     */
    public function index()
    {
        return view('chat.index');
    }

    /**
     * Process a chat message and return the AI response
     */
    public function send(Request $request): JsonResponse
    {
        $request->validate([
            'message' => 'required|string|max:4000',
            'history' => 'array',
        ]);

        $userMessage = $request->input('message');
        $history     = $request->input('history', []);

        $systemInstruction = 'You are a knowledgeable and helpful AI assistant. '
            . 'Answer questions clearly and concisely. '
            . 'When answering coding questions, include working code examples.';

        try {
            $reply = $this->geminiService->chat($history, $userMessage, $systemInstruction);

            return response()->json([
                'success' => true,
                'reply'   => $reply,
                'role'    => 'model',
            ]);

        } catch (\RuntimeException $e) {
            return response()->json([
                'success' => false,
                'error'   => 'Failed to reach the AI. Please try again shortly.',
            ], 503);
        }
    }

    /**
     * Summarize a block of text
     */
    public function summarize(Request $request): JsonResponse
    {
        $request->validate([
            'text'   => 'required|string|max:10000',
            'length' => 'in:short,medium,long',
        ]);

        $text   = $request->input('text');
        $length = $request->input('length', 'medium');

        $lengthInstruction = match($length) {
            'short'  => 'in 3 sentences or fewer',
            'long'   => 'in detail (around 300 words)',
            default  => 'in 5 to 8 sentences',
        };

        $prompt = "Summarize the following text {$lengthInstruction}:\n\n---\n{$text}\n---";

        try {
            $summary = $this->geminiService->generateText($prompt, [
                'temperature' => 0.3,
                'max_tokens'  => 1024,
            ]);

            return response()->json(['success' => true, 'summary' => $summary]);

        } catch (\Exception $e) {
            return response()->json([
                'success' => false,
                'error'   => 'Summarization failed. Please try again.',
            ], 500);
        }
    }
}
```

## Defining Routes

Add the chat routes to `routes/web.php`:

```php
<?php
// routes/web.php

use App\Http\Controllers\ChatController;
use Illuminate\Support\Facades\Route;

Route::prefix('chat')->group(function () {
    Route::get('/',           [ChatController::class, 'index'])->name('chat.index');
    Route::post('/send',      [ChatController::class, 'send'])->name('chat.send');
    Route::post('/summarize', [ChatController::class, 'summarize'])->name('chat.summarize');
});
```

## Rate Limiting and Retry Logic

Protecting your Gemini API calls with rate limiting prevents abuse and controls costs. Laravel makes this straightforward:

```php
// In AppServiceProvider or RouteServiceProvider
use Illuminate\Cache\RateLimiting\Limit;
use Illuminate\Support\Facades\RateLimiter;

RateLimiter::for('gemini-api', function (Request $request) {
    return Limit::perMinute(10)->by($request->user()?->id ?? $request->ip());
});

// Apply the limiter to your route
Route::post('/send', [ChatController::class, 'send'])
    ->name('chat.send')
    ->middleware('throttle:gemini-api');
```

For handling 429 (rate limit) responses from the Gemini API itself, add exponential backoff retry logic:

```php
// Add to GeminiService.php
private function requestWithRetry(string $url, array $body, int $maxRetries = 3): array
{
    for ($attempt = 0; $attempt < $maxRetries; $attempt++) {
        $response = Http::timeout(30)->post($url, $body);

        if ($response->status() === 429) {
            sleep(pow(2, $attempt)); // Wait 1s, 2s, 4s
            continue;
        }

        if ($response->failed()) {
            throw new \RuntimeException("API request failed: {$response->status()}");
        }

        return $response->json();
    }

    throw new \RuntimeException('Max retries exceeded. Please try again later.');
}
```

## Writing Tests

Use Laravel's built-in testing tools to verify your service behaves correctly without hitting the real API:

```php
<?php
// tests/Unit/GeminiServiceTest.php

use App\Services\GeminiService;
use Illuminate\Support\Facades\Http;

test('generateText returns text on success', function () {
    Http::fake([
        'generativelanguage.googleapis.com/*' => Http::response([
            'candidates' => [[
                'content' => ['parts' => [['text' => 'Test response text']]],
            ]],
        ], 200),
    ]);

    $service = new GeminiService();
    $result  = $service->generateText('Test question');

    expect($result)->toBe('Test response text');
});

test('generateText throws on API error', function () {
    Http::fake([
        'generativelanguage.googleapis.com/*' => Http::response([], 500),
    ]);

    $service = new GeminiService();

    expect(fn() => $service->generateText('Test'))
        ->toThrow(\RuntimeException::class);
});
```

Run your tests with:

php artisan test

## FAQ

### Q1. Is there an official PHP SDK for Gemini API?

As of April 2026, Google has not released an official PHP SDK for Gemini API. However, the API is REST-based, so Laravel's HTTP client (which wraps Guzzle) works perfectly. Community packages exist, but using the HTTP client directly — as shown in this guide — keeps your dependency footprint small and gives you full control over request handling.

### Q2. Can I implement streaming responses in PHP?

Yes. Laravel's `StreamedResponse` lets you return `text/event-stream` content. You'll need to use `ob_flush()` and `flush()` calls to push chunks to the client as they arrive, since PHP buffers output by default. On the frontend, you can consume the stream using `fetch` with `ReadableStream` or the `EventSource` API.

### Q3. Where should I store conversation history?

For short-lived sessions, Laravel's session storage (file or cookie backend) works well. For persistence across devices or long-term storage, save conversations to a database table (e.g., `conversations` and `messages`). Redis is a great middle ground — fast for active sessions and easy to set a TTL for automatic expiry.

In this guide you built a fully functional AI chat application using PHP, Laravel, and the Gemini API. The key takeaways are:

Wrapping API logic in a dedicated `GeminiService` class makes your code testable and keeps controllers focused on handling HTTP concerns. Adding rate limiting and retry logic from the start puts your app in a much better position for production traffic.

PHP's ecosystem is mature and battle-tested, and Gemini API's REST interface means you don't need a dedicated SDK to build real AI features. If you're running an existing Laravel app, this pattern lets you add AI capabilities with minimal disruption to your current architecture.
