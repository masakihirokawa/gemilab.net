## Setup and context: Why Automate Your AI Newsletter?

Imagine waking up every morning to a personalized digest of the latest news on topics you care about — without lifting a finger. For developers and solopreneurs, manually curating content, writing summaries, and sending emails is time-consuming. There's a smarter way.

By combining **Gemini API's Grounding with Google Search**, Python, and Gmail API, you can build a fully automated newsletter system that:

- Pulls the latest news on any topic from the web in real time
- Summarizes and formats it into a readable digest using Gemini's language capabilities
- Sends the newsletter to subscribers automatically on a schedule

In this guide, you'll build this system step by step, with complete, working code examples.

**Who this is for**: Python developers who want to build practical Gemini API automations and anyone looking to streamline information delivery workflows.

---

## System Architecture Overview

Here's how the pipeline works end to end:

1. **Cloud Scheduler** triggers your Cloud Run endpoint every morning at 7:00 AM
2. A **Python script** sends Grounding-enabled requests to the Gemini API
3. **Gemini API** searches Google in real time and returns summarized, up-to-date news
4. The content is formatted as an HTML email
5. **Gmail API** sends the newsletter to your subscriber list

Key components:

- `google-generativeai` — Gemini Python SDK
- `google-auth-oauthlib` and `googleapiclient` — Gmail API authentication and client
- Cloud Run or any Python-capable server environment
- Cloud Scheduler for time-based triggers

## Step 2: Collect News with Grounding

The heart of this system is Gemini's **Grounding with Google Search** — it lets the model search the web in real time and incorporate fresh results into its response. This is what keeps your newsletter current.

```python
import os
import google.generativeai as genai

# Initialize Gemini API
genai.configure(api_key=os.environ["GEMINI_API_KEY"])

def fetch_news_summary(topic: str) -> str:
    """
    Fetch and summarize the latest news on a given topic using Grounding.
    topic: e.g., "Google Gemini AI news April 2026"
    Returns: summarized news as a string
    """
    model = genai.GenerativeModel(
        model_name="gemini-2.5-flash",
        tools="google_search_retrieval",  # Enable Grounding
    )

    prompt = f"""
    Search for the latest news on the following topic and summarize 3 to 5 key stories
    in a clear, newsletter-friendly style.

    Topic: {topic}

    For each story, provide:
    - Title: (story headline)
    - Summary: (80 to 120 words)
    - Importance: (High / Medium / Low)

    End with a short "Key Takeaway" paragraph (2 to 3 sentences) summarizing overall trends.
    """

    response = model.generate_content(prompt)
    return response.text

# Collect news across multiple topics
topics = [
    "Google Gemini AI updates April 2026",
    "AI developer tools and automation 2026",
    "Generative AI business applications 2026",
]

news_sections = []
for topic in topics:
    summary = fetch_news_summary(topic)
    news_sections.append({"topic": topic, "content": summary})
    print(f"✅ Collected: '{topic}'")
```

Adding `tools="google_search_retrieval"` is all it takes to enable Grounding. The model will perform live Google searches and incorporate current results — going beyond its training data cutoff.

## Step 3: Format into a Newsletter with Gemini

Once you have the raw summaries, use a second Gemini call (without Grounding) to format everything into a polished HTML email.

```python
def format_newsletter_html(sections: list, date_str: str) -> str:
    """
    Transform collected news sections into a formatted HTML newsletter.
    sections: list of {"topic": str, "content": str}
    date_str: e.g., "April 3, 2026"
    Returns: complete HTML email string
    """
    model = genai.GenerativeModel("gemini-2.5-flash")

    combined = "\n\n".join(
        [f"[{s['topic']}]\n{s['content']}" for s in sections]
    )

    prompt = f"""
    Convert the following news summaries into a clean, well-structured HTML email newsletter.

    Requirements:
    - Output a complete <html>...</html> document
    - Use <h2> tags to separate sections
    - Bold important keywords with <strong>
    - Keep a consistent, friendly tone
    - Add a short closing note at the end

    Newsletter date: {date_str}

    --- Content ---
    {combined}
    """

    response = model.generate_content(prompt)
    return response.text

from datetime import datetime

date_str = datetime.now().strftime("%B %-d, %Y")
html_body = format_newsletter_html(news_sections, date_str)
print("✅ HTML newsletter generated")
```

This two-step approach — Grounding for data collection, plain generation for formatting — is cost-effective. ## Step 4: Send via Gmail API

With the HTML newsletter ready, use Gmail API to deliver it to your subscriber list.

```python
import base64
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from google.auth.transport.requests import Request
from google.oauth2.credentials import Credentials
from google_auth_oauthlib.flow import InstalledAppFlow
from googleapiclient.discovery import build

SCOPES = ["https://www.googleapis.com/auth/gmail.send"]

def get_gmail_service():
    """Authenticate and return a Gmail API service object."""
    creds = None
    if os.path.exists("token.json"):
        creds = Credentials.from_authorized_user_file("token.json", SCOPES)
    if not creds or not creds.valid:
        if creds and creds.expired and creds.refresh_token:
            creds.refresh(Request())
        else:
            flow = InstalledAppFlow.from_client_secrets_file(
                "credentials.json", SCOPES
            )
            creds = flow.run_local_server(port=0)
        with open("token.json", "w") as token:
            token.write(creds.to_json())
    return build("gmail", "v1", credentials=creds)

def send_newsletter(service, to: str, subject: str, html_body: str) -> dict:
    """Send an HTML newsletter email via Gmail API."""
    message = MIMEMultipart("alternative")
    message["Subject"] = subject
    message["To"] = to

    html_part = MIMEText(html_body, "html", "utf-8")
    message.attach(html_part)

    raw = base64.urlsafe_b64encode(message.as_bytes()).decode()
    result = service.users().messages().send(
        userId="me",
        body={"raw": raw}
    ).execute()
    return result

# Send to subscribers
service = get_gmail_service()
subscribers = ["subscriber1@example.com", "subscriber2@example.com"]
subject = f"AI Daily Digest — {date_str}"

for email in subscribers:
    result = send_newsletter(service, email, subject, html_body)
    print(f"✅ Sent to {email} (Message ID: {result['id']})")
```

**Important**: The first run requires a browser-based OAuth flow. For server environments like Cloud Run, store your `token.json` securely using Google Secret Manager. To learn best practices for managing secrets in production, see the [Gemini API Production Security Guide](/en/articles/gemini-api/gemini-api-production-security-guide).

## Step 5: Schedule with Cloud Scheduler

Make the system fully autonomous with Cloud Scheduler.

First, create a Cloud Run entry point:

```python
# main.py — Cloud Run HTTP trigger
import functions_framework
from newsletter import run_newsletter_pipeline

@functions_framework.http
def trigger_newsletter(request):
    """Handle Cloud Scheduler trigger and run the newsletter pipeline."""
    try:
        run_newsletter_pipeline()
        return {"status": "success"}, 200
    except Exception as e:
        print(f"Error: {e}")
        return {"status": "error", "message": str(e)}, 500
```

Then create the Cloud Scheduler job:

```bash
# Create a daily job at 7:00 AM JST
gcloud scheduler jobs create http gemini-newsletter-job \
  --location=asia-northeast1 \
  --schedule="0 7 * * *" \
  --time-zone="Asia/Tokyo" \
  --uri="https://YOUR_CLOUD_RUN_URL/trigger" \
  --http-method=GET \
  --attempt-deadline=600s

# Verify the job
gcloud scheduler jobs list --location=asia-northeast1
```

Your newsletter will now be generated and delivered automatically every morning at 7:00 AM without any manual intervention.
