While ChatGPT's voice mode dominates headlines, if you want to build your own voice conversation app, the Gemini Live API is the most flexible choice available. It streams audio in real-time over WebSocket and gives you fine-grained control—including interrupting Gemini's response when the user starts speaking again.

But Live API is more complex than typical REST endpoints. WebSocket management, audio encoding, streaming, session handling—they all interact. The official docs explain features well but gloss over "how it all fits together" and "how to handle errors in production."

This guide walks you through building a voice app with Gemini Live API, covering architecture, implementation patterns, and production considerations. All code examples run on Node.js.

## Why WebSocket, Not REST? Understanding Live API Architecture

Knowing why Gemini Live API chose WebSocket clarifies the design decisions.

REST APIs work as request-response pairs: send complete voice input, wait for AI response. Bad fit for dialogue.

Live API uses bidirectional WebSocket instead, which enables:

1. **Stream input while speaking**: Voice chunks flow as captured, no waiting
2. **Response starts immediately**: AI begins generating before input ends (lower latency)
3. **Interrupt handling**: User interrupts → AI response cancels → new generation starts
4. **Session persistence**: Multiple turns within one connection, maintaining context

REST cannot offer this. WebSocket was the right call.

### Session Lifecycle

Live API sessions follow this flow:

[1] WebSocket connects → [2] Session setup → [3] Audio input starts → [4] Responses arrive → [5] Playback → [6] Interrupt → [7] Disconnect

Stages [3]–[5] happen in parallel—input flows while receiving and playing output. That's the latency magic.

## Core Implementation: WebSocket Connection and Audio Streaming

### Step 1: Establish the WebSocket Connection

```typescript
import WebSocket from 'ws';
import dotenv from 'dotenv';

dotenv.config();

const API_KEY = process.env.GOOGLE_API_KEY\!;
const LIVE_API_URL = process.env.GOOGLE_GEMINI_LIVE_API_URL\!;

class GeminiLiveSession {
  private ws: WebSocket | null = null;
  private isConnected: boolean = false;

  async connect(): Promise<void> {
    const url = `${LIVE_API_URL}?key=${API_KEY}`;
    
    this.ws = new WebSocket(url);

    this.ws.on('open', () => {
      console.log('✓ WebSocket connected');
      this.isConnected = true;
    });

    this.ws.on('message', (data: Buffer) => {
      this.handleMessage(data);
    });

    this.ws.on('error', (error) => {
      console.error('✗ WebSocket error:', error);
    });

    this.ws.on('close', () => {
      this.isConnected = false;
    });

    return new Promise((resolve, reject) => {
      const timeout = setTimeout(() => {
        reject(new Error('Connection timeout'));
      }, 5000);

      const checkConnection = () => {
        if (this.isConnected) {
          clearTimeout(timeout);
          resolve();
        } else {
          setTimeout(checkConnection, 100);
        }
      };
      checkConnection();
    });
  }

  private handleMessage(data: Buffer): void {
    try {
      const message = JSON.parse(data.toString());
      console.log('Message:', message.type || 'unknown');
    } catch (e) {
      console.error('Parse error:', e);
    }
  }

  disconnect(): void {
    if (this.ws) this.ws.close();
  }
}
```

### Step 2: Initialize the Session

After connecting, configure Gemini's behavior:

```typescript
async initializeSession(systemPrompt: string): Promise<void> {
  if (\!this.ws || \!this.isConnected) {
    throw new Error('WebSocket not connected');
  }

  const setupMessage = {
    setup: {
      model: 'models/gemini-2.0-flash-exp',
      generationConfig: {
        temperature: 0.7,
        maxOutputTokens: 1024
      },
      systemInstruction: {
        parts: [{ text: systemPrompt }]
      }
    }
  };

  this.ws.send(JSON.stringify(setupMessage));
}
```

### Step 3: Capture Microphone Input and Stream to API

Grab mic input chunks and send them:

```typescript
import * as portaudio from 'node-portaudio';

async startAudioInput(durationMs: number = 10000): Promise<void> {
  const SAMPLE_RATE = 16000;
  const stream = portaudio.AudioIO({
    inChannels: 1,
    outChannels: 0,
    sampleRate: SAMPLE_RATE,
    frameSize: 1024
  });

  stream.on('data', (audioBuffer: Buffer) => {
    this.sendAudioChunk(audioBuffer);
  });

  stream.start();
  setTimeout(() => stream.quit(), durationMs);
}

private sendAudioChunk(audioBuffer: Buffer): void {
  if (\!this.ws || \!this.isConnected) return;

  const audioMessage = {
    realtime_input: {
      media_chunks: [{
        data: audioBuffer.toString('base64'),
        mime_type: 'audio/pcm;rate=16000'
      }]
    }
  };

  this.ws.send(JSON.stringify(audioMessage));
}
```

**Design notes**: 16kHz sample rate is Gemini's standard. 1024-byte chunks = ~64ms latency.

## Receiving Streaming Responses and Playing Audio

### Step 4: Handle Streaming Responses

Gemini sends responses in multiple messages. Process each immediately:

```typescript
private audioPlaybackBuffer: Buffer[] = [];
private isPlaying: boolean = false;

private handleMessage(data: Buffer): void {
  const message = JSON.parse(data.toString());
  
  if (message.serverContent?.modelTurn?.parts) {
    for (const part of message.serverContent.modelTurn.parts) {
      if (part.inlineData?.mimeType.startsWith('audio/')) {
        const chunk = Buffer.from(part.inlineData.data, 'base64');
        this.queueAudioForPlayback(chunk);
      }
    }
  }
}

private queueAudioForPlayback(chunk: Buffer): void {
  this.audioPlaybackBuffer.push(chunk);
  if (\!this.isPlaying) this.playAudio();
}

private async playAudio(): Promise<void> {
  if (this.isPlaying || this.audioPlaybackBuffer.length === 0) return;

  this.isPlaying = true;
  const stream = portaudio.AudioIO({
    inChannels: 0,
    outChannels: 1,
    sampleRate: 24000,
    frameSize: 1024
  });

  stream.start();
  while (this.audioPlaybackBuffer.length > 0) {
    stream.write(this.audioPlaybackBuffer.shift()\!);
    await new Promise(r => setTimeout(r, 50));
  }
  stream.quit();
  this.isPlaying = false;
}
```

async handleUserInterrupt(): Promise<void> {

## Error Handling and Recovery

### Auto-Reconnect on Disconnection

```typescript
private maxRetries = 3;
private retryCount = 0;

async reconnect(): Promise<void> {
  if (this.retryCount >= this.maxRetries) {
    console.error('Max retries reached');
    return;
  }

  const delay = 1000 * Math.pow(2, this.retryCount);
  await new Promise(r => setTimeout(r, delay));

  try {
    await this.connect();
    this.retryCount = 0;
  } catch (error) {
    this.retryCount++;
    await this.reconnect();
  }
}
```

### Timeout Protection

```typescript
private messageTimeout = 30000;
private lastMessageTime = Date.now();

private startTimeoutCheck(): void {
  setInterval(() => {
    const elapsed = Date.now() - this.lastMessageTime;
    if (elapsed > this.messageTimeout && this.isConnected) {
      console.warn('No response, reconnecting...');
      this.reconnect();
    }
  }, 5000);
}
```

## Production Deployment Considerations

### Security Measures

- Hide API key in environment variables
- 5-minute idle timeout for sessions
- Rate limiting (e.g., 100 requests/minute)

## Complete Working Example

```typescript
async function main() {
  const session = new GeminiLiveSession();

  try {
    await session.connect();
    await session.initializeSession(
      'You are a helpful voice assistant. Keep responses concise.'
    );
    
    await session.startAudioInput(10000);
    await new Promise(r => setTimeout(r, 15000));
  } catch (error) {
    console.error('Error:', error);
  } finally {
    session.disconnect();
  }
}

main();
```

## Key Takeaways

1. **WebSocket stability**: Keepalive and exponential backoff retry logic are non-negotiable
2. **Audio format**: 16kHz PCM is fixed; other formats aren't supported
3. **Buffer management**: Too large = latency, too small = dropouts
4. **Session lifetime**: ~5 minutes is practical; longer sessions timeout
5. **Error recovery**: Temporary connection hiccups are common; retry with backoff is essential

With Live API, you get low-latency, natural voice conversations. Combine this guide with official documentation, and you can build production voice apps today.
