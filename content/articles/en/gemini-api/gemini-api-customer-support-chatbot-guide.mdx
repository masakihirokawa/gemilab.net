## Designing the System Prompt

The quality of your customer support chatbot depends heavily on how well you design the system prompt. An effective prompt should define three core elements: the bot's role, response guidelines, and escalation conditions.

```python
import google.generativeai as genai
import os

genai.configure(api_key=os.environ["GEMINI_API_KEY"])

# Customer support system prompt
SYSTEM_PROMPT = """You are a friendly and professional customer support agent for "TechShop."

[Role & Responsibilities]
- Answer product-related questions accurately and courteously
- Explain troubleshooting steps in a clear, easy-to-follow way
- Suggest escalation to a human agent when the issue is beyond your scope

[Response Guidelines]
- Always maintain a professional, polite tone
- Present step-by-step instructions using numbered lists
- Never guess — if you're unsure, say so honestly
- Break down complex information into digestible steps

[When to Escalate]
- Complex refund or return cases
- Technical issues requiring deeper investigation
- When the customer explicitly requests a human agent
- Any indication of complaints or legal concerns

When escalation is needed, append "[ESCALATE]" at the end of your response."""
```

## Implementing the Core Chatbot

The following code implements a multi-turn customer support chatbot. Using `start_chat()` lets the model automatically maintain conversation context across turns.

```python
import google.generativeai as genai
import os

genai.configure(api_key=os.environ["GEMINI_API_KEY"])

class CustomerSupportBot:
    def __init__(self, system_prompt: str):
        self.model = genai.GenerativeModel(
            model_name="gemini-2.5-flash",
            system_instruction=system_prompt
        )
        # Start a multi-turn conversation session
        self.chat = self.model.start_chat(history=[])
        self.escalated = False
        self.conversation_log = []

    def send_message(self, user_message: str) -> dict:
        """
        Send a user message and receive a response.

        Returns:
            dict: response_text (the reply) and escalate (transfer flag)
        """
        if self.escalated:
            return {
                "response_text": "We are connecting you with a human agent. Please hold on.",
                "escalate": True
            }

        try:
            response = self.chat.send_message(user_message)
            response_text = response.text

            # Log the conversation
            self.conversation_log.append({"role": "user", "content": user_message})
            self.conversation_log.append({"role": "assistant", "content": response_text})

            # Check for the escalation keyword
            escalate = "[ESCALATE]" in response_text
            if escalate:
                response_text = response_text.replace("[ESCALATE]", "").strip()
                self.escalated = True

            return {
                "response_text": response_text,
                "escalate": escalate
            }

        except Exception as e:
            return {
                "response_text": "We're sorry — a temporary error occurred. Please try again in a moment.",
                "escalate": False
            }

# Example usage
bot = CustomerSupportBot(SYSTEM_PROMPT)

test_messages = [
    "My order hasn't arrived yet.",
    "My order number is 12345.",
    "I just want a refund at this point."
]

for msg in test_messages:
    print(f"User: {msg}")
    result = bot.send_message(msg)
    print(f"Bot: {result['response_text']}")
    if result["escalate"]:
        print(">>> Escalation triggered — transferring to human agent <<<")
    print()

# Expected output:
# User: My order hasn't arrived yet.
# Bot: I'm sorry to hear that. Could you please provide your order number?
#
# User: My order number is 12345.
# Bot: Thank you! Let me look up order 12345 and check the delivery status...
#
# User: I just want a refund at this point.
# Bot: I completely understand your frustration, and I'm sorry for the inconvenience.
#      Your refund request will be handled by one of our team members...
# >>> Escalation triggered — transferring to human agent <<<
```

## Integrating a FAQ Database

To provide more accurate and grounded answers, you can connect your chatbot to a FAQ database using Gemini API's Function Calling. This lets the model fetch relevant information dynamically rather than relying solely on its training data. For Function Calling basics, see [Gemini Function Calling Complete Guide](/articles/gemini-advanced/function-calling-guide).

```python
import google.generativeai as genai
import os

genai.configure(api_key=os.environ["GEMINI_API_KEY"])

# FAQ database (in production, this would come from an external DB or API)
FAQ_DB = {
    "shipping": {
        "answer": "Standard delivery takes 2–5 business days. Express shipping (+$5) is available for urgent orders.",
        "related": "You can track your order using the link in your confirmation email."
    },
    "return": {
        "answer": "Items can be returned within 14 days of delivery, provided they are unopened and unused.",
        "related": "Download a return label from your account dashboard."
    },
    "warranty": {
        "answer": "All products include a 1-year manufacturer warranty.",
        "related": "Repairs within the warranty period are covered at no cost."
    },
    "payment": {
        "answer": "We accept credit cards, bank transfers, and convenience store payments.",
        "related": "Installment plans depend on your credit card provider's terms."
    }
}

def search_faq(query: str) -> str:
    """Search the FAQ database for relevant information."""
    results = []
    query_lower = query.lower()
    for keyword, info in FAQ_DB.items():
        if keyword in query_lower:
            results.append(f"{info['answer']} {info['related']}")
    if results:
        return " ".join(results)
    return "No FAQ entry found. Our team will follow up with a verified answer."

# Function Calling tool definition
faq_tool = {
    "function_declarations": [
        {
            "name": "search_faq",
            "description": "Search the FAQ database to retrieve product and service information.",
            "parameters": {
                "type": "object",
                "properties": {
                    "query": {
                        "type": "string",
                        "description": "The keyword or question to search for"
                    }
                },
                "required": ["query"]
            }
        }
    ]
}

model_with_faq = genai.GenerativeModel(
    model_name="gemini-2.5-flash",
    system_instruction=SYSTEM_PROMPT,
    tools=[faq_tool]
)

chat_with_faq = model_with_faq.start_chat(history=[])

def handle_with_faq(user_message: str) -> str:
    """Process a response with FAQ lookup support."""
    response = chat_with_faq.send_message(user_message)

    # Handle Function Calling responses
    for part in response.candidates[0].content.parts:
        if hasattr(part, "function_call") and part.function_call.name == "search_faq":
            query = part.function_call.args.get("query", user_message)
            faq_result = search_faq(query)

            response = chat_with_faq.send_message(
                genai.protos.Content(
                    parts=[genai.protos.Part(
                        function_response=genai.protos.FunctionResponse(
                            name="search_faq",
                            response={"result": faq_result}
                        )
                    )]
                )
            )

    return response.text

# Test it
print(handle_with_faq("How do I return a product?"))
# Expected output: A polite response incorporating the return policy from the FAQ database
```

## Implementing the Escalation System

Maintaining support quality means knowing when to hand off to a human agent. The implementation below includes conversation summarization and priority assessment to help your team triage incoming escalations effectively.

```python
import google.generativeai as genai
import os
from datetime import datetime

genai.configure(api_key=os.environ["GEMINI_API_KEY"])

def summarize_conversation(conversation_log: list) -> str:
    """Summarize the conversation history using Gemini."""
    if not conversation_log:
        return "No conversation history."

    model = genai.GenerativeModel("gemini-2.5-flash")
    history_text = "\n".join([
        f"{msg['role']}: {msg['content']}"
        for msg in conversation_log
    ])

    prompt = f"""Summarize the following conversation in 3 sentences or fewer.
Include the core issue, current status, and the customer's apparent emotional state.

Conversation:
{history_text}"""

    response = model.generate_content(prompt)
    return response.text

def assess_priority(summary: str) -> str:
    """Assess the escalation priority based on the conversation summary."""
    high_priority_keywords = ["urgent", "refund", "legal", "fraud", "damaged", "never received"]
    for keyword in high_priority_keywords:
        if keyword.lower() in summary.lower():
            return "HIGH"
    return "NORMAL"

def create_escalation_ticket(
    conversation_log: list,
    user_id: str = "anonymous"
) -> dict:
    """
    Create an escalation ticket for a human agent.
    In production, integrate this with Zendesk, Salesforce, or your CRM of choice.

    Returns:
        dict: Ticket information
    """
    summary = summarize_conversation(conversation_log)
    priority = assess_priority(summary)

    ticket = {
        "ticket_id": f"ESC-{datetime.now().strftime('%Y%m%d%H%M%S')}",
        "created_at": datetime.now().isoformat(),
        "user_id": user_id,
        "summary": summary,
        "priority": priority,
        "conversation_log": conversation_log,
        "status": "open",
        "assigned_to": None  # Auto-assign via CRM
    }

    # In production: save to DB, notify via Slack, etc.
    print(f"[Escalation] Ticket created: {ticket['ticket_id']}")
    print(f"  Priority: {ticket['priority']}")
    print(f"  Summary: {ticket['summary'][:120]}...")

    return ticket
```

## Frequently Asked Questions

**Q1. Should I use Gemini Flash or Gemini Pro?**

For most customer support use cases, `gemini-2.5-flash` is the right choice — it balances speed, cost, and quality well. For high-volume production environments, Flash models are significantly more economical. If your support volume includes highly complex technical inquiries requiring multi-step reasoning, consider routing those to `gemini-3.1-pro`. A smart routing layer that selects the model based on query complexity is a practical approach for large-scale deployments.

**Q2. How much conversation history should I keep?**

Gemini's context window supports up to 1 million tokens, but for customer support most sessions only need the last 10–20 turns. Keeping the history too long increases API costs unnecessarily. When bridging sessions, inject a summary of the previous conversation into the system prompt rather than replaying the full history.

**Q3. How do I protect against prompt injection attacks?**

Several layers of defense are useful here. First, explicitly instruct the model in your system prompt not to follow instructions that ask it to change its role or ignore its guidelines. Second, pre-filter user input for unusual length or suspicious character patterns before sending it to the API. Third, implement output monitoring to regularly audit responses for unintended information disclosures. A layered approach is more robust than any single safeguard.

## Summary

Building a customer support chatbot with the Gemini API comes down to four key pillars:

- **System prompt design**: Clearly define the bot's role, response style, and escalation triggers to ensure consistent, on-brand behavior
- **Multi-turn conversation**: Use `start_chat()` to maintain context naturally across an entire support session
- **FAQ integration**: Leverage Function Calling to ground responses in verified, up-to-date information from your own knowledge base
- **Escalation logic**: Combine keyword detection and AI-generated summaries to seamlessly hand off to human agents at exactly the right moment

The system prompt is where most of the heavy lifting happens — it shapes roughly 80% of your bot's quality. Invest time in crafting it carefully for your specific domain, and treat it as a living document that you refine based on real customer interactions.
