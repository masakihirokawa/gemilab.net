## Why Vue.js 3 and Gemini API Are a Great Pair

Vue.js 3 is one of the most developer-friendly frontend frameworks available today. Its reactive system, clean Composition API, and composables pattern make it an excellent fit for building interactive AI-powered applications with Gemini API.

In this guide, you'll build a fully functional streaming AI chat app step by step — starting from project setup and finishing with production-grade error handling and multimodal image support.

Here's what you'll learn:

- How to integrate the Google AI SDK into a Vue 3 + Vite project
- Writing a reusable `useGemini` composable to encapsulate API logic
- Displaying streaming responses in real time
- Handling image uploads for multimodal conversations
- Protecting your API key in production with a backend proxy
- Handling rate limit errors with exponential backoff

**Who this is for:** Vue.js developers with a solid grasp of Composition API who want to add AI capabilities to their apps.

## Project Setup

Start by creating a Vue 3 project and installing the Google Generative AI SDK:

```bash
# Create a new Vue 3 project (select Composition API + TypeScript if you prefer)
npm create vue@latest my-gemini-chat
cd my-gemini-chat

# Install the Google AI SDK
npm install @google/generative-ai

# Start the dev server
npm run dev
```

Next, create a `.env.local` file at the root of your project:

```bash
# .env.local
VITE_GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

**Important:** Variables prefixed with `VITE_` are bundled into your frontend code and visible in the browser. This is fine for local development and prototypes, but for production you should move the key to a backend proxy (covered in a later section). Always add `.env.local` to `.gitignore`.

If you're new to the Gemini API in general, the [Gemini API Quickstart Guide](/en/articles/gemini-api/gemini-api-quickstart) is a great starting point.

## Creating the `useGemini` Composable

The real power of Vue 3 lies in composables — reusable functions that encapsulate reactive state and logic. Let's extract all Gemini API communication into a single composable called `useGemini.js`:

```javascript
// src/composables/useGemini.js
import { ref, reactive } from 'vue'
import { GoogleGenerativeAI } from '@google/generative-ai'

export function useGemini(systemInstruction = 'You are a helpful AI assistant.') {
  // Initialize the API client
  const genAI = new GoogleGenerativeAI(import.meta.env.VITE_GEMINI_API_KEY)
  const model = genAI.getGenerativeModel({
    model: 'gemini-2.5-flash',
    systemInstruction,
  })

  // Reactive state
  const isLoading = ref(false)
  const error = ref(null)
  const messages = reactive([]) // { role: 'user' | 'model', content: string }

  // Start a chat session that maintains conversation history
  let chat = model.startChat({
    generationConfig: {
      maxOutputTokens: 2048,
      temperature: 0.7,
    },
  })

  /**
   * Send a text message and stream the response
   * @param {string} userText - The user's input
   */
  const sendMessage = async (userText) => {
    if (!userText.trim() || isLoading.value) return

    // Add user message to the list
    messages.push({ role: 'user', content: userText })

    // Add an AI placeholder that we'll update as chunks arrive
    const aiMessage = reactive({ role: 'model', content: '' })
    messages.push(aiMessage)

    isLoading.value = true
    error.value = null

    try {
      // sendMessageStream returns an async iterable of chunks
      const result = await chat.sendMessageStream(userText)

      for await (const chunk of result.stream) {
        // Append each chunk to the message in real time
        aiMessage.content += chunk.text()
      }
    } catch (e) {
      error.value = e.message || 'Something went wrong'
      aiMessage.content = `⚠️ Error: ${error.value}`
    } finally {
      isLoading.value = false
    }
  }

  /**
   * Clear conversation history and reset the chat session
   */
  const resetChat = () => {
    messages.splice(0)
    chat = model.startChat({
      generationConfig: { maxOutputTokens: 2048, temperature: 0.7 },
    })
    error.value = null
  }

  return { messages, isLoading, error, sendMessage, resetChat }
}
```

**Expected behavior:** When you call `sendMessage`, the AI's reply streams in character-by-character through Vue's reactive system. The `isLoading` flag lets you disable the send button while a response is in progress.

For a deeper look at the streaming API and how to combine it with function calling, see the [Gemini API Streaming and Function Calling Guide](/en/articles/gemini-api/gemini-api-streaming-function-calling-guide).

## Building the Chat UI Component

Now let's wire the composable into a chat interface:

```vue
<!-- src/components/GeminiChat.vue -->
<template>
  <div class="chat-wrapper">
    <!-- Message list -->
    <div class="message-list" ref="messageListRef">
      <div
        v-for="(msg, index) in messages"
        :key="index"
        :class="['message', msg.role === 'user' ? 'user' : 'ai']"
      >
        <span class="label">{{ msg.role === 'user' ? 'You' : 'Gemini' }}</span>
        <p class="content" style="white-space: pre-wrap;">{{ msg.content }}</p>
      </div>

      <div v-if="isLoading" class="loading">Gemini is thinking...</div>
    </div>

    <!-- Error banner -->
    <div v-if="error" class="error-banner">{{ error }}</div>

    <!-- Input form -->
    <form @submit.prevent="handleSend" class="input-area">
      <textarea
        v-model="inputText"
        placeholder="Type a message... (Ctrl+Enter to send)"
        rows="3"
        @keydown.ctrl.enter.prevent="handleSend"
      />
      <div class="button-row">
        <button type="button" @click="resetChat" class="reset-btn">Reset</button>
        <button
          type="submit"
          :disabled="isLoading || !inputText.trim()"
          class="send-btn"
        >
          {{ isLoading ? 'Sending...' : 'Send' }}
        </button>
      </div>
    </form>
  </div>
</template>

<script setup>
import { ref, nextTick, watch } from 'vue'
import { useGemini } from '@/composables/useGemini'

const { messages, isLoading, error, sendMessage, resetChat } = useGemini(
  'You are a friendly AI assistant for Gemini Lab readers. Answer technical questions clearly and concisely.'
)

const inputText = ref('')
const messageListRef = ref(null)

const handleSend = async () => {
  const text = inputText.value.trim()
  if (!text || isLoading.value) return
  inputText.value = ''
  await sendMessage(text)
}

// Auto-scroll to the latest message whenever the list updates
watch(
  messages,
  async () => {
    await nextTick()
    if (messageListRef.value) {
      messageListRef.value.scrollTop = messageListRef.value.scrollHeight
    }
  },
  { deep: true }
)
</script>
```

The component is intentionally minimal so you can style it however you like. Key UX details include Ctrl+Enter support for quick sending, disabled state on the button during loading, and automatic scroll-to-bottom.

## Adding Multimodal Support — Image Input

One of Gemini's most impressive features is its native understanding of images. Here's how to add image upload to the composable:

```javascript
// Add to useGemini.js

/**
 * Send an image alongside a text prompt (multimodal)
 * @param {string} userText - Question or instruction about the image
 * @param {File} imageFile - The image file to analyze
 */
const sendImageMessage = async (userText, imageFile) => {
  if (isLoading.value) return

  isLoading.value = true
  error.value = null

  messages.push({
    role: 'user',
    content: userText || 'Please analyze this image.',
    imageUrl: URL.createObjectURL(imageFile),
  })

  const aiMessage = reactive({ role: 'model', content: '' })
  messages.push(aiMessage)

  try {
    // Convert the file to base64
    const base64Data = await fileToBase64(imageFile)

    const imagePart = {
      inlineData: {
        // Strip the "data:image/png;base64," prefix — only the raw data is needed
        data: base64Data.split(',')[1],
        mimeType: imageFile.type,
      },
    }

    // Pass text and image as an array to trigger multimodal mode
    const result = await model.generateContentStream([
      userText || 'Please analyze this image.',
      imagePart,
    ])

    for await (const chunk of result.stream) {
      aiMessage.content += chunk.text()
    }
  } catch (e) {
    error.value = e.message || 'Failed to process image.'
    aiMessage.content = `⚠️ Error: ${error.value}`
  } finally {
    isLoading.value = false
  }
}

// Helper: convert a File object to a base64 data URL
const fileToBase64 = (file) =>
  new Promise((resolve, reject) => {
    const reader = new FileReader()
    reader.onload = (e) => resolve(e.target.result)
    reader.onerror = reject
    reader.readAsDataURL(file)
  })
```

## Production Hardening — API Key Protection and Rate Limit Handling

### Backend Proxy Pattern

Never ship your Gemini API key in frontend code for production. Instead, route requests through a lightweight backend:

```javascript
// src/composables/useGeminiProxy.js (production pattern)
const sendMessage = async (userText) => {
  // Your backend holds the API key; the frontend calls your own endpoint
  const response = await fetch('/api/gemini/chat', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ message: userText }),
  })

  if (!response.ok) throw new Error(`API error: ${response.status}`)

  // Read the streaming response via SSE
  const reader = response.body.getReader()
  const decoder = new TextDecoder()
  const aiMessage = reactive({ role: 'model', content: '' })
  messages.push(aiMessage)

  while (true) {
    const { done, value } = await reader.read()
    if (done) break
    aiMessage.content += decoder.decode(value, { stream: true })
  }
}
```

### Automatic Retry with Exponential Backoff

Handle rate limiting gracefully by wrapping your send logic with a retry mechanism:

```javascript
// Retry up to 3 times with exponential backoff on 429 errors
const sendWithRetry = async (userText, retries = 3) => {
  for (let i = 0; i < retries; i++) {
    try {
      await sendMessage(userText)
      return
    } catch (e) {
      if (e.message?.includes('429') && i < retries - 1) {
        // Wait 1s, then 2s, then 4s before retrying
        await new Promise((res) => setTimeout(res, Math.pow(2, i) * 1000))
        continue
      }
      throw e
    }
  }
}
```

## FAQ

**Q: Can I use this composable with Vue 2?**

A: Vue 2 doesn't include the Composition API natively — you'd need the `@vue/composition-api` plugin. That said, Vue 2 has reached end-of-life, so new projects should use Vue 3. The core JavaScript logic in `useGemini.js` is framework-agnostic and works unchanged; only the template syntax needs adapting to the Options API style.

**Q: How do I write this in TypeScript?**

A: The Google AI SDK ships with first-class TypeScript types. Create `useGemini.ts`, import types like `GenerativeModel` and `ChatSession` from `@google/generative-ai`, and type your reactive state with `Ref<boolean>` from Vue. TypeScript will catch mismatches at compile time, which is especially useful as your chat logic grows.

**Q: What's different about using this with Nuxt 3?**

A: The composable logic is identical. In Nuxt 3, placing your file in the `composables/` directory enables auto-import, so you never need to write an explicit import statement. Use `useRuntimeConfig()` to access the API key securely on the server side. If you're using SSR, wrap the API client initialization in `onMounted` or a `<ClientOnly>` component to avoid hydration errors.

**Q: How large can image files be with `inlineData`?**

A: As a rule of thumb, keep images under 4 MB when using the `inlineData` approach. For larger files, upload them via the File API first, then reference the returned URI in your request. This avoids request payload limits and also lets you reuse uploaded files across multiple requests.

**Q: Can I persist the chat history across page reloads?**

A: Yes. Use `watch(messages, () => localStorage.setItem('chat', JSON.stringify(messages)), { deep: true })` to save on every change, and restore on mount with `JSON.parse(localStorage.getItem('chat') || '[]')`. Be mindful of sensitive data in conversation history, and always let users know their chats are being stored locally.
