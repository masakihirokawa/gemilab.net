## Introduction: What Advanced Gemini API Features Actually Enable

Once you've mastered the basics of the Gemini API — text generation, chat — the next step is combining its advanced features to build production-grade applications.

Gemini 2.5 Pro offers multimodal processing (text, images, video, audio, PDF), a context window of up to one million tokens, powerful Function Calling, and real-time grounding via Google Search. Combining these capabilities makes it possible to build applications that simply weren't feasible before.

This guide is a practical, production-focused walkthrough of all these features. Every code example has been verified against Google AI Studio and Vertex AI.

## Multimodal Processing: Beyond Text Input

One of Gemini's defining strengths is the ability to process and reason across text, images, video, audio, and PDF files in a unified way.

### Image Analysis in Practice

Extracting structured data from a product image:

```python
import google.generativeai as genai
from pathlib import Path

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel("gemini-2.5-pro")

image_path = Path("product.jpg")
image_data = image_path.read_bytes()

response = model.generate_content([
    {
        "mime_type": "image/jpeg",
        "data": image_data,
    },
    "Extract the following fields from this product image in JSON format:\n"
    "- product_name: Name of the product\n"
    "- category: Category (electronics/clothing/food/other)\n"
    "- condition: Condition (new/used/unknown)\n"
    "- estimated_price_usd: Estimated price in USD\n"
    "- description: Brief description under 100 words",
])

print(response.text)
# Expected output:
# {
#   "product_name": "Apple iPhone 15 Pro",
#   "category": "electronics",
#   "condition": "new",
#   "estimated_price_usd": 999,
#   "description": "Titanium-body smartphone with advanced camera system..."
# }
```

### Processing Video Files

Use the Gemini File API for efficient handling of large video files:

```python
import time

# Upload video via File API
video_file = genai.upload_file(
    path="meeting_recording.mp4",
    mime_type="video/mp4",
    display_name="Team Meeting 2026-04-04",
)

# Wait for processing to complete
while video_file.state.name == "PROCESSING":
    print("Processing...")
    time.sleep(5)
    video_file = genai.get_file(video_file.name)

if video_file.state.name != "ACTIVE":
    raise ValueError(f"File processing failed: {video_file.state.name}")

# Analyze the video
response = model.generate_content([
    video_file,
    """Analyze this meeting recording and output:
    1. Main topics discussed (bullet points)
    2. Decisions made (bullet points)
    3. Action items (with owner and deadline)
    4. Topics to carry forward to the next meeting
    Format: JSON"""
])

# Clean up to save storage
genai.delete_file(video_file.name)
```

### Production Design Considerations for Multimodal

- **Specify MIME types precisely**: `image/jpeg` and `image/png` are distinct — wrong MIME types cause errors
- **File API TTL**: Uploaded files are automatically deleted after 48 hours — plan your workflow accordingly
- **Base64 vs File API**: Use inline Base64 for files under 1MB; use File API for larger files

## Function Calling: Real-Time Integration with External Systems

Function Calling enables Gemini to call external APIs, query databases, and execute actions in the real world. This transforms Gemini from a static knowledge base into a dynamic agent.

### The Function Calling Flow

```
User: "What's the current temperature in Tokyo?"
→ Gemini decides: should call get_weather(location="Tokyo")
→ Your app: actually calls the weather API
→ Your app: returns the API result to Gemini
→ Gemini: "The current temperature in Tokyo is 20°C."
```

### Production Example: Database Search Agent

```python
import google.generativeai as genai
import json

genai.configure(api_key="YOUR_GEMINI_API_KEY")

tools = [
    genai.protos.Tool(
        function_declarations=[
            genai.protos.FunctionDeclaration(
                name="search_products",
                description="Search the product database. Supports filtering by category, price range, and keyword.",
                parameters=genai.protos.Schema(
                    type=genai.protos.Type.OBJECT,
                    properties={
                        "keyword": genai.protos.Schema(
                            type=genai.protos.Type.STRING,
                            description="Search keyword"
                        ),
                        "category": genai.protos.Schema(
                            type=genai.protos.Type.STRING,
                            description="Product category (electronics/clothing/food)"
                        ),
                        "max_price": genai.protos.Schema(
                            type=genai.protos.Type.NUMBER,
                            description="Maximum price in USD"
                        ),
                    },
                    required=["keyword"]
                )
            ),
            genai.protos.FunctionDeclaration(
                name="get_product_detail",
                description="Retrieve detailed information for a specific product by ID",
                parameters=genai.protos.Schema(
                    type=genai.protos.Type.OBJECT,
                    properties={
                        "product_id": genai.protos.Schema(
                            type=genai.protos.Type.STRING,
                            description="Product ID"
                        ),
                    },
                    required=["product_id"]
                )
            ),
        ]
    )
]

model = genai.GenerativeModel("gemini-2.5-flash", tools=tools)

def handle_function_call(func_name: str, args: dict) -> dict:
    """Execute the actual function (DB or API call)"""
    if func_name == "search_products":
        return {
            "products": [
                {"id": "P001", "name": "Wireless Earbuds", "price": 59.99},
                {"id": "P002", "name": "Bluetooth Speaker", "price": 34.99},
            ],
            "total": 2
        }
    elif func_name == "get_product_detail":
        return {
            "id": args["product_id"],
            "name": "Wireless Earbuds",
            "price": 59.99,
            "stock": 15,
            "rating": 4.3,
            "description": "High-fidelity earbuds with active noise cancellation"
        }
    return {"error": "Unknown function"}

def run_agent(user_message: str) -> str:
    """Function Calling loop"""
    chat = model.start_chat()
    response = chat.send_message(user_message)

    while response.candidates[0].content.parts[0].function_call.name:
        func_call = response.candidates[0].content.parts[0].function_call
        func_name = func_call.name
        func_args = dict(func_call.args)

        print(f"🔧 Calling: {func_name}({func_args})")
        result = handle_function_call(func_name, func_args)

        response = chat.send_message(
            genai.protos.Content(
                parts=[genai.protos.Part(
                    function_response=genai.protos.FunctionResponse(
                        name=func_name,
                        response={"result": result}
                    )
                )]
            )
        )

    return response.text

result = run_agent("I'm looking for wireless earbuds under $100")
print(result)
```

### Handling Parallel Function Calls

Gemini 2.5 can call multiple functions simultaneously:

```python
def handle_parallel_function_calls(response):
    results = []
    for part in response.candidates[0].content.parts:
        if part.function_call.name:
            result = handle_function_call(
                part.function_call.name,
                dict(part.function_call.args)
            )
            results.append({
                "name": part.function_call.name,
                "result": result
            })
    return results
```

## 1M Token Context: Processing Large-Scale Data in One Pass

Gemini 2.5 Pro's one-million-token context window opens up use cases that simply weren't possible before: analyzing entire codebases, processing book-length documents, or reasoning over months of log data.

### Analyzing a Large Codebase

```python
import os
from pathlib import Path

def load_codebase(root_dir: str, extensions: list[str]) -> str:
    """Load an entire codebase as a text string"""
    files_content = []

    for path in Path(root_dir).rglob("*"):
        if path.suffix in extensions and ".git" not in str(path):
            try:
                content = path.read_text(encoding="utf-8")
                files_content.append(f"=== {path} ===\n{content}\n")
            except Exception:
                pass

    return "\n".join(files_content)

codebase = load_codebase("./src", [".py", ".ts", ".tsx"])
token_estimate = len(codebase) // 4
print(f"Estimated tokens: {token_estimate:,}")

model = genai.GenerativeModel("gemini-2.5-pro")
response = model.generate_content([
    codebase,
    """Analyze this codebase and provide:
    1. Architecture overview (layers, key components)
    2. Technical debt and priority improvements
    3. Security concerns
    4. Performance optimization opportunities
    5. Test coverage assessment
    Format each section in Markdown."""
])
```

### Managing Long Context Costs

```python
def estimate_cost(text: str) -> dict:
    """Estimate Gemini 2.5 Pro API cost"""
    token_count = len(text) // 4  # rough approximation

    # Gemini 2.5 Pro pricing (reference): $1.25/1M for ≤200K tokens, $2.50/1M for >200K
    if token_count <= 200_000:
        cost_usd = (token_count / 1_000_000) * 1.25
    else:
        cost_usd = (token_count / 1_000_000) * 2.50

    return {
        "estimated_tokens": token_count,
        "estimated_cost_usd": round(cost_usd, 4),
    }

# Check cost before sending
context = load_codebase("./src", [".py"])
cost = estimate_cost(context)
print(f"Estimated cost: {cost}")
# → {'estimated_tokens': 50000, 'estimated_cost_usd': 0.0625}
```

## Grounding with Google Search: Real-Time Information

Grounding with Google Search lets Gemini pull real-time search results into its responses. This is essential when your use case requires current information — news, prices, recent events — that wasn't available during model training.

### Implementing Google Search Grounding

```python
from google.ai.generativelanguage_v1beta.types import Tool as GlTool

model = genai.GenerativeModel(
    model_name="gemini-2.5-flash",
    tools=[
        GlTool(
            google_search=genai.protos.GoogleSearch()
        )
    ]
)

response = model.generate_content(
    "What are the latest AI startup news in Japan as of April 2026?"
)

# Inspect grounding sources
if response.candidates[0].grounding_metadata:
    print("Sources:")
    for chunk in response.candidates[0].grounding_metadata.grounding_chunks:
        print(f"  - {chunk.web.title}: {chunk.web.uri}")

print("\nAnswer:")
print(response.text)
```

### Grounding Use Cases

- **News apps**: Generate summaries from the latest articles
- **Competitive analysis**: Gather and synthesize real-time competitor information
- **Price comparison**: Retrieve current product prices
- **Customer support**: Answer questions using the latest product documentation

## Cost Optimization for Production

### Model Tiering Strategy

```python
def select_model(task_complexity: str, requires_multimodal: bool = False) -> str:
    """Select the optimal model for a given task"""
    if requires_multimodal and task_complexity == "high":
        return "gemini-2.5-pro"    # Complex multimodal reasoning
    elif task_complexity == "high":
        return "gemini-2.5-pro"    # Deep reasoning, long context
    elif task_complexity == "medium":
        return "gemini-2.5-flash"  # Balanced — great cost efficiency
    else:
        return "gemini-2.0-flash-lite"  # Simple tasks, maximum speed
```

### Context Caching

When you repeatedly use the same large system prompt or document, Context Caching reduces costs by 50–90%:

```python
import google.generativeai as genai
from google.generativeai.caching import CachedContent
from datetime import timedelta

large_system_instruction = """
You are a specialized customer support agent for [Company Name].
Below is the complete product manual:
(tens of thousands of characters follow...)
"""

# Create a cache (TTL: 1 hour)
cached_content = CachedContent.create(
    model="gemini-2.5-flash",
    contents=[{"role": "user", "parts": [{"text": large_system_instruction}]}],
    ttl=timedelta(hours=1),
)

# Initialize model using cached content
model = genai.GenerativeModel.from_cached_content(cached_content)

# Subsequent requests dramatically reduce costs for the cached portion
response = model.generate_content("What is the warranty period for this product?")
```

### Handling Rate Limits

```python
import time
import random
from typing import TypeVar, Callable

T = TypeVar("T")

def retry_with_backoff(
    func: Callable[..., T],
    max_retries: int = 5,
    base_delay: float = 1.0,
) -> T:
    """Retry with exponential backoff for rate limit errors"""
    for attempt in range(max_retries):
        try:
            return func()
        except Exception as e:
            error_str = str(e)
            if "429" in error_str or "RESOURCE_EXHAUSTED" in error_str:
                if attempt < max_retries - 1:
                    delay = base_delay * (2 ** attempt) + random.uniform(0, 1)
                    print(f"Rate limit hit. Retrying in {delay:.1f}s ({attempt + 1}/{max_retries})")
                    time.sleep(delay)
                else:
                    raise
            else:
                raise
```

## Troubleshooting Common Issues

### Issue 1: INVALID_ARGUMENT (Invalid MIME Type)

**Symptom**: INVALID_ARGUMENT error when passing images or video

**Fix**: Verify the exact MIME type. `image/jpg` is invalid — the correct type is `image/jpeg`. Consult the official Gemini documentation for the complete list of supported MIME types.

### Issue 2: Safety Filter Blocks

**Symptom**: Generated content is blocked by Gemini's safety system

**Fix**: Check `response.prompt_feedback` for the block reason. Adjust `safety_settings` if necessary for your use case, and reinforce constraints in your system instructions (e.g., "generate only educational content").

### Issue 3: Infinite Function Calling Loop

**Symptom**: Gemini repeatedly calls the same function without making progress

**Fix**: Set a `max_iterations` limit on your function-calling loop. Add constraints to your function descriptions stating the maximum number of times they should be called.

## FAQ

**Q1. When should I use Gemini 2.5 Pro vs. 2.5 Flash?**

Use Gemini 2.5 Pro for complex reasoning, intricate code analysis, and long context processing (over 100K tokens). Use Gemini 2.5 Flash for chat interfaces, summarization, classification, and any task where speed and cost efficiency matter. Flash runs at roughly one-fifth the cost of Pro with faster response times. The practical approach: start with Flash, switch to Pro only if quality is insufficient.

**Q2. When is Context Caching worth using?**

If you're using the same system instructions or large documents more than 5–10 times, Context Caching can reduce costs by 50–90% — highly worthwhile. For 1–2 uses, the cost of creating the cache may exceed the savings. Use caching when you have stable, reusable context that's used frequently.

**Q3. When should I use Function Calling vs. a regular prompt?**

Use Function Calling when you need real-time data, need to perform actions in external systems, or need structured output that's guaranteed to conform to a specific schema. Use regular prompting when the task is entirely self-contained within Gemini's knowledge. Function Calling has higher design and debugging overhead — only use it when the benefits are clear.

## Conclusion

Here's a summary of the key principles for using advanced Gemini API features in production:

- **Multimodal requires precise MIME types and smart use of File API**: Inline Base64 for small files, File API for large ones; always specify the exact MIME type
- **Function Calling bridges Gemini to the real world**: Careful function design, parallel support, and loop limits make it production-safe
- **1M token context requires cost awareness**: Estimate token counts before sending and only pass the data you actually need
- **Grounding unlocks real-time information**: Use Google Search grounding whenever current data is essential to your use case
- **Optimize costs through model tiering and caching**: Match model capability to task complexity; use Context Caching for frequently reused prompts

Combining these advanced features unlocks application categories that weren't achievable with earlier AI APIs. Use the code examples in this guide as a foundation and adapt them to your specific production requirements.
