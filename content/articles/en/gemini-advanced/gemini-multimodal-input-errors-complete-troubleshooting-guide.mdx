# Gemini Multimodal Input Error Guide — Complete Fix for Images, Audio, Video & PDF Processing

Gemini 2.5 Pro's ability to process images, audio, video, and PDFs alongside text is one of its most compelling capabilities. But in practice, multimodal inputs are also where developers hit unexpected errors most often.

"I sent an image but Gemini says it can't see it." "Video processing times out." "The PDF content isn't being extracted correctly." — This guide walks through every major failure mode with working code to fix each one.

## The Two Ways to Send Multimodal Content

Before diving into errors, understand the two core approaches:

**Method 1: inline_data** — embed the file directly in the request

```python
import google.generativeai as genai
import base64

genai.configure(api_key="YOUR_API_KEY")
model = genai.GenerativeModel("gemini-2.5-pro")

with open("photo.jpg", "rb") as f:
    image_data = base64.b64encode(f.read()).decode("utf-8")

response = model.generate_content([
    {
        "inline_data": {
            "mime_type": "image/jpeg",
            "data": image_data
        }
    },
    "What's in this image?"
])
print(response.text)
```

**Method 2: File API** — upload the file first, then reference it

```python
import google.generativeai as genai
import time

uploaded_file = genai.upload_file(
    path="large_video.mp4",
    mime_type="video/mp4"
)

# Wait for processing to complete — critical step!
while uploaded_file.state.name == "PROCESSING":
    time.sleep(5)
    uploaded_file = genai.get_file(uploaded_file.name)

if uploaded_file.state.name == "FAILED":
    raise ValueError(f"File processing failed: {uploaded_file.state}")

response = model.generate_content([
    uploaded_file,
    "Summarize the key points in this video."
])
```

**When to use which:**
- Images and short audio under 20MB → `inline_data` is simpler
- Videos, large PDFs, audio files → `File API` (supports up to 2GB)
- Files you'll reference multiple times → `File API` (cached for 48 hours)

## Error #1: MIME Type Mismatch

**Symptom**: "I can't view the image" or Claude processes the request as text-only.

```python
# Wrong MIME types that fail silently or throw errors:
# "image/jpg"     → invalid (correct: "image/jpeg")
# "audio/mp4"     → ambiguous for audio-only (use "audio/mp4" or "audio/aac")
# "video/quicktime" → use "video/mov" for .mov files

# Build a utility that detects the correct MIME type automatically
import mimetypes
import pathlib

SUPPORTED_MIME_TYPES = {
    "image/jpeg", "image/png", "image/gif", "image/webp",
    "image/heic", "image/heif",
    "audio/wav", "audio/mp3", "audio/mpeg", "audio/ogg",
    "audio/flac", "audio/aac",
    "video/mp4", "video/mpeg", "video/mov", "video/avi",
    "video/webm", "video/wmv",
    "application/pdf",
    "text/plain", "text/html", "text/csv", "text/markdown"
}

def get_mime_type(file_path: str) -> str:
    mime, _ = mimetypes.guess_type(file_path)
    if mime not in SUPPORTED_MIME_TYPES:
        raise ValueError(
            f"Unsupported MIME type: {mime}\n"
            f"Supported types: {SUPPORTED_MIME_TYPES}"
        )
    return mime

def embed_file_inline(file_path: str, prompt: str) -> str:
    mime_type = get_mime_type(file_path)
    with open(file_path, "rb") as f:
        data = base64.b64encode(f.read()).decode("utf-8")
    
    response = model.generate_content([
        {"inline_data": {"mime_type": mime_type, "data": data}},
        prompt
    ])
    return response.text
```

## Error #2: File Size Exceeded

**Symptom**: `400 Request payload too large` or silent failures with large files.

```python
import os

MAX_INLINE_BYTES = 20 * 1024 * 1024  # 20MB threshold

def smart_send_file(file_path: str, prompt: str) -> str:
    """Automatically choose inline_data or File API based on file size."""
    
    file_size = os.path.getsize(file_path)
    mime_type = get_mime_type(file_path)
    
    if file_size <= MAX_INLINE_BYTES:
        with open(file_path, "rb") as f:
            data = base64.b64encode(f.read()).decode("utf-8")
        content = [
            {"inline_data": {"mime_type": mime_type, "data": data}},
            prompt
        ]
    else:
        print(f"File size {file_size / 1024 / 1024:.1f}MB — using File API")
        uploaded = genai.upload_file(path=file_path, mime_type=mime_type)
        
        import time
        while uploaded.state.name == "PROCESSING":
            time.sleep(3)
            uploaded = genai.get_file(uploaded.name)
        
        if uploaded.state.name != "ACTIVE":
            raise RuntimeError(f"File API upload failed: {uploaded.state}")
        
        content = [uploaded, prompt]
    
    return model.generate_content(content).text
```

## Error #3: Video Processing Timeout

**Symptom**: Long videos take forever or time out during File API processing.

```python
import time
import google.generativeai as genai

def process_video_with_timeout(video_path: str, prompt: str, timeout: int = 300) -> str:
    """Process video with polling and configurable timeout."""
    
    print(f"Uploading video: {video_path}")
    uploaded = genai.upload_file(path=video_path, mime_type="video/mp4")
    
    start = time.time()
    while uploaded.state.name == "PROCESSING":
        elapsed = time.time() - start
        if elapsed > timeout:
            raise TimeoutError(
                f"Video processing timed out after {timeout}s. "
                f"Try reducing resolution or splitting into shorter segments."
            )
        print(f"Processing... {elapsed:.0f}s elapsed", end="\r")
        time.sleep(5)
        uploaded = genai.get_file(uploaded.name)
    
    if uploaded.state.name != "ACTIVE":
        raise RuntimeError(f"Video processing failed: {uploaded.state.name}")
    
    print(f"\nProcessing complete. Sending to Gemini...")
    response = model.generate_content(
        [uploaded, prompt],
        request_options={"timeout": 120}
    )
    return response.text

def split_video(video_path: str, segment_minutes: int = 10) -> list[str]:
    """Split long video into segments using ffmpeg."""
    import subprocess, pathlib
    
    output_dir = pathlib.Path(video_path).parent / "segments"
    output_dir.mkdir(exist_ok=True)
    
    subprocess.run([
        "ffmpeg", "-i", video_path, "-c", "copy",
        "-segment_time", str(segment_minutes * 60),
        "-f", "segment", "-reset_timestamps", "1",
        str(output_dir / "seg_%03d.mp4")
    ], check=True, capture_output=True)
    
    return sorted(str(p) for p in output_dir.glob("seg_*.mp4"))
```

## Error #4: Audio Format Not Supported

**Symptom**: `Invalid MIME type` or poor transcription quality with certain audio formats.

```python
import pathlib

SUPPORTED_AUDIO_EXTS = {
    ".wav": "audio/wav",
    ".mp3": "audio/mp3",
    ".m4a": "audio/mp4",
    ".aac": "audio/aac",
    ".ogg": "audio/ogg",
    ".flac": "audio/flac",
    ".opus": "audio/opus"
}

def transcribe_audio(audio_path: str, language: str = "en") -> str:
    ext = pathlib.Path(audio_path).suffix.lower()
    
    if ext not in SUPPORTED_AUDIO_EXTS:
        # Convert to mp3 using ffmpeg
        converted = str(pathlib.Path(audio_path).with_suffix(".mp3"))
        import subprocess
        subprocess.run(
            ["ffmpeg", "-i", audio_path, "-acodec", "libmp3lame", "-q:a", "2", converted],
            check=True, capture_output=True
        )
        audio_path = converted
        ext = ".mp3"
    
    mime_type = SUPPORTED_AUDIO_EXTS[ext]
    file_size = pathlib.Path(audio_path).stat().st_size
    
    if file_size < 5 * 1024 * 1024:
        with open(audio_path, "rb") as f:
            data = base64.b64encode(f.read()).decode("utf-8")
        content = [
            {"inline_data": {"mime_type": mime_type, "data": data}},
            f"Transcribe this audio in {language}. Include punctuation."
        ]
    else:
        uploaded = genai.upload_file(path=audio_path, mime_type=mime_type)
        import time
        while uploaded.state.name == "PROCESSING":
            time.sleep(3)
            uploaded = genai.get_file(uploaded.name)
        content = [uploaded, f"Transcribe this audio in {language}."]
    
    return model.generate_content(content).text
```

## Error #5: PDF Processing Accuracy

**Symptom**: PDF text not extracted correctly, or specific pages are missed.

```python
import base64, pathlib

def analyze_pdf(pdf_path: str, query: str) -> str:
    """Analyze a PDF document with automatic size routing."""
    
    file_size = pathlib.Path(pdf_path).stat().st_size
    
    if file_size > 20 * 1024 * 1024:
        uploaded = genai.upload_file(path=pdf_path, mime_type="application/pdf")
        import time
        while uploaded.state.name == "PROCESSING":
            time.sleep(3)
            uploaded = genai.get_file(uploaded.name)
        content = [uploaded, query]
    else:
        with open(pdf_path, "rb") as f:
            data = base64.b64encode(f.read()).decode("utf-8")
        content = [
            {"inline_data": {"mime_type": "application/pdf", "data": data}},
            query
        ]
    
    return model.generate_content(content).text

def extract_specific_pages(pdf_path: str, page_numbers: list[int], query: str) -> str:
    """Extract and analyze specific pages from a PDF (requires pypdf)."""
    import pypdf, io
    
    reader = pypdf.PdfReader(pdf_path)
    writer = pypdf.PdfWriter()
    
    for page_num in page_numbers:
        if 0 <= page_num < len(reader.pages):
            writer.add_page(reader.pages[page_num])
    
    buffer = io.BytesIO()
    writer.write(buffer)
    buffer.seek(0)
    
    data = base64.b64encode(buffer.read()).decode("utf-8")
    response = model.generate_content([
        {"inline_data": {"mime_type": "application/pdf", "data": data}},
        f"Pages {page_numbers}: {query}"
    ])
    return response.text
```

## Debugging Multimodal Responses

```python
def debug_response(response):
    """Print detailed debug information about a multimodal response."""
    
    print("=== Multimodal Response Debug ===")
    
    if response.prompt_feedback:
        print(f"Prompt feedback: {response.prompt_feedback}")
    
    for i, candidate in enumerate(response.candidates):
        print(f"\nCandidate {i}: finish_reason={candidate.finish_reason.name}")
        
        if candidate.finish_reason.name != "STOP":
            print(f"  WARNING: Non-standard finish reason")
            if hasattr(candidate, "safety_ratings"):
                for rating in candidate.safety_ratings:
                    print(f"  Safety: {rating.category.name} = {rating.probability.name}")
        
        if candidate.content and candidate.content.parts:
            for part in candidate.content.parts:
                if hasattr(part, "text"):
                    preview = part.text[:300]
                    print(f"  Response preview: {preview}...")
```

## File API Lifecycle Management

```python
def list_uploaded_files():
    """List all active uploaded files and their status."""
    for f in genai.list_files():
        print(f"  {f.name}: {f.state.name}, {f.mime_type}")

def cleanup_files():
    """Delete all uploaded files to free quota."""
    deleted = 0
    for f in genai.list_files():
        try:
            genai.delete_file(f.name)
            deleted += 1
        except Exception as e:
            print(f"Failed to delete {f.name}: {e}")
    print(f"Deleted {deleted} files")
```

## Looking back

Multimodal input errors typically trace back to a handful of root causes:

- **MIME type errors** → Use automatic detection from file extension; verify against the supported types list
- **File too large** → Use `smart_send_file()` to auto-route to File API above 20MB
- **Video timeout** → Poll with a timeout; split long videos into 10-minute segments
- **Unsupported audio format** → Convert to mp3/wav with ffmpeg before sending
- **PDF accuracy issues** → For large PDFs, use File API; for specific pages, extract them with pypdf first

The most common cause of "Gemini can't see my file" is either a MIME type mismatch or forgetting to wait for File API processing to complete (`ACTIVE` state). Check both of those before investigating further.
