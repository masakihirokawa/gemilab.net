## Initial Setup in VS Code and IntelliJ

### Getting Started with VS Code

1. **Install the extension**
   - Open VS Code's Marketplace and search for "Gemini Code Assist"
   - Click Install, then restart the editor

2. **Set up authentication**
   - Open Command Palette (Cmd/Ctrl+Shift+P) and type "Gemini: Sign In"
   - Authenticate with your Google account
   - Select your Google Cloud project from the prompt

3. **Verify default settings**
   - Check your `settings.json` to confirm:
     ```json
     {
       "gemini.enabled": true,
       "gemini.inlineCompletions": true,
       "gemini.chat": true,
       "gemini.agentMode": true
     }
     ```

### IntelliJ IDEA Setup

1. **Install the plugin**
   - Go to Settings → Plugins → Marketplace
   - Search for "Gemini Code Assist" and install

2. **Restart your IDE**
   - An authentication dialog appears automatically
   - Select your Google Cloud project

3. **Verify Project SDK**
   - Navigate to Project Settings → Project → SDK
   - Gemini uses the SDK path for context inference

## Agent Mode Preview — AI That Plans, Then Codes

The newest addition to Gemini Code Assist is **Agent Mode**. It shifts from simple completion to a true agent workflow: **automatic planning → implementation → verification**.

### How Agent Mode Works

1. **Planning phase**
   - You tell Gemini: "`/refactor Reorganize Main.java to follow the MVC pattern`"
   - Gemini analyzes your codebase and proposes multiple refactoring plans

2. **Implementation phase**
   - You select and approve a plan
   - Gemini generates inline diffs showing changes file by file

3. **Review phase**
   - You review each diff and approve
   - Gemini applies changes and suggests test cases automatically

### Real-World Use Cases

**Pattern 1: Modernizing legacy code**

```
You: "/refactor Convert this code to modern TypeScript. Use async/await throughout"

Agent Mode output:
- Plan: Refactor Promise-based functions to async/await
- Inline diffs showing each location
- Auto-generated test function suggestions
```

**Pattern 2: Building new features**

```
You: "/implement Add user authentication using OAuth 2.0"

Agent Mode output:
- OAuth library recommendations
- Component structure proposal
- Auto-generated boilerplate code
- Security checklist
```

To use Agent Mode, type `/` in the chat panel and select from the menu. While still in Preview, it's already production-ready.

## Finish Changes — Auto-Complete From Incomplete Code

**Finish Changes** takes incomplete code and automatically generates a complete, ready-to-use version. It works with three patterns.

### 1. TODO comments

```typescript
// TODO: Fetch user data and format it
async function processUserData(userId: string) {
  // Gemini auto-generates:
  const user = await fetchUser(userId);
  return {
    id: user.id,
    name: user.full_name,
    email: user.email,
    createdAt: new Date(user.created_at),
  };
}
```

Place your cursor below the TODO, use the keyboard shortcut (VS Code: `Ctrl+Shift+E`), and Gemini fills in the function call and type inference automatically.

### 2. Pseudocode

```python
def calculate_average_score(students):
    # Pseudocode:
    # - Get each student's score
    # - Sum all scores
    # - Divide by count
    
    # Gemini generates:
    scores = [student['score'] for student in students]
    return sum(scores) / len(scores) if students else 0
```

### 3. Function signatures

```go
func (r *Repository) FindByEmail(ctx context.Context, email string) (*User, error) {
    // Finish Changes fills in the body
    // Database query construction and error handling auto-generated
}
```

**Using Finish Changes can cut implementation time by 30-50%**, especially for repetitive data processing and boilerplate code.

**File Outline** understands your entire file's structure and auto-generates JSDoc comments or docstrings.

### How to use it

1. Open Command Palette and run "Gemini: Generate Outline"
2. Gemini scans your file and generates:
   - Class and function descriptions
   - Parameter and return type documentation
   - Usage examples

**Generation example (TypeScript):**

```typescript

 * if (payload) {
 *   console.log('User ID:', payload.userId);
 * }
 */
function verifyToken(token: string, secret: string): TokenPayload | null {
  // ...
}
```

Generated documentation automatically appears in your IDE's IntelliSense, **dramatically accelerating team code understanding**. Especially powerful in microservices and plugin ecosystems.

## Code Transformation — Refactor With Commands

**Code Transformation** executes prompt-based instructions on existing code: "Convert to Python," "Refactor to this pattern," and similar transformations.

### Transformation examples

**Original code (JavaScript):**
```javascript
function filterUsers(users, role) {
  return users.filter(u => u.role === role);
}
```

**Prompt:** "Convert to Python"

**Result:**
```python
def filter_users(users: list[dict], role: str) -> list[dict]:
    return [u for u in users if u['role'] == role]
```

**Prompt:** "Refactor to functional programming style"

**Result:**
```python
from functools import reduce

filter_users = lambda role: (
    lambda users: list(filter(lambda u: u['role'] == role, users))
)
```

Compare multiple versions side by side in your IDE and pick the best one.
