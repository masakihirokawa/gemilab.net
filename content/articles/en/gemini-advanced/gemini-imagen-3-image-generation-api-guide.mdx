## Key Features of Imagen 3

Imagen 3 stands apart from previous image generation models in several important ways:

- **Resolution and Aspect Ratios**: Generates up to 1024×1024 pixels with flexible aspect ratios including 1:1, 3:4, 4:3, 9:16, and 16:9 for different use cases
- **Photorealism**: Produces images virtually indistinguishable from real photography, with exceptional light refraction, texture detail, and depth perception
- **Text Rendering**: Overcomes the traditional weakness of image generation models by accurately rendering text and typography within images
- **Artistic Versatility**: Handles diverse styles from photographic realism to illustration, watercolor, and 3D rendering on demand
- **SynthID Watermarking**: Automatically embeds invisible watermarks in generated images that can be detected to verify authenticity and origin

## Basic Image Generation Example

Here's the simplest way to generate your first image:

```python
import google.generativeai as genai
import PIL.Image
import io
import os

# Configure the API key
genai.configure(api_key=os.environ["GEMINI_API_KEY"])

# Initialize the Imagen 3 model
model = genai.ImageGenerationModel("imagen-3.0-generate-002")

# Generate an image from a text prompt
response = model.generate_images(
    prompt="Tokyo cityscape at night, modern skyscrapers with cherry blossoms, dreamlike atmosphere, photorealistic",
    number_of_images=1,
    aspect_ratio="16:9",
)

# Save the generated image
for i, image in enumerate(response.generated_images):
    img = PIL.Image.open(io.BytesIO(image.image.image_bytes))
    img.save(f"output_{i}.png")
    print(f"Image saved to output_{i}.png")

# Expected output:
# Image saved to output_0.png
```

Run this script and you'll get a PNG image matching your text description.

## Mastering Prompt Engineering

The quality of generated images depends heavily on prompt quality. Detailed, specific prompts consistently outperform vague ones.

### Concrete Prompt Examples

**Landscape and Architecture**

- **Weak**: "A mountain photo" — too generic, unpredictable results
- **Strong**: "Golden hour sunrise over Mount Fuji, mist clinging to fifth station, orange and purple gradient sky, ultra-high resolution commercial photography"

**Portrait Photography**

- **Weak**: "A businessman photo"
- **Strong**: "30-year-old Japanese software engineer working on laptop in a café, soft afternoon light, creamy bokeh background, professional portrait photography quality"

**Product Mockups**

- **Weak**: "A smartphone mockup"
- **Strong**: "Latest iPhone mockup on minimal white background with soft shadow, app interface visible on screen, product photography lighting"

### Elements That Boost Image Quality

- **Photography Style**: Use keywords like "photorealistic," "illustration style," "watercolor," "3D render"
- **Lighting Conditions**: "Golden hour," "studio lighting," "backlighting," "soft natural light"
- **Composition**: "Bird's eye view," "macro photography," "wide-angle lens," "close-up shot"
- **Quality Markers**: "Ultra high resolution," "commercial photography quality," "4K"

Combining these elements strategically transforms ordinary prompts into powerful directives.

## Advanced Options: Aspect Ratios and Batch Generation

Imagen 3 supports multiple aspect ratios and can generate multiple variations in a single request:

```python
import google.generativeai as genai
import PIL.Image
import io
import os

genai.configure(api_key=os.environ["GEMINI_API_KEY"])
model = genai.ImageGenerationModel("imagen-3.0-generate-002")

# Generate a portrait-oriented image
response_portrait = model.generate_images(
    prompt="Spring cherry blossom pathway, petals falling, bright daylight, photorealistic",
    number_of_images=1,
    aspect_ratio="3:4",  # Portrait orientation
)

# Generate a banner-style image
response_banner = model.generate_images(
    prompt="Modern tech company office interior, minimalist design, natural light streaming in",
    number_of_images=1,
    aspect_ratio="16:9",  # Widescreen for banners and headers
)

# Generate multiple design variations at once (up to 4)
response_multiple = model.generate_images(
    prompt="Minimalist circular logo design, blue and gray gradient palette",
    number_of_images=4,  # Get four different variations
    aspect_ratio="1:1",  # Square for logos
)

print(f"Generated {len(response_multiple.generated_images)} images")
# Expected output:
# Generated 4 images
```

Batch generation is perfect for design exploration or creating multiple product photography variations.

## Using Negative Prompts

You can specify what you want to exclude from generation:

```python
response = model.generate_images(
    prompt="Restaurant food photography, Italian pasta dish, elegant plating",
    number_of_images=1,
    negative_prompt="blurry, low quality, watermark, text overlay, cartoon",
    aspect_ratio="4:3",
)
```

Exclusion keywords like "blurry," "low quality," and "watermark" guide Imagen 3 toward cleaner, more professional results.

## Commercial Use and Important Considerations

Before deploying Imagen 3-generated images commercially, understand these key points:

### About SynthID Watermarking

**SynthID** is Google DeepMind's invisible watermarking system automatically embedded in every Imagen 3 image. While imperceptible to humans, specialized tools can detect it, enabling authenticity verification—a major advantage for enterprise deployment.

### Content Policy Restrictions

Imagen 3 cannot generate:

- Images impersonating real people or public figures
- Content depicting violence, sexual material, or illegal activity
- Reproductions of copyrighted characters
- Harmful or illegal material

See [Google's Generative AI Use Policy](https://policies.google.com/terms/generative-ai/use-policy) for full details.

### Copyright and Ownership Rights

The copyright status of AI-generated images varies significantly by jurisdiction. While Google's terms state that ownership belongs to the user, the intersection with national copyright law remains legally complex. **Always consult legal counsel before commercial deployment.**

## Frequently Asked Questions

**Q: Is Imagen 3 completely free?**

A: Google AI Studio provides free monthly credits, but production-scale image generation requires Google Cloud billing. The cost is minimal but non-zero depending on usage volume.

**Q: Who owns the copyright to generated images?**

A: Google's terms grant ownership to the user, but copyright law varies by country. Before commercial use, consult an intellectual property lawyer familiar with AI-generated content laws in your jurisdiction.

**Q: How does Imagen 3 compare to Stable Diffusion or Midjourney?**

A: Imagen 3 integrates natively into Google's ecosystem, enabling seamless combination with other Gemini features like text generation and image analysis. SynthID watermarking comes built-in, making enterprise compliance straightforward—something competitors charge separately for.

**Q: Can I use Japanese prompts?**

A: Absolutely. Imagen 3 supports Japanese prompts effectively, though English prompts sometimes yield marginally better quality. Mixing English and Japanese in a single prompt works well too.

**Q: Is user data used to train future models?**

A: No. Imagen 3 is designed not to use your prompts or images in future model training. Always check Google's current privacy policy for the latest information.

**Q: What's the typical generation time?**

A: A single image usually generates in 5-15 seconds depending on model load. Batch requests (multiple images) are processed sequentially, so expect roughly linear scaling.
