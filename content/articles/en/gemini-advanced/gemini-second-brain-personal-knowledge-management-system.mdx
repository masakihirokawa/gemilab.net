## Setup and context: Why You Need a Second Brain in the Age of Information Overload

Every day, you accumulate web articles, technical docs, meeting notes, and scattered ideas. Months later, you think "I wrote something about this somewhere" — and spend an hour searching, or worse, redo the research from scratch.

The "Second Brain" concept, popularized by Tiago Forte in [Building a Second Brain](https://www.amazon.co.jp/dp/B09MDNDYYF/?tag=pinocchio-22), is a personal knowledge management (PKM) framework that treats your digital note system as an external memory device: designed to capture, organize, and retrieve knowledge on demand.

This guide takes that concept further and builds an **AI-native second brain** using the Gemini API. Rather than just organizing notes manually, we'll implement semantic search, automatic tagging, knowledge graph construction, Obsidian integration, and a spaced repetition system (SRS) — all powered by Gemini.

### What We're Building

The system consists of four core components:

- **Ingestor**: Reads Markdown/Obsidian files, generates summaries and embeddings via Gemini API
- **Semantic Search Engine**: Stores vectors in ChromaDB and retrieves relevant notes using natural language queries
- **Knowledge Graph Builder**: Uses Gemini API to auto-tag, extract entities, and auto-link related notes
- **Spaced Repetition Scheduler (SRS)**: Dynamically schedules review sessions to maximize memory retention

## System Architecture

### Technology Stack

- **Gemini API**: `text-embedding-004` for embedding generation; `gemini-2.5-flash` for text processing and tagging
- **ChromaDB**: Vector database (local development) / Chroma Cloud (production)
- **Python 3.12**: Primary implementation language
- **FastAPI**: REST API server for Obsidian plugin integration
- **SQLite**: Metadata and SRS scheduling

### Data Flow Overview

```
[Note Files]
    → [Ingestor] → [Gemini Embedding API]
                 → [ChromaDB (Vector DB)]
                 → [Gemini Flash (tags + summaries)]
                 → [SQLite (metadata)]

[Search Query]
    → [Gemini Embedding API] → [ChromaDB similarity search]
    → [Top-N relevant notes returned]

[Obsidian Plugin]
    → [FastAPI Server] → [Semantic Search]
                       → [Auto-link related notes]
                       → [Get SRS schedule]
```

## Core Module Implementation

### 1. Gemini Client

```python
# gemini_client.py
import google.generativeai as genai
from config import GEMINI_API_KEY, EMBEDDING_MODEL, GENERATION_MODEL

genai.configure(api_key=GEMINI_API_KEY)

def get_embedding(text: str) -> list[float]:
    """Generate a document embedding vector."""
    result = genai.embed_content(
        model=EMBEDDING_MODEL,
        content=text,
        task_type="retrieval_document",  # Optimized for document retrieval
    )
    return result["embedding"]

def get_query_embedding(query: str) -> list[float]:
    """Generate a query embedding vector (different task type for better accuracy)."""
    result = genai.embed_content(
        model=EMBEDDING_MODEL,
        content=query,
        task_type="retrieval_query",
    )
    return result["embedding"]

def generate_summary(content: str, max_words: int = 150) -> str:
    """Generate an AI summary of a note."""
    model = genai.GenerativeModel(GENERATION_MODEL)
    prompt = f"""Summarize the following note in {max_words} words or less.
Include key concepts, keywords, and any action items.

--- Note ---
{content[:3000]}
--- End ---

Summary:"""
    response = model.generate_content(prompt)
    return response.text.strip()

def extract_tags_and_entities(content: str) -> dict:
    """Auto-extract tags and entities from a note using Gemini."""
    model = genai.GenerativeModel(GENERATION_MODEL)
    prompt = f"""Extract metadata from the following note in JSON format.

--- Note ---
{content[:2000]}
--- End ---

Return ONLY valid JSON in this exact format:
{{
  "tags": ["tag1", "tag2", "tag3"],
  "entities": {{
    "technologies": ["tech1", "tech2"],
    "people": ["name1"],
    "concepts": ["concept1", "concept2"]
  }},
  "category": "technology/business/idea/learning/other",
  "importance": 1 to 5 integer (5 = most important)
}}"""

    import json, re
    response = model.generate_content(prompt)
    json_text = re.search(r'\{.*\}', response.text, re.DOTALL)
    if json_text:
        return json.loads(json_text.group())
    return {"tags": [], "entities": {}, "category": "other", "importance": 3}
```

### 2. Note Ingestor

```python
# ingestor.py
import frontmatter
from pathlib import Path
from datetime import datetime
from gemini_client import get_embedding, generate_summary, extract_tags_and_entities
from database import save_note_metadata
from vector_store import add_to_chroma

def ingest_note(file_path: Path) -> dict:
    """Ingest a Markdown note: vectorize, summarize, and extract metadata."""

    with open(file_path, "r", encoding="utf-8") as f:
        post = frontmatter.load(f)

    content = str(post.content)
    existing_metadata = dict(post.metadata)

    print(f"📝 Ingesting: {file_path.name}")

    # Generate AI summary
    summary = generate_summary(content)

    # Extract tags and entities
    extracted = extract_tags_and_entities(content)

    # Generate embedding from title + summary + beginning of content
    embed_text = f"{existing_metadata.get('title', file_path.stem)}\n{summary}\n{content[:1500]}"
    embedding = get_embedding(embed_text)

    # Create stable note ID from file path hash
    import hashlib
    note_id = hashlib.md5(str(file_path).encode()).hexdigest()

    note_data = {
        "id": note_id,
        "file_path": str(file_path),
        "title": existing_metadata.get("title", file_path.stem),
        "content": content,
        "summary": summary,
        "tags": extracted.get("tags", []),
        "entities": extracted.get("entities", {}),
        "category": extracted.get("category", "other"),
        "importance": extracted.get("importance", 3),
        "embedding": embedding,
        "created_at": datetime.fromtimestamp(file_path.stat().st_ctime),
        "updated_at": datetime.fromtimestamp(file_path.stat().st_mtime),
    }

    add_to_chroma(note_data)
    save_note_metadata(note_data)

    print(f"  ✅ Done: tags={extracted.get('tags', [])[:3]}")
    return note_data

def ingest_directory(notes_dir: Path) -> int:
    """Ingest all Markdown files in a directory recursively."""
    md_files = list(notes_dir.glob("**/*.md")) + list(notes_dir.glob("**/*.mdx"))

    count = 0
    for file_path in md_files:
        try:
            ingest_note(file_path)
            count += 1
        except Exception as e:
            print(f"  ❌ Error ({file_path.name}): {e}")

    print(f"\n📊 Ingestion complete: {count}/{len(md_files)} notes processed")
    return count
```

### 3. ChromaDB Vector Store

```python
# vector_store.py
import chromadb
from config import CHROMA_DIR

chroma_client = chromadb.PersistentClient(path=str(CHROMA_DIR))
collection = chroma_client.get_or_create_collection(
    name="notes",
    metadata={"hnsw:space": "cosine"}  # Use cosine similarity
)

def add_to_chroma(note_data: dict):
    """Add or update a note in ChromaDB."""
    try:
        collection.delete(ids=[note_data["id"]])
    except Exception:
        pass

    collection.add(
        ids=[note_data["id"]],
        embeddings=[note_data["embedding"]],
        documents=[note_data["summary"]],
        metadatas=[{
            "title": note_data["title"],
            "file_path": note_data["file_path"],
            "category": note_data["category"],
            "importance": note_data["importance"],
            "tags": ",".join(note_data["tags"]),
        }]
    )

def semantic_search(query_embedding: list[float], n_results: int = 5,
                    category_filter: str = None) -> list[dict]:
    """Run semantic similarity search against the note collection."""
    where_clause = {"category": category_filter} if category_filter else None

    results = collection.query(
        query_embeddings=[query_embedding],
        n_results=n_results,
        where=where_clause,
        include=["documents", "metadatas", "distances"]
    )

    formatted = []
    for i, (doc, meta, dist) in enumerate(zip(
        results["documents"][0],
        results["metadatas"][0],
        results["distances"][0]
    )):
        formatted.append({
            "rank": i + 1,
            "title": meta["title"],
            "file_path": meta["file_path"],
            "summary": doc,
            "category": meta["category"],
            "tags": meta["tags"].split(",") if meta["tags"] else [],
            "similarity_score": 1 - dist,  # Convert cosine distance to similarity
        })

    return formatted
```

## Knowledge Graph: Auto-Linking Related Notes

The true power of a second brain lies in discovering connections between ideas. Gemini API calculates semantic similarity between notes and automatically generates wiki-style links.

```python
# knowledge_graph.py
from vector_store import semantic_search
from gemini_client import get_query_embedding
from database import update_note_links

def build_note_links(note_data: dict, threshold: float = 0.75, max_links: int = 5):
    """Find and link semantically related notes for a given note."""
    search_text = f"{note_data['title']} {note_data['summary']}"
    query_emb = get_query_embedding(search_text)

    candidates = semantic_search(query_embedding=query_emb, n_results=max_links + 1)
    related = [
        c for c in candidates
        if c["file_path"] != note_data["file_path"]
        and c["similarity_score"] >= threshold
    ][:max_links]

    update_note_links(note_data["id"], related)

    # Generate Obsidian-compatible WikiLinks
    wikilinks = [f"[[{r['title']}]]" for r in related]
    return {"related_notes": related, "wikilinks": wikilinks}

def generate_related_section(note_data: dict) -> str:
    """Generate a Markdown 'Related Notes' section with auto-discovered links."""
    links = build_note_links(note_data)
    if not links["wikilinks"]:
        return ""

    lines = ["", "## Related Notes", ""]
    for note in links["related_notes"]:
        score_pct = int(note["similarity_score"] * 100)
        lines.append(f"- [[{note['title']}]] (similarity: {score_pct}%)")

    return "\n".join(lines)
```

## Real-Time Obsidian Integration

Obsidian is a popular Markdown-based knowledge app. By running our FastAPI server and using a file watcher, we can process notes the moment they're saved — automatically vectorizing, tagging, and linking related notes.

```python
# obsidian_watcher.py
from watchdog.observers import Observer
from watchdog.events import FileSystemEventHandler
from pathlib import Path
from ingestor import ingest_note
from knowledge_graph import generate_related_section
import time

class NoteChangeHandler(FileSystemEventHandler):
    def __init__(self, notes_dir: Path):
        self.notes_dir = notes_dir
        self._processing = set()  # Prevent double-processing

    def on_modified(self, event):
        if event.is_directory:
            return

        file_path = Path(event.src_path)
        if file_path.suffix not in [".md", ".mdx"]:
            return
        if str(file_path) in self._processing:
            return

        self._processing.add(str(file_path))
        try:
            print(f"\n🔄 Change detected: {file_path.name}")
            time.sleep(0.5)  # Wait for file write to complete

            note_data = ingest_note(file_path)

            # Auto-append related notes section
            related_section = generate_related_section(note_data)
            if related_section:
                with open(file_path, "a", encoding="utf-8") as f:
                    f.write(related_section)
                print(f"  🔗 Related note links appended")
        finally:
            self._processing.discard(str(file_path))

def start_watching(notes_dir: Path):
    """Start watching an Obsidian Vault for file changes."""
    handler = NoteChangeHandler(notes_dir)
    observer = Observer()
    observer.schedule(handler, str(notes_dir), recursive=True)
    observer.start()
    print(f"👁️  Watching: {notes_dir}")
    print("Press Ctrl+C to stop")
    try:
        while True:
            time.sleep(1)
    except KeyboardInterrupt:
        observer.stop()
    observer.join()
```

## Spaced Repetition System (SRS)

Spaced repetition is a learning technique that schedules reviews right before memory naturally fades — dramatically improving long-term retention. Our SRS uses the SM-2 algorithm combined with Gemini-generated quizzes.

```python
# srs.py
from datetime import datetime, timedelta
from database import get_notes_due_for_review, update_review_result, get_current_interval_index
from config import SRS_INTERVALS_DAYS, SRS_MAX_DAILY_REVIEWS, GENERATION_MODEL
import google.generativeai as genai
import json, re

def get_today_reviews() -> list[dict]:
    """Get notes due for review today (up to daily limit)."""
    return get_notes_due_for_review(limit=SRS_MAX_DAILY_REVIEWS)

def generate_review_quiz(note_content: str, difficulty: str = "medium") -> dict:
    """Auto-generate a review quiz from a note using Gemini."""
    model = genai.GenerativeModel(GENERATION_MODEL)

    difficulty_prompt = {
        "easy": "one straightforward recall question",
        "medium": "two comprehension questions",
        "hard": "three application or synthesis questions",
    }.get(difficulty, "two comprehension questions")

    prompt = f"""Generate {difficulty_prompt} to review the following note.

--- Note ---
{note_content[:1500]}
--- End ---

Return ONLY valid JSON:
{{
  "questions": [
    {{
      "question": "Question text here",
      "answer": "Model answer here"
    }}
  ]
}}"""

    response = model.generate_content(prompt)
    json_match = re.search(r'\{.*\}', response.text, re.DOTALL)
    if json_match:
        return json.loads(json_match.group())
    return {"questions": []}

def update_schedule(note_id: str, recall_quality: int):
    """Update the next review date based on recall quality (0-5 scale).

    0 = Completely forgot, 5 = Perfect recall
    Based on SM-2 algorithm.
    """
    if recall_quality >= 4:
        interval_index = min(5, get_current_interval_index(note_id) + 1)
    elif recall_quality >= 2:
        interval_index = get_current_interval_index(note_id)
    else:
        interval_index = 0  # Reset to beginning

    next_review = datetime.now() + timedelta(days=SRS_INTERVALS_DAYS[interval_index])
    update_review_result(note_id, interval_index, next_review, recall_quality)

    print(f"⏰ Next review: {next_review.strftime('%Y/%m/%d')} "
          f"({SRS_INTERVALS_DAYS[interval_index]} days from now)")
```

## Production Scaling Strategies

### Batch Processing for Regular Re-indexing

```python
# scheduler.py
import asyncio
from pathlib import Path
from datetime import datetime, timedelta
from config import NOTES_DIR
from ingestor import ingest_note
from srs import get_today_reviews

async def daily_maintenance():
    """Run every morning to keep the index fresh."""
    print("🌅 Starting daily maintenance")

    # 1. Re-index only recently modified notes
    recently_updated = [
        p for p in NOTES_DIR.glob("**/*.md")
        if p.stat().st_mtime > (datetime.now() - timedelta(days=1)).timestamp()
    ]
    print(f"  📝 Updated notes: {len(recently_updated)}")
    for note_path in recently_updated:
        ingest_note(note_path)

    # 2. Prepare today's review list
    reviews = get_today_reviews()
    print(f"  📚 Reviews due today: {len(reviews)}")

    print("✅ Daily maintenance complete")

if __name__ == "__main__":
    asyncio.run(daily_maintenance())
```

### Key Performance Optimization Tips

- **Batch embeddings**: The `genai.embed_content` API supports batch requests. Send 100 notes at a time to reduce API calls and latency significantly.
- **Incremental updates**: Compare file `mtime` before re-indexing — only process notes that have actually changed.
- **Embedding cache**: Store generated embeddings by content hash to avoid redundant API calls for unchanged notes.
- **Model selection**: Use `text-embedding-004` for embeddings and `gemini-2.5-flash` for text generation to balance cost and quality.
