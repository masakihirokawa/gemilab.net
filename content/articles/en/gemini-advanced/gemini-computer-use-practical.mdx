# Gemini Computer Use Practical Guide — Form Automation, Data Extraction, and Browser RPA

## Setup and context

Gemini 3's Computer Use feature lets AI read screenshots and autonomously control browser and desktop UIs. But understanding the concept is just the starting point. Building reliable production systems requires proper error handling, timeout management, and verification mechanisms.

This guide transforms Computer Use from concept to business value. You'll learn practical implementation patterns for form automation, multi-site data extraction, and building RPA pipelines that work reliably in production environments.

## Practical Example 1: Web Form Automation System

### Use Case

Imagine a sales team system that reads customer data from CSV and auto-fills a quotation web form. What takes 30 seconds per form manually can be completed in seconds with Computer Use.

### Implementation Code

```python
import anthropic
import base64
import time
from selenium import webdriver
from selenium.webdriver.common.by import By

# Initialize Anthropic client
client = anthropic.Anthropic(api_key="YOUR_GEMINI_API_KEY")

def capture_screenshot(driver):
    """Capture current browser state"""
    screenshot = driver.get_screenshot_as_png()
    return base64.standard_b64encode(screenshot).decode('utf-8')

def fill_form_with_gemini(driver, form_data):
    """Use Computer Use to auto-fill a form"""
    max_steps = 20
    step_count = 0

    while step_count < max_steps:
        screenshot_b64 = capture_screenshot(driver)

        message = client.messages.create(
            model="gemini-2.0-flash",
            max_tokens=1024,
            tools=[
                {
                    "type": "computer_use",
                    "name": "computer",
                    "display_width": 1920,
                    "display_height": 1080,
                }
            ],
            messages=[
                {
                    "role": "user",
                    "content": [
                        {
                            "type": "image",
                            "source": {
                                "type": "base64",
                                "media_type": "image/png",
                                "data": screenshot_b64
                            }
                        },
                        {
                            "type": "text",
                            "text": f"Fill form with: {form_data}"
                        }
                    ]
                }
            ]
        )

        for block in message.content:
            if block.type == "tool_use":
                tool_input = block.input
                if tool_input.get("action") == "click":
                    x, y = tool_input["coordinate"]
                    execute_click(driver, x, y)

        step_count += 1
        time.sleep(0.5)

    return True

def execute_click(driver, x, y):
    """Convert screenshot coordinates to clickable elements"""
    window_width = driver.execute_script("return window.innerWidth")
    window_height = driver.execute_script("return window.innerHeight")
    element = driver.execute_script(
        f"return document.elementFromPoint({int(x * window_width / 1920)}, {int(y * window_height / 1080)})"
    )
    if element:
        driver.execute_script("arguments[0].click();", element)
```

### Key Points

- Wrap Computer Use in loop with max step limits for safety
- Map screenshot coordinates to actual DOM elements using Selenium
- Implement retry logic for error recovery

## Practical Example 2: Multi-Site Data Extraction

### Use Case

Daily competitive price monitoring: extract product prices from 5 competitor websites. Computer Use adapts when HTML structure changes.

### Implementation Flow

```python
def scrape_product_prices(urls, product_name):
    """Extract product prices from multiple sites"""
    results = {}

    for url in urls:
        driver = webdriver.Chrome()
        driver.get(url)
        time.sleep(2)

        message = client.messages.create(
            model="gemini-2.0-flash",
            max_tokens=2048,
            tools=[{"type": "computer_use", "name": "computer", ...}],
            messages=[{
                "role": "user",
                "content": [
                    {
                        "type": "image",
                        "source": {
                            "type": "base64",
                            "media_type": "image/png",
                            "data": capture_screenshot(driver)
                        }
                    },
                    {
                        "type": "text",
                        "text": f"Extract price for {product_name}"
                    }
                ]
            }]
        )

        for block in message.content:
            if block.type == "text" and "$" in block.text:
                results[url] = block.text

        driver.quit()

    return results
```

### Advantages

- **JavaScript Rendering**: Captures dynamic content HTML parsers miss
- **UI Change Resilience**: Works when HTML structure changes
- **Complex Interactions**: Handles dropdowns, popups, conditional flows

## Practical Example 3: Customer Support Diagnostic Bot

### Use Case

When customers report "can't reach page X," Computer Use reproduces the issue automatically.

```python
def diagnose_website_issue(issue_description, target_url):
    """Automatically diagnose website access problems"""
    driver = webdriver.Chrome()
    diagnostic_report = []

    try:
        driver.get(target_url)
        time.sleep(3)

        for iteration in range(5):
            screenshot_b64 = capture_screenshot(driver)

            message = client.messages.create(
                model="gemini-2.0-flash",
                max_tokens=1024,
                tools=[{"type": "computer_use", "name": "computer", ...}],
                messages=[{
                    "role": "user",
                    "content": [
                        {
                            "type": "image",
                            "source": {
                                "type": "base64",
                                "media_type": "image/png",
                                "data": screenshot_b64
                            }
                        },
                        {
                            "type": "text",
                            "text": f"Diagnose: {issue_description}"
                        }
                    ]
                }]
            )

            for block in message.content:
                if block.type == "text":
                    diagnostic_report.append(block.text)

    finally:
        driver.quit()

    return "\n".join(diagnostic_report)
```

## Best Practices: Error Handling and Reliability

### 1. Timeout Management

Always set **max_tokens and max_steps** explicitly.

```python
max_tokens = 2048
max_steps = 15
timeout_seconds = 60

def safe_computer_use_call(max_tokens=2048, max_steps=15, timeout=60):
    """Timeout-aware wrapper"""
    try:
        message = client.messages.create(
            model="gemini-2.0-flash",
            max_tokens=max_tokens,
            tools=[{"type": "computer_use", "name": "computer", ...}],
            messages=[...],
            timeout=timeout
        )
        return message
    except Exception as e:
        print(f"Timeout or error: {e}")
        return None
```

### 2. Operation Verification

Capture a screenshot after each operation to confirm success.

```python
def verify_operation(driver, expected_state):
    """Verify operation succeeded"""
    time.sleep(0.5)
    screenshot = capture_screenshot(driver)

    message = client.messages.create(
        model="gemini-2.0-flash",
        max_tokens=256,
        messages=[{
            "role": "user",
            "content": [
                {
                    "type": "image",
                    "source": {
                        "type": "base64",
                        "media_type": "image/png",
                        "data": screenshot
                    }
                },
                {
                    "type": "text",
                    "text": f"Has this state been achieved? {expected_state}"
                }
            ]
        }]
    )

    return "yes" in message.content[0].text.lower()
```

### 3. Retry Logic

Implement automatic retries with exponential backoff.

```python
def robust_form_fill(driver, form_data, max_retries=3):
    """Auto-retry on failure"""
    for attempt in range(max_retries):
        try:
            result = fill_form_with_gemini(driver, form_data)
            if result:
                return True
        except Exception as e:
            print(f"Attempt {attempt + 1} failed: {e}")
            if attempt < max_retries - 1:
                time.sleep(2 ** attempt)
                driver.refresh()

    return False
```

## Comparison with Other Automation Tools

- **Selenium**: Reliable for defined UI patterns / Struggles with dynamic changes
- **Playwright**: Modern browser automation / No AI decision-making capability
- **Computer Use**: Adapts to UI changes / Handles exceptions / Complex setup

Computer Use's biggest advantage: AI assesses pages visually and makes intelligent decisions, auto-adapting to markup and layout changes.
