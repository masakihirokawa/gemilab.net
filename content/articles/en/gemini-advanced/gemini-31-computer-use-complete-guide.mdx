## What Is Gemini 3.1 Computer Use? A New Paradigm for Automation

**Computer Use** is the ability for an AI to observe a screen — just like a human does — and take actions: mouse clicks, keyboard input, scrolling, navigation. Gemini 3.1 has made substantial accuracy improvements to this capability, bringing it into the range of genuinely useful production automation.

"Gemini 3.1 computer use" consistently ranks among the top search queries on Gemini Lab, which tells us that developers and business users are actively looking for a practical answer to one question: *can I actually use Gemini to automate tasks that interact with real applications and websites?* This guide answers that question directly, with working code.

Gemini 3.1's Computer Use comes in two forms:

**Project Mariner integration** (for Google AI Pro/Ultra subscribers): Cloud-based browser automation that handles tab navigation, form fills, web research, and more — orchestrated by Gemini within the Google ecosystem.

**Computer Use API** (for developers): A programmatic interface where your code captures screenshots, sends them to Gemini 3.1, and receives structured action decisions (click at x,y; type this text; press this key) that your application then executes.

## Why Computer Use Matters Now

Traditional automation tools like Selenium and Playwright are powerful — but they work by parsing HTML structure. Dynamic single-page apps, complex JavaScript UIs, and especially non-browser desktop applications present real challenges for them. Maintaining test suites that target specific DOM selectors is a perpetual battle against UI changes.

Computer Use sidesteps the HTML dependency entirely. Because it operates from visual information, it can, in principle, automate **any application with a screen** — legacy enterprise systems with no APIs, desktop software, mobile emulators, even video games. The trade-off is speed and determinism; the upside is generality.

## Implementing Gemini 3.1 Computer Use

### Core Architecture

```python
# Gemini 3.1 Computer Use — core implementation
# Requirements: pip install google-generativeai pillow pyautogui

import google.generativeai as genai
import base64, json, time, io
from PIL import ImageGrab
import pyautogui

genai.configure(api_key="YOUR_GEMINI_API_KEY")

def capture_screenshot() -> bytes:
    """Capture the current screen as PNG bytes."""
    screenshot = ImageGrab.grab()
    buf = io.BytesIO()
    screenshot.save(buf, format="PNG")
    return buf.getvalue()

def ask_gemini_for_action(
    screenshot_bytes: bytes,
    task: str,
    action_history: list[dict]
) -> dict:
    """
    Send a screenshot to Gemini 3.1 and receive the next action to execute.

    Parameters:
        screenshot_bytes: Raw PNG screenshot data
        task: Natural-language task description
        action_history: Previously executed actions

    Returns:
        Action dict: {type, x, y, text, key, direction, description, reason}
    """
    model = genai.GenerativeModel("gemini-1.5-pro")

    history_text = "\n".join(
        [f"- {a.get('type')}: {a.get('description', '')}" for a in action_history]
    ) or "None (first action)"

    screenshot_b64 = base64.standard_b64encode(screenshot_bytes).decode()

    prompt = f"""
You are an AI agent that controls a computer by observing the screen.
Look at the screenshot and return the NEXT action to complete the task.

## Task
{task}

## Actions Taken So Far
{history_text}

## Response Format (JSON only, no markdown)
{{
  "type": "click" | "type" | "scroll" | "key" | "done" | "error",
  "x": <x-coordinate in pixels>,   // required for type="click"
  "y": <y-coordinate in pixels>,   // required for type="click"
  "text": "<text to type>",         // required for type="type"
  "key": "<key name>",              // required for type="key" (e.g., "enter", "tab")
  "direction": "up" | "down",       // required for type="scroll"
  "amount": <scroll amount>,        // required for type="scroll"
  "description": "<what this action does>",
  "reason": "<why you chose this action>"
}}

Return type="done" when the task is complete.
Return type="error" if the task cannot be completed.
"""

    response = model.generate_content([
        {"inline_data": {"mime_type": "image/png", "data": screenshot_b64}},
        prompt
    ])

    text = response.text.strip()
    if "```json" in text:
        text = text.split("```json")[1].split("```")[0].strip()
    elif "```" in text:
        text = text.split("```")[1].split("```")[0].strip()

    return json.loads(text)

def execute_action(action: dict) -> bool:
    """
    Execute an action returned by Gemini.

    Returns:
        True to continue the loop, False to stop (done or error).
    """
    t = action.get("type")

    if t == "click":
        print(f"  🖱️  Click ({action['x']}, {action['y']}) — {action.get('description', '')}")
        pyautogui.click(action["x"], action["y"])
        time.sleep(0.5)

    elif t == "type":
        print(f"  ⌨️  Type '{action['text']}' — {action.get('description', '')}")
        pyautogui.write(action["text"], interval=0.05)
        time.sleep(0.3)

    elif t == "key":
        print(f"  🔑 Key '{action['key']}' — {action.get('description', '')}")
        pyautogui.press(action["key"])
        time.sleep(0.3)

    elif t == "scroll":
        direction = action.get("direction", "down")
        amount = action.get("amount", 3)
        print(f"  📜 Scroll {direction} {amount} — {action.get('description', '')}")
        pyautogui.scroll(-amount if direction == "down" else amount)
        time.sleep(0.3)

    elif t == "done":
        print(f"  ✅ Task complete: {action.get('description', 'Task completed successfully')}")
        return False

    elif t == "error":
        print(f"  ❌ Error: {action.get('description', 'Unknown error')}")
        return False

    return True

def run_computer_use_agent(task: str, max_steps: int = 20) -> bool:
    """
    Run a Gemini 3.1 Computer Use agent loop.

    Parameters:
        task: Natural-language task description
        max_steps: Maximum steps before stopping

    Returns:
        True if task completed, False otherwise.
    """
    print(f"\n🚀 Task: {task}")
    print("-" * 60)

    action_history = []

    for step in range(max_steps):
        print(f"\n[Step {step + 1}/{max_steps}]")

        screenshot = capture_screenshot()

        try:
            action = ask_gemini_for_action(screenshot, task, action_history)
            print(f"  📋 Decision: {action.get('type')} — {action.get('reason', '')[:100]}")
        except Exception as e:
            print(f"  ❌ Gemini API error: {e}")
            return False

        action_history.append(action)

        if not execute_action(action):
            return action.get("type") == "done"

        time.sleep(1.0)  # Allow UI to settle

    print(f"\n⚠️ Reached maximum step limit ({max_steps})")
    return False

# Example
if __name__ == "__main__":
    success = run_computer_use_agent(
        task="Open Google Chrome, search for 'Gemini 3.1 Computer Use latest news', "
             "and read the titles of the top 3 results.",
        max_steps=10
    )
    print(f"\nResult: {'Success' if success else 'Failed'}")
```

### Browser-Scoped Implementation (Safer Approach)

For most automation use cases, limiting Computer Use to the browser window is safer and more reliable than controlling the full desktop.

```python
# Playwright + Gemini 3.1: browser-scoped Computer Use agent

from playwright.async_api import async_playwright
import asyncio, json, base64
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel("gemini-1.5-pro")

async def browser_agent(task: str, start_url: str = "https://www.google.com"):
    """
    Gemini 3.1 Computer Use agent operating within a browser window.

    Parameters:
        task: Task to perform inside the browser
        start_url: Starting URL
    """
    async with async_playwright() as pw:
        browser = await pw.chromium.launch(headless=False)
        page = await browser.new_page(viewport={"width": 1280, "height": 800})
        await page.goto(start_url)

        history = []

        for step in range(15):
            screenshot = await page.screenshot()
            b64 = base64.standard_b64encode(screenshot).decode()
            history_text = "\n".join([f"- {h}" for h in history]) or "None"

            resp = model.generate_content([
                {"inline_data": {"mime_type": "image/png", "data": b64}},
                f"""
Look at the browser screenshot and determine the next action to complete this task.

Task: {task}
Actions so far: {history_text}
Current URL: {page.url}

Return JSON only:
{{
  "action": "click" | "type" | "navigate" | "scroll" | "done",
  "selector": "<CSS selector>",     // for click / type
  "text": "<text to enter>",        // for type
  "url": "<URL>",                    // for navigate
  "direction": "up" | "down",        // for scroll
  "description": "<action description>"
}}
"""
            ])

            text = resp.text.strip()
            if "```json" in text:
                text = text.split("```json")[1].split("```")[0].strip()
            action = json.loads(text)

            desc = action.get("description", "")
            history.append(f"{action['action']}: {desc}")
            print(f"[Step {step+1}] {action['action']}: {desc}")

            if action["action"] == "click":
                await page.click(action["selector"])
                await page.wait_for_load_state("networkidle")
            elif action["action"] == "type":
                await page.fill(action["selector"], action["text"])
            elif action["action"] == "navigate":
                await page.goto(action["url"])
                await page.wait_for_load_state("networkidle")
            elif action["action"] == "scroll":
                delta = 300 if action.get("direction") == "down" else -300
                await page.mouse.wheel(0, delta)
            elif action["action"] == "done":
                print(f"✅ Complete: {desc}")
                break

            await asyncio.sleep(1.5)

        await browser.close()

# Run
asyncio.run(browser_agent(
    task="Go to gemilab.net and find the titles of the three most recent articles.",
    start_url="https://gemilab.net"
))
```

## Real-World Use Cases

### Competitive Intelligence Automation

### Legacy System Data Entry

### UI Test Automation Without Brittle Selectors

Rather than writing Selenium tests that break every time a class name changes, describe the test in plain English: "Click the Submit button and verify that the success message appears." Computer Use executes it visually.

## Using Computer Use Safely

Computer Use executes real actions with real consequences. Before going to production:

**Test in sandboxed environments first.** Confirm the agent's behavior on a staging or test system before letting it touch production data.

**Implement Human-in-the-Loop validation.** Start with a mode where the agent proposes each action and a human approves before execution. Graduate to full automation once you trust the agent's decision-making in your specific context.

**Restrict the operational scope.** Constrain the agent to specific applications or URLs, and reject any actions outside those boundaries in code — not just in prompting.

## FAQ

**Q1: How does Gemini 3.1 Computer Use compare to Anthropic's Computer Use?**

Both use the same core pattern: screenshot → model → action decision. The key differences are Google's deeper integration with its own ecosystem (Workspace, Android, Pixel) and the safety filtering built into Project Mariner for browser operations. Anthropic's version is generally praised for reasoning depth; Gemini's strengths lie in Google ecosystem integration and multimodal speed.

**Q2: Which Gemini model supports Computer Use?**

Gemini 1.5 Pro and Gemini 3.1 Pro support Computer Use via the API. Project Mariner's browser automation is included in the Google AI Ultra subscription.

**Q3: How is Computer Use priced?**

API usage is billed on Gemini API standard rates — input token count plus image size for each screenshot you send. Project Mariner browser automation is included in Google AI Ultra. High-frequency automation loops (many screenshots per minute) can accumulate costs quickly, so batch or throttle where possible.

**Q4: How well does it handle non-English UIs?**

Gemini 3.1 has strong visual text recognition for Japanese and other major languages. Japanese UI elements — buttons, menus, form labels — are reliably understood. Very small text, unusual fonts, or low-contrast UI elements may reduce accuracy, so design prompts that guide the agent to interact with visually prominent, well-labeled elements where possible.
