## Introduction — AI That Can See, Hear, and Read

If your mental model of AI is still "I type something, it writes something back," it's worth updating. Gemini processes text, images, video, audio, and PDFs — not in separate specialized modes, but as a unified model that understands and reasons across all of them simultaneously.

This changes what's possible in meaningful ways. You can hand Gemini an hour-long meeting recording and ask it to extract action items with timestamps. You can pass multiple product photos and ask for a comparative analysis. You can upload a hundred-page contract as a PDF and ask it to flag clauses that create liability.

This guide covers the practical implementation patterns for each modality, with working Python code and real-world use cases. The goal is to give you a solid foundation for building multimodal workflows, not just an overview of what's theoretically possible.

## What Gemini Supports

Gemini 1.5 Pro and Flash handle the following input types:

Text (all languages), images (JPEG, PNG, WebP, HEIC, HEIF), video (MP4, MPEG, MOV, AVI, FLV, MPG, WebM, WMV, 3GPP), audio (WAV, MP3, AIFF, AAC, OGG, FLAC), PDFs, and code.

## Image Understanding

### Comparative Analysis Across Multiple Images

Gemini can receive and analyze multiple images in a single request — useful for product comparison, before/after evaluation, or visual quality control.

```python
import google.generativeai as genai

def compare_product_images(image_paths: list[str], comparison_criteria: str) -> str:
    """Analyze multiple product images comparatively."""
    
    model = genai.GenerativeModel('gemini-1.5-pro')
    
    uploaded_images = []
    for path in image_paths:
        file = genai.upload_file(path)
        uploaded_images.append(file)
    
    content = uploaded_images + [
        f"""Compare these images across the following dimensions:
{comparison_criteria}

For each dimension, describe what you observe in each image specifically, 
then provide a comparative summary."""
    ]
    
    response = model.generate_content(content)
    return response.text

# Example usage
image_files = ["product_a.jpg", "product_b.jpg", "product_c.jpg"]
criteria = """
1. Design sophistication and visual quality
2. Functionality communicated through visuals
3. Appeal to target audience (young professionals)
4. Brand consistency and memorability
"""

analysis = compare_product_images(image_files, criteria)
```

### Document Structure Extraction

Beyond reading text in images (basic OCR), Gemini understands document structure — sections, tables, forms, and the relationships between elements.

```python
def analyze_document_image(image_path: str) -> dict:
    """Extract structured information from a document image."""
    
    model = genai.GenerativeModel('gemini-1.5-pro')
    image_file = genai.upload_file(image_path)
    
    response = model.generate_content([
        image_file,
        """Analyze this document image and return structured data:
1. Document type (invoice, contract, report, form, etc.)
2. Key extracted data (dates, amounts, parties, IDs)
3. Document structure (sections, tables, charts present)
4. Important findings or flags

Return as JSON."""
    ])
    
    import json
    text = response.text
    if "```json" in text:
        json_str = text.split("```json")[1].split("```")[0].strip()
    else:
        json_str = text
    
    try:
        return json.loads(json_str)
    except:
        return {"raw_analysis": text}
```

## Video Understanding

### Long-Form Video Summarization

Gemini 1.5 Pro can process up to one hour of video in a single request. Meeting recordings, lectures, product demos — all processable in one call.

```python
import time

def summarize_video(video_path: str) -> dict:
    """Generate a structured summary of a video."""
    
    model = genai.GenerativeModel('gemini-1.5-pro')
    
    print(f"Uploading video: {video_path}")
    video_file = genai.upload_file(video_path)
    
    while video_file.state.name == "PROCESSING":
        print("Processing...")
        time.sleep(5)
        video_file = genai.get_file(video_file.name)
    
    if video_file.state.name == "FAILED":
        raise ValueError("Video upload failed")
    
    print("Analyzing...")
    response = model.generate_content([
        video_file,
        """Analyze this video and provide:

1. Overview (3-5 sentences)
2. Key topics with timestamps (format: MM:SS)
3. Important statements or key points (bullet list)
4. Action items or next steps if any
5. Overall assessment

Use MM:SS format for all timestamps."""
    ])
    
    return {"summary": response.text}
```

## Cross-Modal Integration

### Combining Text, Image, and Audio

The most powerful patterns combine modalities in a single analysis:

```python
def cross_modal_analysis(
    text_context: str,
    image_path: str | None = None,
    audio_path: str | None = None
) -> str:
    """Unified analysis combining text, image, and audio inputs."""
    
    model = genai.GenerativeModel('gemini-1.5-pro')
    content = []
    
    if text_context:
        content.append(f"Context:\n{text_context}\n")
    
    if image_path:
        image_file = genai.upload_file(image_path)
        content.append(image_file)
        content.append("(Regarding the image above)\n")
    
    if audio_path:
        audio_file = genai.upload_file(audio_path)
        content.append(audio_file)
        content.append("(Regarding the audio above)\n")
    
    content.append("""
Integrate all provided inputs (text, image, audio as applicable) and analyze:
1. Key information from each modality
2. Points of agreement and contradiction across modalities
3. New insights that emerge from combining sources
4. Overall conclusions and recommendations""")
    
    response = model.generate_content(content)
    return response.text
```

### Streaming for Long Media

For long videos or audio files, streaming gives users real-time feedback while processing:

```python
def stream_video_analysis(video_path: str, question: str):
    """Analyze a video with streaming output."""
    
    model = genai.GenerativeModel('gemini-1.5-pro')
    video_file = genai.upload_file(video_path)
    
    while video_file.state.name == "PROCESSING":
        time.sleep(5)
        video_file = genai.get_file(video_file.name)
    
    print("Analysis (streaming):")
    
    response = model.generate_content(
        [video_file, question],
        stream=True
    )
    
    for chunk in response:
        print(chunk.text, end="", flush=True)
    
    print()
```

## PDF and Document Processing

### Long Document Analysis

Gemini 1.5 Pro processes PDFs up to approximately 1,000 pages, making it practical for legal documents, research papers, and annual reports:

```python
def analyze_pdf_document(pdf_path: str, analysis_type: str) -> str:
    """Analyze a PDF with a specific focus."""
    
    model = genai.GenerativeModel('gemini-1.5-pro')
    pdf_file = genai.upload_file(pdf_path, mime_type="application/pdf")
    
    analysis_prompts = {
        "executive_summary": "Write an executive summary of this document focused on key decisions and strategic implications.",
        "key_metrics": "Extract all numerical data, KPIs, and metrics from this document. Present in table format.",
        "risk_analysis": "Identify all risks, challenges, and concerns mentioned. Rank by apparent severity.",
        "action_items": "Extract all action items, owners, and deadlines mentioned in this document."
    }
    
    prompt = analysis_prompts.get(analysis_type, f"Analyze this document from the perspective of: {analysis_type}")
    
    response = model.generate_content([pdf_file, prompt])
    return response.text
```

## Model Selection and Cost Management

### Choosing the Right Model

Matching model to task keeps costs reasonable without sacrificing quality where it matters:

```python
def smart_model_selector(task_complexity: str, file_size_mb: float) -> str:
    """Select the appropriate model based on task complexity and file size."""
    
    if task_complexity == "high" or file_size_mb > 100:
        return "gemini-1.5-pro"   # Full capability for complex tasks
    elif task_complexity == "low" and file_size_mb < 5:
        return "gemini-1.5-flash"  # Speed and cost for simple tasks
    else:
        return "gemini-1.5-pro"   # Default to Pro when uncertain
```

For routing tasks (classification, short analysis), Flash is significantly cheaper and faster. For synthesis, reasoning, and long-document work, Pro is the reliable choice.
