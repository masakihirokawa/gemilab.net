## Introduction

**Deno** is a modern TypeScript runtime gaining traction as a compelling alternative to Node.js. Its native TypeScript support, built-in security model, and zero-configuration deployment make it an excellent choice for building AI-powered applications.

What you'll learn:

- How to integrate Gemini API with Deno
- Implementing streaming responses
- Handling multimodal inputs (images and PDFs)
- Deploying globally with Deno Deploy

This guide assumes basic TypeScript knowledge. If you're new to Gemini API, we recommend starting with the [Gemini API Quickstart](/en/articles/gemini-api/gemini-api-quickstart) first.

## What is Deno? Differences from Node.js

Deno was created by Ryan Dahl — the original creator of Node.js — as a reimagined runtime that addresses Node.js's shortcomings. Here are the key advantages for AI app development:

**Key benefits of Deno**:

- **Native TypeScript support**: Run `.ts` files directly — no `tsc` or `ts-node` needed
- **Built-in security model**: File, network, and environment variable access requires explicit permission
- **npm compatibility**: Use npm packages with the `npm:` prefix
- **Deno Deploy**: Zero-configuration global deployment with GitHub integration
- **Rich standard library**: Built-in HTTP, testing, crypto, and more

The biggest difference from Node.js is that **TypeScript just works** — no `package.json`, `tsconfig.json`, or `node_modules`. This makes Deno ideal for rapid AI prototyping.

## Step 1: Basic Text Generation

Let's start with a simple text generation example:

```typescript
// main.ts
import { GoogleGenerativeAI } from "npm:@google/generative-ai";

// Retrieve API key from environment
const apiKey = Deno.env.get("GEMINI_API_KEY");
if (!apiKey) {
  throw new Error("GEMINI_API_KEY is not set");
}

const genAI = new GoogleGenerativeAI(apiKey);
const model = genAI.getGenerativeModel({ model: "gemini-2.5-flash" });

async function generateText(prompt: string): Promise<string> {
  const result = await model.generateContent(prompt);
  const response = await result.response;
  return response.text();
}

// Example usage
const text = await generateText(
  "List three benefits of using Deno with TypeScript for AI app development."
);
console.log(text);
```

Run the script:

```bash
# Load .env file and grant required permissions
deno run --allow-env --allow-net --env-file=.env main.ts
```

Expected output:

```
1. Native TypeScript support eliminates the need for build configuration...
2. The built-in security model provides fine-grained control over...
3. Deno Deploy enables zero-configuration global deployment...
```

## Step 2: Streaming Responses

For longer content generation, streaming dramatically improves user experience:

```typescript
// streaming.ts
import { GoogleGenerativeAI } from "npm:@google/generative-ai";

const genAI = new GoogleGenerativeAI(Deno.env.get("GEMINI_API_KEY")!);
const model = genAI.getGenerativeModel({ model: "gemini-2.5-flash" });

async function streamText(prompt: string): Promise<void> {
  console.log("Generating...\n");

  // Use generateContentStream for streaming output
  const streamResult = await model.generateContentStream(prompt);

  for await (const chunk of streamResult.stream) {
    const text = chunk.text();
    // Write each chunk immediately without buffering
    Deno.stdout.writeSync(new TextEncoder().encode(text));
  }

  console.log("\n\n✅ Generation complete");
}

await streamText(
  "Explain five real-world use cases for AI apps built with Gemini API and TypeScript."
);
```

To expose streaming as an HTTP endpoint using Deno's built-in server:

```typescript
// server.ts — HTTP streaming server
import { GoogleGenerativeAI } from "npm:@google/generative-ai";

const genAI = new GoogleGenerativeAI(Deno.env.get("GEMINI_API_KEY")!);
const model = genAI.getGenerativeModel({ model: "gemini-2.5-flash" });

Deno.serve({ port: 8000 }, async (req: Request): Promise<Response> => {
  if (req.method !== "POST" || new URL(req.url).pathname !== "/generate") {
    return new Response("Not Found", { status: 404 });
  }

  const { prompt } = await req.json() as { prompt: string };

  // Return a ReadableStream for streaming responses
  const stream = new ReadableStream({
    async start(controller) {
      const encoder = new TextEncoder();
      const streamResult = await model.generateContentStream(prompt);

      for await (const chunk of streamResult.stream) {
        controller.enqueue(encoder.encode(chunk.text()));
      }
      controller.close();
    },
  });

  return new Response(stream, {
    headers: {
      "Content-Type": "text/plain; charset=utf-8",
      "Transfer-Encoding": "chunked",
    },
  });
});

console.log("Server running at http://localhost:8000");
```

```bash
# Start the server
deno run --allow-env --allow-net --env-file=.env server.ts

# Test with curl (separate terminal)
curl -X POST http://localhost:8000/generate \
  -H "Content-Type: application/json" \
  -d '{"prompt": "What are Deno'\''s main features?"}' \
  --no-buffer
```

## Step 3: Multimodal — Image Analysis

Deno makes it straightforward to work with Gemini's multimodal capabilities:

```typescript
// vision.ts — Analyze an image file
import { GoogleGenerativeAI } from "npm:@google/generative-ai";

const genAI = new GoogleGenerativeAI(Deno.env.get("GEMINI_API_KEY")!);
const model = genAI.getGenerativeModel({ model: "gemini-2.5-flash" });

async function analyzeImage(
  imagePath: string,
  question: string
): Promise<string> {
  // Read and Base64-encode the image
  const imageData = await Deno.readFile(imagePath);
  const base64Image = btoa(String.fromCharCode(...imageData));

  // Determine MIME type from extension
  const ext = imagePath.split(".").pop()?.toLowerCase() ?? "jpeg";
  const mimeMap: Record<string, string> = {
    jpg: "image/jpeg",
    jpeg: "image/jpeg",
    png: "image/png",
    webp: "image/webp",
    gif: "image/gif",
  };
  const mimeType = mimeMap[ext] ?? "image/jpeg";

  const result = await model.generateContent([
    {
      inlineData: {
        data: base64Image,
        mimeType,
      },
    },
    { text: question },
  ]);

  return result.response.text();
}

// Usage
const description = await analyzeImage(
  "./sample.png",
  "Describe what you see in this image in detail."
);
console.log(description);
```

```bash
deno run --allow-env --allow-net --allow-read --env-file=.env vision.ts
```

## Step 4: Deploying to Deno Deploy

Deno Deploy lets you push to GitHub and go live globally in seconds.

### Project Structure

```
my-gemini-app/
├── main.ts          ← Entry point
├── deno.json        ← Configuration and task runner
└── .github/
    └── workflows/
        └── deploy.yml
```

### deno.json

```json
{
  "tasks": {
    "dev": "deno run --allow-env --allow-net --env-file=.env main.ts",
    "start": "deno run --allow-env --allow-net main.ts"
  },
  "imports": {
    "@google/generative-ai": "npm:@google/generative-ai@^0.24.0"
  }
}
```

With import maps configured in `deno.json`, you can use cleaner imports:

```typescript
import { GoogleGenerativeAI } from "@google/generative-ai";
```

### Deployment Steps

1. Create an account at [deno.com/deploy](https://deno.com/deploy)
2. Click "New Project" and connect your GitHub repository
3. Set the entry point to `main.ts`
4. Add the `GEMINI_API_KEY` environment variable
5. Deploy — done in about 30 seconds

Your app becomes available at `https://your-project.deno.dev`. With edge execution, your Gemini-powered app responds with minimal latency to users worldwide.

## Common Errors and Fixes

**Error 1: `Requires net access`**

```
error: Requires net access to "generativelanguage.googleapis.com"
```

Fix: Add the `--allow-net` flag. For tighter security, specify the exact domain:

```bash
deno run --allow-net=generativelanguage.googleapis.com main.ts
```

**Error 2: `Requires env access`**

Environment variable access requires `--allow-env`. To restrict to a specific variable:

```bash
deno run --allow-env=GEMINI_API_KEY main.ts
```

**Error 3: npm package cache errors**

```bash
# Clear the Deno cache
deno clean
# Re-run
deno run --allow-env --allow-net main.ts
```

## Advanced: Multi-Turn Chat

Here's how to maintain conversation history in Deno:

```typescript
// chat.ts — Stateful chat session
import { GoogleGenerativeAI } from "npm:@google/generative-ai";

const genAI = new GoogleGenerativeAI(Deno.env.get("GEMINI_API_KEY")!);
const model = genAI.getGenerativeModel({
  model: "gemini-2.5-flash",
  systemInstruction: "You are a helpful AI assistant. Keep responses concise.",
});

// Start a chat session
const chat = model.startChat({
  history: [],
  generationConfig: {
    maxOutputTokens: 1024,
    temperature: 0.7,
  },
});

async function sendMessage(message: string): Promise<string> {
  const result = await chat.sendMessage(message);
  return result.response.text();
}

// Sample conversation
console.log(await sendMessage("What is type inference in TypeScript?"));
console.log(await sendMessage("Can you give a concrete example?"));
console.log(await sendMessage("Great, can you summarize the key points?"));
```

## FAQ

**Q: Should I use Deno or Node.js for Gemini API projects?**

A: If you're integrating into an existing Node.js project, Node.js is the natural choice. For new projects where you want native TypeScript support and easy serverless deployment, Deno is excellent. The combination of Deno + Deno Deploy is particularly powerful for globally distributed AI apps.

**Q: Can I use JSR instead of `npm:@google/generative-ai`?**

A: The Google Generative AI SDK is currently published on npm. Using the `npm:` prefix in Deno works seamlessly. There's no official JSR package at this time, so stick with `npm:@google/generative-ai`.

**Q: How do I manage environment variables on Deno Deploy?**

A: In the Deno Deploy dashboard, navigate to "Settings → Environment Variables" to securely store secrets. Always use `Deno.env.get("GEMINI_API_KEY")` in your code — never hardcode API keys.

**Q: How does Deno Deploy compare to Cloudflare Workers?**

A: Both are edge computing platforms, but Deno Deploy offers higher npm compatibility and a gentler learning curve for developers familiar with TypeScript. For Cloudflare Workers implementations, see the [Gemini API × Hono + Cloudflare Edge AI Guide](/en/articles/gemini-api/gemini-api-hono-cloudflare-edge-ai-guide).
