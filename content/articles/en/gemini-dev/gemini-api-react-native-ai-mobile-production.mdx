Network latency, battery life, memory limitations—these constraints shape everything. How do you deliver that smooth, trustworthy AI experience users expect to rely on daily?

React Native combined with Expo and Gemini API provides a powerful foundation for cross-platform iOS/Android development. This guide takes you beyond "it works" to production-ready AI mobile applications, with practical code examples throughout.

- Secure integration patterns for Gemini API in Expo environments

```typescript
import { useState, useEffect } from "react";
import * as Network from "expo-network";

export const useNetwork = () => {
  const [isOnline, setIsOnline] = useState(true);
  const [connectionType, setConnectionType] = useState<string | null>(null);

  useEffect(() => {
    let subscription: any;

    const checkNetwork = async () => {
      const state = await Network.getNetworkStateAsync();
      setIsOnline(state.isInternetReachable ?? false);
      setConnectionType(state.type);
    };

    checkNetwork();

    if (Network.addEventListener) {
      subscription = Network.addEventListener("networkStateChange", (state) => {
        setIsOnline(state.isInternetReachable ?? false);
        setConnectionType(state.type);
      });
    }

    return () => {
      if (subscription) subscription.remove();
    };
  }, []);

  return { isOnline, connectionType };
};
```

## Streaming Chat UI

### Gemini Streaming Integration

`src/services/geminiService.ts`:

```typescript
import { getGeminiModel, createChatSession } from "../config/gemini";

interface Message {
  id: string;
  role: "user" | "model";
  text: string;
  timestamp: Date;
  isStreaming?: boolean;
}

export const sendMessageWithStreaming = async (
  userMessage: string,
  onChunk: (chunk: string) => void,
  onComplete: (fullResponse: string) => void,
  onError: (error: string) => void
): Promise<void> => {
  try {
    const model = getGeminiModel();
    const chat = createChatSession(
      model,
      "You are a helpful AI assistant. Be concise and friendly."
    );

    const stream = await chat.sendMessageStream(userMessage);

    let fullResponse = "";

    // Process streaming chunks as they arrive
    for await (const chunk of stream.stream) {
      const chunkText =
        chunk.candidates?.[0]?.content?.parts[0]?.text || "";

      if (chunkText) {
        fullResponse += chunkText;
        onChunk(chunkText); // Real-time UI update
      }
    }

    onComplete(fullResponse || "");
  } catch (error) {
    const errorMessage =
      error instanceof Error ? error.message : "Network error occurred";
    onError(errorMessage);
  }
};

export const generateMessageId = (): string => {
  return `msg_${Date.now()}_${Math.random().toString(36).substr(2, 9)}`;
};
```

### Cache Service

`src/services/cacheService.ts`:

```typescript
import AsyncStorage from "@react-native-async-storage/async-storage";

interface CacheEntry {
  id: string;
  userMessage: string;
  modelResponse: string;
  timestamp: number;
  hasSynced: boolean;
}

const CACHE_KEY = "gemini_chat_cache";
const SYNC_QUEUE_KEY = "gemini_sync_queue";

export const saveChatToCache = async (
  message: CacheEntry
): Promise<void> => {
  try {
    const cache = await getCacheData();
    cache.push(message);

    // Keep latest 100 messages
    const limitedCache = cache.slice(-100);

    await AsyncStorage.setItem(CACHE_KEY, JSON.stringify(limitedCache));
  } catch (error) {
    console.error("Cache save error:", error);
  }
};

export const getCacheData = async (): Promise<CacheEntry[]> => {
  try {
    const data = await AsyncStorage.getItem(CACHE_KEY);
    return data ? JSON.parse(data) : [];
  } catch (error) {
    console.error("Cache read error:", error);
    return [];
  }
};

export const addToSyncQueue = async (
  message: CacheEntry
): Promise<void> => {
  try {
    const queue = await getSyncQueue();
    queue.push(message);
    await AsyncStorage.setItem(SYNC_QUEUE_KEY, JSON.stringify(queue));
  } catch (error) {
    console.error("Sync queue error:", error);
  }
};

export const getSyncQueue = async (): Promise<CacheEntry[]> => {
  try {
    const data = await AsyncStorage.getItem(SYNC_QUEUE_KEY);
    return data ? JSON.parse(data) : [];
  } catch (error) {
    return [];
  }
};

export const clearSyncQueue = async (): Promise<void> => {
  try {
    await AsyncStorage.removeItem(SYNC_QUEUE_KEY);
  } catch (error) {
    console.error("Clear queue error:", error);
  }
};

export const syncOfflineMessages = async (
  syncFunction: (message: CacheEntry) => Promise<void>
): Promise<void> => {
  const queue = await getSyncQueue();

  for (const message of queue) {
    try {
      await syncFunction(message);
      const cache = await getCacheData();
      const updatedCache = cache.map((c) =>
        c.id === message.id ? { ...c, hasSynced: true } : c
      );
      await AsyncStorage.setItem(CACHE_KEY, JSON.stringify(updatedCache));
    } catch (error) {
      console.error(`Sync failed for message ${message.id}:`, error);
    }
  }

  await clearSyncQueue();
};
```

```typescript
import { useEffect, useState } from "react";
import { useNetwork } from "./useNetwork";
import { getSyncQueue, syncOfflineMessages } from "../services/cacheService";

export const useGeminiChat = () => {
  const { isOnline } = useNetwork();
  const [isSyncing, setIsSyncing] = useState(false);

  useEffect(() => {
    if (isOnline && !isSyncing) {
      performSync();
    }
  }, [isOnline]);

  const performSync = async () => {
    const queue = await getSyncQueue();
    if (queue.length === 0) return;

    setIsSyncing(true);
    try {
      await syncOfflineMessages(async (message) => {
        // Backend sync logic
        console.log("Syncing message:", message.id);
      });
    } catch (error) {
      console.error("Sync error:", error);
    } finally {
      setIsSyncing(false);
    }
  };

  return { isOnline, isSyncing };
};
```

```typescript
const BACKGROUND_SYNC_TASK = "background-message-sync";

  }

export const setupBackgroundSync = async () => {
  try {
    await BackgroundFetch.registerTaskAsync(BACKGROUND_SYNC_TASK, {
      minimumInterval: 60 * 15, // 15 minutes
      stopOnTerminate: false,
      startOnBoot: true,
    });
  } catch (error) {
    console.error("Background task error:", error);
  }
```

## FAQ

### Q: What happens to chats created offline?

A: They're automatically saved to AsyncStorage and synced via the sync queue when connectivity returns. The `useGeminiChat` hook monitors `isOnline` and triggers `performSync()` automatically.

### Q: How do I handle large message histories?

A: Use `FlatList` virtualization to render only visible messages. AsyncStorage cache is limited to the latest 100 messages. For longer histories, implement server-side storage with pagination.

### Q: How should I compress images before sending?

A: Use `compressImage()` with a target width of 800px and quality 0.7. This significantly reduces API latency and battery consumption while maintaining visual quality.

### Q: What's the Gemini API pricing?

A: As of 2024, the free tier includes 60 requests per minute. Production apps use pay-as-you-go pricing: Images/Videos at $0.075 per 1000, Text at $0.075 per 1M tokens. Check [Google AI Studio](https://aistudio.google.com/app/apikey) for current rates.

### Q: How do I add push notifications?

A: Install `expo-notifications` and implement user opt-in explicitly. App Store requires clear notification purpose. Spam notifications cause review rejection.

### Q: Why doesn't background sync work on Android?

A: Doze mode and device battery optimization can interfere. Test on physical devices before submission. Ensure `startOnBoot` is enabled in your EAS build configuration.

React Native with Expo and Gemini API is a powerful combination for cross-platform AI mobile development. Production success comes from understanding mobile constraints and building with user experience at the center.

3. **Multimodal Input** — Combine camera with Gemini Vision for image recognition
4. **Offline-First Design** — Cache responses in AsyncStorage with automatic sync on network recovery
5. **Mobile-First Performance** — Virtual lists, battery optimization, and bundle size management

The difference between a "working" app and a "loved" app lies in these details. Users notice smooth streaming, fast responses, offline reliability, and battery efficiency. Build with care, test on real devices, and launch an AI mobile experience the world will want to use.
