Gemini Code Assist brings AI-powered coding directly into VS Code, but authentication hiccups and configuration issues can prevent it from working properly. This guide covers the most common problems and exactly how to fix them.

## Installation and Authentication Errors

**"Sign in failed" or "OAuth error"**

If Google sign-in fails, open the VS Code Command Palette (`Ctrl+Shift+P` or `Cmd+Shift+P` on Mac) and run "Gemini: Sign In." If the OAuth popup doesn't appear, disable your browser's popup blocker temporarily and try again.

For Google Workspace (enterprise) accounts, your IT administrator may have restricted access to Google Cloud APIs. In that case, you'll need to request approval to use Gemini Code Assist within your organization.

**API not enabled**

Visit [Google Cloud Console](https://console.cloud.google.com) and verify that the "Cloud AI Companion API" is enabled for your project. If it isn't, click "Enable API" and wait a minute before retrying.

## Code Completion Not Showing Up

Work through these steps in order if inline suggestions aren't appearing:

**Update the extension**

Open the Extensions panel in VS Code, search for "Gemini Code Assist," and make sure it's up to date. Older versions may have bugs that have since been fixed.

**Check settings.json**

Make sure your VS Code settings include:
```json
{
  "editor.inlineSuggest.enabled": true,
  "gemini.codeAssist.enable": true
}
```

**Verify language support**

Gemini Code Assist supports Python, JavaScript, TypeScript, Go, Java, C/C++, and more. If you're working in an unsupported language, completions won't appear. Check the language mode shown in the VS Code status bar at the bottom right.

## Outline Feature Not Generating

The Outline assist feature provides a structural overview of your code, but it needs to be properly configured.

**Enable Outline assist**

Run "Gemini: Show Code Outline" from the Command Palette. For persistent access, add this to settings.json:
```json
{
  "gemini.codeAssist.outline.enabled": true
}
```

**Supported file types**

Outline works with Python, JavaScript, TypeScript, Java, and Go files. It won't generate for Markdown, JSON, or configuration files.

**Generation stops mid-way**

Very large files (1,000+ lines) can cause the outline generation to stall. Try extracting just the section you want outlined into a temporary file, or break your file into smaller modules.

## Quota Exceeded (429 Error)

If you see "Quota exceeded" or a 429 error, you've hit your usage limit.

**Understanding Free Tier limits**

The free tier includes limits on requests per minute (RPM) and daily token usage. When you hit the limit, wait a few minutes and try again, or consider upgrading to a paid tier.

**Managing your usage**

In [Google AI Studio](https://aistudio.google.com), you can view your current usage and set project-level spend caps to prevent unexpected overages. This is especially useful for teams sharing a single project.

## Slow Response Times

**Network and VPN issues**

Gemini Code Assist communicates with Google Cloud APIs, so your network connection quality matters. If you're on a VPN, try temporarily disabling it to see if response times improve.

**Extension conflicts**

Running multiple AI coding assistants simultaneously (GitHub Copilot, Codeium, etc.) can cause instability. Try disabling other AI extensions while using Gemini Code Assist to rule out conflicts.

## When All Else Fails

If none of the above resolves your issue, try this reset sequence:
1. Uninstall Gemini Code Assist from VS Code
2. Clear VS Code's extension cache
3. Restart VS Code
4. Reinstall the extension fresh

For persistent issues, [Google Cloud Support](https://cloud.google.com/support) can help, especially for enterprise accounts with specific authentication requirements.
