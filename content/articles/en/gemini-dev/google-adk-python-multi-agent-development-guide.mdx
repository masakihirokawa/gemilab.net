## What Is Google ADK — The New Standard for AI Agent Development

Google Agent Development Kit (ADK) is an open-source framework for building AI agents powered by the Gemini API. Its ecosystem has expanded rapidly in 2026, and the Python SDK in particular has gained strong traction in data science and workflow automation.

What makes ADK stand out is how straightforward it is to implement **multi-agent architectures where multiple specialized agents collaborate on a single task**. For example, you can chain a research agent, an analysis agent, and a report-writing agent to automate everything from data gathering to final document generation — all in just a few dozen lines of code.

This guide walks through the design and implementation of multi-agent systems using ADK's Python SDK, with practical code examples you can adapt for your own projects.

## Multi-Agent Architecture Basics

ADK's multi-agent system follows a hierarchical structure where a **parent agent (Orchestrator)** delegates tasks to **child agents (Sub-agents)**.

Here's the simplest possible multi-agent setup:

```python
from google.adk.agents import Agent

# --- Child agent: Research specialist ---
research_agent = Agent(
    name="research_agent",
    model="gemini-3.1-pro",
    instruction="""
    You are a research specialist.
    When given a topic, compile at least 5 key points
    and report your findings in a structured format.
    """,
)

# --- Child agent: Summary specialist ---
summary_agent = Agent(
    name="summary_agent",
    model="gemini-3.1-flash",
    instruction="""
    You are a summarization specialist.
    Condense the provided information into a concise summary
    of no more than 150 words. Maintain technical accuracy
    while keeping the language accessible.
    """,
)

# --- Parent agent: Orchestrator ---
orchestrator = Agent(
    name="orchestrator",
    model="gemini-3.1-pro",
    instruction="""
    You are the team leader.
    Route user requests to the appropriate agent:
    - For information gathering, delegate to research_agent
    - For summarization, delegate to summary_agent
    Compile and deliver the final response yourself.
    """,
    sub_agents=[research_agent, summary_agent],
)
```

Simply pass child agents to the `sub_agents` parameter, and the parent agent will automatically delegate tasks based on context. No complex routing logic required.

## Building Agents with Custom Tools

Real-world agents need tools — connections to external APIs, databases, and services. ADK lets you register plain Python functions as tools.

```python
from google.adk.agents import Agent
import json
from datetime import datetime

# --- Tool definitions ---
def get_current_weather(city: str) -> dict:
    """Get the current weather for a specified city.

    Args:
        city: The city name to get weather for (e.g., "Tokyo", "London")

    Returns:
        A dictionary containing weather information
    """
    # In a real app, call a weather API here
    weather_data = {
        "city": city,
        "temperature": 18,
        "condition": "Clear",
        "humidity": 45,
        "timestamp": datetime.now().isoformat(),
    }
    return weather_data


def search_database(query: str, limit: int = 5) -> list:
    """Search the internal database.

    Args:
        query: Search keyword
        limit: Maximum number of results to return (default: 5)

    Returns:
        A list of search results
    """
    # In a real app, execute a database query here
    return [
        {"id": 1, "title": f"Report on {query}", "relevance": 0.95},
        {"id": 2, "title": f"Analysis of {query}", "relevance": 0.87},
    ]


# --- Agent with tools ---
data_agent = Agent(
    name="data_agent",
    model="gemini-3.1-pro",
    instruction="""
    You are a data collection agent.
    Use the available tools to gather information
    and report your findings to the user.
    """,
    tools=[get_current_weather, search_database],
)
```

The key detail here is writing thorough **docstrings and type hints**. ADK parses these to construct Function Calling definitions for Gemini, so incomplete descriptions will cause the agent to misuse or ignore the tool entirely.

## Practical Example: Research → Analysis → Report Pipeline

Let's build a more realistic multi-agent pipeline where three specialized agents process tasks sequentially to generate a final report.

```python
from google.adk.agents import Agent, SequentialAgent

# --- 1. Research agent ---
researcher = Agent(
    name="researcher",
    model="gemini-3.1-pro",
    instruction="""
    You are a technology research expert.
    For the given topic, compile findings covering:
    1. Current landscape overview
    2. Key technologies and tools
    3. Advantages and disadvantages
    4. Latest trends
    Output your findings in JSON format.
    """,
    output_key="research_result",
)

# --- 2. Analysis agent ---
analyst = Agent(
    name="analyst",
    model="gemini-3.1-pro",
    instruction="""
    You are a data analyst.
    Based on research_result, provide:
    - Market growth potential (high/medium/low)
    - Implementation difficulty (high/medium/low)
    - Recommendation score (1-10)
    - Three specific use case scenarios
    Output in JSON format.
    """,
    output_key="analysis_result",
)

# --- 3. Report generation agent ---
reporter = Agent(
    name="reporter",
    model="gemini-3.1-flash",
    instruction="""
    You are a business report writer.
    Using research_result and analysis_result,
    create a concise executive summary (approximately 400 words).
    Use headings, bullet points, and data effectively.
    """,
)

# --- Sequential execution pipeline ---
pipeline = SequentialAgent(
    name="report_pipeline",
    sub_agents=[researcher, analyst, reporter],
)
```

`SequentialAgent` ensures agents execute in the defined order. Each agent's `output_key` stores its results, which downstream agents can automatically access.

## Running Agents and Managing Sessions

Here's how to execute the pipeline you've built:

```python
from google.adk.runners import Runner
from google.adk.sessions import InMemorySessionService
from google.genai import types

# Initialize the session service
session_service = InMemorySessionService()

# Create a runner
runner = Runner(
    agent=pipeline,  # The pipeline defined above
    app_name="tech_report_generator",
    session_service=session_service,
)

# Create a session
session = session_service.create_session(
    app_name="tech_report_generator",
    user_id="user-001",
)

# User input
user_message = types.Content(
    role="user",
    parts=[types.Part(text="Research the current state and future of multi-agent systems using the Gemini API")],
)

# Execute with streaming
async def run_pipeline():
    async for event in runner.run_async(
        user_id="user-001",
        session_id=session.id,
        new_message=user_message,
    ):
        if event.content and event.content.parts:
            # Display each agent's output
            print(f"[{event.author}] {event.content.parts[0].text[:200]}")

# Expected output:
# [researcher] {"overview": "Multi-agent systems are...", ...}
# [analyst] {"growth_potential": "high", "difficulty": "medium", ...}
# [reporter] # Multi-Agent Systems Research Report ...
```

`InMemorySessionService` works well for prototyping, but production deployments need persistence. ADK also provides `DatabaseSessionService` and `VertexAiSessionService` for this purpose.

## Error Handling and Retry Strategies

In multi-agent systems, it's critical to design for individual agent failures.

```python
from google.adk.agents import Agent
import logging

logger = logging.getLogger(__name__)

def safe_api_call(endpoint: str, params: str = "{}") -> dict:
    """Safely call an external API.

    Args:
        endpoint: The API endpoint URL
        params: JSON-formatted parameter string

    Returns:
        API response or error information
    """
    import json
    import urllib.request
    import urllib.error

    try:
        req = urllib.request.Request(
            endpoint,
            data=json.dumps(json.loads(params)).encode(),
            headers={"Content-Type": "application/json"},
        )
        with urllib.request.urlopen(req, timeout=10) as resp:
            return json.loads(resp.read())
    except urllib.error.HTTPError as e:
        logger.error(f"API error: {e.code} - {e.reason}")
        return {"error": f"API Error: {e.code}", "fallback": True}
    except Exception as e:
        logger.error(f"Unexpected error: {e}")
        return {"error": str(e), "fallback": True}


# Agent with fallback behavior
resilient_agent = Agent(
    name="resilient_agent",
    model="gemini-3.1-pro",
    instruction="""
    You are responsible for retrieving external data.
    If a tool result contains an "error" key,
    report the error transparently and provide the best
    possible answer using whatever data you do have.
    Never hide errors from the user.
    """,
    tools=[safe_api_call],
)
```

By explicitly defining error behavior in the agent's instructions, the system achieves graceful degradation — returning partial results rather than crashing entirely when something goes wrong.

## ADK vs. LangChain: Choosing the Right Framework

When building agents in Python, you may wonder whether to use ADK or LangChain. Here's how they compare:

- **Google ADK**: Deep integration with Gemini's native features — Function Calling, Grounding, Code Execution — and seamless connections to Google Cloud services like Vertex AI and Firebase Genkit
- **LangChain**: Model-agnostic architecture supporting OpenAI, Anthropic, local models, and more. Larger community with extensive plugins and tutorials

If Gemini is your primary model and Google Cloud is your deployment target, ADK is the natural choice. If multi-model support and vendor flexibility matter more, LangChain is the better fit. For a deeper comparison, see [Google ADK vs LangChain — AI Agent Framework Comparison Guide](/en/articles/gemini-dev/google-adk-vs-langchain-ai-agent-framework-comparison).

## FAQ

### Is ADK free to use?

ADK itself is open-source under the Apache 2.0 license, so it's completely free. However, Gemini API calls beyond Google AI Studio's free tier (15 requests per minute) incur charges. The free tier is more than sufficient for development and testing.

### How can I reduce costs in a multi-agent system?

Assign models based on task complexity. Use Gemini 3.1 Pro for tasks requiring high accuracy (research, code generation) and Gemini 3.1 Flash for lighter tasks (summarization, formatting). In the code examples above, the reporter agent uses Flash for exactly this reason.

### How does ADK compare to the TypeScript version?

Feature parity is nearly identical, but the Python SDK shines when integrating with data science libraries like pandas, NumPy, and scikit-learn. The TypeScript version is better suited for web application integration. For production TypeScript patterns, see [Google ADK × Gemini — TypeScript Production Multi-Agent System](/en/articles/gemini-advanced/google-adk-gemini-typescript-production-agents).

### Can I use the same code on Vertex AI?

Yes, ADK supports both Google AI Studio and Vertex AI. Simply point the `model` parameter to a Vertex AI endpoint — everything else works the same, aside from authentication and region configuration.
