## What Function Calling Makes Possible

Gemini API's **Function Calling** feature is what transforms a language model from a text generator into an action-taking agent. With it, you can build apps that actually *do things*:

- "What's the weather in Tokyo today?" → Gemini calls your weather API and returns live data
- "Order everything with fewer than 10 units in stock" → Gemini queries your DB and triggers your ordering system
- "Summarize this PDF and post it to Slack" → Gemini coordinates file processing and Slack API calls


## Understanding the Execution Model

A common misconception: Gemini does **not** execute your functions directly. Understanding the actual flow is essential for building reliable systems.

```
① You send a user request + function schema definitions to Gemini
② Gemini decides which function to call and with what arguments
③ Gemini returns a functionCall response (no execution happens yet)
④ Your code executes the function and collects the result
⑤ You send the result back to Gemini
⑥ Gemini generates the final natural language response
```

**Your code always controls execution.** This design makes it straightforward to add authorization checks, rate limiting, and human confirmation steps before any function runs.

## Basic Implementation: Your First Function Call

Let's walk through a complete TypeScript implementation.

```typescript
import { GoogleGenerativeAI, FunctionDeclarationSchemaType } from "@google/generative-ai";

const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY!);

// Step 1: Define your tool schema
const tools = [
  {
    functionDeclarations: [
      {
        name: "get_weather",
        description: "Fetch current weather for a specified city",
        parameters: {
          type: FunctionDeclarationSchemaType.OBJECT,
          properties: {
            city: {
              type: FunctionDeclarationSchemaType.STRING,
              description: "City name (e.g. Tokyo, London)",
            },
            unit: {
              type: FunctionDeclarationSchemaType.STRING,
              enum: ["celsius", "fahrenheit"],
              description: "Temperature unit",
            },
          },
          required: ["city"],
        },
      },
    ],
  },
];

// Step 2: Implement the actual function
async function getWeather(city: string, unit: string = "celsius") {
  const response = await fetch(
    `https://api.openweathermap.org/data/2.5/weather?q=${city}&appid=${process.env.OPENWEATHER_API_KEY}&units=${unit === "celsius" ? "metric" : "imperial"}`
  );
  if (!response.ok) throw new Error(`Weather fetch failed for ${city}`);
  const data = await response.json() as any;
  return {
    city: data.name,
    temperature: data.main.temp,
    description: data.weather[0].description,
    humidity: data.main.humidity,
    feelsLike: data.main.feels_like,
  };
}

// Step 3: The Function Calling chat loop
async function chatWithTools(userMessage: string) {
  const model = genAI.getGenerativeModel({ model: "gemini-2.0-flash", tools });
  const chat = model.startChat();
  let response = await chat.sendMessage(userMessage);

  // Process function calls until Gemini is done
  while (response.response.functionCalls()?.length) {
    const functionCalls = response.response.functionCalls()!;
    const functionResults = [];

    for (const call of functionCalls) {
      console.log(`Calling ${call.name}...`, call.args);
      let result;

      if (call.name === "get_weather") {
        const args = call.args as { city: string; unit?: string };
        result = await getWeather(args.city, args.unit);
      } else {
        result = { error: `Unknown function: ${call.name}` };
      }

      functionResults.push({
        functionResponse: { name: call.name, response: { result } },
      });
    }

    response = await chat.sendMessage(functionResults);
  }

  return response.response.text();
}

const answer = await chatWithTools("Compare the weather in Tokyo and London right now.");
console.log(answer);
```

## Parallel Function Calling: Running Multiple Tools at Once

Gemini can request multiple function calls simultaneously. Handling them in parallel is a significant performance win.

```typescript
async function handleParallelCalls(functionCalls: FunctionCall[]) {
  // Fire all functions concurrently
  const results = await Promise.allSettled(
    functionCalls.map(async (call) => {
      try {
        const result = await executeFunction(call.name, call.args);
        return { functionResponse: { name: call.name, response: { result } } };
      } catch (error) {
        // Return error for this call without blocking others
        return {
          functionResponse: {
            name: call.name,
            response: { error: error instanceof Error ? error.message : "Execution error" },
          },
        };
      }
    })
  );

  return results
    .filter((r): r is PromiseFulfilledResult<any> => r.status === "fulfilled")
    .map((r) => r.value);
}

// Example: four cities compared simultaneously
// "Compare weather in Tokyo, London, New York, and Sydney"
// → Gemini requests 4 get_weather calls at once
// → Parallel execution finishes in ~¼ the time of sequential calls
```

## Safe Function Calling: Confirmation Flows for High-Risk Actions

For write operations — sending emails, creating orders, deleting records — always confirm before executing.

```typescript
interface PendingAction {
  id: string;
  functionName: string;
  args: Record<string, unknown>;
  description: string;
  riskLevel: "low" | "medium" | "high";
}

class SafeFunctionCaller {
  private pendingActions: Map<string, PendingAction> = new Map();

  async queueAction(call: FunctionCall): Promise<PendingAction | null> {
    const riskLevel = this.assessRisk(call.name);

    if (riskLevel === "high") {
      const action: PendingAction = {
        id: crypto.randomUUID(),
        functionName: call.name,
        args: call.args as Record<string, unknown>,
        description: this.describeAction(call),
        riskLevel,
      };
      this.pendingActions.set(action.id, action);
      return action; // Ask the frontend to confirm before executing
    }

    return null; // Safe to execute immediately
  }

  private assessRisk(functionName: string): "low" | "medium" | "high" {
    const highRisk = ["send_email", "create_order", "delete_record", "transfer_funds"];
    const mediumRisk = ["create_task", "update_status"];
    if (highRisk.includes(functionName)) return "high";
    if (mediumRisk.includes(functionName)) return "medium";
    return "low";
  }
}
```

## Python Implementation

```python
import google.generativeai as genai
import os

genai.configure(api_key=os.environ["GEMINI_API_KEY"])

weather_tool = genai.protos.Tool(
    function_declarations=[
        genai.protos.FunctionDeclaration(
            name="get_current_weather",
            description="Get current weather for a city",
            parameters=genai.protos.Schema(
                type=genai.protos.Type.OBJECT,
                properties={
                    "city": genai.protos.Schema(
                        type=genai.protos.Type.STRING,
                        description="City name"
                    ),
                },
                required=["city"],
            ),
        )
    ]
)

model = genai.GenerativeModel(
    model_name="gemini-2.0-flash",
    tools=[weather_tool],
)

chat = model.start_chat()
response = chat.send_message("What's the weather in San Francisco?")

for part in response.parts:
    if fn := part.function_call:
        result = get_weather(fn.args["city"])
        response = chat.send_message(
            genai.protos.Content(
                parts=[genai.protos.Part(
                    function_response=genai.protos.FunctionResponse(
                        name=fn.name,
                        response={"result": result},
                    )
                )]
            )
        )

print(response.text)
```
