For much of the past year, I've been caught between two worlds: Gemini API for capability, but wishing for a local inference option that didn't sacrifice performance on my Mac. GGUF models existed, but MLX—the framework optimized for Apple Silicon—hadn't caught up to Gemma 4. That changed in mid-April.

Last week, I confirmed that LMStudio's updated MLX runtime runs Gemma 4 (26B parameters, 4-bit quantized) at **41 tokens/second** on an M5 Pro MacBook with 32GB of RAM. This guide walks you through setup, download, and your first inference run on Apple Silicon.

## Prerequisites — Hardware and Model Selection

Running Gemma 4 locally on Apple Silicon requires some breathing room in memory. Here's what I recommend:

| Mac Model | RAM | Viability |
|---|---|---|
| M3 MacBook Air | 16GB | Works (tight) |
| M4 MacBook Pro | 16GB | Works (recommended) |
| M5 Pro/Max | 32GB | Ideal (comfortable) |

The model we'll use is `mlx-community/gemma-4-26b-a4b-it-4bit`—Google's Gemma 4 26B in 4-bit quantization from the MLX community. Disk footprint: roughly 16GB. Memory during inference: 10–12GB.

A 2-bit version exists if you need something lighter, but quality drops noticeably. If you have 16GB or more, stick with 4-bit.

## Installing LMStudio and Verifying MLX Runtime

Download LMStudio from the Mac App Store or [lmstudio.ai](https://lmstudio.ai). On first launch, verify your MLX runtime version.

Open the app, navigate to **Settings** in the left menu, then scroll to **About**. You'll see "MLX Runtime Version" listed. If it's dated mid-April 2026 or later, you're set for Gemma 4. If not, grab the latest update from App Store or the website, fully quit LMStudio, and relaunch.

## Downloading the Model and Running Your First Inference

With MLX verified, head to the main search screen. Type `gemma-4-26b-a4b-it-4bit` into the search box. When the MLX community model appears, click **Download**. Expect 10–30 minutes over WiFi for the roughly 16GB file.

Once downloaded, click the model name to launch it. After a few seconds of loading, you'll see the prompt interface.

Try this:

```
You are a helpful AI assistant. Explain in one paragraph why Apple Silicon Macs are efficient for running local LLMs.
```

Press the run button. On my M5 Pro, completion streamed at about 41 tokens per second—fast enough to forget API latency exists.

You can also call it programmatically via Python:

```python
import requests

response = requests.post(
    "http://localhost:1234/v1/chat/completions",
    json={
        "model": "local-model",
        "messages": [
            {"role": "user", "content": "What is Gemma 4?"}
        ],
        "temperature": 0.7,
        "max_tokens": 256
    }
)

result = response.json()
print(result["choices"][0]["message"]["content"])
```

Leave LMStudio running in the background, execute this script, and the result streams back as JSON.

## Common Stumbling Blocks and How to Dodge Them

### Out of Memory Errors

If you see "Out of memory" on startup, your Mac is maxed out. Close other apps, or consider the 2-bit version. (Quality trade-off is real, though.)

### No Reasoning Feature

MLX's Gemma 4 doesn't include the Reasoning capability that ships in Gemini 2.0. For complex logical inference, you'll need a hybrid approach—Gemini API for reasoning, local model for everything else. More on that in the advanced guide.

### Model Confusion

LMStudio also lists official Google Gemma 4 models in GGUF format. These are slower on Apple Silicon. Always pick the one explicitly labeled `mlx-community`.
