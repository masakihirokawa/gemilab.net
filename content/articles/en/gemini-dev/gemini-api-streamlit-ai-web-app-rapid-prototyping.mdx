## Setup and context — Why Streamlit × Gemini API?

You want to build an AI-powered web application, but frontend development isn't your strong suit. If that sounds familiar, you're not alone. Streamlit is a Python framework that lets you build interactive web interfaces entirely in Python — no HTML, CSS, or JavaScript required. When combined with the Gemini API, you can create a fully functional AI app prototype in just a few dozen lines of code.

In this guide, we'll walk through building an AI chat application with the Gemini API, running it locally with Streamlit, and deploying it for free on Streamlit Community Cloud. By the end, you'll have a working AI web app accessible from anywhere — built entirely with Python.

## Setting Up Your Development Environment

Let's start by creating a project directory and installing the required packages.

```bash
# Create project directory
mkdir gemini-streamlit-app && cd gemini-streamlit-app

# Create and activate virtual environment
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Install dependencies
pip install streamlit google-genai python-dotenv
```

Next, configure your Gemini API key. You can obtain a free key from [Google AI Studio](https://aistudio.google.com/).

```bash
# Create .env file
echo "GEMINI_API_KEY=YOUR_API_KEY" > .env
```

Also create a `requirements.txt` file — you'll need it for deployment later.

```text
streamlit>=1.40.0
google-genai>=1.0.0
python-dotenv>=1.0.0
```

## Building the AI Chat Application

Here's the complete code for a Gemini API-powered chat app with Streamlit. Save this as `app.py`.

```python
# app.py — Gemini API × Streamlit Chat Application
import streamlit as st
from google import genai
from google.genai import types
import os
from dotenv import load_dotenv

load_dotenv()

# Page configuration
st.set_page_config(
    page_title="Gemini AI Chat",
    page_icon="✨",
    layout="centered"
)

st.title("✨ Gemini AI Chat")
st.caption("An intelligent chat app powered by Gemini API")

# Initialize Gemini client (cached to avoid reconnection on rerun)
@st.cache_resource
def get_client():
    return genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

client = get_client()

# Model selection in sidebar
model_name = st.sidebar.selectbox(
    "Select Model",
    ["gemini-2.5-flash", "gemini-2.5-pro"],
    index=0
)

# System instruction configuration
system_instruction = st.sidebar.text_area(
    "System Instruction (optional)",
    value="You are a helpful and knowledgeable AI assistant.",
    height=100
)

# Initialize chat history
if "messages" not in st.session_state:
    st.session_state.messages = []

# Display chat history
for message in st.session_state.messages:
    with st.chat_message(message["role"]):
        st.markdown(message["content"])

# Handle user input
if prompt := st.chat_input("Type your message here"):
    # Display and store user message
    st.session_state.messages.append({"role": "user", "content": prompt})
    with st.chat_message("user"):
        st.markdown(prompt)

    # Send to Gemini API with streaming
    with st.chat_message("assistant"):
        message_placeholder = st.empty()
        full_response = ""

        # Convert chat history to Gemini format
        contents = []
        for msg in st.session_state.messages:
            role = "user" if msg["role"] == "user" else "model"
            contents.append(
                types.Content(
                    role=role,
                    parts=[types.Part.from_text(text=msg["content"])]
                )
            )

        # Get streaming response
        response = client.models.generate_content_stream(
            model=model_name,
            contents=contents,
            config=types.GenerateContentConfig(
                system_instruction=system_instruction,
                temperature=0.7,
                max_output_tokens=2048,
            )
        )

        for chunk in response:
            if chunk.text:
                full_response += chunk.text
                message_placeholder.markdown(full_response + "▌")

        message_placeholder.markdown(full_response)

    # Store assistant response
    st.session_state.messages.append(
        {"role": "assistant", "content": full_response}
    )
```

Run the app locally with:

```bash
streamlit run app.py
# Browser opens automatically at http://localhost:8501
```

You'll immediately see a clean chat interface. The sidebar lets you switch between Gemini models and adjust the system instruction in real time — changes take effect on the very next message.

## Adding Multimodal Image Input

One of the Gemini API's greatest strengths is its multimodal capabilities. Let's add image upload support so users can have the AI analyze photos, charts, or documents alongside their text prompts. For a deeper dive into Gemini's multimodal features, check out our [Gemini API Multimodal Techniques Collection]((/articles/gemini-api/gemini-api-multimodal-techniques).

```python
# Add to app.py: Image upload feature
import base64

# Add image uploader to sidebar
uploaded_file = st.sidebar.file_uploader(
    "Upload an image (optional)",
    type=["png", "jpg", "jpeg", "webp"]
)

# Replace the chat input handler with the following
if prompt := st.chat_input("Type your message here"):
    st.session_state.messages.append({"role": "user", "content": prompt})
    with st.chat_message("user"):
        st.markdown(prompt)
        if uploaded_file:
            st.image(uploaded_file, width=300)

    with st.chat_message("assistant"):
        message_placeholder = st.empty()
        full_response = ""

        # Build parts with text and optional image
        parts = [types.Part.from_text(text=prompt)]
        if uploaded_file:
            image_bytes = uploaded_file.getvalue()
            parts.append(
                types.Part.from_bytes(
                    data=image_bytes,
                    mime_type=uploaded_file.type
                )
            )

        response = client.models.generate_content_stream(
            model=model_name,
            contents=[types.Content(role="user", parts=parts)],
            config=types.GenerateContentConfig(
                system_instruction=system_instruction,
                temperature=0.7,
            )
        )

        for chunk in response:
            if chunk.text:
                full_response += chunk.text
                message_placeholder.markdown(full_response + "▌")

        message_placeholder.markdown(full_response)

    st.session_state.messages.append(
        {"role": "assistant", "content": full_response}
    )
```

With this addition, users can upload a photo of a meal and ask for a recipe, share a chart and request trend analysis, or submit a document screenshot for summarization — interactions that go far beyond what text-only interfaces can offer.

## Deploying for Free on Streamlit Community Cloud

Once your app is working locally, deploying it to the web is remarkably straightforward. Streamlit Community Cloud provides free hosting for public apps — all you need is a GitHub repository.

### Step-by-Step Deployment

**1. Create a `.gitignore` file**

```text
.env
venv/
__pycache__/
```

**2. Push your code to GitHub**

```bash
git init
git add app.py requirements.txt .gitignore
git commit -m "Initial commit: Gemini Streamlit app"
git remote add origin https://github.com/your-username/gemini-streamlit-app.git
git push -u origin main
```

**3. Deploy on Streamlit Community Cloud**

- Visit [share.streamlit.io](https://share.streamlit.io/) and sign in with your GitHub account
- Click "New app" and select your repository, branch, and main file (`app.py`)
- Under "Advanced settings," add your `GEMINI_API_KEY` to the Secrets section
- Click "Deploy" — your app will be live at a public URL within minutes

### Configuring Secrets

Instead of a `.env` file, Streamlit Community Cloud uses a Secrets feature. In the deployment settings under "Advanced settings" > "Secrets," enter:

```toml
GEMINI_API_KEY = "YOUR_API_KEY"
```

Your code doesn't need any changes — `os.getenv("GEMINI_API_KEY")` works seamlessly with both `.env` files locally and Secrets in production. If you're planning to manage API keys at scale, our [Gemini API Production Security Guide]((/articles/gemini-api/gemini-api-production-security-guide) covers comprehensive security practices.

## Performance Optimization Tips

To keep your Streamlit × Gemini API app running smoothly, keep these best practices in mind.

- **`@st.cache_resource` for client initialization**: As shown in the code above, wrapping the Gemini client in `@st.cache_resource` prevents reconnection on every Streamlit rerun, significantly improving responsiveness
- **`@st.cache_data` for repeated queries**: If your app frequently processes the same inputs, `@st.cache_data` can cache API responses and reduce unnecessary calls
- **Streaming for perceived speed**: Using `generate_content_stream` instead of `generate_content` displays the first tokens immediately, making the app feel much faster even though total response time is similar
- **Session state management**: As chat history grows, the token count sent to Gemini increases with each request. Implement a sliding window that trims older messages beyond a threshold to optimize both response speed and API costs
