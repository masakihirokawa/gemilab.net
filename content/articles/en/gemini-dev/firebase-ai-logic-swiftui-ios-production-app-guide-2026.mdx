When you want to add Gemini to an iOS app, the first decision is which SDK to use. Direct Gemini API calls, Google AI SDK for Swift, or Firebase AI Logic SDK.

For indie developers building iOS apps, I recommend Firebase AI Logic. Three reasons: natural integration with Firebase Authentication for per-user access control; App Attest + Firebase App Check for secure API calls without a separate backend; and unified management of costs, logs, and configuration within your existing Firebase project.

Here's the full implementation — from setup to App Store submission.

## Firebase Project Setup

Enable AI Logic in the Firebase console: Project Settings → AI → Firebase AI Logic → Enable.

You'll choose between Gemini Developer API (free tier available) and Vertex AI Gemini API (pay-as-you-go). For an indie app in its early phase, start with the Developer API and migrate to Vertex AI when user numbers justify it.

Add to your Podfile:

```ruby
pod 'FirebaseAI', '~> 11.0'
pod 'FirebaseAuth', '~> 11.0'
pod 'FirebaseAppCheck', '~> 11.0'
```

Don't skip App Check. Without it, someone who reverse-engineers your IPA can make API calls on your behalf.

```swift
// AppDelegate.swift
import Firebase
import FirebaseAppCheck

class AppDelegate: NSObject, UIApplicationDelegate {
    func application(_ application: UIApplication,
                     didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]? = nil) -> Bool {
        
        #if DEBUG
        let providerFactory = AppCheckDebugProviderFactory()
        #else
        let providerFactory = DeviceCheckProviderFactory()
        #endif
        
        AppCheck.setAppCheckProviderFactory(providerFactory)
        FirebaseApp.configure()
        return true
    }
}
```

## The Gemini Client Implementation

A Swift 6-compatible client using the `@Observable` macro:

```swift
import FirebaseAI
import FirebaseAuth
import Observation

@Observable
final class GeminiClient {
    private(set) var model: GenerativeModel?
    private(set) var isInitialized = false
    private(set) var sessionTokensUsed: Int = 0
    private let maxSessionTokens: Int = 50000
    
    func initialize() async throws {
        guard Auth.auth().currentUser != nil else {
            throw GeminiClientError.notAuthenticated
        }
        
        let ai = FirebaseAI.firebaseAI(backend: .googleAI())
        
        model = ai.generativeModel(
            modelName: "gemini-2.0-flash",
            generationConfig: GenerationConfig(
                temperature: 0.7,
                maxOutputTokens: 2048,
                responseMIMEType: "text/plain"
            ),
            safetySettings: [
                SafetySetting(harmCategory: .harassment, threshold: .blockMediumAndAbove),
                SafetySetting(harmCategory: .hateSpeech, threshold: .blockMediumAndAbove)
            ]
        )
        isInitialized = true
    }
    
    func generateText(prompt: String) async throws -> String {
        guard let model = model else { throw GeminiClientError.notInitialized }
        guard sessionTokensUsed < maxSessionTokens else {
            throw GeminiClientError.sessionBudgetExceeded(limit: maxSessionTokens)
        }
        
        let response = try await model.generateContent(prompt)
        if let usage = response.usageMetadata {
            sessionTokensUsed += usage.totalTokenCount ?? 0
        }
        return response.text ?? ""
    }
    
    enum GeminiClientError: LocalizedError {
        case notAuthenticated
        case notInitialized
        case sessionBudgetExceeded(limit: Int)
        
        var errorDescription: String? {
            switch self {
            case .notAuthenticated: return "Please log in to use AI features"
            case .notInitialized: return "AI feature initialization failed"
            case .sessionBudgetExceeded(let limit):
                return "Session token limit (\(limit) tokens) reached"
            }
        }
    }
}
```

## Streaming Response Implementation

Streaming substantially improves perceived responsiveness:

```swift
@Observable
final class ChatViewModel {
    private let geminiClient: GeminiClient
    private(set) var messages: [ChatMessage] = []
    private(set) var isGenerating = false
    private(set) var streamingText = ""
    
    init(geminiClient: GeminiClient) {
        self.geminiClient = geminiClient
    }
    
    func sendMessage(_ userText: String) async {
        guard !userText.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty else { return }
        guard !isGenerating else { return }
        
        messages.append(ChatMessage(role: .user, content: userText))
        isGenerating = true
        streamingText = ""
        
        do {
            guard let model = geminiClient.model else { throw GeminiClientError.notInitialized }
            let chat = model.startChat(history: buildHistory())
            
            for try await chunk in try chat.sendMessageStream(userText) {
                if let text = chunk.text {
                    streamingText += text
                }
            }
            
            messages.append(ChatMessage(role: .model, content: streamingText))
        } catch {
            messages.append(ChatMessage(
                role: .system,
                content: "Error: \(error.localizedDescription)"
            ))
        }
        
        streamingText = ""
        isGenerating = false
    }
    
    private func buildHistory() -> [ModelContent] {
        // Limit context to last 10 messages to control input token costs
        return messages.suffix(10).map { msg in
            ModelContent(
                role: msg.role == .user ? "user" : "model",
                parts: [.text(msg.content)]
            )
        }
    }
}
```

The `suffix(10)` limit on conversation history is important for cost control. Sending the full conversation history grows input tokens quickly. 10–20 messages is a practical balance between context quality and cost.

## SwiftUI Chat Interface

```swift
struct ChatView: View {
    @Environment(ChatViewModel.self) private var viewModel
    @State private var inputText = ""
    
    var body: some View {
        VStack(spacing: 0) {
            ScrollViewReader { proxy in
                ScrollView {
                    LazyVStack(alignment: .leading, spacing: 12) {
                        ForEach(viewModel.messages) { message in
                            MessageBubble(message: message).id(message.id)
                        }
                        if viewModel.isGenerating && !viewModel.streamingText.isEmpty {
                            MessageBubble(message: ChatMessage(
                                role: .model, content: viewModel.streamingText
                            )).id("streaming")
                        }
                    }
                    .padding()
                }
                .onChange(of: viewModel.streamingText) { _, _ in
                    withAnimation { proxy.scrollTo("streaming", anchor: .bottom) }
                }
            }
            
            Divider()
            
            HStack(spacing: 12) {
                TextField("Message", text: $inputText, axis: .vertical)
                    .lineLimit(1...5)
                
                Button {
                    Task {
                        let text = inputText
                        inputText = ""
                        await viewModel.sendMessage(text)
                    }
                } label: {
                    Image(systemName: "arrow.up.circle.fill")
                        .font(.title2)
                        .foregroundStyle(inputText.isEmpty ? .secondary : .blue)
                }
                .disabled(inputText.isEmpty || viewModel.isGenerating)
            }
            .padding()
        }
    }
}
```

## App Store Review Pitfalls

AI-powered iOS apps get scrutinized more carefully than standard apps. Things I've run into:

Your privacy policy must explicitly mention AI. State that user messages are sent to an AI service (Google Gemini) and describe how that data is handled. Omitting this is a common rejection reason.

App Privacy settings must include AI provider data transmission. Not configuring this during review can cause problems even after approval.

You need a content moderation policy for generated content. Having SafetySettings configured and being able to show this in screenshots helps reviewers understand your approach.

The Kids Category and AI features don't mix — AI features are generally not permitted in apps with that rating.

## Preventing Cost Runaway

The most common cost incident for indie developers: a malicious user sending massive request volumes. Using Firestore to track per-user daily usage is the simplest effective approach:

```swift
func checkAndUpdateDailyUsage(userId: String, tokensToUse: Int) async throws -> Bool {
    let db = Firestore.firestore()
    let today = Calendar.current.startOfDay(for: Date())
    let docRef = db.collection("usage").document(
        "\(userId)_\(today.timeIntervalSince1970)"
    )
    
    return try await db.runTransaction { transaction, _ in
        let current = (try? transaction.getDocument(docRef))?.data()?["tokens"] as? Int ?? 0
        let dailyLimit = 10000
        
        if current + tokensToUse > dailyLimit { return false }
        
        transaction.setData(
            ["tokens": current + tokensToUse, "updatedAt": Timestamp()],
            forDocument: docRef,
            merge: true
        )
        return true
    } as! Bool
}
```
