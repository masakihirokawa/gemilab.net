# Gemini Code Assist Outline Complete Guide — Visualize Code Structure

## Introduction

Joining a large project immediately hits you with the question: "What does this codebase actually do?" Thousands-of-line files, interdependent modules, function calls that seem to come from nowhere—traditionally you'd hunt for documentation or fire up a debugger and wade through the code blindly.

Gemini Code Assist's **Outline feature** solves these challenges instantly. AI reads your code and **visualizes file structure, function call flows, and data dependencies** in easy-to-understand diagrams. This guide covers how to use Outline, practical applications, and implementation techniques.

---

## What is the Outline Feature?

### Concept

Gemini Code Assist's **Outline** visualizes your code structure as a tree or diagram format:

- Function hierarchy: Top-level → called functions → dependencies
- Class definitions: Member variables, methods, inheritance chains
- Import/export relationships: Module dependencies
- Variable scope: Global and local variable usage

Unlike traditional code folding, Gemini's Outline leverages AI to understand structure and present it intelligently.

---

## How to Display Outline

### In VS Code

1. Open Gemini Code Assist panel
   - Click the Gemini icon in the left sidebar
   - Or press `Ctrl+Shift+G` (Windows/Linux) / `Cmd+Shift+G` (macOS)

2. Select Outline tab
   - Click "Outline" at the top of the panel

3. Specify target file (optional)
   - Default is the active file

### In IntelliJ IDEA

1. Open the Gemini panel in the right sidebar
2. Click Outline section
3. Code structure displays as a tree

## Practical Example: Understanding Multi-File Node.js Structure

### Scenario

Joining a team and inheriting an Express.js backend project. You need to understand:

- Application entry point
- Middleware structure
- Route definitions
- Database connection flow

### Steps to Review with Outline

**Step 1: Open main file (app.js)**

```javascript
// app.js
const express = require('express');
const authMiddleware = require('./middleware/auth');
const userRoutes = require('./routes/users');
const dbConnection = require('./db/connection');

const app = express();

app.use(express.json());
app.use(authMiddleware);

app.use('/api/users', userRoutes);

app.use((err, req, res, next) => {
  console.error(err.stack);
  res.status(500).json({ error: 'Internal Server Error' });
});

module.exports = app;
```

**Step 2: Display Outline**

Outline panel shows:

- require() section
- app initialization
- Middleware stack
- Route definitions
- Error handler

**Step 3: Click sections to explore details**

Click "authMiddleware" → jumps to ./middleware/auth.js

```javascript
// middleware/auth.js
const jwt = require('jsonwebtoken');

module.exports = (req, res, next) => {
  const token = req.headers.authorization?.split(' ')[1];

  if (!token) {
    return res.status(401).json({ error: 'No token' });
  }

  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.user = decoded;
    next();
  } catch (err) {
    res.status(403).json({ error: 'Invalid token' });
  }
};
```

## Advanced Outline Usage

### 1. Multi-File Function Tracing

Visualize function call flows across multiple files:

```javascript
// button.js
document.getElementById('submit').addEventListener('click', () => {
  processUserInput(inputData);
});

// validator.js
function processUserInput(data) {
  if (validateInput(data)) {
    sendToServer(data);
  }
}

function validateInput(data) {
  return checkFormat(data) && checkLength(data);
}

// api.js
async function sendToServer(data) {
  const response = await fetch('/api/submit', {
    method: 'POST',
    body: JSON.stringify(data)
  });
  return response.json();
}
```

Outline makes the function call flow immediately clear.

### 2. Class Hierarchy at a Glance

Complex Python class inheritance becomes instantly clear:

```python
# models.py
class BaseModel:
    def __init__(self, id):
        self.id = id

    def save(self):
        raise NotImplementedError()

class User(BaseModel):
    def __init__(self, id, name, email):
        super().__init__(id)
        self.name = name
        self.email = email

    def save(self):
        return db.insert('users', self.__dict__)

    def get_profile(self):
        return {
            'id': self.id,
            'name': self.name,
            'email': self.email
        }

class Admin(User):
    def __init__(self, id, name, email, role):
        super().__init__(id, name, email)
        self.role = role

    def delete_user(self, user_id):
        return db.delete('users', user_id)
```

Outline displays the class hierarchy structure clearly.

## FAQ

### Q1. Does Outline update in real-time?

**A.** Yes. Outline auto-updates as you edit. For large files (thousands of lines), expect a few seconds' lag.

### Q2. Can I filter what Outline displays?

**A.** Yes, newer Gemini Code Assist versions offer:

- Show functions only
- Show classes only
- Show public methods only
- Hide private methods

### Q3. Does Outline show TypeScript type information?

**A.** Yes. Outline recognizes TypeScript types and displays them in function signatures.

```typescript
// Implementation
function fetchUser(id: number): Promise<User> {
  return db.query('SELECT * FROM users WHERE id = ?', [id]);
}

// Outline displays
fetchUser(id: number) → Promise<User>
```

## Outline Limitations and Solutions

### 1. Lag with Very Large Files

Files exceeding 10,000 lines may take 5-10 seconds to generate Outline.

**Solution**: Modularize code into smaller, focused modules

### 2. Dynamic Code Generation Not Tracked

Outline can't trace code generated dynamically via metaprogramming.

**Solution**: Add explicit comments

```javascript
/**
 * Dynamic methods (Outline helper):
 * - create(id): Create record
 * - read(id): Read record
 * - update(id): Update record
 * - delete(id): Delete record
 */
```
