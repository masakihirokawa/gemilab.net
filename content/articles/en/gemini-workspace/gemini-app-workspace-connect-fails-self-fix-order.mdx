I once asked the Gemini app, signed in with a work account, to find an email thread with a client. The reply was a single line: "I couldn't find anything." There was no prompt to connect anything, either.

The email was sitting in my inbox. I assumed my search words were off and rephrased the request three different ways. Each attempt came back the same.

What I want to pass on first is this: the cause is often not something only an administrator can fix. When I reread Google's help pages, four of the checks were things a user can do alone, and they came before anything about admin settings.

**Work through the places you can fix yourself before you ask anyone else.** Since I started doing it in that order, my messages to IT arrive with the facts already checked, and one reply is usually enough. Everything below follows the Japanese-language help pages as of October 18, 2026.

## First, decide whether it is "not connected" or "connected but empty"

"Gemini can't read my Gmail" covers two different situations, and mixing them up sends you to the wrong place.

<thead>
<tr><th>What you see</th><th>What it means</th><th>Where to look first</th></tr>
</thead>
<tbody>
<tr><td>No prompt to connect, or a message that it can't connect</td><td>The connection itself isn't in place</td><td>Activity setting, account, admin enablement</td></tr>
<tr><td>It's connected, yet you get "not found" or outdated content</td><td>The connection works; the request or the file type is the issue</td><td>Your prompt, and whether the item is a supported type</td></tr>

</table>

The help page also warns that Gemini can return information from an older email even when a newer one has arrived. Open the sources shown under the answer and see which email it actually used.

## One: fix how you ask

Before doubting the connection, check how you phrased the request. It costs nothing. The help lists three points:

- Type **@** in the input box and pick the service, such as Gmail or Drive
- At the start of every new conversation, tell Gemini again to use that service. Follow-up questions in the same conversation don't need the reminder
- Don't paste a document or email URL; name the service and use keywords from the content

I had typed only the client's company name and "find the email." I hadn't named a service, and I was in a fresh conversation. It's a rewrite rather than a settings change, so it is worth trying first.

## Two: confirm which account you're signed in with

One of the conditions is that you are signed in to the Gemini app with the same account you use in Workspace. If your browser holds both a personal and a work account, the avatar in the corner doesn't always tell them apart. I'd suggest opening it and reading the address aloud before anything else.

## Three: is "Save activity" turned on?

With "Save activity" off, Gemini can't connect to Google Workspace. On a personal account you can flip this yourself.

On work or school accounts it works differently: only the Workspace administrator can manage this setting. If the toggle won't move, [the three screens to check when a work account's Gemini activity setting won't switch](/en/articles/gemini-basics/gemini-work-account-activity-setting-locked-admin-vault) walks through it.

## Four: Gmail's smart features (personal accounts)

The help page for personal accounts says that "Smart features in other Google products" must be turned on in Gmail's settings. After enabling it, reload the Gemini app and try connecting again.

That item doesn't appear in the help for work and school accounts. Organizations often manage smart features centrally, so I keep it as a detail to mention to the admin rather than something to change myself.

## Five: from here, only an administrator can fix it

If the four checks above don't resolve it, you're in admin territory. The help names two conditions:

- Your Workspace edition is eligible for app integrations
- The administrator has enabled the ability to connect apps to Gemini

You can compare editions in the table on [Use the Gemini app with a work or school Google Account](https://support.google.com/gemini/answer/14620100). We also covered external-service connections being on by default in [Workspace's third-party connections were on by default: two screens to check](/en/articles/gemini-workspace/gemini-workspace-third-party-connectors-default-on-inventory).

A message like this tends to get answered in one round trip:

```text
I'd like the Gemini app to search Gmail and Drive, but the connection isn't working.
Already checked: service named with @; signed in with the same account.
Could you tell me: (1) whether Save activity is on for my account, (2) whether app integrations for Gmail and Drive are enabled, (3) whether my license is an eligible edition?
```

## Asking for several services at once stops all of them

One behavior is easy to miss. If a prompt involves several services and any one of them is disabled, none of the requested actions are carried out. The help's own example: ask Gemini to create a calendar event and set a reminder, and if the to-do list app is off, the event isn't added either.

So for diagnosis, send one service per prompt.

<table>
<thead>
<tr><th>Test</th><th>Example prompt</th><th>What a pass tells you</th></tr>
</thead>
<tbody>
<tr><td>Gmail only</td><td>Using @Gmail, list the subjects of three emails I received last week</td><td>Gmail integration is on</td></tr>
<tr><td>Drive only</td><td>Using @Google Drive, find one document with "minutes" in the file name</td><td>Drive integration is on</td></tr>
<tr><td>Calendar only</td><td>Using @Google Calendar, tell me today's events</td><td>Calendar integration is on</td></tr>
</tbody>
</table>

The service that fails is the one to name to your admin. "Only Drive fails" shortens their work far more than "it doesn't connect."

## Even when connected, some things never come back

Some actions are listed in the help as unsupported even when the connection is fine. Many "connected but empty" cases fall here.

<table>
<thead>
<tr><th>Service</th><th>What it can't do</th></tr>
</thead>
<tbody>
<tr><td>Gmail</td><td>Access comments or images; create drafts or delete email; count items or check storage</td></tr>
<tr><td>Drive</td><td>Access images or videos (only Docs, Sheets, Slides and PDF are covered); manage content such as creating folders; count items or check free space</td></tr>
<tr><td>Docs, Sheets, Slides</td><td>Access comments or images; create, draft or delete files</td></tr>
</tbody>
</table>

If you tried to find a receipt saved as a photo in Drive and came back empty, that is the second row, a separate matter from whether the file exists. When you need a draft, the help points to exporting the answer to Google Workspace.

## What happens when an admin disables an app later

If an administrator turns an app off after you've started a conversation that used it, you can still view and continue that conversation. Gemini only keeps access to the information needed for the original prompt, and can't reach anything else.

If something worked a moment ago but a new question fails, this may be why. Ask your admin when the setting changed.

## What to do next

Today, run the three one-service prompts on your work account and note which service fails. That single line turns your message to the admin into one that says what was checked and how far.

When the connection works but you aren't sure of the result, I open the sources under the answer and look at the underlying email or file myself before using it.
