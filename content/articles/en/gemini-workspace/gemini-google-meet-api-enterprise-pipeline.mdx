## Introduction

"Writing up meeting notes takes over an hour every time." "Tasks keep falling through the cracks and follow-ups are a constant struggle." These are pain points that countless teams deal with every day.

By combining the Gemini API's multimodal capabilities with Function Calling, you can transform your Google Meet sessions into a **fully automated data processing pipeline**. The goal of this article is to build a production-grade system where — within five minutes of a meeting ending — a formatted summary, an owner-assigned task list, and next actions are already sitting in everyone's inbox.

Our companion article [Automate Meeting Notes with Gemini and Google Workspace](/en/articles/gemini-workspace/gemini-meeting-notes-auto-summary-guide) covers the basics of using Gemini with Google Docs. ### What We're Building

Meeting ends → Recording saved to Google Drive → Apps Script fires trigger → Python Cloud Function calls Gemini API → Transcription + summary + task extraction → Google Sheets registration + Gmail delivery + Google Calendar follow-up events created

## Google Drive × Apps Script: Setting Up the Automatic Trigger

### Step 1: Recording Files Auto-Saved to Drive

With the appropriate Google Workspace admin settings, Google Meet recordings are automatically saved to a designated Drive folder. We'll use this as the entry point to kick off our pipeline when a new file appears.

### Step 2: Detecting New Files with Apps Script

Add the following Apps Script to your project and configure it as a time-driven trigger (every 5 minutes):

```javascript
// Code.gs — Google Apps Script
const DRIVE_FOLDER_ID = 'YOUR_DRIVE_FOLDER_ID';
const CLOUD_FUNCTION_URL = 'https://YOUR_REGION-YOUR_PROJECT.cloudfunctions.net/process-meeting';
const PROCESSED_LABEL = 'processed';

function checkNewMeetingRecordings() {
  const folder = DriveApp.getFolderById(DRIVE_FOLDER_ID);
  const files = folder.getFiles();

  while (files.hasNext()) {
    const file = files.next();
    const fileName = file.getName();

    // Identify Google Meet recordings (.mp4) that haven't been processed yet
    if (fileName.includes('Meet') &&
        fileName.endsWith('.mp4') &&
        !file.getDescription().includes(PROCESSED_LABEL)) {

      const fileId = file.getId();
      const createdDate = file.getDateCreated();

      // Only process files created within the last hour
      const oneHourAgo = new Date(Date.now() - 60 * 60 * 1000);
      if (createdDate > oneHourAgo) {
        triggerProcessing(fileId, fileName, file);
      }
    }
  }
}

function triggerProcessing(fileId, fileName, file) {
  const payload = {
    file_id: fileId,
    file_name: fileName,
    created_at: new Date().toISOString()
  };

  const options = {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    payload: JSON.stringify(payload),
    muteHttpExceptions: true
  };

  const response = UrlFetchApp.fetch(CLOUD_FUNCTION_URL, options);

  if (response.getResponseCode() === 200) {
    // Mark as processed to avoid duplicate runs
    file.setDescription(PROCESSED_LABEL);
    console.log(`Processing started: ${fileName}`);
  } else {
    console.error(`Error: ${response.getContentText()}`);
  }
}
```

## The Python Pipeline: Transcription and Structured Summaries

### Step 3: Audio Transcription with the Gemini API

Gemini 2.5 Pro accepts audio files as direct input and produces high-accuracy transcriptions. Here's the main pipeline implemented as a Cloud Function:

```python
# main.py — Cloud Function entry point
import os
import json
from pathlib import Path
from datetime import datetime
import google.generativeai as genai
from google.oauth2 import service_account
from googleapiclient.discovery import build
from googleapiclient.http import MediaIoBaseDownload
import io
import functions_framework

# Configure Gemini API
genai.configure(api_key=os.environ['GEMINI_API_KEY'])
model = genai.GenerativeModel('gemini-2.5-pro')

@functions_framework.http
def process_meeting(request):
    """Cloud Function: main entry point for processing meeting recordings"""
    request_json = request.get_json()
    file_id = request_json.get('file_id')
    file_name = request_json.get('file_name')

    try:
        # 1. Download recording from Drive
        audio_data = download_from_drive(file_id)

        # 2. Transcribe with Gemini API
        transcript = transcribe_audio(audio_data, file_name)

        # 3. Generate structured summary
        summary = generate_structured_summary(transcript)

        # 4. Extract tasks via Function Calling
        tasks = extract_tasks_with_function_calling(transcript)

        # 5. Save to Sheets
        save_to_sheets(summary, tasks, file_name)

        # 6. Send email report
        send_meeting_report(summary, tasks, file_name)

        return {'status': 'success', 'tasks_count': len(tasks)}, 200

    except Exception as e:
        print(f"Error processing {file_name}: {e}")
        return {'status': 'error', 'message': str(e)}, 500


def download_from_drive(file_id: str) -> bytes:
    """Download a file from Google Drive"""
    creds = service_account.Credentials.from_service_account_file(
        'service-account.json',
        scopes=['https://www.googleapis.com/auth/drive.readonly']
    )
    service = build('drive', 'v3', credentials=creds)

    request = service.files().get_media(fileId=file_id)
    buffer = io.BytesIO()
    downloader = MediaIoBaseDownload(buffer, request)

    done = False
    while not done:
        _, done = downloader.next_chunk()

    return buffer.getvalue()


def transcribe_audio(audio_data: bytes, file_name: str) -> str:
    """Transcribe audio using the Gemini API"""
    import tempfile
    with tempfile.NamedTemporaryFile(suffix='.mp4', delete=False) as tmp:
        tmp.write(audio_data)
        tmp_path = tmp.name

    uploaded_file = genai.upload_file(tmp_path, mime_type='video/mp4')

    prompt = """
    Please transcribe this meeting recording accurately.
    - Label speakers as [Speaker A]:, [Speaker B]: etc. when identifiable
    - Mark inaudible sections as [INAUDIBLE]
    - Preserve technical terms and proper nouns as-is
    - Insert timestamps in [MM:SS] format every 5 minutes
    """

    response = model.generate_content([prompt, uploaded_file])

    # Clean up temp files
    os.unlink(tmp_path)
    uploaded_file.delete()

    return response.text
```

### Step 4: Generating Structured Summaries

Rather than a raw transcript dump, we want a **structured, business-ready summary**:

```python
def generate_structured_summary(transcript: str) -> dict:
    """Generate a structured summary using the Gemini API"""

    prompt = f"""
    From the meeting transcript below, generate a structured business summary.

    # Output format (JSON)
    {{
      "meeting_title": "Meeting title or main topic",
      "date": "YYYY-MM-DD",
      "duration_minutes": number,
      "attendees": ["list of attendees (inferred)"],
      "executive_summary": "3-sentence executive summary",
      "key_decisions": ["list of decisions made"],
      "discussion_points": [
        {{"topic": "Topic name", "summary": "Discussion summary", "outcome": "Conclusion"}}
      ],
      "risks_concerns": ["risks or concerns raised"],
      "next_meeting_agenda": ["suggested items for the next meeting"]
    }}

    # Transcript
    {transcript[:8000]}

    Return only valid JSON with no additional commentary.
    """

    response = model.generate_content(
        prompt,
        generation_config=genai.GenerationConfig(
            response_mime_type='application/json',
            temperature=0.2  # Lower temperature for more consistent structured output
        )
    )

    return json.loads(response.text)
```

## Function Calling: Extracting Tasks as Structured Data

Function Calling is one of the Gemini API's most powerful capabilities. It lets you pull **owner-assigned, deadline-aware, prioritized tasks** directly from a conversation transcript as structured data.

### Step 5: Defining the Function and Extracting Tasks

```python
def extract_tasks_with_function_calling(transcript: str) -> list[dict]:
    """Extract structured tasks using Function Calling"""

    register_task_func = genai.protos.FunctionDeclaration(
        name='register_task',
        description='Register a task or action item that emerged from the meeting',
        parameters=genai.protos.Schema(
            type=genai.protos.Type.OBJECT,
            properties={
                'task_title': genai.protos.Schema(
                    type=genai.protos.Type.STRING,
                    description='A concise task title (under 50 characters)'
                ),
                'description': genai.protos.Schema(
                    type=genai.protos.Type.STRING,
                    description='Detailed description of the task'
                ),
                'assignee': genai.protos.Schema(
                    type=genai.protos.Type.STRING,
                    description='Name of the person responsible (use "TBD" if unknown)'
                ),
                'due_date': genai.protos.Schema(
                    type=genai.protos.Type.STRING,
                    description='Deadline in YYYY-MM-DD format ("TBD" if not mentioned)'
                ),
                'priority': genai.protos.Schema(
                    type=genai.protos.Type.STRING,
                    enum=['High', 'Medium', 'Low'],
                    description='Task priority'
                ),
                'category': genai.protos.Schema(
                    type=genai.protos.Type.STRING,
                    enum=['Research', 'Implementation', 'Review', 'Communication', 'Design', 'Other'],
                    description='Task category'
                )
            },
            required=['task_title', 'description', 'assignee', 'priority']
        )
    )

    tool = genai.protos.Tool(function_declarations=[register_task_func])
    model_with_tools = genai.GenerativeModel(
        model_name='gemini-2.5-pro',
        tools=[tool]
    )

    prompt = f"""
    Analyze the meeting transcript below and register every task or action item —
    both explicit and implied — using the register_task function.

    Watch for these patterns:
    - "I'll take care of..." / "I'll look into..." → task
    - "We need to..." / "Someone should..." → task
    - "by next week" / "before Friday" → deadline clues
    - Name + verb construction → potential owner

    After registering all tasks, reply with only the word "done".

    Transcript:
    {transcript[:6000]}
    """

    response = model_with_tools.generate_content(prompt)

    tasks = []
    for part in response.candidates[0].content.parts:
        if hasattr(part, 'function_call') and part.function_call.name == 'register_task':
            task_args = dict(part.function_call.args)
            tasks.append(task_args)

    print(f"Tasks extracted: {len(tasks)}")
    return tasks
```

## Google Sheets Integration: Your Task Management Dashboard

### Step 6: Auto-Registering Tasks in Sheets

```python
def save_to_sheets(summary: dict, tasks: list[dict], file_name: str):
    """Save meeting data to Google Sheets"""
    creds = service_account.Credentials.from_service_account_file(
        'service-account.json',
        scopes=['https://www.googleapis.com/auth/spreadsheets']
    )
    service = build('sheets', 'v4', credentials=creds)
    spreadsheet_id = os.environ['SPREADSHEET_ID']

    # 1. Append to Meeting Summary sheet
    summary_row = [[
        datetime.now().strftime('%Y-%m-%d %H:%M'),
        summary.get('meeting_title', ''),
        summary.get('duration_minutes', ''),
        ', '.join(summary.get('attendees', [])),
        summary.get('executive_summary', ''),
        '\n'.join(summary.get('key_decisions', [])),
        file_name
    ]]

    service.spreadsheets().values().append(
        spreadsheetId=spreadsheet_id,
        range='Meeting Summary!A:G',
        valueInputOption='USER_ENTERED',
        body={'values': summary_row}
    ).execute()

    # 2. Append each task to Task Tracker sheet
    meeting_date = datetime.now().strftime('%Y-%m-%d')
    task_rows = []
    for task in tasks:
        task_rows.append([
            meeting_date,
            summary.get('meeting_title', ''),
            task.get('task_title', ''),
            task.get('description', ''),
            task.get('assignee', 'TBD'),
            task.get('due_date', 'TBD'),
            task.get('priority', 'Medium'),
            task.get('category', 'Other'),
            'Not Started'  # Initial status
        ])

    if task_rows:
        service.spreadsheets().values().append(
            spreadsheetId=spreadsheet_id,
            range='Task Tracker!A:I',
            valueInputOption='USER_ENTERED',
            body={'values': task_rows}
        ).execute()

    print(f"Sheets saved: 1 summary, {len(task_rows)} tasks")
```

### Recommended Sheet Structure

**"Meeting Summary" sheet**: Date, title, attendees, summary, decisions

**"Task Tracker" sheet**: Meeting date, title, task name, description, assignee, due date, priority, category, status

For the Task Tracker, use Google Sheets' **conditional formatting** to color-code rows by priority (High = red, Medium = yellow, Low = green) and highlight overdue tasks with a red background.

def generate_email_html(summary: dict, tasks: list[dict]) -> str:
    """Generate the HTML body for the meeting report email"""
    decisions_html = ''.join(
        f'<li>{d}</li>' for d in summary.get('key_decisions', [])
    )

    tasks_by_priority = {'High': [], 'Medium': [], 'Low': []}
    for t in tasks:

            tasks_by_priority[priority].append(t)

            <tr>
              <td style="padding:8px;border:1px solid #e5e7eb;">{task.get('task_title','')}</td>

              <td style="padding:8px;border:1px solid #e5e7eb;color:{color};font-weight:bold;">{priority}</td>

## Google Calendar Integration: Auto-Creating Follow-Up Events

Automatically adding deadline-bound tasks to Google Calendar gives owners a natural reminder without any manual effort:

```python
def create_calendar_followups(tasks: list[dict], summary: dict):
    """Register deadline-bound tasks as Google Calendar events"""
    creds = service_account.Credentials.from_service_account_file(
        'service-account.json',
        scopes=['https://www.googleapis.com/auth/calendar']
    )
    calendar_service = build('calendar', 'v3', credentials=creds)

    created_count = 0
    for task in tasks:
        due_date = task.get('due_date')
        if not due_date or due_date == 'TBD':
            continue

        try:
            event = {
                'summary': f"[Task] {task.get('task_title', '')}",
                'description': (
                    f"Meeting: {summary.get('meeting_title', '')}\n"
                    f"Owner: {task.get('assignee', 'TBD')}\n"
                    f"Details: {task.get('description', '')}\n"
                    f"Priority: {task.get('priority', 'Medium')}"
                ),
                'start': {'date': due_date},  # All-day event on the due date
                'end': {'date': due_date},
                'colorId': '11' if task.get('priority') == 'High' else '5',
                'reminders': {
                    'useDefault': False,
                    'overrides': [
                        {'method': 'email', 'minutes': 24 * 60},  # 1 day before
                        {'method': 'popup', 'minutes': 60}         # 1 hour before
                    ]
                }
            }

            calendar_service.events().insert(
                calendarId='primary',
                body=event
            ).execute()
            created_count += 1

        except Exception as e:
            print(f"Calendar error ({task.get('task_title')}): {e}")

    print(f"Calendar events created: {created_count}")
```

## Production Readiness: Error Handling and Cost Optimization

### Error Handling Best Practices

For a production system, implement three layers of error handling:

**Layer 1: Retry with exponential backoff**

```python
import time
from functools import wraps

def retry_with_exponential_backoff(max_retries=3, base_delay=1.0):
    """Decorator for retry logic with exponential backoff"""
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(max_retries):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    if attempt == max_retries - 1:
                        raise e

                    # Longer wait for 429 (rate limit) errors
                    wait_time = base_delay * (2 ** attempt) * (5 if '429' in str(e) else 1)

                    print(f"Retry {attempt + 1}/{max_retries}: waiting {wait_time}s")
                    time.sleep(wait_time)
            return None
        return wrapper
    return decorator

@retry_with_exponential_backoff(max_retries=3)
def transcribe_audio_with_retry(audio_data: bytes, file_name: str) -> str:
    return transcribe_audio(audio_data, file_name)
```

**Layer 2: Handling partial failures**

Design each processing step to be independent. If the transcription succeeds but the Calendar registration fails, the email should still go out. Don't let one failure cascade.

**Layer 3: Error logging and alerts**

Set up Cloud Logging for error records and Cloud Monitoring alerts for critical failures. Silent failures are the worst kind — you want to know immediately when something breaks.

### Cost Optimization Strategies

Here are practical ways to keep Gemini API costs in check:

**Chunked transcription for long meetings**: For sessions over an hour, split the audio into 30-minute segments. This keeps you within context limits and often improves accuracy.

**Two-stage summarization**: Use `gemini-2.5-flash` (lower cost) for a rough first pass, then only escalate to `gemini-2.5-pro` for high-priority meetings flagged by the organizer.

**Context caching for prompt templates**: If you use the same system prompt across dozens of meetings, [Context Caching](/en/articles/gemini-api/context-caching-guide) can cut costs by 60–80%.

**Monthly cost estimate (10-person team, 20 meetings/week)**:
- Transcription (gemini-2.5-flash): ~200K tokens per 1-hour meeting × $0.075/1M = $0.015/meeting
- Summary + task extraction (gemini-2.5-pro): ~300K tokens × $1.25/1M = $0.375/meeting
- Monthly (80 meetings): ~$31 — negligible compared to the hours of manual work saved

## Frequently Asked Questions

**Q1: Which Google Workspace plans support Meet recording?**

A1: Meet recording is available on Google Workspace Business Starter and above. The feature must be enabled by your organization's admin. Recordings are automatically saved to the meeting organizer's Google Drive. Personal Google accounts do not have this feature.

**Q2: How accurate is the speech recognition for English meetings?**

A2: Gemini 2.5 Pro's audio understanding performs well with standard business meetings recorded in decent acoustic conditions — expect 90%+ accuracy for clear audio. To improve accuracy for technical jargon or company-specific proper nouns, add context to your prompt: "This meeting discusses the XYZ project and includes terminology such as..." For noisy environments, consider pre-processing the audio with noise reduction (e.g., `pydub` with appropriate filters).

**Q3: What are the key considerations for service account permissions?**

A3: Apply the **principle of least privilege**. Limit Drive access to `drive.file` scope (restricted to files the service account created/opened), and Sheets access to only the specific spreadsheet it needs. Never include your `service-account.json` key file in your codebase or Git repository — store it in Google Cloud Secret Manager. If you're using Domain-Wide Delegation to act on behalf of users, this requires explicit approval from your Workspace admin.

**Q4: How do I handle very long meetings (2+ hours)?**

A4: Gemini API's context limit (1 million tokens for Gemini 2.5 Pro) is sufficient for most business meetings. For 2+ hour sessions, use a "chunk and merge" approach: split the transcript into 30–45 minute segments, generate a summary for each, then pass all partial summaries to a final summarization call. In the code examples above, adjusting `transcript[:8000]` to `transcript[:30000]` with a chunking loop handles this.

**Q5: Is the Apps Script + Cloud Function combination required?**

A5: Apps Script alone can call the Gemini API directly via `UrlFetchApp`, so you can start simpler. However, Apps Script has a hard 6-minute execution limit, which makes it unsuitable for processing long audio files or large transcripts. The recommended split is: Apps Script handles file detection and triggering (lightweight), while Cloud Functions handle the heavy processing (transcription, analysis). This architecture is far more reliable for production.
