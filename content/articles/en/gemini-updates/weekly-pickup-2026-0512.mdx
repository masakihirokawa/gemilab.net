## Minimal Task-Based Model Routing

From article #3, the routing pattern that keeps API costs down by matching task complexity to model tier:

```python
import google.generativeai as genai

TASK_MODEL_MAP = {
    "classification": "gemini-2.5-flash",
    "summarization": "gemini-2.5-flash",
    "code_review": "gemini-3.2-pro",
    "complex_reasoning": "gemini-3.2-pro",
    "structured_output": "gemini-2.5-flash",
}

def call_gemini(prompt: str, task_type: str) -> str:
    model_name = TASK_MODEL_MAP.get(task_type, "gemini-2.5-flash")
    model = genai.GenerativeModel(model_name)
    response = model.generate_content(prompt)
    return response.text

# Example
result = call_gemini("Review this code for security issues: ...", "code_review")
```

The more granular your task taxonomy, the more cost reduction you can achieve. The full classification framework and measured cost comparisons are in the original article.
