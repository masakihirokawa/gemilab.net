## 🥉 #3: Firebase Studio Quickstart Guide

**[Firebase Studio Quickstart Guide: Build Full-Stack AI Apps Fast with Gemini](/articles/gemini-dev/firebase-studio-gemini-quickstart-guide)**

Firebase Studio — Google's new AI-integrated development environment — makes it significantly easier to build production-ready AI applications. With Gemini baked in throughout the workflow, the gap between "idea" and "working app" has shrunk considerably.

This guide walks you through setup, your first Gemini-powered feature, and deployment, in a way that's accessible even if you haven't worked with Firebase before.

```javascript
// Basic Gemini integration in Firebase Studio
import { initializeApp } from 'firebase/app';
import { getVertexAI, getGenerativeModel } from 'firebase/vertexai';

const app = initializeApp(firebaseConfig);
const vertexAI = getVertexAI(app);
const model = getGenerativeModel(vertexAI, { model: "gemini-2.0-flash" });

async function generateContent(prompt) {
  const result = await model.generateContent(prompt);
  return result.response.text();
}
```

If you've wanted to build an AI app but weren't sure where to start, Firebase Studio with Gemini is a strong on-ramp.

# Create a cache for a document referenced repeatedly
cache = genai.caching.CachedContent.create(
    model="gemini-1.5-flash-001",
    contents=[large_document],
    ttl=datetime.timedelta(hours=1),
