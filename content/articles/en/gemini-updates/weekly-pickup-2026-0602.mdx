## #1: 403 when calling Gemini from iOS via Firebase AI Logic

The most-read piece was [Why Firebase AI Logic Returns 403 When Calling Gemini from iOS — And How to Fix It](/articles/gemini-api/firebase-ai-logic-ios-gemini-403-permission-denied-fix). When PERMISSION_DENIED comes back the instant you call Gemini from an iOS app, it's tempting to blame your code — but the cause is usually an un-enabled API on the Firebase side or an App Check setting.

I lost half a day to this 403 on the first day I wired it into a new app. Checking the console's enablement state *before* the client code is the fastest way to isolate it.

## #2: Splitting Gemini 2.5 Flash and Flash-Lite

Second is [Mixing Gemini 2.5 Flash and Flash-Lite for App Store Localization](/articles/gemini-api/gemini-flash-vs-flash-lite-app-localization-cost-quality-review). Short boilerplate goes to Flash-Lite; nuance-heavy descriptions go to Flash. The piece records how I balanced cost and quality in practice.

You don't need to push everything onto the pricier model. Just varying the model by the role of the text visibly lowers the monthly API bill.

## #3: Empty output but finish_reason is MAX_TOKENS

From troubleshooting, [Empty Output but finish_reason Is MAX_TOKENS on Gemini 2.5/3: Cause and Fix](/articles/gemini-api/gemini-thinking-model-empty-output-max-tokens-budget-fix) ranked high. On thinking models, internal thinking tokens can eat the whole budget and cut off before any body text appears.

```python
# Set thinking_budget explicitly and reserve tokens for the body
from google import genai
client = genai.Client()
resp = client.models.generate_content(
    model="gemini-2.5-pro",
    contents="Summarize this.",
    config={
        "thinking_config": {"thinking_budget": 1024},
        "max_output_tokens": 4096,  # reserve body tokens apart from thinking
    },
)
print(resp.text)
```

The key isn't just raising `max_output_tokens` — it's setting `thinking_budget` explicitly so thinking and output tokens are accounted for separately.

## This week in review
