## Code Snippet of the Week

From the Gemini 2.5 Pro production guide, here's a streaming response pattern with timeout handling:

```python
import google.generativeai as genai
import time

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel("gemini-2.5-pro")

def stream_with_timeout(prompt: str, timeout_sec: int = 30) -> str:
    result = []
    start = time.time()
    
    for chunk in model.generate_content(prompt, stream=True):
        if time.time() - start > timeout_sec:
            break
        if chunk.text:
            result.append(chunk.text)
            print(chunk.text, end="", flush=True)
    
    return "".join(result)

response = stream_with_timeout("Explain Gemini 2.5 Pro's key features")
```

Combining streaming with explicit timeout control keeps your user-facing responses predictable even when inference runs long.
