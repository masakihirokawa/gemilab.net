## #1: A production design for cutting tail latency on Gemini API with request hedging

[A production design for cutting tail latency on Gemini API with request hedging](/articles/gemini-api/gemini-api-request-hedging-tail-latency-production-design)

The week's top read was a design article on cutting p99 latency with request hedging. Gemini Flash usually returns in ~800ms, but a few times a month a single call stalls for 5–8 seconds. In my four-site article-generation pipeline, that drift propagates and throws off downstream scheduled tasks.

The article walks through the hedged-request pattern from Google's SRE book: if the primary hasn't returned after 1.5 seconds, fire a second identical call and take whichever finishes first. The cost goes up by roughly 1.1×, but in my production measurements p99 dropped from 4s to 1.8s.

```python
async def hedged_call(prompt: str, hedge_delay_s: float = 1.5):
    primary = asyncio.create_task(call_gemini(prompt))
    done, _ = await asyncio.wait({primary}, timeout=hedge_delay_s)
    if primary in done:
        return primary.result()
    hedge = asyncio.create_task(call_gemini(prompt))
    done, pending = await asyncio.wait({primary, hedge}, return_when=asyncio.FIRST_COMPLETED)
    for p in pending: p.cancel()
    return next(iter(done)).result()
```

## #2: A three-tier cache (memory + Redis + Context Cache) that cut Gemini cost by 60%

[A three-tier cache (memory + Redis + Context Cache) that cut Gemini cost by 60%](/articles/gemini-api/gemini-api-three-tier-cache-memory-redis-context-cache)

Gemini's Context Cache cuts the cost of repeated long-prompt calls noticeably — but it can't absorb "the identical request I made five seconds ago." This article describes how I cover that gap with an in-process memory cache and Redis, then fall through to Context Cache, all wired into my blog ops pipeline.

In my case the input-token bill dropped by roughly 60% month over month. L1 (memory) absorbs request duplication, L2 (Redis) absorbs session-level duplication, L3 (Context Cache) absorbs the template. If you don't lay out what each tier covers, it's easy to drop Context Cache in alone and call it done.
