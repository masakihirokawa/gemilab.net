## 🥇 #1: gemini-2.5-flash-lite Is Now Deprecated — How to Migrate to Gemini 3.1 Flash-Lite

**Category**: Gemini Updates ／ **Level**: Beginner

[gemini-2.5-flash-lite 本日終了 — Gemini 3.1 Flash-Lite への移行](/articles/gemini-updates/gemini-25-flash-lite-shutdown-31-migration-guide)

This article surged to the top of our charts today. As of March 31, 2026, `gemini-2.5-flash-lite` has been officially deprecated. This migration guide walks you through everything you need to update — from model strings to parameter differences — with minimal disruption to your existing code.

For most integrations, the change is a one-liner. But response formatting and a few edge-case behaviors differ, so we strongly recommend testing in a staging environment before pushing to production.

```python
# Before (deprecated)
model = "gemini-2.5-flash-lite"

# After (recommended)
model = "gemini-3.1-flash-lite"

# API call syntax remains the same
import google.generativeai as genai
genai.configure(api_key="YOUR_GEMINI_API_KEY")
model_instance = genai.GenerativeModel(model)
response = model_instance.generate_content("Hello!")
print(response.text)
```

## 🥉 #3: Async Task Processing with Gemini Background Execution

**Category**: Gemini API ／ **Level**: Intermediate

[Gemini Background Execution で非同期タスクを処理する完全ガイド](/articles/gemini-api/gemini-background-execution-async-guide)

Not every AI task can be completed in a single synchronous call. Background Execution opens the door to long-running analysis, batch document processing, and multi-step research pipelines that would otherwise time out or block your application.

```python
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel("gemini-3.1-flash")

# Launch a long-running task asynchronously
operation = model.generate_content_async(
    "Generate a comprehensive analysis report from this data...",
    background=True
)

# Wait for completion (polling or webhook)
result = operation.wait_for_completion()
print(result.text)
```
