Gemini Canvas is Google's take on human-AI collaboration: instead of chatting with an AI and copy-pasting its output, you co-edit the final artifact together in real time on a shared canvas. It's a fundamentally different way to work with AI.


## What Is Gemini Canvas?

Available at gemini.google.com, Gemini Canvas places a live editing area — the "canvas" — alongside the chat interface. The result is that AI-generated content appears directly in a workspace you can immediately edit, annotate, and refine together with the AI.

The contrast with traditional AI chat is significant:

```
Traditional AI Chat                  Gemini Canvas
────────────────────────────────────────────────────
AI generates text                    AI + human co-edit the canvas
→ Copy to clipboard                  in real time
→ Paste into another editor          until the artifact is complete
→ Edit manually
→ Request another revision...
```

## Getting Started

### Step 1: Launch Canvas Mode

```
1. Go to https://gemini.google.com
2. Start a new chat
3. Click the "Canvas" button on the right side of the input field
   (or Canvas launches automatically for document-style prompts)
4. Enter your prompt to generate content
```

### Step 2: Edit the Canvas

Once content is generated on the canvas, you have several ways to refine it:

```
Ways to give instructions:
1. Select text on canvas → Right-click → "Refine with AI"
2. Type "Make the second paragraph more concise" in the chat
3. Select and drag text to rearrange sections
4. Use @mention to direct the AI to a specific part
```

### Step 3: Version History and Sharing

```
Canvas controls:
- Ctrl+Z: Undo the last change
- "Version History": Review the full co-editing history
- "Share": Generate a shareable link
- "Export": Download as .docx / .md / .pdf
```

### Real-Time Code Development and Debugging

Gemini Canvas also works as a code editor:

```python
# Example: Generating and editing Python code in the canvas

# 1. Prompt: "Write a user authentication module in Python on the canvas"
# 2. Code appears on canvas
# 3. Select a section → "Change this to use JWT authentication"

# Canvas suggests updated code:
import jwt
from datetime import datetime, timedelta

def create_token(user_id: str, secret: str) -> str:
    """Generate a JWT token"""
    payload = {
        "user_id": user_id,
        "exp": datetime.utcnow() + timedelta(hours=24),
        "iat": datetime.utcnow()
    }
    return jwt.encode(payload, secret, algorithm="HS256")

def verify_token(token: str, secret: str) -> dict:
    """Verify a JWT token"""
    try:
        return jwt.decode(token, secret, algorithms=["HS256"])
    except jwt.ExpiredSignatureError:
        raise ValueError("Token has expired")
    except jwt.InvalidTokenError:
        raise ValueError("Invalid token")

# 4. "Add comprehensive error handling" → canvas updates automatically
# 5. "Copy Code" when done
```

## FAQ

**Q: Is Gemini Canvas free?**

Basic features are available with a free Gemini account. Generation volume limits apply; Google AI Pro/Ultra plans relax those limits.

**Q: Does it work offline?**

An internet connection is currently required. However, you can export finished content and work with it offline.

**Q: Can it integrate with other Google services?**

Direct export to Google Docs and Drive is supported. Some Google Sheets integration (for data display) also works.

**Q: Can I run code directly in the canvas?**

Gemini Canvas supports code generation and editing, but not execution. The typical flow is to generate code in Canvas, then run it in Google Colab or AI Studio.

**Q: How is the quality for non-English content?**

Gemini 2.5 Pro powers the canvas, so non-English quality — including Japanese — is excellent for most professional writing tasks.
