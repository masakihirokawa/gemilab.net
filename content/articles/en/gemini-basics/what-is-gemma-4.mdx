On April 2, 2026, Google released Gemma 4 — described as "the most capable open models byte for byte." Released under the Apache 2.0 license, Gemma 4 is freely available for both research and commercial use, making it one of the most significant open model releases of the year.

Here's what you need to know.

## Four Model Sizes for Every Use Case

Gemma 4 comes in four sizes, each designed for a different deployment context.

**E2B (Effective 2B)** is the lightest model in the family, optimized for edge deployment and on-device inference. It natively processes audio in addition to text and images, making it well-suited for voice-enabled mobile applications.

**E4B (Effective 4B)** steps up in capability while remaining efficient enough for edge environments. Like E2B, it supports native audio input for speech recognition and understanding.

**26B MoE (Mixture of Experts)** uses a sparse MoE architecture, activating only the relevant "expert" sub-networks for each inference. This gives it strong capability relative to its total parameter count, with current rankings placing it 6th among all open models on the Arena AI text leaderboard.

**31B Dense** is the flagship model in the Gemma 4 family. Currently ranked 3rd among all open models globally, it outperforms several models with far higher parameter counts — including some in the 400B range.

## Native Multimodal: Video, Images, and Audio

Every Gemma 4 model natively processes video and images, not as an add-on but as a core capability. This enables tasks like:

Reading and extracting text from scanned documents via OCR. Interpreting charts, graphs, and diagrams to extract quantitative data. Understanding the content of video clips and generating summaries.

The E2B and E4B models go a step further with **native audio input**, enabling applications that combine speech recognition with language understanding in a single model pass.

## Extended Context Windows

Gemma 4 significantly extends the context windows available for both edge and cloud deployments.

Edge models (E2B, E4B) support **128,000 tokens** — a 4x increase over Gemma 3's context limit, enabling longer conversations and more complex documents to be processed in a single pass. The larger models (26B, 31B) extend this further to **256,000 tokens**, making it practical to pass entire codebases or long technical documents within a single prompt.

## 140+ Languages Natively Supported

Gemma 4 was trained natively across more than 140 languages, enabling high-quality multilingual applications without relying on translation layers. This makes it a practical foundation for global products and services that need to work well across diverse language communities, including many that have historically been underserved by AI models.

## Agent-Ready: Function Calling, JSON Output, System Instructions

Gemma 4 includes native support for the building blocks of autonomous agents:

Function calling lets the model interact with external APIs and tools. Structured JSON output makes it reliable for data extraction and pipeline integration. Native system instructions allow fine-grained control over model behavior.

Together, these capabilities make Gemma 4 a practical foundation for building agents that can plan, retrieve information, and act — not just respond.

## License and Access

As an Apache 2.0 model, Gemma 4 can be used commercially without licensing fees or restrictions. You can access it through:

[Google Cloud Vertex AI](https://cloud.google.com/blog/products/ai-machine-learning/gemma-4-available-on-google-cloud) for managed API access. [LM Studio](https://lmstudio.ai/models/gemma-4) for local, offline inference on your own hardware. Hugging Face for direct model weight downloads and self-hosted deployment.

## Why Gemma 4 Matters

The combination of multimodal capability, extended context, agent-ready features, and an open license is genuinely unusual. Most models with Gemma 4's performance profile are either closed-access or come with restrictive licensing. The fact that a model ranking in the top 3 of all open models globally is freely available for commercial use raises the floor significantly for what developers can build without depending on proprietary APIs.

Whether you're building mobile applications with on-device AI, cloud-scale data processing pipelines, or multilingual products for underserved markets, Gemma 4 is worth a serious look.
