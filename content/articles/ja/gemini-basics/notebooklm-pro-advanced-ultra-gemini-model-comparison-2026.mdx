「NotebookLM Pro と Advanced と Ultra、結局どれを契約すれば最新の Gemini が使えるんですか？」— 最近この質問を立て続けに受けました。検索結果を見ると無理もない話で、Google は 2024 年に「Gemini Advanced」というブランドを廃止しているのに、いまだに Advanced という言葉が独り歩きしています。NotebookLM 単独のプランも別に存在していたため、用語が二重三重に入り組んでいるのが現状です。

ここでは2026年4月時点で **NotebookLM の中で実際に動いている Gemini モデルと、無料・Google AI Pro・Google AI Ultra の3層でできること** を整理します。プラン選びで迷っている方が、自分のユースケースに必要な層を10分で判断できる構成にしました。

Gemini API を実プロダクトで運用してきた知見から、この問題に普段から向き合ってきた立場で、要点を整理します。

## まず用語を整理します — 「Advanced」は今どこにあるのか

検索クエリで頻出する「NotebookLM Pro vs Advanced vs Ultra」という3項対立は、実は**正確には現存しません**。整理すると次のようになります。

- **Gemini Advanced**: 2024年初頭に登場した有料プラン名。2025年中に **Google AI Pro** へとブランド変更され、2026年現在は名称として存在しません
- **Google AI Pro**: 旧 Gemini Advanced の後継。月額プランで、NotebookLM の高機能枠（旧 NotebookLM Plus）も含まれます
- **Google AI Ultra**: 2025年に新設された最上位プラン。Deep Think 推論モードや Project Mariner といった研究プレビュー機能、強化された生成枠が含まれます
- **NotebookLM Plus**: 2024年にスタンドアローン製品として登場しましたが、現在は Google AI Pro / Ultra に内包される形で提供されています

つまり「Advanced」を探している方の多くは、実質 **Google AI Pro** を見ていることになります。本記事でも以降は AI Pro / AI Ultra という現行名称で統一します。

## 各プランで使える Gemini モデル

NotebookLM の内部では、ユーザーから直接モデル名を選ばせるインターフェイスは出していません。ただし「NotebookLM の応答品質はどのモデルで動いているのか」は、プランによって明確に差があります。

- **無料プラン**: Gemini 2.5 Flash 系を中心に、軽量な応答が割り当てられます。長文の引用・複雑な推論が必要な場面では、応答の深さに天井を感じる場面があります
- **Google AI Pro 加入時**: NotebookLM が **Gemini 2.5 Pro 相当** の推論を呼び出すようになります。長文ソースの要約品質、複数ソース横断の整合性が一段上がるのはこの層からです
- **Google AI Ultra 加入時**: AI Pro の機能をすべて含み、加えて **Deep Think モード**（複雑な推論を時間をかけて掘り下げる機能）や、より高い生成枠が利用できます。NotebookLM 内では「より深い分析」が要求される質問に対して、応答までの待機時間が伸びる代わりに考察の網羅性が増します

技術的には NotebookLM は単一モデルではなく、タスクの性質に応じて Gemini ファミリーを使い分けるハイブリッド設計になっています。そのため「常に最上位モデルが呼ばれる」という理解は正確ではなく、**プラン契約は『どの上限に到達できるか』を決めるもの**と捉えるほうが実態に近いと感じています。

## ソース数・生成枠の違い

モデル品質と並んで、プラン選択の決め手になるのがソース数と生成枠です。2026年4月時点の数字でまとめます（公式ヘルプの記載ベース）。

- **無料プラン**:
  - ノートブック数: 100
  - ノートブック1冊あたりのソース数: 50
  - 1日の質問数: 50
  - 音声概要（Audio Overview）: 1日3回
- **Google AI Pro 加入時**:
  - ノートブック数: 500
  - ノートブック1冊あたりのソース数: 300
  - 1日の質問数: 500
  - 音声概要: 1日20回（カスタム指示・対話型音声も解放）
  - 動画概要（Video Overview）: 1日5回
- **Google AI Ultra 加入時**:
  - AI Pro と同一上限に加え、優先処理キュー
  - 動画概要: 1日20回
  - Deep Think 推論モードの利用枠

数字は段階的に増えていますが、**最も体感差が出るのはソース300件への拡張** です。50件の壁は研究・調査・社内ドキュメント分析を本格的に行うとすぐに到達します。逆に、教科書1〜2冊や論文数本を読み解く程度であれば、無料枠で十分に戦えます。

## 「どのプランを選ぶべきか」の判断軸

個人的に運用しているユースケース別の判断軸を共有します。検索エンジンに頼らず、自分の使い方から逆算するのが結局いちばん早いと感じています。

### 無料で十分なケース

- 月に数冊の本や論文を読み解く読書補助として使う
- 学生で、レポート作成のために特定の教科書から引用を探す
- ブログ記事を書くために、既に集めた数十ページの資料を整理する

このレベルなら無料枠の音声概要1日3回・ソース50件でも困りません。むしろ無理に課金して使い切れず後悔する方が損失です。

### Google AI Pro が活きるケース

- **業務でドキュメント分析が日常化している**: 会議資料・議事録・仕様書を継続的に放り込んで横断検索したい場合、ソース300件は2〜3週間で埋まります
- **音声概要を社内共有や通勤時の学習に使う**: 1日20回の枠とカスタム指示が解放されるため、テンプレートを整えれば実用ツールになります
- **NotebookLM 単体のためではなく、Gemini アプリ・Gmail・Docs 全体の Gemini 統合と合わせて月額を回収したい**: AI Pro は NotebookLM 専用課金ではないため、Workspace 連携全体で価値を測るのが正しい比較です

このあたりの全体像は [Google AI Pro と Ultra プランの料金とサービス全比較](/articles/gemini-basics/google-ai-pro-ultra-pricing-services-complete-guide-2026) で詳しく整理しています。

### Google AI Ultra を選ぶ意味があるケース

- 研究職・コンサル・編集者など **「Deep Think で時間をかけて掘り下げる価値」がある業務** に従事している
- Project Mariner や Veo 3 など、Ultra でしか触れない研究プレビュー機能を本気で評価したい
- AI Pro の上限（音声概要1日20回・動画概要5回）を日常的に使い切っている

Ultra は価格が大きく跳ねるので、**「Pro を1〜2ヶ月使って上限が常に張り付くようになってから検討する」**順序がおすすめです。最初から Ultra にすると、機能を活かしきれず月額が重荷になりがちです。Mariner や Deep Think の実用評価は [Google AI Ultra Deep Think と Mariner は本当にお金を払う価値があるか](/articles/gemini-advanced/google-ai-ultra-deep-think-mariner-worth-it) を参考にしてみてください。

## API 経由で同じモデルを使うという選択肢

NotebookLM の体験そのものを置き換えることはできませんが、「Gemini 2.5 Pro / 3.1 系の応答品質だけが欲しい」のであれば **Gemini API を直接呼ぶ選択肢** があります。

```python
# 必要パッケージ: pip install google-genai
# 環境変数: GEMINI_API_KEY を設定
import os
from google import genai

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

# モデル名は安定エイリアスを推奨
# - "gemini-2.5-pro-latest" は最新の安定版を指す
# - 本番では具体的なバージョン文字列に固定することを推奨します
response = client.models.generate_content(
    model="gemini-2.5-pro-latest",
    contents="この PDF の重要ポイントを5つ挙げ、各ポイントに引用元の段落番号を付けてください。",
)

print(response.text)
# 期待出力: 各ポイントが「・要点(段落X)」形式で5項目並ぶ
```

API 経由なら、NotebookLM のソース数上限とは別に、自前で RAG パイプラインを組めます。月額固定よりも従量課金のほうが安く済むケースも多く、たとえば「月に数十回の長文要約だけが必要」な個人開発者には API のほうがフィットすることが多いです。実装パターンは [Gemini 2.5 Pro Latest API 本番運用ガイド](/articles/gemini-api/gemini-25-pro-latest-api-production-guide) にまとめています。

## NotebookLM ならではの価値はどこに残るか

「API があるなら NotebookLM は要らないのでは」と聞かれることもありますが、私の答えは **NotebookLM の本当の価値は UI と引用整合性にある** です。具体的には次の3点が大きいです。

- **引用の自動付与**: 応答の各文に「ソースのどこから来たか」が紐づく。これを自前で実装すると、PDF のページ単位パース・チャンク管理・出典マッピングだけで丸1日溶けます
- **音声概要・動画概要のワンクリック生成**: 内部で複数のモデルとパイプラインが連携している成果物を、無料〜月額で叩けるのは破格です
- **コラボレーション**: ノートブック単位の共有が前提に作られているため、研究室・編集チーム・社内勉強会のような「複数人で同じ資料を読み込む」場面で摩擦が少ない

逆に「自分1人で使う」「Slack や独自 UI に組み込みたい」「データを外に出せない」場合は API のほうが筋がよく、無理に NotebookLM の枠に閉じ込める必要はありません。

## まとめ — まずは無料で輪郭を掴むのが最短

プラン選びで迷っている方への私の勧めは、**1週間ガッツリ無料枠を使って、何が足りなくなるかを観察する** ことです。ソース50件の壁にぶつかるのか、音声概要の3回上限が惜しくなるのか、応答の深さが物足りないのか。足りないものが見えてはじめて AI Pro / Ultra のどちらに進むかが決まります。
