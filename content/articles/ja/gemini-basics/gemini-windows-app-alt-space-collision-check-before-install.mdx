Windows 版の Gemini アプリが公開されたと知って、公式のヘルプセンターを開いたのは夜でした。インストールの手順は五行で終わっており、ショートカットは「Alt + Space で呼び出せます」とあります。

私が探していたのは、その先です。キーを押しても何も起きなかったとき、どこを見ればよいのか。ところがヘルプには、ショートカットが効かないときの項目も、キーを変えられる場所の案内も、載っておりませんでした。

私自身の作業机は iMac で、Windows 版は手元で動かしておりません。ですのでこの記事は、動かして確かめた記録ではなく、公式の記載と Windows の仕組みから組み立てた「確かめる順番」です。その前提でお読みいただければ幸いです。

**キーが効かないときは、壊れているかを疑う前に、誰が先に握っているかを数えます。** 以下はその数え方です。

## 最初にお伝えしたいのは、Alt + Space はもともと空いていないということです

Windows では、アクティブなウィンドウで Alt + Space を押すと、左上の「システムメニュー」（元のサイズに戻す、移動、サイズ変更、閉じる）が開くのが標準の動きです。そこに、Gemini がグローバルなショートカットとして同じキーを登録しにいきます。

日本語の紹介記事の中にも、Alt + Space は他のアプリと競合することが多い、という注意書きがありました。常駐ツール同士のキーの取り合いは、後から入れたものが負けても、画面には何も出ないのが厄介なところです。

## 入れる前の三点確認

公式のヘルプに書かれている条件は、次の三つに絞れます。

<table>
<thead>
<tr><th>確認すること</th><th>公式の記載</th><th>見る場所</th></tr>
</thead>
<tbody>
<tr><td>パソコンの条件</td><td>Windows 10 以降、メモリ 8 GB 以上、空き容量 200 MB 以上、安定したネット接続。x64 と ARM64 に対応</td><td>設定 → システム → バージョン情報</td></tr>
<tr><td>使うアカウント</td><td>個人の Google アカウントは利用可。仕事用・学校用は、管理者が Gemini へのアクセスを有効にしている場合のみ</td><td>ログインできなければ管理者へ</td></tr>
<tr><td>導入の流れ</td><td>公式サイトから GeminiSetup.exe を保存して実行し、スタートメニューの Gemini を開いて Google アカウントでログイン</td><td>gemini.google/desktop</td></tr>
</tbody>
</table>

仕事用のアカウントでログインできない場合は、キーの問題ではなく管理者側の設定の問題です。切り分けの考え方は[Gemini の新機能が Workspace に出てこないときの記事](/articles/gemini-workspace/gemini-workspace-feature-rollout-wait-or-fault-triage)にまとめております。

## 入れる前に、同じキーを使いそうなものを数えます

インストールの前に、メモ帳でかまいませんので次の三つを書き出します。

- 常駐しているランチャーや検索ツール、ほかの AI アシスタント（通知領域に出ているアイコンを数えます）
- 画面のキャプチャや翻訳、辞書の呼び出しなどに、自分で割り当てたキー
- 入力切り替えや、キーボード設定ツールに登録したキー

三つとも空であれば、そのまま入れて問題ありません。何か書き出せたときは、そのキーの割り当てを先に確認しておくと、後で「どちらが効いていないのか」を探さずに済みます。

## 押しても出なかった日の切り分けは、この五つの順です

ここからが、本題の順番です。上から順に、一つ確かめるたびに結果を書き残してください。

1. **Gemini が本当に起動しているかを見ます。** スタートメニューから Gemini を開き、タスクバーか通知領域にアイコンがあるか確認します。起動していなければ、キーは当然効きません。
2. **押した瞬間に別のものが反応していないかを見ます。** ウィンドウ左上にシステムメニューが開いたなら、Windows 側が先にキーを受け取っています。ほかのアプリが反応したなら、そのアプリが握っています。
3. **常駐物を一つずつ止めて試します。** 先ほど書き出した一覧を、一つ止めては押す、を繰り返します。同時に止めると、どれが原因か分からなくなります。
4. **Gemini 側のショートカットを変えます。** 公式サイトと日本語の紹介記事には、設定からショートカットを変更できると書かれています。ただしヘルプセンターには変更場所の案内がありません。設定画面の中を探していただく形になります。
5. **それでも駄目なら、タスクバーかスタートメニューから開く運用に切り替えます。** キーを使えなくても、アプリそのものは使えます。呼び出しの速さより、毎日確実に開けることを優先します。

私はこういう場面で、早く片づけたくて、三つ目と四つ目を同時にやりがちでした。結果は芳しくありませんでした。原因が分からないまま、直ったという事実だけが残るのです。

## 期待しすぎないために、Windows 版でまだ使えないもの

日本語の紹介記事によると、Mac 版にある次の機能は、Windows 版では未提供で、今後順次提供される予定です。

<table>
<thead>
<tr><th>機能</th><th>Mac 版</th><th>Windows 版</th></tr>
</thead>
<tbody>
<tr><td>画面共有（画面の内容を見せて質問）</td><td>Command を二回同時に押して起動</td><td>未提供</td></tr>
<tr><td>音声入力</td><td>どのアプリにも口述できる</td><td>未提供</td></tr>
<tr><td>ローカルフォルダーの操作（Gemini Spark）</td><td>要約を Docs や Sheets に出力</td><td>未提供</td></tr>
<tr><td>呼び出しのキー</td><td>Option + Space（小さなチャット）／Option + Shift + Space（フルのチャット）</td><td>Alt + Space</td></tr>
</tbody>
</table>

「キーを押しても画面共有が始まらない」という困りごとは、衝突ではなく、まだ存在しない機能を探している可能性があります。公式サイトも、提供状況は変わるとしており、時期は示していません。

## 今日やることは一つだけです

インストーラーを開く前に、通知領域のアイコンを数えて、メモ帳に書き出してください。それだけで、押しても出ない夜の捜索範囲がかなり狭くなります。

私は今日も、画面の隅の小さなアイコンが何をしているのかを、一つずつ確かめるところから作業を始めています。
