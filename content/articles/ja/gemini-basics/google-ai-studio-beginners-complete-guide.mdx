## Google AI Studio とは？——無料で使える Gemini の開発プラットフォーム

Google AI Studio（[aistudio.google.com](https://aistudio.google.com)）は、Google が提供する**ブラウザベースの AI 開発プラットフォーム**です。プログラミング知識がなくてもテキスト生成、画像認識、コード分析などが可能で、API キーを取得すれば自分のアプリケーションに Gemini AI を統合できます。

### 主な特徴

**完全無料（無料枠あり）**
- アカウント作成から API 利用まで、すべて無料で開始可能
- 月間上限内であれば課金の心配なし
- 詳細な使用量は無料枠ダッシュボードで確認

**UI がシンプルで直感的**
- 複雑なコード記述不要（テキストとクリックだけで試験可能）
- プロンプト（指示）をリアルタイムに実験
- テンプレートが充実（チャットボット、コンテンツ生成、翻訳など）

**本格的な API 統合に対応**
- Python、JavaScript、Go など複数の SDK が用意
- OpenAI の API と同じように呼び出し可能（互換性も部分的に存在）
- Gemini 2.5 Pro / Flash など最新モデルへの即座なアクセス

## アカウント作成と API キーの取得手順

Google AI Studio を始めるまでの流れを、ステップバイステップで解説します。

### Step 1: Google AI Studio にアクセス

ブラウザで [aistudio.google.com](https://aistudio.google.com) を開きます。既に Google アカウントでログインしている場合は、即座にダッシュボードが表示されます。ログインしていない場合は、画面の指示に従い Google アカウントでサインインしてください。

### Step 2: 無料の API キーを生成

1. 左側ナビゲーションメニューの **「API Keys」** をクリック
2. **「+ Create API Key」** ボタンをクリック
3. **「Create API key in a new Google Cloud project」** を選択（推奨）

Google が自動的に新しい Google Cloud プロジェクトを作成し、API キーが生成されます。

### Step 3: API キーをコピーして保存

生成された API キーは 1 回だけ表示されます。**必ず別の場所にコピーして保存してください**。紛失した場合は新しいキーを再生成する必要があります。

セキュリティのため、以下の方法で安全に管理することを推奨します：

**環境変数として設定（推奨）**

```bash
# Linux / Mac
export GEMINI_API_KEY="your_actual_api_key_here"

# Windows（コマンドプロンプト）
set GEMINI_API_KEY=your_actual_api_key_here

# Windows（PowerShell）
$env:GEMINI_API_KEY="your_actual_api_key_here"
```

**Python ファイルでの読み込み**

```python
import os
api_key = os.environ.get("GEMINI_API_KEY")
```

**注意：** API キーをコード内に直接記述（`api_key = "AIzaSy..."`）したり、GitHub にコミットしてはいけません。リークされると他者が無料枠を消費するリスクがあります。

## Google AI Studio の主要機能を使いこなす

Google AI Studio には、AI との対話を強化するための複数の機能があります。

### 1. Prompt（プロンプト）

プロンプトは、AI に与える「指示」です。明確で具体的なプロンプトを書くほど、より正確な結果が返ってきます。

**良いプロンプトの例：**
```
日本語で、初心者向けに「Gemini API」とは何かを、300 文字で説明してください。
```

**悪いプロンプトの例：**
```
Gemini について説明して
```

### 2. System Instructions（システム指示）

AI の「性格」や「行動」を定義するメタプロンプトです。全てのリクエストに適用されます。

例えば、カスタマーサポート チャットボットを作る場合：

```
あなたはテクノロジー企業のカスタマーサポート担当者です。
以下のガイドラインに従ってください：
- 丁寧で親切なトーンを保つ
- 回答は必ず 3 文以内に簡潔にする
- 技術用語を使う場合は説明を付ける
- わからない場合は「申し訳ありません。詳細は弊社サポートへお問い合わせください」と答える
```

### 3. Temperature（温度・創造性パラメータ）

AI の「創造性」をコントロールするパラメータです：

- **低（0.0 〜 0.3）** — 一貫性重視。事実ベースの回答や翻訳に最適
- **中（0.5 〜 0.7）** — バランス型。通常のチャットやコンテンツ生成に推奨
- **高（0.8 〜 1.0）** — 創造性重視。創作やブレインストーミング向け

データ分析レポートを生成するなら Temperature を低めに、プロダクト アイデア出しなら高めに設定します。

### 4. Google Search Grounding（ウェブ検索グラウンディング）

AI がリアルタイムのウェブ情報を参照して回答する機能です。

- **有効** — 最新のニュース、株価、イベント情報など、常に更新される情報に対応
- **無効** — 学習済みの一般的な知識で十分な場合（トレーニング速度も向上）

「今日の天気」や「2026年最新の AI 技術」といった質問には、この機能を有効にすると正確です。

## Your First Gemini API Call in Python

実際に Python で Gemini API を呼び出すコードを書いてみましょう。これが、本格的なアプリケーション開発への第一歩です。

### インストール

```bash
pip install google-generativeai
```

### 最初のコード

```python
import os
import google.generativeai as genai

# API キーを環境変数から読み込む
api_key = os.environ.get("GEMINI_API_KEY")
genai.configure(api_key=api_key)

# Gemini モデルを初期化
model = genai.GenerativeModel("gemini-1.5-flash")

# テキスト生成（シンプルな例）
response = model.generate_content(
    "日本語で、AI の可能性について 200 文字で説明してください。"
)

print(response.text)
```

**実行結果例：**
```
AI は大量のデータから複雑なパターンを学習し、
人間の判断を補助したり、創造的タスクを自動化したりできます。
医療診断から芸術制作まで、あらゆる分野での応用が進んでいます。
```

### マルチターン会話（チャットボット）

複数の質問を通じた継続的な会話も可能です：

```python
chat = model.start_chat(
    history=[
        {"role": "user", "parts": "あなたは日本語の先生です。"},
        {"role": "model", "parts": "はい、喜んでお手伝いします。"},
    ]
)

# 会話を続ける
response = chat.send_message("『努力』の使い方を例文で教えてください。")
print(response.text)

response = chat.send_message("その例文を英語に訳してください。")
print(response.text)
```

## 無料枠の上限と有料プランへの移行タイミング

Google AI Studio は無料で始められますが、利用量に応じて段階的に有料プランへの移行を検討する必要があります。

### 無料枠の上限

| リソース | 無料枠 |
|---------|--------|
| Gemini 1.5 Flash | 1分あたり15リクエスト |
| Gemini 2.5 Pro | 1分あたり2リクエスト |
| Vision（画像解析） | 1日100リクエスト |
| Embedding（埋め込みモデル） | 1分あたり1000リクエスト |

**注意：** 無料枠を超過しても自動的に課金されません。その代わり、リクエストが拒否（429 エラー）されます。

### 有料プランへの移行タイミング

有料プランへ移行すべき目安：

- **アプリケーション本番化** — ユーザーが日常的に利用する場合
- **毎日 1000 件以上のリクエスト** — 無料枠では対応不可
- **より高速で高精度なモデルが必要** — Gemini 2.5 Pro の利用頻度が高い

有料利用時は、Google Cloud Console で「予算管理」を有効化し、予期しない高額請求を防ぐことを推奨します。
