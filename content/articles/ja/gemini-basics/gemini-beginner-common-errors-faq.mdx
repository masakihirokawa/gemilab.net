Gemini の画面を開いたまま、同じ質問を三回送り直したことがあります。回答が途中で切れ、画像は読み込まれず、Workspace の連携も反応しない夜でした。慌てて設定を片っ端から触った結果、どれが効いたのか分からなくなり、翌朝にもう一度やり直すことになりました。

最初にお伝えしたいのは、初心者の方がつまずく不具合の多くは「設定を疑う前に、新しい会話とログイン中のアカウントを確かめる」だけで片づく、ということです。ここでは、私が実際に何度か踏んだ順番で、7つの症状と切り分けの手順を書き残します。

:::info
画面の名称やプランの内容、ファイルの上限値は更新のたびに変わります。数値は目安として読み、最終的には Gemini の公式ヘルプで確かめてください。
:::

## Q1: 回答が途中で止まる、出力が途切れるのはなぜですか？

いちばん多く見かける症状です。長い文章を頼むと、文の途中でぷつりと終わります。

考えられる原因は三つあります。

1. 一度に出力できる長さの上限に達した
2. 会話が長くなり、やり取りの履歴が膨らみすぎた
3. ネットワークやサーバー側の一時的な不調

対処は、副作用の少ない順に次のとおりです。

- 「続きをお願いします」と送り、止まった地点から再開できるか見る
- 質問を「見出しだけ」「第1章だけ」のように分けて頼み直す
- 新しい会話を開き、必要な前提だけを貼り直す
- 回線を確かめ、別のブラウザで開き直す

私は最初のうち、長文を一回で出させようとしすぎました。結果は芳しくなく、途切れるたびに質問を足して、かえって履歴を重くしていたのです。いまは最初から「構成案」「本文」「推敲」の三回に分けています。**長い仕事は、一回で頼まず、区切って渡すようにしています。**

:::tip
「800字程度で」のように、ほしい長さを先に伝えておくと、途中で止まる頻度が下がります。
:::

## Q2: 画像を送っても「処理できません」と返されるのはなぜですか？

画像を読み取れるはずなのに、断られる場合があります。原因は大きく五つに分かれます。

1. 形式が合っていない。JPEG や PNG に変換すると通ることが多いです。
2. ファイルが壊れている、または転送が途中で終わっている
3. サイズが大きすぎる。数MB程度まで縮小して試します。
4. 内容がポリシー上の制限に触れている
5. ブラウザ側のキャッシュが悪さをしている

私の経験では、スマートフォンで撮った写真が特殊な形式で保存されていて、変換したら通ったことが何度かありました。まず別の画像で試し、通るなら元の画像の側に原因があります。

:::warning
個人情報や機密情報が写り込んだ画像は、アップロードしないでください。
:::

## Q3: 日本語で質問したのに英語で返ってくるのはなぜですか？

アカウントや端末の表示言語が英語になっている場合と、プロンプトの側に言語の指定がない場合があります。

- Google アカウントの言語設定と、ブラウザの言語設定を日本語に揃える
- プロンプトの先頭に「以下はすべて日本語で答えてください」と書く
- 英語の資料を貼るときは、「要約は日本語で」と付け加える

英語の長い資料を貼った直後に英語で返ってきたのは、私の指定が足りなかったからでした。言語の指定は一行で済みますので、定型文として手元に置いておくと楽です。

## Q4: Google Workspace 連携（Gmail や Drive の参照）が動かないのはなぜですか？

確認する順番は、手元から管理側へ、です。

1. 使っているアカウントが、仕事用か個人用か。複数ログイン中だと取り違えます。
2. 連携や拡張機能の設定が、そのアカウントで有効になっているか
3. ログアウトして入り直し、新しい会話で試す
4. 組織のアカウントなら、管理者がその機能を許可しているか

最後の項目は、手元では直せません。管理者の方に「Gemini と Workspace アプリの連携を有効にしていただけますか」と依頼するのが近道です。

:::warning
Gmail の連携は、Gmail 本体を使っている場合の機能です。他社のメールを転送しているだけの環境では、期待どおりに動かないことがあります。
:::

## Q5: ファイルのアップロードでエラーになるのはなぜですか？

ファイル形式、サイズ、枚数の三つを順に見ます。

- 形式: PDF、テキスト、画像、Google ドキュメントなどは扱えますが、実行ファイルなどは扱えません。
- サイズ: 上限を超えていないか。大きな PDF は、必要なページだけを書き出して渡します。
- 枚数: 一度に添付できる数には上限があります。

私は分厚い PDF を丸ごと渡して、何度も失敗したことがあります。必要な章だけを切り出したところ、すぐ通りました。Drive に置いてから参照させる方法も、手堅い選択肢です。

:::tip
添付する前に、機密情報が含まれていないかを一度だけ見直す癖をつけておくと安心です。
:::

## Q6: 拡張機能（連携）を有効にしても反映されないのはなぜですか？

設定を変えた直後の会話には、変更が反映されないことがあります。

1. 設定画面で、その拡張機能が有効になっているか確かめる
2. 新しい会話を開いて、もう一度試す
3. 外部サービスと連携しているものは、いったん連携を解除して認証し直す
4. ブラウザのキャッシュを消し、別のブラウザでも試す

認証の期限が切れていただけ、ということが、私の場合は一番多い原因でした。いま思えば、設定を疑う前に入り直すだけで済んだ場面ばかりだったのだと思います。

## Q7: 有料プランのはずなのに、機能が使えません。どこを見ればよいですか？

プランの名称や中身は、これまでに何度も入れ替わってきました。そのため、記事に書いてある名前ではなく、ご自身の契約画面を基準にします。

1. 契約中のプランと、支払い状況を Google アカウントの管理画面で確かめる
2. 購入した Google アカウントで、Gemini にログインしているか。複数アカウントでの取り違えが多いです。
3. 購入直後は、反映まで少し時間がかかることがあります。
4. 地域や年齢、組織アカウントの制限で、提供対象外になっていないか
5. 通常のウィンドウで、拡張機能やプライバシー設定を一度外して試す

「買ったのに使えない」と感じたとき、私は決まって別のアカウントで入っていました。契約を疑う前に、右上のアイコンのメールアドレスを見てください。

## 切り分けの順番だけ、手元に残しておく

7つの症状に共通する順番は、次のとおりです。

1. 新しい会話で、同じ質問を送り直す
2. ログイン中のアカウントを確かめる
3. 別のブラウザ、または別の端末で試す
4. 設定と権限、プランを見る
5. それでも直らなければ、公式ヘルプとサポートに状況を伝える

**設定を触る前に、まず場所を変えて同じことを試します。** この線引きを守るようになってから、半日かかっていた原因探しが、十分ほどで終わるようになりました。

まずは次に不調を感じたとき、設定画面を開く前に、新しい会話で同じ質問を一度だけ送り直してみていただければと思います。
