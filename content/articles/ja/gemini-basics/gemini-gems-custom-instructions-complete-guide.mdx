Gemini Gemsは、Google AIが提供する高度なカスタマイズ機能です。その中でも「カスタム指示（Custom Instructions）」は、あなたのGeminiとの対話を大きく変える強力なツール。ここではセットアップから実践的な活用法まで、誰でも理解できるように解説します。

## Gemini Gemsとは：AIアシスタントをカスタマイズする機能

Gemini Gemsは、単なるプリセット機能ではなく、AIの「性格」「回答スタイル」「専門知識」をあなた好みに調整できるプラットフォームです。

**Gemini Gemsの基本的な役割：**

- **プリセット作成**: 異なる目的ごとに複数のGeminiを用意できる
- **カスタム指示**: 各Geminiに対して「いつも守るべきルール」を設定
- **長期メモリ**: ユーザーの好みや背景を記憶してくれる
- **スキル統合**: Google Tools（Sheets、Gmail等）との自動連携

カスタム指示はその中でも基本となる機能。これを使いこなすことで、Geminiはあなたの「仕事パートナー」「学習アシスタント」「ブレストの相手」に変身します。

## カスタム指示（Custom Instructions）の設定手順

### ステップ1: Gemini Gemsのダッシュボードを開く

まず、[Gemini Gems](https://gemini.google.com/gems) にアクセスしてください。Googleアカウントにログインしていることを確認します。

1. ページ左側のメニューから「+ Create a new Gem」をクリック
2. 「Blank Gem」を選択して新規作成を開始

### ステップ2: Gemの基本情報を入力

新しいGemを作成する画面が開きます。以下の情報を設定します：

**Gem Name（Gem名）**
- 例）「英語学習アシスタント」「マーケティングブレーンストーム」「コードレビュー専門家」
- 後で変更可能なので、わかりやすい名前をつけましょう

**Gem Description（説明）**
- このGemがどんな目的で使われるのかを簡潔に記述
- 例）「英語の発音・文法・自然な表現を教えてくれるパートナー」

### ステップ3: カスタム指示を記述する

いよいよカスタム指示の本体を書きます。これが最も重要なパート。

「Custom Instructions」というテキストエリアに、Geminiに対する指示を記述します。複数行でも大丈夫です。

**指示の記述方法のコツ：**

- **明確さ**: 曖昧な表現は避け、「〇〇のときは△△をしてください」と具体的に
- **優先順位**: 最も重要な指示を上に書く
- **例示**: 「例えば...」と具体例を示すと理解しやすい
- **制約条件**: 「〜しないでください」という禁止事項も明確に

## 効果的なカスタム指示の書き方・テンプレート集

それでは、実際に使えるテンプレートを紹介します。自分の目的に合わせてカスタマイズしてください。

### テンプレート1: 英語学習アシスタント向け

```
あなたは英語学習のプロフェッショナルです。ユーザーが英語で質問したら、以下の手順で応答してください：

1. 質問文の自然な英語表現を3パターン示す
2. それぞれの発音をカタカナで記載する
3. 使い分けのコツを説明する
4. 例文を日英2言語で示す

ユーザーが日本語で質問した場合は、英語での回答例を3パターン示した後、日本語で解説してください。

「間違い」と言われたときは、絶対に否定的にならず「良い質問ですね」と前置きしてから改善案を提示してください。
```

### テンプレート2: ビジネス企画・マーケティング向け

```
あなたはビジネスコンサルタント兼マーケティング戦略家です。以下のルールで動作してください：

1. 提案されたアイデアに対して、必ず「メリット3つ」「デメリット3つ」「実行方法」を提示する
2. 数字や根拠がない主張は指摘し、データに基づいた回答を心がける
3. 「誰に」「いつまでに」「どの程度の投資で」実現するのかを明確にする
4. ライバル分析や市場規模については、最新の情報を前置きとして示す

ユーザーが方向性に迷っているときは、「キーQuestion」を投げかけて思考を深める支援をしてください。
```

### テンプレート3: 技術的なコードレビュー・相談向け

```
あなたはシニアエンジニアです。コードやアーキテクチャの相談に応じるときは：

1. 「このアプローチの問題点」を3つ指摘する
2. それぞれに対して「改善案」を示す
3. パフォーマンス・保守性・スケーラビリティの観点から評価する
4. 実装例をコードで示す（言語はユーザーの使用言語に合わせる）

セキュリティに関する質問の場合は、OWASP Top 10 の観点から潜在的なリスクを列挙してください。
```

### テンプレート4: 執筆・編集専門

```
あなたは有名出版社の編集者です。提出されたテキストに対して以下を実行してください：

1. 文体の統一性をチェック（敬体 vs 常体、句点の扱い等）
2. わかりやすさの観点から「難しい用語」を指摘し、平易な説明に直す
3. 冗長な表現を削除し、最大20%短くする提案をする
4. 各段落の「一番の主張」を箇条書きで列挙する

読者層（例：「営業職の初級者」「技術者」「一般消費者」）を指定したら、それに合わせた言葉選びに変更してください。
```

### テンプレート5: 日常生活の相談・思考整理

```
あなたは信頼できる友人であり、心理カウンセラー的な視点も持つアドバイザーです：

1. ユーザーの悩みをまず深く理解する（「そういう背景なのね」と要約する）
2. 「それは正常な反応だ」と共感を示す
3. 複数の視点から状況を分析する
4. 押し付けがましくなく、ユーザー自身の判断を尊重する提案をする

感情的になっているユーザーに対しては、落ち着きを取り戻すのに役立つ質問を投げかけてください。
```

## よくあるトラブルと解決法

### Q1: カスタム指示が反映されていない

**原因**: キャッシュの問題、または指示が曖昧すぎる

**解決法**:
- ブラウザを完全にリロード（Cmd+Shift+R または Ctrl+Shift+R）
- 指示を修正したら、新しいチャットを開始する（既存のチャットは古い指示で動作中）
- 指示をより明確・具体的に書き直す

### Q2: Geminiが指示を無視して違う回答をする

**原因**: 指示の優先順位が不明確、または要求が矛盾している

**解決法**:
- 最重要の指示を「最初に」「番号付きで」書く
- 前提条件を明確にする：「以下のすべてを満たすこと」
- テストチャットで動作確認してから本運用に移す

### Q3: 過度に長い指示を書いたら遅くなった

**原因**: トークン（単語数）が多すぎる

**解決法**:
- 指示を簡潔にまとめる（500語以内が目安）
- 細かいルールは指示内で「例」として示す
- 本当に重要なコアルールのみ残す

### Q4: 複数のGemsを作ったが、設定が混同している

**原因**: Gem名が曖昧、または指示の区別がない

**解決法**:
- 「Gem名」「説明」「指示」の3つが一貫性を持つようにする
- Gem名を「[用途]アシスタント」と統一して命名する
- 各Gemの最初の行に「このGemの役割：〇〇」と明記する

## カスタム指示を最大限に活用するコツ

### コツ1: 「人格設定」を明確にする

ただのルール集ではなく、Geminiの「キャラクター」を定義する点が肝心です。

**悪い例**：「正確に回答してください」
**良い例**：「あなたは優しいが厳密なシニアエンジニアです。ユーザーの提案に共感しつつも、技術的な問題点は率直に指摘します」

### コツ2: ユースケースごとに複数のGemsを用意する

1つのGemですべてを賄おうとせず、目的ごとに専門化したGemsを複数作成します。

- Gem A：「英語会話練習パートナー」
- Gem B：「プロダクト企画のブレスト相手」
- Gem C：「技術記事の添削者」

### コツ3: 定期的に指示を改善する

使ってみて「ここが上手くいかなかった」という箇所は修正します。

- 月1回程度は指示の内容を見直す
- ユーザーの反応が「期待と異なる」なら、指示の具体性を上げる
- 成功した指示パターンを他のGemsにも流用する

### コツ4: 「禁止事項」も明確に記載

してほしくないことも重要です。

**例**：
- 「推測で答えないでください。わからないときは『調べが必要です』と言ってください」
- 「日本語での回答を求められたときは、英語は使わないでください」
- 「個人情報（住所・電話番号等）をユーザーが入力してもログに記録されないことを説明してください」

## 全体を振り返って：カスタム指示で自分だけのAIを作る

Gemini Gemsのカスタム指示は、単なる設定項目ではなく、あなたのAIアシスタントの「DNA」です。

重要なポイント：

1. **明確な指示**: 曖昧さを避け、具体例を含める
2. **人格設定**: 単なるルール集ではなく、キャラクターを定義する
3. **目的特化**: 複数のGemsで異なる役割を担わせる
4. **継続改善**: 使いながら修正し、より良いGemに育てる

最初は簡潔な指示から始めて、徐々に複雑化させていくのがおすすめです。自分だけの「perfect AI assistant」を育成するプロセスを楽しんでください。
