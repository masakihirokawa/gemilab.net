## Gemini Gems とは？

Google Gemini の **Gems** 機能は、特定の目的に特化したカスタムAIアシスタントを自分で作れる機能です。Gemini との会話を始める前に、「このGemはどんな役割を担い、どのように振る舞うべきか」を指示しておくことで、毎回前提を説明しなくても一貫したAIの対応が得られます。

2026年現在、Gems は Gemini Advanced（Google One AI Premium）プランで利用できます。一度作ったGemは何度でも呼び出せるため、よく使うAI活用パターンを「型」として保存しておくイメージです。

この記事では、Gems の **カスタム指示（Custom Instructions）** をどのように書けば効果的なアシスタントを作れるか、実例とともに詳しく解説します。

---

## カスタム指示が重要な理由

Gems のカスタム指示は、AIの「性格・役割・ルール」を定義する部分です。ここを丁寧に書くほど、Gemini の応答が期待通りになります。

逆に言えば、指示が曖昧だと Gemini はデフォルトの汎用アシスタントとして振る舞うため、せっかくの Gems 機能を活かしきれません。

**カスタム指示が特に重要なシーン：**

- 特定のトーン・文体で応答させたい（例：フォーマルなビジネス文書のみ）
- 特定の知識分野に絞って回答させたい（例：医療情報には答えず法律の観点で回答）
- ユーザーに対して毎回同じ流れで対応させたい（例：まずヒアリングしてから提案）
- 禁止事項を守らせたい（例：確認のない外部リンクを提示しない）

## カスタム指示の基本構成

効果的なカスタム指示は、次の4つの要素で構成されます。

### 1. ペルソナ（誰として振る舞うか）

まず「このGemはどんなキャラクターなのか」を明確に定義します。

```
例：
あなたはプロのコピーライターです。
20年以上の広告業界での経験を持ち、
読者の感情に訴えながら行動を促す文章を得意としています。
常に日本語で回答してください。
```

ペルソナを設定することで、Gemini の応答の方向性・語彙・視点が一貫したものになります。

### 2. 役割と目的（何をするために存在するか）

このGemが何をするためのアシスタントなのかを明示します。

```
例：
あなたの役割は、ユーザーが作成したブログ記事のタイトルと
リード文を改善することです。
記事のSEO効果を高めながら、読者の興味を引くコピーを
提案することを最優先の目的とします。
```

### 3. 行動ルール（どのように振る舞うか）

具体的な行動指針を箇条書きで記述します。

```
例：
- 必ず3つの改善案を提示してください
- 各案には「改善のポイント」を1〜2文で添えてください
- タイトルは35文字以内に収めてください
- 体言止めを適度に使い、テンポのある文章にしてください
- 読者層は30〜50代の会社員を想定してください
```

### 4. 制約（してはいけないこと）

Gemが踏み越えてはいけない境界線を定義します。

```
例：
- 根拠のある情報のみを使用し、事実確認が取れない情報は提示しない
- 政治・宗教に関する意見は述べない
- ユーザーが提示した記事と無関係な提案はしない
- 英語タイトルは原則として提案しない（特に依頼がある場合を除く）
```

## 実際のカスタム指示の書き方：具体例3選

### 例1：マーケティングリサーチアシスタント

```
【ペルソナ】
あなたはB2Bマーケティングの専門家です。
市場調査・競合分析・ターゲット定義を得意とします。

【目的】
ユーザーが提供するビジネス情報をもとに、
実践的なマーケティング戦略を提案することです。

【行動ルール】
- 回答の冒頭に「分析の前提」として確認した情報を整理してください
- 具体的なアクションアイテムを常に含めてください
- 業界データや調査結果を引用する場合は出典を明示してください
- 抽象論に終わらず、明日からできる施策を提案してください

【制約】
- 特定の商品・サービスを無根拠に推薦しない
- 法的なアドバイスは行わない（専門家への相談を推奨する）
```

### 例2：英語学習サポートアシスタント

```
【ペルソナ】
あなたはネイティブ英語教師です。
初中級レベルの日本人学習者の指導経験が豊富です。

【目的】
ユーザーの英語を添削し、自然で伝わりやすい英語表現を教えることです。

【行動ルール】
- 修正箇所は日本語で理由を説明してください
- 1回の添削で修正点は最大3つに絞ってください
- 良い表現については積極的に褒めてください
- アメリカ英語を基準にしてください（特に指定がない場合）
- 例文は必ず文脈に沿った自然なものにしてください

【制約】
- 一度に大量の文章を添削しない（500文字以内を推奨）
- 文法の専門用語を使いすぎない（初心者にわかる言葉で説明する）
```

### 例3：プロダクトマネジメントアシスタント

```
【ペルソナ】
あなたはシニアプロダクトマネージャーです。
アジャイル開発・ユーザーリサーチ・KPI設計を専門とします。

【目的】
プロダクトの課題整理・優先順位付け・ロードマップ作成を支援することです。

【行動ルール】
- フレームワーク（RICE・MoSCoW・Jobs-to-be-Done など）を積極的に活用してください
- 意思決定には必ずトレードオフを明示してください
- ユーザーインタビューや定量データの不足がある場合は指摘してください
- 次のアクションを常に明確にしてください

【制約】
- 技術的な実装の詳細には踏み込まない（エンジニアの領域を尊重する）
- 根拠のない楽観的な見通しは述べない
```

## カスタム指示を効果的にするコツ

### コツ1：具体的な例を含める

「良い文章を書いてください」よりも「以下のような文体で書いてください：〔例文〕」の方が格段に精度が上がります。指示の中に「入力例」「出力例」を含めることで、Gemini が期待する応答パターンを学習します。

### コツ2：指示は短く・明確に

カスタム指示が長すぎると、Gemini がどの指示を優先するか判断しにくくなります。**1つの指示につき1つの行動** を原則に、箇条書きで整理するのがベストです。

### コツ3：テスト → フィードバック → 改善のサイクルを回す

最初から完璧な指示を書こうとせず、まず動かしてみることが重要です。期待と違う応答が返ってきたら、どの指示が足りなかったか・曖昧だったかを確認し、少しずつ改善します。

```
改善サイクルの例：
1. 指示を書く
2. テスト質問を5つ投げる
3. 期待と違う応答をリストアップ
4. 問題のある指示を修正または追加
5. 再テスト
```

### コツ4：ユーザー情報を含める（パーソナライズ）

カスタム指示にユーザー自身の情報を含めることで、より的確な応答が得られます。

```
例：
私は福岡在住のフリーランスのWebデザイナーです。
主にEC業界のクライアントを担当しています。
この前提でアドバイスをお願いします。
```

## よくある質問（FAQ）

**Q. カスタム指示はどこで設定するのですか？**

Gemini のサイドメニューから「Gems」→「新しいGemを作成」を選択し、「カスタム指示」欄に入力します。Gemini Advanced（Google One AI Premiumプラン）が必要です。

**Q. 指示の文字数に上限はありますか？**

Gems のカスタム指示には文字数制限があります（現在は数千文字程度）。長すぎる場合は重要な指示に絞り込み、細部は会話の中で補足する形にしましょう。

**Q. 日本語と英語のどちらで書くべきですか？**

Gemini に日本語で応答させたい場合は「必ず日本語で回答してください」という指示を明記した上で、指示自体は日本語・英語どちらでも問題ありません。ただし一般的に、指示と応答を同じ言語に統一する方が整合性が取りやすいです。

**Q. カスタム指示を後から変更できますか？**

はい。Gems の管理画面からいつでも指示を編集できます。編集は即座に反映されます。

## まとめ

Gemini Gems のカスタム指示は、AIアシスタントの「性格」と「ルール」を定義する最重要部分です。以下のポイントを押さえて書くことで、格段に使いやすいGemが作れます。

- **ペルソナ**（誰として振る舞うか）を明確に
- **役割と目的**（何をするためのGemか）を定義する
- **行動ルール**（具体的な指示）を箇条書きで整理する
- **制約**（してはいけないこと）を明示する
- **具体例を含める**と精度が上がる
