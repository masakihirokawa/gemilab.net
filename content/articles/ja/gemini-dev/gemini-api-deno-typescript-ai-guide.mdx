## はじめに

Node.js に代わるモダンな TypeScript ランタイムとして注目を集める **Deno**。ネイティブ TypeScript サポート・組み込みセキュリティ・ゼロ設定のデプロイ環境など、AI アプリ開発において非常に相性のよい特徴を備えています。

この記事で学べること:

- Deno と Gemini API の基本統合方法
- ストリーミングレスポンスの実装パターン
- 画像・PDF を扱うマルチモーダル処理
- Deno Deploy を使ったゼロ設定デプロイ

対象読者は、TypeScript の基本知識があり、AI 機能をアプリに組み込んでみたい方です。Gemini API が初めての方は、まず [Gemini API クイックスタート](/articles/gemini-api/gemini-api-quickstart) をご覧になることをおすすめします。

## Deno とは？Node.js との違い

Deno は、Node.js の作者 Ryan Dahl が「Node.js の反省点を活かして作り直した」JavaScript/TypeScript ランタイムです。AI アプリ開発の観点から特に重要な特徴を整理します。

**Deno の主な利点**:

- **ネイティブ TypeScript サポート**: `tsc` や `ts-node` は不要。`.ts` ファイルをそのまま実行できます
- **組み込みセキュリティモデル**: ファイル・ネットワーク・環境変数へのアクセスは明示的な許可が必要
- **npm パッケージの直接利用**: `npm:` プレフィックスで npm パッケージも使用可能
- **Deno Deploy**: GitHub と連携したゼロ設定グローバルデプロイ
- **標準ライブラリ**: テスト・HTTP・暗号化など豊富な標準モジュールが付属

Node.js との最大の違いは、**設定ファイルなしで TypeScript が動く**点です。`package.json`・`tsconfig.json`・`node_modules` が不要なため、AI プロトタイプをすばやく試すのに最適です。

## Step 1: 基本的なテキスト生成

まずシンプルなテキスト生成から始めましょう。

```typescript
// main.ts
import { GoogleGenerativeAI } from "npm:@google/generative-ai";

// 環境変数から API キーを取得
const apiKey = Deno.env.get("GEMINI_API_KEY");
if (!apiKey) {
  throw new Error("GEMINI_API_KEY が設定されていません");
}

const genAI = new GoogleGenerativeAI(apiKey);
const model = genAI.getGenerativeModel({ model: "gemini-2.5-flash" });

async function generateText(prompt: string): Promise<string> {
  const result = await model.generateContent(prompt);
  const response = await result.response;
  return response.text();
}

// 実行例
const text = await generateText("Deno と TypeScript の組み合わせの利点を3つ教えてください。");
console.log(text);
```

実行コマンド:

```bash
# --env-file で .env ファイルを読み込み、--allow-env でアクセス許可
deno run --allow-env --allow-net --env-file=.env main.ts
```

期待する出力:

```
1. ネイティブ TypeScript サポートにより、トランスパイル設定が不要...
2. 組み込みのセキュリティモデルで...
3. Deno Deploy による簡単なデプロイ...
```

## Step 2: ストリーミングレスポンスの実装

長文生成では、ストリーミングを使うことでユーザー体験が大幅に向上します。

```typescript
// streaming.ts
import { GoogleGenerativeAI } from "npm:@google/generative-ai";

const genAI = new GoogleGenerativeAI(Deno.env.get("GEMINI_API_KEY")!);
const model = genAI.getGenerativeModel({ model: "gemini-2.5-flash" });

async function streamText(prompt: string): Promise<void> {
  console.log("生成開始...\n");

  // generateContentStream でストリーミング取得
  const streamResult = await model.generateContentStream(prompt);

  for await (const chunk of streamResult.stream) {
    const text = chunk.text();
    // リアルタイムに出力（改行なし）
    Deno.stdout.writeSync(new TextEncoder().encode(text));
  }

  // 完了後に改行
  console.log("\n\n✅ 生成完了");
}

await streamText(
  "TypeScript で書かれた Gemini AI アプリの活用事例を5つ、それぞれ詳しく説明してください。"
);
```

ストリーミングを HTTP API として提供する場合は、`ReadableStream` を使います:

```typescript
// server.ts — Deno の組み込みサーバー
import { GoogleGenerativeAI } from "npm:@google/generative-ai";

const genAI = new GoogleGenerativeAI(Deno.env.get("GEMINI_API_KEY")!);
const model = genAI.getGenerativeModel({ model: "gemini-2.5-flash" });

Deno.serve({ port: 8000 }, async (req: Request): Promise<Response> => {
  if (req.method !== "POST" || new URL(req.url).pathname !== "/generate") {
    return new Response("Not Found", { status: 404 });
  }

  const { prompt } = await req.json() as { prompt: string };

  // ReadableStream でストリーミングレスポンス
  const stream = new ReadableStream({
    async start(controller) {
      const encoder = new TextEncoder();
      const streamResult = await model.generateContentStream(prompt);

      for await (const chunk of streamResult.stream) {
        controller.enqueue(encoder.encode(chunk.text()));
      }
      controller.close();
    },
  });

  return new Response(stream, {
    headers: {
      "Content-Type": "text/plain; charset=utf-8",
      "Transfer-Encoding": "chunked",
    },
  });
});

console.log("サーバー起動: http://localhost:8000");
```

```bash
# サーバー起動
deno run --allow-env --allow-net --env-file=.env server.ts

# テスト（別ターミナル）
curl -X POST http://localhost:8000/generate \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Deno の特徴を教えてください"}' \
  --no-buffer
```

## Step 3: マルチモーダル — 画像解析

Gemini の強みであるマルチモーダル処理も Deno で簡単に実装できます。

```typescript
// vision.ts — 画像ファイルを解析する
import { GoogleGenerativeAI } from "npm:@google/generative-ai";

const genAI = new GoogleGenerativeAI(Deno.env.get("GEMINI_API_KEY")!);
const model = genAI.getGenerativeModel({ model: "gemini-2.5-flash" });

async function analyzeImage(
  imagePath: string,
  question: string
): Promise<string> {
  // 画像ファイルを Base64 エンコード
  const imageData = await Deno.readFile(imagePath);
  const base64Image = btoa(String.fromCharCode(...imageData));

  // ファイル拡張子から MIME タイプを判定
  const ext = imagePath.split(".").pop()?.toLowerCase() ?? "jpeg";
  const mimeMap: Record<string, string> = {
    jpg: "image/jpeg",
    jpeg: "image/jpeg",
    png: "image/png",
    webp: "image/webp",
    gif: "image/gif",
  };
  const mimeType = mimeMap[ext] ?? "image/jpeg";

  const result = await model.generateContent([
    {
      inlineData: {
        data: base64Image,
        mimeType,
      },
    },
    { text: question },
  ]);

  return result.response.text();
}

// 使用例
const description = await analyzeImage(
  "./sample.png",
  "この画像に写っているものを詳しく説明してください。日本語で回答してください。"
);
console.log(description);
```

```bash
deno run --allow-env --allow-net --allow-read --env-file=.env vision.ts
```

## Step 4: Deno Deploy でサーバーレスデプロイ

Deno Deploy を使えば、GitHub にプッシュするだけでグローバルにデプロイできます。

### プロジェクト構成

```
my-gemini-app/
├── main.ts          ← エントリポイント
├── deno.json        ← Deno 設定（タスク定義）
└── .github/
    └── workflows/
        └── deploy.yml
```

### deno.json

```json
{
  "tasks": {
    "dev": "deno run --allow-env --allow-net --env-file=.env main.ts",
    "start": "deno run --allow-env --allow-net main.ts"
  },
  "imports": {
    "@google/generative-ai": "npm:@google/generative-ai@^0.24.0"
  }
}
```

`deno.json` でインポートマップを設定すると、コード内で短縮パスを使用できます:

```typescript
// deno.json のインポートマップを使用する場合
import { GoogleGenerativeAI } from "@google/generative-ai";
```

### Deno Deploy の設定手順

1. [deno.com/deploy](https://deno.com/deploy) でアカウント作成
2. 「New Project」→ GitHub リポジトリを選択
3. エントリポイントを `main.ts` に設定
4. 環境変数 `GEMINI_API_KEY` を設定
5. デプロイ完了（約30秒）

デプロイ後は `https://your-project.deno.dev` でアクセス可能になります。コールドスタートがなく、世界中のエッジで動作するため、AI アプリのレイテンシが大幅に改善します。

## よくあるエラーと対処法

**エラー1: `Requires net access`**

```
error: Requires net access to "generativelanguage.googleapis.com"
```

対処: `--allow-net` フラグが必要です。本番環境では、アクセス先ドメインを明示的に指定するとよりセキュアです:

```bash
deno run --allow-net=generativelanguage.googleapis.com main.ts
```

**エラー2: `Requires env access`**

環境変数へのアクセスに `--allow-env` が必要です。特定の変数のみ許可する場合:

```bash
deno run --allow-env=GEMINI_API_KEY main.ts
```

**エラー3: npm パッケージのキャッシュエラー**

```bash
# キャッシュをクリア
deno clean
# 再実行
deno run --allow-env --allow-net main.ts
```

さらに詳しいエラーハンドリングパターンについては、[Gemini API TypeScript 完全入門](/articles/gemini-api/gemini-api-typescript-complete-beginners-guide) も参考になります。

## 応用: マルチターンチャットの実装

Deno でチャット履歴を管理する実装例です:

```typescript
// chat.ts — 会話履歴を保持するチャット
import { GoogleGenerativeAI } from "npm:@google/generative-ai";

const genAI = new GoogleGenerativeAI(Deno.env.get("GEMINI_API_KEY")!);
const model = genAI.getGenerativeModel({
  model: "gemini-2.5-flash",
  systemInstruction: "あなたは親切な日本語アシスタントです。簡潔に回答してください。",
});

// チャットセッションを開始
const chat = model.startChat({
  history: [],
  generationConfig: {
    maxOutputTokens: 1024,
    temperature: 0.7,
  },
});

async function sendMessage(message: string): Promise<string> {
  const result = await chat.sendMessage(message);
  return result.response.text();
}

// 会話例
console.log(await sendMessage("TypeScript の型推論について教えてください"));
console.log(await sendMessage("もう少し具体的な例を挙げていただけますか？"));
console.log(await sendMessage("ありがとうございます。まとめてください。"));
```

より高度な型安全な設計については、[Gemini API × TypeScript 型安全 AI アプリ設計ガイド](/articles/gemini-api/gemini-api-typescript-typesafe-ai-application-architecture) で詳しく解説しています。
