## Function Calling が変えるAIアプリ開発

Gemini API の **Function Calling** は、AI を単なる「テキスト生成器」から「行動できるエージェント」へと昇華させる中核機能です。これを使いこなすことで、以下のような高度なアプリを構築できます。

- 「今日の東京の天気を教えて」→ 天気 API を呼び出して最新データを回答
- 「在庫が10個以下の商品を全部発注して」→ データベースを検索して発注システムを実行
- 「このPDFを要約してSlackに投稿して」→ ファイル処理と Slack API を連携

本記事では、Function Calling の基本的な仕組みから、複数ツールの並列呼び出し、エラーハンドリング、そして本番品質のアーキテクチャまでを詳しく解説します。

## Function Calling の仕組みを正確に理解する

多くの開発者が誤解しがちですが、Function Calling では **Gemini が関数を直接実行するわけではありません**。

実際の動作フローは以下の通りです。

```
① ユーザーのリクエスト + 利用可能な関数定義を Gemini に送信
② Gemini が「どの関数をどの引数で呼び出すべきか」を判断
③ Gemini が functionCall レスポンスを返す（実際の実行はしない）
④ あなたのコードが関数を実行し、結果を取得
⑤ 実行結果を Gemini に返す
⑥ Gemini が最終的な自然言語レスポンスを生成
```

つまり、**実行の制御権は常にあなたのコードにある**という設計です。これにより、セキュリティの確保や実行前の確認フローが実装しやすくなっています。

## 基本実装：最初の Function Calling

TypeScript での基本的な実装から始めましょう。

```typescript
import { GoogleGenerativeAI, FunctionDeclarationSchemaType } from "@google/generative-ai";

const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY!);

// ステップ1: 関数の定義（スキーマ）
const tools = [
  {
    functionDeclarations: [
      {
        name: "get_weather",
        description: "指定した都市の現在の天気情報を取得します",
        parameters: {
          type: FunctionDeclarationSchemaType.OBJECT,
          properties: {
            city: {
              type: FunctionDeclarationSchemaType.STRING,
              description: "天気を調べたい都市名（例: Tokyo, Osaka）",
            },
            unit: {
              type: FunctionDeclarationSchemaType.STRING,
              enum: ["celsius", "fahrenheit"],
              description: "温度の単位",
            },
          },
          required: ["city"],
        },
      },
    ],
  },
];

// ステップ2: 実際の関数実装
async function getWeather(city: string, unit: string = "celsius") {
  const response = await fetch(
    `https://api.openweathermap.org/data/2.5/weather?q=${city}&appid=${process.env.OPENWEATHER_API_KEY}&units=${unit === "celsius" ? "metric" : "imperial"}`
  );

  if (!response.ok) throw new Error(`天気データの取得失敗: ${city}`);
  const data = await response.json() as any;

  return {
    city: data.name,
    temperature: data.main.temp,
    description: data.weather[0].description,
    humidity: data.main.humidity,
    feelsLike: data.main.feels_like,
  };
}

// ステップ3: Function Calling を使ったチャット
async function chatWithTools(userMessage: string) {
  const model = genAI.getGenerativeModel({
    model: "gemini-2.0-flash",
    tools,
  });

  const chat = model.startChat();
  let response = await chat.sendMessage(userMessage);

  // 関数呼び出しが要求された場合の処理ループ
  while (response.response.functionCalls()?.length) {
    const functionCalls = response.response.functionCalls()!;
    const functionResults = [];

    for (const call of functionCalls) {
      console.log(`関数 ${call.name} を呼び出し中...`, call.args);

      let result;
      if (call.name === "get_weather") {
        const args = call.args as { city: string; unit?: string };
        result = await getWeather(args.city, args.unit);
      } else {
        result = { error: `未定義の関数: ${call.name}` };
      }

      functionResults.push({
        functionResponse: {
          name: call.name,
          response: { result },
        },
      });
    }

    // 関数実行結果を Gemini に返す
    response = await chat.sendMessage(functionResults);
  }

  return response.response.text();
}

// 使用例
const answer = await chatWithTools("東京と大阪の今日の天気を教えてください");
console.log(answer);
```

## 並列 Function Calling：複数ツールを同時実行

Gemini は複数の関数を並列で呼び出すことができます。この機能を活用することでレスポンス時間を大幅に短縮できます。

```typescript
async function handleParallelCalls(functionCalls: FunctionCall[]) {
  // 全ての関数呼び出しを並列実行
  const results = await Promise.allSettled(
    functionCalls.map(async (call) => {
      try {
        const result = await executeFunction(call.name, call.args);
        return {
          functionResponse: {
            name: call.name,
            response: { result },
          },
        };
      } catch (error) {
        // 個別のエラーはキャッチして、他の関数の実行は継続
        return {
          functionResponse: {
            name: call.name,
            response: {
              error: error instanceof Error ? error.message : "実行エラー",
            },
          },
        };
      }
    })
  );

  return results
    .filter((r): r is PromiseFulfilledResult<any> => r.status === "fulfilled")
    .map((r) => r.value);
}

// 使用例: 複数都市の天気を同時取得（直列より大幅に高速）
const userInput = "東京、大阪、名古屋、福岡の天気を比較してください";
// → Gemini が4つの get_weather 呼び出しを同時に要求
// → 並列実行で4都市分を同時取得（直列の場合の約1/4の時間）
```

## 安全な Function Calling：確認フローの実装

外部 API への書き込み・送信操作は、実行前にユーザー確認を求めることがベストプラクティスです。

```typescript
interface PendingAction {
  id: string;
  functionName: string;
  args: Record<string, unknown>;
  description: string;
  riskLevel: "low" | "medium" | "high";
}

class SafeFunctionCaller {
  private pendingActions: Map<string, PendingAction> = new Map();

  // リスクの高い操作は確認待ちキューに追加
  async queueAction(call: FunctionCall): Promise<PendingAction | null> {
    const riskLevel = this.assessRisk(call.name);

    if (riskLevel === "high") {
      const action: PendingAction = {
        id: crypto.randomUUID(),
        functionName: call.name,
        args: call.args as Record<string, unknown>,
        description: this.describeAction(call),
        riskLevel,
      };
      this.pendingActions.set(action.id, action);
      return action; // フロントエンドに確認を求める
    }

    return null; // 即時実行してOK
  }

  private assessRisk(functionName: string): "low" | "medium" | "high" {
    const highRiskFunctions = ["send_email", "create_order", "delete_record", "transfer_funds"];
    const mediumRiskFunctions = ["create_task", "update_status"];

    if (highRiskFunctions.includes(functionName)) return "high";
    if (mediumRiskFunctions.includes(functionName)) return "medium";
    return "low";
  }
}
```

## Python での実装例

Python でも同様に実装できます。

```python
import google.generativeai as genai
import os

genai.configure(api_key=os.environ["GEMINI_API_KEY"])

# ツールの定義
weather_tool = genai.protos.Tool(
    function_declarations=[
        genai.protos.FunctionDeclaration(
            name="get_current_weather",
            description="指定した都市の現在の天気を取得する",
            parameters=genai.protos.Schema(
                type=genai.protos.Type.OBJECT,
                properties={
                    "city": genai.protos.Schema(
                        type=genai.protos.Type.STRING,
                        description="都市名"
                    ),
                },
                required=["city"],
            ),
        )
    ]
)

model = genai.GenerativeModel(
    model_name="gemini-2.0-flash",
    tools=[weather_tool],
)

chat = model.start_chat()
response = chat.send_message("大阪の天気は？")

# Function Call の処理
for part in response.parts:
    if fn := part.function_call:
        # 関数を実行
        result = get_weather(fn.args["city"])

        # 結果を返す
        response = chat.send_message(
            genai.protos.Content(
                parts=[genai.protos.Part(
                    function_response=genai.protos.FunctionResponse(
                        name=fn.name,
                        response={"result": result},
                    )
                )]
            )
        )

print(response.text)
```
