Gemini Code AssistはVS Codeに統合されたAIコーディングアシスタントですが、初期設定や認証周りでつまずくことが少なくありません。ここではよく報告されるエラーとその解決方法を実際の画面に沿って解説します。

## インストール・認証エラーの対処法

**「Sign in failed」「OAuth error」が表示される**

Googleアカウントへのサインインに失敗する場合、まずブラウザの認証フローを確認しましょう。VS Codeで `Ctrl+Shift+P`（Mac: `Cmd+Shift+P`）を開き、「Gemini: Sign In」を実行します。ポップアップが表示されない場合は、ポップアップブロッカーを一時的に無効にしてください。

企業のGoogleワークスペースアカウントを使用している場合、IT管理者によってGoogle Cloud APIへのアクセスが制限されている場合があります。この場合は管理者にGemini Code Assistの利用承認を依頼する必要があります。

**APIが有効化されていない**

[Google Cloud Console](https://console.cloud.google.com) にアクセスし、プロジェクトで「Cloud AI Companion API」が有効になっているか確認してください。有効でない場合は「APIを有効にする」ボタンをクリックして有効化します。

## コード補完が動かない時の確認手順

コード補完の提案が表示されない場合は、以下を順番に確認してください。

**拡張機能のバージョン確認**

VS Codeの拡張機能ビューで「Gemini Code Assist」を検索し、最新バージョンに更新されているか確認します。古いバージョンでは既知の不具合があることがあります。

**settings.jsonの設定確認**

VS Codeの設定ファイル（settings.json）に以下が含まれているか確認してください:
```json
{
  "editor.inlineSuggest.enabled": true,
  "gemini.codeAssist.enable": true
}
```

**対応言語の確認**

Gemini Code AssistはPython、JavaScript、TypeScript、Go、Java、C/C++など主要言語をサポートしています。対応していない言語ファイルでは補完が表示されません。現在のファイルの言語モードをVS Code右下で確認してください。

## Outline機能が生成されない問題

Gemini Code AssistのOutlineアシスト機能は、コードの構造を概要として表示する便利な機能ですが、正しく設定されていないと機能しません。

**Outline機能の有効化**

VS Codeのコマンドパレットから「Gemini: Show Code Outline」を実行します。初回は機能を有効にするための設定が必要です。settings.jsonに以下を追加してください:
```json
{
  "gemini.codeAssist.outline.enabled": true
}
```

**対応ファイル形式**

OutlineアシストはPython（.py）、JavaScript（.js/.jsx）、TypeScript（.ts/.tsx）、Java（.java）、Go（.go）などで動作します。Markdownや設定ファイルでは動作しません。

**生成が途中で止まる場合**

ファイルサイズが大きすぎると生成が止まることがあります。1,000行を超えるファイルでは、アウトラインを生成したいセクションだけを別ファイルに切り出してお試しください。

## クォータ超過（429エラー）の対処法

「Quota exceeded」または「429 Too Many Requests」エラーが表示される場合、利用制限に達しています。

**無料枠の制限**

Gemini Code AssistのFree Tierでは、1分あたりのリクエスト数（RPM）と1日あたりのトークン数に制限があります。制限に達した場合、しばらく待つか、有料プランへのアップグレードを検討してください。

**Usage Tiersの確認**

[Google AI Studio](https://aistudio.google.com) でUsage Tiersを確認できます。プロジェクトごとに利用上限を設定するproject-level spend capsの機能も活用すると、予期しない超過を防げます。

## パフォーマンス問題（レスポンスが遅い）

**ネットワーク確認**

Google Cloud APIへの接続速度が影響します。VPNを使用している場合は一時的にオフにして、速度の変化を確認してください。

**拡張機能の競合**

他のAIコーディングアシスタント（GitHub Copilot、Codeium等）と同時に有効にしていると、動作が不安定になることがあります。Gemini Code Assistを試す際は他の類似拡張機能を一時的に無効にしてみましょう。

## 全体を振り返って

Gemini Code Assistの問題の多くは、認証設定か拡張機能の設定で解決できます。エラーが続く場合は、VS Codeを再起動してから再試行するか、拡張機能を一度アンインストールして再インストールしてみてください。それでも解決しない場合は、[Google Cloudサポート](https://cloud.google.com/support)へお問い合わせください。
