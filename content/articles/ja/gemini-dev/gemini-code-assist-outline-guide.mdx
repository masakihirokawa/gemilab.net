「gemini code assist outlineとは」という検索が増えているのを見て、意外と知られていない機能だと気づきました。Gemini Code AssistのOutline機能は、地味に見えてかなり実用的な機能です。大きいファイルを触るとき、この機能のあるなしでナビゲーションの速度が変わってきます。

Outline機能を使い始めてから、特に1,000行を超えるファイルを扱うときの「あのメソッドどこだっけ」という時間が減りました。具体的に何ができて、どう使えるのかをまとめます。

Gemini API を実プロダクトで運用してきた知見から、この問題に普段から向き合ってきた立場で、要点を整理します。

累計5,000万ダウンロードのアプリ群に Gemini を組み込んできた経験から、本番運用のコツを整理します。

## Gemini Code Assist Outline とは

Gemini Code AssistのOutline機能は、現在開いているファイルの構造をAIがリアルタイムで解析し、ツリー表示してくれる機能です。VS Codeのアウトラインパネルに似ていますが、Gemini版は以下の点が異なります。

- **言語依存なし**: パーサーが対応していない言語や設定ファイル（YAML、TOML、MDXなど）も構造化できます
- **コメント・ドキュメントの要約表示**: 関数名だけでなく、docstringやコメントの概要も合わせて表示されます
- **コンテキスト対応のナビゲーション**: アウトライン上の項目をクリックすると、Geminiのチャットパネルがその関数・クラスにフォーカスした状態で開きます

## VS Code での使い方

### セットアップ

Google Cloud拡張機能（または Gemini Code Assist拡張機能）をインストール後、サインインすると自動的に有効になります。

```bash
# VS Code拡張機能のインストール（コマンドラインから）
code --install-extension google-cloud.cloudcode
```

### Outlineパネルの表示

1. VS Codeのアクティビティバー（左サイドバー）のGeminiアイコンをクリック
2. 「Code Assist」パネルから「Outline」タブを選択
3. 現在のファイルの構造が自動的に表示されます

ファイルを切り替えるたびにOutlineが更新されます。プロジェクト全体のOutlineを一覧表示する「Project Outline」モードも備わっており、`Ctrl+Shift+P`（Mac: `Cmd+Shift+P`）から`Gemini: Show Project Outline`で起動できます。

## 実際にどう役立つか

### 1,000行超のファイルのナビゲーション

Reactコンポーネントや設定ファイルが肥大化したとき、どこに何があるかを把握するのに使います。

```typescript
// 例：肥大化したuseAuth.ts（700行超）
// Outlineで見ると、こういう構造が一目で分かる:
//
// useAuth (hook)
// ├── validateToken()
// ├── refreshSession()
// ├── loginWithEmail()
// │   ├── validateInput()
// │   └── handleOAuthRedirect()
// ├── loginWithGoogle()
// └── logout()
//     └── clearLocalStorage()
```

このツリーからメソッドをクリックすると、エディタがその位置にジャンプします。VSCodeのデフォルトOutlineとの違いは、Gemini版が「メソッドの役割の概要」もコメントから生成して表示してくれる点です。

### 「この関数何するもの？」を即座に確認

Outlineの各項目にカーソルを合わせると、その関数・クラスの概要がポップアップ表示されます。引き継ぎや他人のコードを読むときに、ファイルを上から読まずに「何をするファイルか」を掴めます。

```python
# 例：outlineのホバー表示
# def process_payment(user_id: str, amount: float) -> dict:
# 
# ホバーすると表示される概要:
# "Stripe APIを使って決済処理を行い、成功・失敗・リトライが必要な状態を返す。
#  user_idはDBの顧客IDと紐付け済みであることを前提とする。"
```

docstringが書かれていない関数でも、コード本体からGeminiが概要を生成します。

### チャットへのコンテキスト渡し

Outlineから特定のメソッドを右クリック → 「Geminiに質問」を選ぶと、そのメソッドをコンテキストとして含んだチャットが開きます。

「このクラスの設計についてレビューしてほしい」「このメソッドのパフォーマンスを改善するには？」という質問を、ファイルのどこに居ても1クリックで始められます。

## JetBrains系IDEでの使い方

IntelliJ IDEA・PyCharm・GoLandなどでも利用可能です。

1. Gemini Code Assistプラグインをインストール（JetBrains Marketplace）
2. `View > Tool Windows > Gemini Outline`を選択
3. VS Codeとほぼ同等の機能が使えます

ただし2026年5月時点では、JetBrains版はVS Code版より更新が少し遅れる傾向があります。

## 実用的な使い方のコツ

Outline機能をより活かすために、実際に使っていて気づいたことをいくつか。

**コードベースの「地図」として使う**

新しいプロジェクトを引き継いだとき、重要ファイルを順番にOutlineで表示するだけで、「このプロジェクトは何をしているか」の地図が頭に入ります。READMEより速いことも多いです。

**長いファイルを分割するきっかけとして**

Outlineを見たときに「ツリーが深すぎる / 項目が多すぎる」と感じたら、ファイル分割のサインです。Outlineは設計の見直しを促す視覚的なフィードバックにもなります。

**コードレビューの補助として**

PRのレビュー時に、変更ファイルのOutlineを先に確認する習慣をつけると、「このPRは何をしているか」を素早く把握できます。差分を上から読む前に構造を掴む、という順序です。

Gemini Code AssistのAPI統合については、[Gemini APIシステムインストラクション完全ガイド](/articles/gemini-api/system-instructions-guide)もあわせて参照してください。
