## はじめに — なぜ Streamlit × Gemini API なのか

AI を活用した Web アプリを作りたいけれど、フロントエンド開発の知識がない — そんな悩みを持つ Python 開発者は少なくありません。Streamlit は Python コードだけでインタラクティブな Web UI を構築できるフレームワークで、Gemini API と組み合わせると、数十行のコードで本格的な AI アプリのプロトタイプを完成させることができます。


## 環境構築と依存パッケージのインストール

まず、プロジェクトディレクトリを作成し、必要なパッケージをインストールします。

```bash
# プロジェクトディレクトリの作成
mkdir gemini-streamlit-app && cd gemini-streamlit-app

# 仮想環境の作成と有効化
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 必要なパッケージのインストール
pip install streamlit google-genai python-dotenv
```

次に、Gemini API キーを `.env` ファイルに設定します。API キーは [Google AI Studio](https://aistudio.google.com/) から無料で取得できます。

```bash
# .env ファイルを作成
echo "GEMINI_API_KEY=YOUR_API_KEY" > .env
```

`requirements.txt` も作成しておきましょう。デプロイ時に必要になります。

```text
streamlit>=1.40.0
google-genai>=1.0.0
python-dotenv>=1.0.0
```

## AI チャットアプリの実装

以下が Gemini API × Streamlit で動作する AI チャットアプリの完全なコードです。`app.py` として保存してください。

```python
# app.py — Gemini API × Streamlit チャットアプリ
import streamlit as st
from google import genai
from google.genai import types
import os
from dotenv import load_dotenv

load_dotenv()

# ページ設定
st.set_page_config(
    page_title="Gemini AI Chat",
    page_icon="✨",
    layout="centered"
)

st.title("✨ Gemini AI チャット")
st.caption("Gemini API を使ったインテリジェントチャットアプリ")

# Gemini クライアントの初期化
@st.cache_resource
def get_client():
    return genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

client = get_client()

# モデル選択
model_name = st.sidebar.selectbox(
    "モデルを選択",
    ["gemini-2.5-flash", "gemini-2.5-pro"],
    index=0
)

# System Instruction の設定
system_instruction = st.sidebar.text_area(
    "System Instruction（任意）",
    value="あなたは親切で知識豊富なAIアシスタントです。",
    height=100
)

# チャット履歴の初期化
if "messages" not in st.session_state:
    st.session_state.messages = []

# チャット履歴の表示
for message in st.session_state.messages:
    with st.chat_message(message["role"]):
        st.markdown(message["content"])

# ユーザー入力の処理
if prompt := st.chat_input("メッセージを入力してください"):
    # ユーザーメッセージの表示と保存
    st.session_state.messages.append({"role": "user", "content": prompt})
    with st.chat_message("user"):
        st.markdown(prompt)

    # Gemini API への送信（ストリーミング）
    with st.chat_message("assistant"):
        message_placeholder = st.empty()
        full_response = ""

        # 会話履歴を Gemini 形式に変換
        contents = []
        for msg in st.session_state.messages:
            role = "user" if msg["role"] == "user" else "model"
            contents.append(
                types.Content(
                    role=role,
                    parts=[types.Part.from_text(text=msg["content"])]
                )
            )

        # ストリーミングレスポンスの取得
        response = client.models.generate_content_stream(
            model=model_name,
            contents=contents,
            config=types.GenerateContentConfig(
                system_instruction=system_instruction,
                temperature=0.7,
                max_output_tokens=2048,
            )
        )

        for chunk in response:
            if chunk.text:
                full_response += chunk.text
                message_placeholder.markdown(full_response + "▌")

        message_placeholder.markdown(full_response)

    # アシスタントの応答を保存
    st.session_state.messages.append(
        {"role": "assistant", "content": full_response}
    )
```

このコードを保存したら、以下のコマンドでローカルサーバーを起動できます。

```bash
streamlit run app.py
# ブラウザで http://localhost:8501 が自動的に開きます
```

ブラウザが開くと、すぐにチャットインターフェースが表示されます。サイドバーからモデルの切り替えや System Instruction の変更もリアルタイムで反映されます。

## 画像入力に対応したマルチモーダル版への拡張

Gemini API の強みはマルチモーダル対応です。画像をアップロードして AI に分析させる機能を追加してみましょう。Gemini API のマルチモーダル機能についてさらに詳しく知りたい方は、[Gemini API マルチモーダル実践テクニック集](/articles/gemini-api/gemini-api-multimodal-techniques)も参考にしてください。

```python
# app.py に追加: 画像アップロード機能
import base64

# サイドバーに画像アップロードを追加
uploaded_file = st.sidebar.file_uploader(
    "画像をアップロード（任意）",
    type=["png", "jpg", "jpeg", "webp"]
)

# チャット入力処理を以下に差し替え
if prompt := st.chat_input("メッセージを入力してください"):
    st.session_state.messages.append({"role": "user", "content": prompt})
    with st.chat_message("user"):
        st.markdown(prompt)
        if uploaded_file:
            st.image(uploaded_file, width=300)

    with st.chat_message("assistant"):
        message_placeholder = st.empty()
        full_response = ""

        # テキストと画像をパーツとして構築
        parts = [types.Part.from_text(text=prompt)]
        if uploaded_file:
            image_bytes = uploaded_file.getvalue()
            parts.append(
                types.Part.from_bytes(
                    data=image_bytes,
                    mime_type=uploaded_file.type
                )
            )

        response = client.models.generate_content_stream(
            model=model_name,
            contents=[types.Content(role="user", parts=parts)],
            config=types.GenerateContentConfig(
                system_instruction=system_instruction,
                temperature=0.7,
            )
        )

        for chunk in response:
            if chunk.text:
                full_response += chunk.text
                message_placeholder.markdown(full_response + "▌")

        message_placeholder.markdown(full_response)

    st.session_state.messages.append(
        {"role": "assistant", "content": full_response}
    )
```

これにより、料理の写真をアップロードしてレシピを聞いたり、グラフ画像を読み込んでデータの傾向を分析させたりと、テキストだけでは実現できないインタラクションが可能になります。

## Streamlit Community Cloud への無料デプロイ

ローカルで動作を確認できたら、Streamlit Community Cloud に無料でデプロイしましょう。GitHub リポジトリにコードを push するだけでデプロイが完了します。

### デプロイ手順

**1. `.gitignore` を作成する**

```text
.env
venv/
__pycache__/
```

**2. GitHub リポジトリに push する**

```bash
git init
git add app.py requirements.txt .gitignore
git commit -m "Initial commit: Gemini Streamlit app"
git remote add origin https://github.com/your-username/gemini-streamlit-app.git
git push -u origin main
```

**3. Streamlit Community Cloud でデプロイ**

- [share.streamlit.io](https://share.streamlit.io/) にアクセスし、GitHub アカウントでログイン
- 「New app」をクリックし、リポジトリ・ブランチ・ファイル（`app.py`）を選択
- 「Advanced settings」で `GEMINI_API_KEY` を Secrets に設定（`.env` の代わり）
- 「Deploy」をクリック — 数分で公開 URL が発行されます

### Secrets の設定方法

Streamlit Community Cloud では、`.env` ファイルの代わりに Secrets 機能を使います。デプロイ設定画面の「Advanced settings」 > 「Secrets」に以下を記述してください。

```toml
GEMINI_API_KEY = "YOUR_API_KEY"
```

コード側は `os.getenv("GEMINI_API_KEY")` のままで変更不要です。`python-dotenv` はローカル開発用のフォールバックとして機能します。

API キーの管理やセキュリティについて、より本格的な運用を考えている方は [Gemini API 本番環境セキュリティ完全ガイド](/articles/gemini-api/gemini-api-production-security-guide) も併せてご確認ください。

## パフォーマンス最適化のポイント

Streamlit × Gemini API アプリを快適に動作させるために、以下のポイントを押さえておきましょう。

- **`@st.cache_resource`**: Gemini クライアントの初期化は `@st.cache_resource` でキャッシュし、リロードのたびに再接続しないようにします（上記コード例で実装済み）
- **`@st.cache_data`**: 同じプロンプトに対するレスポンスをキャッシュしたい場合は `@st.cache_data` デコレータを使い、API 呼び出し回数を削減できます
- **ストリーミング**: `generate_content_stream` を使うことで、レスポンスの最初の部分がすぐに表示され、ユーザーの待ち時間を体感的に短縮できます
- **`session_state` の管理**: チャット履歴が長くなると Gemini API へのトークン送信量が増えるため、一定件数を超えたら古いメッセージを削除する仕組みを入れると、レスポンス速度と API コストの両方を最適化できます

ストリーミングや Function Calling の詳細な実装パターンについては、[Gemini API ストリーミング＆Function Calling 統合ガイド](/articles/gemini-api/gemini-api-streaming-function-calling-guide) で体系的に解説しています。

## よくある質問（FAQ）

### Q1: Streamlit Community Cloud の無料枠に制限はありますか？

はい、無料プランではアプリが一定時間アクセスされないとスリープ状態になります。アクセスがあると自動的に復帰しますが、初回の読み込みに数秒かかる場合があります。個人のプロトタイプやポートフォリオ用途であれば、無料枠で十分対応可能です。

### Q2: Gemini API の利用料金はどのくらいかかりますか？

Gemini 2.5 Flash は無料枠が用意されており、個人開発レベルのプロトタイピングであれば無料で利用できます。無料枠を超えた場合でも、Flash モデルは入力 100 万トークンあたり数十セント程度と非常に低コストです。Gemini 2.5 Pro はより高精度ですが、その分コストも高くなるため、用途に応じてモデルを使い分けるのがおすすめです。

### Q3: 本番環境として Streamlit を使い続けても問題ないですか？

プロトタイプや社内ツールとしては十分ですが、大量のユーザーが同時アクセスするような本番サービスには向いていません。プロトタイプで仮説を検証した後、FastAPI + React や Next.js などのフルスタック構成に移行するのが一般的なアプローチです。Streamlit は「まず動くものを作って試す」フェーズで最も力を発揮します。

### Q4: Streamlit で作ったアプリにユーザー認証を追加できますか？

Streamlit には `st.experimental_user` や外部認証サービス（Auth0、Firebase Authentication など）を組み合わせた認証機能があります。また、Streamlit Community Cloud では GitHub アカウントによるアクセス制限が可能です。ただし、きめ細かい権限管理が必要な場合はフルスタックフレームワークへの移行を検討してください。
