## 取り組みの背景 — Gradio で AI アプリを「最速」で公開する

AI モデルの性能がいくら高くても、ユーザーが触れる UI がなければ価値は伝わりません。Gemini API を使った AI 機能を素早くデモ可能な Web アプリに仕上げたいとき、Python の UI フレームワーク **Gradio** は最有力の選択肢です。

Gradio を使えば、フロントエンド開発の経験がなくても、数十行の Python コードで以下のような AI アプリを構築できます。

- テキスト生成・要約アプリ
- 画像アップロード → AI 分析アプリ
- リアルタイムチャットボット
- ファイルアップロード → ドキュメント解析アプリ

Gemini API と Gradio を組み合わせた **3 つの実践的なアプリ** をステップバイステップで構築し、Hugging Face Spaces への公開までを順を追って整理していきます。Gemini API の基本的な使い方については [Gemini API クイックスタートガイド](/articles/gemini-api/gemini-api-quickstart) も併せてご覧ください。

## 環境準備 — Python と必要なライブラリのインストール

まずは開発環境をセットアップします。Python 3.10 以上が必要です。

```bash
# 仮想環境の作成（推奨）
python -m venv gemini-gradio-env
source gemini-gradio-env/bin/activate  # Windows: gemini-gradio-env\Scripts\activate

# 必要なライブラリのインストール
pip install google-genai gradio pillow
```

次に、Gemini API キーを取得します。[Google AI Studio](https://aistudio.google.com/) にアクセスし、左メニューの「Get API key」から API キーを発行してください。

```bash
# 環境変数に API キーを設定
export GEMINI_API_KEY="YOUR_API_KEY"
```

API キーの取得方法について詳しく知りたい場合は、[Google AI Studio の使い方ガイド](/articles/gemini-dev/google-ai-studio-guide) を参照してください。

## アプリ 1 — テキスト生成・要約アプリ

最初に、ユーザーが入力したテキストを Gemini が要約するシンプルなアプリを作ります。

```python
import os
import gradio as gr
from google import genai

# Gemini クライアントの初期化
client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

def summarize_text(text: str, style: str) -> str:
    """テキストを指定されたスタイルで要約する"""
    prompt = f"""以下のテキストを{style}で要約してください。
要点を箇条書きで3〜5個にまとめ、最後に一文で結論を述べてください。

テキスト:
{text}
"""
    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=prompt,
    )
    return response.text

# Gradio UI の定義
demo = gr.Interface(
    fn=summarize_text,
    inputs=[
        gr.Textbox(
            label="要約したいテキスト",
            placeholder="ここにテキストを貼り付けてください...",
            lines=10,
        ),
        gr.Radio(
            choices=["ビジネス向け", "カジュアル", "技術者向け"],
            label="要約スタイル",
            value="ビジネス向け",
        ),
    ],
    outputs=gr.Markdown(label="要約結果"),
    title="Gemini テキスト要約アプリ",
    description="Gemini API を使ってテキストを素早く要約します。",
)

# 期待される出力:
# ブラウザに要約アプリのUIが表示され、テキスト入力と
# スタイル選択で即座にGeminiが要約を生成する

demo.launch()
```

このコードを `app_summary.py` として保存し、`python app_summary.py` で実行すると、ブラウザに要約アプリが表示されます。`gr.Interface` の引数を変更するだけで、入力フォームや出力形式を自由にカスタマイズできます。

## アプリ 2 — 画像分析チャットアプリ

次に、Gemini のマルチモーダル機能を活かして、画像をアップロードすると AI が分析結果を返すアプリを作ります。

```python
import os
import gradio as gr
from google import genai
from PIL import Image

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

def analyze_image(image: Image.Image, question: str) -> str:
    """アップロードされた画像を分析し、質問に回答する"""
    if image is None:
        return "画像をアップロードしてください。"

    prompt = question if question else "この画像の内容を詳しく説明してください。"

    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=[prompt, image],
    )
    return response.text

demo = gr.Interface(
    fn=analyze_image,
    inputs=[
        gr.Image(type="pil", label="分析する画像"),
        gr.Textbox(
            label="質問（任意）",
            placeholder="例: この画像に写っている食べ物のカロリーは？",
        ),
    ],
    outputs=gr.Markdown(label="分析結果"),
    title="Gemini 画像分析アプリ",
    description="画像をアップロードすると、Gemini が内容を分析します。",
    examples=[
        ["https://upload.wikimedia.org/wikipedia/commons/thumb/a/a7/Camponotus_flavomarginatus_ant.jpg/320px-Camponotus_flavomarginatus_ant.jpg", "この画像に写っている生物は何ですか？"],
    ],
)

# 期待される出力:
# 画像アップロードエリアとテキスト入力欄が表示され、
# 画像を送信するとGeminiがマルチモーダル分析結果を返す

demo.launch()
```

Gemini 2.5 Flash は画像・テキストの同時処理に対応しており、`contents` にリストとして渡すだけでマルチモーダル推論が実行されます。さらに高度なマルチモーダル活用テクニックを学びたい方は、[Gemini API マルチモーダル実践テクニック集](/articles/gemini-api/gemini-api-multimodal-techniques) で詳しく解説しています。

## アプリ 3 — リアルタイムチャットボット

Gradio の `gr.ChatInterface` を使うと、チャットボット UI を簡単に構築できます。ストリーミング応答にも対応させてみましょう。

```python
import os
import gradio as gr
from google import genai

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

def chat_with_gemini(message: str, history: list) -> str:
    """Gemini とのチャット（履歴付き）"""
    # チャット履歴を Gemini API 形式に変換
    contents = []
    for user_msg, bot_msg in history:
        contents.append({"role": "user", "parts": [{"text": user_msg}]})
        contents.append({"role": "model", "parts": [{"text": bot_msg}]})
    contents.append({"role": "user", "parts": [{"text": message}]})

    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=contents,
        config={
            "system_instruction": "あなたは親切で知識豊富なAIアシスタントです。日本語で丁寧に回答してください。",
        },
    )
    return response.text

demo = gr.ChatInterface(
    fn=chat_with_gemini,
    title="Gemini チャットボット",
    description="Gemini API を使ったリアルタイムチャットボットです。",
    examples=["Pythonの効率的な学習方法を教えてください", "今日の天気に合う料理のレシピを3つ提案して"],
    theme="soft",
)

# 期待される出力:
# チャットUIが表示され、メッセージを送信するたびに
# Geminiが会話履歴を考慮した応答を返す

demo.launch()
```

`gr.ChatInterface` は会話履歴の管理を自動で行ってくれるため、`history` パラメータに過去のやり取りがリスト形式で渡されます。これを Gemini API の `contents` 形式に変換するだけでマルチターン会話が実現できます。

## UI をカスタマイズする — Gradio Blocks API

より自由度の高い UI が必要な場合は、`gr.Blocks` を使ってレイアウトをカスタマイズできます。以下は、テキスト要約と画像分析を **タブで切り替えられる統合アプリ** の例です。

```python
import os
import gradio as gr
from google import genai
from PIL import Image

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

def summarize(text: str) -> str:
    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=f"以下のテキストを要約してください:\n{text}",
    )
    return response.text

def analyze(image: Image.Image) -> str:
    if image is None:
        return "画像を選択してください。"
    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=["この画像を詳しく分析してください。", image],
    )
    return response.text

with gr.Blocks(title="Gemini AI ツールキット", theme=gr.themes.Soft()) as demo:
    gr.Markdown("# Gemini AI ツールキット")
    gr.Markdown("Gemini API を活用した AI ツール集です。")

    with gr.Tabs():
        with gr.TabItem("テキスト要約"):
            text_input = gr.Textbox(label="テキスト", lines=8)
            text_btn = gr.Button("要約する", variant="primary")
            text_output = gr.Markdown(label="結果")
            text_btn.click(fn=summarize, inputs=text_input, outputs=text_output)

        with gr.TabItem("画像分析"):
            img_input = gr.Image(type="pil", label="画像")
            img_btn = gr.Button("分析する", variant="primary")
            img_output = gr.Markdown(label="結果")
            img_btn.click(fn=analyze, inputs=img_input, outputs=img_output)

# 期待される出力:
# タブ切り替え式のUIが表示され、
# 「テキスト要約」タブと「画像分析」タブを切り替えて使える

demo.launch()
```

`gr.Blocks` を使うと、行・列レイアウト（`gr.Row`, `gr.Column`）やアコーディオン（`gr.Accordion`）なども自在に組み合わせられるため、複雑な UI も Python だけで構築できます。

## Hugging Face Spaces にデプロイする

Gradio アプリを世界中に公開する最も手軽な方法は、**Hugging Face Spaces** を使うことです。

### 手順 1 — リポジトリの準備

```bash
# 必要なファイルを用意
mkdir gemini-gradio-app && cd gemini-gradio-app

# requirements.txt を作成
cat > requirements.txt << 'EOF'
google-genai>=1.0.0
gradio>=5.0.0
pillow>=10.0.0
EOF
```

### 手順 2 — app.py の作成

前述のアプリコード（アプリ 3 のチャットボットなど）を `app.py` として保存します。

### 手順 3 — Hugging Face Spaces にデプロイ

```bash
# Hugging Face CLI をインストール
pip install huggingface_hub

# ログイン
huggingface-cli login

# Space を作成してプッシュ
huggingface-cli repo create gemini-chatbot --type space --space-sdk gradio
git init
git remote add origin https://huggingface.co/spaces/YOUR_USERNAME/gemini-chatbot
git add .
git commit -m "Initial commit"
git push origin main
```

Hugging Face Spaces の設定画面で、**Secrets** に `GEMINI_API_KEY` を登録すれば、API キーをコードにハードコードせずにアプリを公開できます。本番運用時のセキュリティベストプラクティスについては、[Gemini API 本番環境セキュリティ完全ガイド](/articles/gemini-api/gemini-api-production-security-guide) で詳しく解説しています。

## Streamlit との比較 — どちらを選ぶべきか

Gradio と並んで人気の高い Python UI フレームワークに **Streamlit** があります。それぞれの特徴を整理します。

- **Gradio**: ML デモに特化した設計。`gr.Interface` で入出力を定義するだけで UI が完成する。Hugging Face との統合が強く、モデルのデモ公開に最適
- **Streamlit**: 汎用的なデータアプリ向け。ダッシュボードやデータ可視化に強い。独自のデプロイ基盤（Streamlit Cloud）を持つ

選択の目安として、**AI モデルのデモ・プロトタイプなら Gradio**、**データダッシュボードや複雑な業務アプリなら Streamlit** がおすすめです。Streamlit で AI アプリを作る方法については [Gemini API × Streamlit で AI Web アプリを効率的にプロトタイピング](/articles/gemini-dev/gemini-api-streamlit-ai-web-app-rapid-prototyping) で解説しています。

## まとめ

Gemini API と Gradio の組み合わせは、AI アプリのプロトタイピングにおいて非常に強力です。本記事で紹介した 3 つのパターン（テキスト要約・画像分析・チャットボット）をベースに、さまざまな AI アプリを素早く構築・公開できます。

Gradio の `gr.Interface` でシンプルに始め、必要に応じて `gr.Blocks` で UI をカスタマイズし、Hugging Face Spaces で世界に公開する。この一連のフローを身につければ、アイデアを形にするまでの時間を大幅に短縮できます。
