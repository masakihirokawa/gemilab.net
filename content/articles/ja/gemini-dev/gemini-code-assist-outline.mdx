# Gemini Code Assist Outline 機能完全ガイド — 複雑なコードを図解で理解

## はじめに

大規模なプロジェクトに参入したとき、最初にぶつかる壁は **「このコードベース、どうなってるの？」**という疑問です。数千行のファイル、複雑に絡み合ったモジュール、呼び出し関係が不明な関数……。従来なら、ドキュメントを探したり、デバッガを使ったりして手探りで進めていましました。

Gemini Code Assist の **Outline 機能**は、これらの課題を一気に解決します。AI がコードを読み込み、**ファイル構造、関数呼び出しの流れ、データフローを図解で表示**してくれるのです。本記事では、Outline 機能の使い方、活用シーン、実装テクニックを詳しく解説します。

---

## Outline 機能とは？

### 概念

Gemini Code Assist の **Outline** は、現在のファイル（または選択範囲）のコード構造をツリー形式またはダイアグラム形式で可視化する機能です。

- 関数の階層構造：トップレベル関数 → 呼び出す関数 → その先へ……
- クラス定義：メンバー変数、メソッド、継承関係
- import / export 関係：モジュール間の依存性
- 変数スコープ：グローバル変数、ローカル変数の使用箇所

従来の「コード折りたたみ」機能とは異なり、Gemini の Outline は **単なる表示ではなく、AI が構造を理解したうえで**最適な形で提示します。

## Outline を表示する方法

### VS Code での操作

1. Gemini Code Assist パネルを開く
   - VS Code の左サイドバーから「Gemini」アイコンをクリック
   - または `Ctrl+Shift+G`（Windows/Linux）/ `Cmd+Shift+G`（macOS）

2. Outline タブを選択
   - パネル上部のタブから「Outline」をクリック

3. 対象ファイルを指定（オプション）
   - デフォルトは現在のアクティブファイル

### IntelliJ での操作

IntelliJ IDEA でも同様に利用可能：

1. 右サイドバーの「Gemini」パネルを開く
2. 「Outline」セクションをクリック
3. コード構造がツリー形式で表示される

## 実践例：Node.js 複数ファイルの構造理解

### シナリオ

新しいチームに加わり、Express.js で書かれたバックエンドプロジェクトを引き継いです。理解すべき項目：

- アプリケーションの入口（main ファイル）
- ミドルウェアの構成
- ルート定義
- データベース接続フロー

### Outline で確認する手順

**Step 1：メインファイル（app.js）を開く**

```javascript
// app.js
const express = require('express');
const authMiddleware = require('./middleware/auth');
const userRoutes = require('./routes/users');
const dbConnection = require('./db/connection');

const app = express();

app.use(express.json());
app.use(authMiddleware);

app.use('/api/users', userRoutes);

app.use((err, req, res, next) => {
  console.error(err.stack);
  res.status(500).json({ error: 'Internal Server Error' });
});

module.exports = app;
```

**Step 2：Outline を表示**

Outline パネルに以下のような構造が表示：

- require() セクション
- app 初期化
- ミドルウェアスタック
- ルート定義
- エラーハンドラ

**Step 3：各セクションをクリックして詳細を確認**

「authMiddleware」をクリック → 実装ファイル（./middleware/auth.js）にジャンプ

```javascript
// middleware/auth.js
const jwt = require('jsonwebtoken');

module.exports = (req, res, next) => {
  const token = req.headers.authorization?.split(' ')[1];

  if (!token) {
    return res.status(401).json({ error: 'No token' });
  }

  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.user = decoded;
    next();
  } catch (err) {
    res.status(403).json({ error: 'Invalid token' });
  }
};
```

## Outline 機能の高度な活用

### 1. マルチファイル関数追跡

複数ファイルに渡る関数呼び出しの流れを視覚化：

```javascript
// button.js
document.getElementById('submit').addEventListener('click', () => {
  processUserInput(inputData);
});

// validator.js
function processUserInput(data) {
  if (validateInput(data)) {
    sendToServer(data);
  }
}

function validateInput(data) {
  return checkFormat(data) && checkLength(data);
}

// api.js
async function sendToServer(data) {
  const response = await fetch('/api/submit', {
    method: 'POST',
    body: JSON.stringify(data)
  });
  return response.json();
}
```

Outline で「processUserInput」を追跡すると、関数呼び出しの流れが一目瞭然です。

### 2. クラス構造の一目理解

Python の複雑なクラス継承関係も即座に把握：

```python
# models.py
class BaseModel:
    def __init__(self, id):
        self.id = id

    def save(self):
        raise NotImplementedError()

class User(BaseModel):
    def __init__(self, id, name, email):
        super().__init__(id)
        self.name = name
        self.email = email

    def save(self):
        return db.insert('users', self.__dict__)

    def get_profile(self):
        return {
            'id': self.id,
            'name': self.name,
            'email': self.email
        }

class Admin(User):
    def __init__(self, id, name, email, role):
        super().__init__(id, name, email)
        self.role = role

    def delete_user(self, user_id):
        return db.delete('users', user_id)
```

Outline に表示されるクラス階層構造で、継承関係が明確になります。

## よくある質問（FAQ）

### Q1. Outline はリアルタイムで更新されますか？

**A.** はい。ファイルを編集するたびに Outline は自動更新されます。ただし、大規模ファイル（数千行）の場合は数秒のラグが生じる可能性があります。

### Q2. Outline で表示する関数を選別できますか？

**A.** バージョンによります。新しい Gemini Code Assist では、以下のフィルタオプションが利用可能：

- 関数のみ表示
- クラスのみ表示
- 公開メソッド（public）のみ表示
- プライベートメソッド（private）を非表示

### Q3. TypeScript の型情報も Outline に表示されますか？

**A.** はい。Outline は TypeScript の型定義も認識し、関数シグネチャに型を含めて表示します。

```typescript
// 実装
function fetchUser(id: number): Promise<User> {
  return db.query('SELECT * FROM users WHERE id = ?', [id]);
}

// Outline に表示される
fetchUser(id: number) → Promise<User>
```

## Outline の制限と対策

### 1. 非常に大きなファイルでの遅延

1万行を超えるファイルの場合、Outline の生成に 5〜10 秒かかる可能性があります。

**対策**：ファイルを分割してモジュール化

### 2. 動的に生成されるコードの追跡不可

メタプログラミングで動的に関数を生成する場合、Outline は追跡できません。

**対策**：明示的なコメント追加

```javascript
/**
 * Dynamic methods (Outline helper):
 * - create(id): Create record
 * - read(id): Read record
 * - update(id): Update record
 * - delete(id): Delete record
 */
```
