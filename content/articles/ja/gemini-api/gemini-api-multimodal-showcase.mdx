Gemini APIの最大の魅力は、テキスト・画像・動画・音声・コードを単一のモデルで横断的に処理できる「マルチモーダル能力」にあります。単なるテキスト生成AIを超え、現実世界の複雑な情報を統合的に扱えるこの力は、アプリケーション開発の可能性を大きく広げます。


## Gemini APIの基本セットアップ

まずは開発環境の準備から始めましょう。Gemini APIはPython・JavaScript/TypeScript・Go・Java・REST APIなど多様なインターフェースで利用できます。本記事ではPythonを中心に解説します。

### APIキーの取得

[Google AI Studio](https://aistudio.google.com) にアクセスし、Googleアカウントでサインインした後、「APIキーを取得」からキーを発行します。

### Pythonライブラリのインストール

```bash
pip install google-generativeai
```

### 基本的な初期化

```python
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")

# モデルの選択
model = genai.GenerativeModel('gemini-2.0-flash')
```

プロダクションコードでは、APIキーを環境変数から読み込むことを強くおすすめします。

```python
import os
import google.generativeai as genai

genai.configure(api_key=os.environ.get("GEMINI_API_KEY"))
```

## テキスト生成の基本

まず最もシンプルなテキスト生成から確認しましょう。

```python
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")

```

## 画像理解：ビジュアルコンテンツを解析する

Geminiの真骨頂の一つが画像理解能力です。画像をテキストと組み合わせて入力できます。

### ローカル画像の解析

```python
import PIL.Image
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel('gemini-2.0-flash')

# 画像ファイルを読み込む
image = PIL.Image.open("screenshot.png")

response = model.generate_content([
    "この画像のUIについて、改善点を3つ指摘してください。",
    image
])
print(response.text)
```

### URLから画像を解析する

```python
import httpx
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel('gemini-2.0-flash')

# URLから画像データを取得
image_url = "https://example.com/product-photo.jpg"
image_data = httpx.get(image_url).content

response = model.generate_content([
    {
        "mime_type": "image/jpeg",
        "data": image_data
    },
    "この商品画像から、主な特徴を箇条書きで説明してください。"
])
print(response.text)
```

### 複数画像の比較分析

## 動画理解：映像コンテンツを分析する

Gemini 1.5/2.0系のモデルは最大1時間程度の動画を処理できます。

### File APIを使った動画アップロード

大きなファイルはFile APIを経由してアップロードします。

```python
import time
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")

# 動画ファイルをアップロード
video_file = genai.upload_file("demo_video.mp4")

# 処理完了を待機
while video_file.state.name == "PROCESSING":
    time.sleep(2)
    video_file = genai.get_file(video_file.name)

if video_file.state.name == "FAILED":
    raise ValueError("動画の処理に失敗しました")

# 動画について質問する
model = genai.GenerativeModel('gemini-2.0-flash')
response = model.generate_content([
    video_file,
    "この動画の内容を時系列で要約し、主要なポイントを3つ挙げてください。"
])
print(response.text)

# 使用後はファイルを削除（ストレージ節約）
genai.delete_file(video_file.name)
```

## 構造化データの生成：JSONレスポンス

アプリケーション開発では、LLMの出力を構造化されたデータとして受け取りたい場面が多くあります。

```python
import json
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel('gemini-2.0-flash')

response = model.generate_content(
    """次の商品説明からJSONデータを生成してください。

    商品説明: 「高品質なステンレス製水筒。容量500ml、保温保冷8時間対応。カラー展開：赤・青・黒。価格：¥2,980。」

    以下のJSON形式で出力してください:
    {
        "name": "商品名",
        "material": "素材",
        "capacity_ml": 容量（数値）,
        "insulation_hours": 保温保冷時間（数値）,
        "colors": ["色1", "色2"],
        "price_jpy": 価格（数値）
    }

    JSONのみ出力し、説明文は不要です。""",
    generation_config=genai.types.GenerationConfig(
        response_mime_type="application/json"
    )
)

product_data = json.loads(response.text)
print(product_data)
```

## Function Calling：外部ツールとの連携

Function Callingを使うと、Geminiが必要に応じて外部関数を呼び出すエージェント的な動作を実現できます。

```python
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")

# 外部関数の定義
def get_current_weather(city: str) -> dict:
    """指定都市の現在の天気を返す（実際のAPIと連携する場合）"""
    # 実装例（実際はWeather APIを呼ぶ）
    return {"city": city, "temperature": 22, "condition": "晴れ"}

def get_stock_price(symbol: str) -> dict:
    """株価を返す"""
    return {"symbol": symbol, "price": 15000, "change": "+2.3%"}

# ツールの定義をGeminiに伝える
tools = [
    genai.protos.Tool(
        function_declarations=[
            genai.protos.FunctionDeclaration(
                name="get_current_weather",
                description="指定した都市の現在の天気情報を取得します",
                parameters=genai.protos.Schema(
                    type=genai.protos.Type.OBJECT,
                    properties={
                        "city": genai.protos.Schema(type=genai.protos.Type.STRING)
                    },
                    required=["city"]
                )
            )
        ]
    )
]

model = genai.GenerativeModel('gemini-2.0-flash', tools=tools)
response = model.generate_content("東京の現在の天気を教えてください")

# Function Callの処理
if response.candidates[0].content.parts[0].function_call:
    fc = response.candidates[0].content.parts[0].function_call
    result = get_current_weather(**dict(fc.args))
    print(f"天気情報: {result}")
```

## ストリーミングレスポンス

長い回答を生成する場合、ストリーミングを使うとリアルタイムに出力を受け取れます。

```python
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel('gemini-2.0-flash')

response = model.generate_content(
    "量子コンピュータの原理を詳しく説明してください",
    stream=True
)

for chunk in response:
    print(chunk.text, end="", flush=True)
print()  # 最後に改行
```

## エラーハンドリングとリトライ処理

本番環境ではAPIエラーへの対策が不可欠です。

```python
import time
import google.generativeai as genai
from google.api_core import exceptions

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel('gemini-2.0-flash')

def generate_with_retry(prompt: str, max_retries: int = 3) -> str:
    """リトライ機能付きのコンテンツ生成"""
    for attempt in range(max_retries):
        try:
            response = model.generate_content(prompt)
            return response.text
        except exceptions.ResourceExhausted:
            # レートリミットに達した場合
            if attempt < max_retries - 1:
                wait_time = 2 ** attempt  # 指数バックオフ
                print(f"レートリミット。{wait_time}秒後にリトライ...")
                time.sleep(wait_time)
            else:
                raise
        except exceptions.GoogleAPIError as e:
            print(f"APIエラー: {e}")
            raise
    return ""
```
