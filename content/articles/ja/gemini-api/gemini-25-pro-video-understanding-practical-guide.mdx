## YouTube URLから直接解析する

最もシンプルな使い方は、YouTube URLをそのまま渡す方法です。

```python
import google.generativeai as genai
import json

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel("gemini-2.5-pro-latest")

# YouTube URLを直接渡す
response = model.generate_content([
    {
        "file_data": {
            "mime_type": "video/mp4",
            "file_uri": "https://www.youtube.com/watch?v=動画ID"
        }
    },
    "この動画の内容を以下の形式でJSONとして出力してください:\n"
    "- title: 動画のタイトル\n"
    "- summary: 200文字以内の要約\n"
    "- key_points: 重要ポイントのリスト（最大5件）\n"
    "- mentioned_tools: 言及されたツール・技術名のリスト"
])

try:
    # Geminiが```json ```で囲んで返すことがある
    text = response.text.strip()
    if text.startswith("```"):
        text = text.split("```")[1]
        if text.startswith("json"):
            text = text[4:]
    result = json.loads(text.strip())
    print(json.dumps(result, ensure_ascii=False, indent=2))
except json.JSONDecodeError:
    print(response.text)
```

YouTube URLを渡すとGeminiがYouTubeから動画を取得して処理する。自分でダウンロードする必要はありません。ただし、限定公開動画や年齢制限のある動画には対応していません。

## ローカル動画ファイルの処理

手元の動画ファイルを処理するにはFile APIを使います。

```python
import google.generativeai as genai
import time

genai.configure(api_key="YOUR_GEMINI_API_KEY")

def analyze_local_video(file_path: str, prompt: str) -> str:
    """ローカル動画ファイルをアップロードして解析する"""
    
    print(f"アップロード中: {file_path}")
    video_file = genai.upload_file(
        path=file_path,
        mime_type="video/mp4"
    )
    
    # アップロード後、処理完了まで待機が必要
    max_wait = 120  # 最大2分待機
    elapsed = 0
    while video_file.state.name == "PROCESSING":
        if elapsed >= max_wait:
            raise TimeoutError("動画の処理がタイムアウトしました")
        print(f"  処理中... ({elapsed}s)")
        time.sleep(10)
        elapsed += 10
        video_file = genai.get_file(video_file.name)
    
    if video_file.state.name == "FAILED":
        raise RuntimeError(f"動画の処理に失敗しました: {video_file.state}")
    
    print("解析開始...")
    model = genai.GenerativeModel("gemini-2.5-pro-latest")
    response = model.generate_content([video_file, prompt])
    
    # 使い終わったファイルは削除（ストレージ節約）
    genai.delete_file(video_file.name)
    
    return response.text

# 使用例
result = analyze_local_video(
    "product_demo.mp4",
    "この製品デモ動画で紹介されている機能を、操作の順番に沿ってリストアップしてください。"
    "各機能について「操作方法」「想定ユーザー」「特に強調されていた点」を含めてください。"
)
print(result)
```

アップロードから処理完了まで動画の長さによって数十秒かかります。`PROCESSING`状態の間はAPIコールを待機する必要がある点が実装上のポイントです。

## 複数動画を一括処理するバッチ処理

同じ仕様の動画を大量に処理するなら、アップロードと解析を分離するとエラー時のリトライが楽になります。

```python
import google.generativeai as genai
import time
from pathlib import Path
from typing import Optional

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel("gemini-2.5-pro-latest")

ANALYSIS_PROMPT = """
この動画を解析して、以下のフィールドを含むJSONを出力してください。
マークダウンコードブロックは使わず、JSONのみ出力してください。

{
  "duration_estimated": "推定時間（例: 約5分）",
  "content_type": "チュートリアル/プレゼン/デモ/インタビュー のいずれか",
  "main_topic": "主要トピック（50文字以内）",
  "key_insights": ["洞察1", "洞察2", "洞察3"],
  "action_items": ["次にできるアクション1", "アクション2"],
  "quality_rating": 1から5の数字
}
"""

def upload_video(file_path: str) -> Optional[genai.types.File]:
    """動画をアップロードして処理完了まで待つ"""
    try:
        video_file = genai.upload_file(path=file_path, mime_type="video/mp4")
        for _ in range(24):  # 最大4分待機
            if video_file.state.name \!= "PROCESSING":
                break
            time.sleep(10)
            video_file = genai.get_file(video_file.name)
        return video_file if video_file.state.name == "ACTIVE" else None
    except Exception as e:
        print(f"アップロードエラー ({file_path}): {e}")
        return None

def batch_analyze(video_dir: str) -> list[dict]:
    """ディレクトリ内の動画を一括解析"""
    results = []
    video_files = list(Path(video_dir).glob("*.mp4"))
    
    for i, path in enumerate(video_files, 1):
        print(f"[{i}/{len(video_files)}] {path.name}")
        
        video_file = upload_video(str(path))
        if not video_file:
            results.append({"file": path.name, "error": "upload_failed"})
            continue
        
        try:
            response = model.generate_content([video_file, ANALYSIS_PROMPT])
            import json
            result = json.loads(response.text.strip())
            result["file"] = path.name
            results.append(result)
        except Exception as e:
            results.append({"file": path.name, "error": str(e)})
        finally:
            # 成功/失敗を問わずファイルを削除
            try:
                genai.delete_file(video_file.name)
            except Exception:
                pass
        
        # レート制限対策：動画ごとに2秒待機
        time.sleep(2)
    
    return results

# 実行
results = batch_analyze("./videos")
import json
with open("video_analysis_results.json", "w", encoding="utf-8") as f:
    json.dump(results, f, ensure_ascii=False, indent=2)
print(f"完了: {len(results)}件を処理しました")
```

## タイムスタンプを使ったシーン検索

「このトピックが説明されているのは動画のどこか」を調べたいときは、タイムスタンプ付きの情報抽出が有効です。

```python
def find_topic_timestamps(video_file, topic: str) -> list[dict]:
    """指定したトピックが登場するタイムスタンプを取得"""
    
    prompt = f"""
    動画の中で「{topic}」について説明・言及している部分を見つけてください。
    各箇所について以下の形式で出力してください：
    
    [開始時刻(MM:SS形式)] [終了時刻(MM:SS形式)] [説明: その箇所の内容を1文で]
    
    複数ある場合はすべて列挙してください。
    見つからない場合は「該当箇所なし」と出力してください。
    """
    
    response = model.generate_content([video_file, prompt])
    return response.text

# 例：APIエラーハンドリングについて説明している箇所を検索
timestamps = find_topic_timestamps(video_file, "APIエラーハンドリング")
print(timestamps)
# 出力例:
# [12:30] [14:45] 説明: try/exceptを使ったAPIエラーの処理方法を解説している部分
# [28:10] [29:20] 説明: レート制限エラーのリトライ実装について補足している部分
```

## コストと処理時間の目安

動画処理はトークン消費が大きいです。Gemini 2.5 Pro の動画処理コストは1秒あたり約263トークン換算となっています。

- 5分動画（300秒）：約78,900トークン ≒ 約$0.60（入力のみ）
- 30分動画（1,800秒）：約473,400トークン ≒ 約$3.60（入力のみ）

処理時間は動画の長さの約20〜50%程度（5分動画なら1〜2.5分）が目安だが、APIの混雑状況によって変わる。コストを抑えたい場合は、Gemini 2.5 Flashで概要抽出 → 重要箇所だけProで精査、という二段階アプローチも有効です。

動画解析APIの使い道は思った以上に広い。チュートリアル動画のドキュメント化、会議録画からのアクションアイテム抽出、競合製品デモの分析など、手作業でやっていた情報整理の多くを自動化できます。まずは手元にある短い動画で試してみるとよい。
