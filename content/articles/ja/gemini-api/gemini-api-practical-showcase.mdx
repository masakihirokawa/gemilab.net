## はじめに：Gemini APIが切り拓く新しい開発の地平

Google の Gemini API は、2024年から2025年にかけて急速に進化し、開発者にとって最も強力なAI APIの一つとなりましました。特筆すべきは、テキスト・画像・音声・動画・コードを横断して処理できる「マルチモーダル」能力で、これは他のAIサービスと比べても際立った強みです。

さらに、Gemini Flash モデルは非常に高速かつ低コストで、大量リクエストが必要な商用アプリでの使用に適しています。一方の Gemini Pro・Ultra は複雑な推論や高精度な分析が求められるタスクに力を発揮します。

この記事では、Gemini API の実践的な使い方を、コード例とともに体系的に解説します。Gemini Lab のプレミアム会員向けの深掘りガイドを、本日は見本として全文無料でお届けします。

## Gemini APIのセットアップ：5分で始める

### APIキーの取得

Google AI Studio（[aistudio.google.com](https://aistudio.google.com)）にアクセスし、Googleアカウントでログインします。左側メニューの「Get API key」をクリックし、新しいAPIキーを生成します。

**重要**: 生成したAPIキーは安全な場所に保管し、コードに直接書き込まないようにしましょう。環境変数として管理するのが基本です。

```bash
export GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
```

### Pythonのセットアップ

```bash
pip install google-generativeai
```

### 最初のAPI呼び出し

```python
import google.generativeai as genai
import os

genai.configure(api_key=os.environ.get("GEMINI_API_KEY"))
model = genai.GenerativeModel("gemini-2.0-flash")

response = model.generate_content("AIの未来について、3つの重要なトレンドを教えてください")
print(response.text)
```

これだけで Gemini API の基本的な使い方がわかります。では、より実践的な活用方法を見ていきましょう。

## マルチモーダル機能1：画像理解・分析

### 画像の内容を解析する

Gemini の最大の特徴の一つが、画像を直接入力として受け取り、その内容を理解・分析できることです。

```python
import google.generativeai as genai
import PIL.Image
import os

genai.configure(api_key=os.environ.get("GEMINI_API_KEY"))
model = genai.GenerativeModel("gemini-2.0-flash")

# 画像を読み込む
image = PIL.Image.open("product_photo.jpg")

# 画像について質問する
response = model.generate_content([
    image,
    "この商品の特徴を200文字で説明してください。ECサイト用の商品説明として使います"
])

print(response.text)
```

### 実践的なユースケース：商品画像からの自動説明文生成

ECサイト運営者にとって、大量の商品画像から説明文を生成するタスクは時間のかかる作業です。Gemini APIを使えば、このプロセスを大幅に自動化できます：

```python
import google.generativeai as genai
import PIL.Image
import os
import json
from pathlib import Path

genai.configure(api_key=os.environ.get("GEMINI_API_KEY"))
model = genai.GenerativeModel("gemini-2.0-flash")

def generate_product_description(image_path: str) -> dict:
    image = PIL.Image.open(image_path)
    
    prompt = """この商品画像を分析し、以下のJSON形式で情報を出力してください：
    {
        "title": "商品名（40文字以内）",
        "description": "商品説明（200文字以内）",
        "features": ["特徴1", "特徴2", "特徴3"],
        "keywords": ["キーワード1", "キーワード2", "キーワード3"]
    }
    JSONのみを出力し、他のテキストは含めないでください。"""
    
    response = model.generate_content([image, prompt])
    
    # JSON解析
    text = response.text.strip()
    if text.startswith("```"):
        text = text.split("```")[1]
        if text.startswith("json"):
            text = text[4:]
    
    return json.loads(text)

# 商品画像フォルダの全画像を処理
product_folder = Path("./products")
results = []

for image_file in product_folder.glob("*.jpg"):
    print(f"処理中: {image_file.name}")
    description = generate_product_description(str(image_file))
    description["file"] = image_file.name
    results.append(description)

# 結果をJSONで保存
with open("product_descriptions.json", "w", encoding="utf-8") as f:
    json.dump(results, f, ensure_ascii=False, indent=2)

print(f"完了: {len(results)}件の商品説明を生成しました")
```

## マルチモーダル機能2：PDF・文書の処理

### PDFを直接読み込んで分析する

Gemini 1.5 Pro 以降のモデルは、PDFを直接入力として受け取り、内容を理解できます。長大な文書でも高精度に処理できるため、契約書レビューや論文要約などに非常に有用です。

```python
import google.generativeai as genai
import os

genai.configure(api_key=os.environ.get("GEMINI_API_KEY"))
model = genai.GenerativeModel("gemini-1.5-pro")

# PDFファイルをアップロード
pdf_file = genai.upload_file("contract.pdf", mime_type="application/pdf")

# PDFの内容について質問
response = model.generate_content([
    pdf_file,
    """この契約書を分析し、以下の点を確認してください：
    1. 契約当事者と役割
    2. 契約期間と更新条件
    3. 主要な義務事項（両当事者）
    4. 解約条件とペナルティ
    5. 注意すべき不利な条項
    
    法的な専門用語を避け、わかりやすい日本語で説明してください。"""
])

print(response.text)
```

### 長文書の複数ページ処理

100ページを超えるような長い文書でも、Gemini 1.5 Pro の100万トークンのコンテキストウィンドウを活用すれば一度に処理できます。これにより、長い報告書全体を踏まえた質問や、複数セクション間の矛盾検出なども可能になります。

## マルチモーダル機能3：動画・音声の処理

### 動画コンテンツの分析

Gemini APIは動画ファイルを直接処理できます。会議の録画、製品デモ動画、教育コンテンツなどの分析や書き起こしに活用できます：

```python
import google.generativeai as genai
import os

genai.configure(api_key=os.environ.get("GEMINI_API_KEY"))
model = genai.GenerativeModel("gemini-1.5-pro")

# 動画をアップロード
print("動画をアップロード中...")
video_file = genai.upload_file("meeting_recording.mp4", mime_type="video/mp4")

# アップロード完了待機
import time
while video_file.state.name == "PROCESSING":
    time.sleep(5)
    video_file = genai.get_file(video_file.name)

# 動画の内容を分析
response = model.generate_content([
    video_file,
    """このミーティング録画を分析し、以下を出力してください：
    1. 議題の概要（箇条書き）
    2. 主な決定事項
    3. アクションアイテム（担当者・期限付き）
    4. 次回ミーティングの予定事項"""
])

print(response.text)
```

### 音声からの書き起こしと分析

音声ファイル（MP3・WAVなど）の書き起こしと内容分析も同様のアプローチで実現できます。インタビュー音声の自動文字起こし、カスタマーサポートの通話分析、ポッドキャストのサマリー生成など、幅広い用途があります。

## 実践的なアプリ開発：RAGシステムの構築

### RAG（検索拡張生成）とは

RAG（Retrieval-Augmented Generation）は、LLMに独自のデータソースを組み合わせて回答精度を高める技術です。「自社の製品マニュアルを参照しながら顧客の質問に答えるチャットボット」が典型的なユースケースです。

### Gemini APIとChromaDBで構築するシンプルなRAG

```python
import google.generativeai as genai
import chromadb
from chromadb.utils import embedding_functions
import os

genai.configure(api_key=os.environ.get("GEMINI_API_KEY"))

# ChromaDBの設定（ベクトルデータベース）
chroma_client = chromadb.Client()
google_ef = embedding_functions.GoogleGenerativeAiEmbeddingFunction(
    api_key=os.environ.get("GEMINI_API_KEY")
)

collection = chroma_client.create_collection(
    name="company_docs",
    embedding_function=google_ef
)

# ドキュメントを登録
documents = [
    "製品Aの返品ポリシー：購入から30日以内であれば全額返金します。",
    "製品Bは防水仕様（IPX7）で、水深1メートルに30分耐えられます。",
    "配送は通常3〜5営業日かかります。北海道・沖縄は追加1〜2日。",
]

collection.add(
    documents=documents,
    ids=["doc1", "doc2", "doc3"]
)

# 質問に対して関連ドキュメントを検索して回答
def rag_chat(question: str) -> str:
    # 関連ドキュメントを検索
    results = collection.query(query_texts=[question], n_results=2)
    context = "\n".join(results["documents"][0])
    
    # Geminiで回答生成
    model = genai.GenerativeModel("gemini-2.0-flash")
    prompt = f"""以下の情報に基づいて、質問に回答してください。
    
情報：
{context}

質問：{question}

情報に含まれていない場合は「その情報はありません」と答えてください。"""
    
    response = model.generate_content(prompt)
    return response.text

# テスト
print(rag_chat("製品Bは雨の中で使えますか？"))
print(rag_chat("返品したい場合はどうすればよいですか？"))
```

## コスト最適化：Gemini APIを賢く使う

### モデルの使い分け

Gemini には用途別に複数のモデルがあります。コストを抑えながら品質を維持するには、適切なモデルを選ぶことが重要です。

シンプルな分類・要約・変換タスクには Gemini Flash を使用するとコストを大幅に抑えられます。複雑な推論・長文書処理・高精度が必要なタスクには Gemini Pro を使用します。マルチモーダルかつ高度な推論が必要な最重要タスクには Gemini Ultra を検討します。

### キャッシュの活用

同じプロンプトや文書を繰り返し処理する場合は、Gemini APIのキャッシュ機能を活用しましょう。特に大きな文書（PDFなど）を基に複数の質問をする場合、文書のキャッシュにより大幅なコスト削減が可能です。

### バッチ処理の活用

リアルタイム性が不要なタスク（一括分析・定期レポート生成など）は、バッチ処理モードを使うことで、同じ処理を50%低いコストで実行できます。

## ストリーミングレスポンスとチャットUI

### リアルタイムストリーミング

長い回答を待たせずにユーザーに見せるには、ストリーミングレスポンスが効果的です：

```python
import google.generativeai as genai
import os

genai.configure(api_key=os.environ.get("GEMINI_API_KEY"))
model = genai.GenerativeModel("gemini-2.0-flash")

# ストリーミングで回答を受信
response = model.generate_content(
    "量子コンピュータの仕組みを初心者向けに詳しく説明してください",
    stream=True
)

for chunk in response:
    print(chunk.text, end="", flush=True)
print()  # 改行
```

### マルチターン会話（チャット）

会話の文脈を保持したチャットアプリを作るには、`ChatSession`を使います：

```python
chat = model.start_chat(history=[])

# 会話を続ける
while True:
    user_input = input("あなた: ")
    if user_input.lower() in ["quit", "終了"]:
        break
    
    response = chat.send_message(user_input)
    print(f"Gemini: {response.text}\n")
```
