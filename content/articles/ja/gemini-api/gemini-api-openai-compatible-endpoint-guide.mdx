OpenAI APIを使ったアプリケーションを開発してきた方にとって、Geminiへの移行は「大規模なコード改修が必要では？」と感じることがあるかもしれません。しかし、Gemini APIが提供する **OpenAI互換エンドポイント** を活用すれば、既存のOpenAI SDKコードを最小限の変更でそのままGeminiに接続することができます。

この記事では、OpenAI互換エンドポイントの仕組みから実際の使い方、注意点まで丁寧に解説します。

## OpenAI互換エンドポイントとは

GeminiのOpenAI互換エンドポイントとは、OpenAI APIと同じリクエスト・レスポンス形式をサポートする特別なエンドポイントです。つまり、`openai` ライブラリをインポートしたまま、接続先をGeminiのURLに変更するだけで、GeminiのモデルをOpenAI SDKから呼び出せます。

主なメリットは以下の通りです。

- **コードの再利用**: 既存のOpenAI APIクライアントコードを大幅に書き換えずに済む
- **段階的な移行**: 一部の機能だけGeminiに切り替えながらテストできる
- **LangChainなどのフレームワーク対応**: OpenAI互換インターフェースを前提としたツールがそのまま使える
- **コスト最適化**: Geminiの料金体系を活かしつつOpenAIのエコシステムを維持できる

対応しているGeminiモデルは `gemini-2.0-flash`、`gemini-2.5-pro` など主要モデルが含まれており、最新の対応状況は [Google AI Studio](https://aistudio.google.com/) で確認できます。

## 事前準備：APIキーの取得

まず、Gemini APIキーが必要です。

1. [Google AI Studio](https://aistudio.google.com/) にアクセスし、Googleアカウントでログインする
2. 画面左側の「API keys」を選択し、「Create API key」をクリックする
3. 生成されたキーをコピーして安全な場所に保管する

取得したAPIキーは環境変数に設定しておきましょう。

```bash
export GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
```

セキュリティの観点から、キーをコードに直接書き込まないことを強くおすすめします。

## PythonでOpenAI SDKを使ってGeminiを呼び出す

まず `openai` パッケージをインストールします（すでにインストール済みであれば不要です）。

```bash
pip install openai
```

次のコードを参照してください。変更点はベースURLと使用するAPIキーのみです。

```python
import os
from openai import OpenAI

# Gemini の OpenAI互換エンドポイントを指定する
client = OpenAI(
    api_key=os.environ["GEMINI_API_KEY"],
    base_url="https://generativelanguage.googleapis.com/v1beta/openai/"
)

response = client.chat.completions.create(
    model="gemini-2.0-flash",  # 使用するGeminiモデルを指定
    messages=[
        {"role": "system", "content": "あなたは親切なAIアシスタントです。"},
        {"role": "user", "content": "Geminiの主な特徴を3つ教えてください。"}
    ]
)

# OpenAI APIと同じ形式でレスポンスが返る
print(response.choices[0].message.content)
```

**期待する出力例:**

```
Geminiの主な特徴は以下の3つです。
1. マルチモーダル対応: テキスト・画像・音声・動画を統合して処理できます。
2. 長いコンテキストウィンドウ: 最大100万トークンのコンテキストを扱えます。
3. 強力な推論能力: Deep Think機能により、複雑な問題を段階的に考えられます。
```

### ストリーミングレスポンス

OpenAI SDKのストリーミング機能もそのまま使えます。

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["GEMINI_API_KEY"],
    base_url="https://generativelanguage.googleapis.com/v1beta/openai/"
)

# stream=True でストリーミングを有効化
stream = client.chat.completions.create(
    model="gemini-2.0-flash",
    messages=[
        {"role": "user", "content": "Pythonでフィボナッチ数列を生成するコードを書いてください。"}
    ],
    stream=True
)

# チャンクを受け取りながら順次出力
for chunk in stream:
    if chunk.choices[0].delta.content is not None:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()  # 最後に改行
```

## JavaScriptでOpenAI SDKを使ってGeminiを呼び出す

Node.js環境でも同様に `openai` パッケージを利用できます。

```bash
npm install openai
```

```javascript
import OpenAI from "openai";

// Gemini の OpenAI互換エンドポイントを指定する
const client = new OpenAI({
  apiKey: process.env.GEMINI_API_KEY,
  baseURL: "https://generativelanguage.googleapis.com/v1beta/openai/",
});

async function main() {
  const response = await client.chat.completions.create({
    model: "gemini-2.0-flash",
    messages: [
      {
        role: "system",
        content: "You are a helpful AI assistant.",
      },
      {
        role: "user",
        content: "What are the top 3 features of Gemini?",
      },
    ],
  });

  console.log(response.choices[0].message.content);
}

main();
```

### JavaScriptでのストリーミング

```javascript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.GEMINI_API_KEY,
  baseURL: "https://generativelanguage.googleapis.com/v1beta/openai/",
});

async function streamResponse() {
  const stream = await client.chat.completions.create({
    model: "gemini-2.5-pro",
    messages: [
      { role: "user", content: "JavaScriptで非同期処理を学ぶためのロードマップを教えてください。" },
    ],
    stream: true,
  });

  // 非同期イテレーターでチャンクを処理
  for await (const chunk of stream) {
    const content = chunk.choices[0]?.delta?.content || "";
    process.stdout.write(content);
  }
  console.log();
}

streamResponse();
```

## LangChainでの活用

LangChainを使っている場合、ChatOpenAIクラスのベースURLを変更するだけでGeminiを組み込めます。

```python
import os
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, SystemMessage

# LangChainのChatOpenAIにGeminiのエンドポイントを設定
llm = ChatOpenAI(
    model="gemini-2.0-flash",
    openai_api_key=os.environ["GEMINI_API_KEY"],
    openai_api_base="https://generativelanguage.googleapis.com/v1beta/openai/"
)

messages = [
    SystemMessage(content="あなたは日本語で丁寧に回答するAIアシスタントです。"),
    HumanMessage(content="LangChainでRAGシステムを構築する際のベストプラクティスを教えてください。")
]

response = llm.invoke(messages)
print(response.content)
```

LangChainとGeminiを組み合わせたRAGシステムのさらに詳しい実装については、[Gemini API × LangChain インテグレーション完全ガイド](/articles/gemini-dev/gemini-langchain-integration) もご覧ください。

## ネイティブGemini SDKとの違い

OpenAI互換エンドポイントは便利ですが、ネイティブの `google-genai` SDKと比べていくつかの制限があります。

### サポート状況の違い

- **コンテキストキャッシング**: OpenAI互換エンドポイント経由では一部機能が制限される場合がある
- **マルチモーダル入力**: 画像や動画の添付はサポートされているが、APIのバージョンによって挙動が異なることがある
- **Grounding with Google Search**: ネイティブSDK経由でのみ完全サポート
- **Function Calling（Tool Use）**: 基本的な形式はサポートされているが、Gemini固有の拡張機能は使えない場合がある

Geminiの全機能を最大限に活用したい場合は、ネイティブSDKへの移行も検討してみてください。

### ネイティブSDKへの移行例（比較）

```python
# OpenAI互換エンドポイント（移行前）
from openai import OpenAI
client = OpenAI(api_key="...", base_url="https://generativelanguage.googleapis.com/v1beta/openai/")

# ネイティブGemini SDK（移行後）
from google import genai
client = genai.Client(api_key="YOUR_GEMINI_API_KEY")
response = client.models.generate_content(
    model="gemini-2.0-flash",
    contents="こんにちは！"
)
```

## よくあるエラーと対処法

OpenAI互換エンドポイントを使う際に遭遇しやすいエラーとその解決策をまとめましました。

### 401 Unauthorized

APIキーが誤っているか、環境変数が正しく設定されていない場合に発生します。環境変数名が `GEMINI_API_KEY` になっているか、コード内で正しく参照しているか確認してください。

### 404 Not Found（モデル名の間違い）

`gpt-4o` など、OpenAIのモデル名をそのまま使うと404エラーになります。`gemini-2.0-flash` や `gemini-2.5-pro` など、Geminiのモデル名に変更してください。

### 429 Too Many Requests

無料プランではレート制限があります。リトライロジックを実装するか、[Google AI Studio](https://aistudio.google.com/) でAPI使用量を確認してプランのアップグレードを検討しましょう。

### base_url のスラッシュに注意

`base_url` の末尾にスラッシュ `/` が必要です。

```python
# ❌ 間違い（スラッシュなし）
base_url="https://generativelanguage.googleapis.com/v1beta/openai"

# ✅ 正しい（末尾にスラッシュあり）
base_url="https://generativelanguage.googleapis.com/v1beta/openai/"
```

## FAQ

**Q1. 既存のOpenAI APIコードを変更せずにGeminiに移行できますか？**

ベースURLとAPIキーの2か所を変更するだけで、ほとんどの基本機能は動作します。ただし、GPT固有の機能（`gpt-4-vision-preview` 形式のモデル名など）はGeminiに対応するモデル名へ変更が必要です。

**Q2. OpenAI互換エンドポイントは有料ですか？**

Gemini APIの通常の料金体系が適用されます。無料枠内であれば無料で利用できます。最新の料金は [Google AI Studio](https://aistudio.google.com/) の料金ページでご確認ください。

**Q3. マルチモーダル（画像入力）はOpenAI互換エンドポイントで使えますか？**

画像URLを `content` に含める形式であれば動作します。ただし、一部のマルチモーダル機能はネイティブSDKの方がより安定しているため、画像解析や動画処理を本格的に行う場合はネイティブSDKへの移行を推奨します。

**Q4. LangChainやLlamaIndexでも使えますか？**

はい、どちらもOpenAI互換インターフェースをサポートしているため、ベースURLの変更だけでGeminiと連携できます。

## まとめ

Gemini APIのOpenAI互換エンドポイントを使えば、**既存のOpenAI SDKコードを最小限の変更でGeminiに接続**できます。移行のポイントは次の2点だけです。

1. `base_url` を `https://generativelanguage.googleapis.com/v1beta/openai/` に変更する
2. `api_key` をGemini APIキーに変更し、モデル名をGeminiのものに変更する

LangChainなどのフレームワークを使っている場合も同様のアプローチで対応できます。まずはOpenAI互換エンドポイントで移行し、Gemini固有の機能（マルチモーダル・Grounding・コンテキストキャッシング）を活用したくなったタイミングでネイティブSDKへ移行するのが、スムーズな移行戦略としておすすめです。
