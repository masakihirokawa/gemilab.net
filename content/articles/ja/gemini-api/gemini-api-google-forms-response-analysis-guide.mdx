Google フォームはアンケートや申し込みフォームとして広く使われていますが、集まった回答を一件ずつ読んで分析するのは時間がかかります。Gemini API を活用すると、フォームの回答データをまとめて読み込み、AI が感情分析・テーマ分類・改善提案まで自動で行う仕組みを簡単に構築できます。

この記事では、Python を使って Google フォームの回答データを取得し、Gemini API で自動分析してレポートを生成する方法をステップバイステップで解説します。プログラミング初心者の方でも読み進められるよう、コードには丁寧なコメントを付けています。

## Google フォーム × Gemini API で何ができるのか

Google フォームで収集した回答を Gemini API に送ると、次のような処理が自動化できます。

- **自由記述の感情分析**: 「満足・普通・不満」などの傾向を自動で集計
- **テーマ別クラスタリング**: 似た意見や要望をグループ化
- **改善提案の抽出**: 批判的なコメントから具体的な課題を抽出
- **サマリーレポート自動生成**: 回答全体を読み解いた要約文を生成

アンケートの規模が10件でも1,000件でも、Gemini API を使えば数秒で結果が得られます。

## Google フォーム回答データを取得する

まず、スプレッドシートから回答データを読み込む関数を作ります。

```python
import gspread
from google.oauth2.service_account import Credentials

def get_form_responses(spreadsheet_url: str, sheet_name: str = "フォームの回答 1") -> list[dict]:
    """
    Google フォームに連携されたスプレッドシートから回答データを取得する。

    Args:
        spreadsheet_url: スプレッドシートのURL
        sheet_name: シート名（デフォルトはGoogleフォームの自動生成名）

    Returns:
        回答データのリスト（各行が辞書形式）
    """
    # サービスアカウントの認証設定
    scopes = [
        "https://www.googleapis.com/auth/spreadsheets.readonly",
        "https://www.googleapis.com/auth/drive.readonly",
    ]
    creds = Credentials.from_service_account_file(
        "service_account.json",  # ダウンロードしたJSONファイルのパス
        scopes=scopes,
    )

    # スプレッドシートを開いてデータを取得
    client = gspread.authorize(creds)
    spreadsheet = client.open_by_url(spreadsheet_url)
    worksheet = spreadsheet.worksheet(sheet_name)

    # 全レコードを辞書形式で返す（1行目がヘッダー、2行目以降が回答）
    records = worksheet.get_all_records()
    print(f"✅ {len(records)} 件の回答を取得しました")
    return records
```

## Gemini API でフォーム回答を一括分析する

回答データが取得できたら、Gemini API に送って分析します。大量の回答もまとめてプロンプトに含められる点が Gemini の強みです。

```python
from google import genai

def analyze_form_responses(responses: list[dict], gemini_api_key: str) -> str:
    """
    Gemini API を使ってフォーム回答データを一括分析する。

    Args:
        responses: get_form_responses() で取得した回答データ
        gemini_api_key: Gemini API キー

    Returns:
        Gemini が生成した分析レポート（文字列）
    """
    # Gemini クライアントを初期化
    client = genai.Client(api_key=gemini_api_key)

    # 回答データをテキスト形式に整形する
    response_texts = []
    for i, row in enumerate(responses, start=1):
        # タイムスタンプを除いた回答項目だけを取得
        items = {k: v for k, v in row.items() if k != "タイムスタンプ"}
        text = f"【回答 {i}】\n" + "\n".join(f"{k}: {v}" for k, v in items.items())
        response_texts.append(text)

    all_responses_text = "\n\n".join(response_texts)

    # Gemini に渡すプロンプト（分析の観点を詳しく指示する）
    prompt = f"""
以下は、サービスアンケートの回答データです。全体を詳細に分析し、以下の観点でレポートを作成してください。

1. **全体サマリー**: 回答全体から見える傾向を3〜5文で要約してください。
2. **感情分析**: 肯定的な意見・否定的な意見・中立的な意見の件数と割合を推定してください。
3. **頻出テーマ**: 回答に繰り返し登場するキーワードやテーマを5つ以内でまとめてください。
4. **改善提案**: 批判的・改善要求の意見から、具体的なアクションアイテムを3つ挙げてください。
5. **注目すべき回答**: 特に参考になる（良い意見・悪い意見それぞれ1件ずつ）回答を引用してください。

---
{all_responses_text}
---
    """

    # Gemini 2.5 Flash（軽量・高速モデル）で分析を実行
    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=prompt,
    )

    return response.text
```

## レポートをファイルに保存する

生成したレポートを Markdown ファイルとして保存すれば、後から参照しやすくなります。

```python
from datetime import datetime

def save_report(report: str, form_name: str = "アンケート") -> str:
    """
    分析レポートをMarkdownファイルとして保存する。

    Returns:
        保存したファイルのパス
    """
    # ファイル名にタイムスタンプを付けて一意にする
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    filename = f"report_{form_name}_{timestamp}.md"

    with open(filename, "w", encoding="utf-8") as f:
        f.write(f"# {form_name} 分析レポート\n")
        f.write(f"**生成日時**: {datetime.now().strftime('%Y年%m月%d日 %H:%M')}\n\n")
        f.write(report)

    print(f"✅ レポートを保存しました: {filename}")
    return filename
```

## 完成スクリプト：一連の処理をまとめる

ここまでの関数を組み合わせて、「取得 → 分析 → 保存」を一括実行するスクリプトを作ります。

```python
import os
import gspread
import google.genai as genai
from google.oauth2.service_account import Credentials
from datetime import datetime

# ─────── 設定（ここを書き換えてください）───────
SPREADSHEET_URL = "https://docs.google.com/spreadsheets/d/YOUR_SPREADSHEET_ID/edit"
SHEET_NAME = "フォームの回答 1"  # シート名を確認して変更
FORM_NAME = "顧客満足度アンケート"
# ───────────────────────────────────────────

def main():
    # 1. APIキーの読み込み
    api_key = os.environ.get("GEMINI_API_KEY")
    if not api_key:
        raise ValueError("環境変数 GEMINI_API_KEY が設定されていません")

    # 2. フォーム回答の取得
    print("📋 Google フォームの回答を取得中...")
    scopes = [
        "https://www.googleapis.com/auth/spreadsheets.readonly",
        "https://www.googleapis.com/auth/drive.readonly",
    ]
    creds = Credentials.from_service_account_file("service_account.json", scopes=scopes)
    gc = gspread.authorize(creds)
    ws = gc.open_by_url(SPREADSHEET_URL).worksheet(SHEET_NAME)
    responses = ws.get_all_records()
    print(f"  → {len(responses)} 件取得")

    if len(responses) == 0:
        print("⚠️ 回答データが空です。スプレッドシートを確認してください。")
        return

    # 3. Gemini API で分析
    print("🤖 Gemini API で分析中...")
    client = genai.Client(api_key=api_key)

    response_texts = "\n\n".join(
        f"【回答 {i+1}】\n" + "\n".join(
            f"{k}: {v}" for k, v in row.items() if k != "タイムスタンプ"
        )
        for i, row in enumerate(responses)
    )

    prompt = f"""
以下のアンケート回答を分析し、日本語でレポートを作成してください。

1. **全体サマリー**（3〜5文）
2. **感情分析**（肯定/否定/中立の割合）
3. **頻出テーマ**（5つ以内）
4. **改善提案**（具体的なアクション3つ）
5. **注目すべき回答**（良い意見・改善意見 各1件）

---
{response_texts}
    """

    result = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=prompt,
    )

    # 4. レポートの保存
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    filename = f"report_{timestamp}.md"
    with open(filename, "w", encoding="utf-8") as f:
        f.write(f"# {FORM_NAME} 分析レポート\n")
        f.write(f"**生成日時**: {datetime.now().strftime('%Y年%m月%d日 %H:%M')}\n\n")
        f.write(result.text)

    print(f"✅ レポートを保存しました: {filename}")

if __name__ == "__main__":
    main()
```

## 応用：自動メール通知と定期実行

作成したスクリプトを定期実行し、レポートをメールで受け取る仕組みに拡張できます。Google Workspace との連携方法については [Google Apps Script × Gemini AI 自動化ガイド](/articles/gemini-dev/gemini-google-apps-script-automation) も参考にしてください。

```python
import smtplib
from email.mime.text import MIMEText
from email.mime.multipart import MIMEMultipart

def send_report_email(report: str, to_email: str, smtp_password: str):
    """
    生成したレポートをメールで送信する（Gmail使用例）。
    """
    msg = MIMEMultipart()
    msg["Subject"] = f"📊 アンケート分析レポート {datetime.now().strftime('%Y/%m/%d')}"
    msg["From"] = "YOUR_GMAIL@gmail.com"
    msg["To"] = to_email

    body = MIMEText(report, "plain", "utf-8")
    msg.attach(body)

    with smtplib.SMTP_SSL("smtp.gmail.com", 465) as server:
        server.login("YOUR_GMAIL@gmail.com", smtp_password)
        server.send_message(msg)

    print(f"✅ レポートを {to_email} に送信しました")
```

定期実行には cron（Linux/Mac）や Windows タスクスケジューラーを活用すると、毎週月曜の朝にレポートが届く仕組みを実現できます。

より大量の回答データを扱ったり、分析の精度を高めたい場合は、Gemini API の非同期処理や構造化出力（Structured Output）を組み合わせると効果的です。詳しくは [Gemini API ドキュメント要約自動化システム構築ガイド](/articles/gemini-api/gemini-api-document-summarization-automation) もあわせてご覧ください。

## よくあるエラーと対処法

### gspread.exceptions.SpreadsheetNotFound

**原因**: スプレッドシートのURLが間違っているか、サービスアカウントに共有されていない

**対処**: スプレッドシートを開き、「共有」ボタンからサービスアカウントのメールアドレス（`xxxx@your-project.iam.gserviceaccount.com`）を「編集者」または「閲覧者」として追加する

### google.auth.exceptions.DefaultCredentialsError

**原因**: `service_account.json` が見つからない、またはパスが間違っている

**対処**: `service_account.json` をスクリプトと同じディレクトリに置くか、`Credentials.from_service_account_file()` に絶対パスを指定する

### Gemini API のタイムアウト（回答が多い場合）

**原因**: 回答数が多すぎてプロンプトが長くなりすぎている

**対処**: 回答を100件ごとに分割して処理し、複数の部分レポートを生成した後まとめる方法を取る

```python
# 100件ずつ分割して処理する例
BATCH_SIZE = 100
partial_reports = []

for i in range(0, len(responses), BATCH_SIZE):
    batch = responses[i:i + BATCH_SIZE]
    partial = analyze_form_responses(batch, api_key)
    partial_reports.append(partial)

# 部分レポートを統合
final_report = "\n\n---\n\n".join(partial_reports)
```

## FAQ

**Q: 無料の Gemini API で何件の回答まで処理できますか？**

A: Gemini 2.5 Flash の無料枠（Google AI Studio）では、1分あたり15リクエスト・1日1,500リクエストまで利用できます（2026年4月時点）。100件程度のアンケートなら1リクエストで処理できるため、無料枠で十分な場合がほとんどです。回答数が多い場合は、バッチ処理を使って複数リクエストに分割してください。

**Q: 日本語の自由記述が多いアンケートでも正確に分析できますか？**

A: はい。Gemini は日本語の自然言語処理が得意で、敬語・口語・方言混じりのテキストも含めて高精度に分析します。ただし、専門用語が多い業界（医療・法律など）では、プロンプトに「この回答は医療アンケートです。専門用語を正確に解釈してください」のような指示を加えると精度が上がります。

**Q: Google フォーム以外のアンケートツール（SurveyMonkey 等）にも使えますか？**

A: はい。回答データを CSV に書き出し、Python の `csv` モジュールで読み込めば、どのアンケートツールの回答でも同様に分析できます。CSV ファイルの場合は `gspread` は不要で、`import csv` と `csv.DictReader` を使って読み込んでください。

## まとめ

この記事では、Gemini API を使って Google フォームの回答を自動分析・レポート化する方法を解説しました。主な手順は以下の通りです。

- `gspread` でフォームに連携したスプレッドシートから回答を取得
- Gemini API（`gemini-2.5-flash`）に回答をまとめて送り、感情分析・テーマ抽出・改善提案を生成

この仕組みを応用すると、採用アンケート・社内満足度調査・イベント後のフィードバック収集など、あらゆるアンケートの分析を自動化できます。
