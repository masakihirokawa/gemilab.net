## はじめに — Gemini × Notion が生産性を変える理由

Notion は世界中のナレッジワーカーに愛用されるドキュメント・データベースツールです。そこに Google の最新 AI である **Gemini API** を組み合わせることで、「情報を蓄積する場所」が「AIが自律的に動くワークスペース」へと進化します。

この記事では、以下のような実践的なユースケースを Python のコード例付きで解説します。

- Notion データベースに新しいページを自動追加する
- Gemini API でウェブ記事を要約して Notion に保存する
- タスクの優先度を AI が判定して自動タグ付けする
- Notion のコンテンツを Gemini で分析・レポート生成する

API の基本的な使い方は [Gemini API クイックスタート](/articles/gemini-api/gemini-api-quickstart) で確認できます。Python の自動化レシピをさらに学びたい方は [Gemini API Python 自動化レシピ集](/articles/gemini-api/gemini-api-python-automation-recipes) もあわせてご覧ください。

## Notion API の基本操作

### Notion クライアントの初期化とデータベース取得

まず Notion API の基本操作を確認しましょう。

```python
from notion_client import Client

# Notion クライアントを初期化
notion = Client(auth=NOTION_TOKEN)

def get_database_pages(database_id: str) -> list:
    """データベースの全ページを取得する"""
    results = []
    has_more = True
    start_cursor = None

    while has_more:
        response = notion.databases.query(
            database_id=database_id,
            start_cursor=start_cursor,
        )
        results.extend(response["results"])
        has_more = response["has_more"]
        start_cursor = response.get("next_cursor")

    return results

# 使用例
pages = get_database_pages(NOTION_DATABASE_ID)
print(f"取得したページ数: {len(pages)}")
# 期待する出力: 取得したページ数: 42
```

### 新規ページの追加

```python
def create_notion_page(
    database_id: str,
    title: str,
    content: str,
    tags: list[str] = None
) -> dict:
    """Notion データベースに新規ページを追加する"""
    properties = {
        "Name": {
            "title": [{"text": {"content": title}}]
        }
    }

    # タグが指定されている場合は追加
    if tags:
        properties["Tags"] = {
            "multi_select": [{"name": tag} for tag in tags]
        }

    # ページ本文（ブロック）
    children = [
        {
            "object": "block",
            "type": "paragraph",
            "paragraph": {
                "rich_text": [{"type": "text", "text": {"content": content}}]
            }
        }
    ]

    response = notion.pages.create(
        parent={"database_id": database_id},
        properties=properties,
        children=children
    )
    return response

# 使用例
page = create_notion_page(
    database_id=NOTION_DATABASE_ID,
    title="Gemini API 活用メモ",
    content="Gemini 3.1 Pro を使った新しいワークフローについてのメモ",
    tags=["AI", "メモ"]
)
print(f"作成されたページID: {page['id']}")
```

## Gemini API × Notion の実践的な活用例

### 活用例1: ウェブ記事の要約を Notion に自動保存

URL を渡すと Gemini が内容を要約し、Notion のデータベースに保存するスクリプトです。

```python
import google.generativeai as genai
from notion_client import Client
import requests
from bs4 import BeautifulSoup

genai.configure(api_key=GEMINI_API_KEY)
model = genai.GenerativeModel("gemini-2.5-flash-preview-04-17")
notion = Client(auth=NOTION_TOKEN)

def fetch_article_text(url: str) -> str:
    """URLから記事テキストを取得する"""
    headers = {"User-Agent": "Mozilla/5.0"}
    response = requests.get(url, headers=headers, timeout=10)
    soup = BeautifulSoup(response.text, "html.parser")
    # 主要コンテンツを抽出（article タグ優先）
    article = soup.find("article") or soup.find("main") or soup.body
    return article.get_text(separator="\n", strip=True)[:5000]  # 5000文字に制限

def summarize_and_save(url: str, category: str = "未分類") -> dict:
    """
    記事を取得 → Gemini で要約 → Notion に保存する一連の処理
    """
    # 1. 記事テキストを取得
    article_text = fetch_article_text(url)

    # 2. Gemini API で要約生成
    prompt = f"""以下の記事を日本語で300文字以内に要約してください。
要点を箇条書きで3〜5点にまとめ、最後に「ひとことコメント」を添えてください。

【記事内容】
{article_text}
"""
    response = model.generate_content(prompt)
    summary = response.text

    # 3. Notion に保存
    page = create_notion_page(
        database_id=NOTION_DATABASE_ID,
        title=f"[要約] {url[:50]}...",
        content=f"URL: {url}\n\n{summary}",
        tags=[category, "AI要約"]
    )

    print(f"✅ Notion に保存完了: {page['id']}")
    return {"page_id": page["id"], "summary": summary}

# 使用例
result = summarize_and_save(
    url="https://ai.google.dev/gemini-api/docs",
    category="AI技術"
)
# 期待する出力: ✅ Notion に保存完了: abc123...
```

### 活用例2: タスクの優先度を Gemini が自動判定

Notion のタスクデータベースを読み込み、Gemini が各タスクの優先度を判定・更新します。

```python
import json

def analyze_task_priority(task_title: str, task_description: str) -> dict:
    """
    Gemini API でタスクの優先度・カテゴリ・推定工数を判定する
    """
    prompt = f"""以下のタスクを分析し、JSON形式で返答してください。

タスク名: {task_title}
説明: {task_description}

返答形式（必ずこのJSON形式で）:
{{
  "priority": "high" | "medium" | "low",
  "category": "開発" | "マーケティング" | "運用" | "調査" | "その他",
  "estimated_hours": 数値（例: 2.5）,
  "reason": "判定理由を1文で"
}}
"""

    # Gemini の構造化出力機能を活用
    response = model.generate_content(
        prompt,
        generation_config={"response_mime_type": "application/json"}
    )

    return json.loads(response.text)

def auto_prioritize_tasks(database_id: str) -> None:
    """
    Notion データベースの全タスクを取得し、Gemini で優先度を自動設定する
    """
    pages = get_database_pages(database_id)
    prioritized = 0

    for page in pages:
        # タイトルと説明を取得
        title_blocks = page["properties"].get("Name", {}).get("title", [])
        title = title_blocks[0]["text"]["content"] if title_blocks else "無題"

        desc_blocks = page["properties"].get("Description", {}).get("rich_text", [])
        description = desc_blocks[0]["text"]["content"] if desc_blocks else ""

        # 優先度が未設定のタスクのみ処理
        current_priority = page["properties"].get("Priority", {}).get("select")
        if current_priority:
            continue

        # Gemini で優先度判定
        analysis = analyze_task_priority(title, description)

        # Notion ページを更新
        notion.pages.update(
            page_id=page["id"],
            properties={
                "Priority": {
                    "select": {"name": analysis["priority"]}
                },
                "Category": {
                    "select": {"name": analysis["category"]}
                }
            }
        )
        prioritized += 1
        print(f"✅ {title}: {analysis['priority']} ({analysis['reason']})")

    print(f"\n🎉 {prioritized} 件のタスクを自動優先度付け完了")

# 使用例
auto_prioritize_tasks(NOTION_DATABASE_ID)
# 期待する出力例:
# ✅ LP デザイン修正: high (ユーザー体験に直結するため)
# ✅ 競合分析レポート: medium (戦略立案に必要だが期限に余裕がある)
# 🎉 12 件のタスクを自動優先度付け完了
```

### 活用例3: 定期レポートの自動生成

週次のプロジェクト進捗を Notion から取得し、Gemini が分析レポートを生成します。

```python
from datetime import datetime, timedelta

def generate_weekly_report(database_id: str) -> str:
    """
    過去1週間のタスク完了状況を取得し、Gemini で進捗レポートを生成する
    """
    # 1週間前の日付を取得
    one_week_ago = (datetime.now() - timedelta(days=7)).isoformat()

    # 完了タスクを取得
    response = notion.databases.query(
        database_id=database_id,
        filter={
            "and": [
                {
                    "property": "Status",
                    "select": {"equals": "Done"}
                },
                {
                    "property": "Completed At",
                    "date": {"after": one_week_ago}
                }
            ]
        }
    )

    completed_tasks = []
    for page in response["results"]:
        title_blocks = page["properties"].get("Name", {}).get("title", [])
        title = title_blocks[0]["text"]["content"] if title_blocks else "無題"
        completed_tasks.append(title)

    if not completed_tasks:
        return "今週の完了タスクはありません。"

    # Gemini でレポート生成
    task_list = "\n".join([f"- {t}" for t in completed_tasks])
    prompt = f"""以下は今週完了したタスクの一覧です。
プロジェクトマネージャー視点で週次レポートを作成してください。
レポートには「今週の成果」「課題・気づき」「来週への提言」の3セクションを含めてください。

【完了タスク】
{task_list}
"""
    response = model.generate_content(prompt)
    report_text = response.text

    # レポートを Notion に保存
    today = datetime.now().strftime("%Y-%m-%d")
    create_notion_page(
        database_id=database_id,
        title=f"週次レポート {today}",
        content=report_text,
        tags=["レポート", "週次"]
    )

    return report_text

# 使用例
report = generate_weekly_report(NOTION_DATABASE_ID)
print(report)
```

### エラー2: Gemini API レート制限（429 Too Many Requests）

```python
import time

def generate_with_retry(prompt: str, max_retries: int = 3) -> str:
    """レート制限対策のリトライロジック付き生成"""
    for attempt in range(max_retries):
        try:
            response = model.generate_content(prompt)
            return response.text
        except Exception as e:
            if "429" in str(e) and attempt < max_retries - 1:
                wait_time = 2 ** attempt  # 1秒、2秒、4秒と指数バックオフ
                print(f"⏳ レート制限: {wait_time}秒後にリトライ ({attempt + 1}/{max_retries})")
                time.sleep(wait_time)
            else:
                raise
    return ""
```

### エラー3: Notion ページのブロック数制限

Notion API の1リクエストあたりのブロック数は最大100に制限されています。長いコンテンツを保存する際は分割が必要です。

```python
def create_long_content_page(database_id: str, title: str, content: str) -> dict:
    """長いコンテンツを複数ブロックに分割して保存する"""
    # 2000文字ごとに分割（Notion のテキストブロック制限対策）
    chunks = [content[i:i+2000] for i in range(0, len(content), 2000)]

    children = [
        {
            "object": "block",
            "type": "paragraph",
            "paragraph": {
                "rich_text": [{"type": "text", "text": {"content": chunk}}]
            }
        }
        for chunk in chunks
    ]

    return notion.pages.create(
        parent={"database_id": database_id},
        properties={"Name": {"title": [{"text": {"content": title}}]}},
        children=children[:100]  # 最大100ブロック
    )
```

## FAQ

**Q1. Notion の無料プランでも Gemini 連携はできますか？**

はい、Notion の無料プランでも Notion API（インテグレーション機能）は利用できます。Gemini API も無料枠（Flash モデルで1分間60リクエスト）がありますので、個人利用や学習目的であれば費用ゼロで始められます。

**Q2. Notion のページ本文（ブロック）を読み取るにはどうすればいいですか？**

`notion.blocks.children.list(block_id=page_id)` でページ内のブロック一覧を取得できます。各ブロックの `type` フィールドで種類を判別し、`paragraph`・`heading_2` などのテキストブロックから `rich_text` を抽出します。深くネストしたブロックは再帰的に取得が必要です。

**Q3. Notion データベースの更新を検知してリアルタイムに処理することはできますか？**

現時点で Notion API にはWebhookがありません（2026年4月時点）。定期実行（cron）で変更を検出する方法が一般的です。GitHub Actions や Cloud Scheduler + Cloud Run を使って5〜15分おきにポーリングする設計が実用的です。定期実行の詳しい実装は [Gemini API GitHub Actions CI/CDガイド](/articles/gemini-dev/gemini-api-github-actions-ai-code-quality-pipeline) を参考にしてください。
