## はじめに — なぜ Gemini API × Qdrant なのか

RAG（Retrieval-Augmented Generation）システムの精度を左右する最大の要因は、「適切なドキュメントを適切なタイミングで取得できるか」にあります。従来の単純なセマンティック検索（密ベクトルのみ）では、キーワードの完全一致が含まれる重要なドキュメントを見落とすことがありましました。

そこで注目されているのが**ハイブリッド検索**です。密ベクトル（Dense Vector）による意味的な類似性検索と、疎ベクトル（Sparse Vector）によるキーワードマッチングを組み合わせることで、両者の長所を活かした高精度な検索が実現します。

**Qdrant**はRustで実装された高性能ベクターデータベースで、ハイブリッド検索をネイティブにサポートする数少ないベクターDBの一つです。**Gemini Embedding API**（`text-embedding-004`モデル）は768次元の高品質な埋め込みベクトルを生成し、Qdrantとの組み合わせで優れたRAGシステムを構築できます。

Gemini APIとQdrantを使ったハイブリッドRAGシステムをゼロから本番環境まで構築する完全な実装手順を順を追って整理していきます。

## Qdrant の基本概念とセットアップ

### アーキテクチャの全体像

Qdrantは以下のコアコンセプトで構成されています。

- **コレクション（Collection）**: ベクトルデータの論理的なグループ（RDBのテーブルに相当）
- **ポイント（Point）**: コレクションの基本単位。ID・ベクトル・ペイロードで構成
- **ペイロード（Payload）**: ポイントに付随するJSON形式のメタデータ
- **セグメント（Segment）**: ディスク上のデータ管理単位（自動最適化される）
- **シャード（Shard）**: 水平分散のための分割単位

## Gemini Embedding API でベクトルを生成する

### 埋め込みモデルの選択

Gemini APIが提供する埋め込みモデルには用途別に複数の選択肢があります。

- **`text-embedding-004`**: 汎用テキスト埋め込み（768次元）。RAGに最適
- **`gemini-embedding-exp-03-07`**: 実験的な最新モデル（最高精度）
- **`embedding-001`**: レガシーモデル（768次元、後方互換）

本ガイドでは安定性の高い`text-embedding-004`を使用します。

### 埋め込みクラスの実装

```python
import os
import time
from typing import Optional
import google.generativeai as genai
from dotenv import load_dotenv

load_dotenv()
genai.configure(api_key=os.getenv("GEMINI_API_KEY"))

class GeminiEmbedder:
    """Gemini Embedding API のラッパークラス"""

    def __init__(self, model: str = "text-embedding-004"):
        self.model = model
        self.dimension = 768  # text-embedding-004 の出力次元数

    def embed_text(
        self,
        text: str,
        task_type: str = "RETRIEVAL_DOCUMENT"
    ) -> list[float]:
        """
        テキストを埋め込みベクトルに変換する

        Args:
            text: 埋め込むテキスト
            task_type: タスクタイプ
                - RETRIEVAL_DOCUMENT: ドキュメントのインデックス時
                - RETRIEVAL_QUERY: 検索クエリ時
                - SEMANTIC_SIMILARITY: 類似度計算時
                - CLASSIFICATION: 分類タスク時

        Returns:
            768次元の浮動小数点数リスト
        """
        result = genai.embed_content(
            model=self.model,
            content=text,
            task_type=task_type
        )
        return result["embedding"]

    def embed_batch(
        self,
        texts: list[str],
        task_type: str = "RETRIEVAL_DOCUMENT",
        batch_size: int = 100,
        sleep_seconds: float = 0.5
    ) -> list[list[float]]:
        """
        テキストのバッチを埋め込みベクトルに変換する
        APIレート制限を考慮したバッチ処理

        Args:
            texts: テキストのリスト
            batch_size: 1バッチあたりのサイズ（最大100）
            sleep_seconds: バッチ間のスリープ時間

        Returns:
            埋め込みベクトルのリスト
        """
        embeddings = []
        for i in range(0, len(texts), batch_size):
            batch = texts[i:i + batch_size]
            result = genai.embed_content(
                model=self.model,
                content=batch,
                task_type=task_type
            )
            embeddings.extend(result["embedding"])
            if i + batch_size < len(texts):
                time.sleep(sleep_seconds)  # レート制限対策
        return embeddings

# 動作確認
embedder = GeminiEmbedder()
vec = embedder.embed_text("Gemini APIは強力なAIモデルです", task_type="RETRIEVAL_DOCUMENT")
print(f"ベクトル次元数: {len(vec)}")
print(f"最初の5次元: {vec[:5]}")
# 期待する出力:
# ベクトル次元数: 768
# 最初の5次元: [-0.023..., 0.041..., ...]
```

## コレクション設計とインデックス最適化

### ハイブリッド検索のための設計

ハイブリッド検索では、密ベクトルと疎ベクトルの**2つのベクトル空間**をコレクションに定義します。

```python
from qdrant_client import QdrantClient
from qdrant_client.models import (
    Distance,
    VectorParams,
    SparseVectorParams,
    SparseIndexParams,
    HnswConfigDiff,
    OptimizersConfigDiff,
    ScalarQuantizationConfig,
    ScalarType,
    QuantizationConfig,
)

def create_hybrid_collection(
    client: QdrantClient,
    collection_name: str,
    dense_dimension: int = 768,
):
    """
    ハイブリッド検索対応のコレクションを作成する

    Args:
        collection_name: コレクション名
        dense_dimension: 密ベクトルの次元数（text-embedding-004は768）
    """
    client.create_collection(
        collection_name=collection_name,
        vectors_config={
            # 密ベクトル: セマンティック検索用（Gemini埋め込み）
            "dense": VectorParams(
                size=dense_dimension,
                distance=Distance.COSINE,  # コサイン類似度
                hnsw_config=HnswConfigDiff(
                    m=16,            # グラフの連結数（精度と速度のトレードオフ）
                    ef_construct=100, # インデックス構築時の探索幅
                ),
                quantization_config=QuantizationConfig(
                    scalar=ScalarQuantizationConfig(
                        type=ScalarType.INT8,  # 量子化でメモリ削減（精度は軽微に低下）
                        quantile=0.99,
                        always_ram=True,  # 量子化ベクトルをRAMに常駐させる
                    )
                ),
            )
        },
        # 疎ベクトル: キーワードマッチング用（BM25/SPLADE等）
        sparse_vectors_config={
            "sparse": SparseVectorParams(
                index=SparseIndexParams(
                    on_disk=False,  # 高速アクセスのためRAMに保持
                )
            )
        },
        # 最適化設定
        optimizers_config=OptimizersConfigDiff(
            indexing_threshold=20000,  # インデックスを構築するまでのポイント数
            memmap_threshold=50000,    # メモリマップに切り替えるポイント数
        ),
    )
    print(f"✅ コレクション '{collection_name}' を作成しました")
    print(f"   密ベクトル: {dense_dimension}次元（COSINE距離、INT8量子化）")
    print(f"   疎ベクトル: 動的次元（キーワードマッチング）")

# コレクション作成
client = QdrantClient(url="http://localhost:6333")
create_hybrid_collection(client, "knowledge_base")
```

## ドキュメントのインデックスとハイブリッド検索の実装

### 疎ベクトルの生成（BM25）

疎ベクトルにはBM25スコアを使用します。`qdrant_client`に含まれるBM25エンコーダーを活用します。

```python
from qdrant_client.models import PointStruct, SparseVector
from qdrant_client.qdrant_fastembed import QdrantFastEmbedClient
import uuid

# BM25エンコーダーの初期化（初回はモデルをダウンロード）
# pip install fastembed で追加インストールが必要
from fastembed import SparseTextEmbedding

sparse_encoder = SparseTextEmbedding(model_name="Qdrant/bm25")

def encode_sparse(text: str) -> SparseVector:
    """テキストをBM25疎ベクトルに変換する"""
    result = list(sparse_encoder.embed([text]))[0]
    return SparseVector(
        indices=result.indices.tolist(),
        values=result.values.tolist(),
    )

class DocumentIndexer:
    """Qdrantへのドキュメントインデックス管理クラス"""

    def __init__(
        self,
        qdrant_client: QdrantClient,
        embedder: GeminiEmbedder,
        collection_name: str,
    ):
        self.client = qdrant_client
        self.embedder = embedder
        self.collection_name = collection_name

    def index_documents(
        self,
        documents: list[dict],
        batch_size: int = 50,
    ) -> int:
        """
        ドキュメントをQdrantにインデックスする

        Args:
            documents: インデックスするドキュメントのリスト
                各ドキュメントは {"text": str, "title": str, "category": str, ...} 形式
            batch_size: 1バッチあたりのドキュメント数

        Returns:
            インデックスされたドキュメント数
        """
        total_indexed = 0

        for i in range(0, len(documents), batch_size):
            batch = documents[i:i + batch_size]
            texts = [doc["text"] for doc in batch]

            # 密ベクトルのバッチ生成
            dense_embeddings = self.embedder.embed_batch(
                texts, task_type="RETRIEVAL_DOCUMENT"
            )

            # ポイントリストの構築
            points = []
            for j, (doc, dense_vec) in enumerate(zip(batch, dense_embeddings)):
                sparse_vec = encode_sparse(doc["text"])
                point = PointStruct(
                    id=str(uuid.uuid4()),
                    vector={
                        "dense": dense_vec,
                        "sparse": sparse_vec,
                    },
                    payload={
                        "text": doc["text"],
                        "title": doc.get("title", ""),
                        "category": doc.get("category", "general"),
                        "created_at": doc.get("created_at", 0),
                        "source_url": doc.get("source_url", ""),
                    }
                )
                points.append(point)

            # バッチアップサート
            self.client.upsert(
                collection_name=self.collection_name,
                points=points,
                wait=True,  # 完了を待機（本番ではFalseで非同期にも可）
            )
            total_indexed += len(batch)
            print(f"  インデックス進捗: {total_indexed}/{len(documents)}")

        return total_indexed

# 使用例
documents = [
    {
        "text": "Gemini 2.5 ProはGoogleが開発した最先端のマルチモーダルAIモデルです。100万トークンのコンテキストウィンドウをサポートし、複雑な推論タスクに優れています。",
        "title": "Gemini 2.5 Pro の概要",
        "category": "gemini",
        "created_at": 1743000000,
        "source_url": "https://blog.google/technology/ai/gemini-2-5-pro",
    },
    {
        "text": "Qdrantはベクターデータベースの中でも特にパフォーマンスが高く、Rustで実装されています。ハイブリッド検索をネイティブサポートしており、RAGシステムに最適です。",
        "title": "Qdrant の特徴",
        "category": "database",
        "created_at": 1743000001,
        "source_url": "https://qdrant.tech/documentation",
    },
]

indexer = DocumentIndexer(client, embedder, "knowledge_base")
count = indexer.index_documents(documents)
print(f"✅ {count}件のドキュメントをインデックスしました")
```

## ハイブリッド検索の実装と RRF スコアリング

### Reciprocal Rank Fusion（RRF）による結果の統合

ハイブリッド検索では、密ベクトル検索と疎ベクトル検索それぞれの結果を**RRF（Reciprocal Rank Fusion）**で統合します。RRFは各検索結果のランキングを利用してスコアを計算し、両者のバランスを取ります。

```python
from qdrant_client.models import (
    Query,
    FusionQuery,
    Fusion,
    Prefetch,
    SparseVector,
    Filter,
    FieldCondition,
    MatchValue,
    Range,
)

class HybridSearchEngine:
    """Qdrantを使ったハイブリッド検索エンジン"""

    def __init__(
        self,
        qdrant_client: QdrantClient,
        embedder: GeminiEmbedder,
        collection_name: str,
    ):
        self.client = qdrant_client
        self.embedder = embedder
        self.collection_name = collection_name

    def search(
        self,
        query: str,
        top_k: int = 5,
        category_filter: Optional[str] = None,
        min_date: Optional[int] = None,
        score_threshold: float = 0.0,
    ) -> list[dict]:
        """
        ハイブリッド検索（RRF統合）を実行する

        Args:
            query: 検索クエリ
            top_k: 返す結果数
            category_filter: カテゴリフィルター（Noneで全カテゴリ）
            min_date: 最小作成日時（UNIXタイムスタンプ）
            score_threshold: 最小スコア閾値

        Returns:
            検索結果のリスト（スコア・テキスト・メタデータ含む）
        """
        # クエリのベクトル化
        dense_query = self.embedder.embed_text(query, task_type="RETRIEVAL_QUERY")
        sparse_query = encode_sparse(query)

        # フィルター条件の構築
        filter_conditions = []
        if category_filter:
            filter_conditions.append(
                FieldCondition(key="category", match=MatchValue(value=category_filter))
            )
        if min_date:
            filter_conditions.append(
                FieldCondition(key="created_at", range=Range(gte=min_date))
            )

        query_filter = (
            Filter(must=filter_conditions) if filter_conditions else None
        )

        # ハイブリッド検索クエリの実行（RRF統合）
        results = self.client.query_points(
            collection_name=self.collection_name,
            prefetch=[
                # 密ベクトル検索（セマンティック）
                Prefetch(
                    query=dense_query,
                    using="dense",
                    limit=top_k * 3,  # 候補を多めに取得してRRFで絞り込む
                    filter=query_filter,
                ),
                # 疎ベクトル検索（キーワード）
                Prefetch(
                    query=SparseVector(
                        indices=sparse_query.indices,
                        values=sparse_query.values,
                    ),
                    using="sparse",
                    limit=top_k * 3,
                    filter=query_filter,
                ),
            ],
            # RRFで統合
            query=FusionQuery(fusion=Fusion.RRF),
            limit=top_k,
            score_threshold=score_threshold,
            with_payload=True,
        )

        # 結果の整形
        return [
            {
                "id": str(point.id),
                "score": point.score,
                "text": point.payload.get("text", ""),
                "title": point.payload.get("title", ""),
                "category": point.payload.get("category", ""),
                "source_url": point.payload.get("source_url", ""),
            }
            for point in results.points
        ]

    def search_dense_only(self, query: str, top_k: int = 5) -> list[dict]:
        """密ベクトルのみの検索（比較用）"""
        dense_query = self.embedder.embed_text(query, task_type="RETRIEVAL_QUERY")
        results = self.client.search(
            collection_name=self.collection_name,
            query_vector=("dense", dense_query),
            limit=top_k,
            with_payload=True,
        )
        return [
            {
                "id": str(r.id),
                "score": r.score,
                "text": r.payload.get("text", ""),
            }
            for r in results
        ]

# 使用例
search_engine = HybridSearchEngine(client, embedder, "knowledge_base")

# ハイブリッド検索の実行
results = search_engine.search(
    query="Gemini APIのベクター検索実装方法",
    top_k=5,
    category_filter=None,
)

for i, result in enumerate(results, 1):
    print(f"\n--- 結果 {i} (スコア: {result['score']:.4f}) ---")
    print(f"タイトル: {result['title']}")
    print(f"テキスト: {result['text'][:100]}...")
```

## RAG パイプラインへの統合

### Gemini API を使った回答生成

検索結果をコンテキストとして Gemini API に渡し、回答を生成します。

```python
import google.generativeai as genai

class HybridRAGSystem:
    """Gemini API + Qdrant ハイブリッドRAGシステム"""

    def __init__(
        self,
        search_engine: HybridSearchEngine,
        model_name: str = "gemini-2.5-pro",
    ):
        self.search_engine = search_engine
        self.model = genai.GenerativeModel(model_name)

    def answer(
        self,
        question: str,
        top_k: int = 5,
        category_filter: Optional[str] = None,
        temperature: float = 0.1,  # 事実ベースの回答は低温度で安定させる
    ) -> dict:
        """
        RAGシステムで質問に回答する

        Args:
            question: ユーザーの質問
            top_k: 参照するドキュメント数
            category_filter: カテゴリフィルター
            temperature: 生成温度

        Returns:
            回答テキストと参照ドキュメントを含む辞書
        """
        # 1. ハイブリッド検索でコンテキストを取得
        search_results = self.search_engine.search(
            query=question,
            top_k=top_k,
            category_filter=category_filter,
        )

        if not search_results:
            return {
                "answer": "関連する情報が見つかりませんでした。",
                "sources": [],
            }

        # 2. コンテキストを構築
        context_parts = []
        for i, result in enumerate(search_results, 1):
            context_parts.append(
                f"[文書{i}] {result['title']}\n{result['text']}"
            )
        context = "\n\n".join(context_parts)

        # 3. プロンプトを構築してGemini APIで回答生成
        prompt = f"""以下の文書を参照して、質問に正確に答えてください。
文書に記載されていない内容は推測で回答せず、「この情報は提供された文書には含まれていません」と明記してください。

【参照文書】
{context}

【質問】
{question}

【回答】"""

        response = self.model.generate_content(
            prompt,
            generation_config={
                "temperature": temperature,
                "max_output_tokens": 1024,
            }
        )

        return {
            "answer": response.text,
            "sources": [
                {
                    "title": r["title"],
                    "score": r["score"],
                    "url": r["source_url"],
                }
                for r in search_results
            ],
        }

# 使用例
rag = HybridRAGSystem(search_engine)
result = rag.answer("Qdrantはどのようなデータベースですか？")

print(f"回答:\n{result['answer']}")
print(f"\n参照文書:")
for source in result["sources"]:
```

```python
    return CollectionStats(

        indexed_vectors_count=info.indexed_vectors_count,
        collection_status=info.status,
    )

    """システムのヘルスチェック"""
    try:
        start = time.time()
        # 軽量な検索でレスポンスタイムを計測
        client.search(
            collection_name=collection_name,
            query_vector=("dense", [0.0] * 768),

        logger.info(f"Qdrant ヘルスチェック OK: レイテンシ {latency_ms:.1f}ms")
```

```python
from qdrant_client.models import QuantizationConfig

quantization_config = QuantizationConfig(

        type=ScalarType.INT8,
        quantile=0.99,    # 外れ値の1%を除いてキャリブレーション
        always_ram=True,  # 量子化ベクトルはRAMに、元のベクトルはディスクに
    )
)

from qdrant_client.models import SearchParams, QuantizationSearchParams
```

### Gemini API コスト最適化

```python
import hashlib
import json
from functools import lru_cache

# 埋め込みキャッシュ（Redisまたはインメモリ）
embedding_cache: dict[str, list[float]] = {}

def embed_with_cache(
    embedder: GeminiEmbedder,
    text: str,
    task_type: str = "RETRIEVAL_QUERY"
) -> list[float]:
    """
    埋め込みをキャッシュして Gemini API の呼び出しを削減する

    検索クエリは同じテキストが繰り返されるケースが多いため、
    キャッシュによって API コストを大幅に削減できる
    """
    cache_key = hashlib.md5(f"{text}:{task_type}".encode()).hexdigest()

    if cache_key not in embedding_cache:
        embedding_cache[cache_key] = embedder.embed_text(text, task_type)
        # Redis等の永続化キャッシュを使う場合はここで保存する

    return embedding_cache[cache_key]

# コスト試算（参考）
# text-embedding-004: $0.00001/1000文字（2026年4月時点）
# 1ドキュメント平均500文字として：100万ドキュメント = $5
# 検索クエリ（キャッシュなし1万件）: $0.05
# 月間運用コスト目安: インデックス $5 + 検索 $2-10 = $7-15/月
```

## まとめ

本稿ではGemini APIとQdrantを組み合わせたハイブリッドRAGシステムの完全な実装方法を解説しました。

重要なポイントをまとめます。

- **コレクション設計**: 密ベクトル（768次元）と疎ベクトルを明示的に定義し、ペイロードインデックスで高速フィルタリングを実現する
- **ハイブリッド検索**: RRFによる統合で、セマンティック検索とキーワード検索の双方の長所を活かす
- **量子化**: INT8量子化でメモリを4分の1に削減しつつ、精度低下を最小限に抑える
- **コスト最適化**: 埋め込みキャッシュでGemini API呼び出しを削減し、月間コストを最小化する
- **本番運用**: Qdrant Cloudでインフラ管理を省力化し、ヘルスチェックと監視を組み込む

RAGシステムの品質は、検索エンジンの精度に直接依存します。Qdrantのハイブリッド検索とGemini Embedding APIを組み合わせることで、従来のセマンティック検索のみのシステムと比べて大幅な精度向上が見込めます。まずはローカル環境でプロトタイプを構築し、精度を測定してから本番環境へ展開することをお勧めします。
