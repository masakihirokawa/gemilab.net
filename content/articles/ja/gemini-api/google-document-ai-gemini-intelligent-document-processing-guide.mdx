PDF や画像形式のビジネス文書——請求書、契約書、申請書——を手作業で処理することは、多くの企業で人的コストとエラーの温床になっています。Google Document AI と Gemini API を組み合わせることで、これらの処理を高精度で自動化できます。

Document AI は文書の構造解析とエンティティ抽出に特化した専用モデルを提供し、Gemini はそのデータをもとに複雑な解釈・要約・判断を行います。この2つを連携させることで、単純な OCR を超えた「インテリジェント・ドキュメント・プロセッシング（IDP）」が実現します。

## Google Document AI の基本アーキテクチャ

Document AI は以下の3種類のプロセッサを提供しています。

**Pretrained Processor（事前学習済みプロセッサ）**
特定文書タイプ向けに最適化されたモデルです。Invoice Parser（請求書）、Contract Document Analyzer（契約書）、Form Parser（フォーム）などがあります。

**Custom Document Extractor**
独自文書タイプに対して Field-level の学習ができるカスタムモデルです。業種固有の書類（医療レセプト、税務申告書など）に対応できます。

**Document OCR**
汎用 OCR プロセッサです。構造化抽出は必要なく、テキスト化だけでよい場合に使用します。

from google.cloud import documentai_v1 as documentai

def create_invoice_processor(project_id: str, location: str = "us"):
    client = documentai.DocumentProcessorServiceClient()

    # プロセッサの作成
    processor = documentai.Processor(
        type_="INVOICE_PROCESSOR",
        display_name="Invoice Processor Production",
    )

    parent = f"projects/{project_id}/locations/{location}"
    response = client.create_processor(parent=parent, processor=processor)

    print(f"Processor created: {response.name}")
    return response.name  # プロセッサIDを保存しておく
```

## 請求書の自動処理パイプライン

### Document AI で請求書を解析する

```python
from google.cloud import documentai_v1 as documentai
from dataclasses import dataclass
from typing import Optional
import json

@dataclass
class InvoiceData:
    invoice_id: str
    supplier_name: str
    invoice_date: Optional[str]
    due_date: Optional[str]
    total_amount: Optional[float]
    tax_amount: Optional[float]
    line_items: list[dict]
    confidence_score: float

def process_invoice_with_docai(
    pdf_bytes: bytes,
    processor_name: str,
    project_id: str,
    location: str = "us"
) -> InvoiceData:
    client = documentai.DocumentProcessorServiceClient()

    # ドキュメントの準備
    raw_document = documentai.RawDocument(
        content=pdf_bytes,
        mime_type="application/pdf"
    )

    request = documentai.ProcessRequest(
        name=processor_name,
        raw_document=raw_document,
    )

    result = client.process_document(request=request)
    document = result.document

    # エンティティの抽出
    entities = {}
    for entity in document.entities:
        key = entity.type_
        value = entity.mention_text
        confidence = entity.confidence
        entities[key] = {"value": value, "confidence": confidence}

    # ラインアイテムの抽出
    line_items = []
    for entity in document.entities:
        if entity.type_ == "line_item":
            item = {}
            for prop in entity.properties:
                item[prop.type_] = prop.mention_text
            line_items.append(item)

    # 金額のパース
    total_str = entities.get("total_amount", {}).get("value", "0")
    total = float(total_str.replace(",", "").replace("¥", "").replace("$", "").strip())

    return InvoiceData(
        invoice_id=entities.get("invoice_id", {}).get("value", ""),
        supplier_name=entities.get("supplier_name", {}).get("value", ""),
        invoice_date=entities.get("invoice_date", {}).get("value"),
        due_date=entities.get("due_date", {}).get("value"),
        total_amount=total,
        tax_amount=None,
        line_items=line_items,
        confidence_score=min(
            e.get("confidence", 1.0)
            for e in entities.values()
        ) if entities else 0.0,
    )
```

### Gemini API で異常検知・解釈を行う

Document AI が抽出した構造化データを Gemini に渡し、より深い解釈を行います。

```python
import google.generativeai as genai
import json
from dataclasses import asdict

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel("gemini-2.5-flash")

def analyze_invoice_with_gemini(
    invoice_data: InvoiceData,
    vendor_history: list[dict]
) -> dict:
    """
    Document AI で抽出したデータを Gemini で高度分析する
    - 異常金額の検知
    - 過去取引との整合性チェック
    - 支払い優先度の判断
    """

    prompt = f"""
以下の請求書データを分析して、以下の点を評価してください。

## 請求書データ
{json.dumps(asdict(invoice_data), ensure_ascii=False, indent=2)}

## 過去の取引履歴（直近3ヶ月）
{json.dumps(vendor_history, ensure_ascii=False, indent=2)}

## 分析してほしいこと
1. **異常検知**: 金額・商品・数量に不自然な点はあるか
2. **整合性チェック**: 過去の取引と比べて異常な変化はあるか
3. **支払い優先度**: Due Dateと重要度から支払い優先度を判断（HIGH/MEDIUM/LOW）
4. **アクション提案**: 担当者に連絡が必要な場合はその内容を記述

JSON形式で回答してください:
{{
  "anomalies": [...],
  "consistency_issues": [...],
  "payment_priority": "HIGH|MEDIUM|LOW",
  "priority_reason": "...",
  "recommended_action": "...",
  "confidence": 0.0-1.0
}}
"""

    response = model.generate_content(prompt)

    # JSONパース
    text = response.text.strip()
    if text.startswith("```json"):
        text = text[7:-3]
    elif text.startswith("```"):
        text = text[3:-3]

    return json.loads(text)
```

## 契約書解析パイプライン

```python
from google.cloud import documentai_v1 as documentai

def analyze_contract(
    pdf_bytes: bytes,
    contract_processor_name: str
) -> dict:
    """Contract Document Analyzer プロセッサで契約書を解析"""
    client = documentai.DocumentProcessorServiceClient()

    raw_document = documentai.RawDocument(
        content=pdf_bytes,
        mime_type="application/pdf"
    )

    request = documentai.ProcessRequest(
        name=contract_processor_name,
        raw_document=raw_document,
    )

    result = client.process_document(request=request)
    document = result.document

    # 契約書固有のエンティティを抽出
    contract_data = {
        "parties": [],
        "effective_date": None,
        "expiration_date": None,
        "payment_terms": None,
        "termination_clauses": [],
        "governing_law": None,
    }

    entity_map = {
        "contract_party": "parties",
        "effective_date": "effective_date",
        "expiration_date": "expiration_date",
        "payment_terms": "payment_terms",
        "governing_law": "governing_law",
    }

    for entity in document.entities:
        key = entity_map.get(entity.type_)
        if not key:
            continue

        if key == "parties":
            contract_data["parties"].append(entity.mention_text)
        else:
            contract_data[key] = entity.mention_text

    return contract_data


def assess_contract_risks_with_gemini(
    contract_text: str,
    contract_data: dict
) -> dict:
    """Gemini で契約書のリスク評価を行う"""
    model = genai.GenerativeModel("gemini-2.5-flash")

    prompt = f"""
以下の契約書について、法的リスクと重要事項を分析してください。

## 抽出済みメタデータ
{json.dumps(contract_data, ensure_ascii=False, indent=2)}

## 契約書本文（抜粋）
{contract_text[:8000]}  # トークン制限のため最初の8000文字

## 分析項目
1. **リスク条項**: 不利な条件・一方的な条項・免責事項
2. **期限管理**: 更新期限・通知義務の期限
3. **ペナルティ**: 違約金・損害賠償の範囲
4. **解約条件**: 解約可能な条件と手続き
5. **総合リスク評価**: LOW/MEDIUM/HIGH + 理由

JSON形式で回答:
{{
  "risk_clauses": [
    {{"clause": "...", "risk_type": "...", "severity": "LOW|MEDIUM|HIGH"}}
  ],
  "important_dates": [...],
  "penalty_terms": [...],
  "termination_conditions": [...],
  "overall_risk": "LOW|MEDIUM|HIGH",
  "risk_summary": "...",
  "recommended_review_points": [...]
}}
"""

    response = model.generate_content(
        prompt,
        generation_config=genai.types.GenerationConfig(
            temperature=0.1  # 分析タスクは低温度で一貫性を確保
        )
    )

    text = response.text.strip()
    if text.startswith("```json"):
        text = text[7:-3]
    elif text.startswith("```"):
        text = text[3:-3]

    return json.loads(text)
```

## Cloud Run + Pub/Sub によるスケーラブルなパイプライン

大量のドキュメントを処理する本番システムでは、イベント駆動アーキテクチャが適しています。

```python
# Cloud Run サービス: ドキュメント処理ワーカー
# main.py

from flask import Flask, request, jsonify
from google.cloud import pubsub_v1, storage
import base64
import json

app = Flask(__name__)

@app.route('/process', methods=['POST'])
def process_document_event():
    """Pub/Sub からのメッセージを受信してドキュメントを処理する"""
    envelope = request.get_json()
    message = envelope.get('message', {})

    # Pub/Sub メッセージのデコード
    data = base64.b64decode(message.get('data', '')).decode('utf-8')
    event = json.loads(data)

    bucket_name = event['bucket']
    file_name = event['name']
    doc_type = event.get('doc_type', 'invoice')

    # GCS からドキュメントを取得
    storage_client = storage.Client()
    bucket = storage_client.bucket(bucket_name)
    blob = bucket.blob(file_name)
    pdf_bytes = blob.download_as_bytes()

    # Document AI で処理
    if doc_type == 'invoice':
        invoice_data = process_invoice_with_docai(
            pdf_bytes,
            processor_name=INVOICE_PROCESSOR_NAME,
            project_id=PROJECT_ID
        )
        # 取引履歴を取得（例: Firestore から）
        vendor_history = get_vendor_history(invoice_data.supplier_name)

        # Gemini で分析
        analysis = analyze_invoice_with_gemini(invoice_data, vendor_history)

        # 結果を Firestore に保存
        save_invoice_result(invoice_data, analysis, file_name)

    elif doc_type == 'contract':
        contract_data = analyze_contract(
            pdf_bytes,
            contract_processor_name=CONTRACT_PROCESSOR_NAME
        )
        # 契約書テキストの抽出（Document AI の fullText を使用）
        contract_text = extract_full_text(pdf_bytes)
        risk_assessment = assess_contract_risks_with_gemini(
            contract_text, contract_data
        )
        save_contract_result(contract_data, risk_assessment, file_name)

    return jsonify({"status": "processed", "file": file_name}), 200


if __name__ == '__main__':
    app.run(host='0.0.0.0', port=8080)
```

### GCS トリガーの設定

```bash
# Cloud Storage にファイルがアップロードされたら Pub/Sub に通知

  gs://YOUR_DOCUMENT_BUCKET \
  --topic=document-processing-topic \
  --event-types=OBJECT_FINALIZE \
  --payload-format=JSON

# Cloud Run サービスを Pub/Sub サブスクリプションに接続

  --topic=document-processing-topic \

## 信頼度スコアによる品質ゲーティング

```python
CONFIDENCE_THRESHOLDS = {
    "auto_approve": 0.95,      # 自動承認
    "human_review": 0.80,      # 人間のレビューが必要
    "manual_processing": 0.60, # 手動処理が必要
}

def route_document_by_confidence(
    invoice_data: InvoiceData,
    analysis: dict
) -> str:
    """信頼度スコアに基づいて処理ルートを決定する"""
    doc_confidence = invoice_data.confidence_score
    ai_confidence = analysis.get("confidence", 0.0)
    combined = (doc_confidence + ai_confidence) / 2

    anomaly_count = len(analysis.get("anomalies", []))

    # 異常が検出された場合は必ずレビューへ
    if anomaly_count > 0 or analysis.get("payment_priority") == "HIGH":
        return "human_review"

    if combined >= CONFIDENCE_THRESHOLDS["auto_approve"]:
        return "auto_approve"
    elif combined >= CONFIDENCE_THRESHOLDS["human_review"]:
        return "human_review"
    else:
        return "manual_processing"
```
