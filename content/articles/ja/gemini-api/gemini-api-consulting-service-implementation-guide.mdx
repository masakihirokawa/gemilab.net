AI技術を持っている人と、それを必要としている企業の間には、まだ大きな橋渡しの余地があります。

「Gemini APIを触れる」という技術は、多くの中小企業・個人事業主には相当価値のあるスキルです。彼らはAIに興味はあるが、自分でAPIを叩くことはできない。あなたができることを彼らに提供すれば、それはそのままビジネスになります。

この記事では、Gemini APIをベースにしたBtoBコンサルティングサービスの設計から、デモ実装・提案書・請求設計まで、実際に使えるレベルで解説します。

## どんなサービスが売れるか：3つの収益化パターン

AIコンサルとして売れるサービスには、明確なパターンがあります。

**パターン1 — 業務自動化エージェント（月額 ¥30,000〜¥150,000）**

具体例: 「問い合わせメールを自動分類して担当者に振り分ける」「請求書PDFから金額と取引先を抽出してスプレッドシートに記録する」など。

企業が毎月繰り返している定型作業をGemini APIで自動化します。月額保守費用として継続的に請求でき、MRRが積み上がります。エージェントの構築費用は別途スポット請求（¥100,000〜¥300,000）が一般的です。

**パターン2 — AIレポート生成サービス（月額 ¥20,000〜¥80,000）**

具体例: 「競合他社のニュースを週次でモニタリングして要約レポートを自動生成」「自社ECの売上データを分析して月次インサイトレポートを作成」など。

情報収集と分析をGeminiに任せ、人間が確認・承認するだけの状態を作ります。レポートの「仕様」を定義すれば、あとはほぼ自動で動きます。

**パターン3 — AIチャットボット構築（スポット ¥150,000〜¥500,000）**

FAQチャットボット・社内ナレッジ検索・営業支援ボットなど。RAG（Retrieval-Augmented Generation）を組み合わせて、企業固有の情報に基づいた回答を返すシステムを構築します。スポット案件として請求し、保守は月額オプションで設定します。

## 提案前のヒアリングフレームワーク

初回商談で確認すべき内容は5つです。これをヒアリングできれば、90%の確率で適切なサービス提案ができます。

**① 現在の業務課題はどこか**（例：問い合わせ対応に1日2時間かかっている）

**② その業務の頻度と規模はどのくらいか**（例：月500件・担当者3名）

**③ 現在の処理方法は何か**（例：Excelで管理・Gmailで返信・コピペで対応）

**④ 改善の優先度は何か**（例：時間削減 vs コスト削減 vs ミス削減）

**⑤ 予算規模のイメージはあるか**（例：月¥5万なら検討可能・初期費用は¥50万以下）

ヒアリング結果をもとに、どのパターンが最も価値を届けられるかを判断します。

## 実装：問い合わせ分類エージェント（デモ品質）

商談時に見せるデモを用意することで、成約率が大きく変わります。以下は問い合わせメールを自動分類するエージェントの実装例です。

```python
import google.generativeai as genai
import json
from enum import Enum
from dataclasses import dataclass

genai.configure(api_key="YOUR_GEMINI_API_KEY")

class InquiryCategory(str, Enum):
    SUPPORT = "サポート・障害"
    BILLING = "請求・支払い"
    SALES = "営業・見積もり"
    GENERAL = "一般問い合わせ"
    URGENT = "緊急対応必要"

@dataclass
class ClassificationResult:
    category: InquiryCategory
    priority: str          # high / medium / low
    suggested_assignee: str
    summary: str
    estimated_response_time: str

def classify_inquiry(email_body: str, company_context: str = "") -> ClassificationResult:
    """
    問い合わせメールを分類し、担当者への振り分け情報を返す。
    
    company_context: 企業固有の情報（担当者の得意領域など）をここに渡す
    """
    model = genai.GenerativeModel(
        "gemini-2.5-pro",
        generation_config=genai.GenerationConfig(
            response_mime_type="application/json",
            response_schema={
                "type": "object",
                "properties": {
                    "category": {"type": "string", "enum": [e.value for e in InquiryCategory]},
                    "priority": {"type": "string", "enum": ["high", "medium", "low"]},
                    "suggested_assignee": {"type": "string"},
                    "summary": {"type": "string"},
                    "estimated_response_time": {"type": "string"},
                },
                "required": ["category", "priority", "suggested_assignee", "summary", "estimated_response_time"]
            }
        )
    )
    
    context_section = f"\n【会社情報】\n{company_context}" if company_context else ""
    
    prompt = f"""以下の問い合わせメールを分析して、分類・優先度・担当者を決定してください。{context_section}

【問い合わせ内容】
{email_body}

判断基準:
- priorityがhighの場合: システム障害・返金要求・法的リスクがある問い合わせ
- priorityがmediumの場合: 通常のサポート・一般的な質問
- priorityがlowの場合: 資料請求・一般的な営業問い合わせ
- estimated_response_timeは「即時」「2時間以内」「当日中」「2営業日以内」のいずれか"""
    
    response = model.generate_content(prompt)
    data = json.loads(response.text)
    
    return ClassificationResult(
        category=InquiryCategory(data["category"]),
        priority=data["priority"],
        suggested_assignee=data["suggested_assignee"],
        summary=data["summary"],
        estimated_response_time=data["estimated_response_time"]
    )

# デモ実行
sample_inquiry = """
お世話になります。先月購入した製品について、
起動時にエラーコード「E-0023」が表示され、全く使えない状態です。
業務で毎日使用しているため、早急な対応をお願いしたいです。
返金も視野に入れています。
"""

company_context = """
- 担当者A: システム・技術サポート専門
- 担当者B: 請求・返金対応専門  
- 担当者C: 営業・見積もり専門
"""

result = classify_inquiry(sample_inquiry, company_context)
print(f"カテゴリ: {result.category.value}")
print(f"優先度: {result.priority}")
print(f"担当者: {result.suggested_assignee}")
print(f"応答目標: {result.estimated_response_time}")
print(f"要約: {result.summary}")
```

このコードをデモとして見せるポイントは2つです。まず「structured output」を使って確実にJSON形式で返しており、後続のシステム（メール送信・スプレッドシート記録など）と自動連携できる形になっています。次に`company_context`を渡すことで、クライアントの担当者情報・業界特性・社内ルールをエージェントに組み込める設計にしています。

## 実装：月次レポート自動生成

継続課金を正当化するために、月次レポートは非常に重要です。何もしていないと「本当に動いているのか」と疑われます。

```python
import google.generativeai as genai
from datetime import datetime, date
import json

def generate_monthly_report(
    client_name: str,
    service_description: str,
    usage_data: dict,
    period: str,
) -> str:
    """
    クライアント向け月次レポートを自動生成する。
    
    usage_data: {
        "total_processed": 件数,
        "auto_resolved": 自動解決件数,
        "escalated": エスカレーション件数,
        "avg_response_time_minutes": 平均応答時間(分),
        "cost_saved_hours": 節約時間(時間),
    }
    """
    model = genai.GenerativeModel("gemini-2.5-pro")
    
    # 自動解決率を計算
    resolution_rate = (usage_data["auto_resolved"] / usage_data["total_processed"] * 100) if usage_data["total_processed"] > 0 else 0
    
    prompt = f"""以下のデータをもとに、クライアント向けの月次レポートを作成してください。

クライアント名: {client_name}
対象期間: {period}
提供サービス: {service_description}

実績データ:
- 処理件数合計: {usage_data['total_processed']}件
- 自動解決件数: {usage_data['auto_resolved']}件（自動解決率: {resolution_rate:.1f}%）
- エスカレーション件数: {usage_data['escalated']}件
- 平均応答時間: {usage_data['avg_response_time_minutes']}分
- 節約工数: {usage_data['cost_saved_hours']}時間

以下の構成でレポートを作成してください:
1. エグゼクティブサマリー（箇条書き3点）
2. 今月の主な成果
3. 数値ハイライト（表形式ではなくリスト形式で）
4. 来月の改善提案（1〜2点）

文体: 丁寧・プロフェッショナル・ポジティブ（成果を前面に出す）
"""
    
    response = model.generate_content(prompt)
    return response.text

# 月次レポート生成例
usage_data = {
    "total_processed": 847,
    "auto_resolved": 721,
    "escalated": 126,
    "avg_response_time_minutes": 2.3,
    "cost_saved_hours": 42.5,
}

report = generate_monthly_report(
    client_name="株式会社サンプル",
    service_description="問い合わせ自動分類・担当者振り分けシステム",
    usage_data=usage_data,
    period="2026年4月",
)
print(report)
```

このレポートをPDFに変換してメールで自動送信する仕組みを作れば、月1回の定型業務も自動化できます。クライアントからの見え方は「毎月きちんと報告が来る、信頼できるサービス」になります。

## 価格設計と契約形態

価格の設定は心理的なハードルが高いですが、基準を持つと楽になります。

**原価計算の考え方**: Gemini APIのコスト（月1万件処理で約¥1,000〜¥3,000）を把握した上で、自分の時間（初期構築・保守・レポート確認）に時間単価¥5,000〜¥8,000を乗せ、マージンを足します。

**月額¥30,000なら月何時間費やせるか**: ¥30,000 / ¥6,000（時間単価）= 5時間。初期構築が終われば、月5時間以下で運用できるサービスなら、¥30,000は持続可能な設定です。

**値下げ要求への対処**: 「費用を下げるなら、この機能を外す形にできます」と伝えます。値下げに応じるのではなく、スコープを変えることで単価を守ります。

## よくある失敗と対処法

**失敗1 — スコープが膨らむ**

「ついでにこれも自動化できませんか」という追加要求は必ず来ます。最初の契約書にスコープを明記し、追加機能は別途見積もりとすることを最初に伝えておくことが重要です。

**失敗2 — APIエラーのせいにされる**

Gemini APIが一時的にエラーを返すことはあります。SLA（稼働率保証）を設定し、エラー時のフォールバック処理を実装しておかないと、信頼を損ねます。重要な処理には必ずエラーハンドリングとリトライロジックを入れること。

**失敗3 — 成果が見えにくい**

月次レポートを送らないと「本当に動いているのか」と思われます。上記のレポート生成コードを使い、最低でも月1回、数値ベースの報告をする習慣をつけましょう。

## 最初の受注に向けた現実的なルート

AIコンサルで最初の受注を得る最短ルートは、身近な人（前職の同僚・知人の経営者・地域の商工会）に「無料で試させてほしい」と持ちかけることです。

最初の1〜2案件は無償または格安で行い、実績データ（節約工数・処理件数など）を積み上げます。そのデータが最強の営業ツールになります。「他社でこういう成果が出ました」と言える状態になれば、初回の商談から有償で進められるようになります。
