## 取り組みの背景 — なぜ「本番対応」のLive API実装が難しいのか

Gemini Live APIは、低レイテンシのリアルタイム双方向通信を実現する強力なAPIです。しかし、多くの開発者がデモや検証段階ではうまく動かせても、プロダクション環境に移行しようとした段階で壁にぶつかります。

その最大の理由は**セキュリティ設計**です。

Gemini Live APIはWebSocket（WSS）接続を使用します。単純な実装では、クライアント（ブラウザ）が直接 `wss://generativelanguage.googleapis.com/ws/...?key=YOUR_API_KEY` に接続することになります。これはAPIキーがブラウザのデベロッパーツールやネットワークログに丸見えになることを意味し、本番環境では絶対に許容できない設計です。

Google公式が推奨するのは**エフェメラルトークン（Ephemeral Token）**を使ったアーキテクチャです。バックエンドが短期間有効な使い捨てトークンを発行し、フロントエンドはそのトークンでLive APIに直接接続します。これにより、APIキーをクライアントに一切露出させずに、低レイテンシなクライアント直接接続の恩恵を最大限に活かせます。

基礎的な使い方については[Gemini Live API 完全ガイド](/articles/gemini-api/gemini-live-api-guide)を先にご確認ください。本記事はその上級編として、本番運用で必要な実装ノウハウに特化した内容です。

## Gemini Live APIのアーキテクチャ全体像

まず、通常のREST APIとLive APIの根本的な違いを整理します。

**通常のREST API（generateContent）**では、リクエストとレスポンスが1対1で完結します。クライアントがHTTPリクエストを送り、サーバーがJSONで返す、ステートレスな設計です。

**Live API（BidiGenerateContent）**は、WebSocketを使った永続的な双方向接続です。接続が確立した後は、クライアントとサーバーが非同期に何度でもメッセージを交換できます。音声や映像のリアルタイムストリーミング、割り込み発話（barge-in）、ツール呼び出しがすべて単一の接続上で処理されます。

接続後のライフサイクルは以下の流れです。

**Step 1: セットアップメッセージの送信**

接続確立直後、クライアントはモデル名・生成設定・レスポンスモダリティ・System Instructionを含む `setup` メッセージを送ります。

**Step 2: setupComplete の受信**

サーバーが `setupComplete` を返すと、セッションが開始します。

**Step 3: 双方向ストリーミング**

クライアントは `realtimeInput`（高頻度の音声/映像/テキスト入力）または `clientContent`（ターン形式のテキスト入力）を送信し、サーバーからは `serverContent`（モデルのレスポンス）や `toolCall`（Function Calling）が届きます。

**Step 4: 切断**

クライアントまたはサーバーが接続を閉じます。サーバー側から切断する場合は `goAway` メッセージが先に届きます。

## 基本実装：WebSocketセッションの確立

まずエフェメラルトークンを使わないサーバーサイド限定の基本実装を確認します。これはバックエンドのみで動作するスクリプトやサーバー側プロキシの実装に使います。

```python
# backend/live_api_basic.py
import asyncio
import json
import websockets
import os

GEMINI_API_KEY = os.environ["GEMINI_API_KEY"]
LIVE_API_URL = (
    f"wss://generativelanguage.googleapis.com/ws/"
    f"google.ai.generativelanguage.v1beta."
    f"GenerativeService.BidiGenerateContent?key={GEMINI_API_KEY}"
)

# セットアップメッセージ
SETUP_MESSAGE = {
    "setup": {
        "model": "models/gemini-2.0-flash",
        "generationConfig": {
            "temperature": 0.7,
            "maxOutputTokens": 1024,
            "responseModalities": ["TEXT"]
        },
        "systemInstruction": {
            "parts": [{"text": "You are a helpful assistant. Respond concisely."}]
        }
    }
}

async def run_live_session():
    async with websockets.connect(LIVE_API_URL) as ws:
        # 1. セットアップ送信
        await ws.send(json.dumps(SETUP_MESSAGE))
        print("Setup sent")

        # 2. setupComplete を待つ
        while True:
            msg = json.loads(await ws.recv())
            if "setupComplete" in msg:
                print("Session ready!")
                break

        # 3. テキスト入力を送信
        client_content = {
            "clientContent": {
                "turns": [
                    {"role": "user", "parts": [{"text": "Hello! What can you do?"}]}
                ],
                "turnComplete": True
            }
        }
        await ws.send(json.dumps(client_content))

        # 4. レスポンスを受信
        full_response = []
        async for raw_msg in ws:
            msg = json.loads(raw_msg)

            if "serverContent" in msg:
                content = msg["serverContent"]
                if "modelTurn" in content:
                    for part in content["modelTurn"].get("parts", []):
                        if "text" in part:
                            full_response.append(part["text"])
                            print(part["text"], end="", flush=True)
                if content.get("turnComplete"):
                    print("\n--- Turn complete ---")
                    break

        return "".join(full_response)

if __name__ == "__main__":
    result = asyncio.run(run_live_session())
    print(f"\nFull response: {result}")
```

このコードを動かすと、以下のような出力が得られます。

```
Setup sent
Session ready!
I can help you with a wide range of tasks...
--- Turn complete ---
```

## エフェメラルトークンの実装（本番セキュリティの核心）

本番環境では、APIキーをクライアントに渡さないエフェメラルトークン方式が必須です。このアーキテクチャは次のように動作します。

```
[Client] → 認証リクエスト → [自社バックエンド]
                          ↓
                [Gemini APIキーでエフェメラルトークンを発行]
                          ↓
[Client] ← 短命トークン（30分有効） ← [自社バックエンド]
    ↓
[Client] → WebSocket接続（トークン使用） → [Gemini Live API]
```

### バックエンド：エフェメラルトークン発行API

Next.js App Router（Node.js）で実装する例です。

```typescript
// app/api/live/token/route.ts
import { NextRequest, NextResponse } from "next/server";

// エフェメラルトークン発行エンドポイント
// Google AI APIのv1alphaエンドポイントを使用
const TOKEN_ENDPOINT =
  "https://generativelanguage.googleapis.com/v1alpha/ephemeralTokens:create";

export async function POST(req: NextRequest) {
  // 1. ユーザー認証の確認（自社の認証ロジック）
  const session = await getServerSession(req); // 例: next-auth
  if (!session?.user) {
    return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
  }

  const apiKey = process.env.GEMINI_API_KEY;
  if (!apiKey) {
    return NextResponse.json({ error: "Server config error" }, { status: 500 });
  }

  // 2. エフェメラルトークンを発行
  try {
    const response = await fetch(`${TOKEN_ENDPOINT}?key=${apiKey}`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        // トークンの有効期限（デフォルト: 30分）
        ttl: "1800s",
        // モデルとSystem Instructionを事前設定
        model: "models/gemini-2.0-flash",
        systemInstruction: {
          parts: [{ text: "You are a helpful assistant for our application." }]
        },
        // 許可するレスポンスモダリティを制限（セキュリティ強化）
        responseModalities: ["TEXT", "AUDIO"]
      })
    });

    if (!response.ok) {
      const errorBody = await response.text();
      console.error("Token generation failed:", errorBody);
      return NextResponse.json(
        { error: "Failed to generate token" },
        { status: 500 }
      );
    }

    const data = await response.json();
    return NextResponse.json({
      token: data.token,        // 短命トークン
      expiresAt: data.expireTime // 有効期限
    });
  } catch (err) {
    console.error("Token API error:", err);
    return NextResponse.json({ error: "Internal error" }, { status: 500 });
  }
}
```

### フロントエンド：エフェメラルトークンでLive APIに接続

```typescript
// hooks/useLiveApi.ts
import { useCallback, useRef, useState } from "react";

const LIVE_WS_BASE =
  "wss://generativelanguage.googleapis.com/ws/" +
  "google.ai.generativelanguage.v1alpha." +
  "GenerativeService.BidiGenerateContentConstrained";

interface LiveApiHook {
  connect: () => Promise<void>;
  sendText: (text: string) => void;
  disconnect: () => void;
  isConnected: boolean;
  messages: string[];
}

export function useLiveApi(): LiveApiHook {
  const wsRef = useRef<WebSocket | null>(null);
  const [isConnected, setIsConnected] = useState(false);
  const [messages, setMessages] = useState<string[]>([]);

  const connect = useCallback(async () => {
    // 1. バックエンドからエフェメラルトークンを取得
    const res = await fetch("/api/live/token", { method: "POST" });
    if (!res.ok) throw new Error("Failed to get token");
    const { token } = await res.json();

    // 2. エフェメラルトークンでLive APIに直接接続
    const wsUrl = `${LIVE_WS_BASE}?access_token=${token}`;
    const ws = new WebSocket(wsUrl);
    wsRef.current = ws;

    ws.onopen = () => {
      // 3. セットアップメッセージ送信（トークン発行時に設定済みなので最小限）
      ws.send(JSON.stringify({
        setup: {
          model: "models/gemini-2.0-flash",
          generationConfig: {
            temperature: 0.7,
            maxOutputTokens: 1024,
            responseModalities: ["TEXT"]
          }
        }
      }));
    };

    ws.onmessage = (event) => {
      const msg = JSON.parse(event.data);

      if ("setupComplete" in msg) {
        setIsConnected(true);
        console.log("Live API session ready");
        return;
      }

      if ("serverContent" in msg) {
        const content = msg.serverContent;
        if (content.modelTurn?.parts) {
          for (const part of content.modelTurn.parts) {
            if (part.text) {
              setMessages((prev) => [...prev, part.text]);
            }
          }
        }
      }
    };

    ws.onerror = (err) => console.error("WebSocket error:", err);
    ws.onclose = () => {
      setIsConnected(false);
      console.log("WebSocket closed");
    };
  }, []);

  const sendText = useCallback((text: string) => {
    if (!wsRef.current || wsRef.current.readyState !== WebSocket.OPEN) return;
    wsRef.current.send(JSON.stringify({
      clientContent: {
        turns: [{ role: "user", parts: [{ text }] }],
        turnComplete: true
      }
    }));
  }, []);

  const disconnect = useCallback(() => {
    wsRef.current?.close();
    wsRef.current = null;
    setIsConnected(false);
  }, []);

  return { connect, sendText, disconnect, isConnected, messages };
}
```

## リアルタイム音声ストリーミングの実装

音声ストリーミングはLive APIの最も強力な機能です。マイクから16kHz・16bit PCMでキャプチャしたデータをBase64エンコードして送信します。

```typescript
// hooks/useLiveAudio.ts
import { useCallback, useRef } from "react";

const SAMPLE_RATE = 16000; // 入力は16kHz
const OUTPUT_SAMPLE_RATE = 24000; // 出力は24kHz

export function useLiveAudio(ws: WebSocket | null) {
  const audioContextRef = useRef<AudioContext | null>(null);
  const processorRef = useRef<ScriptProcessorNode | null>(null);
  const streamRef = useRef<MediaStream | null>(null);

  const startRecording = useCallback(async () => {
    if (!ws || ws.readyState !== WebSocket.OPEN) return;

    // マイクアクセスをリクエスト
    const stream = await navigator.mediaDevices.getUserMedia({
      audio: {
        sampleRate: SAMPLE_RATE,
        channelCount: 1,
        echoCancellation: true,
        noiseSuppression: true
      }
    });
    streamRef.current = stream;

    const audioCtx = new AudioContext({ sampleRate: SAMPLE_RATE });
    audioContextRef.current = audioCtx;

    const source = audioCtx.createMediaStreamSource(stream);
    // ScriptProcessorNode（非推奨だがシンプルな実装のため使用）
    // 本番では AudioWorkletNode を推奨
    const processor = audioCtx.createScriptProcessor(4096, 1, 1);
    processorRef.current = processor;

    processor.onaudioprocess = (event) => {
      const inputData = event.inputBuffer.getChannelData(0);

      // Float32Array → 16-bit PCM に変換
      const pcm16 = float32ToPcm16(inputData);

      // Base64エンコードしてLive APIに送信
      const base64Audio = arrayBufferToBase64(pcm16.buffer);
      ws.send(JSON.stringify({
        realtimeInput: {
          mediaChunks: [{
            mimeType: "audio/pcm;rate=16000",
            data: base64Audio
          }]
        }
      }));
    };

    source.connect(processor);
    processor.connect(audioCtx.destination);
  }, [ws]);

  const stopRecording = useCallback(() => {
    processorRef.current?.disconnect();
    audioContextRef.current?.close();
    streamRef.current?.getTracks().forEach((t) => t.stop());
  }, []);

  return { startRecording, stopRecording };
}

// Float32Array (-1〜1) を Int16Array (-32768〜32767) に変換
function float32ToPcm16(float32Array: Float32Array): Int16Array {
  const pcm16 = new Int16Array(float32Array.length);
  for (let i = 0; i < float32Array.length; i++) {
    const clamp = Math.max(-1, Math.min(1, float32Array[i]));
    pcm16[i] = clamp < 0 ? clamp * 32768 : clamp * 32767;
  }
  return pcm16;
}

function arrayBufferToBase64(buffer: ArrayBuffer): string {
  const bytes = new Uint8Array(buffer);
  let binary = "";
  for (let i = 0; i < bytes.byteLength; i++) {
    binary += String.fromCharCode(bytes[i]);
  }
  return btoa(binary);
}
```

サーバーから音声が返ってきた場合は、`serverContent.modelTurn.parts[].inlineData.data`（Base64エンコードされた24kHz PCM）をデコードして再生します。

## Function Callingの統合

Live APIでもFunction Callingは利用できます。セットアップメッセージに `tools` を定義し、サーバーから `toolCall` が届いたら処理してから `toolResponse` を返します。

```typescript
// Function Callingのセットアップと処理

// セットアップメッセージ内でツールを定義
const SETUP_WITH_TOOLS = {
  setup: {
    model: "models/gemini-2.0-flash",
    generationConfig: { responseModalities: ["TEXT"] },
    tools: [
      {
        functionDeclarations: [
          {
            name: "get_weather",
            description: "Get current weather for a location",
            parameters: {
              type: "OBJECT",
              properties: {
                location: {
                  type: "STRING",
                  description: "City and country, e.g. Tokyo, Japan"
                }
              },
              required: ["location"]
            }
          },
          {
            name: "create_calendar_event",
            description: "Create a new calendar event",
            parameters: {
              type: "OBJECT",
              properties: {
                title: { type: "STRING" },
                date: { type: "STRING", description: "ISO 8601 format" },
                duration_minutes: { type: "NUMBER" }
              },
              required: ["title", "date"]
            }
          }
        ]
      }
    ]
  }
};

// toolCallを処理する関数
async function handleToolCall(
  ws: WebSocket,
  toolCallMsg: Record<string, unknown>
) {
  const toolCall = toolCallMsg.toolCall as {
    functionCalls: Array<{
      id: string;
      name: string;
      args: Record<string, unknown>;
    }>;
  };

  const functionResponses = await Promise.all(
    toolCall.functionCalls.map(async (call) => {
      let result: unknown;

      switch (call.name) {
        case "get_weather":
          // 実際のAPIを呼ぶ（例）
          result = await fetchWeather(call.args.location as string);
          break;
        case "create_calendar_event":
          result = await createCalendarEvent(
            call.args.title as string,
            call.args.date as string,
            call.args.duration_minutes as number
          );
          break;
        default:
          result = { error: "Unknown function" };
      }

      return {
        id: call.id,
        name: call.name,
        response: { result }
      };
    })
  );

  // toolResponseを送信
  ws.send(JSON.stringify({
    toolResponse: { functionResponses }
  }));
}
```

## 本番対応：再接続ロジックとエラーハンドリング

Live APIのWebSocket接続は、ネットワーク不安定や長時間セッションによる切断が発生することがあります。本番環境では指数バックオフ（Exponential Backoff）を使った自動再接続が必須です。

```typescript
// lib/LiveApiManager.ts
type MessageHandler = (msg: Record<string, unknown>) => void;

export class LiveApiManager {
  private ws: WebSocket | null = null;
  private reconnectAttempts = 0;
  private readonly maxReconnectAttempts = 5;
  private readonly baseDelay = 1000; // 1秒
  private onMessageHandler: MessageHandler | null = null;
  private isIntentionallyClosed = false;

  constructor(
    private readonly getToken: () => Promise<string>,
    private readonly wsBase: string
  ) {}

  setMessageHandler(handler: MessageHandler) {
    this.onMessageHandler = handler;
  }

  async connect(): Promise<void> {
    this.isIntentionallyClosed = false;
    await this.createConnection();
  }

  private async createConnection(): Promise<void> {
    const token = await this.getToken();
    const ws = new WebSocket(`${this.wsBase}?access_token=${token}`);

    ws.onopen = () => {
      console.log("✅ Connected to Gemini Live API");
      this.reconnectAttempts = 0;
      ws.send(JSON.stringify({
        setup: {
          model: "models/gemini-2.0-flash",
          generationConfig: {
            temperature: 0.7,
            responseModalities: ["TEXT"]
          }
        }
      }));
    };

    ws.onmessage = (event) => {
      const msg = JSON.parse(event.data);
      this.onMessageHandler?.(msg);
    };

    ws.onclose = (event) => {
      this.ws = null;
      if (this.isIntentionallyClosed) return;

      console.warn(`WebSocket closed (code: ${event.code}). Reconnecting...`);
      this.scheduleReconnect();
    };

    ws.onerror = (err) => {
      console.error("WebSocket error:", err);
    };

    this.ws = ws;
  }

  private scheduleReconnect() {
    if (this.reconnectAttempts >= this.maxReconnectAttempts) {
      console.error("Max reconnect attempts reached. Giving up.");
      return;
    }

    // 指数バックオフ: 1s, 2s, 4s, 8s, 16s
    const delay =
      this.baseDelay * Math.pow(2, this.reconnectAttempts) +
      Math.random() * 500; // ジッター追加

    this.reconnectAttempts++;
    console.log(
      `Reconnecting in ${Math.round(delay)}ms ` +
      `(attempt ${this.reconnectAttempts}/${this.maxReconnectAttempts})`
    );

    setTimeout(() => this.createConnection(), delay);
  }

  send(data: Record<string, unknown>): boolean {
    if (!this.ws || this.ws.readyState !== WebSocket.OPEN) {
      console.warn("WebSocket not ready. Message dropped.");
      return false;
    }
    this.ws.send(JSON.stringify(data));
    return true;
  }

  disconnect() {
    this.isIntentionallyClosed = true;
    this.ws?.close();
    this.ws = null;
  }

  get isConnected(): boolean {
    return this.ws?.readyState === WebSocket.OPEN;
  }
}
```

```tsx
        const content = msg.serverContent as Record<string, unknown>;
        const parts =
          (content.modelTurn as Record<string, unknown>)?.parts as Array<
            Record<string, unknown>
          > | undefined;

        if (parts) {
          const text = parts
            .filter((p) => typeof p.text === "string")
            .map((p) => p.text as string)
            .join("");

          if (text) {
            setMessages((prev) => [...prev, { role: "model", text }]);
          }
        }
      }
    });

    managerRef.current = manager;

    // 自動接続
    manager.connect().then(() => setIsConnected(true));

    return () => {
      manager.disconnect();
    };
  }, []);

  const handleSend = () => {
    const text = input.trim();
    if (!text || !isReady || !managerRef.current) return;

    setMessages((prev) => [...prev, { role: "user", text }]);
    managerRef.current.send({
      clientContent: {
        turns: [{ role: "user", parts: [{ text }] }],
        turnComplete: true
      }
    });
    setInput("");
  };

  return (
    <div className="flex flex-col h-screen max-w-2xl mx-auto p-4">
      <div className="mb-4 flex items-center gap-2">
        <div
          className={`w-3 h-3 rounded-full ${
            isReady ? "bg-green-500" : isConnected ? "bg-yellow-500" : "bg-red-500"
          }`}
        />
        <span className="text-sm text-gray-600">
          {isReady ? "Ready" : isConnected ? "Connecting..." : "Disconnected"}
        </span>
      </div>

      <div className="flex-1 overflow-y-auto space-y-4 mb-4">
        {messages.map((msg, i) => (
          <div
            key={i}
            className={`p-3 rounded-lg ${
              msg.role === "user"
                ? "bg-blue-100 ml-auto max-w-xs"
                : "bg-gray-100 mr-auto max-w-sm"
            }`}
          >
            {msg.text}
          </div>
        ))}
      </div>

      <div className="flex gap-2">
        <input
          className="flex-1 border rounded-lg px-4 py-2 focus:outline-none focus:ring-2"
          value={input}
          onChange={(e) => setInput(e.target.value)}
          onKeyDown={(e) => e.key === "Enter" && handleSend()}
          placeholder="メッセージを入力..."
          disabled={!isReady}
        />
        <button
          className="px-6 py-2 bg-blue-600 text-white rounded-lg disabled:opacity-50"
          onClick={handleSend}
          disabled={!isReady || !input.trim()}
        >
          送信
        </button>
      </div>
    </div>
  );
}
```

## コスト管理とトークン消費の最適化

Live APIはリアルタイムのストリーミングを行うため、使い方を誤るとコストが急増します。以下の点に注意してください。

**接続コストの考え方**: 音声入力は16kHz・1チャンネルで約1分あたり約960KBのデータを送信します。長時間の無音でも接続を維持しているとトークンが消費されることがあります。

**セッション管理の最適化**: 一定時間（例: 30秒）ユーザー入力がない場合は接続を切断し、再び入力があったときに再接続する「アイドル切断」パターンを実装します。

**音声検知（VAD）の活用**: ブラウザのWeb Audio APIで音量レベルを監視し、閾値以下の音は送信しない実装で、無効なパケットをフィルタリングできます。

コスト最適化の全体戦略については[Gemini APIコスト完全最適化ガイド](/articles/gemini-api/gemini-api-cost-optimization-complete-guide)も参照ください。

## まとめ

ここではGemini Live APIをプロダクション環境で安全に運用するための主要な設計パターンを解説しました。

エフェメラルトークン認証は、Live APIを本番投入する際に最初に実装すべきセキュリティ基盤です。バックエンドでトークンを発行し、フロントエンドはそのトークンでGemini Live APIに直接接続するアーキテクチャにより、APIキーのクライアント露出を完全に防ぐことができます。

再接続ロジック（指数バックオフ+ジッター）、音声PCM変換、Function Calling統合、Next.js App Routerとの統合パターンを組み合わせることで、エンタープライズグレードのリアルタイムAIアプリケーションを構築できます。
