Gemini APIキーをGoogle AI Studioで発行して、「さあ、Pythonで試してみよう」と思ったその瞬間からエラーが出る——これは、多くの方が通る洗礼のようなものです。

私自身も初めてAPIを叩いたとき、環境変数の設定を間違えて認証エラーを1時間追いかけた経験があります。同じ轍を踏む方が少しでも減るよう、よくあるパターンを整理してみました。

## SDKのインストールで詰まる場合

最初の壁は、インストールするパッケージ名の混乱です。Gemini API用のPython SDKは現在 `google-genai` という名前になっており、旧SDK `google-generativeai` は非推奨となっています。

```bash
# ✅ 正しいインストール
pip install google-genai

# ❌ 旧SDK（現在は非推奨・新SDKとAPIが異なる）
pip install google-generativeai
```

インストール後のimport文も変わっています。

```python
# ✅ 新SDK（google-genai）のimport
from google import genai
from google.genai import types

# ❌ 旧SDKのimport（新SDKでは動かない）
import google.generativeai as genai  # 旧SDK
```

`pip list | grep google` を実行して、両方がインストールされていないか確認してみてください。混在させると `ModuleNotFoundError` や `AttributeError` が発生します。詳しくは[Gemini SDK バージョン・インストールエラーの解決ガイド](/articles/gemini-api/gemini-sdk-version-install-error-fix)も参考になります。

## 環境変数の設定ミスによる認証エラー

`PERMISSION_DENIED` や `API key not valid` といった認証エラーが出る場合、まず環境変数を確認します。

```python
import os
from google import genai

client = genai.Client(api_key=os.environ.get("GOOGLE_API_KEY"))
```

よく見かける失敗パターンを3つ挙げます。

**① `.env` ファイルを読み込んでいない**

`.env` ファイルに `GOOGLE_API_KEY=AIzaSy...` と書いていても、`python-dotenv` で明示的に読み込まないと反映されません。

```python
from dotenv import load_dotenv
import os

load_dotenv()  # これがないと .env が無視される

api_key = os.environ.get("GOOGLE_API_KEY")
print(f"キーの先頭: {api_key[:10] if api_key else 'None'}")
```

**② APIキーに余分なスペースが混入している**

`.env` ファイルを手で書くと `GOOGLE_API_KEY= AIzaSy...` のように先頭にスペースが入ることがあります。`os.environ.get("GOOGLE_API_KEY").strip()` で除去するか、ファイルを開いて確認してください。

**③ AIStudio用キーをVertex AIに使っている**

Google AI Studioで取得したAPIキーは、Vertex AI SDK（`google-cloud-aiplatform`）では使えません。使いたいプラットフォームに合ったキーを取得しているか確認してください。詳細は[Gemini API 認証エラーの解決策まとめ](/articles/gemini-api/gemini-api-authentication-error-solutions)をご覧ください。

## 最初のAPIコールで出るエラー集

セットアップができたら、実際にAPIを呼んでみましょう。

```python
from google import genai

client = genai.Client(api_key="YOUR_GOOGLE_API_KEY")

response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="こんにちは"
)
print(response.text)
```

このシンプルなコードでもいくつかのエラーが発生することがあります。

### `models/gemini-2.5-flash is not found`

モデル名のスペルミスか、お使いのリージョンで当該モデルが未対応の場合に発生します。利用可能なモデルは次のコードで確認できます。

```python
# 利用可能なモデルを一覧表示
for model in client.models.list():
    print(model.name)
```

`gemini-2.5-flash-preview` など末尾に `-preview` が付くモデルは、時期によって名前が変わることがあります。常に最新の公式ドキュメントで名前を確認してください。

### `429 Resource Exhausted`

無料枠のレート制限に当たっています。無料プランの制限（2026年4月時点の目安）は次のとおりです。

- Gemini 2.5 Flash: 15 RPM（リクエスト/分）
- Gemini 2.5 Pro: 5 RPM

連続してAPIを呼ぶスクリプトでは、リクエスト間に待機時間を入れることで回避できます。

```python
import time

items = ["文章1", "文章2", "文章3"]

for item in items:
    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=item
    )
    print(response.text)
    time.sleep(4)  # 15 RPM = 1リクエスト/4秒
```

429エラーの詳細な対処法は[Gemini API 429エラー・クォータ制限の完全解決ガイド](/articles/gemini-api/gemini-api-quota-429-error-troubleshooting)をご参照ください。

## レスポンスの扱い方でつまずく点

### `response.text` が `None` または空になる

安全フィルターによってレスポンスがブロックされると、`response.text` は `None` になります。そのままアクセスすると `AttributeError` が発生します。

```python
response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="..."
)

# ❌ None のまま使うとエラー
print(response.text)

# ✅ 正しい書き方
if response.text:
    print(response.text)
else:
    # ブロックされた理由を確認
    for candidate in response.candidates:
        print(f"finish_reason: {candidate.finish_reason}")
```

`finish_reason` が `SAFETY` の場合は安全フィルターによるブロック、`MAX_TOKENS` の場合はトークン上限到達です。

### JSONでレスポンスを取得したいのにMarkdown形式で返ってくる

デフォルトでは、モデルはMarkdownのコードブロックで囲んだJSONを返すことがあります。構造化データが必要な場合は、`response_mime_type` を明示的に指定してください。

```python
import json
from google.genai import types

response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="東京・大阪・名古屋の人口をJSONで返して",
    config=types.GenerateContentConfig(
        response_mime_type="application/json"
    )
)

# JSON文字列として取得し、パース
data = json.loads(response.text)
print(data)
```

## Google AI Studio とコードの動作が違う

「AI Studioでは期待通りに動いたのに、コードにするとうまくいかない」——この場合の多くは、システムインストラクションの設定方法の違いです。

```python
from google.genai import types

response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="商品の説明文を書いて",
    config=types.GenerateContentConfig(
        system_instruction="あなたはプロのコピーライターです。簡潔で魅力的な文章を書いてください。",
        temperature=0.7,
        max_output_tokens=512,
    )
)
```

AI Studioの「System Prompt」欄に書いた内容は、コードでは `system_instruction` として渡す必要があります。`temperature` などのパラメータも同様に `GenerateContentConfig` の中に設定します。

## APIキーの無効化と再発行

「昨日は動いていたのに今日は認証エラーになった」という場合、APIキーが誤って無効化されていることがあります。Google AI Studio（[aistudio.google.com](https://aistudio.google.com)）にアクセスし、「Get API key」から現在のキーのステータスを確認してください。不審なアクセスがあった場合はキーを無効化して新しいものを発行し直します。
