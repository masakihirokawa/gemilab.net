ブログ運営を続けるうえで「記事を定期的に更新したい、でも執筆に時間がかかる」という悩みは多くの方が感じていることです。Gemini API と WordPress REST API を組み合わせると、記事のアイデア出しから本文生成、WordPress への下書き投稿までを Python スクリプト一本で自動化できます。

単純なテキスト生成にとどまらず、SEO を意識したタイトルや見出しの設計、メタディスクリプションの自動付与、さらには画像生成 API との連携まで視野に入れた、実践的な内容をお届けします。

## Gemini API × WordPress 連携で実現できること

Gemini API と WordPress REST API を組み合わせることで、次のような自動化が可能になります。

- **記事本文の自動生成**: キーワードやテーマを与えるだけで、構成・本文・まとめまで一括生成
- **SEO最適化コンテンツの作成**: タイトルタグ・メタディスクリプション・見出しH2/H3を自動で整形
- **下書き自動投稿**: 生成した記事を WordPress の下書き状態で自動投稿し、人間が確認してから公開
- **タグ・カテゴリの自動設定**: Gemini に内容を分析させて適切なカテゴリとタグを付与
- **定期実行との組み合わせ**: cron や GitHub Actions と組み合わせて、毎朝新しい下書きを自動作成

重要なのは「**人間がレビューしてから公開する**」というワークフローを組み込む点です。AI 生成コンテンツをそのまま公開するのではなく、下書きとして蓄積し、担当者が確認・加筆してから公開する設計にすることで、品質を担保しつつ作業コストを大幅に削減できます。

## 事前に準備するもの

システムを構築するにあたり、以下を準備してください。

- **Google AI Studio の API キー**: [Google AI Studio](https://aistudio.google.com/) から無料で取得可能
- **WordPress サイト**: WordPress.com（有料プラン）または自己ホスト型の WordPress
- **WordPress Application Password**: WordPress の管理画面 → ユーザー → プロフィールから発行
- **Python 3.10 以上**: `google-genai` と `requests` ライブラリをインストール

Python ライブラリのインストールは以下のコマンドで行います。

```bash
pip install google-genai requests python-dotenv
```

環境変数の管理には `python-dotenv` を使い、API キーをコードに直書きしないようにしましょう。プロジェクトフォルダに `.env` ファイルを作成し、以下のように記述します。

```
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
WP_URL=https://your-wordpress-site.com
WP_USERNAME=your_wp_username
WP_APP_PASSWORD=your_application_password
```

## WordPress Application Password の取得方法

WordPress REST API を使って記事を投稿するには、Application Password という認証トークンが必要です。WordPress 5.6 以降はデフォルトで利用できます。

取得手順は次の通りです。

1. WordPress 管理画面にログインする
2. 「ユーザー」→「プロフィール」を開く
3. ページ下部の「アプリケーションパスワード」セクションまでスクロール
4. アプリケーション名（例: `Gemini Auto Post`）を入力して「新しいアプリケーションパスワードを追加」をクリック
5. 表示されたパスワードを `.env` ファイルの `WP_APP_PASSWORD` に設定する

パスワードは一度しか表示されないので、必ずすぐにコピーしてください。

## ステップ1: Gemini API で記事本文を生成する

まず、Gemini API を使って記事本文を生成するモジュールを作成します。SEO に効果的な構成をプロンプトで指定するのがポイントです。

```python
# article_generator.py
import os
from google import genai
from google.genai import types
from dotenv import load_dotenv

load_dotenv()

# Gemini クライアントの初期化
client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

def generate_article(topic: str, target_keywords: list[str]) -> dict:
    """
    トピックとキーワードを受け取り、SEO最適化された記事を生成する。

    Args:
        topic: 記事のテーマ（例: "Python で始める機械学習入門"）
        target_keywords: SEO対策したいキーワードリスト

    Returns:
        title, meta_description, content, tags を含む辞書
    """
    keywords_str = "、".join(target_keywords)

    prompt = f"""
あなたはSEOに精通したブログライターです。以下のテーマとキーワードで、
検索上位を狙える高品質なブログ記事を日本語で作成してください。

テーマ: {topic}
対象キーワード: {keywords_str}

以下のJSON形式で出力してください:
{{
  "title": "記事タイトル（キーワードを含む60文字以内）",
  "meta_description": "メタディスクリプション（キーワードを含む120文字以内）",
  "content": "記事本文（マークダウン形式、2000文字以上）",
  "tags": ["タグ1", "タグ2", "タグ3"]
}}

本文の構成:
- 導入（読者の課題を共感を持って提示）
- H2見出しを4〜5個使った本文
- 具体的なコード例または手順
- よくある質問（FAQ）を3つ
- まとめ
"""

    response = client.models.generate_content(
        model="gemini-2.5-pro",
        contents=prompt,
        config=types.GenerateContentConfig(
            response_mime_type="application/json",
            temperature=0.7,
        )
    )

    import json
    article_data = json.loads(response.text)
    return article_data

# 動作確認
if __name__ == "__main__":
    result = generate_article(
        topic="Python で始める機械学習入門",
        target_keywords=["機械学習 Python", "scikit-learn 入門", "機械学習 初心者"]
    )
    print(f"タイトル: {result['title']}")
    print(f"文字数: {len(result['content'])}文字")
    # 期待する出力:
    # タイトル: Python で始める機械学習入門 — scikit-learn を使った初心者向けガイド
    # 文字数: 2500文字
```

`response_mime_type="application/json"` を指定することで、Gemini が JSON 形式で確実に返答するよう制御できます。これにより、後続の WordPress 投稿処理でパースエラーが発生しにくくなります。

## ステップ2: WordPress REST API で下書き投稿する

生成した記事を WordPress の下書きとして自動投稿するモジュールを作成します。

```python
# wp_poster.py
import os
import requests
import base64
from dotenv import load_dotenv

load_dotenv()

WP_URL = os.environ["WP_URL"]
WP_USERNAME = os.environ["WP_USERNAME"]
WP_APP_PASSWORD = os.environ["WP_APP_PASSWORD"]

def get_auth_header() -> dict:
    """WordPress REST API の認証ヘッダーを生成する"""
    credentials = f"{WP_USERNAME}:{WP_APP_PASSWORD}"
    token = base64.b64encode(credentials.encode()).decode()
    return {"Authorization": f"Basic {token}"}

def get_or_create_tags(tag_names: list[str]) -> list[int]:
    """
    タグ名のリストを受け取り、WordPress のタグIDリストを返す。
    存在しないタグは新規作成する。
    """
    tag_ids = []
    headers = get_auth_header()

    for tag_name in tag_names:
        # 既存タグを検索
        response = requests.get(
            f"{WP_URL}/wp-json/wp/v2/tags",
            params={"search": tag_name},
            headers=headers,
            timeout=10
        )
        existing_tags = response.json()

        if existing_tags:
            tag_ids.append(existing_tags[0]["id"])
        else:
            # 新規タグを作成
            create_response = requests.post(
                f"{WP_URL}/wp-json/wp/v2/tags",
                json={"name": tag_name},
                headers={**headers, "Content-Type": "application/json"},
                timeout=10
            )
            if create_response.status_code == 201:
                tag_ids.append(create_response.json()["id"])

    return tag_ids

def post_draft(title: str, content: str, meta_description: str, tags: list[str]) -> dict:
    """
    記事を WordPress に下書き投稿する。

    Returns:
        投稿結果（id, link 等を含む辞書）
    """
    tag_ids = get_or_create_tags(tags)
    headers = get_auth_header()

    post_data = {
        "title": title,
        "content": content,
        "status": "draft",          # 下書きとして保存
        "tags": tag_ids,
        "meta": {
            "_yoast_wpseo_metadesc": meta_description  # Yoast SEO 対応
        }
    }

    response = requests.post(
        f"{WP_URL}/wp-json/wp/v2/posts",
        json=post_data,
        headers={**headers, "Content-Type": "application/json"},
        timeout=30
    )

    if response.status_code == 201:
        result = response.json()
        print(f"✅ 下書き投稿完了: {result['link']}")
        return result
    else:
        print(f"❌ 投稿失敗: {response.status_code} {response.text}")
        response.raise_for_status()
```

`status: "draft"` を指定することで、生成した記事が即座に公開されることなく下書きとして保存されます。担当者が内容を確認し、必要に応じて加筆・修正してから公開する運用フローを実現できます。

## ステップ3: 記事生成と投稿を統合して実行する

ここまでのモジュールを組み合わせて、メインスクリプトを作成します。

```python
# main.py
import time
from article_generator import generate_article
from wp_poster import post_draft

# 自動生成したいテーマのリスト
TOPICS = [
    {
        "topic": "Pythonで始める機械学習入門",
        "keywords": ["機械学習 Python", "scikit-learn 使い方", "機械学習 初心者"]
    },
    {
        "topic": "Next.js 15 の App Router 完全ガイド",
        "keywords": ["Next.js App Router", "Next.js 使い方", "React Server Components"]
    },
    {
        "topic": "Docker 入門 — 環境構築から実践デプロイまで",
        "keywords": ["Docker 使い方", "コンテナ 入門", "Docker Compose"]
    }
]

def main():
    for item in TOPICS:
        print(f"\n📝 記事生成中: {item['topic']}")

        try:
            # Gemini API で記事を生成
            article = generate_article(
                topic=item["topic"],
                target_keywords=item["keywords"]
            )

            # WordPress に下書き投稿
            result = post_draft(
                title=article["title"],
                content=article["content"],
                meta_description=article["meta_description"],
                tags=article["tags"]
            )

            print(f"  タイトル: {article['title']}")
            print(f"  投稿ID: {result['id']}")
            print(f"  URL: {result['link']}")

            # API レート制限への配慮
            time.sleep(3)

        except Exception as e:
            print(f"  ❌ エラー: {e}")
            continue

    print("\n✅ 全記事の生成・投稿が完了しました")

if __name__ == "__main__":
    main()
```

このスクリプトを実行すると、リスト内の全テーマについて記事生成と下書き投稿が順番に実行されます。`time.sleep(3)` で Gemini API のレート制限に配慮しています。

Gemini API の Python 自動化についてさらに幅広い活用パターンを知りたい方には、[Gemini API Python 自動化レシピ集](/articles/gemini-api/gemini-api-python-automation-recipes) もあわせてご覧ください。

## GitHub Actions で定期自動実行する

毎日自動的に記事の下書きを生成したい場合は、GitHub Actions を使った定期実行が便利です。

```yaml
# .github/workflows/auto-blog.yml
name: Auto Blog Generation

on:
  schedule:
    - cron: "0 22 * * *"   # 毎日 JST 07:00（UTC 22:00）に実行
  workflow_dispatch:         # 手動実行も可能

jobs:
  generate-posts:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Install dependencies
        run: pip install google-genai requests python-dotenv

      - name: Run article generator
        env:
          GEMINI_API_KEY: ${{ secrets.GEMINI_API_KEY }}
          WP_URL: ${{ secrets.WP_URL }}
          WP_USERNAME: ${{ secrets.WP_USERNAME }}
          WP_APP_PASSWORD: ${{ secrets.WP_APP_PASSWORD }}
        run: python main.py
```

GitHub リポジトリの Settings → Secrets and variables → Actions から、各環境変数をシークレットとして登録しておけば、ワークフロー内で安全に参照できます。

SNS 投稿の自動化にも興味がある方は、[Gemini API × Python でSNS投稿を自動生成する方法](/articles/gemini-api/gemini-api-sns-post-automation-python) が参考になります。

## SEO を高めるプロンプト設計のコツ

Gemini に「良い記事」を生成させるためには、プロンプトの品質が重要です。特に SEO に効果的な記事を安定して生成するためのポイントをまとめます。

**検索意図を明示する**

単に「〇〇について書いて」とお願いするより、「〇〇を始めたい初心者が検索するクエリを想定して、そのニーズを解決する記事を書いて」と、読者の検索意図を明示すると精度が上がります。

**構成を詳細に指定する**

見出し数・文字数・含めるべき要素（コード例・FAQ・まとめ）を細かく指定することで、毎回一定品質の記事が生成されるようになります。

**競合記事との差別化を促す**

「既存の類似記事より具体的で実践的な内容にしてください」「実際のコード例を含めてください」といった指示を加えると、表面的な解説にならず価値のあるコンテンツになりやすいです。

**ニュアンスを調整する**

「丁寧でわかりやすい口調、技術用語は日本語で補足する」のようにトーンを指定すると、サイトのブランドに合った文体が維持されます。

## よくある質問（FAQ）

**Q1. 生成した記事を自動的に公開（`status: publish`）してもよいですか？**

技術的には可能ですが、AI 生成コンテンツをノーチェックで公開することは SEO 上のリスクがあります。Google は AI 生成コンテンツそのものを否定しているわけではありませんが、「有益で信頼できる独自情報」を重視しています。下書きで蓄積し、人間がレビューしてから公開する運用を強くおすすめします。

**Q2. WordPress.com の無料プランで REST API は使えますか？**

WordPress.com の REST API は有料プラン（Starter 以上）で利用可能です。自己ホスト型の WordPress では、バージョン 5.6 以降であれば Application Password がデフォルトで使えます。

**Q3. Gemini API の料金はどのくらいかかりますか？**

Gemini 2.5 Pro の場合、無料枠（1日あたり上限あり）を超えると従量課金が発生します。1記事あたりのトークン消費量にもよりますが、数十記事程度であれば月数百円以下に収まるケースが多いです。詳しい料金体系は [Gemini API 料金・課金体系完全ガイド](/articles/gemini-api/gemini-api-pricing-billing-complete-guide-2026) をご参照ください。
