2014年からアプリ事業を続けている個人開発者の経験から、本題に入ります。

## Gemini のマルチモーダル能力を n8n で活用する

Gemini API の特筆すべき強みの一つが、テキストだけでなく**画像・動画・音声を同時に理解できるマルチモーダル能力**です。この能力を n8n の自動化基盤と組み合わせると、これまで手作業でしか対処できなかった視覚情報の処理を自動化できます。

たとえば、次のようなワークフローが実現できます。

- ECサイトの商品画像をアップロードすると、Gemini が自動でカテゴリ・色・特徴をタグとして抽出する
- SNSに投稿された画像を監視し、ブランドガイドライン違反の可能性があるものをフラグ立てする
- フォームから送られてきたレシートや領収書の画像を Gemini が読み取り、金額・日付・項目を自動で入力する
- 定点カメラの画像を定期取得し、Gemini が変化を検知してアラートを送る

---

## 必要なもの

- n8n アカウント（n8n.cloud 無料プランでOK）
- Gemini API キー（Google AI Studio から取得）
- Google アカウント（Google Drive・Sheets 連携用）

---

## Google AI Studio で API キーを取得する

Google AI Studio（[aistudio.google.com](https://aistudio.google.com/)）は、Gemini API キーを発行できる開発者向けプラットフォームです。

1. Google AI Studio にアクセスし、Googleアカウントでサインインする
2. 左サイドバーの「**Get API key**」をクリックする
3. 「Create API key」を選択し、プロジェクトを選ぶ
4. 発行された API キー（`AIzaSy...` 形式ではなく `YOUR_GEMINI_API_KEY` として保管）を安全に保存する

> **注意**: API キーは Gemini API への認証に使用します。外部に漏洩しないよう、n8n の Credentials として管理することを強くお勧めします。

---

## n8n に Gemini API の認証情報を設定する

1. n8n の「Credentials」→「Add Credential」→「**Header Auth**」を選択する
2. 以下を入力して保存する
   - **Name**: `Gemini API`
   - **Header Name**: `x-goog-api-key`
   - **Header Value**: 取得した API キー

---

## ワークフローの全体設計

```
Google Drive Trigger（新規ファイル追加）
  ↓
HTTP Request（画像データ取得）
  ↓
Set ノード（Base64エンコード）
  ↓
HTTP Request（Gemini API マルチモーダルリクエスト）
  ↓
Set ノード（レスポンス整形）
  ↓
Google Sheets（結果を記録）
```

---

## Step 1: Google Drive Trigger を設定する

1. 「+」→「Google Drive Trigger」ノードを追加する
2. Google アカウントと連携する
3. トリガー条件を以下に設定する
   - **Event**: `File Created`
   - **Drive**: 監視したいドライブ
   - **Folder**: 画像をアップロードするフォルダ

### ポイント

監視フォルダはあらかじめ Google Drive に作成しておきます。テスト用の画像（JPEG/PNG）をここに配置することでワークフローを手動起動できます。

---

## Step 2: HTTP Request で画像データを取得する

Google Drive Trigger は画像の **ID** を返しますが、バイナリデータは含まれていません。別途 HTTP Request で画像を取得します。

```
Method: GET
URL: https://www.googleapis.com/drive/v3/files/{{ $json.id }}?alt=media
Authentication: OAuth2（Google Drive の Credential を使用）
Response Format: File
```

---

## Step 3: Set ノードで Base64 エンコードする

Gemini API のマルチモーダルリクエストでは、画像を **Base64 エンコード**して `inline_data` として送信します。

```json
{
  "imageBase64": "{{ $binary.data.data }}",
  "mimeType": "{{ $binary.data.mimeType }}"
}
```

n8n の `$binary.data.data` は既に Base64 エンコードされた状態で格納されているため、そのまま利用できます。

---

## Step 4: Gemini API にマルチモーダルリクエストを送る

いよいよ Gemini API を呼び出す核心部分です。HTTP Request ノードを以下のように設定します。

```
Method: POST
URL: https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent
Authentication: Header Auth（Gemini API Credential を使用）
Content-Type: application/json
```

**リクエストボディ（JSON）:**

```json
{
  "contents": [
    {
      "parts": [
        {
          "text": "この画像を分析し、以下の情報をJSON形式で返してください：\n1. カテゴリ（例：食品、家電、衣類など）\n2. 主な色（最大3色）\n3. 特徴的なキーワード（最大5個）\n4. 品質スコア（1〜10で評価）\n5. 簡単な説明（50文字以内）"
        },
        {
          "inline_data": {
            "mime_type": "{{ $json.mimeType }}",
            "data": "{{ $json.imageBase64 }}"
          }
        }
      ]
    }
  ],
  "generationConfig": {
    "temperature": 0.2,
    "responseMimeType": "application/json"
  }
}
```

`temperature: 0.2` に設定することで、一貫性の高い構造化された出力が得やすくなります。また `responseMimeType: "application/json"` を指定することで、Gemini が JSON を直接返すよう指示できます。

**期待されるレスポンス例:**

```json
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "text": "{\"カテゴリ\":\"食品\",\"主な色\":[\"赤\",\"緑\",\"白\"],\"キーワード\":[\"新鮮\",\"野菜\",\"サラダ\",\"ヘルシー\",\"彩り豊か\"],\"品質スコア\":8,\"説明\":\"新鮮な野菜が彩り豊かに盛り付けられたサラダの写真。\"}"
          }
        ]
      }
    }
  ]
}
```

---

## Step 5: Google Sheets に結果を記録する

1. Gemini のレスポンスからテキスト部分を取り出す

```
{{ JSON.parse($json.candidates[0].content.parts[0].text).カテゴリ }}
```

2. Google Sheets ノードを追加し、スプレッドシートのシートを指定する
3. 各列に対応するフィールドをマッピングする

## よくあるエラーと対処法（トラブルシューティング）

### エラー 1: 画像の MIME タイプエラー

**症状**: `Invalid mime type` エラーが発生する

**原因と対処**:
- Gemini API がサポートする画像形式は `image/jpeg`, `image/png`, `image/gif`, `image/webp` です
- BMP や TIFF などの形式は直接サポートされていません。Google Drive から取得した `mimeType` が対応しているか確認してください

### エラー 2: リクエストサイズ超過

**症状**: `Request entity too large` またはタイムアウトが発生する

**原因と対処**:
- 大きな画像ファイル（10MB超）を Base64 エンコードすると、リクエストサイズが制限を超える場合があります
- 事前に画像を圧縮するか、Gemini API の [File API](https://ai.google.dev/) を使った大容量ファイルのアップロード方式に切り替えてください

### エラー 3: JSON パースエラー

**症状**: Gemini のレスポンスが JSON として解析できない

**原因と対処**:
- `responseMimeType: "application/json"` が設定されていない場合、Gemini が JSON 以外のフォーマットで回答することがあります
- プロンプト内に「必ずJSON形式で返してください」と明示的に指定することも有効です
- `temperature` を低く設定（0.1〜0.3）することで安定した JSON 出力が得やすくなります

### エラー 4: 画像の内容が認識されない

**症状**: Gemini が「画像を認識できません」または空の回答を返す

**原因と対処**:
- 画像が暗すぎる、小さすぎる（32×32px未満）、または回転している可能性があります
- Base64 エンコードが正しく行われているか確認してください。n8n で `$binary.data.data` を使う場合、ノードが `Binary` 形式で画像を受け取っているか確認が必要です

### エラー 5: Google Drive の権限エラー

**症状**: `403 Forbidden` または `insufficient permissions` が出る

**原因と対処**:
- n8n の Google Drive 連携に必要な OAuth スコープ（`drive.readonly` など）が付与されているか確認してください
- n8n.cloud の場合は「Reconnect」して再認証することで解決することが多いです

## 応用：画像の品質スコアで自動振り分けをする

品質スコアが一定以下の画像を自動で別フォルダに移動したり、担当者に通知する仕組みも簡単に追加できます。

```
Gemini API レスポンス
  ↓
IF ノード: 品質スコア < 5 の場合
  ↓ YES                     ↓ NO
Slack 通知（要確認）      Google Sheets 記録
```

このように n8n の IF ノードと組み合わせることで、AI の判断を起点とした自動振り分けシステムが構築できます。マルチモーダル AI の活用についてより体系的に学びたい方には、[Python で学ぶマルチモーダルAI（山田太郎 著）](https://www.amazon.co.jp/dp/4815626677/?tag=pinocchio-22) もあわせてご覧ください。
