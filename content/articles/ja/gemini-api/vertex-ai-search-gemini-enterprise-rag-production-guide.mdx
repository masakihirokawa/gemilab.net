社内のナレッジベース、製品ドキュメント、技術仕様書——これらを検索可能にし、Gemini に「根拠を持った回答」を生成させたい。そんなニーズに応えるのが Vertex AI Search と Gemini API の Grounding 機能の組み合わせです。

Vertex AI Search は Google の検索技術を企業向けに提供するマネージドサービスです。ベクトルインデックス管理・スケーリング・ACL（アクセス制御）を担当し、Gemini はその検索結果を根拠として自然言語回答を生成します。この組み合わせにより、pgvector やカスタム Chroma サーバーを自前で運用する必要なく、エンタープライズグレードの RAG システムが実現します。

## Vertex AI Search のアーキテクチャ

Vertex AI Search は主に3種類のデータストアをサポートしています。

**非構造化データストア（Unstructured）**: PDF、Word、HTML、テキストファイルなどのドキュメントを格納し、セマンティック検索を提供します。社内マニュアルや技術文書に最適です。

**構造化データストア（Structured）**: JSON/BigQuery のような構造化データをインデックス化します。製品カタログや在庫データに使用します。

**Webサイトデータストア**: URLパターンを指定してWebサイトをクロール・インデックス化します。公開ドキュメントサイトに有効です。

## データストアの作成とドキュメント登録

### 非構造化データストアの作成

```python
from google.cloud import discoveryengine_v1 as discoveryengine

PROJECT_ID = "YOUR_PROJECT_ID"
LOCATION = "global"
DATA_STORE_ID = "company-docs-store"

def create_unstructured_datastore():
    client = discoveryengine.DataStoreServiceClient()

    parent = f"projects/{PROJECT_ID}/locations/{LOCATION}/collections/default_collection"

    data_store = discoveryengine.DataStore(
        display_name="Company Documentation Store",
        industry_vertical=discoveryengine.IndustryVertical.GENERIC,
        content_config=discoveryengine.DataStore.ContentConfig.CONTENT_REQUIRED,
        solution_types=[discoveryengine.SolutionType.SOLUTION_TYPE_SEARCH],
    )

    operation = client.create_data_store(
        parent=parent,
        data_store=data_store,
        data_store_id=DATA_STORE_ID,
    )

    result = operation.result()
    print(f"Data store created: {result.name}")
    return result.name
```

        reconciliation_mode=discoveryengine.ImportDocumentsRequest.ReconciliationMode.INCREMENTAL,
    )

    operation = client.import_documents(request=request)
    print(f"Import started: {operation.operation.name}")

    # 非同期処理の完了を待つ
    response = operation.result(timeout=600)
    print(f"Import completed: {response.operation_statistics}")
    return response

## Vertex AI Search API による検索

### セマンティック検索の実装

```python
from google.cloud import discoveryengine_v1 as discoveryengine

SEARCH_ENGINE_ID = "company-search-app"

def semantic_search(
    query: str,
    page_size: int = 5,
    filter_expr: str | None = None,
) -> list[dict]:
    """Vertex AI Search でセマンティック検索を実行する"""
    client = discoveryengine.SearchServiceClient()

    serving_config = (
        f"projects/{PROJECT_ID}/locations/{LOCATION}"
        f"/collections/default_collection"
        f"/engines/{SEARCH_ENGINE_ID}"
        f"/servingConfigs/default_config"
    )

    content_search_spec = discoveryengine.SearchRequest.ContentSearchSpec(
        snippet_spec=discoveryengine.SearchRequest.ContentSearchSpec.SnippetSpec(
            return_snippet=True,
            max_snippet_count=3,
        ),
        extractive_content_spec=discoveryengine.SearchRequest.ContentSearchSpec.ExtractiveContentSpec(
            max_extractive_answer_count=3,
            max_extractive_segment_count=5,
        ),
        summary_spec=discoveryengine.SearchRequest.ContentSearchSpec.SummarySpec(
            summary_result_count=3,
            include_citations=True,  # 引用元を含む
            ignore_adversarial_query=True,
            model_spec=discoveryengine.SearchRequest.ContentSearchSpec.SummarySpec.ModelSpec(
                version="stable",
            ),
        ),
    )

    request = discoveryengine.SearchRequest(
        serving_config=serving_config,
        query=query,
        page_size=page_size,
        content_search_spec=content_search_spec,
        filter=filter_expr,  # 例: "category = 'technical_doc'"
        query_expansion_spec=discoveryengine.SearchRequest.QueryExpansionSpec(
            condition=discoveryengine.SearchRequest.QueryExpansionSpec.Condition.AUTO,
        ),
        spell_correction_spec=discoveryengine.SearchRequest.SpellCorrectionSpec(
            mode=discoveryengine.SearchRequest.SpellCorrectionSpec.Mode.AUTO,
        ),
    )

    response = client.search(request)

    results = []
    for result in response.results:
        doc = result.document
        chunks = []

        if doc.derived_struct_data:
            # 抽出的回答の取得
            extractive_answers = doc.derived_struct_data.get("extractive_answers", [])
            extractive_segments = doc.derived_struct_data.get("extractive_segments", [])

            for answer in extractive_answers:
                chunks.append({
                    "type": "extractive_answer",
                    "content": answer.get("content", ""),
                    "page_number": answer.get("pageNumber"),
                })

            for segment in extractive_segments:
                chunks.append({
                    "type": "extractive_segment",
                    "content": segment.get("content", ""),
                    "relevance_score": segment.get("relevanceScore"),
                })

        results.append({
            "id": doc.id,
            "title": doc.derived_struct_data.get("title", "") if doc.derived_struct_data else "",
            "link": doc.derived_struct_data.get("link", "") if doc.derived_struct_data else "",
            "chunks": chunks,
            "relevance_score": result.relevance_score,
        })

    # サマリーの取得
    summary_text = ""
    if hasattr(response, "summary") and response.summary:
        summary_text = response.summary.summary_text

    return results, summary_text
```

## Gemini API の Grounding with Vertex AI Search

Gemini の Grounding 機能を使うと、Vertex AI Search の検索結果を根拠として Gemini が自動的に参照し、幻覚を抑えた回答を生成します。

```python
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")

def generate_grounded_answer(
    query: str,
    use_vertex_search: bool = True,
) -> dict:
    """
    Vertex AI Search をグラウンディングソースとして Gemini で回答を生成する
    """
    model = genai.GenerativeModel("gemini-2.5-flash")

    if use_vertex_search:
        # Vertex AI Search をグラウンディングソースとして設定
        grounding_source = genai.types.Tool(
            retrieval=genai.types.Retrieval(
                vertex_ai_search=genai.types.VertexAISearch(
                    datastore=f"projects/{PROJECT_ID}/locations/{LOCATION}"
                             f"/collections/default_collection"
                             f"/dataStores/{DATA_STORE_ID}",
                )
            )
        )

        response = model.generate_content(
            query,
            tools=[grounding_source],
            generation_config=genai.types.GenerationConfig(
                temperature=0.2,  # 低温度で事実ベースの回答を促す
            )
        )
    else:
        response = model.generate_content(query)

    # グラウンディング情報の取得
    grounding_chunks = []
    if response.candidates[0].grounding_metadata:
        metadata = response.candidates[0].grounding_metadata
        for chunk in metadata.grounding_chunks:
            if chunk.retrieved_context:
                grounding_chunks.append({
                    "title": chunk.retrieved_context.title,
                    "uri": chunk.retrieved_context.uri,
                    "text": chunk.retrieved_context.text,
                })

    return {
        "answer": response.text,
        "grounding_sources": grounding_chunks,
        "is_grounded": len(grounding_chunks) > 0,
    }
```

### 手動 RAG パイプライン（細かい制御が必要な場合）

Grounding の自動化ではなく、より細かい制御が必要な場合は手動でRAGを実装します。

```python
def manual_rag_pipeline(
    user_query: str,
    conversation_history: list[dict] = None,
) -> dict:
    """
    手動RAGパイプライン:
    1. Vertex AI Search で関連チャンクを取得
    2. Gemini に検索結果をコンテキストとして渡して回答を生成
    """
    # Step 1: 検索
    search_results, search_summary = semantic_search(
        query=user_query,
        page_size=5,
    )

    # Step 2: コンテキストの構築
    context_parts = []
    for i, result in enumerate(search_results, 1):
        if result["chunks"]:
            top_chunk = result["chunks"][0]
            context_parts.append(
                f"[文書{i}: {result['title']}]\n{top_chunk['content']}"
            )

    context = "\n\n".join(context_parts)

    # Step 3: Gemini でのプロンプト設計
    system_prompt = """あなたは社内ナレッジベースのアシスタントです。
提供されたコンテキストに基づいて回答してください。
コンテキストに情報がない場合は「その情報はドキュメントに見当たりません」と正直に伝えてください。
回答には必ず情報源（文書名）を引用してください。"""

    user_message = f"""コンテキスト:
{context}

質問: {user_query}"""

    model = genai.GenerativeModel(
        "gemini-2.5-flash",
        system_instruction=system_prompt,
    )

    messages = []
    if conversation_history:
        messages.extend(conversation_history)
    messages.append({"role": "user", "parts": [user_message]})

    response = model.generate_content(messages)

    return {
        "answer": response.text,
        "sources": [
            {"title": r["title"], "link": r["link"]}
            for r in search_results[:3]
        ],
        "search_summary": search_summary,
    }
```

## アクセス制御と ACL の設定

エンタープライズ環境では、ユーザーに応じた文書アクセス制御が必要です。

```python
def search_with_access_control(
    query: str,
    user_email: str,
    user_groups: list[str],
) -> list[dict]:
    """
    ユーザーのロールに基づいてフィルタリングされた検索を実行する
    """
    # アクセス可能な文書カテゴリを取得（例: Firestore から）
    accessible_categories = get_user_accessible_categories(
        user_email, user_groups
    )

    # Vertex AI Search のフィルター式を構築
    if accessible_categories:
        filter_expr = " OR ".join(
            [f'category = "{cat}"' for cat in accessible_categories]
        )
    else:
        return []  # アクセス権なし

    results, summary = semantic_search(
        query=query,
        filter_expr=filter_expr,
    )

    return results
```

## レスポンスキャッシュとパフォーマンス最適化

```python
import hashlib
import json
from functools import lru_cache
import time

# インメモリキャッシュ（本番では Redis を推奨）
_cache: dict[str, dict] = {}
CACHE_TTL = 3600  # 1時間

def cached_search(query: str, filter_expr: str | None = None) -> dict:
    cache_key = hashlib.md5(
        f"{query}:{filter_expr}".encode()
    ).hexdigest()

    # キャッシュヒット確認
    if cache_key in _cache:
        cached = _cache[cache_key]
        if time.time() - cached["timestamp"] < CACHE_TTL:
            return cached["data"]

    # 検索実行
    results, summary = semantic_search(query, filter_expr=filter_expr)
    response = manual_rag_pipeline(query)

    data = {
        "results": results,
        "summary": summary,
        "answer": response["answer"],
        "sources": response["sources"],
    }

    _cache[cache_key] = {"data": data, "timestamp": time.time()}
    return data
```

## まとめ：エンタープライズ RAG の実践

Vertex AI Search × Gemini API の組み合わせは、RAGシステムの運用負担を大幅に削減します。ベクトルDBの管理・スケーリング・バックアップを Google が担当し、開発チームはアプリケーションロジックに集中できます。

Grounding 機能を使えば、Gemini が自動的に Vertex AI Search を参照するため、最も速くシステムを構築できます。より細かい制御が必要な場合は本記事の手動RAGパイプラインを参考にしてください。
