PHPは世界中のWebアプリケーションで広く利用されており、WordPressをはじめ、LaravelやSymfonyといったフレームワークで多くのサービスが動いています。そのPHP製アプリケーションにGemini APIを組み込むことで、AIチャット機能や文章生成、コンテンツ要約などを手軽に実現できます。

この記事では、Laravelフレームワークを使ってGemini APIとの連携を段階的に実装する方法を、動作するコード例とともに解説します。「PHPでもGemini APIを使えるの？」と疑問に思っている方にとって、具体的な答えが見つかるはずです。

## 必要な環境と事前準備

まず、開発環境を整えましょう。以下のものが必要です。

- PHP 8.2以上
- Composer（PHPのパッケージマネージャー）
- Laravel 11.x
- Gemini APIキー（[Google AI Studio](https://aistudio.google.com/)で無料取得可能）

Laravelプロジェクトがまだない場合は、以下のコマンドで新規作成します。

```bash
# Laravelプロジェクトを新規作成
composer create-project laravel/laravel gemini-chat-app
cd gemini-chat-app

# 環境変数ファイルを準備
cp .env.example .env
php artisan key:generate
```

次に、`.env`ファイルにGemini APIキーを追加します。

```dotenv
# .env に追加
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
GEMINI_MODEL=gemini-2.5-flash
```

## GeminiServiceクラスの作成

Laravelではサービスクラスを作ってAPIロジックをカプセル化するのがベストプラクティスです。`app/Services/GeminiService.php`を作成しましょう。

```php
<?php
// app/Services/GeminiService.php

namespace App\Services;

use Illuminate\Support\Facades\Http;
use Illuminate\Support\Facades\Log;

class GeminiService
{
    private string $apiKey;
    private string $model;
    private string $baseUrl = 'https://generativelanguage.googleapis.com/v1beta';

    public function __construct()
    {
        $this->apiKey = config('services.gemini.api_key');
        $this->model  = config('services.gemini.model', 'gemini-2.5-flash');
    }

    /**
     * テキストを生成して返す（非ストリーミング）
     */
    public function generateText(string $prompt, array $options = []): string
    {
        $url = "{$this->baseUrl}/models/{$this->model}:generateContent?key={$this->apiKey}";

        $body = [
            'contents' => [
                [
                    'parts' => [['text' => $prompt]],
                ],
            ],
        ];

        // システムインストラクションがあれば追加
        if (!empty($options['system_instruction'])) {
            $body['systemInstruction'] = [
                'parts' => [['text' => $options['system_instruction']]],
            ];
        }

        // 生成パラメータの設定
        if (!empty($options['temperature']) || !empty($options['max_tokens'])) {
            $body['generationConfig'] = [
                'temperature'    => $options['temperature'] ?? 0.7,
                'maxOutputTokens'=> $options['max_tokens'] ?? 2048,
            ];
        }

        try {
            $response = Http::timeout(30)
                ->post($url, $body);

            if ($response->failed()) {
                Log::error('Gemini API error', [
                    'status' => $response->status(),
                    'body'   => $response->body(),
                ]);
                throw new \RuntimeException('Gemini API request failed: ' . $response->status());
            }

            $data = $response->json();

            // レスポンスからテキストを抽出
            return $data['candidates'][0]['content']['parts'][0]['text'] ?? '';

        } catch (\Exception $e) {
            Log::error('GeminiService error', ['message' => $e->getMessage()]);
            throw $e;
        }
    }

    /**
     * マルチターン会話（チャット履歴付き）
     */
    public function chat(array $history, string $userMessage, string $systemInstruction = ''): string
    {
        $url = "{$this->baseUrl}/models/{$this->model}:generateContent?key={$this->apiKey}";

        // 会話履歴を構築
        $contents = [];
        foreach ($history as $turn) {
            $contents[] = [
                'role'  => $turn['role'], // 'user' または 'model'
                'parts' => [['text' => $turn['content']]],
            ];
        }

        // 新しいユーザーメッセージを追加
        $contents[] = [
            'role'  => 'user',
            'parts' => [['text' => $userMessage]],
        ];

        $body = ['contents' => $contents];

        if ($systemInstruction) {
            $body['systemInstruction'] = [
                'parts' => [['text' => $systemInstruction]],
            ];
        }

        $response = Http::timeout(30)->post($url, $body);

        if ($response->failed()) {
            throw new \RuntimeException('Chat API error: ' . $response->status());
        }

        $data = $response->json();
        return $data['candidates'][0]['content']['parts'][0]['text'] ?? '';
    }
}
```

```php
    'api_key' => env('GEMINI_API_KEY'),

```

## サービスプロバイダへの登録

Laravel のサービスコンテナにGeminiServiceを登録することで、依存注入が使えるようになります。`app/Providers/AppServiceProvider.php`を更新します。

```php
<?php
// app/Providers/AppServiceProvider.php

namespace App\Providers;

use App\Services\GeminiService;
use Illuminate\Support\ServiceProvider;

class AppServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        // シングルトンとして登録（インスタンスを使い回す）
        $this->app->singleton(GeminiService::class, function ($app) {
            return new GeminiService();
        });
    }

    public function boot(): void
    {
        //
    }
}
```

## コントローラーの作成

チャット機能を処理するコントローラーを作成します。

```bash
php artisan make:controller ChatController
```

```php
<?php
// app/Http/Controllers/ChatController.php

namespace App\Http\Controllers;

use App\Services\GeminiService;
use Illuminate\Http\Request;
use Illuminate\Http\JsonResponse;

class ChatController extends Controller
{
    public function __construct(private readonly GeminiService $geminiService)
    {
        // GeminiServiceを依存注入で受け取る
    }

    /**
     * チャット画面を表示
     */
    public function index()
    {
        return view('chat.index');
    }

    /**
     * メッセージを送信してAIの返答を取得
     */
    public function send(Request $request): JsonResponse
    {
        $request->validate([
            'message' => 'required|string|max:4000',
            'history' => 'array',
        ]);

        $userMessage = $request->input('message');
        $history     = $request->input('history', []);

        // システムインストラクションで応答スタイルを定義
        $systemInstruction = 'あなたは親切で知識豊富なAIアシスタントです。'
            . '質問に対して正確かつ分かりやすく日本語で回答してください。'
            . 'コードの質問には動作するサンプルコードを添えて説明してください。';

        try {
            $reply = $this->geminiService->chat($history, $userMessage, $systemInstruction);

            return response()->json([
                'success' => true,
                'reply'   => $reply,
                'role'    => 'model',
            ]);

        } catch (\RuntimeException $e) {
            return response()->json([
                'success' => false,
                'error'   => 'AIとの通信に失敗しました。しばらくしてから再試行してください。',
            ], 503);
        }
    }

    /**
     * テキスト要約エンドポイント
     */
    public function summarize(Request $request): JsonResponse
    {
        $request->validate([
            'text'   => 'required|string|max:10000',
            'length' => 'in:short,medium,long',
        ]);

        $text   = $request->input('text');
        $length = $request->input('length', 'medium');

        $lengthInstruction = match($length) {
            'short'  => '3文以内で',
            'long'   => '詳しく（500文字程度で）',
            default  => '5〜8文で',
        };

        $prompt = "以下のテキストを{$lengthInstruction}要約してください。\n\n---\n{$text}\n---";

        try {
            $summary = $this->geminiService->generateText($prompt, [
                'temperature' => 0.3, // 要約は低めの温度で一貫性を保つ
                'max_tokens'  => 1024,
            ]);

            return response()->json([
                'success' => true,
                'summary' => $summary,
            ]);

        } catch (\Exception $e) {
            return response()->json([
                'success' => false,
                'error'   => '要約処理に失敗しました。',
            ], 500);
        }
    }
}
```

```html
    <div id="chat-container">
        <div class="message model">こんにちは！何でもご質問ください。</div>
    </div>

    <div id="input-area">
        <form id="input-form">
            <textarea id="user-input" placeholder="メッセージを入力..." rows="2"></textarea>
            <button type="submit" id="send-btn">送信</button>

    <script>
        const chatContainer = document.getElementById('chat-container');
        const inputForm     = document.getElementById('input-form');
        const userInput     = document.getElementById('user-input');
        const sendBtn       = document.getElementById('send-btn');
        const csrfToken     = document.querySelector('meta[name="csrf-token"]').getAttribute('content');

        // 会話履歴を保持
        let history = [];

        function addMessage(text, role) {
            const div = document.createElement('div');
            div.className = `message ${role}`;
            div.textContent = text;
            chatContainer.appendChild(div);
            chatContainer.scrollTop = chatContainer.scrollHeight;
        }

        inputForm.addEventListener('submit', async (e) => {
            e.preventDefault();
            const message = userInput.value.trim();
            if (!message) return;

            addMessage(message, 'user');
            userInput.value = '';
            sendBtn.disabled = true;
            sendBtn.textContent = '送信中...';

            try {
                const res = await fetch('{{ route("chat.send") }}', {
                    method: 'POST',
                    headers: {
                        'Content-Type': 'application/json',
                        'X-CSRF-TOKEN': csrfToken,
                        'Accept': 'application/json',
                    },
                    body: JSON.stringify({ message, history }),
                });

                const data = await res.json();

                if (data.success) {
                    addMessage(data.reply, 'model');
                    // 会話履歴を更新
                    history.push({ role: 'user',  content: message    });
                    history.push({ role: 'model', content: data.reply });
                    // 履歴が長くなりすぎないよう最新20ターンに制限
                    if (history.length > 40) history = history.slice(-40);
                } else {
                    addMessage('エラーが発生しました: ' + data.error, 'model');
                }
            } catch (err) {
                addMessage('通信エラーが発生しました。', 'model');
            } finally {
                sendBtn.disabled = false;
                sendBtn.textContent = '送信';
            }
        });

        // Enterで送信（Shift+Enterは改行）
        userInput.addEventListener('keydown', (e) => {
            if (e.key === 'Enter' && !e.shiftKey) {
                e.preventDefault();
                inputForm.dispatchEvent(new Event('submit'));
            }
        });
    </script>
</body>
</html>
```

## レート制限とエラーハンドリングの強化

本番環境では、APIの呼び出し頻度を制限してコストを管理することが重要です。Laravelのスロットリング機能を活用しましょう。

```php
// routes/web.php に追加（スロットリング）
use Illuminate\Cache\RateLimiting\Limit;
use Illuminate\Support\Facades\RateLimiter;

// AppServiceProvider の boot() または RouteServiceProvider に追加
RateLimiter::for('gemini-api', function (Request $request) {
    return Limit::perMinute(10)->by($request->user()?->id ?? $request->ip());
});

// ルートにミドルウェアを適用
Route::post('/send', [ChatController::class, 'send'])
    ->name('chat.send')
    ->middleware('throttle:gemini-api');
```

また、Gemini APIのレート制限エラー（429）に対応するリトライロジックも実装しておくと安心です。

```php
// GeminiService.php のgenerateTextメソッドを拡張
private function requestWithRetry(string $url, array $body, int $maxRetries = 3): array
{
    $attempt = 0;
    while ($attempt < $maxRetries) {
        $response = Http::timeout(30)->post($url, $body);

        if ($response->status() === 429) {
            // レート制限: 指数バックオフで再試行
            $waitSeconds = pow(2, $attempt);
            sleep($waitSeconds);
            $attempt++;
            continue;
        }

        if ($response->failed()) {
            throw new \RuntimeException("API request failed: {$response->status()}");
        }

        return $response->json();
    }

    throw new \RuntimeException('Max retries exceeded. Please try again later.');
}
```

Gemini APIのコスト最適化については、[Gemini APIコスト完全最適化ガイド](/articles/gemini-api/gemini-api-cost-optimization-complete-guide)も参考になります。

```php
<?php
// tests/Unit/GeminiServiceTest.php

use App\Services\GeminiService;
use Illuminate\Support\Facades\Http;

test('generateText returns text on success', function () {
    // HTTPリクエストをフェイクに差し替え
    Http::fake([
        'generativelanguage.googleapis.com/*' => Http::response([
            'candidates' => [[
                'content' => [
                    'parts' => [['text' => 'テスト応答テキスト']],
                ],
            ]],
        ], 200),
    ]);

    $service = new GeminiService();
    $result  = $service->generateText('テスト質問');

    expect($result)->toBe('テスト応答テキスト');
});

test('generateText throws on API error', function () {
    Http::fake([
        'generativelanguage.googleapis.com/*' => Http::response([], 500),
    ]);

    $service = new GeminiService();

    expect(fn() => $service->generateText('テスト'))
        ->toThrow(\RuntimeException::class);
});
```

## FAQ

### Q1. Gemini APIの公式PHPライブラリはありますか？

現時点（2026年4月）では、Google製の公式PHP SDKはありません。ただし、Gemini APIはRESTベースなので、LaravelのHTTPクライアント（GuzzleラッパーのHttp::）で直接呼び出すことができます。コミュニティ製のパッケージも存在しますが、公式SDKの安定性には及ばないため、この記事のようにHTTPクライアントを直接使うアプローチが信頼性の面でも推奨されます。

### Q2. ストリーミングレスポンスはPHPで実装できますか？

PHPとLaravelでもストリーミングは可能です。`StreamedResponse`を使って`text/event-stream`形式でレスポンスを返し、フロントエンドで`EventSource`や`fetch`のストリーム読み取りで受け取る実装ができます。ただし、PHPのデフォルト設定ではバッファリングが有効なため、`ob_flush()`や`flush()`を適切に呼び出す必要があります。

### Q3. 会話履歴はどこに保存するのがベストですか？

短時間のセッションであればLaravelのセッション（デフォルトはファイルまたはCookie）で十分です。長期保存やマルチデバイス対応が必要な場合は、MySQLなどのデータベースに`conversations`テーブルを作成して保存するのがベストプラクティスです。Redisを使えば高速なキャッシュとしても機能します。
