## はじめに：AI ニュースレターを自動化するメリット

毎朝、特定テーマのニュースをまとめて読みたい——そんなニーズは多くのエンジニアや個人開発者が抱えています。しかし、手動でキュレーションして文章にまとめ、メールを送るのは非常に手間がかかります。

Gemini API の **Grounding with Google Search** 機能を使えば、最新の Web 情報をリアルタイムで取得し、Gemini の高い文章生成能力でわかりやすいニュースレターへと編集できます。さらに Gmail API と Cloud Scheduler を組み合わせることで、毎朝決まった時間に自動配信するパーソナル AI ニュースレターを完全無人で運用できます。

この記事では以下を学べます。

- Gemini API の Grounding 機能で最新情報を自動収集する方法
- Gemini でニュースを要約・編集してニュースレター形式に整形する方法
- Gmail API でメールを自動送信する方法
- Cloud Scheduler で毎日定時実行するスケジューリングの設定方法

**対象読者**: Python の基礎知識がある方、Gemini API を活用した実践的な自動化システムを構築したい方

## システム構成の概要

今回構築するシステムの全体像を整理しておきましょう。

処理の流れは次の通りです。

1. **Cloud Scheduler** が毎朝 7:00 に Cloud Run（または自サーバー）のエンドポイントをトリガー
2. **Python スクリプト**が起動し、Gemini API に対して Grounding 付きのリクエストを送信
3. **Gemini API（Grounding）** が Google 検索結果を参照しながら、指定テーマの最新ニュースを取得・要約
4. 取得した内容を HTML メール形式に整形
5. **Gmail API** を使って購読者リストへ自動送信

使用する主なコンポーネントは次の通りです。

- `google-generativeai`（Gemini Python SDK）
- `google-auth-oauthlib`（Gmail API 認証）
- `googleapiclient`（Gmail API クライアント）
- Cloud Run または任意の Python 実行環境
- Cloud Scheduler（スケジューリング）

## Step 2: Grounding でテーマ別ニュースを収集する

Gemini API の Grounding with Google Search 機能を使うと、モデルがリアルタイムで Google 検索を行い、最新情報に基づいた回答を生成できます。これがニュース収集の核心部分です。

```python
import os
import google.generativeai as genai

# Gemini APIの初期化
genai.configure(api_key=os.environ["GEMINI_API_KEY"])

def fetch_news_summary(topic: str) -> str:
    """
    指定テーマのニュースをGroundingで取得し、要約を返す。
    topic: 例 "Google Gemini AI 最新ニュース 2026"
    """
    model = genai.GenerativeModel(
        model_name="gemini-2.5-flash",
        tools="google_search_retrieval",  # Grounding有効化
    )

    prompt = f"""
    以下のテーマに関する最新ニュースを3〜5件収集し、
    ニュースレター向けに日本語でわかりやすく要約してください。

    テーマ: {topic}

    各ニュースについて以下の形式で出力してください:
    - タイトル: （ニュースのタイトル）
    - 要約: （100〜150文字程度の概要）
    - 重要度: （高・中・低）

    最後に「今週のポイント」として全体の傾向を2〜3文でまとめてください。
    """

    response = model.generate_content(prompt)
    return response.text

# 複数テーマで収集
topics = [
    "Google Gemini AI 最新アップデート 2026",
    "生成AI 個人開発 活用事例",
    "AIツール 副業 収益化 2026",
]

news_sections = []
for topic in topics:
    summary = fetch_news_summary(topic)
    news_sections.append({"topic": topic, "content": summary})
    print(f"✅ '{topic}' の収集完了")
```

`tools="google_search_retrieval"` を指定するだけで Grounding が有効になります。モデルは Google 検索を実行しながら最新情報を反映した回答を生成するため、トレーニングデータのカットオフ以降の情報も取得できます。

## Step 3: Gemini でニュースレター形式に整形する

収集したニュースをニュースレターとしてまとめる整形処理を行います。ここでは別途 Grounding なしの Gemini を使い、コンテンツの編集・HTMLフォーマット化を担当させます。

```python
def format_newsletter_html(sections: list, date_str: str) -> str:
    """
    収集したニュースセクションをHTML形式のニュースレターに整形する。
    sections: [{"topic": str, "content": str}, ...]
    date_str: 例 "2026年4月3日"
    """
    model = genai.GenerativeModel("gemini-2.5-flash")

    # セクション内容を結合
    combined = "\n\n".join(
        [f"【{s['topic']}】\n{s['content']}" for s in sections]
    )

    prompt = f"""
    以下のニュース要約を、読みやすいHTMLメール形式に変換してください。

    要件:
    - シンプルで読みやすいHTMLを出力する
    - 各セクションは<h2>タグで区切る
    - 重要なキーワードは<strong>タグで強調
    - 最後に簡潔な締めくくりコメントを添える
    - <html>〜</html>の完全なHTML文書として出力する

    配信日: {date_str}

    --- ニュース内容 ---
    {combined}
    """

    response = model.generate_content(prompt)
    return response.text

from datetime import datetime

date_str = datetime.now().strftime("%Y年%-m月%-d日")
html_body = format_newsletter_html(news_sections, date_str)
print("✅ HTMLニュースレター生成完了")
```

Grounding ありのモデルは情報収集に、Grounding なしのモデルは文章整形・フォーマット変換に使い分けることで、コストを抑えながら品質を保てます。より詳しいコスト管理の実践については、[Gemini API コスト完全最適化ガイド](/articles/gemini-api/gemini-api-cost-optimization-complete-guide) もご参照ください。

## Step 4: Gmail API でメールを自動送信する

整形した HTML ニュースレターを Gmail API 経由で送信します。

```python
import base64
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from google.auth.transport.requests import Request
from google.oauth2.credentials import Credentials
from google_auth_oauthlib.flow import InstalledAppFlow
from googleapiclient.discovery import build

SCOPES = ["https://www.googleapis.com/auth/gmail.send"]

def get_gmail_service():
    """Gmail API サービスオブジェクトを取得する"""
    creds = None
    if os.path.exists("token.json"):
        creds = Credentials.from_authorized_user_file("token.json", SCOPES)
    if not creds or not creds.valid:
        if creds and creds.expired and creds.refresh_token:
            creds.refresh(Request())
        else:
            flow = InstalledAppFlow.from_client_secrets_file(
                "credentials.json", SCOPES
            )
            creds = flow.run_local_server(port=0)
        with open("token.json", "w") as token:
            token.write(creds.to_json())
    return build("gmail", "v1", credentials=creds)

def send_newsletter(service, to: str, subject: str, html_body: str) -> dict:
    """HTMLニュースレターをGmail APIで送信する"""
    message = MIMEMultipart("alternative")
    message["Subject"] = subject
    message["To"] = to

    # HTMLパートを追加
    html_part = MIMEText(html_body, "html", "utf-8")
    message.attach(html_part)

    # Base64エンコード
    raw = base64.urlsafe_b64encode(message.as_bytes()).decode()
    result = service.users().messages().send(
        userId="me",
        body={"raw": raw}
    ).execute()

    return result

# 送信実行
service = get_gmail_service()
subscribers = ["subscriber1@example.com", "subscriber2@example.com"]
subject = f"AI Daily Digest — {date_str}"

for email in subscribers:
    result = send_newsletter(service, email, subject, html_body)
    print(f"✅ 送信完了: {email} (Message ID: {result['id']})")
```

**注意点**: 初回実行時はブラウザでの OAuth 認証フローが必要です。Cloud Run などサーバー環境では、`token.json` を安全な場所（Secret Manager など）に保存・読み込みする仕組みが必要になります。本番環境でのシークレット管理については、[Gemini API 本番環境セキュリティ完全ガイド](/articles/gemini-api/gemini-api-production-security-guide) が参考になります。

## Step 5: Cloud Scheduler でスケジューリングする

毎朝自動実行するためのスケジューリング設定を行います。まずスクリプトを Cloud Run にデプロイし、HTTP エンドポイントを作成します。

```python
# main.py（Cloud Run 用エントリポイント）
import functions_framework
from newsletter import run_newsletter_pipeline  # 上記関数をまとめたモジュール

@functions_framework.http
def trigger_newsletter(request):
    """Cloud Scheduler からのリクエストを受けてニュースレターを実行する"""
    try:
        run_newsletter_pipeline()
        return {"status": "success"}, 200
    except Exception as e:
        print(f"エラー: {e}")
        return {"status": "error", "message": str(e)}, 500
```

次に Cloud Scheduler でジョブを作成します。

```bash
# Cloud Schedulerジョブの作成（毎朝7時 JST）
gcloud scheduler jobs create http gemini-newsletter-job \
  --location=asia-northeast1 \
  --schedule="0 7 * * *" \
  --time-zone="Asia/Tokyo" \
  --uri="https://YOUR_CLOUD_RUN_URL/trigger" \
  --http-method=GET \
  --attempt-deadline=600s

# ジョブの確認
gcloud scheduler jobs list --location=asia-northeast1
```

これで毎朝 7:00 JST に自動的にニュースレターが生成・配信されるようになります。

## よくある質問（FAQ）

**Q1. Grounding は無料で使えますか？**

Gemini API の Grounding with Google Search は、API 呼び出し回数に応じた従量課金です。無料枠の範囲内でも利用可能ですが、Grounding を有効にした場合は通常の API 呼び出しに加えて Google 検索コストが発生します。少量のテスト利用なら無料枠で十分まかなえます。料金の詳細は Google AI Studio の価格ページをご確認ください。

**Q2. 購読者数が増えた場合、Gmail API の送信制限は大丈夫ですか？**

Gmail API には 1 日あたりの送信数制限（無料 Gmail アカウントは約 500 通/日）があります。購読者数が多い場合は SendGrid や Mailgun などのトランザクションメールサービスの利用を検討してください。これらのサービスは Python SDK が充実しており、Gmail API から移行しやすい設計になっています。

**Q3. Grounding なしで静的なコンテンツを定期配信することもできますか？**

もちろん可能です。Grounding を外して、固定のプロンプト（例：「Gemini APIの使い方 初級チュートリアル」）を渡すだけで、モデルのトレーニング知識に基づく記事を生成できます。技術チュートリアルの定期配信や、社内向けナレッジシェアなどの用途にも活用できます。
