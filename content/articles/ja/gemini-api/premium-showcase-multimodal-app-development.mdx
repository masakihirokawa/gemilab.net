## はじめに

Google Geminiのマルチモーダル能力は、テキスト・画像・動画・音声を統一的に処理できる唯一のAI APIです。しかし「マルチモーダル対応」は単に複数モダリティを入力できるだけでなく、**各モダリティの特性を理解し、効率的に統合処理する設計**が必須です。


## Gemini APIのマルチモーダル能力

### 対応モダリティと仕様

```
Gemini Vision API
├─ テキスト入力 (Text)
│  └─ 最大 context_window トークン
│
├─ 画像入力 (Image)
│  ├─ JPEG / PNG / WebP / GIF
│  ├─ 最大 4.2MB（1画像）
│  ├─ 複数画像対応（最大 16枚推奨）
│  └─ 空間関係も理解可能
│
├─ 動画入力 (Video)
│  ├─ MP4 / WebM / MOV 等
│  ├─ 最大 2時間のビデオ処理
│  ├─ フレーム単位での分析可能
│  └─ オーディオトラックも同時処理
│
└─ 音声入力 (Audio)
   ├─ WAV / MP3 / FLAC 等
   ├─ 最大 25 MB（約 1時間）
   └─ 日本語含む 95言語対応
```

## 実装パターン1: 画像理解ベースの アプリケーション

レシート認識・商品検出・ドキュメント分析などが該当します。

### ユースケース: ECサイトの自動商品カテゴリ分類

```python
from google.generativeai import GenerativeModel
from PIL import Image
import base64

class ProductCategoryClassifier:
    def __init__(self):
        self.model = GenerativeModel('gemini-2.0-flash')
    
    def classify_product(self, image_path):
        """
        商品画像を自動分類
        入力: 商品画像ファイルパス
        出力: カテゴリ + サブカテゴリ + 信頼度スコア
        """
        
        # Step 1: 画像を base64 エンコード
        with open(image_path, 'rb') as f:
            image_data = base64.standard_b64encode(f.read()).decode('utf-8')
        
        # Step 2: Gemini に送信
        prompt = """
        この商品画像を分析してください。
        
        以下の形式で回答してください：
        - メインカテゴリ: [カテゴリ名]
        - サブカテゴリ: [サブカテゴリ]
        - 商品タイプ: [具体的な商品名]
        - 信頼度: [0.0-1.0]
        - 視覚的特徴: [画像から読み取った特徴]
        - 推奨タグ: [SEO用タグ3〜5個]
        """
        
        response = self.model.generate_content(
            contents=[
                {"type": "text", "text": prompt},
                {
                    "type": "image",
                    "image": {
                        "mime_type": "image/jpeg",
                        "data": image_data
                    }
                }
            ]
        )
        
        # Step 3: 結果をパース
        return self._parse_classification(response.text)
    
    def _parse_classification(self, response_text):
        # 応答テキストから構造化データを抽出
        import re
        result = {}
        
        patterns = {
            'main_category': r'メインカテゴリ:\s*(.+)',
            'sub_category': r'サブカテゴリ:\s*(.+)',
            'product_type': r'商品タイプ:\s*(.+)',
            'confidence': r'信頼度:\s*([\d.]+)'
        }
        
        for key, pattern in patterns.items():
            match = re.search(pattern, response_text)
            if match:
                result[key] = match.group(1).strip()
        
        return result
```

```python
class OptimizedProductClassifier:
    def __init__(self):
        self.model = GenerativeModel('gemini-2.0-flash')
        self.cache_ttl = 3600  # 1時間
        self.classification_cache = {}
    
    def classify_batch(self, image_paths, batch_size=10):
        """
        複数の商品画像を効率的に分類
        
        最適化ポイント:
        1. バッチ処理で API 呼び出し削減
        2. キャッシング で重複計算を防止
        3. 並列処理で 処理時間短縮
        """
        
        import concurrent.futures
        from functools import lru_cache
        
        # キャッシュ付き分類関数
        @lru_cache(maxsize=1000)
        def classify_single(image_hash):
            return self.classify_product(image_hash)
        
        results = []
        with concurrent.futures.ThreadPoolExecutor(max_workers=5) as executor:
            futures = [
                executor.submit(classify_single, path) 
                for path in image_paths
            ]
            results = [f.result() for f in futures]
        
        return results
```

```python
class VideoAnomalyDetector:
    def __init__(self):
        self.model = GenerativeModel('gemini-2.0-flash')
    
    def analyze_surveillance_video(self, video_path, timestamps=None):
        """
        監視カメラ映像を分析して異常を検出
        
        入力:
        - video_path: ビデオファイルパス
        - timestamps: 分析対象タイムスタンプ (Optional)
        
        出力:
        - 異常検出結果
        - 時刻
        - 異常レベル (LOW / MEDIUM / HIGH)
        - 説明
        """
        
        prompt = """
        このセキュリティビデオを分析してください。
        
        以下の異常パターンを検出してください：
        1. 不正侵入（エリア外への人物侵入）
        2. 不審な行動（長時間停止、異常な動き）
        3. 物品の盗難リスク（荷物の持ち出し）
        4. 暴力的行為の予兆
        5. その他の異常
        
        各異常について：
        - 発生時刻（hh:mm:ss）
        - 異常レベル（LOW / MEDIUM / HIGH）
        - 根拠となる視覚情報
        - 推奨対応
        
        JSON形式で回答してください。
        """
        
        with open(video_path, 'rb') as f:
            video_data = f.read()
        
        response = self.model.generate_content(
            contents=[
                {"type": "text", "text": prompt},
                {
                    "type": "video",
                    "video": {
                        "mime_type": "video/mp4",
                        "data": video_data
                    }
                }
            ]
        )
        
        return self._parse_anomalies(response.text)
    
    def _parse_anomalies(self, response_text):
        import json
        try:
            # 応答から JSON ブロックを抽出
            json_match = re.search(r'```json\n(.+?)\n```', response_text, re.DOTALL)
            if json_match:
                return json.loads(json_match.group(1))
        except:
            pass
        
        return {"error": "Failed to parse response", "raw": response_text}
```

### 動画処理の実装上注意点

```python
class VideoProcessingBestPractices:
    """
    動画処理の最適化テクニック
    """
    
    @staticmethod
    def optimize_video_for_api(input_path, output_path):
        """
        Gemini API に最適な動画形式に変換
        
        最適な仕様:
        - Codec: H.264
        - 解像度: 720p 推奨（1080p OK）
        - フレームレート: 30fps
        - 音声: AAC, 128kbps
        - ファイルサイズ: <100MB（最大 2時間）
        """
        
        import subprocess
        
        cmd = [
            'ffmpeg',
            '-i', input_path,
            '-c:v', 'libx264',
            '-preset', 'medium',  # 速度と品質のバランス
            '-crf', '23',  # 品質レベル
            '-s', '1280x720',  # 解像度
            '-r', '30',  # フレームレート
            '-c:a', 'aac',
            '-b:a', '128k',
            output_path
        ]
        
        subprocess.run(cmd, check=True)
        return output_path
    
    @staticmethod
    def extract_key_frames(video_path, max_frames=30):
        """
        動画から重要フレームを抽出
        
        処理時間削減のため、動画全体ではなく
        重要フレームのみを分析することで
        API コストを 50-70% 削減可能
        """
        
        import cv2
        import numpy as np
        
        cap = cv2.VideoCapture(video_path)
        frames = []
        prev_frame = None
        frame_count = 0
        
        while True:
            ret, frame = cap.read()
            if not ret:
                break
            
            # フレーム間の差分を計算
            if prev_frame is not None:
                diff = cv2.absdiff(prev_frame, frame)
                change_score = np.mean(diff)
                
                # 大きな変化がある フレームのみ抽出
                if change_score > 50:  # 閾値
                    frames.append(frame)
            
            prev_frame = frame
            frame_count += 1
            
            # 最大フレーム数に達したら終了
            if len(frames) >= max_frames:
                break
        
        cap.release()
        return frames
```

```python
class ContextWindowOptimizer:
    """
    Gemini の context_window (200k トークン) を
    効率的に利用するための戦略
    """
    
    @staticmethod
    def chunk_long_document(document, chunk_size=4000):
        """
        長い文書をチャンク分割
        
        各チャンクで先行文脈を保持することで
        分析精度を維持
        """
        words = document.split()
        chunks = []
        overlap_words = 100  # 前後のチャンク間で重複させる
        
        for i in range(0, len(words), chunk_size - overlap_words):
            chunk = ' '.join(words[i:i+chunk_size])
            chunks.append(chunk)
        
        return chunks
    
    @staticmethod
    def cache_system_prompt():
        """
        長いシステムプロンプトはキャッシングして
        コスト削減（キャッシュトークン: 90% 割引）
        
        重いシステムプロンプト（会話ルール・形式指定等）を
        毎回 API に送るのは無駄。
        キャッシュキーの活用で削減可能。
        """
        
        system_prompt = """
        あなたはカスタマーサポート AI です。
        
        [長い ルール・ガイドライン・例... 2000トークン]
        """
        
        # キャッシュを有効にしたリクエスト
        response = GenerativeModel('gemini-2.0-flash').generate_content(
            contents=[
                {"type": "text", "text": system_prompt, "cache_control": True},
                {"type": "text", "text": "ユーザー質問: ..."}
            ]
        )
        
        return response
```

## 本番環境での最適化

### レート制限と リトライ戦略

```python
class RobustAPIClient:
    def __init__(self, max_retries=3, initial_backoff=1):
        self.model = GenerativeModel('gemini-2.0-flash')
        self.max_retries = max_retries
        self.initial_backoff = initial_backoff
    
    def call_with_retry(self, contents):
        """
        レート制限 (429 エラー) に対応した リトライロジック
        """
        
        import time
        import random
        
        backoff = self.initial_backoff
        
        for attempt in range(self.max_retries):
            try:
                return self.model.generate_content(contents=contents)
            
            except Exception as e:
                if "429" in str(e) or "rate" in str(e).lower():
                    # exponential backoff + jitter
                    wait_time = backoff * (2 ** attempt) + random.uniform(0, 1)
                    print(f"Rate limited. Retrying in {wait_time:.1f}s...")
                    time.sleep(wait_time)
                else:
                    raise
        
        raise Exception(f"Failed after {self.max_retries} retries")
```

### コスト監視

```python
class CostMonitor:
    """
    API 呼び出しのコストを監視
    """
    
    PRICING = {
        "text_input": 0.075 / 1_000_000,      # $/token
        "text_output": 0.3 / 1_000_000,
        "image": 0.001,                        # $/image
        "video": 0.001,                        # $/sec
        "audio": 0.0001                        # $/sec
    }
    
    @staticmethod
    def estimate_cost(contents):
        """
        リクエスト送信前にコストを見積もり
        """
        
        cost = 0
        
        for item in contents:
            if item["type"] == "text":
                # テキストトークンを推定（1トークン≈4文字）
                tokens = len(item["text"]) / 4
                cost += tokens * CostMonitor.PRICING["text_input"]
            
            elif item["type"] == "image":
                cost += CostMonitor.PRICING["image"]
            
            elif item["type"] == "video":
                # 動画の長さから推定（秒単位）
                cost += 120 * CostMonitor.PRICING["video"]  # 2分と仮定
        
        return cost
```

1. **4つのモダリティの特性を理解**: テキスト・画像・動画・音声それぞれに最適な用途がある

3. **パフォーマンス最適化**: バッチ処理・キャッシング・チャンク分割で効率化
