Gemini TTS（テキスト読み上げ）API は、テキストを自然な音声に変換する強力なサービスですが、様々なエラーや予期しない動作が起こることがあります。このガイドでは、最も一般的な問題の原因と、それぞれの対処方法を詳しく解説します。

## TTS API の基本的な使い方のおさらい

トラブルシューティングに入る前に、TTS API の基本的な使い方を確認しましょう。

```python
import google.generativeai as genai

# API キーを設定
genai.configure(api_key='YOUR_GEMINI_API_KEY')

# TTS API を呼び出す（基本的な例）
response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=['Hello, this is a test message']
)

# 音声データを取得
audio_data = response.audio
```

TTS API の基本的な構造を理解してから、各エラーの対処法を確認してください。

## 音声が生成されない（空のレスポンス）

### モデル名が間違っている

TTS 機能は、すべてのモデルで利用可能ではありません。正しいモデル名を使用する必要があります。

**利用可能なモデル:**
- `gemini-2.5-flash-tts`（推奨・最新）
- `gemini-2.5-pro-tts`
- `gemini-1.5-pro-tts`（レガシー）

```python
# 間違い：通常のモデルを使用
response = genai.models.generate_content(
    model='gemini-2.5-pro',  # TTS対応していない
    contents=['Test']
)

# 正しい：TTS対応モデルを使用
response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=['Test']
)
```

モデル名が不明な場合は、利用可能なモデル一覧を取得できます。

```python
# 利用可能なモデルを確認
for model in genai.list_models():
    if 'tts' in model.name.lower():
        print(f"利用可能: {model.name}")
```

### speech_config パラメータの設定ミス

`speech_config` を設定する場合、形式が正しくないと音声が生成されません。

```python
# 間違い：辞書形式で設定
response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=['Test'],
    speech_config={
        'voice_config': {'preset_voice': 'Aoife'}  # 形式が不正
    }
)

# 正しい：speech_config オブジェクトを使用
from google.generativeai.types import speech_config as speech_types

response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=['Test'],
    speech_config=speech_types.SpeechConfig(
        voice_config=speech_types.VoiceConfig(preset_voice='Aoife')
    )
)
```

### テキストが長すぎる場合のトークン制限

TTS API はテキストの長さに制限があります。1回のリクエストで処理できるテキストの長さを超えると、エラーが発生するか、音声が途切れます。

```python
# テキストの長さを確認（トークン数の目安：1単語 ≈ 1.3トークン）
text = "長いテキスト..."
estimated_tokens = len(text.split()) * 1.3

if estimated_tokens > 3000:  # TTS API の上限目安
    print(f"警告: テキストが長すぎます（推定 {estimated_tokens} トークン）")
    # テキストを分割して処理
    texts = [text[i:i+1000] for i in range(0, len(text), 1000)]
    for chunk in texts:
        response = genai.models.generate_content(
            model='gemini-2.5-flash-tts',
            contents=[chunk]
        )
```

より正確なトークン数を計算するには、Tokenizer を使用します。

```python
# トークン数を正確に計算
model = genai.GenerativeModel('gemini-2.5-flash')
token_data = model.count_tokens(text)
print(f"トークン数: {token_data.total_tokens}")

if token_data.total_tokens > 3000:
    # テキストを分割する
    pass
```

## 音声品質が悪い場合

### voice_config の適切な設定

音声品質は `voice_config` パラメータで改善できます。

```python
from google.generativeai.types import speech_config as speech_types

# 高品質な音声設定
response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=['This is a high-quality voice test.'],
    speech_config=speech_types.SpeechConfig(
        voice_config=speech_types.VoiceConfig(
            preset_voice='Aoife'  # 利用可能な声：Aoife, Breeze, Cora, Ember等
        ),
        speaking_rate=1.0  # 1.0 = 標準速度（0.25 ～ 4.0）
    )
)
```

**利用可能な声の一覧:**
- Aoife（女性・クリア）
- Breeze（女性・自然）
- Cora（女性・フレンドリー）
- Ember（女性・ダイナミック）
- Juniper（女性・プロフェッショナル）
- Kore（男性・クリア）
- Orion（男性・深い）
- Sage（男性・自然）

異なる声を試して、用途に最適なものを選びましょう。

### スタイル指定（style instructions）の活用

`style_instructions` を使用すると、音声の表現をより細かく制御できます。

```python
from google.generativeai.types import speech_config as speech_types

response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=['Welcome to our service!'],
    speech_config=speech_types.SpeechConfig(
        voice_config=speech_types.VoiceConfig(preset_voice='Cora'),
        style_instructions='Speak in a warm, enthusiastic tone. Add a slight emphasis on key words.'
    )
)
```

スタイル指定により、以下のような表現を制御できます：
- トーン（カジュアル、フォーマル、ユーモア）
- ペース（ゆっくり、標準、素早い）
- 感情（喜び、中立、真摯さ）

## 多言語対応時のエラー

### テキストのエンコーディング問題

日本語など非ASCII文字を含むテキストを処理する場合、エンコーディングエラーが発生することがあります。

```python
# 間違い：エンコーディングを指定しない
text = "こんにちは、テスト中です。"
response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=[text]
)

# 正しい：UTF-8 で明示的にエンコード
text = "こんにちは、テスト中です。"
response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=[text.encode('utf-8').decode('utf-8')]  # UTF-8 で正規化
)
```

テキストの言語を明示的に指定することで、音声生成の精度が向上します。

```python
response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=['こんにちは、テスト中です。'],
    speech_config=speech_types.SpeechConfig(
        voice_config=speech_types.VoiceConfig(preset_voice='Aoife'),
        language_code='ja-JP'  # 日本語を明示
    )
)
```

## ストリーミング出力が途切れる場合

### ネットワーク接続の安定性確認

ストリーミング出力が途切れる場合、ネットワーク接続に問題がある可能性があります。

```python
# タイムアウト値を設定して安定性を向上
import time

def generate_tts_with_retry(text, max_retries=3):
    for attempt in range(max_retries):
        try:
            response = genai.models.generate_content(
                model='gemini-2.5-flash-tts',
                contents=[text],
                generation_config={
                    'timeout': 30.0  # 30秒のタイムアウト
                }
            )
            return response
        except Exception as e:
            if attempt < max_retries - 1:
                wait_time = 2 ** attempt  # 指数バックオフ
                print(f"再試行します。{wait_time}秒待機中...")
                time.sleep(wait_time)
            else:
                raise

# 使用方法
audio_response = generate_tts_with_retry("テスト用のテキストです。")
```

### ストリーミングレスポンスの正しい処理

ストリーミングモードでレスポンスを処理する場合、正しくバッファリングする必要があります。

```python
# ストリーミングで音声を処理
response = genai.models.generate_content(
    model='gemini-2.5-flash-tts',
    contents=['This is a streaming test.'],
    stream=True
)

audio_buffer = b''

for chunk in response:
    if hasattr(chunk, 'audio'):
        audio_buffer += chunk.audio
        print(f"Received {len(chunk.audio)} bytes")

# 完全な音声データを保存
if audio_buffer:
    with open('output.wav', 'wb') as f:
        f.write(audio_buffer)
```

## レート制限・クォータ管理

TTS API には以下の制限があります：
- **無料プラン**: 1日あたり1,000文字（日本語は多めにカウント）
- **Pro プラン**: 月額費用に応じた制限

```python
# レート制限をチェック
try:
    response = genai.models.generate_content(
        model='gemini-2.5-flash-tts',
        contents=['Test']
    )
except Exception as e:
    if '429' in str(e) or 'quota' in str(e).lower():
        print("レート制限に達しました。しばらく待ってから再度試してください。")
    else:
        raise
```

無料プランを使用している場合、クォータの確認は Google AI Studio のダッシュボードから行えます。

## エラーハンドリングの実装例

以下は、TTS API の一般的なエラーに対応した実装例です。

```python
import google.generativeai as genai
import time
from typing import Optional

class TTSError(Exception):
    pass

def generate_speech(
    text: str,
    voice: str = 'Aoife',
    max_retries: int = 3
) -> Optional[bytes]:
    """
    テキストから音声を生成する関数

    Args:
        text: 音声化するテキスト
        voice: 使用する声（Aoife, Breeze, Cora 等）
        max_retries: リトライ回数

    Returns:
        音声データ（bytes）、またはエラー時は None
    """

    if not text:
        raise TTSError("テキストが空です")

    if len(text) > 5000:
        raise TTSError(f"テキストが長すぎます（{len(text)} 文字）")

    for attempt in range(max_retries):
        try:
            response = genai.models.generate_content(
                model='gemini-2.5-flash-tts',
                contents=[text],
                speech_config={
                    'voice_config': {'preset_voice': voice}
                }
            )

            if hasattr(response, 'audio') and response.audio:
                return response.audio
            else:
                raise TTSError("音声データが返されませんでした")

        except Exception as e:
            error_msg = str(e)

            # 429 レート制限エラー
            if '429' in error_msg:
                if attempt < max_retries - 1:
                    wait_time = 60 * (2 ** attempt)
                    print(f"レート制限に達しました。{wait_time}秒待機中...")
                    time.sleep(wait_time)
                    continue
                else:
                    raise TTSError("レート制限: 再度リトライしてください")

            # 401 認証エラー
            elif '401' in error_msg:
                raise TTSError("API キーが無効です")

            # 400 無効なリクエスト
            elif '400' in error_msg:
                raise TTSError(f"無効なリクエスト: {error_msg}")

            # その他のエラー
            else:
                if attempt < max_retries - 1:
                    wait_time = 2 ** attempt
                    print(f"エラー発生。{wait_time}秒後に再試行します...")
                    time.sleep(wait_time)
                    continue
                else:
                    raise TTSError(f"予期しないエラー: {error_msg}")

    return None

# 使用例
try:
    audio_data = generate_speech("これはテスト音声です。", voice='Cora')
    if audio_data:
        with open('output.wav', 'wb') as f:
            f.write(audio_data)
        print("音声ファイルが保存されました")
except TTSError as e:
    print(f"TTS エラー: {e}")
```

## よくある質問（FAQ）

**Q1: `model='gemini-2.5-flash-tts'` を使用しているのに「Model not found」というエラーが出ます。**

A: 複数の原因が考えられます。(1) API キーが正しく設定されているか確認してください。(2) ご使用の API キーが TTS API へのアクセスを許可しているか確認してください（Google AI Studio のセッティングから確認可能）。(3) モデル名のタイプミスがないか確認してください（`gemini-2.5-flash-tts` が正しい名称です）。それでも解決しない場合は、`genai.list_models()` で利用可能なモデルを確認してください。

**Q2: 日本語のテキストを音声化すると、発音が不自然です。**

A: 複数の対策があります。(1) `language_code='ja-JP'` を明示的に設定してください。(2) 異なる声を試してみてください（Aoife、Breeze、Cora など）。(3) `style_instructions` で表現を調整してください（例: 「ゆっくり、丁寧に喋ってください」）。(4) テキストに句読点を適切に入れることで、音声の抑揚が改善されます。

**Q3: 同じテキストを何度も音声化すると、毎回異なる音声が生成されます。これは正常ですか？**

A: はい、これは正常な動作です。TTS API は毎回新しい音声を生成するため、若干のバリエーションが発生します。同じ音声を再生したい場合は、一度生成した音声ファイルをキャッシュして再利用してください。テキストの hash 値をキーにして、生成済みの音声をメモリやデータベースに保存する方法が効果的です。
