## 取り組みの背景

LINEは日本国内で月間アクティブユーザー数9,700万人以上を誇るメッセージングプラットフォームです。このLINE上にGemini APIを活用したAIチャットボットを構築できれば、顧客対応の自動化、社内ヘルプデスク、パーソナルアシスタントなど、多彩なユースケースに対応できます。

Google の Gemini API と LINE Messaging API を Python（Flask）で組み合わせ、メッセージの受信からAI応答の返信までを一気通貫で実装する方法を順を追って整理していきます。

**この記事で学べること:**

- LINE Developers でチャネルを作成し Messaging API を有効化する手順
- Gemini API（Google AI Python SDK）のセットアップ
- Flask で Webhook サーバーを構築し、ユーザーメッセージに Gemini が応答する仕組み
- 会話履歴を保持するマルチターン対応
- Cloud Run へのデプロイ方法

Gemini API の基本的な使い方については [Gemini API クイックスタート](/articles/gemini-api/gemini-api-quickstart) も合わせてご覧ください。

1. [LINE Developers Console](https://developers.line.biz/console/) にログイン
2. 「プロバイダー」を作成（例: `My AI Bot`）
3. 「Messaging API」チャネルを作成
4. チャネル設定画面で以下を取得:
   - **チャネルシークレット**（Basic settings タブ）
   - **チャネルアクセストークン**（Messaging API タブ → 「発行」ボタン）
5. Webhook URL は後のステップで設定します

## LINE Bot サーバーの構築

### メインアプリケーション

Flask で Webhook サーバーを構築し、LINE からのメッセージを受信して Gemini API で応答を生成します:

```python
# app.py
import os
import hashlib
import hmac
import base64
from flask import Flask, request, abort
from google import genai
from linebot.v3 import WebhookParser
from linebot.v3.messaging import (
    Configuration,
    ApiClient,
    MessagingApi,
    ReplyMessageRequest,
    TextMessage,
)
from linebot.v3.webhooks import MessageEvent, TextMessageContent

app = Flask(__name__)

# --- 設定 ---
GEMINI_API_KEY = os.environ["GEMINI_API_KEY"]
LINE_CHANNEL_SECRET = os.environ["LINE_CHANNEL_SECRET"]
LINE_CHANNEL_ACCESS_TOKEN = os.environ["LINE_CHANNEL_ACCESS_TOKEN"]

# Gemini クライアント初期化
gemini_client = genai.Client(api_key=GEMINI_API_KEY)

# LINE API 初期化
configuration = Configuration(access_token=LINE_CHANNEL_ACCESS_TOKEN)
parser = WebhookParser(LINE_CHANNEL_SECRET)

# ユーザーごとの会話履歴（メモリ内保持）
conversation_history: dict[str, list[dict]] = {}
MAX_HISTORY = 20  # 直近20メッセージまで保持

def get_gemini_response(user_id: str, user_message: str) -> str:
    """Gemini APIでマルチターン応答を生成する"""
    # 会話履歴を取得（なければ初期化）
    if user_id not in conversation_history:
        conversation_history[user_id] = []

    history = conversation_history[user_id]

    # ユーザーメッセージを履歴に追加
    history.append({"role": "user", "parts": [{"text": user_message}]})

    # Gemini APIを呼び出し
    response = gemini_client.models.generate_content(
        model="gemini-3-flash",
        contents=history,
        config={
            "system_instruction": (
                "あなたはLINE上で動作する親切なAIアシスタントです。"
                "日本語で簡潔に、フレンドリーな口調で回答してください。"
                "回答は300文字以内に収めてください。"
            ),
            "temperature": 0.7,
            "max_output_tokens": 500,
        },
    )

    assistant_message = response.text

    # アシスタント応答を履歴に追加
    history.append({"role": "model", "parts": [{"text": assistant_message}]})

    # 履歴が長くなりすぎたら古い部分を削除
    if len(history) > MAX_HISTORY:
        conversation_history[user_id] = history[-MAX_HISTORY:]

    return assistant_message

@app.route("/callback", methods=["POST"])
def callback():
    """LINE Webhookエンドポイント"""
    signature = request.headers.get("X-Line-Signature", "")
    body = request.get_data(as_text=True)

    try:
        events = parser.parse(body, signature)
    except Exception:
        abort(400)

    for event in events:
        if isinstance(event, MessageEvent) and isinstance(
            event.message, TextMessageContent
        ):
            user_id = event.source.user_id
            user_message = event.message.text

            # Gemini で応答を生成
            reply_text = get_gemini_response(user_id, user_message)

            # LINE に返信
            with ApiClient(configuration) as api_client:
                line_bot_api = MessagingApi(api_client)
                line_bot_api.reply_message(
                    ReplyMessageRequest(
                        reply_token=event.reply_token,
                        messages=[TextMessage(text=reply_text)],
                    )
                )

    return "OK"

@app.route("/health", methods=["GET"])
def health():
    """ヘルスチェック用エンドポイント"""
    return "OK"

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=8080, debug=True)
```

### コードのポイント

- **`conversation_history`**: ユーザーIDをキーとした辞書で、会話の文脈を保持します。これにより「さっきの続きで…」のような自然な会話が実現します
- **`system_instruction`**: Gemini に LINE ボットとしての振る舞いを指示。回答の長さやトーンをここで制御します
- **`MAX_HISTORY`**: メモリ効率のため直近20メッセージに制限。本番環境では Redis や Firestore での永続化を検討しましょう

```python
import requests
from linebot.v3.webhooks import ImageMessageContent

def download_line_image(message_id: str) -> bytes:
    """LINE サーバーから画像をダウンロード"""
    url = f"https://api-data.line.me/v2/bot/message/{message_id}/content"
    headers = {"Authorization": f"Bearer {LINE_CHANNEL_ACCESS_TOKEN}"}
    resp = requests.get(url, headers=headers)
    return resp.content

def get_gemini_image_response(user_id: str, image_bytes: bytes) -> str:
```

```dockerfile

WORKDIR /app

RUN pip install --no-cache-dir -r requirements.txt

COPY app.py .

CMD ["gunicorn", "--bind", "0.0.0.0:8080", "--workers", "2", "app:app"]
```

```bash

gcloud run deploy gemini-line-bot \
  --source . \
```

## 基本的なテキスト応答ボットの構築

まずは、ユーザーのメッセージに Gemini API で応答するシンプルなボットを作りましょう。

```python
import os
import logging
from dotenv import load_dotenv
from google import genai
from telegram import Update
from telegram.ext import (
    ApplicationBuilder,
    CommandHandler,
    MessageHandler,
    ContextTypes,
    filters,
)

# 環境変数の読み込み
load_dotenv()

# ログ設定
logging.basicConfig(
    format="%(asctime)s - %(name)s - %(levelname)s - %(message)s",
    level=logging.INFO,
)
logger = logging.getLogger(__name__)

# Gemini クライアントの初期化
client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

async def start(update: Update, context: ContextTypes.DEFAULT_TYPE):
    """
    /start コマンドのハンドラー
    """
    await update.message.reply_text(
        "こんにちは！Gemini AI アシスタントです。\n"
        "テキストや画像を送ってください。AI が分析・回答します。\n\n"
        "コマンド一覧:\n"
        "/start - ボットの説明\n"
        "/reset - 会話履歴をリセット"
    )

async def reset(update: Update, context: ContextTypes.DEFAULT_TYPE):
    """
    /reset コマンドで会話履歴をクリア
    """
    context.user_data.pop("history", None)
    await update.message.reply_text("会話履歴をリセットしました。")

async def handle_message(update: Update, context: ContextTypes.DEFAULT_TYPE):
    """
    テキストメッセージに Gemini API で応答
    """
    user_message = update.message.text

    # 会話履歴の管理（最大20ターン）
    history = context.user_data.get("history", [])
    history.append({"role": "user", "parts": [{"text": user_message}]})

    # 履歴が長くなりすぎないよう制限
    if len(history) > 40:
        history = history[-40:]

    try:
        # Gemini API 呼び出し
        response = client.models.generate_content(
            model="gemini-3-flash",
            contents=history,
            config={
                "system_instruction": (
                    "あなたは親切で知識豊富なAIアシスタントです。"
                    "日本語で質問された場合は日本語で、"
                    "英語で質問された場合は英語で回答してください。"
                    "回答は簡潔かつ正確に行ってください。"
                ),
                "max_output_tokens": 2048,
                "temperature": 0.7,
            },
        )

        reply = response.text

        # アシスタントの応答を履歴に追加
        history.append({"role": "model", "parts": [{"text": reply}]})
        context.user_data["history"] = history

        # Telegram のメッセージ長制限（4096文字）に対応
        if len(reply) > 4000:
            for i in range(0, len(reply), 4000):
                await update.message.reply_text(reply[i : i + 4000])
        else:
            await update.message.reply_text(reply)

    except Exception as e:
        logger.error(f"Gemini API error: {e}")
        await update.message.reply_text(
            "申し訳ありません。エラーが発生しました。しばらくしてからもう一度お試しください。"
        )

def main():
    """
    ボットを起動
    """
    app = (
        ApplicationBuilder()
        .token(os.getenv("TELEGRAM_BOT_TOKEN"))
        .build()
    )

    app.add_handler(CommandHandler("start", start))
    app.add_handler(CommandHandler("reset", reset))
    app.add_handler(MessageHandler(filters.TEXT & ~filters.COMMAND, handle_message))

    logger.info("Bot is running...")
    app.run_polling()

if __name__ == "__main__":
    main()
```

実行すると、Telegram でボットにテキストを送るだけで Gemini API を通じた AI 応答が返ってきます。会話履歴も保持されるため、文脈を踏まえたマルチターン会話が可能です。

## マルチモーダル対応 — 画像分析機能の追加

Gemini API の強みであるマルチモーダル機能を活かし、ユーザーが送信した画像を AI で分析する機能を追加します。

```python
import io
import httpx

async def handle_photo(update: Update, context: ContextTypes.DEFAULT_TYPE):
    """
    画像メッセージを受信して Gemini で分析
    """
    # 最も高解像度の画像を取得
    photo = update.message.photo[-1]
    file = await context.bot.get_file(photo.file_id)

    # 画像データをダウンロード
    async with httpx.AsyncClient() as http_client:
        response = await http_client.get(file.file_path)
        image_bytes = response.content

    # キャプション（ユーザーの質問）があれば使用
    caption = update.message.caption or "この画像について詳しく説明してください。"

    try:
        await update.message.reply_text("画像を分析中です...")

        # Gemini API にマルチモーダルリクエスト
        response = client.models.generate_content(
            model="gemini-3-flash",
            contents=[
                {
                    "role": "user",
                    "parts": [
                        {"text": caption},
                        {
                            "inline_data": {
                                "mime_type": "image/jpeg",
                                "data": __import__("base64").b64encode(
                                    image_bytes
                                ).decode(),
                            }
                        },
                    ],
                }
            ],
            config={
                "max_output_tokens": 2048,
                "temperature": 0.5,
            },
        )

        await update.message.reply_text(response.text)

    except Exception as e:
        logger.error(f"Image analysis error: {e}")
        await update.message.reply_text(
            "画像の分析中にエラーが発生しました。別の画像でお試しください。"
        )
```

`main()` 関数に以下のハンドラーを追加します。

```python
app.add_handler(MessageHandler(filters.PHOTO, handle_photo))
```

これで、ユーザーが画像を送信すると Gemini がその内容を分析して回答します。画像にキャプションを付けて送れば、「この料理のカロリーは？」「このエラーメッセージの解決方法は？」といった具体的な質問にも対応できます。

## ドキュメント分析機能の追加

PDF やテキストファイルを送信して AI に分析してもらう機能も実装できます。

```python
async def handle_document(update: Update, context: ContextTypes.DEFAULT_TYPE):
    """
    ドキュメント（PDF・テキスト）を受信して Gemini で分析
    """
    document = update.message.document

    # サポートする MIME タイプ
    supported_types = {
        "application/pdf": "application/pdf",
        "text/plain": "text/plain",
        "text/csv": "text/csv",
    }

    mime_type = document.mime_type
    if mime_type not in supported_types:
        await update.message.reply_text(
            "対応していないファイル形式です。PDF、テキスト、CSV ファイルを送信してください。"
        )
        return

    # ファイルサイズチェック（20MB制限）
    if document.file_size > 20 * 1024 * 1024:
        await update.message.reply_text(
            "ファイルサイズが大きすぎます（上限: 20MB）。"
        )
        return

    file = await context.bot.get_file(document.file_id)

    async with httpx.AsyncClient() as http_client:
        response = await http_client.get(file.file_path)
        file_bytes = response.content

    caption = update.message.caption or "このドキュメントの内容を要約してください。"

    try:
        await update.message.reply_text("ドキュメントを分析中です...")

        import base64
        response = client.models.generate_content(
            model="gemini-3-flash",
            contents=[
                {
                    "role": "user",
                    "parts": [
                        {"text": caption},
                        {
                            "inline_data": {
                                "mime_type": mime_type,
                                "data": base64.b64encode(file_bytes).decode(),
                            }
                        },
                    ],
                }
            ],
            config={
                "max_output_tokens": 4096,
                "temperature": 0.3,
            },
        )

        reply = response.text
        if len(reply) > 4000:
            for i in range(0, len(reply), 4000):
                await update.message.reply_text(reply[i : i + 4000])
        else:
            await update.message.reply_text(reply)

    except Exception as e:
        logger.error(f"Document analysis error: {e}")
        await update.message.reply_text(
            "ドキュメントの分析中にエラーが発生しました。"
        )
```

`main()` 関数にハンドラーを追加します。

```python
app.add_handler(MessageHandler(filters.Document.ALL, handle_document))
```

## エラーハンドリングとレート制限対策

本番運用では、API のレート制限やネットワークエラーへの適切な対処が不可欠です。リトライロジックを組み込んだラッパー関数を作成しましょう。

```python
import asyncio
from google.api_core.exceptions import ResourceExhausted, ServiceUnavailable

async def call_gemini_with_retry(contents, config, max_retries=3):
    """
    リトライ付き Gemini API 呼び出し
    """
    for attempt in range(max_retries):
        try:
            response = client.models.generate_content(
                model="gemini-3-flash",
                contents=contents,
                config=config,
            )
            return response

        except ResourceExhausted:
            # レート制限 — 指数バックオフで待機
            wait_time = 2 ** attempt
            logger.warning(
                f"Rate limited. Retrying in {wait_time}s "
                f"(attempt {attempt + 1}/{max_retries})"
            )
            await asyncio.sleep(wait_time)

        except ServiceUnavailable:
            # サービス一時停止 — リトライ
            wait_time = 3 ** attempt
            logger.warning(
                f"Service unavailable. Retrying in {wait_time}s "
                f"(attempt {attempt + 1}/{max_retries})"
            )
            await asyncio.sleep(wait_time)

    raise Exception("Maximum retries exceeded")
```

ここではGemini API と LINE Messaging API を組み合わせて Python でAIチャットボットを構築する方法を解説しました。

1. **LINE Developers Console** でチャネルを作成し、アクセストークンを取得する
