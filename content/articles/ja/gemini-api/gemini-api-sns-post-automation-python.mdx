SNS の運用を続けるうえで「毎日投稿のネタを考え続ける」のは思いのほか大変な作業です。特に X（旧 Twitter）・Instagram・LinkedIn といった複数のプラットフォームを同時に管理していると、それぞれの文体や文字数制限に合わせた投稿を用意するだけで相当な時間を費やしてしまいます。

単発の投稿生成から、1週間分のコンテンツカレンダーをまとめて出力するバッチ処理まで、実践的なコードとともに丁寧に紹介します。

Gemini API を実プロダクトで運用してきた知見から、この問題に普段から向き合ってきた立場で、要点を整理します。

2014年から個人開発でモバイルアプリを続けてきた立場で見ると、API の選び方は AdMob を含む既存スタックとの相性が鍵です。

## なぜ Gemini API が SNS 自動化に向いているのか

Gemini API が SNS コンテンツ生成に適している理由はいくつかあります。まず、**構造化出力（JSON モード）** によって、複数プラットフォーム向けの投稿文を一度のリクエストで整理した形式として受け取れる点が挙げられます。

次に、**大きなコンテキストウィンドウ（最大 100 万トークン）** により、過去の投稿履歴やブランドガイドライン、参考 URL などを一度に渡してトーンの一貫性を保てます。さらに、**マルチモーダル対応** によって商品画像や資料を入力として受け取り、その内容に基づいた投稿文を生成することも可能です。

料金面については [Gemini API の料金・課金の仕組み完全ガイド](/articles/gemini-api/gemini-api-pricing-billing-complete-guide-2026) で詳しく解説していますが、`gemini-2.5-flash` モデルを使えば大量の投稿を非常にリーズナブルなコストで生成できます。

## 基本的な投稿生成：単一プラットフォーム

まずはシンプルに、1つのトピックから X（Twitter）向けの投稿を生成してみましょう。

```python
import os
from google import genai

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

def generate_tweet(topic: str, tone: str = "informative") -> str:
    """
    指定したトピックとトーンで X（Twitter）投稿を生成する

    Args:
        topic: 投稿のテーマ（例: "Python の非同期処理"）
        tone: 投稿のトーン（"informative" / "casual" / "inspiring"）

    Returns:
        生成された投稿文（280文字以内）
    """
    prompt = f"""
あなたはプロフェッショナルなSNSコンテンツクリエイターです。
以下の条件で X（Twitter）の投稿文を1つ作成してください。

トピック: {topic}
トーン: {tone}

制約:
- 日本語で作成
- 140文字以内（日本語の場合）
- 関連するハッシュタグを2〜3個含める
- 絵文字を1〜2個使用して視認性を高める
- 投稿文のみを返答（説明文は不要）
"""

    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=prompt
    )
    return response.text.strip()

# 使用例
topic = "Gemini API を使った業務自動化"
tweet = generate_tweet(topic, tone="informative")
print(tweet)
# 出力例:
# 🤖 Gemini APIで業務を丸ごと自動化！
# メール分類・レポート生成・SNS投稿まで一括処理できます。
# 初期投資ゼロ、無料枠から始めて費用対効果を実感してみてください。
# #GeminiAPI #業務自動化 #Python
```

## マルチプラットフォーム対応：構造化出力の活用

実際の運用では、同じトピックから X・Instagram・LinkedIn 向けにそれぞれ異なるフォーマットの投稿を生成したいケースが多いはずです。Gemini API の **構造化出力（JSON モード）** を使うと、1回のリクエストで全プラットフォーム分をまとめて取得できます。

```python
import os
import json
from google import genai
from pydantic import BaseModel

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

class SocialMediaPost(BaseModel):
    platform: str       # "twitter" / "instagram" / "linkedin"
    content: str        # 投稿本文
    hashtags: list[str] # ハッシュタグリスト（#なし）
    char_count: int     # 文字数

class SocialMediaBundle(BaseModel):
    topic: str
    posts: list[SocialMediaPost]

def generate_multi_platform_posts(
    topic: str,
    brand_voice: str = "プロフェッショナルで親しみやすい"
) -> SocialMediaBundle:
    """
    1つのトピックから X・Instagram・LinkedIn 向けの投稿を一括生成する

    Args:
        topic: 投稿のテーマ
        brand_voice: ブランドの声のスタイル

    Returns:
        各プラットフォーム向けの投稿をまとめた SocialMediaBundle
    """
    prompt = f"""
あなたはSNSマーケティングの専門家です。
以下のトピックとブランドボイスに基づき、3つのプラットフォーム向けの投稿を作成してください。

トピック: {topic}
ブランドボイス: {brand_voice}

各プラットフォームの要件:
- X（Twitter）: 140文字以内、ハッシュタグ2〜3個、絵文字OK
- Instagram: キャプション形式（500文字以内）、ハッシュタグ5〜10個、改行を効果的に使用
- LinkedIn: プロフェッショナルな文体（300文字以内）、ハッシュタグ3〜5個、洞察や学びを含める

日本語で作成し、各プラットフォームのユーザー層に最適化してください。
"""

    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=prompt,
        config=genai.types.GenerateContentConfig(
            response_mime_type="application/json",
            response_schema=SocialMediaBundle,
        )
    )

    return SocialMediaBundle.model_validate_json(response.text)

# 使用例
topic = "Python 自動化で業務時間を50%削減した事例"
bundle = generate_multi_platform_posts(topic)

for post in bundle.posts:
    print(f"\n=== {post.platform.upper()} ===")
    print(post.content)
    print(f"ハッシュタグ: {', '.join(['#' + h for h in post.hashtags])}")
    print(f"文字数: {post.char_count}")
```

実行すると次のような出力が得られます（モデルの生成結果は実行ごとに異なります）。

```

⚡ Python自動化で業務時間を50%削減！
メール振り分け・レポート生成・データ集計をスクリプト1本で。
導入事例とコードを公開中です👇
ハッシュタグ: #Python, #業務効率化, #自動化
文字数: 89

=== INSTAGRAM ===
業務自動化で毎日2時間を取り戻した話✨

先月からPythonでルーティン作業を自動化したところ...
（省略）
ハッシュタグ: #Python, #業務自動化, #エンジニア, ...
```

## バッチ処理：1週間分のコンテンツカレンダーを一括生成

個別に投稿を生成するより、まとめて1週間分を一気に作成するほうが効率的です。以下のコードでは、テーマリストから全日程の投稿を自動生成します。

```python
import os
import json
from datetime import date, timedelta
from google import genai

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

def generate_content_calendar(
    topics: list[str],
    start_date: date,
    platform: str = "twitter"
) -> list[dict]:
    """
    複数のトピックから指定期間のコンテンツカレンダーを生成する

    Args:
        topics: 1週間分のテーマリスト（7個推奨）
        start_date: カレンダーの開始日
        platform: 対象プラットフォーム

    Returns:
        日付と投稿文を含む辞書のリスト
    """
    topics_text = "\n".join([f"{i+1}. {t}" for i, t in enumerate(topics)])

    prompt = f"""
以下の7つのトピックについて、{platform} 向けの投稿を1つずつ作成してください。

{topics_text}

各投稿の要件:
- 日本語
- 140文字以内（Xの場合）
- 絵文字を1〜2個
- ハッシュタグを2〜3個
- 曜日の雰囲気に合わせたトーン（月曜=やる気喚起、金曜=週末感、など）

JSON形式で返してください。形式:
[
  {{"day": 1, "topic": "テーマ", "post": "投稿文", "hashtags": ["tag1", "tag2"]}},
  ...
]
"""

    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=prompt,
        config=genai.types.GenerateContentConfig(
            response_mime_type="application/json",
        )
    )

    posts_data = json.loads(response.text)
    calendar = []
    for i, post in enumerate(posts_data):
        post_date = start_date + timedelta(days=i)
        calendar.append({
            "date": post_date.strftime("%Y-%m-%d"),
            "day_of_week": ["月", "火", "水", "木", "金", "土", "日"][post_date.weekday()],
            "topic": post["topic"],
            "post": post["post"],
            "hashtags": post.get("hashtags", [])
        })

    return calendar

# 使用例
topics = [
    "Gemini API の始め方",
    "Python 自動化の基本",
    "プロンプトエンジニアリング入門",
    "Function Calling の活用法",
    "今週のAIニュースまとめ",
    "週末の学習リソース紹介",
    "SNS自動化の成果報告"
]

today = date.today()
calendar = generate_content_calendar(topics, start_date=today)

for entry in calendar:
    print(f"\n[{entry['date']}（{entry['day_of_week']}）]")
    print(entry["post"])
    print(f"Tags: {', '.join(['#' + h for h in entry['hashtags']])}")
```

## 画像付き投稿のキャプション生成（マルチモーダル活用）

Gemini のマルチモーダル機能を使えば、商品画像や資料の画像を渡してその内容に基づいたキャプションを自動生成できます。

```python
import os
import base64
from pathlib import Path
from google import genai

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

def generate_caption_from_image(
    image_path: str,
    platform: str = "instagram",
    brand_keywords: list[str] = None
) -> str:
    """
    画像を解析して Instagram 向けキャプションを生成する

    Args:
        image_path: 画像ファイルのパス
        platform: 対象プラットフォーム
        brand_keywords: ブランドに関連するキーワードリスト

    Returns:
        生成されたキャプション文
    """
    image_data = Path(image_path).read_bytes()
    image_base64 = base64.b64encode(image_data).decode("utf-8")

    keywords_text = ""
    if brand_keywords:
        keywords_text = f"\nブランドキーワード: {', '.join(brand_keywords)}"

    prompt = f"""
この画像を分析して、{platform} 向けの魅力的なキャプションを作成してください。

要件:
- 日本語で作成
- 画像の内容を的確に表現
- 感情に訴える言葉を使う
- ハッシュタグを5〜8個含める
- 改行を効果的に使って読みやすくする{keywords_text}
"""

    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=[
            prompt,
            {
                "inline_data": {
                    "mime_type": "image/jpeg",
                    "data": image_base64
                }
            }
        ]
    )
    return response.text.strip()

# )

```

## よくあるエラーと対処法

### `ResourceExhausted: 429 RESOURCE_EXHAUSTED`

無料枠の RPM（リクエスト/分）制限に達した場合に発生します。バッチ処理時は `time.sleep(2)` などで間隔を空けるか、`gemini-2.5-flash` のような高レート制限モデルを使用してください。

```python
import time

for topic in topics:
    post = generate_tweet(topic)
    print(post)
    time.sleep(2)  # 2秒待機してレート制限を回避
```

### 生成されるコンテンツの品質が低い場合

System Instructions を追加してモデルにブランドコンテキストを与えると、出力の一貫性と品質が向上します。

```python
response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents=prompt,
    config=genai.types.GenerateContentConfig(
        system_instruction=(
            "あなたはテック系スタートアップのSNSマネージャーです。"
            "読者はエンジニアや起業家で、実用的で簡潔な情報を好みます。"
            "誇張表現を避け、具体的なメリットや数字を使った投稿を心がけてください。"
        )
    )
)
```

### JSON パースエラー

`response_mime_type="application/json"` を指定しても稀に不完全な JSON が返ることがあります。その場合は `try/except` でハンドリングしてリトライしてください。

```python
import json

try:
    data = json.loads(response.text)
except json.JSONDecodeError:
    # リトライ処理
    print("JSON パースエラー。再試行します。")
    response = client.models.generate_content(model="gemini-2.5-flash", contents=prompt)
    data = json.loads(response.text)
```
