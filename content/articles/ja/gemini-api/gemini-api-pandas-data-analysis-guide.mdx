## はじめに：Gemini API × Pandas でデータ分析が変わる

データ分析の現場では、CSV や Excel ファイルを扱う作業が日常的に発生します。しかし「この列の意味は何か」「外れ値をどう処理すべきか」「どんなグラフが適切か」といった判断を毎回手作業で行うのは、時間と労力がかかります。

Gemini API と Python の Pandas ライブラリを組み合わせることで、こうした作業の多くを自動化できます。本記事では、以下のことを実践的に学べます。

- DataFrame の内容を Gemini に自然言語で問い合わせる
- CSV データのクリーニングを AI が自動で提案・実行する
- データの統計サマリーと分析レポートを自動生成する
- 適切な可視化方針を Gemini に決めてもらう

対象読者は Python と Pandas の基本を理解していて、Gemini API を実務に活かしたいと考えているエンジニア・データアナリストの方です。

## DataFrameの内容を Gemini に問い合わせる

### CSV データの読み込みと Gemini への渡し方

Pandas DataFrame を Gemini に渡す際の基本パターンを解説します。DataFrame を文字列に変換して、プロンプトに埋め込む方法が最もシンプルです。

```python
import pandas as pd
import google.generativeai as genai
import os

genai.configure(api_key=os.environ["GEMINI_API_KEY"])
model = genai.GenerativeModel("gemini-2.5-flash")

# サンプル CSV の読み込み（ここでは架空の売上データ）
df = pd.read_csv("sales_data.csv")

def ask_gemini_about_dataframe(df: pd.DataFrame, question: str) -> str:
    """
    DataFrame の内容について Gemini に質問する関数。

    Args:
        df: 分析対象の DataFrame
        question: 自然言語の質問

    Returns:
        Gemini の回答テキスト
    """
    # DataFrame の情報をまとめてプロンプトに含める
    df_info = f"""
データ概要:
- 行数: {len(df)}行, 列数: {len(df.columns)}列
- 列名: {', '.join(df.columns.tolist())}
- データ型:
{df.dtypes.to_string()}

先頭5行:
{df.head().to_string()}

基本統計:
{df.describe().to_string()}
"""

    prompt = f"""
以下のデータについて質問に答えてください。

{df_info}

質問: {question}

データに基づいた具体的な分析と洞察を提供してください。
"""

    response = model.generate_content(prompt)
    return response.text

# 使用例
question = "このデータで最も売上が高い商品カテゴリはどれですか？また、季節性のトレンドは見られますか？"
answer = ask_gemini_about_dataframe(df, question)
print(answer)
# 例: "売上が最も高いカテゴリは『電子機器』で全体の35%を占めています。
#      また、12月に顕著なピークが見られ、季節性の影響が強いと考えられます..."
```

### 大規模データの処理

行数が多い場合、DataFrame 全体を渡すのはトークン消費が増えます。サンプリングと集計を組み合わせるのが効果的です。

```python
def prepare_df_summary(df: pd.DataFrame, sample_size: int = 20) -> str:
    """
    大規模 DataFrame のサマリーを生成する関数。
    トークン消費を抑えつつ、データの特徴を Gemini に伝える。

    Args:
        df: 対象 DataFrame
        sample_size: サンプル行数（デフォルト20行）

    Returns:
        サマリー文字列
    """
    summary_parts = []

    # 基本情報
    summary_parts.append(f"データサイズ: {len(df)}行 × {len(df.columns)}列")

    # 数値列の統計
    numeric_cols = df.select_dtypes(include='number').columns.tolist()
    if numeric_cols:
        summary_parts.append(f"\n数値列の統計:\n{df[numeric_cols].describe().to_string()}")

    # カテゴリ列のユニーク値
    cat_cols = df.select_dtypes(include='object').columns.tolist()
    for col in cat_cols[:5]:  # 最大5列まで
        unique_vals = df[col].value_counts().head(5)
        summary_parts.append(f"\n{col}のトップ5値:\n{unique_vals.to_string()}")

    # 欠損値情報
    missing = df.isnull().sum()
    if missing.any():
        summary_parts.append(f"\n欠損値:\n{missing[missing > 0].to_string()}")

    # サンプル行
    sample = df.sample(min(sample_size, len(df)), random_state=42)
    summary_parts.append(f"\nランダムサンプル({sample_size}行):\n{sample.to_string()}")

    return "\n".join(summary_parts)

# 使用例：100万行のデータでも効率的に処理
large_df = pd.read_csv("large_sales_data.csv")
summary = prepare_df_summary(large_df, sample_size=30)
response = model.generate_content(f"以下のデータを分析して主要なトレンドを教えてください:\n{summary}")
print(response.text)
```

## データクリーニングの自動化

Gemini API を使って、データの品質問題を自動で検出・修正案を生成できます。

```python
def auto_clean_suggestions(df: pd.DataFrame) -> dict:
    """
    DataFrame の品質問題を検出し、Gemini にクリーニング方針を提案させる。

    Returns:
        {'issues': [...], 'suggestions': '...', 'cleaned_df': DataFrame}
    """
    # データ品質チェック
    issues = []

    # 欠損値の検出
    missing = df.isnull().sum()
    if missing.any():
        issues.append(f"欠損値: {missing[missing > 0].to_dict()}")

    # 重複行の検出
    duplicates = df.duplicated().sum()
    if duplicates > 0:
        issues.append(f"重複行: {duplicates}件")

    # 数値列の外れ値検出（IQR法）
    for col in df.select_dtypes(include='number').columns:
        Q1 = df[col].quantile(0.25)
        Q3 = df[col].quantile(0.75)
        IQR = Q3 - Q1
        outliers = ((df[col] < Q1 - 1.5 * IQR) | (df[col] > Q3 + 1.5 * IQR)).sum()
        if outliers > 0:
            issues.append(f"外れ値（{col}）: {outliers}件（IQR法）")

    # Gemini にクリーニング方針を質問
    issues_text = "\n".join(issues) if issues else "主要な品質問題は検出されませんでした"

    prompt = f"""
データ品質の問題が以下のように検出されました:
{issues_text}

データの概要:
- 行数: {len(df)}行, 列数: {len(df.columns)}列
- 列名: {', '.join(df.columns.tolist())}
- データ型: {df.dtypes.to_dict()}

各問題に対してデータサイエンティストとして最適なクリーニング方針を提案してください。
Pythonのpandasコードも含めてください。
"""

    response = model.generate_content(prompt)

    return {
        "issues": issues,
        "suggestions": response.text
    }

# 使用例
df = pd.read_csv("messy_data.csv")
result = auto_clean_suggestions(df)
print("検出された問題:")
for issue in result["issues"]:
    print(f"  - {issue}")
print("\nGeminiの提案:")
print(result["suggestions"])
```

## 自動レポート生成

Gemini API を使って、データ分析レポートをマークダウン形式で自動生成できます。

```python
def generate_analysis_report(df: pd.DataFrame, report_title: str = "データ分析レポート") -> str:
    """
    DataFrame の包括的な分析レポートを Gemini で自動生成する。

    Args:
        df: 分析対象 DataFrame
        report_title: レポートのタイトル

    Returns:
        マークダウン形式の分析レポート
    """
    # データサマリーの準備
    numeric_stats = df.describe().to_string() if not df.select_dtypes(include='number').empty else "数値列なし"

    prompt = f"""
あなたはプロのデータアナリストです。以下のデータセットについて、詳細な分析レポートをマークダウン形式で作成してください。

## データ概要
- 行数: {len(df)}
- 列数: {len(df.columns)}
- 列名と型: {df.dtypes.to_dict()}
- 欠損値: {df.isnull().sum().to_dict()}

## 数値データの統計
{numeric_stats}

## 先頭データ（5行）
{df.head().to_string()}

## レポート要件
1. エグゼクティブサマリー（3-5文）
2. データの特徴と品質評価
3. 主要な統計的発見
4. ビジネス上の示唆（推測で構いません）
5. 次のステップの推奨事項

レポートタイトル: {report_title}

日本語でプロフェッショナルなレポートを作成してください。
"""

    response = model.generate_content(prompt)
    return response.text

# 使用例
df = pd.read_csv("quarterly_sales.csv")
report = generate_analysis_report(df, "2026年第1四半期 売上分析レポート")

# レポートをファイルに保存

    f.write(report)

print("✅ レポート生成完了: analysis_report.md")
print(report[:500] + "...")  # 先頭500文字をプレビュー
```

## 可視化方針の自動決定

どのグラフが最適かを Gemini に判断させる実装例です。

```python
import matplotlib.pyplot as plt
import matplotlib
matplotlib.use('Agg')  # 非インタラクティブ環境用

def decide_visualization(df: pd.DataFrame, target_column: str) -> dict:
    """
    データの特性に基づいて最適な可視化方針を Gemini に決定させる。

    Returns:
        {'chart_type': 'bar'/'line'/'scatter'/'histogram',
         'reason': '理由',
         'x_col': '列名', 'y_col': '列名'}
    """
    col_info = {
        col: {
            "dtype": str(df[col].dtype),
            "nunique": df[col].nunique(),
            "sample": df[col].dropna().head(3).tolist()
        }
        for col in df.columns
    }

    prompt = f"""
以下のデータセットで「{target_column}」を可視化したいです。

列情報:
{col_info}

最適なグラフの種類（bar/line/scatter/histogram/box）とX軸・Y軸の列を選んでください。
以下のJSON形式で回答してください:
{{
  "chart_type": "グラフ種類",
  "x_col": "X軸の列名またはnull",
  "y_col": "Y軸の列名",
  "reason": "選択理由（1文）"
}}
"""

    response = model.generate_content(prompt)

    # JSONを抽出してパース
    import json
    import re
    json_match = re.search(r'\{[^}]+\}', response.text, re.DOTALL)
    if json_match:
        return json.loads(json_match.group())
    return {"chart_type": "histogram", "x_col": None, "y_col": target_column, "reason": "デフォルト"}

def create_chart(df: pd.DataFrame, viz_config: dict, save_path: str = "chart.png"):
    """
    Gemini が提案した可視化設定に基づいてグラフを生成する。
    """
    fig, ax = plt.subplots(figsize=(10, 6))

    chart_type = viz_config.get("chart_type", "histogram")
    x_col = viz_config.get("x_col")
    y_col = viz_config.get("y_col")

    if chart_type == "bar" and x_col:
        df.groupby(x_col)[y_col].mean().plot(kind="bar", ax=ax)
        ax.set_xlabel(x_col)
        ax.set_ylabel(f"平均 {y_col}")
    elif chart_type == "line" and x_col:
        df.plot(x=x_col, y=y_col, kind="line", ax=ax)
    elif chart_type == "scatter" and x_col:
        df.plot(x=x_col, y=y_col, kind="scatter", ax=ax, alpha=0.5)
    elif chart_type == "box":
        df[y_col].plot(kind="box", ax=ax)
    else:  # histogram
        df[y_col].plot(kind="hist", ax=ax, bins=20)
        ax.set_xlabel(y_col)

    ax.set_title(f"{y_col} の分析（{chart_type}グラフ）")
    plt.tight_layout()
    plt.savefig(save_path, dpi=150)
    print(f"✅ グラフ保存: {save_path}")
    return fig

# 使用例
df = pd.read_csv("sales_data.csv")
viz = decide_visualization(df, "monthly_sales")
print(f"推奨グラフ: {viz['chart_type']} - 理由: {viz['reason']}")
create_chart(df, viz, "sales_chart.png")
```

## よくあるエラーと対処法

### エラー1: `ResourceExhausted` （レート制限）

Pandas で大量の行を処理している場合、1つのプロンプトが長くなりすぎてレート制限に引っかかることがあります。

```python
import time
from google.api_core.exceptions import ResourceExhausted

def safe_generate(model, prompt: str, max_retries: int = 3) -> str:
    """
    レート制限に対応した安全な生成関数。
    指数バックオフで自動リトライする。
    """
    for attempt in range(max_retries):
        try:
            response = model.generate_content(prompt)
            return response.text
        except ResourceExhausted:
            wait_time = 2 ** attempt  # 1秒、2秒、4秒
            print(f"レート制限。{wait_time}秒後にリトライ... ({attempt + 1}/{max_retries})")
            time.sleep(wait_time)
    raise Exception("最大リトライ回数に達しました")
```

### エラー2: プロンプトが長すぎてトークン制限超過

Gemini 2.5 Flash のコンテキストウィンドウは約 100万トークンですが、DataFrame を全て渡すのは現実的ではありません。

```python
def truncate_df_for_prompt(df: pd.DataFrame, max_rows: int = 50) -> pd.DataFrame:
    """
    プロンプト用に DataFrame を適切なサイズに縮小する。
    統計的代表性を維持するためランダムサンプリングを使用。
    """
    if len(df) <= max_rows:
        return df

    # 層化サンプリング（数値列の分布を保持）
    numeric_col = df.select_dtypes(include='number').columns
    if len(numeric_col) > 0:
        primary_col = numeric_col[0]
        df['_quantile'] = pd.qcut(df[primary_col], q=min(10, max_rows), labels=False, duplicates='drop')
        sampled = df.groupby('_quantile', group_keys=False).apply(
            lambda x: x.sample(min(len(x), max(1, max_rows // 10)), random_state=42)
        )
        return sampled.drop('_quantile', axis=1).head(max_rows)

    return df.sample(max_rows, random_state=42)
```

### エラー3: Gemini の返答が期待した形式でない

```python
import json
import re

def extract_json_from_response(text: str) -> dict:
    """
    Gemini の返答からJSONを抽出する（マークダウンコードブロック対応）。
    """
    # コードブロック内のJSONを優先的に抽出
    code_block = re.search(r'```(?:json)?\s*(\{.*?\})\s*```', text, re.DOTALL)
    if code_block:
        return json.loads(code_block.group(1))

    # 裸のJSONを抽出
    json_match = re.search(r'\{[^{}]*\}', text, re.DOTALL)
    if json_match:
        return json.loads(json_match.group())

    raise ValueError(f"JSONが見つかりませんでした: {text[:200]}")
```

## FAQ

**Q. Gemini API の料金はどのくらいかかりますか？**

Gemini 2.5 Flash は入力トークン 100万あたり約 $0.15、出力 100万あたり約 $0.60 です（2026年4月時点）。通常のデータ分析用途では、1回の分析あたり数十〜数百円程度に収まることがほとんどです。コスト削減のヒントについては [Gemini API コスト完全最適化ガイド](/articles/gemini-api/gemini-api-cost-optimization-complete-guide) で詳しく解説しています。

**Q. Google Colab で使えますか？**

はい、Google Colab は Pandas と Gemini API の両方をサポートしています。`pip install google-generativeai` でインストールでき、Colab の秘密管理機能（左側パネルの🔑アイコン）で API キーを安全に管理できます。詳しくは [Google Colab × Gemini API 完全ガイド](/articles/gemini-dev/google-colab-gemini-guide) を参照してください。

**Q. 機密データを Gemini API に送っても大丈夫ですか？**

Google の API データ利用ポリシーでは、API 経由で送信されたデータはモデルの学習に使用されない（デフォルト設定）とされています。ただし、本番環境の機密データを扱う場合は、個人情報や機密情報をマスキングしてから送信することを強く推奨します。

**Q. pandas の代わりに polars でも使えますか？**

はい。polars の DataFrame も `to_pandas()` で変換するか、`to_string()` / `write_csv()` で文字列化してプロンプトに渡せます。処理速度にこだわる場合、データ加工は polars で行い、Gemini への送信部分のみ文字列変換するのが最も効率的です。

**Q. 日本語のデータでも精度よく動きますか？**

Gemini 2.5 シリーズは多言語対応が非常に優れており、日本語データの理解・分析においても高精度な結果を出します。列名や値が日本語でもプロンプトを日本語で記述すれば、適切な分析を返してくれます。
