## はじめに：YouTube 動画 × Gemini API で広がる自動化の可能性

「長い YouTube 動画を要点だけ把握したい」「英語のチュートリアル動画に日本語字幕を付けたい」——そんな悩みを、Gemini API を使って Python スクリプト 1 本で解決できます。

Gemini API のマルチモーダル能力と Files API を組み合わせると、YouTube 動画の音声を文字起こしし、構造化した要約を生成し、SRT 形式の字幕ファイルを出力するツールを自作することができます。本記事では、環境構築からコード実装・エラー対処まで、すべてのステップを実践形式で解説します。

対象読者は **Python の基本文法を理解している方**で、Gemini API の利用経験がなくても読み進められるよう丁寧に説明しています。

## Step 1：YouTube 動画の音声をダウンロードする

yt-dlp を使って YouTube 動画の音声を MP3 形式でダウンロードします。

```python
import yt_dlp
import os

def download_youtube_audio(url: str, output_dir: str = "./audio") -> str:
    """
    YouTube 動画の音声を MP3 形式でダウンロードし、
    保存先のファイルパスを返す関数。

    Args:
        url: YouTube 動画の URL
        output_dir: 音声ファイルの保存先ディレクトリ

    Returns:
        ダウンロードされた音声ファイルのパス
    """
    os.makedirs(output_dir, exist_ok=True)

    ydl_opts = {
        "format": "bestaudio/best",
        "outtmpl": f"{output_dir}/%(id)s.%(ext)s",
        "postprocessors": [
            {
                "key": "FFmpegExtractAudio",
                "preferredcodec": "mp3",
                "preferredquality": "128",
            }
        ],
        "quiet": True,
    }

    with yt_dlp.YoutubeDL(ydl_opts) as ydl:
        info = ydl.extract_info(url, download=True)
        video_id = info["id"]
        audio_path = f"{output_dir}/{video_id}.mp3"

    print(f"✅ 音声ダウンロード完了: {audio_path}")
    return audio_path


# 使用例
# audio_file = download_youtube_audio("https://www.youtube.com/watch?v=EXAMPLE_VIDEO_ID")
```

ダウンロードする音声の品質は `preferredquality` で調整できます。長尺動画の場合は `"64"` に下げるとファイルサイズを抑えられます。

## Step 2：Gemini Files API で音声をアップロードする

ダウンロードした音声ファイルを Gemini の Files API にアップロードします。Gemini API は Files API 経由でアップロードされたファイルを最大 2 日間保持するため、同じファイルを繰り返し分析する場合は再アップロード不要です。

```python
import google.genai as genai
import google.genai.types as types
import os
import time

# APIキーの設定
client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

def upload_audio_to_gemini(audio_path: str) -> genai.types.File:
    """
    音声ファイルを Gemini Files API にアップロードする関数。

    Args:
        audio_path: アップロードする音声ファイルのパス

    Returns:
        アップロードされたファイルオブジェクト
    """
    print(f"📤 Files API へアップロード中: {audio_path}")

    with open(audio_path, "rb") as f:
        uploaded_file = client.files.upload(
            file=f,
            config=types.UploadFileConfig(
                mime_type="audio/mpeg",
                display_name=os.path.basename(audio_path),
            ),
        )

    # アップロード完了を待機
    while uploaded_file.state.name == "PROCESSING":
        time.sleep(3)
        uploaded_file = client.files.get(name=uploaded_file.name)

    if uploaded_file.state.name == "FAILED":
        raise RuntimeError(f"ファイルのアップロードに失敗しました: {uploaded_file.state}")

    print(f"✅ アップロード完了: {uploaded_file.uri}")
    return uploaded_file
```

Files API の詳しい使い方は [Gemini 音声理解 API ガイド](/articles/gemini-api/gemini-audio-understanding) で解説しています。

## Step 3：Gemini API で動画内容を要約する

アップロードした音声ファイルを使って、Gemini に要約を生成させます。System Instructions でプロンプトを最適化することで、箇条書き・章立て・キーポイント抽出など、目的に合った出力形式を指定できます。

```python
def summarize_video(uploaded_file: genai.types.File, language: str = "ja") -> str:
    """
    アップロードされた音声ファイルを Gemini で要約する関数。

    Args:
        uploaded_file: Files API にアップロードされたファイルオブジェクト
        language: 要約の言語（"ja" = 日本語, "en" = 英語）

    Returns:
        要約テキスト
    """
    lang_instruction = (
        "日本語で" if language == "ja" else "in English"
    )

    system_prompt = f"""あなたは動画コンテンツの専門的な要約者です。
提供された音声の内容を{lang_instruction}分析し、以下の形式で出力してください：

1. **タイトル**: 動画の主題を一言で表したタイトル
2. **概要**: 100字以内の要点まとめ
3. **主なポイント**: 箇条書きで 5〜8 項目
4. **結論**: 視聴者が得られる主なメッセージ（2〜3文）
"""

    response = client.models.generate_content(
        model="gemini-2.5-pro",
        contents=[
            types.Part.from_uri(
                file_uri=uploaded_file.uri,
                mime_type="audio/mpeg",
            ),
            types.Part.from_text(
                "この音声コンテンツを指定された形式で要約してください。"
            ),
        ],
        config=types.GenerateContentConfig(
            system_instruction=system_prompt,
            temperature=0.3,  # 低めに設定して一貫性を高める
        ),
    )

    return response.text


# 期待する出力例:
# **タイトル**: Gemini API 活用術：マルチモーダル処理の基礎
# **概要**: Gemini API を使ったマルチモーダル処理の基本的な使い方を解説...
# **主なポイント**:
# - Files API でのファイルアップロード方法
# - テキスト・画像・音声の組み合わせ処理
# ...
```

## Step 4：SRT 形式の字幕を自動生成する

Gemini はタイムスタンプ付きの文字起こしを生成する能力も持っています。これを SRT（SubRip Text）形式に変換することで、動画プレーヤーで読み込める字幕ファイルを作成できます。

```python
import re

def generate_subtitles(uploaded_file: genai.types.File, output_path: str = "output.srt") -> str:
    """
    音声ファイルから SRT 形式の字幕を生成する関数。

    Args:
        uploaded_file: Files API にアップロードされたファイルオブジェクト
        output_path: 出力する SRT ファイルのパス

    Returns:
        生成された SRT テキスト
    """
    subtitle_prompt = """この音声を文字起こしし、以下の厳密な SRT 形式で出力してください。
他のテキストは一切含めず、SRT 形式のみを出力してください：

1
00:00:00,000 --> 00:00:05,000
最初の字幕テキスト

2
00:00:05,000 --> 00:00:10,000
次の字幕テキスト

各字幕ブロックは 1〜5 秒程度の長さにし、1行あたり最大 40 文字にしてください。"""

    response = client.models.generate_content(
        model="gemini-2.5-pro",
        contents=[
            types.Part.from_uri(
                file_uri=uploaded_file.uri,
                mime_type="audio/mpeg",
            ),
            types.Part.from_text(subtitle_prompt),
        ],
        config=types.GenerateContentConfig(
            temperature=0.1,  # 字幕生成は正確さを優先
        ),
    )

    srt_content = response.text

    # SRT ファイルに保存
    with open(output_path, "w", encoding="utf-8") as f:
        f.write(srt_content)

    print(f"✅ 字幕ファイルを保存しました: {output_path}")
    return srt_content


# 期待する出力例（output.srt の内容）:
# 1
# 00:00:00,000 --> 00:00:04,500
# こんにちは。今日は Gemini API について説明します。
#
# 2
# 00:00:04,500 --> 00:00:09,200
# まず最初に API キーの取得方法から始めましょう。
```

## 全体を統合したコンプリートスクリプト

上記のステップを 1 つのスクリプトに統合した、実際に使えるツールを以下に示します。

```python
"""
YouTube 動画自動要約・字幕生成ツール
使い方: python youtube_summarizer.py <YouTube_URL>
"""

import sys
import os
import time
import yt_dlp
import google.genai as genai
import google.genai.types as types

# APIクライアントの初期化
client = genai.Client(api_key=os.environ.get("GEMINI_API_KEY"))


def main(youtube_url: str):
    print(f"🎬 処理開始: {youtube_url}\n")

    # Step 1: 音声をダウンロード
    print("📥 Step 1: 音声をダウンロード中...")
    os.makedirs("./audio", exist_ok=True)
    ydl_opts = {
        "format": "bestaudio/best",
        "outtmpl": "./audio/%(id)s.%(ext)s",
        "postprocessors": [{"key": "FFmpegExtractAudio", "preferredcodec": "mp3", "preferredquality": "128"}],
        "quiet": True,
    }
    with yt_dlp.YoutubeDL(ydl_opts) as ydl:
        info = ydl.extract_info(youtube_url, download=True)
        video_id = info["id"]
        audio_path = f"./audio/{video_id}.mp3"
    print(f"  ✅ 音声を保存: {audio_path}")

    # Step 2: Files API にアップロード
    print("\n📤 Step 2: Gemini Files API にアップロード中...")
    with open(audio_path, "rb") as f:
        uploaded = client.files.upload(
            file=f,
            config=types.UploadFileConfig(mime_type="audio/mpeg"),
        )
    while uploaded.state.name == "PROCESSING":
        time.sleep(3)
        uploaded = client.files.get(name=uploaded.name)
    print(f"  ✅ アップロード完了")

    # Step 3: 要約を生成
    print("\n🤖 Step 3: 要約を生成中...")
    summary_response = client.models.generate_content(
        model="gemini-2.5-pro",
        contents=[
            types.Part.from_uri(file_uri=uploaded.uri, mime_type="audio/mpeg"),
            types.Part.from_text("この音声の内容を日本語で要約してください。主なポイントを箇条書きで 5〜8 項目挙げてください。"),
        ],
        config=types.GenerateContentConfig(temperature=0.3),
    )
    summary_text = summary_response.text
    with open(f"./summary_{video_id}.txt", "w", encoding="utf-8") as f:
        f.write(summary_text)
    print(f"  ✅ 要約を保存: ./summary_{video_id}.txt")

    # Step 4: 字幕を生成
    print("\n📝 Step 4: 字幕（SRT）を生成中...")
    subtitle_response = client.models.generate_content(
        model="gemini-2.5-pro",
        contents=[
            types.Part.from_uri(file_uri=uploaded.uri, mime_type="audio/mpeg"),
            types.Part.from_text(
                "この音声を SRT 形式で文字起こしし、タイムスタンプ付き字幕を生成してください。SRT 形式のみを出力し他のテキストは含めないでください。"
            ),
        ],
        config=types.GenerateContentConfig(temperature=0.1),
    )
    with open(f"./subtitle_{video_id}.srt", "w", encoding="utf-8") as f:
        f.write(subtitle_response.text)
    print(f"  ✅ 字幕を保存: ./subtitle_{video_id}.srt")

    # Step 5: アップロードファイルを削除（ストレージ節約）
    client.files.delete(name=uploaded.name)
    print("\n🗑️ アップロードファイルを削除しました")
    print("\n✨ 処理完了！")
    print(f"  要約: ./summary_{video_id}.txt")
    print(f"  字幕: ./subtitle_{video_id}.srt")


if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("使い方: python youtube_summarizer.py <YouTube_URL>")
        sys.exit(1)
    main(sys.argv[1])
```

このスクリプトを使えば、例えば 30 分のチュートリアル動画も 1〜2 分程度で要約・字幕生成できます。

## よくあるエラーと対処法

### エラー 1：`yt_dlp.utils.DownloadError`

YouTube 側の仕様変更で URL フォーマットが変わることがあります。`pip install -U yt-dlp` でライブラリを最新版に更新してください。

### エラー 2：`google.genai.errors.ResourceExhausted`（429）

API のレート制限に達した場合です。無料枠では 1 分あたり 15 リクエストの制限があります。`time.sleep(10)` をリクエスト間に挿入するか、有料プランへのアップグレードを検討してください。

### エラー 3：字幕のタイムスタンプがずれる

音声の品質（BGM・雑音）が高い場合に起こりやすい問題です。`yt_dlp` の `preferredquality` を `"192"` に上げるか、より明瞭な音声を対象にすることで改善できます。また、Gemini への指示に「正確なタイムスタンプを維持してください」と追記すると精度が向上します。

マルチモーダル処理をより本格的な本番環境で活用したい場合は、[Gemini API マルチモーダル技術集](/articles/gemini-api/gemini-api-multimodal-techniques) で高度なテクニックを解説しています。

## FAQ

**Q1. YouTube のプレミアム動画や会員限定動画にも使えますか？**

プレミアム動画や会員限定コンテンツは利用規約上ダウンロードが制限されている場合があります。本記事のツールは自分がアクセス権を持つ動画のみに使用し、著作権や利用規約を必ず確認してください。

**Q2. 1 時間を超える長時間動画に対応できますか？**

Files API は最大 2 GB のファイルを受け付けますが、Gemini API のコンテキストウィンドウには上限があります。長時間動画の場合は 10〜15 分ごとに分割して処理し、要約を後から結合するアプローチが効果的です。

**Q3. 日本語以外の動画にも対応していますか？**

Gemini は多言語対応しているため、英語・中国語・韓国語など多くの言語で同様に動作します。`summarize_video()` 関数の `language` 引数を `"en"` に変えるだけで、英語での要約生成が可能です。字幕生成時にも言語を指定することで翻訳字幕を生成できます。

**Q4. API 利用料金の目安はどのくらいですか？**

Gemini 2.5 Pro のコスト感は音声 1 時間あたり約 $0.10〜$0.30 程度（2026 年 4 月現在、トークン数によって変動）です。無料枠（1 分あたり 15 リクエスト）でも個人利用には十分ですが、大量バッチ処理を行う場合は Batch API の活用も検討してください。
