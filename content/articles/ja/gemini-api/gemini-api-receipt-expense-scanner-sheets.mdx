## はじめに：領収書管理をAIで自動化しよう

フリーランスや個人事業主にとって、領収書の整理・経費管理は毎月の悩みの種です。スマートフォンで撮影した領収書を手動でスプレッドシートへ転記する作業は、時間がかかるうえにミスも起きやすいものです。

この記事では、**Gemini API のマルチモーダル（画像認識）機能**と **Google Sheets API** を組み合わせて、領収書の画像を自動解析し、経費データをスプレッドシートへ自動記録するPythonシステムを構築する方法を解説します。

この記事で学べること:

- Gemini API で画像から日付・店名・金額・税区分などを自動抽出する方法
- Google Sheets API を使って経費データを自動書き込みする方法
- 複数の領収書を一括処理するバッチ処理の実装手順

対象読者は、PythonとGemini APIの基本的な使い方を知っている中級者の方です。環境設定から実際に動くコードまで、ステップごとに説明します。

## 仕組みの解説

このシステムは以下の3ステップで動作します。

**Step 1 — 画像をGemini APIへ送信**

Gemini のマルチモーダル機能を使い、領収書の画像とプロンプトを組み合わせてAPIへ送信します。「日付」「店名」「合計金額」「消費税額」「税区分」「支払い方法」を構造化データとして返すよう指示します。

**Step 2 — Gemini が JSON 形式で情報を返す**

プロンプトを工夫することで、Gemini は画像内の情報を整理し、プログラムで扱いやすいJSON形式にして返します。

**Step 3 — Google Sheets API で自動書き込み**

抽出したデータをGoogle スプレッドシートの指定シートへ追記します。

## ステップバイステップの実装

### 1. Gemini API で領収書を解析する関数

```python
import google.generativeai as genai
import base64
import json
import os
from pathlib import Path

# Gemini APIの初期化
genai.configure(api_key=os.environ["GEMINI_API_KEY"])
model = genai.GenerativeModel("gemini-2.5-flash")

def analyze_receipt(image_path: str) -> dict:
    """
    領収書画像をGemini APIで解析し、経費データを返す。

    Args:
        image_path: 領収書画像のファイルパス（JPEG/PNG）

    Returns:
        dict: date, store_name, total_amount, tax_amount,
              tax_rate, tax_type, payment_method, notes
    """
    with open(image_path, "rb") as f:
        image_data = base64.b64encode(f.read()).decode("utf-8")

    suffix = Path(image_path).suffix.lower()
    mime_type = "image/jpeg" if suffix in [".jpg", ".jpeg"] else "image/png"

    prompt = """
この領収書・レシートの画像を解析し、以下の情報をJSON形式で返してください。
情報が読み取れない場合は null を設定してください。
JSONのみを返してください。説明文やマークダウンは不要です。

{
  "date": "YYYY-MM-DD形式の日付",
  "store_name": "店名または発行者名",
  "total_amount": 税込合計金額（数値のみ、円単位）,
  "tax_amount": 消費税額（数値のみ、不明な場合はnull）,
  "tax_rate": 消費税率（例: 10 または 8、不明な場合はnull）,
  "tax_type": "課税" または "非課税" または "軽減税率",
  "payment_method": "現金" または "クレジットカード" または "電子マネー" または "その他",
  "notes": "品目の概要など（不要な場合は空文字）"
}
"""

    response = model.generate_content([
        {"mime_type": mime_type, "data": image_data},
        prompt,
    ])

    raw = response.text.strip()
    if raw.startswith("```"):
        raw = raw.split("```")[1]
        if raw.startswith("json"):
            raw = raw[4:]

    return json.loads(raw.strip())
```

実行例と期待される出力:

```python

print(result)
# 出力例:
# {

#   "tax_rate": 10,
#   "tax_type": "課税",
#   "payment_method": "クレジットカード",
#   "notes": "コーヒー、ケーキ"
# }
```

### 2. Google Sheets API でデータを書き込む関数

```python
from googleapiclient.discovery import build
from google.oauth2 import service_account

SCOPES = ["https://www.googleapis.com/auth/spreadsheets"]
SPREADSHEET_ID = "YOUR_SPREADSHEET_ID"  # スプレッドシートのURLからIDを取得
SHEET_NAME = "経費記録"

def get_sheets_service():
    """Google Sheets API のサービスオブジェクトを返す。"""
    creds = service_account.Credentials.from_service_account_file(
        os.environ["GOOGLE_APPLICATION_CREDENTIALS"], scopes=SCOPES
    )
    return build("sheets", "v4", credentials=creds)

def append_expense_to_sheet(expense: dict, filename: str) -> None:
    """
    経費データをGoogle スプレッドシートに追記する。

    Args:
        expense: analyze_receipt() が返したデータ辞書
        filename: 元の領収書ファイル名（原本照合用）
    """
    service = get_sheets_service()

    row = [
        expense.get("date", ""),
        expense.get("store_name", ""),
        expense.get("total_amount", ""),
        expense.get("tax_amount", ""),
        expense.get("tax_rate", ""),
        expense.get("tax_type", ""),
        expense.get("payment_method", ""),
        expense.get("notes", ""),
        filename,
    ]

    result = service.spreadsheets().values().append(
        spreadsheetId=SPREADSHEET_ID,
        range=f"{SHEET_NAME}!A:I",
        valueInputOption="USER_ENTERED",
        body={"values": [row]},
    ).execute()

    updated = result.get("updates", {}).get("updatedCells", 0)
    print(f"  ✅ {updated} セル追記完了")
```

### 3. 複数ファイルを一括処理するメイン関数

```python
import time

def process_receipts(image_dir: str) -> None:
    """
    指定ディレクトリ内の領収書画像を一括処理してスプレッドシートへ記録する。

    Args:
        image_dir: 領収書画像が格納されたディレクトリのパス
    """
    image_dir = Path(image_dir)
    images = (
        list(image_dir.glob("*.jpg"))
        + list(image_dir.glob("*.jpeg"))
        + list(image_dir.glob("*.png"))
    )

    if not images:
        print("画像ファイルが見つかりませんでした。")
        return

    print(f"{len(images)} 件の領収書を処理します...\n")
    success, errors = 0, 0

    for image_path in sorted(images):
        print(f"解析中: {image_path.name}")
        try:
            expense = analyze_receipt(str(image_path))
            store = expense.get("store_name", "不明")
            amount = expense.get("total_amount", "-")
            print(f"  店名: {store} / 金額: {amount}円")

            append_expense_to_sheet(expense, image_path.name)
            success += 1
            time.sleep(1)  # レート制限対策

        except json.JSONDecodeError as e:
            print(f"  JSONパースエラー: {e}")
            errors += 1
        except Exception as e:
            print(f"  エラー: {e}")
            errors += 1

    print(f"\n完了: 成功 {success} 件 / エラー {errors} 件")


if __name__ == "__main__":
    process_receipts("./receipts")
```

```

## よくあるエラーと対処法

### エラー1: `json.JSONDecodeError`

Gemini が説明文を余分に含めて返すことがあります。プロンプトの最後に「JSONのみを返してください」と明記すると改善されます。それでも発生する場合はプロンプトに「\`\`\`json \`\`\` などのマークダウンを使わないでください」と追記してください。

### エラー2: `403 Forbidden`（Google Sheets API）

サービスアカウントのメールアドレスに対象スプレッドシートの **編集権限** が付与されていない可能性があります。スプレッドシートを開き「共有」→ サービスアカウントのメールアドレスを「編集者」として追加してください。

### エラー3: 金額が正しく読み取れない

手書き領収書や印字がかすれた画像では精度が下がります。画像解像度を上げる（長辺1,200px以上推奨）か、精度重視の場面では `gemini-2.5-flash` から `gemini-2.5-pro` に切り替えることで改善できます。

### エラー4: `ResourceExhausted`（429 エラー）

APIのレート制限に達しています。`time.sleep(1)` を `time.sleep(3)` に増やしてください。Google AI Studio の無料プランでは1分あたり15リクエストの制限があります。

## 応用・発展的な活用法

### 勘定科目の自動分類

プロンプトに勘定科目の分類も含めると、確定申告や帳簿管理がさらに楽になります。

```python
# プロンプト追記例
'"expense_category": "交通費 / 飲食費 / 消耗品費 / 通信費 / その他 のいずれか"'
```

この一行を追加するだけで、各領収書が自動的にカテゴリ分けされ、月次の集計も簡単になります。

### スマートフォンから即時記録（Webhook連携）

Flask などで簡単なWebサーバーを立てると、スマートフォンのLINEやメールから写真を送るだけで即座にスプレッドシートへ記録できます。外出先で領収書を受け取ったその場で処理できるようになるため、月末のまとめ作業が不要になります。

### 月次サマリーの自動生成

Google Sheets の SUMIF 関数と Gemini API の要約機能を組み合わせると、月末に「今月の経費合計と主な支出内訳」をメールで自動送信するシステムも実現できます。

Gemini API の構造化出力をさらに活用したい方は、[Gemini API 構造化出力 完全ガイド](/articles/gemini-advanced/gemini-structured-output-production-guide) も合わせてご覧ください。

## FAQ

**Q1. 手書き領収書にも対応できますか？**

対応できますが、印刷された領収書と比べると精度が下がる場合があります。画像解像度を高く（長辺2,000px以上）し、明るい環境で影が入らないように撮影することが重要です。精度が重要な場面では `gemini-2.5-pro` モデルへの切り替えも検討してください。

**Q2. 海外の領収書（英語・中国語など）にも使えますか？**

はい、Gemini のマルチリンガル対応により、英語・中国語・韓国語などさまざまな言語の領収書に対応できます。プロンプトに「金額はすべて日本円換算で入力し、元の通貨と金額も notes フィールドに記録してください」と追記すると外貨対応も可能です。

**Q3. 月に何枚まで無料で処理できますか？**

Google AI Studio の無料枠では、`gemini-2.5-flash` で1分あたり15リクエスト、1日あたり1,500リクエストが上限です。`time.sleep(1)` を入れた場合、1日約1,000〜1,200枚まで処理できる計算です。大量処理が必要な場合は有料プランへの移行を検討してください。

**Q4. セキュリティ面で注意することはありますか？**

領収書には個人情報や取引情報が含まれます。以下の点にご注意ください: APIキーを環境変数で管理しコードに直書きしない / サービスアカウントには必要最小限の権限（Sheets APIへの書き込み権限のみ）を付与する / 処理後の画像データは速やかに削除するか、アクセス制限されたストレージへ移動します。
