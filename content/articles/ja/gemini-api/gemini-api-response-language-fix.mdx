Gemini APIを使って日本語のチャットボットや自動化ツールを作っていると、こんな経験はありませんか？

「日本語でプロンプトを送ったのに、なぜかレスポンスが英語で返ってくる」「最初は日本語で答えてくれるのに、会話が続くうちに突然英語に切り替わる」

これはGemini APIを使い始めた開発者がよく直面するトラブルです。原因がわかれば対処は難しくありませんが、何が起きているのかを理解していないと、どこを直せばよいか見当もつかないことがあります。

この記事では、Gemini APIのレスポンス言語が意図せず切り替わる問題について、原因ごとに具体的な解決策を丁寧に解説します。

## なぜ Gemini API のレスポンスが英語になるのか

Gemini は本来、ユーザーが使用した言語を自動検出し、同じ言語で返答しようとします。しかし、以下のような条件が重なると、意図しない言語でレスポンスが返ってくることがあります。

**主な原因**

- **システムインストラクションが英語で書かれている**: モデルがシステム指示の言語を参考にして返答言語を決める場合がある
- **英語のサンプルコードをそのままコピペしている**: few-shot例が英語だと、応答も英語になりやすい
- **言語を明示的に指定していない**: プロンプトに言語指定がないと、モデルが「最適な言語」を自動選択する
- **会話履歴に英語が混在している**: マルチターン会話で過去のメッセージに英語が含まれると言語が揺れる
- **モデルバージョンによる挙動の違い**: Gemini 2.5 Pro, Flash など、モデルによって言語検出の精度が異なる

これらを1つずつ確認し、該当する原因を潰していくことが解決への近道です。

## 解決策1: システムインストラクションを日本語で書く

Gemini APIには「システムインストラクション（system_instruction）」という機能があります。これはモデルの振る舞いを定義する特別な指示で、会話全体を通じて適用されます。

英語でシステムインストラクションを書いていると、モデルが英語モードで動作しやすくなります。**日本語で応答させたい場合は、システムインストラクションも日本語で書くことが第一歩**です。

```python
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")

# システムインストラクションを日本語で書く
model = genai.GenerativeModel(
    model_name="gemini-2.5-pro-latest",
    system_instruction="あなたは日本語で回答するAIアシスタントです。ユーザーの質問に対して、常に日本語で丁寧かつ正確に答えてください。英語で質問されても、必ず日本語で回答してください。"
)

response = model.generate_content("今日の天気を教えてください。")
print(response.text)
# 期待する出力例: 「申し訳ありませんが、私はリアルタイムの天気情報にアクセスする機能を持っていません...」
```

**ポイント**: システムインストラクションの中で「必ず〇〇語で回答する」という指示を明示的に書くと、より安定した挙動になります。

## 解決策2: プロンプトに言語指定を追加する

システムインストラクションを変更できない場合や、特定のリクエストだけ日本語で返してほしい場合は、ユーザーメッセージの中に言語指定を含めます。

```python
# ユーザーのプロンプトに言語指定を添える
user_input = "必ず日本語で回答してください。\n\n" + original_user_input

# または、テンプレートとして定義する
def make_japanese_prompt(text: str) -> str:
    return f"以下の質問に日本語で答えてください：\n\n{text}"

response = model.generate_content(make_japanese_prompt("AIとは何ですか？"))
print(response.text)
# 期待する出力: 「AIとは「人工知能（Artificial Intelligence）」の略称で...」
```

ただし、この方法はリクエストごとにトークンを消費するため、常に同じ言語で返してほしい場合はシステムインストラクションで設定する方が効率的です。

## 解決策3: マルチターン会話での言語の統一

チャット形式のアプリケーションでは、会話の途中から言語が切り替わることがあります。特に、英語のエラーメッセージや技術用語を含むメッセージが会話履歴に入ると、モデルが英語モードに移行しやすくなります。

この問題には2つのアプローチがあります。

**アプローチA: 会話履歴のリセット**

```python
# 会話が長くなってきたら、システムインストラクションを維持しながら履歴をリセット
chat = model.start_chat(history=[])

# システムインストラクションは引き継がれる
response = chat.send_message("前の会話の内容を要約してください。")
```

**アプローチB: メッセージに言語強化フレーズを挿入する**

```python
# 会話の折り返し地点でリマインドを挿入
def send_with_language_reminder(chat, message: str, remind_every: int = 5) -> str:
    turn_count = len(chat.history)
    if turn_count % remind_every == 0 and turn_count > 0:
        message = f"（以降も日本語で回答してください）\n\n{message}"
    response = chat.send_message(message)
    return response.text

chat = model.start_chat()
for user_msg in ["こんにちは", "AIについて教えて", "詳しく説明して"]:
    print(send_with_language_reminder(chat, user_msg))
```

## 解決策4: few-shot プロンプトの言語を日本語に統一する

Few-shot学習（例示プロンプティング）を使っている場合、例示の言語がレスポンス言語に影響します。英語の例を使っている場合は日本語に置き換えましょう。

```python
# 英語の例示（避けるべき）
bad_prompt = """
Example:
Q: What is the capital of Japan?
A: The capital of Japan is Tokyo.

Q: 日本の最大の都市はどこですか？
A:
"""

# 日本語の例示（推奨）
good_prompt = """
以下の形式で日本語で回答してください。

例：
Q: 日本の首都はどこですか？
A: 日本の首都は東京です。

Q: 日本の最大の都市はどこですか？
A:
"""

response = model.generate_content(good_prompt)
print(response.text)
# 期待する出力: 「A: 日本の最大の都市は東京です。東京は人口約1,400万人...」
```

## 解決策5: REST API を直接使う場合の設定

`generativelanguage.googleapis.com` を使ったREST APIで直接リクエストする場合も、同様にシステムインストラクションを日本語で設定します。

```bash
curl -X POST \
  "https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-pro-latest:generateContent?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "system_instruction": {
      "parts": [{
        "text": "あなたは日本語で回答するAIアシスタントです。ユーザーの質問に対して、常に日本語で丁寧に答えてください。"
      }]
    },
    "contents": [{
      "parts": [{
        "text": "機械学習とは何ですか？"
      }]
    }],
    "generationConfig": {
      "temperature": 0.7,
      "maxOutputTokens": 1024
    }
  }'
```

REST APIでは `system_instruction` フィールドが `contents` とは別に設定される点に注意してください。

## よくある間違いと確認チェックリスト

実際に「英語で返ってきた」という問題が起きたとき、以下の項目を順番に確認してください。

- **システムインストラクションの言語**: 英語になっていないか確認する
- **few-shot例の言語**: 英語のサンプルが混じっていないか確認する
- **プロンプトテンプレートの言語**: 動的に生成するプロンプトに英語テキストが埋め込まれていないか確認する
- **会話履歴の内容**: 過去のやり取りに英語メッセージが多く含まれていないか確認する
- **使用しているモデル**: モデルによって言語検出の精度が異なるため、別モデルで試してみる

よくある誤ったコードと修正例：

```python
# 誤り: 英語のシステムインストラクション
model = genai.GenerativeModel(
    model_name="gemini-2.5-pro-latest",
    system_instruction="You are a helpful assistant."
)

# 修正: 日本語のシステムインストラクション
model = genai.GenerativeModel(
    model_name="gemini-2.5-pro-latest",
    system_instruction="あなたは親切なアシスタントです。必ず日本語で回答してください。"
)
```

```python
# 誤り: 英語のラベルがプロンプトに混入している
template = f"""
# Task: Summarize the following text
テキスト: {user_text}
Output:
"""

# 修正: プロンプト全体を日本語にする
template = f"""
以下のテキストを日本語で要約してください：

テキスト：
{user_text}

要約：
"""
```

## FAQ

**Q. 日本語のシステムインストラクションを設定したのに、まだ英語で返ってきます。**

A. いくつかの可能性が考えられます。①ユーザーメッセージ自体が英語になっていないか確認してください。②few-shotの例が英語になっていないか確認してください。③APIのリクエストボディで `system_instruction` が正しいフィールドとして送信されているかデバッグしてください（`systemInstruction` と `system_instruction` の表記ゆれに注意）。

**Q. Gemini 2.5 Flash と Gemini 2.5 Pro で挙動が違います。**

A. はい、モデルによって言語検出の精度や指示への忠実さが異なります。一般的に、Pro系モデルはシステムインストラクションへの忠実度が高い傾向があります。Flash系はレスポンス速度を優先しているため、複雑な指示に対してはPro系の方が安定している場合があります。コスト重視の場合はFlashを使いつつ、プロンプト内での言語指定を強化する方法がおすすめです。

**Q. 英語で質問されても日本語で返してほしいのですが、どうすればよいですか？**

A. システムインストラクションに「ユーザーが英語で質問しても、必ず日本語で回答してください」という指示を明記するのが最も確実です。さらに、システムインストラクションの冒頭に優先度の高い指示として記述することをおすすめします。例：「【最重要ルール】言語に関わらず、返答は必ず日本語で行ってください。」

**Q. Node.js（JavaScript）でも同じ設定ができますか？**

A. はい、Node.js の `@google/generative-ai` パッケージでも同様です。JavaScriptではキャメルケースで `systemInstruction` プロパティを使って設定します。パッケージのバージョンによってAPIが異なる場合があるため、最新の公式ドキュメントを確認することをおすすめします。

**Q. 完全に言語を固定することはできますか？**

A. 100%完全に固定することは難しいですが、①日本語のシステムインストラクション＋②明示的な言語指定の組み合わせで、ほぼ確実に日本語レスポンスを維持できます。それでも稀に切り替わる場合は、レスポンスの言語を後処理で検出し、言語が間違っていたら再リクエストする仕組みを入れるとより堅牢になります。

## まとめ

Gemini APIのレスポンスが英語になる・言語が切り替わる問題には、主に以下の対処法があります。

- システムインストラクションを日本語で書き、明示的に「日本語で回答すること」を指示する
- プロンプトテンプレートおよびfew-shot例の言語を日本語に統一する
- マルチターン会話では定期的に言語指定をリマインドするか、長くなったら会話履歴をリセットする
- REST APIを使う場合は `system_instruction` フィールドに日本語の指示を設定する

システムインストラクションの設計については、[Gemini 2.5 Pro システムインストラクション完全マスター](/articles/gemini-api/gemini-25-pro-system-instructions-mastery-guide)に詳しい解説があります。また、APIエラー全般のトラブルシューティングは[Gemini API エラー完全対処ガイド](/articles/gemini-api/gemini-api-error-troubleshooting-guide)も参考にしてください。
