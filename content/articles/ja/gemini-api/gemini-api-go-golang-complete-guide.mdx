そこに **Gemini APIのGo SDKが登場**したことで、Goエンジニアは慣れ親しんだ言語のままAI機能を自分のサービスへ組み込めるようになりましました。

## 環境の準備

### 必要なもの

- Go 1.21以上（`go version` で確認）
- Gemini API キー（[Google AI Studio](https://aistudio.google.com/) で無料取得可能）

### APIキーの取得

1. [Google AI Studio](https://aistudio.google.com/) にアクセスしてGoogleアカウントでサインイン
2. 左サイドバーの「Get API key」をクリック
3. 「Create API key」を選択してキーを生成

生成されたAPIキーは安全な場所に保管してください。本記事のコード例では環境変数 `GEMINI_API_KEY` を通じてキーを参照します。

```bash
# 環境変数として設定（.bashrc や .zshrc に追記すると永続化できます）
export GEMINI_API_KEY="YOUR_API_KEY"
```

### プロジェクトのセットアップ

新しいGoモジュールを作成してGoogle AI Go SDKをインストールします。

```bash
# プロジェクトディレクトリを作成
mkdir gemini-go-example
cd gemini-go-example

# Goモジュールを初期化
go mod init gemini-go-example

# Google AI Go SDKをインストール
go get github.com/google/generative-ai-go/genai
go get google.golang.org/api/option
```

インストールが完了したら、`go.mod` に依存関係が追加されていることを確認してください。

## Step 1: 基本的なテキスト生成

まず最もシンプルなテキスト生成から始めましょう。プロジェクトルートに `main.go` を作成します。

```go
package main

import (
	"context"
	"fmt"
	"log"
	"os"

	"github.com/google/generative-ai-go/genai"
	"google.golang.org/api/option"
)

func main() {
	ctx := context.Background()

	// APIキーを環境変数から取得
	apiKey := os.Getenv("GEMINI_API_KEY")
	if apiKey == "" {
		log.Fatal("GEMINI_API_KEY 環境変数が設定されていません")
	}

	// クライアントを初期化
	client, err := genai.NewClient(ctx, option.WithAPIKey(apiKey))
	if err != nil {
		log.Fatalf("クライアントの作成に失敗しました: %v", err)
	}
	defer client.Close()

	// Gemini 2.5 Flash モデルを使用
	model := client.GenerativeModel("gemini-2.5-flash")

	// テキスト生成リクエストを送信
	resp, err := model.GenerateContent(ctx, genai.Text("Goとはどんなプログラミング言語ですか？3行で教えてください。"))
	if err != nil {
		log.Fatalf("コンテンツ生成に失敗しました: %v", err)
	}

	// レスポンスを表示
	for _, cand := range resp.Candidates {
		if cand.Content != nil {
			for _, part := range cand.Content.Parts {
				fmt.Println(part)
			}
		}
	}
}
```

実行してみましょう。

```bash
go run main.go
# 期待する出力例:
# Goは、Googleが開発したオープンソースのプログラミング言語です。
# シンプルな文法と高速なコンパイル、優れた並行処理機能が特徴です。
# Webサーバー・CLIツール・クラウドサービスの開発に広く使われています。
```

`client.Close()` を `defer` で呼び出すことで、関数終了時にリソースが確実に解放されます。Goらしい書き方ですね。

## Step 2: マルチターンチャットの実装

会話の文脈（履歴）を保持しながら複数回やり取りするチャットを実装します。Gemini APIの `ChatSession` を使えば簡単に実現できます。

```go
package main

import (
	"bufio"
	"context"
	"fmt"
	"log"
	"os"
	"strings"

	"github.com/google/generative-ai-go/genai"
	"google.golang.org/api/option"
)

func main() {
	ctx := context.Background()

	client, err := genai.NewClient(ctx, option.WithAPIKey(os.Getenv("GEMINI_API_KEY")))
	if err != nil {
		log.Fatal(err)
	}
	defer client.Close()

	model := client.GenerativeModel("gemini-2.5-flash")

	// System Instructionでアシスタントの役割を設定
	model.SystemInstruction = &genai.Content{
		Parts: []genai.Part{
			genai.Text("あなたはGoプログラミングの専門家です。初心者にも分かりやすく、簡潔に説明してください。"),
		},
	}

	// チャットセッションを開始（履歴は自動管理される）
	cs := model.StartChat()

	scanner := bufio.NewScanner(os.Stdin)
	fmt.Println("Goアシスタントと会話を開始します（'quit' で終了）")
	fmt.Println("---")

	for {
		fmt.Print("あなた: ")
		if !scanner.Scan() {
			break
		}

		input := strings.TrimSpace(scanner.Text())
		if input == "quit" || input == "" {
			break
		}

		// メッセージを送信（会話履歴は cs が自動で管理）
		resp, err := cs.SendMessage(ctx, genai.Text(input))
		if err != nil {
			log.Printf("エラー: %v", err)
			continue
		}

		fmt.Print("Gemini: ")
		for _, cand := range resp.Candidates {
			if cand.Content != nil {
				for _, part := range cand.Content.Parts {
					fmt.Println(part)
				}
			}
		}
		fmt.Println()
	}
}
```

`StartChat()` で取得した `ChatSession` オブジェクトが会話履歴を自動管理してくれます。2回目以降の質問でも前の内容を踏まえた回答が得られます。

## Step 3: ストリーミングレスポンスの実装

応答が長い場合や、UXをリアルタイムに改善したい場合は、ストリーミングを使うと効果的です。`GenerateContentStream` メソッドを使います。

```go
package main

import (
	"context"
	"fmt"
	"log"
	"os"

	"github.com/google/generative-ai-go/genai"
	"google.golang.org/api/iterator"
	"google.golang.org/api/option"
)

func main() {
	ctx := context.Background()

	client, err := genai.NewClient(ctx, option.WithAPIKey(os.Getenv("GEMINI_API_KEY")))
	if err != nil {
		log.Fatal(err)
	}
	defer client.Close()

	model := client.GenerativeModel("gemini-2.5-flash")

	// ストリーミングでコンテンツ生成
	iter := model.GenerateContentStream(ctx,
		genai.Text("Goのgoroutineとchannelについて、具体的なコード例を交えて詳しく説明してください。"),
	)

	fmt.Print("Gemini: ")
	for {
		resp, err := iter.Next()
		if err == iterator.Done {
			// イテレーションが正常に終了
			break
		}
		if err != nil {
			log.Fatalf("ストリームエラー: %v", err)
		}

		// チャンクごとに出力（\n なしでリアルタイム表示）
		for _, cand := range resp.Candidates {
			if cand.Content != nil {
				for _, part := range cand.Content.Parts {
					fmt.Print(part)
				}
			}
		}
	}
	fmt.Println() // 最後に改行
}
```

`iterator.Done` エラーでストリームの正常終了を検知します。これはGoのイテレータパターンに沿った実装です。

ストリーミングを使うと、ユーザーは生成が完了するまで待つことなく、段階的にテキストを読み進めることができます。Webアプリやチャットボットで特に有効です。

詳しいストリーミングの応用については[Gemini APIでストリーミング応答とマルチターン会話を実装する](/articles/gemini-api/streaming-and-chat)も参考にしてください。

## Step 4: マルチモーダル（画像解析）

Gemini 2.5 Flash はテキストだけでなく、画像・動画・PDFなども入力として受け取れます。ここでは画像を渡してその内容を説明してもらう例を紹介します。

```go
package main

import (
	"context"
	"fmt"
	"log"
	"os"

	"github.com/google/generative-ai-go/genai"
	"google.golang.org/api/option"
)

func main() {
	ctx := context.Background()

	client, err := genai.NewClient(ctx, option.WithAPIKey(os.Getenv("GEMINI_API_KEY")))
	if err != nil {
		log.Fatal(err)
	}
	defer client.Close()

	model := client.GenerativeModel("gemini-2.5-flash")

	// ローカル画像ファイルを読み込む
	imageData, err := os.ReadFile("sample.jpg")
	if err != nil {
		log.Fatalf("画像の読み込みに失敗しました: %v", err)
	}

	// テキストと画像を組み合わせてリクエスト
	resp, err := model.GenerateContent(ctx,
		genai.Text("この画像に何が写っていますか？詳しく教えてください。"),
		genai.ImageData("image/jpeg", imageData),
	)
	if err != nil {
		log.Fatalf("コンテンツ生成に失敗しました: %v", err)
	}

	for _, cand := range resp.Candidates {
		if cand.Content != nil {
			for _, part := range cand.Content.Parts {
				fmt.Println(part)
			}
		}
	}
}
```

`genai.ImageData(mimeType, data)` でバイナリの画像データを渡せます。JPEG・PNG・WebP・GIFなど主要なフォーマットに対応しています。

URLから画像を指定する場合は `genai.FileData` を使う方法もありますが、まずはローカルファイルの読み込みを習得しましょう。

## Step 5: Function Calling（ツール連携）

Function Callingは、Gemini APIが外部の関数やAPIを呼び出せるようにする仕組みです。Goのサービスと組み合わせることで、リアルタイム情報の取得や処理の自動化が可能になります。

```go
package main

import (
	"context"
	"fmt"
	"log"
	"os"

	"github.com/google/generative-ai-go/genai"
	"google.golang.org/api/option"
)

// 天気情報を返すダミー関数（実際の実装では外部APIを呼び出す）
func getWeather(city string) string {
	// ここでは例として固定値を返す
	weatherData := map[string]string{
		"東京":   "晴れ、気温22℃、湿度45%",
		"大阪":   "くもり、気温20℃、湿度55%",
		"札幌":   "雪、気温-2℃、湿度70%",
	}
	if weather, ok := weatherData[city]; ok {
		return weather
	}
	return "データなし"
}

func main() {
	ctx := context.Background()

	client, err := genai.NewClient(ctx, option.WithAPIKey(os.Getenv("GEMINI_API_KEY")))
	if err != nil {
		log.Fatal(err)
	}
	defer client.Close()

	model := client.GenerativeModel("gemini-2.5-flash")

	// ツール（Function）の定義
	weatherTool := &genai.Tool{
		FunctionDeclarations: []*genai.FunctionDeclaration{
			{
				Name:        "get_weather",
				Description: "指定した都市の現在の天気情報を取得します",
				Parameters: &genai.Schema{
					Type: genai.TypeObject,
					Properties: map[string]*genai.Schema{
						"city": {
							Type:        genai.TypeString,
							Description: "天気を調べたい都市名（例: 東京、大阪）",
						},
					},
					Required: []string{"city"},
				},
			},
		},
	}

	// ツールをモデルに設定
	model.Tools = []*genai.Tool{weatherTool}

	// ユーザーの質問
	resp, err := model.GenerateContent(ctx, genai.Text("東京の今日の天気を教えてください"))
	if err != nil {
		log.Fatal(err)
	}

	// Function Callが含まれているか確認
	for _, cand := range resp.Candidates {
		if cand.Content != nil {
			for _, part := range cand.Content.Parts {
				if fc, ok := part.(genai.FunctionCall); ok {
					fmt.Printf("Function呼び出し: %s\n", fc.Name)
					fmt.Printf("引数: %v\n", fc.Args)

					// 実際の関数を実行
					city := fmt.Sprintf("%v", fc.Args["city"])
					result := getWeather(city)
					fmt.Printf("天気情報: %s\n", result)
					// 期待する出力例:
					// Function呼び出し: get_weather
					// 引数: map[city:東京]
					// 天気情報: 晴れ、気温22℃、湿度45%
				} else {
					fmt.Println(part)
				}
			}
		}
	}
}
```

## よくあるエラーと対処法

Gemini API × Go の開発で遭遇しやすいエラーと、その対処法をまとめます。

### エラー1: APIキー認証エラー

```
PERMISSION_DENIED: API key not valid. Please pass a valid API key.
```

**対処法**: `GEMINI_API_KEY` 環境変数が正しく設定されているか確認してください。スペースや不要な文字が混入していないかも要チェックです。

```bash
echo $GEMINI_API_KEY  # 正しいキーが表示されるか確認
```

### エラー2: レート制限エラー

```
RESOURCE_EXHAUSTED: Quota exceeded for quota metric...
```

**対処法**: 無料プランではリクエスト数に制限があります。短時間に大量リクエストを送る場合は指数バックオフでリトライを実装しましょう。

```go
// シンプルなリトライ実装例
import "time"

func generateWithRetry(ctx context.Context, model *genai.GenerativeModel, prompt string) (*genai.GenerateContentResponse, error) {
	for i := 0; i < 3; i++ {
		resp, err := model.GenerateContent(ctx, genai.Text(prompt))
		if err == nil {
			return resp, nil
		}
		// 指数バックオフ: 1秒、2秒、4秒と待機
		time.Sleep(time.Duration(1<<uint(i)) * time.Second)
	}
	return nil, fmt.Errorf("3回リトライしましたが失敗しました")
}
```

### エラー3: コンテキストタイムアウト

長い処理や大きなファイルの送信時に発生することがあります。`context.WithTimeout` でタイムアウトを設定しましょう。

```go
// 30秒のタイムアウトを設定
ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
defer cancel()
```

## 発展的な活用：並行処理でバッチ処理を高速化

Goの強みである goroutine を活用して、複数のリクエストを並行処理するパターンを紹介します。

```go
package main

import (
	"context"
	"fmt"
	"log"
	"os"
	"sync"

	"github.com/google/generative-ai-go/genai"
	"google.golang.org/api/option"
)

func main() {
	ctx := context.Background()

	client, err := genai.NewClient(ctx, option.WithAPIKey(os.Getenv("GEMINI_API_KEY")))
	if err != nil {
		log.Fatal(err)
	}
	defer client.Close()

	model := client.GenerativeModel("gemini-2.5-flash")

	// 並行処理したいプロンプトのリスト
	prompts := []string{
		"Goの goroutine とは何ですか？1行で答えてください。",
		"Goの channel とは何ですか？1行で答えてください。",
		"Goの interface とは何ですか？1行で答えてください。",
	}

	results := make([]string, len(prompts))
	var wg sync.WaitGroup

	for i, prompt := range prompts {
		wg.Add(1)
		go func(idx int, p string) {
			defer wg.Done()

			resp, err := model.GenerateContent(ctx, genai.Text(p))
			if err != nil {
				results[idx] = fmt.Sprintf("エラー: %v", err)
				return
			}

			for _, cand := range resp.Candidates {
				if cand.Content != nil {
					for _, part := range cand.Content.Parts {
						results[idx] = fmt.Sprintf("%v", part)
					}
				}
			}
		}(i, prompt)
	}

	wg.Wait() // 全goroutineの完了を待機

	for i, result := range results {
		fmt.Printf("Q%d: %s\n", i+1, result)
	}
	// 期待する出力例:
	// Q1: goroutineはGoの軽量スレッドで、並行処理を簡単に実現できます。
	// Q2: channelはgoroutine間でデータを安全に受け渡す仕組みです。
	// Q3: interfaceはメソッドのシグネチャを定義する型で、ポリモーフィズムを実現します。
}
```

`sync.WaitGroup` で全goroutineの完了を待ち、結果を集約しています。APIのレート制限に注意しつつ、適切な並行数を設定してください。

## まとめ

ここではGo（Golang）を使ってGemini APIを活用するための基本的な流れを解説しました。

- **環境構築**: `google/generative-ai-go` パッケージのインストールとAPIキーの設定
- **テキスト生成**: `GenerateContent` でシンプルに実装
- **マルチターンチャット**: `StartChat()` + `SendMessage` で会話履歴を自動管理
- **ストリーミング**: `GenerateContentStream` でリアルタイムに逐次出力
- **マルチモーダル**: `genai.ImageData` で画像解析
- **Function Calling**: 外部関数との連携を実現
- **並行処理**: goroutineを活用した高効率なバッチ処理

Goのシンプルさと型安全性を活かすことで、堅牢なAIアプリケーションを構築できます。特にCloud Run・Kubernetes・gRPCなどGoが得意とするインフラ周りとの組み合わせが強力です。

まずは `go run main.go` で動かしてみることが大切です。小さなプロトタイプから始めて、少しずつ機能を拡張していきましょう。
