## はじめに — iPhone を AI の窓口にする

毎日使う iPhone を、Gemini API の強力な AI 機能と直接つなげられたら便利だと思いませんか。実は **iOS のショートカットアプリ** と **Gemini API** を組み合わせるだけで、Siri ショートカットや自動化フローから手軽に AI を呼び出せます。専用アプリは不要で、無料の Google アカウントと API キーさえあれば今すぐ始められます。

この記事では、Gemini API を iOS ショートカットから呼び出す方法を基礎から解説します。テキスト要約、翻訳、アイデア生成など実用的なショートカットを作りながら、仕組みを理解していきましょう。

## 準備するもの

iOS ショートカット × Gemini API 連携に必要なものは以下の 3 つだけです。

**必要なもの:**

- **iOS 16 以降の iPhone（または iPad）** — ショートカットアプリがプリインストール済みです
- **Google アカウント** — 無料アカウントで OK です
- **Gemini API キー** — [Google AI Studio](https://aistudio.google.com/) で無料発行できます

### Gemini API キーの取得方法

1. [Google AI Studio](https://aistudio.google.com/) にアクセスしてサインイン
2. 左サイドバーの「Get API key」をクリック
3. 「Create API key」→ プロジェクトを選択（または新規作成）
4. 表示された API キーをメモ帳などに安全に保存

API キーの発行は 1 〜 2 分で完了します。無料の API 枠（1 分あたり 15 リクエスト、1 日 1,500 リクエスト）で十分に試せます。

> **注意**: API キーは他人に見せないようにしてください。ショートカット内に直接埋め込む際は、そのショートカットを他者と共有しないよう気をつけましょう。

API キーの取得方法については [Gemini API クイックスタートガイド](/articles/gemini-api/gemini-api-quickstart) でも詳しく解説しています。

## iOS ショートカットから Gemini API を呼び出す仕組み

Gemini API は **REST API** として提供されているため、iOS の「ショートカット」アプリに含まれる「**URL の内容を取得**」アクションを使って HTTP リクエストを送るだけで呼び出せます。

呼び出し先の URL はこちらです:

```
https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent?key=YOUR_API_KEY
```

リクエスト本文（JSON）の基本形:

```json
{
  "contents": [
    {
      "parts": [
        {
          "text": "ここにプロンプトを入力します"
        }
      ]
    }
  ]
}
```

レスポンスの JSON から回答テキストを取り出すパスは以下の通りです:

```
candidates[0].content.parts[0].text
```

iOS ショートカットの「辞書の値を取得」アクションを使えばこのパスを辿って回答を取り出せます。

## 最初のショートカットを作る — テキスト要約ボット

では実際に、**選択したテキストを Gemini に要約させる**ショートカットを作ってみましょう。

### ショートカットの全体フロー

```
① 共有シートからテキストを受け取る
② テキストをプロンプトに埋め込む
③ Gemini API へ POST リクエストを送る
④ JSON レスポンスから回答テキストを取り出す
⑤ 結果を通知またはクリップボードに出力する
```

### ステップバイステップ

**ステップ 1: 新しいショートカットを作成**

ショートカットアプリを開き、右上の「+」をタップ。「ショートカット名」に「Gemini 要約」と入力します。

**ステップ 2: 入力の受け取り**

「アクションを追加」→「テキスト」→ 「入力から取得」を追加。共有シートからテキストを受け取れるようにします。

**ステップ 3: プロンプトのテキストを作成**

「テキスト」アクションを追加し、以下のように入力します（`[入力]` の部分に前ステップの変数を挿入）:

```
以下のテキストを日本語で3行以内に要約してください。

[入力テキスト]
```

**ステップ 4: API リクエストを送る**

「URL の内容を取得」アクションを追加して以下を設定します:

- **URL**: `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent?key=YOUR_API_KEY`
  （`YOUR_API_KEY` を実際のキーに置き換える）
- **方法**: POST
- **リクエスト本文**: JSON
- **本文の内容**: 以下の辞書を設定

```json
{
  "contents": [
    {
      "parts": [
        {
          "text": "[ステップ3で作ったテキスト変数]"
        }
      ]
    }
  ]
}
```

**ステップ 5: 回答を取り出す**

「辞書の値を取得」アクションを 3 回連続で追加し、以下の順にキーを指定します:

1. キー: `candidates` → 最初のアイテムを取得
2. キー: `content` → `parts` → 最初のアイテムを取得
3. キー: `text`

**ステップ 6: 結果を表示**

「クイックルック」アクション、または「通知を表示」アクションで取り出したテキストを表示します。

### ショートカットの動作確認

完成したら、Safari などで気になるテキストを選択→共有シート→「Gemini 要約」をタップしてみてください。数秒でテキストの要約が表示されれば成功です。

## 実用的なショートカットのレシピ集

基本の作り方を押さえたら、プロンプトを変えるだけでさまざまな用途に応用できます。

### レシピ 1: 英日・日英 翻訳ショートカット

プロンプトを以下のように変えるだけで、翻訳ショートカットになります:

```
以下のテキストを英語に翻訳してください。自然な英語で、原文のニュアンスを保ってください。

[テキスト]
```

逆方向（英→日）にしたい場合:

```
以下の英語テキストを自然な日本語に翻訳してください。

[テキスト]
```

### レシピ 2: ホーム画面からアイデア生成

ホーム画面にショートカットを追加して、思いついたテーマを入力するとアイデアを提案してもらうショートカットです。

「テキストを入力」アクションでユーザーにテーマを入力させ、以下のプロンプトに渡します:

```
以下のテーマについて、ユニークでクリエイティブなアイデアを5つ提案してください。それぞれ1〜2文で簡潔に説明してください。

テーマ: [入力テキスト]
```

### レシピ 3: メモを Gemini に送って Q&A

Apple メモに書いたテキストを送り、質問に答えてもらうショートカット。「メモから選択」アクションでメモを取得し、「テキストを入力」で質問を入力してから Gemini に送ります。

より発展的な音声対話機能については [Gemini TTS API ガイド](/articles/gemini-api/gemini-tts-api-guide) も参考にしてください。Gemini が音声で回答を読み上げるショートカットも作れます。

## 高度な活用 — モデルの選択とパラメータ調整

API の URL を変えるだけで、より高性能なモデルを使えます。

```
# Gemini 2.5 Pro（より高精度・高推論）
https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-pro:generateContent?key=YOUR_API_KEY

# Gemini 2.5 Flash（高速・無料枠が大きい）
https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=YOUR_API_KEY
```

また、リクエスト JSON に `generationConfig` を追加すると出力を細かく制御できます:

```json
{
  "contents": [
    {
      "parts": [{ "text": "プロンプト" }]
    }
  ],
  "generationConfig": {
    "temperature": 0.7,
    "maxOutputTokens": 512
  }
}
```

- `temperature`: 0 に近いほど一貫した回答、1 に近いほど創造的な回答になります
- `maxOutputTokens`: 回答の最大文字数を制御します（1トークン ≒ 1〜2文字）

「退屈なことはPythonにやらせよう 第2版」のような自動化の観点から学びたい方には、[「退屈なことはPythonにやらせよう 第2版」（Al Sweigart 著）](https://www.amazon.co.jp/dp/4873119278/?tag=pinocchio-22) もあわせて読むとショートカット自動化のアイデアがさらに広がります。

## よくある質問（FAQ）

**Q. API キーを誰かに見せてしまったら？**

すぐに [Google AI Studio](https://aistudio.google.com/) にアクセスし、該当の API キーを削除して新しいキーを発行してください。漏洩したキーは悪用される可能性があるため、迷わず再発行しましょう。

**Q. ショートカットが「URL の内容を取得」でエラーになります**

原因として多いのは以下の 3 点です。

- **API キーが間違っている** — コピーミスがないか確認してください
- **JSON の形式が崩れている** — 「辞書」アクションで設定した内容を見直してください
- **ネットワークが繋がっていない** — Wi-Fi または モバイルデータ通信の状態を確認してください

**Q. Gemini 2.0 Flash と 2.5 Pro はどちらを使えばよいですか？**

日常的な要約・翻訳・アイデア出しには **Gemini 2.0 Flash** で十分です。より複雑な推論や長文の分析には **Gemini 2.5 Pro** が適しています。無料枠はどちらも使えますが、Pro のほうが消費が速い点に注意してください。

**Q. Siri から呼び出せますか？**

はい、可能です。ショートカットに名前（例: 「Gemini に質問」）をつけて Siri に登録すると、「Hey Siri、Gemini に質問」と話しかけるだけでショートカットが起動します。音声での呼び出しにもぜひ活用してください。

## まとめ

iOS ショートカットと Gemini API を組み合わせることで、毎日使う iPhone が AI アシスタントへと変わります。主なポイントを整理すると:

- API キーは [Google AI Studio](https://aistudio.google.com/) で無料取得できる
- 「URL の内容を取得」→「辞書の値を取得」の流れで Gemini API を呼び出せる
- プロンプトを変えるだけで要約・翻訳・アイデア生成など多用途に使える
- `temperature` や `maxOutputTokens` で回答の質とボリュームを調整できる
