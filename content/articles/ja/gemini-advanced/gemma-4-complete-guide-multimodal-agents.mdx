Gemma 4はオープンモデルとして公開されていますが、その活用方法は単純ではありません。E2BからE4B、26B MoE、31B Denseまで4つのサイズが存在し、マルチモーダル・関数呼び出し・長大なコンテキストという複数の強みを持つGemma 4を最大限に引き出すには、設計の選択が重要です。

Dolice Labs の 4 サイト並行運用で得た実感として、この問題に普段から向き合ってきた立場で、要点を整理します。

2014年からの個人開発と AdMob 収益化の経験を踏まえて、現場で効くポイントだけ抽出します。

## モデルサイズ選定の考え方

Gemma 4を使い始める前に、まず「どのモデルサイズを選ぶか」という判断が必要です。性能・コスト・レイテンシのトレードオフを理解することが出発点です。

### E2B / E4B：エッジ・モバイル向け

E2BとE4Bはモバイルデバイスや組み込みシステムへの展開を想定して設計されています。両モデルは128Kトークンのコンテキスト、動画・画像・音声のマルチモーダル入力に対応しています。

選択の目安として、モバイルアプリへの組み込みやラズベリーパイ等の組み込みデバイスへの展開を考えているならE2B、より高い精度が必要なエッジユースケース（医療機器のスクリーニング支援、製造ラインの品質検査等）ではE4Bが適しています。

### 26B MoE：バランス型クラウドモデル

26B MoEはMixture-of-Expertsアーキテクチャにより、実際に計算で使用するパラメータ数を抑えながら高い精度を実現します。Arena AIランキング6位の実力を持ちながら、推論コストを抑えられることが強みです。大量のリクエストを処理するAPIサービスや、精度と速度のバランスが求められるプロダクション環境に向いています。

### 31B Dense：最高精度

31B Denseは全パラメータを常に活用するDenseアーキテクチャで、Gemma 4ファミリー中最高の精度を誇ります。Arena AIランキング3位は400B超の一部クローズドモデルを上回る数字です。精度が最優先のユースケース（高度な法律・医療文書の解析、複雑なコード生成）に最適です。

## Vertex AI での実装基礎

Google Cloud Vertex AIを使ってGemma 4を呼び出す基本的なコードを示します。

```python
import vertexai
from vertexai.preview.generative_models import GenerativeModel, Part

# プロジェクトとリージョンの初期化
vertexai.init(project="YOUR_PROJECT_ID", location="us-central1")

# モデルの選択（サイズに応じて変更）
# "google/gemma-4-e2b" / "google/gemma-4-e4b"
# "google/gemma-4-27b-it" / "google/gemma-4-31b-it"
model = GenerativeModel("google/gemma-4-31b-it")

# シンプルなテキスト生成
response = model.generate_content(
    "日本のAI政策について500文字で解説してください。",
    generation_config={
        "temperature": 0.7,
        "max_output_tokens": 1024,
        "top_p": 0.9,
    }
)
print(response.text)
```

## 関数呼び出し（Function Calling）によるエージェント実装

Gemma 4のエージェント機能の核心は関数呼び出しです。モデルが外部ツール（API、データベース等）を自律的に呼び出して情報を取得・処理できます。

```python
import vertexai
from vertexai.preview.generative_models import (
    GenerativeModel, FunctionDeclaration, Tool
)

vertexai.init(project="YOUR_PROJECT_ID", location="us-central1")

# ツール（関数）の定義
get_weather_func = FunctionDeclaration(
    name="get_current_weather",
    description="指定した都市の現在の天気情報を取得する",
    parameters={
        "type": "object",
        "properties": {
            "location": {
                "type": "string",
                "description": "都市名（例：Tokyo, Osaka）"
            },
            "unit": {
                "type": "string",
                "enum": ["celsius", "fahrenheit"],
                "description": "温度の単位"
            }
        },
        "required": ["location"]
    }
)

search_web_func = FunctionDeclaration(
    name="search_web",
    description="ウェブ検索を実行して関連情報を取得する",
    parameters={
        "type": "object",
        "properties": {
            "query": {
                "type": "string",
                "description": "検索クエリ"
            }
        },
        "required": ["query"]
    }
)

# ツールセットを定義
tools = [Tool(function_declarations=[get_weather_func, search_web_func])]

model = GenerativeModel("google/gemma-4-31b-it", tools=tools)
chat = model.start_chat()

# エージェントとの対話
response = chat.send_message(
    "東京の今日の天気と、最新のAI技術ニュースを教えてください。"
)

# モデルが関数呼び出しを要求しているかチェック
if response.candidates[0].content.parts[0].function_call:
    function_call = response.candidates[0].content.parts[0].function_call
    print(f"呼び出す関数: {function_call.name}")
    print(f"引数: {dict(function_call.args)}")
    
    # 実際のAPI呼び出し（ここでは擬似コード）
    if function_call.name == "get_current_weather":
        weather_result = {"temperature": 22, "condition": "晴れ", "humidity": 60}
        
        # 結果をモデルに返す
        final_response = chat.send_message(
            Part.from_function_response(
                name="get_current_weather",
                response={"result": weather_result}
            )
        )
        print(final_response.text)
```

## 構造化JSON出力による信頼性の高いデータ抽出

プロダクション環境では、モデルの出力を後続のシステムで処理することが多いため、構造化されたJSONレスポンスが必要です。

```python
import json
from vertexai.preview.generative_models import GenerationConfig

model = GenerativeModel("google/gemma-4-31b-it")

# スキーマを明示したJSON出力の指定
response = model.generate_content(
    """以下の製品レビューから情報を抽出してJSON形式で返してください。

レビュー：「このノートPCは軽量で使いやすいです。バッテリー持ちも良く満足しています。
価格が少し高めですが、品質には見合っていると思います。総合評価は4.5/5です。」

必ずこのスキーマで返してください：
{
  "product_type": "製品カテゴリ",
  "positive_points": ["良い点のリスト"],
  "negative_points": ["悪い点のリスト"],
  "overall_rating": 評価値（数値）,
  "sentiment": "positive/negative/neutral"
}""",
    generation_config=GenerationConfig(
        response_mime_type="application/json",
        temperature=0.1
    )
)

# JSONとして安全にパース
result = json.loads(response.text)
print(f"製品カテゴリ: {result['product_type']}")
print(f"評価: {result['overall_rating']}")
print(f"良い点: {result['positive_points']}")
```

## 長大なコンテキストを活かしたコードベース解析

31B Denseの256Kコンテキストを使って、大規模なコードベースを一度に解析する例です。

```python
import os

def read_codebase(root_dir: str) -> str:
    """ディレクトリ内の主要ソースファイルを結合して返す"""
    code_content = []
    for dirpath, dirnames, filenames in os.walk(root_dir):
        # node_modules等を除外
        dirnames[:] = [d for d in dirnames if d not in ['node_modules', '.git', 'dist']]
        for filename in filenames:
            if filename.endswith(('.py', '.ts', '.tsx', '.js')):
                filepath = os.path.join(dirpath, filename)
                with open(filepath, 'r', encoding='utf-8', errors='ignore') as f:
                    content = f.read()
                code_content.append(f"# {filepath}\n{content}")
    return "\n\n".join(code_content)

# コードベース全体を取得（256Kトークン以内であれば一度に渡せる）
codebase = read_codebase("./my_project")

model = GenerativeModel("google/gemma-4-31b-it")

response = model.generate_content(
    f"""以下のコードベースを分析して、以下を報告してください：
1. アーキテクチャの概要
2. 改善すべき技術的負債
3. セキュリティ上の懸念点
4. テストカバレッジが不足している箇所

コードベース：
{codebase}""",
    generation_config={"max_output_tokens": 4096}
)

print(response.text)
```

```bash

from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:1234/v1",
    api_key="lm-studio"  # LM Studioはキー不要だがパラメータとして渡す

response = client.chat.completions.create(
    model="gemma-4-31b-dense",  # LM Studioで読み込んだモデル名

    ],
    temperature=0.7,
    max_tokens=1024
)

print(response.choices[0].message.content)
```

## パフォーマンス最適化のポイント

### バッチ処理で効率化

```python
# 複数のリクエストをまとめて処理（Vertex AI Batch Prediction）
from vertexai.preview.generative_models import GenerativeModel

model = GenerativeModel("google/gemma-4-27b-it")

# 複数のプロンプトをリストで渡す
prompts = [
    "製品Aのレビューを要約してください：[レビューテキスト1]",
    "製品Bのレビューを要約してください：[レビューテキスト2]",
    "製品Cのレビューを要約してください：[レビューテキスト3]",
]

# 非同期で並列処理
import asyncio
import aiohttp

async def process_prompts(prompts):
    tasks = [model.generate_content_async(p) for p in prompts]
    return await asyncio.gather(*tasks)

results = asyncio.run(process_prompts(prompts))
for i, result in enumerate(results):
    print(f"結果{i+1}: {result.text[:100]}...")
```
