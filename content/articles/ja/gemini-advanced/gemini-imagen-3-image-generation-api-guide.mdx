## はじめに

Imagen 3がGemini APIを通じて利用可能になり、テキストから高品質な画像を生成できるようになりました。フォトリアリズム、テキスト描画、スタイル制御の精度において業界トップクラスを誇り、個人開発者からエンタープライズまで幅広く活用されています。

この記事では、Imagen 3をPython SDKから利用する方法、効果的なプロンプトの書き方、商用利用時の注意点を、実践的なコード例とともに解説します。

[Gemini Workspace統合についての詳細は、[Gemini Workspace 2026年3月の主要アップデート解説](/articles/gemini-workspace/gemini-workspace-march-2026-major-update)もあわせてご参考ください。]

## Imagen 3の特徴と魅力

Imagen 3が従来の画像生成モデルと異なる点を整理します。

- **解像度**: 最大1024×1024ピクセル。アスペクト比は1:1、3:4、4:3、9:16、16:9に対応し、様々な用途に対応可能
- **フォトリアリズム**: 現実写真と見分けがつかないレベルの精細な描写が可能。光の反射、テクスチャ、奥行き表現が極めて自然
- **テキスト描画精度**: 従来の画像生成モデルの最大の弱点だったテキスト（文字）の正確なレンダリングを実現
- **スタイル多様性**: 写真、イラスト、絵画、3DCGなど幅広いスタイル指定に対応
- **SynthID透かし**: 生成画像に不可視の電子透かしが自動埋め込まれ、生成画像の真正性を証明可能

## Gemini APIでのImagen 3へのアクセス

Imagen 3はGemini API経由でアクセスでき、Google AI Studioの無料枠でもテスト可能です。本番利用にはAPIキーとGoogle Cloud課金の設定が必要になります。

- **無料枠**: Google AI Studio（月間一定回数まで無料で利用可能）
- **課金モデル**: 生成画像1枚あたりの従量課金。料金はGoogle Cloud Consoleで管理
- **アクセス方法**: `google-generativeai` Python SDK、またはREST API直接呼び出し

詳しいAPI料金については、[Google AI Studioの公式ページ](https://ai.google.dev/pricing)でご確認ください。

## 基本的な画像生成の実装

最もシンプルな画像生成の例です。

```python
import google.generativeai as genai
import PIL.Image
import io
import os

# APIキーを設定
genai.configure(api_key=os.environ["GEMINI_API_KEY"])

# Imagen 3モデルを初期化
model = genai.ImageGenerationModel("imagen-3.0-generate-002")

# 画像を生成する
response = model.generate_images(
    prompt="東京の夜景、高層ビルと桜が共存する幻想的なシーン、フォトリアリスティック",
    number_of_images=1,
    aspect_ratio="16:9",
)

# 生成された画像を保存
for i, image in enumerate(response.generated_images):
    img = PIL.Image.open(io.BytesIO(image.image.image_bytes))
    img.save(f"output_{i}.png")
    print(f"画像を output_{i}.png に保存しました")

# 期待する出力:
# 画像を output_0.png に保存しました
```

このコードを実行すると、テキストプロンプトで指定した内容の画像がPNG形式で生成されます。

## 効果的なプロンプトの書き方

Imagen 3で高品質な画像を得るには、プロンプト（指示文）の工夫が重要です。曖昧な指示より、具体的で詳細なプロンプトほど期待した結果が得られます。

### 具体的なプロンプト例

**風景・建築写真**

- **悪い例**: 「山の写真」→ プロンプトが漠然としすぎて、意図した画像が生成されない可能性が高い
- **良い例**: 「日の出直前の富士山、霧に包まれた五合目の風景、オレンジとパープルのグラデーション空、超高解像度の商業写真クオリティ」

**人物・ポートレート写真**

- **悪い例**: 「ビジネスマンの写真」
- **良い例**: 「30代の日本人男性エンジニア、カフェでノートパソコンを操作している様子、自然光が射す午後の雰囲気、ボケ感のある背景、商業写真クオリティ」

**プロダクトモックアップ**

- **悪い例**: 「スマートフォンのモックアップ」
- **良い例**: 「最新iPhoneのモックアップ、ミニマルな白い背景、柔らかいシャドウ、アプリ画面を表示している状態、プロダクト写真スタイル」

### プロンプトに含めると効果的な要素

- **撮影スタイル**: 「フォトリアリスティック」「イラスト風」「水彩画風」「アニメーション調」
- **ライティング情報**: 「自然光」「夕暮れ時のゴールデンアワー」「スタジオ照明」「逆光」
- **構図や視点**: 「バードアイビュー」「クローズアップ」「広角レンズ視点」「マクロ撮影」
- **解像度・品質の指定**: 「超高解像度」「商業写真クオリティ」「4K品質」

こうした要素を組み合わせることで、生成画像の品質が劇的に向上します。

## アスペクト比と高度なオプション

Imagen 3では複数のアスペクト比に対応し、一度に複数枚の画像を生成できます。

```python
import google.generativeai as genai
import PIL.Image
import io
import os

genai.configure(api_key=os.environ["GEMINI_API_KEY"])
model = genai.ImageGenerationModel("imagen-3.0-generate-002")

# 縦長（ポートレート向け）の画像生成
response_portrait = model.generate_images(
    prompt="春の桜並木、満開の桜が舞い散る公園、明るい日差し、フォトリアリスティック",
    number_of_images=1,
    aspect_ratio="3:4",  # ポートレート向け縦長アスペクト比
)

# 横長（バナー・ヘッダー向け）の画像生成
response_banner = model.generate_images(
    prompt="テック企業のオフィス内部、モダンな内装、開放的な空間、自然光が入る",
    number_of_images=1,
    aspect_ratio="16:9",  # ワイドスクリーン向けアスペクト比
)

# 複数枚同時生成（最大4枚）
response_multiple = model.generate_images(
    prompt="ミニマルなロゴデザイン、円形、青とグレーのグラデーション色彩",
    number_of_images=4,  # 4パターンを一度に生成
    aspect_ratio="1:1",  # 正方形アスペクト比
)

print(f"生成枚数: {len(response_multiple.generated_images)}枚")
# 期待する出力:
# 生成枚数: 4枚
```

複数枚同時生成により、異なるバリエーションを効率よく作成できます。

## ネガティブプロンプトの活用

生成から除外したい要素を指定することもできます。

```python
response = model.generate_images(
    prompt="レストランの料理写真、イタリアンパスタ、おしゃれなプレゼンテーション",
    number_of_images=1,
    negative_prompt="blurry, low quality, watermark, text overlay, cartoon",
    aspect_ratio="4:3",
)
```

「blurry」（ぼやけた）、「low quality」（低品質）などの除外ワードを指定すると、より思い通りの画像が生成されやすくなります。

## 商用利用と重要な注意事項

Imagen 3で生成した画像を商用利用する際は、複数の注意点があります。

### SynthIDについて

Google DeepMindが開発した**SynthID**は、Imagen 3が生成した全ての画像に不可視の電子透かしを埋め込む技術です。人間の目には見えませんが、専用ツールで検出可能であり、生成画像の真正性を証明できます。

### コンテンツポリシー

Imagen 3では以下のコンテンツ生成は禁止されています。

- 実在する著名人・公人を誤解させる可能性のある画像
- 暴力、性的、違法な行為を描いた画像
- 著作権で保護されたキャラクターの複製
- 有害・違法なコンテンツ

詳細は[Google Generative AI利用規約](https://policies.google.com/terms/generative-ai/use-policy)をご確認ください。

### 著作権と権利の扱い

Imagen 3が生成した画像の著作権の扱いは、各国の法律や利用規約によって異なります。商用利用を予定している場合は、事前に法律専門家への相談を強く推奨します。

Googleの利用規約では、ユーザーが生成した画像の利用権はユーザーに帰属するとされていますが、各国の著作権法との相互作用は複雑であるため、詳細は専門家にご相談ください。

## よくある質問

**Q: Imagen 3は完全に無料で使えますか？**

A: Google AI Studioの無料枠では月間一定の生成回数まで無料です。本番環境での大量生成にはGoogle CloudのAPIキーと課金設定が必要になります。

**Q: 生成した画像の著作権はどうなりますか？**

A: 生成画像の権利についてはGoogleの利用規約では「ユーザーに帰属する」と明記されていますが、各国の著作権法によって解釈が異なる可能性があります。商用利用前には法律専門家にご相談ください。

**Q: Stable DiffusionやMidjourneyと何が異なりますか？**

A: Imagen 3はGoogleのAPIエコシステムに直接統合されており、Gemini APIの他機能（テキスト生成・分析など）とシームレスに組み合わせられます。またSynthID透かし機能が標準装備されており、エンタープライズ環境での真正性確認が容易です。

**Q: 日本語プロンプトは使えますか？**

A: はい、日本語プロンプトにも対応しています。ただし英語プロンプトの方が精度が高い傾向があります。日英混在のプロンプトも有効に機能します。

**Q: モデルの学習にユーザー入力は使われますか？**

A: Imagen 3はユーザーのプロンプトや生成画像を今後の学習に使用しない設計になっています。ただし詳細はGoogleの最新ポリシーをご確認ください。
