Gemini Code Assist は、2024年後半から進化を遂げ、2026年現在、Google の代表的な開発支援ツールとなっています。単なる補完機能にとどまらず、**エージェントモード** による計画立案、**自動コード変換**、**ドキュメント生成** など、開発フローの複数レイヤーで活躍する統合ツールへと成長しました。

## Gemini Code Assist とは——2026年の開発支援の最前線

Gemini Code Assist は、Google が提供するエンタープライズグレードの AI コーディングアシスタント。Google Cloud の [Vertex AI](https://cloud.google.com/vertex-ai) 上で実行される Gemini モデル（最新は Gemini 3 / 3.1 Pro）を活用し、IDE 内でコード提案、デバッグ、ドキュメント生成を行います。

**主な特徴:**
- **複数 IDE 対応**: VS Code、IntelliJ IDEA、JetBrains IDE ファミリー（PyCharm、WebStorm 等）
- **言語サポート**: Python、JavaScript/TypeScript、Java、Go、C++、Kotlin など主要言語すべて
- **エディション構成**: Free（Gemini 2.5 Flash、制限あり）、Standard（Vertex AI 課金）、Enterprise（カスタマイズ可）

## VS Code・IntelliJ での初期セットアップ

### VS Code での導入手順

1. **拡張機能をインストール**
   - VS Code のマーケットプレイスで「Gemini Code Assist」を検索
   - 「Install」をクリック、再起動後に有効化

2. **認証設定**
   - コマンドパレット（Cmd/Ctrl+Shift+P）で「Gemini: Sign In」を実行
   - Google アカウントでサインイン
   - プロジェクト選択画面で利用する Google Cloud プロジェクトを指定

3. **デフォルト設定の確認**
   - `settings.json` で以下を確認:
     ```json
     {
       "gemini.enabled": true,
       "gemini.inlineCompletions": true,
       "gemini.chat": true,
       "gemini.agentMode": true
     }
     ```

### IntelliJ IDEA での導入

1. **プラグインをインストール**
   - Settings → Plugins → Marketplace
   - 「Gemini Code Assist」を検索・インストール

2. **IDE を再起動**
   - 自動的に認証ダイアログが表示される
   - Google Cloud プロジェクトを指定

3. **Project SDK の確認**
   - Project Settings → Project → SDK が正しく設定されていることを確認
   - Gemini は SDK パスを参照してコンテキスト推論を行う

## Agent Mode（Preview）——AI が計画を立ててコードを書く

Gemini Code Assist の最新機能が **Agent Mode**。これまでの「補完」から、「**自動計画→実装→検証**」のエージェント的な振る舞いへ進化しました。

### Agent Mode の動作フロー

1. **計画フェーズ**
   - ユーザーが「`/refactor Main.java を MVC パターンに従うよう整理して`」とチャットで指示
   - Gemini がコード全体を理解し、変更計画を複数提案

2. **実装フェーズ**
   - ユーザーが計画を選択・承認
   - Gemini がインラインで diff を生成し、ファイルごとの変更箇所を可視化

3. **確認フェーズ**
   - ユーザーが各 diff を review・承認
   - Gemini が自動で変更を apply、テスト提案も同時実行

### 実務活用パターン

**パターン 1: レガシーコード のリファクタリング**

```
ユーザー: "/refactor このコードをモダン TypeScript に対応させて。async/await を活用して"

Agent Mode 出力:
- 計画: Promise ベースの関数を async/await に変換
- インラインdiff で各変更箇所を提示
- テスト関数の自動生成提案
```

**パターン 2: 新機能の実装**

```
ユーザー: "/implement ユーザー認証機能を追加。OAuth 2.0 を使って"

Agent Mode 出力:
- OAuth ライブラリの選定
- コンポーネント構成の提案
- ボイラープレートコードの自動生成
- セキュリティチェックリストの表示
```

Agent Mode を有効にするには、チャットウィンドウで `/` コマンドを入力し、一覧から選択します。Preview 段階ですが、既に本番環境での実装に耐える品質に達しています。

## Finish Changes——半書きコード・TODO からの自動完成

**Finish Changes** は、不完全な記述から自動で完成形を提案する機能。以下の 3 パターンで活躍します。

### 1. TODO コメント からの補完

```typescript
// TODO: ユーザーデータを取得して整形する
async function processUserData(userId: string) {
  // Gemini が以下を自動生成
  const user = await fetchUser(userId);
  return {
    id: user.id,
    name: user.full_name,
    email: user.email,
    createdAt: new Date(user.created_at),
  };
}
```

カーソルを TODO の下の行に置き、キーボードショートカット（VS Code: `Ctrl+Shift+E`）を実行すると、Gemini が `fetchUser` の呼び出しと型推論を自動で補完します。

### 2. 疑似コード からの実装

```python
def calculate_average_score(students):
    # Pseudocode:
    # - 各学生の点数を取得
    # - 合計を計算
    # - 人数で割る
    
    # Gemini が以下を自動生成
    scores = [student['score'] for student in students]
    return sum(scores) / len(scores) if students else 0
```

### 3. 関数シグネチャ からの本体補完

```go
func (r *Repository) FindByEmail(ctx context.Context, email string) (*User, error) {
    // 関数本体を Finish Changes で補完
    // DB クエリの組み立てと error handling が自動生成される
}
```

**Finish Changes の活用で、実装時間を 30〜50% 削減** できます。特に反復的なデータ処理やボイラープレートコードで効果が高いです。

## File Outline——AI による自動ドキュメント生成

**File Outline** は、ファイル全体のコード構造を理解し、自動で JSDoc / Docstring を生成する機能。

### 使用方法

1. コマンドパレットで「Gemini: Generate Outline」を実行
2. Gemini がファイルをスキャンし、以下を自動生成:
   - クラス・関数の説明文
   - パラメータと戻り値の型情報
   - 使用例

**生成例（TypeScript）:**

```typescript
/**
 * ユーザー認証トークンを検証し、有効期限をチェックする
 * 
 * @param token - JWT トークン文字列
 * @param secret - トークン署名用のシークレット
 * @returns 検証済みのペイロードオブジェクト、無効な場合は null
 * @throws Error トークン署名が改ざんされている場合
 * 
 * @example
 * const payload = verifyToken(myToken, process.env.JWT_SECRET);
 * if (payload) {
 *   console.log('User ID:', payload.userId);
 * }
 */
function verifyToken(token: string, secret: string): TokenPayload | null {
  // ...
}
```

File Outline で生成されたドキュメントは、IDE の IntelliSense に自動反映され、**チーム内でのコード理解が大幅に加速** します。特にマイクロサービスやプラグインシステムで有効。

## Next Edit Predictions——次の編集候補の先読み

**Next Edit Predictions** は、Gemini が現在の編集コンテキストから「次にユーザーが書くであろうコード」を予測し、プレビュー表示する機能。

### 動作例

```typescript
const users = [
  { id: 1, name: 'Alice', role: 'admin' },
  { id: 2, name: 'Bob', role: 'user' },
];

// ここで Gemini が以下を予測・プレビュー:
// const admins = users.filter(u => u.role === 'admin');
```

予測が合致すれば、Tab キーで確定。インラインで複数行の補完が可能です。

## Code Transformation——コマンドとプロンプトによるコード変換

**Code Transformation** は、既存コードに対して「この言語に変換して」「このパターンにリファクタして」といったプロンプトベースの指示を実行します。

### 変換例

**元コード（JavaScript）:**
```javascript
function filterUsers(users, role) {
  return users.filter(u => u.role === role);
}
```

**プロンプト:** "Python に変換"

**変換後:**
```python
def filter_users(users: list[dict], role: str) -> list[dict]:
    return [u for u in users if u['role'] == role]
```

**プロンプト:** "関数型プログラミングのスタイルに"

**変換後:**
```python
from functools import reduce

filter_users = lambda role: (
    lambda users: list(filter(lambda u: u['role'] == role, users))
)
```

IDE 内で複数の案を並べて比較でき、最適なバージョンを選択できます。
