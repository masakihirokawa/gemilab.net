Gemini Computer Useは、AIモデルがスクリーンショットを分析して画面上のUIを自動操作できる機能です。従来のテキストベースのやり取りから進化して、実際のブラウザ操作やアプリケーション制御が可能になります。

## Computer Useとは何か

Gemini Computer Useは、ビジュアルな入力（スクリーンショット）を受け取り、画面上の要素をクリックしたりテキストを入力したりといった具体的なアクション（function call）を実行できる機能です。

従来のAPI利用では「このサイトから価格を取得して」という指示を手動で整形する必要がありました。しかし Computer Use を使うと、モデル自身が画面を「見て」、次に何をすべきかを判断し、実際の操作を指示します。

この仕組みにより、Webサイトの自動操作、UIテストの自動実行、求人情報の自動収集、フォームの自動入力など、幅広いタスクが自動化できます。

## モデル進化：Gemini 2.5からGemini 3へ

Gemini 2.5では、Computer Use専用のモデル変種（gemini-2.5-pro-computer-use）が提供されていました。Gemini 3の登場により状況が簡潔になりました。現在は gemini-3-pro や gemini-3-flash という基本モデルで、デフォルトから Computer Use 機能が組み込まれています。特別な「Computer Use版」を選ぶ必要がなく、通常のモデル利用でこの機能にアクセスできるようになったわけです。

## セットアップから実装まで

最もシンプルに始めるなら、Google AI Studioを使うのがお勧めです。[Google AI Studio](https://aistudio.google.com) にアクセスしてGoogleアカウントでログイン、左サイドバーから「新規チャット」を作成、モデル選択画面で「Gemini 3.0 Pro」を選択、チャット画面内でスクリーンショットを貼り付けて即座にテスト可能です。APIキーの発行や環境設定を省略でき、ブラウザだけで実験できるのが利点です。

本番運用ではVertex AIで、プロジェクト管理、アクセス制御、監視ダッシュボードなどのエンタープライズ機能が利用できます。

## Computer Useの仕組みと操作

Computer Useの動作フローは、次のようなサイクルで回ります：

1. **スクリーンショット取得** — 操作対象の画面をキャプチャ
2. **モデル分析** — AIがスクリーンショットを受け取り、内容を理解
3. **Function Call実行** — モデルがアクション（座標クリック、テキスト入力等）を指示
4. **アクション実行** — ブラウザに操作を実行させる
5. **ループ** — タスク完了まで1～4を繰り返す

Computer Useで使える主な操作は、click_at(x, y)でクリック、type_text_at(x, y, text)でテキスト入力、scroll(direction, amount)でスクロール、key_press(key)でキー入力などです。モデルはスクリーンショットを分析して、次に実行すべきアクションを決定します。精度はプロンプトの質と画面のシンプルさに依存します。

## 実装例：シンプルな自動化エージェント

```python
import google.generativeai as genai
import base64

genai.configure(api_key="YOUR_API_KEY")

def automate_ui_task(screenshot_path: str, task_description: str) -> str:
    """スクリーンショットを分析して操作を実行"""

    with open(screenshot_path, "rb") as f:
        image_data = base64.standard_b64encode(f.read()).decode("utf-8")

    client = genai.Client()
    response = client.aistudio.create_interaction(
        model="gemini-3-pro",
        request={
            "contents": {
                "role": "user",
                "parts": [
                    {"type": "image", "data": image_data},
                    {"type": "text", "text": task_description}
                ]
            }
        }
    )

    return response.content

# 使用例
result = automate_ui_task(
    "current_page.png",
    "このページから検索ボックスを見つけて『Python』を入力し、検索を実行してください。"
)
print(result)
```

このコード例では、スクリーンショットをbase64エンコードして送り、function callで操作を指示します。

## 実装の応用例：Playwright連携

実際の運用では、Computer Use と Playwright（ブラウザ自動化ライブラリ）を組み合わせることが多いです。

```python
from playwright.async_api import async_playwright
import asyncio

async def browser_automation():
    async with async_playwright() as p:
        browser = await p.chromium.launch()
        page = await browser.new_page()

        # ページに移動
        await page.goto("https://example.com")

        # スクリーンショット取得
        screenshot = await page.screenshot()

        # Computer Useに送信（省略）
        # ai_response = call_computer_use(screenshot)

        # AIの指示に基づいて操作
        await page.click("input[name='search']")
        await page.type("input[name='search']", "example")
        await page.click("button[type='submit']")

        await browser.close()

# asyncio.run(browser_automation())
```

Playwrightを使うメリットは、ブラウザのヘッドレス操作、複数ページの並列処理が効率よくできることです。セレニウムより高速で、モダンなブラウザAPIに対応しています。

## 安全性と活用

Computer Useはモデルが勝手に決定・操作するリスクを軽減するための制限が設けられています。明示的な指示がなければモデルは勝手に操作しません。すべてのアクションはログに記録され、監査が可能です。パスワード入力やクレジットカード番号の入力は制限される場合があります。

本番環境では、操作を実行する前に人間による承認ステップを挟むことが推奨されます。また、Webサイトの利用規約やrobots.txtを尊重し、スクレイピングなど規約に反する操作は避けるべきです。

Gemini Computer Use により、単なる情報処理ツールから、実行エージェントとしてのAIの活躍の場が広がります。セットアップは簡単、実装も短いコードで実現でき、Webスクレイピングから自動テストまで、様々なユースケースに対応できます。ぜひ試してみてください。
