## Gemini マルチモーダルの基礎

### サポートされる入力タイプ

Gemini 1.5 Pro / Flash がサポートする入力タイプは以下の通りです。

テキスト（すべての言語）、画像（JPEG、PNG、WebP、HEIC、HEIF）、動画（MP4、MPEG、MOV、AVI、FLV、MPG、WebM、WMV、3GPP）、音声（WAV、MP3、AIFF、AAC、OGG、FLAC）、PDF、そしてコードです。

これらを組み合わせることで、従来の単一モーダルAIでは不可能だった複合的な分析が可能になります。

## 画像理解の高度な活用

### 複数画像の比較分析

Gemini は複数の画像を同時に渡して比較分析させることができます。

```python
import google.generativeai as genai
from pathlib import Path

def compare_product_images(image_paths: list[str], comparison_criteria: str) -> str:
    """複数の商品画像を比較分析"""
    
    model = genai.GenerativeModel('gemini-1.5-pro')
    
    # 画像ファイルをアップロード
    uploaded_images = []
    for path in image_paths:
        file = genai.upload_file(path)
        uploaded_images.append(file)
    
    # 比較プロンプトを構築
    content = uploaded_images + [
        f"""これらの画像を以下の観点で比較分析してください:
{comparison_criteria}

各画像の特徴を具体的に述べ、最後に総合評価をまとめてください。"""
    ]
    
    response = model.generate_content(content)
    return response.text

# 使用例
image_files = ["product_a.jpg", "product_b.jpg", "product_c.jpg"]
criteria = """
1. デザインの洗練度
2. 機能性の視覚的表現
3. ターゲット顧客層への訴求力
4. ブランドイメージとの一貫性
"""

analysis = compare_product_images(image_files, criteria)
print(analysis)
```

### OCRと文書構造の理解

画像内のテキスト抽出（OCR）だけでなく、文書の構造的な理解も Gemini は得意とします。

```python
def analyze_document_image(image_path: str) -> dict:
    """文書画像の構造的分析"""
    
    model = genai.GenerativeModel('gemini-1.5-pro')
    
    image_file = genai.upload_file(image_path)
    
    response = model.generate_content([
        image_file,
        """この文書画像を分析してください:
1. 文書の種類（請求書、契約書、レポートなど）
2. 主要な情報（日付、金額、当事者名など）
3. 文書の構造（セクション、表、グラフなど）
4. 重要な要点

JSON形式で返してください。"""
    ])
    
    import json
    # レスポンスからJSONを抽出する試み
    text = response.text
    if "```json" in text:
        json_str = text.split("```json")[1].split("```")[0].strip()
    else:
        json_str = text
    
    try:
        return json.loads(json_str)
    except:
        return {"raw_analysis": text}
```

## 動画理解の実践活用

### 長時間動画の自動要約

Gemini 1.5 Pro は最大1時間の動画を一度に処理できます。会議録画やレクチャー動画の自動要約に活用できます。

```python
import time

def summarize_video(video_path: str, language: str = "ja") -> dict:
    """動画を自動要約"""
    
    model = genai.GenerativeModel('gemini-1.5-pro')
    
    print(f"動画をアップロード中: {video_path}")
    video_file = genai.upload_file(video_path)
    
    # アップロード処理が完了するまで待機
    while video_file.state.name == "PROCESSING":
        print("処理中...")
        time.sleep(5)
        video_file = genai.get_file(video_file.name)
    
    if video_file.state.name == "FAILED":
        raise ValueError(f"動画のアップロードに失敗しました")
    
    print("分析開始...")
    response = model.generate_content([
        video_file,
        f"""この動画を{'日本語' if language == 'ja' else 'English'}で分析してください:

1. 概要（3〜5文）
2. 主要なトピックと各トピックの開始時間（タイムスタンプ付き）
3. 重要な発言やキーポイント（箇条書き）
4. アクションアイテムや次のステップ（もしあれば）
5. 総評

時間は「MM:SS」形式で記述してください。"""
    ])
    
    return {
        "summary": response.text,
        "video_duration": video_file.expiration_time
    }
```

## 複合マルチモーダル分析

### テキスト＋画像＋音声の統合分析

最も強力な活用法は、複数のモダリティを組み合わせることです。

```python
def cross_modal_analysis(
    text_context: str,
    image_path: str | None = None,
    audio_path: str | None = None
) -> str:
    """テキスト・画像・音声を組み合わせた統合分析"""
    
    model = genai.GenerativeModel('gemini-1.5-pro')
    content = []
    
    # テキストコンテキスト
    if text_context:
        content.append(f"コンテキスト情報:\n{text_context}\n")
    
    # 画像
    if image_path:
        image_file = genai.upload_file(image_path)
        content.append(image_file)
        content.append("（上記の画像について）\n")
    
    # 音声
    if audio_path:
        audio_file = genai.upload_file(audio_path)
        content.append(audio_file)
        content.append("（上記の音声について）\n")
    
    content.append("""
提供されたすべての情報（テキスト・画像・音声）を統合して分析してください:
1. 各モダリティから得られる主要な情報
2. モダリティ間の一致点と矛盾点
3. 統合することで得られる新しい洞察
4. 総合的な結論と推奨事項""")
    
    response = model.generate_content(content)
    return response.text
```

### リアルタイムマルチモーダル処理（ストリーミング）

長い動画や音声の処理時、ストリーミングでリアルタイムにレスポンスを受け取ることができます。

```python
def stream_video_analysis(video_path: str, question: str):
    """動画分析をストリーミングで実行"""
    
    model = genai.GenerativeModel('gemini-1.5-pro')
    video_file = genai.upload_file(video_path)
    
    while video_file.state.name == "PROCESSING":
        time.sleep(5)
        video_file = genai.get_file(video_file.name)
    
    print("分析開始（ストリーミング）:")
    
    response = model.generate_content(
        [video_file, question],
        stream=True
    )
    
    for chunk in response:
        print(chunk.text, end="", flush=True)
    
    print()  # 最後に改行
```

## PDFと文書の高度な処理

### 長大PDFの構造的理解

Gemini 1.5 Pro は最大1000ページのPDFを処理できます。

```python
def analyze_pdf_document(pdf_path: str, analysis_type: str) -> str:
    """PDFの構造的分析"""
    
    model = genai.GenerativeModel('gemini-1.5-pro')
    
    pdf_file = genai.upload_file(pdf_path, mime_type="application/pdf")
    
    analysis_prompts = {
        "executive_summary": "この文書のエグゼクティブサマリーを作成してください。経営層向けに重要な意思決定ポイントを中心にまとめてください。",
        "key_metrics": "この文書から数値データ・KPI・指標をすべて抽出し、表形式でまとめてください。",
        "risk_analysis": "この文書に記載されているリスク・課題・懸念事項をすべて特定し、重要度順に整理してください。",
        "action_items": "この文書から次のアクションアイテムと担当者・期限を抽出してください。"
    }
    
    prompt = analysis_prompts.get(analysis_type, f"この文書を{analysis_type}の観点で分析してください。")
    
    response = model.generate_content([pdf_file, prompt])
    return response.text
```

## コスト最適化とモデル選択

### タスクに応じたモデル選択

Gemini は用途に応じてモデルを使い分けることでコストを最適化できます。

高精度が必要な分析・判断タスクには `gemini-1.5-pro` を使います。速度とコストを重視するシンプルな処理には `gemini-1.5-flash` が適しています。

```python
def smart_model_selector(task_complexity: str, file_size_mb: float) -> str:
    """タスクの複雑さとファイルサイズに基づくモデル選択"""
    
    if task_complexity == "high" or file_size_mb > 100:
        return "gemini-1.5-pro"
    elif task_complexity == "medium" or file_size_mb > 10:
        return "gemini-1.5-pro"  # 確実性を重視
    else:
        return "gemini-1.5-flash"  # 速度とコスト重視
```
