## Gemini 3.1 Computer Use とは — AI が目で見て操作する革命

「**Computer Use**」は、AI が人間と同じように画面を見てマウスクリックやキーボード入力を行い、コンピュータを自律的に操作する機能です。Gemini 3.1 はこの Computer Use 機能において、前世代から大幅な精度向上を果たし、実用的な業務自動化ツールとして評価を高めています。

検索結果からわかるように、「gemini 3.1 computer use」は現在 Gemini Lab の GSC において最も多く検索されているクエリの一つです。それほど多くの開発者・ビジネスパーソンが「Gemini で画面操作を自動化したい」というニーズを持っています。

Gemini 3.1 の Computer Use は大きく以下の2つのモードで提供されています。

**Project Mariner との統合**（Google One AI Pro/Ultra 向け）: ブラウザタブの操作、ウェブサイトのナビゲーション、フォーム入力、情報収集などを自律的に行うクラウドベースの操作。

**Computer Use API**（開発者向け）: スクリーンショットを撮影し、AI が「次に行うべきアクション」（クリック座標、入力テキストなど）を決定するループを構築する、プログラマブルなインターフェース。

## なぜ今 Computer Use が重要なのか

従来の自動化ツール（Selenium、Playwright など）は、ウェブサイトの HTML 構造を直接解析して操作します。これは高速で安定していますが、動的な SPA（Single Page Application）や、HTML を公開していないデスクトップアプリには対応が難しいという限界があります。

Computer Use は視覚情報（スクリーンショット）を理解して操作するため、HTML 構造に依存しません。つまり、**どんなアプリケーションもブラウザ経由で自動化できる**可能性があります。Adobe Photoshop の操作、古い社内システムへのデータ入力、モバイルエミュレーターのテスト——これらすべてが Computer Use の射程内に入ります。

## Gemini 3.1 Computer Use API の基本実装

### セットアップと準備

```python
# Gemini 3.1 Computer Use API の基本実装
# 必要: pip install google-generativeai pillow pyautogui

import google.generativeai as genai
import base64
import json
import time
from PIL import ImageGrab, Image
import pyautogui
import io

# API キーの設定
genai.configure(api_key="YOUR_GEMINI_API_KEY")

def capture_screenshot() -> bytes:
    """現在の画面をスクリーンショットとして取得する"""
    screenshot = ImageGrab.grab()
    buffer = io.BytesIO()
    screenshot.save(buffer, format="PNG")
    return buffer.getvalue()

def screenshot_to_base64(screenshot_bytes: bytes) -> str:
    """スクリーンショットを Base64 エンコードされた文字列に変換する"""
    return base64.standard_b64encode(screenshot_bytes).decode("utf-8")

def ask_gemini_for_action(
    screenshot_base64: str,
    task: str,
    action_history: list[dict]
) -> dict:
    """
    スクリーンショットを基に Gemini 3.1 に次のアクションを問い合わせる

    Parameters:
        screenshot_base64: Base64 エンコードされたスクリーンショット
        task: 実行すべきタスクの説明
        action_history: これまでに実行したアクションのリスト

    Returns:
        実行すべきアクションの辞書（type, x, y, text など）
    """
    model = genai.GenerativeModel("gemini-1.5-pro")  # Computer Use 対応モデル

    history_text = "\n".join([
        f"- {a['type']}: {a.get('description', '')}"
        for a in action_history
    ]) if action_history else "なし（初回アクション）"

    prompt = f"""
あなたはコンピュータ操作を自動化するAIエージェントです。
スクリーンショットを見て、次に実行すべき操作を JSON 形式で返答してください。

## タスク
{task}

## これまでに実行したアクション
{history_text}

## 返答形式（JSON のみ）
{{
  "type": "click" | "type" | "scroll" | "key" | "done" | "error",
  "x": <クリック先のX座標（ピクセル）>,  // type="click"の場合
  "y": <クリック先のY座標（ピクセル）>,  // type="click"の場合
  "text": "<入力するテキスト>",           // type="type"の場合
  "key": "<キー名>",                      // type="key"の場合（例: "enter", "tab"）
  "direction": "up" | "down",             // type="scroll"の場合
  "amount": <スクロール量>,               // type="scroll"の場合
  "description": "<このアクションの説明>",
  "reason": "<なぜこのアクションを選んだか>"
}}

タスクが完了した場合は type="done" を返してください。
エラーが発生した、または続行できない場合は type="error" を返してください。
"""

    response = model.generate_content([
        {
            "inline_data": {
                "mime_type": "image/png",
                "data": screenshot_base64
            }
        },
        prompt
    ])

    # JSON 部分を抽出してパース
    response_text = response.text.strip()
    # マークダウンコードブロックを除去
    if "```json" in response_text:
        response_text = response_text.split("```json")[1].split("```")[0].strip()
    elif "```" in response_text:
        response_text = response_text.split("```")[1].split("```")[0].strip()

    return json.loads(response_text)

def execute_action(action: dict) -> bool:
    """
    Gemini が決定したアクションを実際に実行する

    Parameters:
        action: アクションの辞書

    Returns:
        True: 続行可能, False: 終了（done or error）
    """
    action_type = action.get("type")

    if action_type == "click":
        x, y = action["x"], action["y"]
        print(f"  🖱️ クリック: ({x}, {y}) — {action.get('description', '')}")
        pyautogui.click(x, y)
        time.sleep(0.5)

    elif action_type == "type":
        text = action["text"]
        print(f"  ⌨️ 入力: '{text}' — {action.get('description', '')}")
        pyautogui.write(text, interval=0.05)
        time.sleep(0.3)

    elif action_type == "key":
        key = action["key"]
        print(f"  🔑 キー: {key} — {action.get('description', '')}")
        pyautogui.press(key)
        time.sleep(0.3)

    elif action_type == "scroll":
        direction = action.get("direction", "down")
        amount = action.get("amount", 3)
        print(f"  📜 スクロール: {direction} {amount} — {action.get('description', '')}")
        pyautogui.scroll(-amount if direction == "down" else amount)
        time.sleep(0.3)

    elif action_type == "done":
        print(f"  ✅ タスク完了: {action.get('description', 'タスクが正常に完了しました')}")
        return False

    elif action_type == "error":
        print(f"  ❌ エラー: {action.get('description', '不明なエラー')}")
        return False

    return True

def run_computer_use_agent(task: str, max_steps: int = 20) -> bool:
    """
    Gemini 3.1 Computer Use エージェントを実行する

    Parameters:
        task: 実行したいタスクの説明（自然言語）
        max_steps: 最大ステップ数（無限ループ防止）

    Returns:
        True: タスク成功, False: 失敗またはエラー
    """
    print(f"\n🚀 タスク開始: {task}")
    print("-" * 60)

    action_history = []

    for step in range(max_steps):
        print(f"\n[ステップ {step + 1}/{max_steps}]")

        # スクリーンショット取得
        screenshot_bytes = capture_screenshot()
        screenshot_b64 = screenshot_to_base64(screenshot_bytes)

        # Gemini に次のアクションを問い合わせ
        try:
            action = ask_gemini_for_action(screenshot_b64, task, action_history)
            print(f"  📋 決定: {action.get('type')} — {action.get('reason', '')[:100]}")
        except Exception as e:
            print(f"  ❌ Gemini への問い合わせエラー: {e}")
            return False

        # アクション履歴に追加
        action_history.append(action)

        # アクションを実行
        should_continue = execute_action(action)
        if not should_continue:
            return action.get("type") == "done"

        # 次のステップの前に少し待機（ページ読み込みなど）
        time.sleep(1.0)

    print(f"\n⚠️ 最大ステップ数 ({max_steps}) に達しました")
    return False

# 使用例
if __name__ == "__main__":
    # 例1: Google で検索して結果を確認するタスク
    success = run_computer_use_agent(
        task="Google Chrome を開いて、'Gemini 3.1 Computer Use 最新情報' を検索し、"
             "上位3件の検索結果のタイトルを確認してください。",
        max_steps=10
    )
    print(f"\n結果: {'成功' if success else '失敗'}")
```

### ブラウザ専用の Computer Use（より安全な実装）

デスクトップ全体を操作する代わりに、ブラウザウィンドウのみを対象とした安全な実装も可能です。

```python
# Playwright + Gemini 3.1 を組み合わせたブラウザ操作の安全な実装

from playwright.async_api import async_playwright
import asyncio
import google.generativeai as genai
import base64
import json

genai.configure(api_key="YOUR_GEMINI_API_KEY")
model = genai.GenerativeModel("gemini-1.5-pro")

async def browser_computer_use_agent(task: str, start_url: str = "https://www.google.com"):
    """
    Playwright + Gemini 3.1 を使ったブラウザ限定 Computer Use エージェント

    Parameters:
        task: ブラウザ内で実行したいタスク
        start_url: 開始 URL
    """
    async with async_playwright() as pw:
        browser = await pw.chromium.launch(headless=False)
        page = await browser.new_page(viewport={"width": 1280, "height": 800})
        await page.goto(start_url)

        action_history = []
        max_steps = 15

        for step in range(max_steps):
            # ブラウザのスクリーンショットを取得
            screenshot_bytes = await page.screenshot()
            screenshot_b64 = base64.standard_b64encode(screenshot_bytes).decode()

            # Gemini に次のアクションを問い合わせ
            history_text = "\n".join([f"- {a}" for a in action_history]) or "なし"

            response = model.generate_content([
                {"inline_data": {"mime_type": "image/png", "data": screenshot_b64}},
                f"""
ブラウザ画面を見て、以下のタスクを完了するための次のアクションを JSON で返してください。

タスク: {task}
これまでのアクション: {history_text}
現在の URL: {page.url}

返答形式（JSON のみ）:
{{
  "action": "click" | "type" | "navigate" | "scroll" | "done",
  "selector": "<CSS セレクタ（click/typeの場合）>",
  "text": "<入力テキスト（typeの場合）>",
  "url": "<URL（navigateの場合）>",
  "direction": "up"|"down",
  "description": "<アクションの説明>"
}}
"""
            ])

            # JSON パース
            response_text = response.text.strip()
            if "```json" in response_text:
                response_text = response_text.split("```json")[1].split("```")[0].strip()

            action = json.loads(response_text)
            action_history.append(f"{action['action']}: {action.get('description', '')}")
            print(f"[Step {step+1}] {action['action']}: {action.get('description', '')}")

            # アクション実行
            if action["action"] == "click":
                await page.click(action["selector"])
                await page.wait_for_load_state("networkidle")
            elif action["action"] == "type":
                await page.fill(action["selector"], action["text"])
            elif action["action"] == "navigate":
                await page.goto(action["url"])
                await page.wait_for_load_state("networkidle")
            elif action["action"] == "scroll":
                delta = 300 if action.get("direction") == "down" else -300
                await page.mouse.wheel(0, delta)
            elif action["action"] == "done":
                print(f"✅ タスク完了: {action.get('description')}")
                break

            await asyncio.sleep(1.5)

        await browser.close()

# 実行
asyncio.run(browser_computer_use_agent(
    task="Gemini Lab のサイト(gemilab.net)を開いて、最新の記事タイトルを3つ教えてください",
    start_url="https://gemilab.net"
))
```

## 実用的な活用シナリオ

### シナリオ1: 定期的なデータ収集の自動化

競合他社の価格情報、在庫状況、求人情報など、定期的にウェブサイトを確認する必要がある業務に適しています。スクレイピングが困難なサイトでも Computer Use なら画面を「見て」情報を取得できます。

### シナリオ2: レガシーシステムへのデータ入力

API を持たない古い社内システムへのデータ転記作業を自動化できます。Excel からシステムへのコピー&ペースト作業、複数システム間のデータ同期など、長年担当者の手作業に依存していた業務を AI に委ねることができます。

### シナリオ3: ソフトウェアのテスト自動化

UI テストにおいて、テストコードの保守が困難な場面で Computer Use が役立ちます。「このボタンをクリックして、結果が正しく表示されることを確認する」という指示を自然言語で与えるだけで、テストが実行されます。

## Computer Use を安全に使うために

Computer Use は強力な機能ですが、**取り返しのつかないアクション**（データの削除、外部サービスへの意図しない送信など）を実行するリスクもあります。本番環境での利用にあたっては以下の点に注意してください。

まず、**サンドボックス環境でのテスト**を徹底してください。初期導入時は、本番システムとは切り離されたテスト環境で動作を確認した上で本番適用することを強く推奨します。

次に、**アクションの確認ステップ**を設けることを検討してください。各アクションを実行する前に人間の確認を求める「Human in the Loop」モードから始め、信頼性が確認できた後に完全自動化に移行するアプローチが安全です。

また、**スコープの制限**も重要です。操作対象を特定のアプリケーションやウェブサイトに限定し、それ以外のアクションは拒否するロジックを実装することで、意図しない操作を防ぎます。

## FAQ

**Q1: Gemini 3.1 Computer Use は Anthropic の Computer Use と何が違いますか？**

両者とも「スクリーンショットを見てアクションを決定する」という基本的なアーキテクチャは同じです。主な違いは、Gemini 3.1 は Google のエコシステム（Google Workspace、Android、Pixel など）との統合が優れている点、そして Project Mariner を通じたブラウザ操作では Google の安全フィルタリングが組み込まれている点です。

**Q2: どのモデルが Computer Use に対応していますか？**

Gemini 1.5 Pro および Gemini 3.1 Pro で Computer Use 機能が利用可能です。API 経由での利用は Gemini Advanced 以上のプランで対応しています。

**Q3: Computer Use は有料ですか？**

API 経由での利用は通常の Gemini API 料金体系に従います（入力トークン数＋スクリーンショットの画像サイズに応じた課金）。Project Mariner を使ったブラウザ操作は Google AI Ultra プランに含まれます。

**Q4: 日本語のウェブサイトや UI への対応はどうですか？**

Gemini 3.1 は日本語テキストの視覚的な認識精度が高く、日本語 UI を含む画面の操作を適切に処理できます。ただし、非常に小さいフォントや特殊なフォントには認識精度が下がる場合があります。

## まとめ

Gemini 3.1 Computer Use は、ウェブ自動化と AI エージェントの融合として非常に注目度の高い技術です。Playwright や Selenium のような従来の自動化ツールを補完・代替する存在として、特に「スクレイピングが難しいサイト」「API を持たないレガシーシステム」「UI テストの自然言語化」において大きな価値を発揮します。

もちろん、完全な自動化には慎重なアーキテクチャ設計と安全策が必要です。まずは限られたスコープで試してみて、AIが視覚的に画面を理解して操作するという体験を実感してみてください。

ブラウザ自動化のさらなる知識には、[「Pythonを使ったブラウザ自動化」（書籍）](https://www.amazon.co.jp/dp/4873119634/?tag=pinocchio-22)が Playwright の基礎から応用まで体系的に学べるリソースとして参考になります。また、Gemini の Computer Use と組み合わせることで、より柔軟な自動化が実現できます。
