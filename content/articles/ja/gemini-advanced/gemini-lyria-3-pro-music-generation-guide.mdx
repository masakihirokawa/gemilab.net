## Lyria 3 Pro とは

Lyria はGoogle DeepMind が開発する音楽生成AIです。今回の Lyria 3 Pro は従来バージョンから大幅に進化し、以下の特徴を持ちます。

- **最長3分間の楽曲生成**: 前バージョンの30秒〜1分から大幅延長
- **歌詞付き楽曲**: メロディだけでなく、日本語・英語を含む多言語の歌詞も生成可能
- **楽曲構造の自動設計**: イントロ → ヴァース → コーラス → ブリッジの流れを自動構成
- **写真からの音楽生成**: 画像を渡すと、その雰囲気に合った楽曲を生成する機能
- **スタイル指定**: ジャンル・テンポ・楽器構成・感情トーンを細かく指定可能

料金は **Gemini Advanced（Google AI Ultra）** サブスクリプションに含まれており、追加料金なしで利用可能です。

## API を使った音楽生成の自動化

クリエイティブなワークフローに Lyria 3 Pro を組み込む方法を紹介します。

```python
import google.generativeai as genai
import base64
import os

# APIキーの設定
genai.configure(api_key="YOUR_GEMINI_API_KEY")

def generate_music_with_lyria(
    prompt: str,
    output_path: str = "output.mp3"
) -> str:
    """
    Lyria 3 Pro で音楽を生成してファイルに保存する

    Args:
        prompt: 音楽生成プロンプト（日本語・英語対応）
        output_path: 出力ファイルパス

    Returns:
        保存したファイルパス
    """
    model = genai.GenerativeModel('lyria-3-pro')

    response = model.generate_content(
        prompt,
        generation_config={
            'audio_timestamp': True,  # タイムスタンプ情報を含める
        }
    )

    # 音楽データを取得してファイルに保存
    for part in response.candidates[0].content.parts:
        if hasattr(part, 'inline_data') and part.inline_data.mime_type.startswith('audio'):
            audio_data = base64.b64decode(part.inline_data.data)
            with open(output_path, 'wb') as f:
                f.write(audio_data)
            print(f"✅ 音楽を保存しました: {output_path}")
            return output_path

    raise ValueError("音楽データが見つかりませんでした")


# 使用例
if __name__ == "__main__":
    music_prompt = """
    春の朝をテーマにした、爽やかなアコースティックポップ。
    テンポ: 110BPM。アコースティックギター、軽やかなピアノ、柔らかいドラム。
    歌詞は日本語で、「新しい始まり」への期待と少しの不安を表現。
    イントロ10秒、Aメロ→Bメロ→サビ×2の構成で2分30秒。
    """

    output_file = generate_music_with_lyria(music_prompt, "spring_morning.mp3")
    print(f"生成完了: {output_file}")
```

### 画像から音楽を生成する

Lyria 3 Pro の革新的な機能の一つが、**写真から音楽を生成する**機能です。

```python
import google.generativeai as genai
import base64

genai.configure(api_key="YOUR_GEMINI_API_KEY")

def generate_music_from_image(
    image_path: str,
    style_hint: str = "",
    output_path: str = "from_image.mp3"
) -> str:
    """
    画像の雰囲気に合った音楽を生成する

    Args:
        image_path: 入力画像のパス
        style_hint: スタイルのヒント（任意）
        output_path: 出力ファイルパス
    """
    model = genai.GenerativeModel('lyria-3-pro')

    # 画像を読み込む
    with open(image_path, 'rb') as f:
        image_data = base64.b64encode(f.read()).decode('utf-8')

    # 画像の拡張子からMIMEタイプを判定
    ext = image_path.split('.')[-1].lower()
    mime_types = {'jpg': 'image/jpeg', 'jpeg': 'image/jpeg', 'png': 'image/png'}
    mime_type = mime_types.get(ext, 'image/jpeg')

    prompt_parts = [
        {
            "inline_data": {
                "mime_type": mime_type,
                "data": image_data
            }
        },
        f"この写真の雰囲気や感情に合った音楽を生成してください。{style_hint}歌詞なし、2分間のインストゥルメンタル。"
    ]

    response = model.generate_content(prompt_parts)

    # 音楽データを保存
    for part in response.candidates[0].content.parts:
        if hasattr(part, 'inline_data') and part.inline_data.mime_type.startswith('audio'):
            audio_data = base64.b64decode(part.inline_data.data)
            with open(output_path, 'wb') as f:
                f.write(audio_data)
            return output_path

    raise ValueError("音楽の生成に失敗しました")

# 使用例: 旅行写真から BGM を生成

#     style_hint="和風テイストで、しっとりとした雰囲気で。",
#     output_path="kyoto_bgm.mp3"
# )
```

### シナリオ1：YouTube 動画の BGM 自動生成

```python
def generate_bgm_for_video_scenes(scenes: list[dict]) -> list[str]:
    """
    動画のシーンリストに合わせてBGMを自動生成する

    scenes 例:
    [
        {"scene": "オープニング", "mood": "明るい・期待感", "duration": 30},
        {"scene": "山頂のシーン", "mood": "壮大・感動的", "duration": 60},
        {"scene": "エンディング", "mood": "穏やか・余韻", "duration": 45},
    ]
    """
    output_files = []

    for i, scene in enumerate(scenes):
        prompt = f"""
        {scene['mood']}な雰囲気の{scene['duration']}秒のBGM。
        シーン: {scene['scene']}
        歌詞なし、インストゥルメンタル。
        YouTube動画のバックグラウンドミュージックとして適切なもの。
        """

        output_path = f"bgm_{i:02d}_{scene['scene'].replace(' ', '_')}.mp3"
        generate_music_with_lyria(prompt, output_path)
        output_files.append(output_path)

    return output_files
```

### シナリオ2：ゲームBGM の自動生成パイプライン

```python
GAME_SCENES = {
    "title_screen": "壮大で印象的なゲームタイトル画面のBGM。オーケストラ風、2分間ループ。",
    "battle": "緊張感のある戦闘BGM。エレキギターとオーケストラのハイブリッド、疾走感、90秒。",
    "boss_battle": "ボス戦BGM。ダークで緊張感がありながらもカッコイイ、2分間。",
    "victory": "勝利ファンファーレ。明るく達成感がある、15秒。",
    "town": "のどかな町のBGM。アコースティック、ほのぼのとした雰囲気、2分間ループ。",
    "game_over": "ゲームオーバー画面。哀愁があり、短い、10秒。",
}

def generate_game_soundtrack():
    """ゲーム全シーンのBGMを一括生成する"""
    results = {}
    for scene_name, prompt in GAME_SCENES.items():
        output_path = f"bgm_{scene_name}.mp3"
        try:
            generate_music_with_lyria(prompt, output_path)
            results[scene_name] = output_path
            print(f"✅ {scene_name}: 生成完了")
        except Exception as e:
            print(f"❌ {scene_name}: 生成失敗 — {e}")
    return results
```

## よくある質問（FAQ）

**Q1. Lyria 3 Pro はどのプランで使えますか？**

Lyria 3 Pro は **Google AI Ultra** または **Google AI Pro** サブスクリプションに含まれています。Google AI Studio の無料枠でも試用可能ですが、生成回数に制限があります。API経由での利用は Gemini API の料金が適用されます。

**Q2. 生成した楽曲の著作権は誰のものですか？**

Google の利用規約に基づき、Lyria 3 Pro で生成した楽曲はユーザーが商用利用可能です。ただし、生成に使用したプロンプトや元の音楽（参照した場合）の著作権は別途確認が必要です。商用プロジェクトへの使用前に、最新の利用規約を必ずご確認ください。

**Q3. 既存の楽曲に似たものを生成してしまった場合の対処は？**

Lyria 3 Pro は学習データ内の楽曲に類似した音楽を生成することがあります。商用利用の前に生成物をチェックし、著名な楽曲に酷似している場合は生成しなおすことをお勧めします。Google は安全性フィルターを実装していますが、完全ではありません。
