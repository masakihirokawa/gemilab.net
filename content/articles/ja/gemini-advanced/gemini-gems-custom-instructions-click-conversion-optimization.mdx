## はじめに

Google GeminiのGemsコンテナで「カスタム指示」機能が搭載され、同じプロンプトを何度も入力せずに、Geminiを自分専用にカスタマイズできるようになりましました。本記事では、この強力な機能の活用方法を実践的に解説します。

## Gems（ジェム）とは？

GeminiのGemsは、カスタムプロンプトと設定をプリセットとして保存できる機能です。以下の3つの要素が含まれます：

- **カスタム指示**: Geminiに「あなたの役割は〜」と伝える指示文
- **詳細設定**: 出力フォーマットやトーン（親切、簡潔、詳細など）
- **ファイルアップロード**: 参照資料や背景情報をあらかじめ添付

一度作成しておくと、毎回同じセットアップをする必要がなく、即座に専用のAIアシスタントを起動できます。

## Step 1: Geminiアカウントで最初のGemsを作成する

1. [Google AI Studio](https://aistudio.google.com/) にログイン
2. 左サイドバー「Gems」をクリック
3. 「新しいGemを作成」ボタンをクリック
4. 基本情報を入力：
   - **Gemの名前**: 「営業資料レビュアー」など、用途が明確な名前
   - **説明**: 「営業プレゼン資料の改善点を指摘するAIアシスタント」
5. 「作成」をクリック

次のステップでカスタム指示を追加します。

## Step 2: カスタム指示を書く（最重要）

カスタム指示は、Geminiがあなたのリクエストに応える際のベースになります。以下の要素を含めると、より精度の高い応答が得られます：

**カスタム指示のテンプレート例：**

```
あなたは[職業・役割]です。
以下のスタイルで応答してください：
- トーン: [フォーマル/カジュアル/技術的/教育的など]
- 言語: 日本語
- 対象読者: [初心者/専門家/ビジネスマンなど]
- 出力フォーマット: [箇条書き/ステップバイステップ/表形式など]

応答時の約束：
1. [重視すること1]
2. [重視すること2]
3. [重視すること3]

背景情報：
[必要に応じて、業界知識や特定のルールを記述]
```

**実例：ブログ編集者向けGem**

```
あなたは、テクノロジー業界を専門とするブログ編集者です。

提供する支援内容：
- ブログ記事のタイトル改善
- 検索エンジン最適化（SEO）アドバイス
- 読みやすさの改善提案
- 事実確認

応答スタイル：
- トーン: プロフェッショナルで親しみやすい
- 言語: 日本語
- フォーマット: 箇条書き + 改善例付き
- 読者レベル: テクノロジーに興味のある一般ビジネスマン

重視する点：
1. SEOキーワード（h1, h2に自然に含める）
2. 冒頭100文字でのフック作成
3. 内部リンク機会の指摘
4. 誤字・脱字の指摘
```

## Step 3: 詳細設定（トーンと出力形式）

Geminiの応答スタイルをさらに微調整できます：

| 設定項目 | 説明 | 推奨値 |
|---------|------|-------|
| **トーン** | Geminiの話しぶり | 目的に応じて選択 |
| **簡潔** | 短く結論から | コーディング依頼向け |
| **詳細** | 詳しく背景から説明 | 学習・理解向け |
| **正式** | フォーマルな言葉遣い | ビジネス文書向け |
| **親切** | 丁寧で分かりやすい | 初心者向け |

## Step 4: 参照ファイルの追加（オプション）

Gems内にファイルをアップロードすることで、常に参照可能な資料を保持できます：

```python
# アップロード可能なファイル形式
- PDFドキュメント（会社の企画書、ガイドラインなど）
- Googleドキュメント（スプレッドシートも可能）
- テキストファイル（プロンプト集、業界用語辞書など）
- 画像（デザイン参考例、サンプルなど）
```

**使用例：営業向けGem**
```
営業マニュアル.pdf → Gemにアップロード
「上記の営業プロセスに基づいて、顧客ABCの提案書を作成してください」
```

Gemが自動的に参照ファイルを参照して、より精密な回答を提供します。

## 実践例：3種類の高性能Gem設定

### Gem 1: 「執筆アシスタント」

**カスタム指示：**
```
あなたは、SEOとUXを考慮した記事執筆の専門家です。

与えられたトピックに対して：
1. SEOキーワード調査を念頭に置いたアウトライン提案
2. 冒頭（リード）の案文作成
3. 内部リンク機会の指摘（関連キーワード列挙）
4. 見出し構成（H1→H2→H3の階層）の最適化提案
5. CTA（行動喚起）のベストプラクティス例

出力フォーマット：マークダウン形式で、見出しごとに500〜800文字の本文案を含める
読者層：マーケティング初心者〜中級者
```

### Gem 2: 「データ分析アシスタント」

**カスタム指示：**
```
あなたは、Google Sheets / Google Analyticsのプロです。

与えられたデータに対して：
1. 主要な傾向を3行で要約
2. 異常値の指摘
3. より詳しく調べるべき指標を提案
4. actionable insight（実行可能な洞察）を3つ提供

出力形式：
- 要約（1段落）
- 数値による根拠（表形式）
- 推奨アクション（箇条書き）
```

### Gem 3: 「コード レビュアー」

**カスタム指示：**
```
あなたは、JavaScript/TypeScript/Pythonの経験豊富なシニアエンジニアです。

提供されたコードに対して：
1. 可読性の改善提案
2. パフォーマンスの懸念点（N+1問題、メモリリークなど）
3. セキュリティリスク
4. テストケース提案

出力：
- 問題箇所: [行番号] - [問題内容]
- 修正案: [改善コード]
- テストコード例
```

## よくある質問

**Q1: Gemsで作成したプロンプトを他の人と共有できますか？**

A: はい。Gem詳細ページの「共有」ボタンで、リンク共有やメール招待が可能です。チームメンバーと同じプロンプトを共有すれば、回答の一貫性が保たれます。

**Q2: アップロードしたファイルに個人情報が含まれていても大丈夫？**

A: Gemにアップロードしたファイルはクラウドに保存され、Googleの学習に使われる可能性があります。機密情報やPII（Personally Identifiable Information）の含まれたファイルはアップロード非推奨です。「プライベートGem」として設定することで、ある程度の保護が可能です。

**Q3: Gemsはモバイル版Geminiでも使えますか？**

A: 現在のところ、GeminiのモバイルアプリではGemsの機能が限定的です。PC版 Google AI Studio での利用がもっとも充実した体験が得られます。

**Q4: 無料ユーザーでもGemsを作成・使用できますか？**

A: はい、Gemini無料プラン（Google アカウント）でもGemsの作成・使用が可能です。ただし、API利用に関してはプレミアム機能の制限があります。

**Q5: Gemsで作成したプロンプトをGemini APIで使用することはできますか？**

A: 現在のところ、UI上で作成したGemsはAPI経由で直接利用できません。APIで同じ動作を実現する場合は、[system instruction](https://ai.google.dev/docs/guides/system_instructions) パラメータで同等のプロンプトを指定する必要があります。

## まとめ

Gems機能を活用することで、Geminiをあなた専用のAIアシスタントに変身させられます。

- **カスタム指示**: 役割と背景を明確に指定
- **詳細設定**: トーンと出力形式で応答スタイルを調整
- **参照ファイル**: 常用する資料をあらかじめ用意

3つの要素をうまく組み合わせれば、毎回同じセットアップなしに、高精度の支援が得られます。まずは自分の業務フローに合った1つのGemを作成して、実際に試してみることをお勧めします。
