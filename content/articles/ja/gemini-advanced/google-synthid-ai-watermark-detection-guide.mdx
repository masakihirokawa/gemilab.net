## SynthID とは — AI 生成コンテンツに透かしを埋め込む Google DeepMind の技術

AI が生成したテキスト、画像、音声、動画が急増する中、「このコンテンツは AI が作ったものなのか」を判別する技術のニーズが高まっています。Google DeepMind が開発した **SynthID** は、AI 生成コンテンツに人間の目には見えない電子透かし（ウォーターマーク）を埋め込み、後から検出できるようにする技術です。

SynthID は Gemini のマルチモーダル生成機能と密接に連携しており、Gemini が生成する画像やテキストには自動的に SynthID の透かしが埋め込まれます。ここで扱うのはSynthID の技術的な仕組みから、開発者が API を通じて活用する方法までを体系的に解説します。

## SynthID が対応するコンテンツの種類

SynthID は以下の4種類のモダリティに対応しています。それぞれ異なるアルゴリズムで透かしを埋め込む仕組みです。

**テキスト（SynthID Text）**

大規模言語モデル（LLM）がテキストを生成する際、次のトークンを選択する確率分布にわずかな調整を加えることで透かしを埋め込みます。生成されるテキストの品質には影響を与えず、統計的な検定によって透かしの有無を判定できます。Gemini が生成するテキスト応答にはこの方式が適用されています。

**画像（SynthID Image）**

生成画像のピクセルデータに、人間の知覚閾値以下の微細な変更を加えて透かし情報を埋め込みます。画像の圧縮、リサイズ、トリミングなど一般的な編集操作を行っても透かしが残存するよう設計されています。Gemini の画像生成機能や Imagen で生成された画像に自動適用されます。

**音声（SynthID Audio）**

音声波形のスペクトル領域に透かし信号を重畳します。人間の聴覚ではほぼ知覚できないレベルの変更ですが、専用の検出器で高精度に透かしの存在を確認できます。Lyria などの音楽生成モデルの出力に適用されています。

**動画（SynthID Video）**

動画のフレーム単位で画像透かしを適用しつつ、時間軸方向にも一貫した透かしパターンを維持します。Veo で生成された動画に自動的に埋め込まれます。

## SynthID Text の技術的な仕組み — トークンサンプリングへの介入

SynthID のテキスト透かしは、LLM のトークン生成プロセスに介入することで実現されています。具体的な処理の流れを見てみましょう。

### トーナメントサンプリング方式

従来の透かし手法では、語彙をグリーンリスト（透かしあり）とレッドリスト（透かしなし）に分割する方式が一般的でしました。SynthID Text はこれを発展させた「トーナメントサンプリング」を採用しています。

```python
import numpy as np

def tournament_sampling_demo(logits, watermark_key, num_candidates=4):
    """SynthID Textのトーナメントサンプリングの概念的なデモ"""

    # 1. ロジットから確率分布を計算
    probs = np.exp(logits) / np.sum(np.exp(logits))

    # 2. 確率分布から複数の候補トークンをサンプリング
    candidates = np.random.choice(
        len(probs), size=num_candidates, p=probs
    )

    # 3. 透かしキーに基づくスコアで候補をランキング
    #    （実際の SynthID では暗号学的ハッシュを使用）
    scores = []
    for token_id in candidates:
        hash_input = f"{watermark_key}_{token_id}"
        score = hash(hash_input) % 1000 / 1000.0
        scores.append(score)

    # 4. 最高スコアの候補を選択（透かしパターンの埋め込み）
    winner_idx = np.argmax(scores)
    return candidates[winner_idx]

# 使用例
vocab_size = 32000
logits = np.random.randn(vocab_size)
selected_token = tournament_sampling_demo(logits, watermark_key="secret_key_123")
print(f"選択されたトークンID: {selected_token}")
# 出力例: 選択されたトークンID: 15234
```

この方式のポイントは、元の確率分布を大きく歪めずに透かしパターンを埋め込める点です。高確率のトークンが選ばれやすい傾向は維持されるため、生成テキストの品質低下を最小限に抑えられます。

### 検出の仕組み

検出時は、対象テキストの各トークンに対して同じ透かしキーでスコアを計算し、統計的にスコアの偏りがあるかを検定します。

```python
def detect_watermark_demo(text_tokens, watermark_key, threshold=0.7):
    """テキスト透かし検出の概念的なデモ"""

    scores = []
    for i, token_id in enumerate(text_tokens):
        # 同じキーでスコアを再計算
        hash_input = f"{watermark_key}_{token_id}"
        score = hash(hash_input) % 1000 / 1000.0
        scores.append(score)

    # スコアの平均が閾値を超えていれば透かしあり
    avg_score = np.mean(scores)
    is_watermarked = avg_score > threshold

    return {
        "is_watermarked": is_watermarked,
        "confidence": avg_score,
        "tokens_analyzed": len(text_tokens)
    }

# 期待する出力例:
# {"is_watermarked": True, "confidence": 0.82, "tokens_analyzed": 256}
```

## SynthID Image の仕組み — 知覚できない透かしの埋め込み

画像への透かし埋め込みには、深層学習ベースのエンコーダ・デコーダ構造が使われています。

### アーキテクチャの概要

- **エンコーダ**: 入力画像と透かしメッセージ（バイナリ列）を受け取り、透かし入り画像を出力
- **デコーダ**: 透かし入り画像から透かしメッセージを抽出
- **判別器**: 元画像と透かし入り画像の区別がつかないよう訓練

```python
# SynthID Image の概念的な利用イメージ（Vertex AI 経由）
from google.cloud import aiplatform

def generate_watermarked_image(prompt: str, project_id: str):
    """Vertex AI Imagen で SynthID 透かし付き画像を生成する例"""

    aiplatform.init(project=project_id, location="us-central1")

    # Imagen モデルで画像生成（SynthID は自動適用）
    model = aiplatform.ImageGenerationModel.from_pretrained(
        "imagen-3.0-generate-002"
    )

    response = model.generate_images(
        prompt=prompt,
        number_of_images=1,
        language="ja",
        add_watermark=True  # SynthID 透かし（デフォルトで有効）
    )

    # 生成画像の保存
    response.images[0].save("output_with_watermark.png")
    print("SynthID 透かし付き画像を保存しました")
    return response

# 使用例
# generate_watermarked_image("東京の夜景", "your-project-id")
```

この透かしは、JPEG 圧縮（品質 75% 程度まで）、リサイズ、90度回転などの一般的な画像処理に対して耐性を持つよう設計されています。ただし、大幅なトリミングやテキストの上書きなど、画像の大部分を改変する操作では透かしが失われる可能性があります。

## SynthID の信頼性と限界

SynthID は強力な技術ですが、万能ではありません。開発者として理解しておくべき限界があります。

### 検出の信頼度レベル

SynthID の検出結果は確率的なものであり、以下の3段階で報告されます。

- **検出あり（Detected）**: 高い確率で AI 生成コンテンツと判定
- **不確定（Uncertain）**: 判定に十分な情報がない
- **検出なし（Not Detected）**: 透かしが見つからない（ただし AI 生成でないことの証明ではない）

### 既知の制限事項

- **テキスト**: 短いテキスト（約200トークン未満）では検出精度が低下します
- **画像**: 大幅な画像加工（コラージュ、フィルター重ね掛け）で透かしが破壊される場合があります
- **スクリーンショット**: 画面キャプチャ経由では画像の透かしが失われることがあります
- **他モデルの出力**: SynthID は Google のモデルに統合された技術であり、他社の AI モデルの出力は検出できません

## C2PA メタデータとの併用

SynthID は C2PA（Coalition for Content Provenance and Authenticity）のメタデータ標準とも併用されています。C2PA は画像や動画のメタデータとして来歴情報を記録する仕組みで、SynthID の知覚不可能な透かしとは相補的な関係にあります。

- **SynthID**: コンテンツそのものに埋め込まれ、メタデータが除去されても残存
- **C2PA**: メタデータとして来歴チェーンを記録。改ざん検出に強いが、メタデータ除去で失われる

Google は両方の技術を組み合わせることで、より堅牢な AI コンテンツ識別を実現しています。Gemini で生成された画像には SynthID と C2PA の両方が適用されるケースが増えています。

## 実践：SynthID を活用したコンテンツ管理システムの設計

自社サービスで AI 生成コンテンツを扱う場合、SynthID を組み込んだコンテンツ管理の仕組みを設計できます。

```python
from dataclasses import dataclass
from enum import Enum
from datetime import datetime

class WatermarkStatus(Enum):
    DETECTED = "detected"
    UNCERTAIN = "uncertain"
    NOT_DETECTED = "not_detected"

@dataclass
class ContentMetadata:
    content_id: str
    generated_at: datetime
    model_name: str
    watermark_status: WatermarkStatus
    confidence_score: float

class AIContentManager:
    """AI生成コンテンツの管理クラス"""

    def __init__(self):
        self.content_registry: dict[str, ContentMetadata] = {}

    def register_content(
        self,
        content_id: str,
        model_name: str,
        watermark_confidence: float
    ) -> ContentMetadata:
        """AI生成コンテンツを登録し、透かし情報を記録する"""

        # 信頼度に基づくステータス判定
        if watermark_confidence >= 0.8:
            status = WatermarkStatus.DETECTED
        elif watermark_confidence >= 0.5:
            status = WatermarkStatus.UNCERTAIN
        else:
            status = WatermarkStatus.NOT_DETECTED

        metadata = ContentMetadata(
            content_id=content_id,
            generated_at=datetime.now(),
            model_name=model_name,
            watermark_status=status,
            confidence_score=watermark_confidence
        )

        self.content_registry[content_id] = metadata
        return metadata

    def get_ai_generated_content(self) -> list[ContentMetadata]:
        """AI生成と判定されたコンテンツの一覧を返す"""
        return [
            meta for meta in self.content_registry.values()
            if meta.watermark_status == WatermarkStatus.DETECTED
        ]

# 使用例
manager = AIContentManager()
result = manager.register_content(
    content_id="img_001",
    model_name="gemini-2.5-pro",
    watermark_confidence=0.92
)
print(f"Status: {result.watermark_status.value}")
print(f"Confidence: {result.confidence_score}")
# 出力:
# Status: detected
# Confidence: 0.92
```
