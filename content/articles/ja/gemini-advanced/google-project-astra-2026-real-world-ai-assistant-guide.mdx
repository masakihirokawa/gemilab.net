スマートフォンのカメラを冷蔵庫に向けながら「今夜これで何か作れそうですか？」と話しかけると、AIが中身を見ながらレシピを提案してくれる。コードエディタにカメラを向けて「このエラー、どこを直せばいいですか？」と聞くと、画面を読み取って答えてくれる。

こうした「世界を見ながら考えるAI」を実現しようとしているのが、Google の **Project Astra** です。

Gemini を基盤とした次世代AIアシスタントとして開発が進められており、2026年現在、一部の機能が Google の製品に徐々に統合され始めています。今回はその現状と、実際に使える機能・使い方について整理します。

## Project Astra とは何か

Project Astra は、Google DeepMind が開発するマルチモーダルなリアルタイム AI アシスタントです。テキストだけでなく、カメラ映像・音声・画面内容を同時に処理しながら、自然な会話でやりとりできることが最大の特徴です。

2024年に Google I/O でデモが公開されたとき、眼鏡型デバイスを装着した人が周囲の環境を見ながら AI と会話するシーンが話題になりました。「これは本物なのか？」という反応が多かったほど、そのリアルタイム性は印象的なものでした。

従来の AI アシスタントとの最大の違いは、「記憶を持つこと」と「環境を継続的に認識すること」にあります。

- **継続的な視覚認識**: カメラ映像をリアルタイムに処理し、「さっきそこに置いてあったメモ帳、どこに行きましたか？」という質問にも答えられる
- **マルチモーダルな統合**: 音声・映像・テキストを同時に受け取り、文脈を保ちながら会話を続けられる
- **外部ツールとの連携**: Google 検索・マップ・レンズなどと連動し、見ているものについてリアルタイムで情報を取得できる

## 2026年現在、どこで使えるのか

Project Astra の技術は、いくつかの Google 製品にすでに組み込まれています。

**Google アプリの「Lens + Gemini」統合**

スマートフォンのカメラで何かを見ながら Gemini に質問できる機能は、Google アプリを通じて日本でも利用が広がっています。街中の看板・レストランのメニュー・商品のラベルを映しながら「これは何ですか？どう使いますか？」と話しかけると、映像と音声を合わせた回答が返ってきます。

**Gemini Live との統合**

Gemini Live は、音声でリアルタイムに Gemini と会話できる機能です。ここに画面共有を組み合わせることで、見ているものについてすぐに質問できます。アプリの操作方法を画面を見せながら確認したり、コードエラーをそのまま映して解決策を聞いたりする使い方が実用段階に入っています。

**Android の「画面を見て答える」機能**

Android デバイスでは、AI が現在表示されている画面の内容を認識した上で質問に答える機能が順次展開されています。SNS の投稿を見ながら「これってどういう意味？」と聞いたり、地図を映したまま「ここから一番近い駅は？」と話しかける使い方が可能になっています。

## クリエイターや開発者はどう使えるか

Project Astra の機能は、日常的な用途だけでなくクリエイティブな作業にも応用が広がっています。

**デザインレビューのリアルタイム補佐**

Figma やスケッチブックを画面に映しながら「このレイアウト、視線の流れはどうですか？」と聞くと、映像から読み取った上でフィードバックが返ってきます。デザイン判断を言語化して伝えるのが難しいとき、「見てもらいながら話す」という形式はとても自然です。

**コードデバッグの補助**

エラーが出ているターミナルやコードエディタにカメラを向けながら「どこが問題ですか？」と聞く使い方は、特に複雑なスタックトレースや環境依存のバグに有効です。テキストとして入力するより、画面そのものを見せたほうが文脈が伝わりやすい場面があります。

**現地取材・記録の補助**

展示会や現場取材で見たものをカメラで記録しながら AI に話しかけ、「この機器は何ですか？」「この看板の英語を訳してください」とリアルタイムで確認できます。後から記録を整理する手間が大幅に減ります。

## Gemini との関係を整理する

Project Astra は Gemini をベースとして構築されています。ただし、用途の焦点が異なります。

Gemini（モデル自体）はテキスト・マルチモーダルの基盤モデルであり、API を通じた開発用途が中心です。Project Astra はその Gemini の能力を、カメラ・音声・デバイス連携と組み合わせた「現実世界と接するアシスタント」として具体化したものです。

開発者の視点で言えば、Gemini Live API や Multimodal Live API が Project Astra の機能に最も近い実装先になります。音声と映像をリアルタイムに処理するアプリを作りたい場合は、これらの API から始めるのが現実的なルートです。

## 今後の展開と注目点

Project Astra の完全な形——眼鏡型デバイスとの統合、より長い記憶の保持、多言語でのスムーズなやりとり——は、まだ展開途上です。

ただ、重要なのは方向性がはっきりしていることです。AI が「見て・聞いて・記憶する」ことが当たり前になる世界は、ゆっくりと、でも着実に近づいています。
