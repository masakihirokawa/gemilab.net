## gemini-2.5-flash-lite が本日シャットダウン — 何が起きるのか

2026年3月31日をもって、Google は `gemini-2.5-flash-lite` モデルの提供を正式に終了します。このモデルを利用しているすべてのAPIリクエストは、本日以降エラーを返すようになります。

影響を受けるのは、主に以下のケースです。

- APIコード内でモデル名を `gemini-2.5-flash-lite` にハードコードしているアプリケーション
- Google AI Studio のプロジェクトで同モデルを選択している場合
- Vertex AI のエンドポイント設定で旧モデルを指定している場合

移行先として推奨されるのが `gemini-3.1-flash-lite` です。2.5世代と比較して推論速度・精度ともに大幅に向上しており、API互換性も高いため、多くの場合はモデル名の変更だけで移行が完了します。

## gemini-2.5-flash-lite と 3.1 Flash-Lite の主な違い

移行前に、両モデルのスペック差を把握しておきましょう。

- **推論速度**: 3.1 Flash-Lite は 2.5 Flash-Lite と比較して約30〜40%高速。特にストリーミングレスポンスの初回トークン生成が大幅に改善されています
- **コンテキストウィンドウ**: 2.5 Flash-Lite の 32,768 トークンから、3.1 Flash-Lite では 65,536 トークンに倍増
- **マルチモーダル対応**: 3.1 Flash-Lite はテキスト・画像に加えて音声入力にも対応（2.5世代はテキスト・画像のみ）
- **料金**: 入力トークンあたりの料金はほぼ同等。コスト面での移行障壁はありません
- **System Instructions**: 3.1 Flash-Lite ではより長く複雑なシステム指示を安定して処理できます

これらの改善により、モデル名を変更するだけで、既存アプリケーションのパフォーマンスが向上するケースがほとんどです。

## 移行手順 — Python SDK の場合

Python（Google AI Python SDK）を使っている場合の移行手順を見ていきましょう。変更箇所はモデル名の1行だけです。

```python
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")

# ❌ 旧モデル（2026年3月31日で終了）
# model = genai.GenerativeModel("gemini-2.5-flash-lite")

# ✅ 新モデル（推奨移行先）
model = genai.GenerativeModel("gemini-3.1-flash-lite")

response = model.generate_content("Pythonでフィボナッチ数列を生成する関数を書いてください")
print(response.text)
# 期待出力: フィボナッチ数列を生成するPython関数のコード
```

移行後の動作確認として、いくつかのプロンプトでレスポンスを比較してみることをお勧めします。3.1 Flash-Lite は応答品質が向上しているため、出力内容に若干の変化が生じる可能性があります。

## 移行手順 — JavaScript/TypeScript の場合

Node.js 環境での移行も同様にシンプルです。

```javascript
import { GoogleGenerativeAI } from "@google/generative-ai";

const genAI = new GoogleGenerativeAI("YOUR_GEMINI_API_KEY");

// ❌ 旧モデル
// const model = genAI.getGenerativeModel({ model: "gemini-2.5-flash-lite" });

// ✅ 新モデル
const model = genAI.getGenerativeModel({ model: "gemini-3.1-flash-lite" });

async function main() {
  const result = await model.generateContent(
    "JavaScriptでクイックソートを実装してください"
  );
  console.log(result.response.text());
  // 期待出力: クイックソートのJavaScript実装コード
}

main();
```

TypeScript を使っている場合も同様に、モデル名の文字列を置換するだけで移行が完了します。SDK のバージョンは最新（v0.24.0以降）を推奨します。

## Vertex AI を使っている場合の移行手順

Vertex AI 経由で Gemini を利用している場合は、エンドポイントのモデル指定を更新します。

```python
import vertexai
from vertexai.generative_models import GenerativeModel

vertexai.init(project="your-project-id", location="us-central1")

# ❌ 旧モデル
# model = GenerativeModel("gemini-2.5-flash-lite")

# ✅ 新モデル
model = GenerativeModel("gemini-3.1-flash-lite")

response = model.generate_content("Cloud Runのデプロイ手順を簡潔にまとめてください")
print(response.text)
# 期待出力: Cloud Runデプロイ手順のステップバイステップ解説
```

Vertex AI のモデルガーデンでは、旧モデルは「非推奨」ステータスに変更されます。既存のデプロイ済みエンドポイントを使っている場合は、エンドポイント設定画面からモデルバージョンを更新してください。

## 移行時の注意点とトラブルシューティング

スムーズな移行のために、以下のポイントを確認しておきましょう。

### SDK バージョンの確認

古いバージョンの SDK では `gemini-3.1-flash-lite` モデルが認識されない場合があります。以下のコマンドで最新版に更新してください。

```bash
# Python
pip install --upgrade google-generativeai

# JavaScript/TypeScript
npm install @google/generative-ai@latest
```

### 環境変数でモデル名を管理する

モデル名をハードコードせず、環境変数で管理しておくと、今後のモデル更新にも柔軟に対応できます。

```python
import os
import google.generativeai as genai

MODEL_NAME = os.environ.get("GEMINI_MODEL", "gemini-3.1-flash-lite")
genai.configure(api_key=os.environ["GEMINI_API_KEY"])
model = genai.GenerativeModel(MODEL_NAME)
# これでモデル変更時にコードを修正する必要がなくなります
```

### レスポンス形式の確認

3.1 Flash-Lite では、JSON モード（`response_mime_type: "application/json"`）の安定性が向上しています。旧モデルで JSON パースエラーが発生していた場合、移行によって解消される可能性があります。

### レート制限の変更

3.1 Flash-Lite は無料枠のレート制限が旧モデルと異なる場合があります。Google AI Studio のダッシュボードで、プロジェクトのクォータ設定を確認してください。

## Google AI Studio でのモデル切り替え

コードを書かずに Google AI Studio を使っている方は、以下の手順でモデルを切り替えられます。

1. [Google AI Studio](https://aistudio.google.com/) にアクセス
2. 既存のプロンプトを開く（または新規作成）
3. 右側パネルの「Model」ドロップダウンから `Gemini 3.1 Flash-Lite` を選択
4. 既存のプロンプトをそのまま実行して動作確認

保存済みのプロンプトは、モデルを切り替えた後も同じ設定（Temperature、Top-P など）で動作します。3.1 Flash-Lite ではデフォルトのパラメータでも十分な品質が出るため、パラメータの再調整は必須ではありません。

タスクに応じて最適なモデルを選びたい方には、[Gemini モデル選択ガイド — タスク別に最適なモデルを選ぶ方法](/articles/gemini-basics/gemini-model-selection) も参考になります。

## 今後のモデルライフサイクルに備える

今回の 2.5 Flash-Lite シャットダウンは、Google のモデルライフサイクルポリシーに基づくものです。今後も旧世代モデルは順次廃止されていくため、以下の習慣を身につけておくと安心です。

- **モデル名を環境変数で管理する**: コードの変更を最小限に抑えられます
- **Google AI の公式ブログを定期チェックする**: モデルの廃止予告は通常2〜3ヶ月前にアナウンスされます
- **テストスイートを整備する**: モデル変更後にリグレッションテストを自動実行できる体制を作っておくと移行がスムーズです
- **`gemini-3.1-flash-lite` のエイリアスを活用する**: `latest` エイリアスを使うと最新の安定版が自動適用されますが、本番環境では固定バージョンを指定する方が安全です

3.1 Flash-Lite と上位モデルとの違いを詳しく知りたい方は、[Gemini 3.1 Flash vs Pro 徹底比較 — 速度・精度・コストで選ぶ最適モデル](/articles/gemini-basics/gemini-31-flash-vs-pro-comparison-guide) をご参照ください。
