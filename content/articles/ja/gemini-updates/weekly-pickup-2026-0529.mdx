## 第1位：Gemini API の Request Hedging で tail latency を抑える本番設計

[Gemini API の Request Hedging で tail latency を抑える本番設計](/articles/gemini-api/gemini-api-request-hedging-tail-latency-production-design)

今週もっとも読まれたのは、Request Hedging による p99 レイテンシの設計記事です。Gemini Flash でレスポンスが普段 800ms 程度でも、月に数回は 5〜8 秒で止まる呼び出しが混ざります。私の 4 サイト記事生成パイプラインでは、これが起きると後段のスケジュールタスク全体がずれていきます。

記事では、最初のリクエストから 1.5 秒経っても返ってこない場合に同じプロンプトでもう 1 本を打ち、先に帰ってきた方を採用するという、Google SRE 本でいう Hedged Request の実装を紹介しました。コストはだいたい 1.1 倍に増えますが、p99 が 4 秒から 1.8 秒に下がる、というのが私の本番計測値です。

```python
async def hedged_call(prompt: str, hedge_delay_s: float = 1.5):
    primary = asyncio.create_task(call_gemini(prompt))
    done, _ = await asyncio.wait({primary}, timeout=hedge_delay_s)
    if primary in done:
        return primary.result()
    hedge = asyncio.create_task(call_gemini(prompt))
    done, pending = await asyncio.wait({primary, hedge}, return_when=asyncio.FIRST_COMPLETED)
    for p in pending: p.cancel()
    return next(iter(done)).result()
```

## 第2位：Gemini API の 3 層キャッシュ（メモリ・Redis・Context Cache）でコストを 6 割削った設計

[Gemini API の 3 層キャッシュ（メモリ・Redis・Context Cache）でコストを 6 割削った設計](/articles/gemini-api/gemini-api-three-tier-cache-memory-redis-context-cache)

Gemini の Context Cache を使うと、同じ長文プロンプトを繰り返し投げるコストはかなり下がります。ただ、Context Cache 単体では「数秒前の同一リクエスト」までは吸収できません。そこをメモリキャッシュと Redis で覆い、最後に Context Cache に落とす 3 層構成を、私のブログ運用パイプラインで実装した記録です。

私のケースでは、入力トークン換算で月のコストを約 6 割削れました。L1（メモリ）でリクエスト重複、L2（Redis）でセッション内重複、L3（Context Cache）でテンプレートを吸収します。どこを覆っていないかを把握しておかないと、Context Cache だけを入れて満足してしまいがちな部分です。

## 第3位：Gemini Flash で Staged Rollout の自動判断エンジンを書いた話

[Gemini Flash で Staged Rollout の自動判断エンジンを書いた話](/articles/gemini-api/gemini-flash-staged-rollout-decision-engine-indie)

Google Play Console の Staged Rollout（段階公開）は、Crashlytics のクラッシュフリー率と Android Vitals の主要指標を毎時間見て、進めるか巻き戻すかを判断します。手で見ていると、夜中の数字の動きを取り損ねます。

この記事では、Gemini Flash に Crashlytics・Android Vitals・Play Console のレビュー数値を渡し、`continue` / `pause` / `rollback` の 3 値を JSON で返させる判断エンジンを、私の 4 アプリで 3 週間運用したログ込みで紹介しました。Flash の応答が速いので、5 分粒度のサイクルでも回せます。最終決定は人が見る運用ですが、夜間の見落としを潰してくれます。

[Gemini 3.1 Pro と Claude Sonnet 4.6 を 30 タスクで比較した 2026 年版](/articles/gemini-advanced/gemini-31-pro-vs-claude-sonnet-46-comparison-2026)
