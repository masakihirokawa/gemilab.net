## 🥉 第3位：Firebase Studio 入門ガイド

**[Firebase Studio 入門ガイド：GeminiでフルスタックAIアプリを素早く構築する](/articles/gemini-dev/firebase-studio-gemini-quickstart-guide)**

第3位は、Google の新しい開発環境「Firebase Studio」の入門ガイドです。Gemini との深い統合により、フルスタック AI アプリを従来よりも大幅に短い時間で構築できるようになりましました。


```javascript
// Firebase Studio で Gemini を統合する基本例
import { initializeApp } from 'firebase/app';
import { getVertexAI, getGenerativeModel } from 'firebase/vertexai';

const app = initializeApp(firebaseConfig);
const vertexAI = getVertexAI(app);
const model = getGenerativeModel(vertexAI, { model: "gemini-2.0-flash" });

async function generateContent(prompt) {
  const result = await model.generateContent(prompt);
  return result.response.text();
}
```

### よくある質問（FAQ）

**Q1. Gemini Live 3.1 は無料で使えますか？**

A1. Gemini Live は Google One AI Premium プランに含まれています。無料プランでも一部機能を試すことができますが、Live 3.1 の全機能を活用するにはサブスクリプションが必要です。料金の詳細は Google の公式サイトをご確認ください。

**Q2. Gemini Lyria で生成した音楽は商用利用できますか？**

A2. Google の利用規約に基づき、一定条件のもとで商用利用が可能です。ただし、条件や制限が設けられている場合がありますので、最新の利用規約を必ずご確認ください。詳しくは第2位の記事内で解説しています。

**Q3. Firebase Studio は無料で始められますか？**

A3. はい、Firebase の無料プラン（Spark プラン）の範囲内で Firebase Studio を試すことができます。本番運用やより大きなスケールでの利用には有料プランへの移行が必要な場合があります。
