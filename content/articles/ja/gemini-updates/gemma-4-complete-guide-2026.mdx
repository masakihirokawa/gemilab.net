## Gemma 4 とは — Google が放ったオープンモデルの最新世代

2026年4月2日、Google が待望の「**Gemma 4**」をリリースしましました。Gemma シリーズは Google が公開するオープンウェイトモデルファミリーで、商用利用も可能な **Apache 2.0 ライセンス**のもとで提供されています。Gemma 4 は前世代から大幅に進化し、より小さなモデルでより高い性能を実現しつつ、Raspberry Pi や Android デバイスのような低スペック環境でも動作するエッジ AI の新しい標準として注目されています。

Gemini Lab 読者にとって特に重要なのは、**Gemma 4 が Gemini API と組み合わせて使えるエコシステム**の一部として設計されている点です。Google のクラウド AI（Gemini）とエッジ AI（Gemma）をシームレスに組み合わせる開発アーキテクチャが、個人開発から企業システムまで幅広い用途で現実的な選択肢になりましました。

## Gemma 4 のラインナップ

Gemma 4 は用途・環境に応じて4つのモデルサイズが提供されています。

**E2B（Efficiently 2B）**
最も小さく、最も速いモデルです。スマートフォンやシングルボードコンピュータ（Raspberry Pi 5 など）での動作を主眼に設計されており、推論レイテンシが数百ミリ秒レベルで応答できます。リソース制約の厳しい IoT デバイスや、バッテリー駆動のエッジデバイスに最適です。

**E4B（Efficiently 4B）**
E2B と 26B の中間に位置するバランス型です。モバイルアプリケーションや中程度の推論タスクに適しており、単一の GPU（NVIDIA RTX 3060 クラス）でも動作します。

**26B**
高品質なテキスト生成・要約・翻訳・コード生成が必要な場合に適した中規模モデルです。単一の高性能 GPU（A100 80GB など）での運用が可能で、プロダクション環境での利用を想定した設計になっています。

**31B**
Gemma 4 ファミリーの最大モデルです。複雑な推論タスク、長いコンテキストの処理、高品質なコード生成において特に優秀なパフォーマンスを発揮します。企業のオンプレミス環境や強力なクラウド GPU インスタンスでの利用を想定しています。

## Apache 2.0 ライセンスで何ができるか

Gemma 4 が Apache 2.0 ライセンスであることの意味は非常に大きいです。

- 商用アプリケーションへの組み込みが自由
- モデルの改変・ファインチューニングが可能
- 改変済みモデルの再配布が可能（ライセンス表示が必要）
- クローズドソースのプロダクトへの組み込みが可能

つまり、自社サービスや個人開発アプリの AI 機能として Gemma 4 を使い、それを App Store や Google Play でリリースすることが完全に合法的に行えます。これは従来の「API 経由のみ」の商用利用に比べて、プライバシー保護・オフライン動作・コスト削減という観点で大きなアドバンテージをもたらします。

## Gemma 4 の主要な改善点

### 140言語のマルチリンガル対応

Gemma 4 は 140 言語に対応しており、日本語での指示理解と生成品質が前世代から大幅に向上しています。英語以外の言語でのファインチューニングデータが増加し、アジア言語特有の文脈理解も改善されています。

### マルチモーダル対応（画像理解）

新世代の Gemma 4 はテキストだけでなく画像入力にも対応しましました。カメラからの映像を解析したり、ドキュメントの写真から情報を抽出したりする用途に活用できます。

### エージェント機能の強化

自律的なタスク実行能力が強化され、ツール呼び出し（Function Calling）や段階的な推論（Chain of Thought）が改善されましました。Gemma 4 を使って簡易的な AI エージェントを構築する場合の精度と信頼性が向上しています。

### Python での基本的な使い方（Transformers 経由）

```python
# Gemma 4 を Python で動かす基本的なサンプル
# 必要なパッケージ: pip install transformers torch accelerate

from transformers import AutoTokenizer, AutoModelForCausalLM
import torch

# E4B モデルを Hugging Face Hub からダウンロード
# ※ Gemma モデルの使用には Google アカウントでの利用規約同意が必要です
MODEL_NAME = "google/gemma-4-e4b-it"

def load_gemma4():
    """Gemma 4 モデルとトークナイザーをロードする"""
    print("モデルをロード中... (初回は時間がかかります)")

    tokenizer = AutoTokenizer.from_pretrained(MODEL_NAME)
    model = AutoModelForCausalLM.from_pretrained(
        MODEL_NAME,
        device_map="auto",      # 利用可能な GPU/CPU を自動選択
        torch_dtype=torch.bfloat16,  # メモリ効率化
        low_cpu_mem_usage=True
    )

    return tokenizer, model

def generate_response(
    tokenizer,
    model,
    user_message: str,
    system_prompt: str = "あなたは親切で正確な AI アシスタントです。",
    max_new_tokens: int = 512,
    temperature: float = 0.7
) -> str:
    """
    Gemma 4 でテキスト生成を行う

    Parameters:
        tokenizer: Gemma トークナイザー
        model: Gemma 4 モデル
        user_message: ユーザーの入力
        system_prompt: システムプロンプト（役割定義）
        max_new_tokens: 生成する最大トークン数
        temperature: 生成の多様性（0=決定論的、1=最大多様性）

    Returns:
        生成されたテキスト
    """
    # チャット形式でプロンプトを構築
    messages = [
        {"role": "user", "content": f"{system_prompt}\n\n{user_message}"}
    ]

    # トークナイズ
    input_ids = tokenizer.apply_chat_template(
        messages,
        return_tensors="pt",
        add_generation_prompt=True
    ).to(model.device)

    # テキスト生成
    with torch.no_grad():
        output_ids = model.generate(
            input_ids,
            max_new_tokens=max_new_tokens,
            temperature=temperature,
            do_sample=True,
            pad_token_id=tokenizer.eos_token_id
        )

    # 入力部分を除いた生成テキストを返す
    generated_ids = output_ids[0][input_ids.shape[1]:]
    return tokenizer.decode(generated_ids, skip_special_tokens=True)

# 実行例
if __name__ == "__main__":
    tokenizer, model = load_gemma4()

    # 日本語での質問
    response = generate_response(
        tokenizer, model,
        user_message="機械学習における過学習（オーバーフィッティング）とは何ですか？"
                     "初心者にもわかりやすく例えを使って説明してください。",
        system_prompt="あなたは機械学習の専門家です。"
                      "初心者にもわかりやすい丁寧な説明を心がけてください。"
    )
    print("=== Gemma 4 の回答 ===")
    print(response)
```

### Android アプリへの組み込み（Android AICore / LiteRT）

Gemma 4 は Google の Android AICore 対応デバイスで、オンデバイス推論として動作します。

```kotlin
// Android アプリへの Gemma 4 組み込みイメージ（Kotlin）

import androidx.ai.edge.litert.LiteRtSession

class GemmaInference(context: Context) {

    private lateinit var session: LiteRtSession

    suspend fun initialize() {
        // Android AICore 経由でモデルをロード
        // ※ 実際の実装は google.ai.edge:litert ライブラリを参照
        session = LiteRtSession.createFromModel(
            modelPath = "gemma4_e2b_quantized.task",
            context = context
        )
    }

    suspend fun generateText(prompt: String): String {
        val result = session.runInference(
            inputs = mapOf("text_input" to prompt),
            outputKeys = listOf("text_output")
        )
        return result["text_output"] as String
    }
}

// 使用例
class MainActivity : ComponentActivity() {
    private val gemma = GemmaInference(this)

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        lifecycleScope.launch {
            gemma.initialize()
            val response = gemma.generateText("今日のToDoリストを3つ提案して")
            println(response)
        }
    }
}
```

**オフライン対応アプリ**
ネットワーク接続がない環境でも AI 機能を提供し、接続回復後にクラウドと同期するアプリが Gemma 4 × Gemini API の組み合わせで実現可能です。

## FAQ

**Q1: Gemma 4 は無料で使えますか？**

Gemma 4 のモデルウェイト自体は Hugging Face Hub や Google の公式サイトから無料でダウンロードできます（利用規約への同意が必要）。Apache 2.0 ライセンスのため、商用利用も無料です。ただし、Google AI Studio での API 経由利用や Vertex AI を通じたクラウド推論には費用が発生する場合があります。

**Q2: ChatGPT や Gemini 2.5 Pro と比べて性能はどうですか？**

大規模モデル（GPT-4o、Gemini 2.5 Pro）と比べると、複雑な推論や長いコンテキストでの処理では差があります。ただし、E4B〜26B クラスは日常的なテキスト生成・要約・翻訳・コード補完においては十分な品質を発揮し、特にローカル実行という制約の中では非常に優秀です。

**Q3: ファインチューニングはできますか？**

はい、Apache 2.0 ライセンスのもとでファインチューニングが可能です。Hugging Face の `trl` ライブラリや、Google の Vertex AI Tuning サービスを使って独自データでの特化チューニングができます。医療・法律・特定ドメインへの特化が容易なのも Gemma 4 の魅力です。

**Q4: Gemma 4 と Gemini Nano の違いは何ですか？**

Gemini Nano は Google Pixel などの特定 Android デバイスに組み込まれたオンデバイスモデルで、外部からダウンロードして自由に使うことはできません。Gemma 4 はオープンウェイトで誰でも使える点が大きな違いです。用途・デバイスに応じて使い分けることになります。
