## Gemini API コスト最適化の最小コード例

3位の記事から、タスク別にモデルを切り替えてコストを最適化するパターンの骨格だけ抜粋します。

```python
import google.generativeai as genai

# タスクの複雑さに応じてモデルを切り替える
def get_model_for_task(task_type: str) -> str:
    MODEL_MAP = {
        "classification": "gemini-2.5-flash",   # 安価・高速
        "summarization": "gemini-2.5-flash",
        "code_review": "gemini-3.2-pro",          # 精度重視
        "complex_reasoning": "gemini-3.2-pro",
    }
    return MODEL_MAP.get(task_type, "gemini-2.5-flash")

def call_gemini(prompt: str, task_type: str) -> str:
    model_name = get_model_for_task(task_type)
    model = genai.GenerativeModel(model_name)
    response = model.generate_content(prompt)
    return response.text

# 使用例
result = call_gemini("このコードを改善してください: ...", "code_review")
```

タスクを細かく分類するほど、コスト削減効果が大きくなります。詳細な分類基準と実測コスト比較は3位の元記事をご参照ください。
