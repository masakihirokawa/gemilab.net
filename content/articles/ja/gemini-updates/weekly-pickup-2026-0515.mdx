## 2位：個人開発12年目が実測した Gemini API・Claude API・GPT-4o の費用対効果比較

2014年からアプリを開発し続け、累計5,000万ダウンロードを超える壁紙・癒し系アプリのバックエンドで、3つの主要APIを実際に使い比べた記録です。

[個人開発12年目が実測した Gemini API・Claude API・GPT-4o の費用対効果比較](/articles/gemini-api/gemini-api-vs-claude-gpt4o-indie-dev-cost-benchmark-2026)

**実測結果の概要:**
- コスト最優先ならば Gemini Flash > Haiku > GPT-4o mini の順
- 品質とコストのバランスは Gemini 2.5 Pro が突出している場面が多い
- Claude は長文の推論・コード生成で特に安定していた
- 「どれが実用的か」ではなく「どのタスクに何を使うか」が正しい問い

```python
# モデル選定の実践的な判断フロー
def select_model(task_type: str, budget_per_request: float) -> str:
    if task_type == "classification" and budget_per_request < 0.0005:
        return "gemini-flash-2.5"          # バッチ分類：最安
    elif task_type == "reasoning" and budget_per_request < 0.01:
        return "gemini-2.5-pro"            # 推論：コスパ最良
    elif task_type == "code_generation":
        return "claude-sonnet-4-5"         # コード生成：安定感
    else:
        return "gemini-2.5-pro"            # デフォルト
```

癒し系・壁紙系アプリのバックエンドに Gemini API を採用してから3ヶ月が経過した時点での正直な評価記事です。

[Gemini API を実アプリのバックエンドに採用して3ヶ月 — 個人開発者の正直な評価](/articles/gemini-api/gemini-api-real-backend-indie-app-3month-honest-evaluation)

**良かった点:**
- Flash モデルのレイテンシは他社比較でも際立って速い
- Gemini 2.5 Pro の推論品質は多くのタスクで期待を上回った

**期待外れだった点:**

- ドキュメントのバージョン管理が不明確で、最新の正しい情報を見つけにくい

個人開発者にとって重要なのは「安定して動き続けるか」です。その観点では、改善の余地は残っているものの、月を追うごとに信頼性が増している印象があります。

## 4位：Gemini 3.2 Pro × Imagen 4 で自作アートを壁紙 120 種類に展開した 30 日

アーティストであり個人開発者でもある立場から、自分のアート作品1枚を起点に、Gemini と Imagen を組み合わせて壁紙シリーズ120枚を30日で供給したパイプラインの記録です。

[Gemini 3.2 Pro × Imagen 4 で自作アートを壁紙 120 種類に展開した 30 日](/articles/gemini-advanced/gemini-32-imagen4-artwork-to-wallpaper-pipeline-30day)

**パイプラインの概要:**

1. **Gemini 3.2 Pro による構造解析** — 元アートの色調・形状・主題・感情トーンを分析してJSONに構造化
2. **バリエーション生成プロンプトの自動作成** — 解析結果から120パターンの Imagen プロンプトを生成
3. **Imagen 4 によるバッチ生成** — Cloud Storage に出力
4. **品質フィルタリング** — 生成後に Vision API で再評価し、低品質を除外

このパイプラインで最も重要だったのは「元のアートの精神性を残す」という条件をプロンプトにどう翻訳するかでした。アーティストとしての判断がエンジニアリングの精度を左右する場面が多くありました。制作した作品には「日本特有の祈り」という主題が流れており、それを Imagen に伝えるためのプロンプト設計に最も時間をかけました。技術的な精度と、作品の内側にある意図を両立させること——それが、アーティストでありエンジニアである立場からの最大の問いでもありました。

## 5位：AdMob収益の急落を朝8時に知る仕組みをGemini APIで作った

個人開発者にとってAdMobの収益変動は死活問題です。Gemini API の Function Calling を使って、前日比で異常を検知し朝に通知する仕組みを実装した記録です。

[AdMob収益の急落を朝8時に知る仕組みをGemini APIで作った](/articles/gemini-api/gemini-api-admob-revenue-anomaly-detection)

```python
# Gemini Function Callingでの異常検知パターン
tools = [{
    "function_declarations": [{
        "name": "detect_revenue_anomaly",
        "description": "AdMob収益データの異常を検知して通知内容を生成する",
        "parameters": {
            "type": "object",
            "properties": {
                "current_revenue": {"type": "number"},
                "previous_avg": {"type": "number"},
                "threshold_pct": {"type": "number", "default": 30}
            },
            "required": ["current_revenue", "previous_avg"]
        }
    }]
}]
```

実装のポイントは「単純な閾値チェックではなく、曜日・季節変動・過去トレンドを考慮した文脈的な判断をGeminiに委ねる」設計です。単なるルールベースよりも誤報が少なく、実運用に耐えられるシステムになりました。
