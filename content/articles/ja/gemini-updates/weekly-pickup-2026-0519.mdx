## 3位：AdMob収益の急落を朝8時に知る仕組みをGemini APIで作った

ある朝、AdMob のレポートを開いたら前日の収益が突然3割落ちていた——という出来事が、この記事のきっかけです。広告系の異常は気づくのが遅れると損失が積み上がるので、Gemini API に「異常の意味づけ」を任せて、毎朝8時に Slack に通知する仕組みを組みました。

単純なしきい値アラートではなく、「これは曜日要因」「これは ATT 同意率の変動」「これは要調査」のように、Gemini に運用者の言葉で原因仮説まで考えさせています。月数万円規模で広告収益を回している個人開発者なら、すぐ役に立つはずの記事です。

## 4位：累計5,000万DLの壁紙アプリで、Gemini Function Calling をレコメンドエンジンに使ってみた

長年運用してきた壁紙アプリのレコメンド部分を、ルールベースから Gemini Function Calling 主導の設計に置き換えてみた実装記録です。ユーザーの閲覧履歴・保存履歴・現在の時間帯・天候を踏まえて、関数を呼び出す形でレコメンドを返させています。

## ランキングの選定基準について

毎週のランキングは、Google Search Console のクリック数・平均掲載順位・CTR と、サイト内でのエンゲージメント時間・内部リンククリック率を組み合わせて決めています。新しい記事は表示回数自体が少ないので、CTR の高さやリピーターからの反応も加味するようにしています。

加えて、私自身が「もう一度自分で参照したくなった記事」も評価軸に入れています。書き手として腑に落ちる記事は、長期で読まれ続ける傾向があるからです。

## よくある質問

### Q. 週間ピックアップはいつ更新されますか？

毎週火曜日の午後に更新しています。前週月曜日から日曜日までの記事を対象にしており、火曜日にご覧いただくと、その週の Gemini 関連話題に追いつきやすいガイドになります。

### Q. ピックアップから漏れた記事はもう読めませんか？

もちろん読めます。トップページや各カテゴリページ、タグページからアクセスしてください。今週は INVALID_ARGUMENT 対処、Embedding の落とし穴、Gemini 3.2 Flash の Image Output、Apps Script のタイムアウト対策など、ジャンル違いの記事を意図的に揃えています。ピックアップに入らなかった記事の中にも、特定の問題にピタリと効くものが多くあります。

### Q. ランキングはどうやって決めていますか？

Google Search Console のクリック数、サイト内の平均読了率、内部リンクからの遷移率、SNS での反響を組み合わせて、独断で並べています。アクセス数だけで決めると新しい記事に不利になるので、私自身が「読み返したくなった記事」も評価軸に入れています。
