2026年、Googleは「Gemma 4」シリーズをリリースしましました。Gemma 4は商用利用可能なApache 2.0ライセンスで提供されるオープンウェイトモデルで、スマートフォンから大規模サーバーまで幅広い環境で動作します。


## Gemma 4とは

Gemma 4はGoogleのGeminiシリーズで培われた技術を応用し、軽量・高性能を両立させたオープンウェイトモデルです。

主な特徴は以下の通りです。

まず**オープンウェイト・商用利用可能**（Apache 2.0ライセンス）。クローズドなAPI利用と異なり、モデルの重みを直接ダウンロードして自社サーバーやローカルマシンで動かすことができます。次に**256kトークンのコンテキストウィンドウ**。長い文書やコードベース全体を一度に処理できます。そして**140言語対応**。日本語を含む多言語での高品質な生成が可能です。

さらに**AICore Android統合**により、Androidデバイスでのオンデバイス実行（端末上でのAI処理）が可能になりましました。

### Hugging Face経由でのロード

```python
from transformers import AutoTokenizer, AutoModelForCausalLM
import torch

model_name = "google/gemma-4-4b-it"  # Instruction Tuningバージョン

tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    torch_dtype=torch.bfloat16,   # メモリ節約
    device_map="auto"              # GPU/CPU自動割り当て
)

# テキスト生成
inputs = tokenizer("日本語で俳句を一句詠んでください：", return_tensors="pt")
outputs = model.generate(**inputs, max_new_tokens=100, temperature=0.7)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))
```

## Gemma 4のユースケース

### 1. プライバシー重視のチャットボット

外部にデータを送りたくない企業・個人にとって、ローカル動作は大きなメリットです。

```python
import ollama

class LocalChatbot:
    """Gemma 4を使ったローカルチャットボット"""
    
    def __init__(self):
        self.conversation_history = []
    
    def chat(self, user_message: str) -> str:
        # 会話履歴に追加
        self.conversation_history.append({
            "role": "user",
            "content": user_message
        })
        
        # Gemma 4で応答生成（ローカル実行）
        response = ollama.chat(
            model="gemma4:e4b",
            messages=self.conversation_history
        )
        
        assistant_message = response["message"]["content"]
        self.conversation_history.append({
            "role": "assistant",
            "content": assistant_message
        })
        
        return assistant_message

# 使用例
bot = LocalChatbot()
print(bot.chat("医療情報の要約をお願いします"))  # 外部送信なし
```

### 3. Androidオンデバイス実装（AICore API）

```kotlin
// Android AICore APIを使ったGemma 4オンデバイス実装
// build.gradle: implementation "com.google.android.aicore:aicore:1.0.0"

import com.google.android.aicore.AICore
import com.google.android.aicore.GenerativeModel

class GemmaOnDeviceActivity : AppCompatActivity() {
    
    private lateinit var generativeModel: GenerativeModel
    
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        
        // Gemma 4 E2Bをデバイス上で初期化
        AICore.getGenerativeModel(
            modelName = "gemma-4-e2b-it",  // Edge最適化版
            context = this
        ).addOnSuccessListener { model ->
            generativeModel = model
            runInference("こんにちは！")
        }
    }
    
    private fun runInference(prompt: String) {
        // ネットワーク不要・完全オフライン実行
        generativeModel.generateContent(prompt)
            .addOnSuccessListener { response ->
                val generatedText = response.text
                Log.d("Gemma4", "Response: $generatedText")
            }
    }
}
```

## Gemini APIとの使い分け

同じGoogle製でもGemma 4とGemini APIは異なる選択肢です。

[Gemini Deep Think ガイド](/articles/gemini-advanced/gemini-3-deep-think-guide) で紹介している最新のGemini 3.1 Proは、クラウドAPIとして使う高性能モデルです。一方、Gemma 4はローカル・エッジで動かすオープンモデルです。

使い分けの基準は以下の通りです。

プライバシーが重要・オフライン必要・コスト制約がある場合は **Gemma 4**。最高性能・最新機能・マルチモーダルが必要な場合は **Gemini API**。

## FAQ

**Q: Gemma 4は日本語での利用に向いていますか？**

はい。140言語対応をうたっており、日本語の生成品質は実用的なレベルです。ただし英語に比べると若干精度が落ちる場面もあります。

**Q: MacBook（Apple Silicon）で動きますか？**

ollamaを使えばApple Siliconに最適化されたバイナリで動作します。M3 Proクラスなら4Bモデルはスムーズに動きます。

**Q: 商用プロダクトに組み込めますか？**

Apache 2.0ライセンスのため商用利用可能です。ただし「Google」や「Gemma」ブランドを誤解させる使い方は禁止されています。

**Q: ファインチューニングはできますか？**

はい。Hugging Face TRLやGoogle Vertex AI（マネージドサービス）を使ってファインチューニングできます。

**Q: Gemini APIとどちらが安いですか？**

ローカルで動かすなら実行コストはほぼゼロ（電力コストのみ）です。大量のAPIコールが必要なビジネス用途ではGemma 4の方が圧倒的に安価になります。
