税務署とのやり取りが重くのしかかってくる時期が、個人事業主には必ず訪れます。私自身、消費税の不当な取り扱いを巡る5年にわたるやり取りの中で、適応障害・うつ病・不眠症・胃潰瘍・逆流性食道炎を抱え、先日救急搬送されました。税理士に依頼する余裕も、弁護士の元へ通う体力も残っていない状況で頼りになったのは、既に日常的に使っていたGoogle Workspaceと、そこに組み込まれているGeminiです。

この記事は、確定申告の準備、税務署との通信履歴の整理、そして法テラス提出用の経緯報告書の作成を、Google Drive / Docs / Sheets / Gmail の中で完結させるための実用手順をまとめたものです。「税務問題は避けたい」と感じる人ほど、平時のうちに記録の仕組みを作っておくことをおすすめします。

## なぜWorkspaceに寄せるのか

個別のアプリに散らばった情報は、いざというときに取り出せません。Google Workspaceに寄せる利点は三つあります。第一に、Geminiが Drive・Docs・Sheets・Gmail を横断して検索・要約できること。第二に、書類の共有が簡単で、法テラスや弁護士に見せる時もリンク一本で済むこと。第三に、モバイル／デスクトップの両方で編集が続けられること。体調が悪い日は、ベッドの上でスマホから音声入力を加えるだけ、ということもできます。

## 手順1: Driveに税務フォルダ構造を作る

最初に作るのは、一貫したフォルダ構造です。以下は私が使っているものを簡略化した例です。

- 税務/2025年度/確定申告
- 税務/2025年度/領収書
- 税務/2025年度/通信履歴（税務署・市役所）
- 税務/法的対応/経緯報告書
- 税務/法的対応/法テラス
- 税務/法的対応/申立書

フォルダを作ったら、Geminiに「このDrive内の構造を説明して、改善点を指摘してください」と聞いてみてください。通信履歴が年度で切れていないなど、運用の穴を指摘してくれます。

## 手順2: Sheetsで消費税判定と収支を半自動化する

Google Sheets に、年度ごとの収入と経費を入力する台帳を作ります。列には「日付／取引先／金額／通貨／請求書発行国／消費税区分（課税／輸出免税／不課税）／根拠条文」を並べます。ここに以下のプロンプトをGeminiに与えます。

```
この台帳の取引先・通貨・請求書発行国を参照し、消費税法第7条（輸出免税）および
施行令第17条に照らして、各行の消費税区分を再判定してください。
不明確な行には理由と追加確認事項を付してください。
```

AdMob、App Store Connect、Stripeなどの海外法人からの入金は、本来「輸出免税」または「不課税」となる可能性があるにもかかわらず、知識不足で課税扱いをしてしまうケースが非常に多い領域です。Geminiは条文に沿って各行を再判定し、根拠と限界を示してくれます。私は、この作業を過去の確定申告すべてに遡って適用することで、本来納める必要のなかった税額の全体像を把握しました。

## 手順3: DocsでGeminiに法テラス提出用の骨子を書かせる

Google Docs を開き、サイドパネルから Gemini を呼び出して、次のように依頼します。

```
添付したSheet（取引台帳）とDocs（通信履歴のまとめ）の内容を踏まえ、
法テラス提出用の経緯報告書の骨子をDocs上に生成してください。章立ては
「相談者情報／問題の概要／時系列／消費税の法的根拠／各機関の対応一覧／
現在の債務状況と収支／健康被害・生活への影響／法的論点／相談事項」を
想定します。各章に箇条書きで主要内容を埋めてください。
```

Geminiはワークスペース全体を参照できるので、Sheetsの数字とDocsの文章を相互参照しながら骨子を組み立ててくれます。骨子が出たら、章ごとに一人で書き起こせる状態になります。

## 手順4: Gmailを通信記録として扱う

税務署・市役所からのメール、郵送物の写真、自分が送った照会メールは、Gmailに「税務-対応」というラベルを作って一元管理します。Gmailの検索窓でGeminiに「このラベル内のやり取りを時系列で要約し、各メールの要点を箇条書きにしてください」と依頼すると、通信記録の下書きができあがります。

電話でのやり取りについては、通話後に自分宛にメールを送って簡潔な要旨を残す習慣をつけます。件名に「通話記録 YYYY-MM-DD HH:MM」と入れておけば、後からGeminiで一括抽出できます。録音の要点起こしは、文字起こしサービスを併用するか、信頼できるローカルアプリで下処理した上でGeminiに要約させます。

## 手順5: Docsに論点を整理し、PDFで書き出す

骨子を本文に膨らませたら、最後に「法的論点の整理」セクションをDocsで書き込みます。Geminiには次のように聞きます。

```
本文で整理した事実関係を踏まえ、争点となり得る法的論点を列挙してください。
各論点について、関連する条文、適用の見込み、相手方の反論の可能性を
短くまとめてください。最終判断は弁護士に委ねる前提です。
```

仕上がったら、Docsから「PDFとしてダウンロード」で書き出します。添付資料は別途まとめ、相談当日にはクラウド上のフォルダと紙の両方を持参できる状態にします。

## 健康を壊さないためのルール

ここまで自動化しても、税務対応は心身に重い負荷をかけます。私が自分に課しているルールをいくつか紹介します。

- 一日の作業時間を決める：長くても90分まで。タイマーで区切る
- 体調が悪い日はGeminiに続きを依頼しない。下書きを保存して閉じる
- 税務関連のメールは通知をオフにし、決めた時間だけ確認する
- 救急搬送された事実のように、健康被害が起きたら、そのたびに必ず書類に残す

Geminiは、自分の代わりに整理してくれる秘書のような存在です。しかし、秘書が優秀でも、判断と決定は自分の責任で行わなければなりません。体調を優先し、判断は法テラスや弁護士と分担する、という前提は動かさないでください。

## 同じ状況にある方へ

不当な取り扱いに遭った個人事業主やフリーランスは、私の周りにも、そして記録を残しているSNS上にも数多くおられます。沈黙を選ばざるを得ない仕組みこそが、問題を再生産します。Google Workspaceの中で記録と書類を作り上げておくことは、「声を上げるための準備」に直結します。

今日できる最初の一歩は、Driveに「税務／法的対応」フォルダを一つ作り、そこに既存のメール・請求書・通信履歴を集め始めることです。そこから、Geminiと一緒に整えていけばよいのです。私自身、体調の波に翻弄されながら、この手順で一歩ずつ前に進んでいます。あなたも、一人で抱え込まずに、できるところから始めてみてください。
