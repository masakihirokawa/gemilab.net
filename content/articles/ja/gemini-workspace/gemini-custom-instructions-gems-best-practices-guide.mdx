Google Gemini の **カスタム指示（Custom Instructions）** 機能を活用すれば、AI パートナーの回答スタイルを自分の好みに完全にカスタマイズできます。本記事では、カスタム指示の設定方法から実践的な活用例までを詳しく解説します。

## カスタム指示とは？

カスタム指示は、Gemini に対して「あなたはこのように回答してほしい」という指示を事前に設定する機能です。一度設定すれば、その後のすべての会話でその指示が反映されます。

### カスタム指示でできること

- **回答スタイルの指定**: 丁寧な敬語、カジュアルなトーン、技術的な詳細度の調整
- **専門分野の設定**: 特定の業界知識や背景情報を Gemini に認識させる
- **出力形式の指定**: Markdown、JSON、表形式など、好みの形式で出力させる
- **言語設定**: 日本語で統一、技術用語は英語のままなど細かく調整可能

## カスタム指示を設定する手順

### ステップ 1: Gemini にアクセス

1. [Google AI Studio](https://aistudio.google.com/) にアクセスします
2. Google アカウントでログインします

### ステップ 2: Gems を作成

Gems（ジェムズ）は、カスタム指示を保存し、再利用できるカスタム AI パートナーです。

```
Google AI Studio のホーム画面
  → 左サイドバー「Gems を新規作成」をクリック
  → テンプレートを選択するか「空白から開始」を選択
```

### ステップ 3: システムプロンプトを入力

「Instructions」セクションに、Gemini への指示を詳しく書き込みます。これが最も重要な部分です。

```
例）コンテンツマーケッターのための Gem:

あなたは SEO に精通したコンテンツマーケッターです。
ユーザーの質問に対しては、以下のスタイルで回答してください：
- 回答は常に日本語で
- 技術用語（API、SEO、CTR など）は英語のままでも構いません
- 出力は Markdown フォーマットで
- 見出し（##）を使って階層的に構成する
- 各セクションは 100～150 文字程度に
- 最後に「参考資料」セクションを追加
```

### ステップ 4: Gem に名前を付ける

わかりやすい名前を付けます。例）「SEO ライター」「プロダクト分析官」「JavaScript チューター」

### ステップ 5: 保存して使用開始

「保存」ボタンをクリックすれば、今後いつでもこの Gem を使えます。

## カスタム指示のベストプラクティス

### 1. 目的を明確に

```
❌ 悪い例：
「何でも手伝ってください」

✅ 良い例：
「あなたは企業向けの LinkedIn コンテンツ作成スペシャリストです。
営業リードを引きつけるための短編記事を書くのが得意です。」
```

### 2. 回答スタイルを具体的に指定

```
「回答の際は以下の形式でお願いします：
- 導入（30 秒で読める概要）
- 詳細な解説（技術背景を含む）
- 実装例（コード付き）
- よくある質問への回答
- 次のステップ」
```

### 3. 背景情報を与える

```
「あなたは 15 年の iOS 開発経験を持つベテランエンジニアです。
Swift、SwiftUI、Firebase に詳しく、
最新の iOS 開発トレンド（例：Async/Await、Concurrency）を理解しています。」
```

### 4. 出力形式を指定

```
「常に Markdown フォーマットで回答してください。
テーブルが必要な場合は HTML テーブルを使用してください。」
```

## 実践的なカスタム指示の例

### 例 1: ブログライター向け

```
あなたはプロのテクノロジーブログライターです。

【回答スタイル】
- 読者は初心者から中級者向けを想定
- 難しい用語は最初に定義する
- 実例や具体例を3つ以上含める
- 最後に「参考リンク」セクションを付ける

【形式】
- Markdown 形式
- 見出しは ##、###、#### を使い分け
- コードブロックには言語を明記
- 重要な部分は **太字** で強調
```

### 例 2: データ分析者向け

```
あなたはデータ分析の専門家です。

【あなたの背景】
- 5 年以上の統計解析経験
- Python（pandas、numpy）に精通
- Google Analytics、BigQuery を日常的に使用

【回答方法】
- 常に数字ベースで説明
- グラフやテーブル形式で結果を提示
- 統計的有意性を明記
- 次のアクション（施策提案）まで含める
```

### 例 3: プログラミングメンター向け

```
あなたは 20 年のソフトウェア開発経験を持つベテラン開発者です。

【教える対象】
- 学習者は初心者〜中級者

【教え方の原則】
- 最初に「なぜそうするのか」という背景を説明
- 段階的にステップを示す
- 完全に動作するコード例を毎回含める
- よくあるミスと対策を指摘
- 応用例を示す

【出力形式】
- コードは JavaScript/Python/Go など複数言語に対応
- コメント付きコード例必須
- 実行結果も示す
```

## カスタム指示の注意点

### 1. 長すぎない

カスタム指示は詳しければ詳しいほど良いわけではありません。**200～400 文字程度** が目安です。長すぎると Gemini が指示の優先順位を判断しにくくなります。

### 2. 矛盾する指示を避ける

```
❌ 「短く答えてください」 + 「詳しく説明してください」（矛盾）
✅ 「要点を先に述べ、その後で詳細を説明してください」（明確）
```

### 3. 定期的に見直す

ユースケースが変わったら、カスタム指示も更新しましょう。Gems は後から編集できます。

## カスタム指示が反映されない場合のトラブルシューティング

### ケース 1: Gem が正しく保存されていない

```bash
# 対処法：
1. 「保存」ボタンをクリック
2. 保存完了のメッセージを確認
3. ブラウザをリロード
4. 再度 Gem を開く
```

### ケース 2: 指示が反映されていない

```
原因: Gemini が指示を「提案」と見なしている可能性

対処法:
「あなたは【条件】です。」という命令形で書き直す
「～することをお願いします」→「～してください」に統一
```

### ケース 3: 回答が不安定

長めのカスタム指示を試している場合、**文字数を削減** してみてください。

## FAQ — カスタム指示よくある質問

### Q1: カスタム指示は他のユーザーに見られる？

**A:** いいえ。カスタム指示は完全にあなたのプライベート設定です。他ユーザーからは見えません。

### Q2: 複数の Gem を持つことはできる？

**A:** はい。用途ごとに複数の Gem を作成できます。例）「SEO ライター」「コード査読官」「英語教師」など。

### Q3: Gem を他のユーザーと共有できる？

**A:** 現在、Gem の直接共有機能はありません。ただし、カスタム指示の内容をテキストで共有することはできます。

### Q4: モバイル Gemini App でもカスタム指示は有効？

**A:** 一部機能制限があります。Google AI Studio での完全な機能利用を推奨します。

### Q5: カスタム指示で機密情報を保存しても大丈夫？

**A:** クレジットカード番号やパスワードなどの機密情報は保存しないでください。Gems はクラウド保存されます。

## まとめ

Gemini のカスタム指示を活用すれば、AI パートナーをあなた専用にカスタマイズできます。

**ポイント整理:**
- カスタム指示は Gems で保存できる
- 目的・回答スタイル・出力形式を明確に指定する
- 200～400 文字程度が目安
- 定期的に見直す

本格的な Gemini 活用を目指すなら、まずは自分用の Gem を 1 つ作成して実際に使ってみることをお勧めします。
